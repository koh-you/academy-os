좌표 설명:
- **`\AddToShipoutPictureFG`** (★ 핵심): Background로 그리면 answerheader/quickgrid 박스가 분할선 위로 덮어 *시각상 안 보임*. Foreground로 그려야 모든 박스 위에 분할선 노출.
- **xshift=1mm**: 페이지 절대 중심(94mm) → 본문 가운데(95mm) 보정. `inner=15mm, outer=13mm` 차이 절반
- **yshift 1페이지=-125.6mm**: examsection 가로선 직후 (answerheader 박스 + quickgrid + examsection 헤더 모두 통과). v5 -112mm에서 아래로 조정 + 위·아래 미세 연장 반복 후 확정.
- **yshift 2~마지막=-13.6mm**: 헤더 가로선 직후 (style.sty geometry: top 18 + headheight 10 + 약간 안전). v5 -30mm에서 위로 조정 + 위 미세 연장 반복 후 확정.
- **yshift 끝=+15.8mm**: footer 가로선 직전. v5 +18mm에서 아래 미세 연장 반복 후 확정.

## 2. answerbox 환경 — 정답 표기 양식

마스터 명시 (2026-07-01): "정답에 박스 치지마 + 글씨 색 검정 + 폰트 두껍게 + 황금색 직사각형 마커 살림"

```latex
\renewenvironment{answerbox}{%
  \par\noindent
  \textcolor{vB-answer-rule}{\rule[-0.6mm]{2mm}{4.5mm}}\hspace{2mm}%
  \bfseries\color{black}%
}{%
  \par\medskip%
}
```

규칙:
- 박스(tcolorbox) 일체 제거
- 골드 좌측 바·황금 텍스트 일체 제거
- 정답 텍스트 = 굵은 검정
- 마커 = 황금색 (vB-answer-rule #D4A017) 세로 직사각형 (가로 2mm × 세로 5.1mm)

사용 예:
```latex
\soltitle{1}{경우의 수의 합의 법칙 다루기}{2}
\begin{answerbox}정답: ④ $12$\end{answerbox}

두 주사위의 눈을 ... (풀이 본문)
```

## 4. \soltitle (풀이 헤더)

```latex
\soltitle{문항번호}{[출제의도] 유형명 다루기}{배점}
```

예: `\soltitle{16}{이웃하지 않는 자리에 사람 배치 다루기}{4}`

### 4.1 헤더 아래 가로선 (2026-07-01 확정)

`\soltitle` 매크로 내부 헤더 밑줄은 **TikZ 스트로크 + 1pt + vB-deep** 표준.

```latex
\par\nobreak\vspace{-4pt}\noindent%
\tikz{\draw[vB-deep, line width=1pt, line cap=butt] (0,0) -- (\linewidth,0);}%
\par\vspace{12pt}
```

🔴 **변경 금지 사유**: `\rule` fill 또는 얇은(0.3~0.75pt) 스트로크는 문항이 페이지상 놓이는 절대 Y 좌표가 뷰어 픽셀 그리드와 정렬되는지에 따라 anti-aliasing 폭이 변해 **문항별 두께가 불균일하게 보임** (예: #4·15·16·22가 다른 문항보다 두꺼워 보임 사건 2026-07-01).

- 색 = `vB-deep` (#1E4A8F) — [출제의도] 라벨과 동색
- 두께 = 1pt — sub-pixel 편차 흡수 최소값
- 위치 = 헤더 뒤 `\vspace{-4pt}` 밀착, 아래로 12pt 여백
