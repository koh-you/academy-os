# 문제 검증 체크리스트

문제 작성 후 아래 항목을 모두 확인한다.

## 수학적 정확성
- [ ] 문제 조건이 충분하고 모순이 없는가
- [ ] 풀이의 각 단계가 논리적으로 타당한가
- [ ] 최종 답이 정확한가 (역대입 등으로 검증)
- [ ] 사용한 공식/정리가 교육과정 범위 내인가

## 난이도 적합성
- [ ] 표시된 난이도와 실제 난이도가 일치하는가
- [ ] 해당 난이도에서 요구되는 사고 수준인가
- [ ] 계산량이 난이도에 적합한가

## 교육적 가치
- [ ] 이 문제를 통해 학습자가 얻는 것이 명확한가
- [ ] 유형 분류가 적절한가
- [ ] 풀이가 학습자 수준에서 이해 가능한가

## 표기 및 포맷
- [ ] LaTeX 수식이 올바르게 렌더링되는가
- [ ] 문제 번호와 난이도 라벨이 올바른가
- [ ] 일관된 표기법을 사용하고 있는가
