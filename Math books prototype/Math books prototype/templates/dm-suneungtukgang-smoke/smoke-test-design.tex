\dmexamplebadge{1}{거듭제곱근의 정의}

\begin{dmproblem}
실수 $a$ 와 자연수 $n$ 에 대하여 $x^n = a$ 를 만족시키는 실수 $x$ 를 $a$ 의
$n$제곱근이라고 한다. 다음 값을 구하여라.

$$\sqrt[3]{27} + \sqrt[4]{16}$$
\end{dmproblem}

\begin{dmapproach}
지수·근호의 관계를 이용하여 각 항의 값을 정확히 구한다. $\sqrt[n]{a} = a^{1/n}$
로 지수형태로 표현하면 계산이 간명해진다.
\end{dmapproach}

\begin{dmsolution}
$\sqrt[3]{27} = 3^{3 \cdot 1/3} = 3$ 이고, $\sqrt[4]{16} = 2^{4 \cdot 1/4} = 2$
이므로 $$\sqrt[3]{27} + \sqrt[4]{16} = 3 + 2 = 5.$$
\end{dmsolution}

\dmanswer{5}
