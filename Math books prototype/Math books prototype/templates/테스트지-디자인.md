# 테스트지 제작 지침 (공통수학1 단원 테스트)

> **단일 출처**: 본 문서가 CLAUDE.md §"테스트지 제작 지침"의 분리본. 테스트지 작업 시 본 문서를 직접 참조.

## 개요
공통수학1 단원별 시험지("단원 테스트")는 학생 시험용 문제지 + 별도 답지(해설)로 구성. 출력 경로 `output/공통수학1/testNN-단원명.tex` (+ `-답지.tex`). 유형편과 다른 독립 포맷이지만 같은 템플릿(`mathbook.cls` + `mathbook-*.sty`)을 사용하고 일부 명령(`\stepone/two/three`, `\stepbanner`, `\stepfooterblock`)을 .tex 안에서 로컬 오버라이드하여 디자인을 조정.

**기본 포맷(배너 위치 / 가운데 분할선 / 상하 빨간 라인 / footer)은 한 번 정해지면 절대 흔들면 안 됨.** 디자인 변경 시 이 요소를 건드리지 않는 범위에서 본문만 수정.

## 문항 구성
- **총 15문항**, 페이지당 4문항 (마지막 페이지 3문항) → **4페이지** 구성
- 난이도 분포: **난이도3(중) × 4 + 난이도4(중상) × 7 + 난이도5(최상) × 4**
  - 난이도1·2(기본)는 사용하지 않음 — 중간 이상만 출제
- 페이지별 난이도 배치:
  - **Page 1**: 난이도3 × 4
  - **Page 2**: 난이도4 × 4
  - **Page 3**: 난이도4 × 3 + 난이도5 × 1
  - **Page 4**: 난이도5 × 3

## 5단계 난이도 점 시스템 (테스트지 전용)
.tex 파일 preamble에서 점 매크로를 오버라이드:
```latex
\renewcommand{\dota}{\,{\fontsize{6.5}{6.5}\selectfont ●○○○○}}   % 1단 하
\renewcommand{\dotb}{\,{\fontsize{6.5}{6.5}\selectfont ●●○○○}}   % 2단 중하
\renewcommand{\dotc}{\,{\fontsize{6.5}{6.5}\selectfont ●●●○○}}   % 3단 중 (난이도3)
\newcommand{\dotd}{\,{\fontsize{6.5}{6.5}\selectfont ●●●●○}}     % 4단 중상 (난이도4)
\newcommand{\dote}{\,{\fontsize{6.5}{6.5}\selectfont ●●●●●}}     % 5단 최상 (난이도5)
```

## 페이지 레이아웃 (문제지)
- **표지 없음** — `\chapterintro` 사용하지 않음, 1페이지부터 바로 본문 시작
- **2단 컬럼**: 좌/우 minipage `[t][\probcolheight][t]{\probcolwidth}` 2개 + `\hfill`
  - 각 컬럼에 2문제 (마지막 페이지 우측 컬럼만 1문제)
  - `cellab` 환경 사용 (cellc 사용하지 않음)
- **미니페이지 내부 구조**:
  ```latex
  \begin{minipage}[t][\probcolheight][t]{\probcolwidth}
    \vspace*{-3mm}                  % 상단 빨간 라인에 첫 문제를 가깝게 끌어올림
    \begin{cellab}\begin{prob}[\dotX]...\end{prob}\end{cellab}
    \vfill                          % 사이 공간 (균등 분배)
    \begin{cellab}\begin{prob}[\dotX]...\end{prob}\end{cellab}
    \vspace*{5.5cm}                 % 마지막 문제 아래 풀이공간 (강제 fixed)
  \end{minipage}
  ```
- **문제 번호**: `prob` 환경 사용 (대표문제용 `repprob`는 컬러 박스 박스가 붙으므로 사용하지 않음). 번호는 자동 3자리 zero-padded (001~015), 검정색.
- **풀이공간 균형**: `\vfill`이 위 + `\vspace*{5.5cm}`가 아래 = 첫 문제 아래 ~5.5cm, 둘째 문제 아래 5.5cm로 거의 균등.

## 상단 배너 — 페이지 1 (`\stepone` 오버라이드)
```latex
\renewcommand{\stepone}{%
  \renewcommand{\currentstepcolor}{step3color}%
  \pagestyle{steppage}%
  \noindent
  \makebox[\textwidth][l]{%
    \begin{tikzpicture}[baseline=(badge.south)]
      % 좌: 깊통핵심체크 배지 (12pt, 패딩 7/3pt, 옅은 파랑 + 음영)
      \node[fill=step1color!55, text=black, rounded corners=2pt,
            inner xsep=7pt, inner ysep=3pt,
            drop shadow={shadow xshift=1pt, shadow yshift=-1.2pt, opacity=0.32, fill=black!70},
            font=\fontsize{12}{12}\selectfont\bfseries\sffamily,
            anchor=south west] (badge) at (0,0) {깊통핵심체크};
      % 가운데: 공통수학 I / 단원명 (2줄, 흰 박스 + 테두리 + 강한 음영)
      \node[anchor=south, font=\sffamily\fontsize{14}{17}\selectfont, align=center,
            text=mbdarkgray, fill=white, draw=mbline, line width=0.45pt,
            rounded corners=3.5pt, inner xsep=20pt, inner ysep=8pt,
            drop shadow={shadow xshift=2.2pt, shadow yshift=-2.7pt, opacity=0.6, fill=black!80}]
        at (0.5\textwidth, 0) {공통수학\,I\\[2pt]{\fontsize{18}{20}\selectfont\bfseries 단원명}};
      % 우: 이름 기재란 (9pt + 2.6cm 밑줄)
      \node[anchor=south east, font=\sffamily\fontsize{9}{9}\selectfont]
        at (\textwidth, 0) {이름\,\rule[-2pt]{2.6cm}{0.4pt}};
    \end{tikzpicture}%
  }%
  \par\vspace{4pt}
  \noindent\textcolor{step3color}{\rule{\textwidth}{1.2pt}}
  \par\vspace*{4pt}%
  \stepsplitlinetall
}
```
- 세 요소(배지·박스·이름란) 모두 `y=0` 바닥 정렬 — 빨간 라인 바로 위에 자연스럽게 붙음
- **가운데 박스가 가장 높음(~20mm 상부)** — 다른 요소(배지·이름) 추가/변경해도 박스 높이 안에서면 픽처 전체 높이 불변 → 빨간 라인 위치 안전

## 상단 배너 — 페이지 2/3/4 (`\stepbanner` 오버라이드)
```latex
\renewcommand{\stepbanner}[3]{%
  \noindent
  \tikz[baseline=-1pt]{\node[fill=step1color!55, text=black, rounded corners=2pt,
    inner xsep=8pt, inner ysep=3pt,
    drop shadow={shadow xshift=1pt, shadow yshift=-1.2pt, opacity=0.3, fill=black!70},
    font=\fontsize{14}{14}\selectfont\bfseries\sffamily]{깊통핵심체크};}%
  \par\vspace{4pt}
  \noindent\textcolor{#3}{\rule{\textwidth}{1.2pt}}
  \par\vspace*{2pt}%
}
```
- 배지만 단독 (가운데 박스/이름란 없음, 14pt + 패딩 8/3pt)
- 페이지 1보다 배너가 작음 → 빨간 라인이 페이지 상단에 더 가까움

## 전 페이지 STEP 색상 통일 (`\stepone/two/three`)
모든 STEP 페이지에서 라인·footer 색을 `step3color`(빨강)로 통일:
```latex
\renewcommand{\stepone}{... step3color 사용 ...}
\renewcommand{\steptwo}{ \renewcommand{\currentstepcolor}{step3color}%
  \pagestyle{steppage}\stepbanner{2}{}{step3color}\stepsplitlineshort }
\renewcommand{\stepthree}{... 동일 ...}
```
페이지 4는 `\clearpage \stepthree`를 한 번 더 호출 (4페이지 분량의 STEP 3 페이지 2장).

## Footer (`\stepfooterblock` 오버라이드)
페이지 번호만 검정으로 (라인·로고는 그대로):
```latex
\renewcommand{\stepfooterblock}{%
  \textcolor{\currentstepcolor}{\rule{\textwidth}{1.2pt}}\\[3pt]%
  \makebox[0.3\textwidth][l]{\strut}%
  \makebox[0.4\textwidth][c]{\small\textsf{\bfseries\color{black}\thepage}}%
  \makebox[0.3\textwidth][r]{\raisebox{-4pt}{\includegraphics[height=22pt]{logo/학원로고 (깊이와통찰)}}}%
}
```

## 좌/우 분할선 (페이지 중앙 세로 검정 라인)
- 굵기 0.3pt 검정
- **페이지별 시작/끝 좌표가 다름** (배너 높이 차이 때문)
- TikZ `remember picture` overlay (페이지에 공간 차지 안 함)

```latex
% STEP 1 (큰 배너 + 가운데 박스, 픽처 높이 ~20mm)
\newcommand{\stepsplitlinetall}{%
  \begin{tikzpicture}[remember picture, overlay]
    \draw[black, line width=0.3pt]
      ($(current page.north)+(0,-35mm)$) --
      ($(current page.south)+(0,14.5mm)$);
  \end{tikzpicture}%
}
% STEP 2/3 (작은 배너만, 픽처 높이 ~5mm)
\newcommand{\stepsplitlineshort}{%
  \begin{tikzpicture}[remember picture, overlay]
    \draw[black, line width=0.3pt]
      ($(current page.north)+(0,-21mm)$) --
      ($(current page.south)+(0,14.5mm)$);
  \end{tikzpicture}%
}
```
- 상단: 빨간 라인 바로 아래 시작 (STEP 1=35mm, STEP 2/3=21mm)
- 하단: 빨간 라인 바로 위 종료 (14.5mm 위)
- 픽셀 단위 조정 후 양 페이지 모두 빨간 라인을 침범하지 않도록 검증 필요

## 답지(`-답지.tex`)
- 별도 파일, multicols 2단 구조
- preamble은 문제지와 유사하지만 `\probsol` 매크로 추가 (번호 + 컬러 배지 + 풀이 + 답)
- STEP별 묶음 (난이도별 정리):
  - **STEP 1**: 1~4번 (난이도3, `\probsol{N}` — 기본 step1color 파랑 배지)
  - **STEP 2**: 5~11번 (난이도4, `\probsol[step2color]{N}` — 보라 배지)
  - **STEP 3**: 12~15번 (난이도5, `\probsol[step3color]{N}` — 빨강 배지)
- STEP 페이지 배너는 문제지와 동일한 깊통핵심체크 (빨간 라인)
- 표지 없음 — 1페이지부터 풀이 바로 시작
- 풀이 환경: `\begin{solution}...\end{solution}` + `\answer{...}` (정답 강조)

## 디자인 의도 핵심 결정 ("왜 이렇게 했는가")
- **표지 삭제**: 4페이지 단원 테스트지에서 표지는 공간 낭비. 1페이지부터 바로 시작.
- **5단계 점 시스템**: 유형편의 3단계(상/중/하)보다 세분화된 평가가 필요. 5단계가 변별력 확보.
- **모든 STEP 빨강 통일**: STEP별 다른 색(파/보/빨)은 시험지에서 산만함. 빨강 단일톤이 시험지 정체성.
- **배지·박스·이름란 3-컬럼 페이지 1 헤더**: 시험지 첫 페이지는 정체성(과목/단원)과 응시자 정보가 필요. 가운데 박스가 헤드라인 역할.
- **STEP 1만 큰 배너, STEP 2~ 는 작은 배너**: 응시자 정보는 첫 페이지만, 이후는 깊통핵심체크 브랜드만.
- **검정 분할선**: 시험 중 학생이 좌/우 컬럼을 구분해 풀이공간을 명확히 인지하도록.
- **`\vspace*{5.5cm}` 풀이공간**: 시험 도중 학생이 풀이를 적을 공간. 균등 분배가 핵심 (위 \vfill + 아래 5.5cm).
- **`\vspace*{-3mm}` 상단 끌어올림**: 빨간 라인과 첫 문제 사이 간격을 시각적으로 좁힘.
- **번호 박스 제거(`prob` only)**: 유형편의 대표문제 강조용 컬러 박스는 시험지에선 모든 문제가 동등하므로 검정 번호로 통일.
- **로고는 footer만**: 헤더에 로고를 추가하면 배너 높이가 늘어나 빨간 라인이 이동. footer는 영구 위치라 안전.
