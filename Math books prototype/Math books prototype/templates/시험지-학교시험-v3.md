## 페이지 배치 — `\probpair` 자동 균등 분배 시스템 (2026-07-11 v3.1)

### 핵심 원리

이전 v3.0 방식(`\begin{minipage}[t][\probboxheight][t]{0.46\linewidth}` 수동 크기 지정)은 좌우 문항 크기 차이에 따라 아래 여백이 불균등한 문제 발생. **v3.1은 `\probpair` 매크로가 자동으로:**

1. **좌우 문항 실제 크기 측정** (`\savebox`)
2. **max(좌, 우) + \probvpadding(20mm)** 으로 좌우 minipage 크기 자동 통일
3. **좌우 하단 baseline 정렬** — 페이지 빈 공간 최소화, 각 pagepair 안 좌우 여백 균등

**필수**: problem 환경도 자연 크기 minipage `[t]{\linewidth}` 사용 (문제.tex 상단 `\renewenvironment{problem}` override).

### 페이지 1~3 (선택형)

```latex
% preamble에 문항 뒤 20mm 여백 padding 설정 (기본값)
% \setlength{\probvpadding}{20mm}  ← style.sty 기본, 필요 시 override

\begin{pagepair}
\vfill                                % 상단 여백 자동 흡수
\probpair{%
  \begin{problem}{1}{s} ... \end{problem}
}{%
  \begin{problem}{2}{s} ... \end{problem}
}

\vfill                                % 상하 pagepair 사이 여백 자동 흡수

\probpair{%
  \begin{problem}{3}{s} ... \end{problem}
}{%
  \begin{problem}{4}{s} ... \end{problem}
}
\vfill                                % 하단 여백 자동 흡수
\end{pagepair}
```

**3개 `\vfill`**이 페이지 안 남는 공간을 상단·중간·하단으로 균등 분배. `\vspace{6mm}`·`\vspace{25mm}` 수동 지정 폐기.

### problem 환경 로컬 override (문제.tex 상단)

```latex
\makeatletter
\renewenvironment{problem}[2]{%
  \par%
  \setcounter{probnum}{#1}%
  \noindent
  \begin{minipage}[t]{\linewidth}%     ← [t][\probboxheight][t] 아닌 자연 크기
  \setlength{\parskip}{4pt plus 1pt}%
  {\sffamily\bfseries\large\color{black}#1.}\par\smallskip\ignorespaces
}{%
  \end{minipage}\par%                  ← \vfill\null 제거
}
\makeatother
```

**Why**: `\probpair`가 `\savebox`로 문항 자연 크기를 측정하려면 problem 안 minipage가 자연 크기여야 함. `[t][\probboxheight][t]` 고정 크기면 measurement가 항상 probboxheight 반환 → 자동 통일 실패.

### 페이지 4~ (서술형) — 소문항 vspace 실전 표준 (2026-07-07 확립)

| 문항 형태 | probboxheight | 소문항별 vspace |
|---|---|---|
| **소문항 2개, 첫째 계산량 많음 (문제 13)** | 175mm | (1) **70mm** · (2) **45mm** |
| **소문항 2개, 균형 (문제 16)** | 175mm | (1) **60mm** · (2) **45mm** |
| **소문항 3개 (문제 14)** | **205mm** | (1) **50mm** · (2) **50mm** · (3) **55mm** |

첫째 소문항이 계산량 많으면 첫 vspace를 크게. 문항별 조정 가능.

```latex
\setlength{\probboxheight}{175mm}  % 소문항 2개
% 또는
\setlength{\probboxheight}{205mm}  % 소문항 3개

\noindent
\begin{minipage}[t][\probboxheight][t]{0.46\linewidth}
\begin{problem}{13}{s}
\pointbadge{6}\par\smallskip
% 발문
\vspace{3mm}
\textbf{(1)} 소문항 1 \hfill [3점]
\vspace{55mm}  % 학생 풀이 공간

\textbf{(2)} 소문항 2 \hfill [3점]
\vspace{55mm}
\end{problem}
\end{minipage}%
\hfill
\begin{minipage}[t][\probboxheight][t]{0.46\linewidth}
% 문제 14
\end{minipage}
```

**서술형 페이지 별도 `\examsection` 금지** (1페이지 헤더에 통합 표기).

## 보기 환경 4종 (2026-07-07 v3.0 최종)

| 환경 | 배치 | 용도 | 정렬 방식 |
|---|---|---|---|
| `choices` | **한 줄 강제 폭 균등** | 짧은 5개 (숫자·짧은 식) | `\hbox to \linewidth` + 4 hfill 균등 |
| `choicesv` | 5줄 세로 (5인자) | 긴 부등식·긴 수식 · 좁은 minipage | tabular `l` 왼쪽 정렬 |
| `choices32` | 3-2 두 줄 (5인자) | 좌표·분수 등 짧은 5개 | tabular* `\extracolsep{\fill}` 균등 + **12pt 줄 간격** |
| `choicesii` | 2-2-1 (5인자) | 중간 길이 5개 | tabular 2컬럼 균등 |

**choices 균등 배치 원리** (2026-07-07 확립):
- `\hbox to \linewidth\bgroup...\egroup` 로 minipage 폭 강제
- `\choice{}` 첫 번째: `\hfill` 없음 → **① 왼쪽 시작점 (문제 첫 줄과 일치)**
- `\choice{}` 두 번째~다섯 번째: 앞에 `\hfill` (4개 hfill 균등 분할)
- 결과: **① 왼쪽 · ⑤ 오른쪽 · ③ 정확히 중앙**

**choices32 두 줄 간격** (2026-07-07 확립):
- `\\[12pt]` (3배 확대). 기존 4pt는 다닥다닥 붙어 있음 시각 문제.

**5인자 문법 (choicesii·choicesv·choices32)**:
```latex
\begin{choicesv}
{$-3 - 3\sqrt{5} < k < -3 + 3\sqrt{5}$}
{$-5 - 3\sqrt{5} < k < -5 + 3\sqrt{5}$}
{...}
{...}
{...}
\end{choicesv}
```

**⚠️ 존재하지 않는 환경 (2026-07-06 실수 사건)**:
- ❌ `\begin{cond}` → 정답: `\begin{conditions}` 환경 (텍스트 직접 (가)(나)(다) + `\\[3pt]`)
- ❌ `\begin{step}`
- ❌ `\begin{soltitle}...\end{soltitle}` → 정답: `\soltitle{}{}{}` 명령어
- ❌ `\circledchoice{N}` → 정답: `\quick{번호}{③ 답}`

## conditions 환경 사용법

```latex
\begin{conditions}
(가) $A \cup B = U$ \\[3pt]
(나) $A \cap B = \{2, 4\}$ \\[3pt]
(다) $A - B = \{6, 8\}$
\end{conditions}
```

`\item[(가)]` 문법 **미지원**. 텍스트 직접 (가)(나)(다) 또는 ㄱㄴㄷ 입력.

## 수식 배치 규약

### 긴 수식 + 조사 붙이기 → conditions 박스 활용 (권장, 2026-07-07 확립)

발문 안 여러 조건 또는 긴 수식 뒤에 조사가 오면 스페이싱 이슈 발생:
```
❌ 두 직선 $l_1: (a-1)x + 2y - 3 = 0$과 $l_2: 3x - (a+2)y + 5 = 0$이 서로 수직일 때...
❌ 전체집합 $U$의 두 부분집합 $A$, $B$에 대하여 $n(U)=30$, $n(A)=18$, $n(B)=15$, $n(A \cap B)=8$일 때...
```

**해결: `conditions` 박스로 분리**:
```
✅ 다음 두 직선이 서로 수직일 때, 실수 $a$의 값은?
   \begin{conditions}
   $l_{1}:\;(a-1)x + 2y - 3 = 0$ \\[3pt]
   $l_{2}:\;3x - (a+2)y + 5 = 0$
   \end{conditions}

✅ 전체집합 $U$의 두 부분집합 $A$, $B$가 다음을 만족시킬 때, $n(A^c \cap B^c)$의 값은?
   \begin{conditions}
   $n(U)=30$, \ $n(A)=18$, \ $n(B)=15$, \ $n(A \cap B)=8$
   \end{conditions}
```

**또는 단일 긴 수식은 디스플레이 수식**:
```
✅ 실수 $k$의 값에 관계없이 다음 직선이 지나는 점의 좌표를 $(a,\,b)$라 할 때, $a + b$의 값은?
$$(k+1)x - (k-2)y - 3k - 3 = 0$$
```

관련 정책: `CLAUDE.md` §"수식 줄바꿈·디스플레이 배치 규약"

## 답지 형식

### 정답표
```latex
\begin{quickgrid}
\quick{1}{③ $5$} & \quick{2}{③ $(3,-4)$} & \quick{3}{③ $10$} & \quick{4}{③ $7$} & \quick{5}{③ $5$} \\
\quick{6}{②} & \quick{7}{③ $1$} & \quick{8}{⑤ ㄱ,ㄴ,ㄷ} & \quick{9}{① $\tfrac{4\sqrt{17}}{3}$} & \quick{10}{⑤ $3$} \\
...
\end{quickgrid}
```

### 풀이 (`\soltitle` 명령어 + `answerbox`)
```latex
\soltitle{1}{두 점 사이 거리 다루기}{2}
\begin{answerbox}정답: ③ $5$\end{answerbox}

두 점 사이 거리 공식으로
\[ \overline{\mathrm{AB}} = \sqrt{(2-(-2))^{2}+(-1-2)^{2}} = 5. \]
```

- `\soltitle{번호}{제목}{배점}`: 명령어 (환경 아님)
- `\begin{answerbox}...\end{answerbox}`: 정답 박스
- 풀이는 그냥 텍스트 (별도 `step` 환경 사용 안 함)
