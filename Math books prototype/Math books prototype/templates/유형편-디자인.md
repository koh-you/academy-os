# 유형편 LaTeX 디자인 가이드

> **단일 출처**: 본 문서가 CLAUDE.md §"유형편 LaTeX 템플릿 구조" + §"유형편 페이지 레이아웃 규칙" + §"유형편 콘텐츠 규약" + §"변경 가능/금지 영역"의 분리본. 유형편 작업 시 본 문서를 직접 참조.

## LaTeX 템플릿 구조 (`templates/mathbook.cls` + `mathbook-*.sty`)

- **`mathbook.cls`** — 8pt `extarticle` 기반. 한글 `kotex` + Malgun Gothic, 수식 `unicode-math` + Latin Modern Math. `tikz`(+ `calc` 라이브러리), `tcolorbox` (skins, breakable) 로드.
- **`mathbook-layout.sty`** — B5 페이지 geometry, fancyhdr footer/header, 표지(`\chapterintro` + TikZ 배경), 개념 페이지 배너(`\conceptbanner`), STEP 배너(`\stepone/\steptwo/\stepthree`), STEP 연속 페이지 헤더(`\stepcontheader`), 페이지 스타일(`steppage`), `\probcolheight` / `\probcolwidth` 길이 정의, `\graphicspath{{../../}{./}}` 설정.
- **`mathbook-boxes.sty`** — `defbox`(공식/정의), `typetip`(유형 해결 TIP), `schema`, `thinkbox`
- **`mathbook-problems.sty`** — `\dota/\dotb/\dotc` 난이도 점, `\freq/\essay/\examvar` 뱃지, `\typename`/`\typeheader`(유형 헤더), `cellab`/`cellc`(고정높이 문제 셀), `prob`/`repprob` 환경(3자리 자동 번호, leading 4pt), `\choices/\choicesii/\choicesv` 보기, `\lefttype/\righttype`(매크로 형태 컬럼 래퍼).
- **`mathbook-colors.sty`** — 컬러 팔레트: 브랜드(`mbmain` 보라/`mblighttint`/`mbaccent` 골드), STEP 컬러(`step1color` 파랑/`step2color` 보라/`step3color` 빨강), 개념(`conceptcolor` 짙은청색), 뱃지(`freqcolor` 등), 중성(`mbgray`, `mblightgray`, `mbline`, `mbdarkgray`).

## 페이지 레이아웃 규칙

### 페이지 geometry
- **용지**: B5
- **여백**: `top=12mm, bottom=24mm, left/right=13mm`
- **header/footer**: `headheight=14pt, headsep=6pt, footskip=28pt`
- **본문 폰트**: 8pt (`extarticle`). 표지/배너 등 시각 강조 요소는 `\fontsize` 절대값 사용.

### 본문 컬럼 (STEP 페이지)
- 좌/우 2단 minipage 패턴:
  ```latex
  \noindent
  \begin{minipage}[t][\probcolheight][t]{\probcolwidth}
    \typeheader{유형명}{TIP}
    \begin{cellab}\begin{repprob}[\dotX...]...\end{repprob}\end{cellab}
    \vfill
    \begin{cellab}\begin{prob}[...]...\end{prob}\end{cellab}
    \vfill
    \begin{cellab}\begin{prob}[...]...\end{prob}\end{cellab}
  \end{minipage}%
  \hfill
  \begin{minipage}[t][\probcolheight][t]{\probcolwidth}
    ...
  \end{minipage}
  ```
- **`\probcolheight = 16.8cm`** (2026-06-03 조정) — 컬럼 내 `\vfill` 신축량(≈2.6cm)과 minipage 바깥 본문 빈공간(≈3.7cm)으로 inter-prob 풀이공간보다 마지막 문제 아래가 살짝 넓음. 완벽 균등이 아니라 균형감 우선. strut/choices 간격 증가 누적으로 콘텐츠가 늘어난 만큼 bottom을 +0.7cm 확보.
- **`\probcolwidth = 0.45\textwidth`** — 좌/우 컬럼 사이 `\hfill` 분배로 약 0.10·textwidth(≈15mm) 가운데 간격.
- **[t] 내부 정렬의 함정**: minipage 마지막에 위치한 stretchable glue(`\vfill`, `\probendvfill` 등)는 TeX vbox 마감 시 strip되어 신축이 안 됨. 따라서 마지막 `\vfill`/`\probendvfill`을 두지 않고, 대신 `\probcolheight`를 줄여 외부 본문 공간으로 균형을 맞춤.

### 컬럼 내 셀 구조
- STEP 1/2: `\typeheader{...}{...}` (2cm 고정) → `cellab`(repprob 3.2cm 고정) → `\vfill` → `cellab`(prob) → `\vfill` → `cellab`(prob)
- STEP 3: `cellc` × 3 (각 4cm 고정), 사이에 `\vfill`
- 연속 페이지(STEP 첫 페이지 다음): `\clearpage` 직후 `\stepcontheader` (배너 자리 높이 + 컬러 라인) 호출 → minipage 시작
- `cellab` / `cellc` 고정 높이로 좌/우 컬럼의 N번째 문제 시작 위치가 정렬됨
- `\vfill`은 잔여 공간을 균등 분배 → 문제 간 간격 일정

### STEP 배너 & 페이지 스타일
- `\stepone/\steptwo/\stepthree`가 호출되면:
  1. `\currentstepcolor`를 해당 STEP 컬러로 변경
  2. `\pagestyle{steppage}` 적용 — 상단 컬러 라인 + 하단 컬러 라인 + 가운데 페이지 번호 + 우측 로고
  3. `\stepbanner` 본문 출력 — `STEP X 부제 [핵심·심화·최고난도 뱃지]` + 컬러 라인
- 연속 페이지(`\stepcontheader`)는 배너 텍스트 자리에 22pt invisible strut + 컬러 라인 → 본문 콘텐츠가 첫페이지와 동일한 Y에서 시작
- 본문 모든 STEP 페이지: 상단 라인 위치(첫페이지 배너 아래)와 하단 라인(footer 위)이 페이지 가장자리 기준 ~26mm 대칭

### 표지(`\chapterintro`)
- TikZ `current page` overlay 기반 배경:
  - 상단 우측 삼각형: `gray!10 → mbmain!32` vertical shade
  - 하단 좌측 삼각형: `mblighttint → mbmain!55` vertical shade
  - NW→SE 사선 + 사선 따라 부드러운 흰색 하이라이트
  - 28개 수학 수식 워터마크(30° 회전, 12~28pt 다양한 크기, 0.10~0.16 opacity) 페이지 전체에 분산. 일부는 제목 박스 뒤로 깔리도록 가장자리에 배치.
  - 그래프 3종: 포물선 y=x², 단위원(θ), 사인 곡선(모두 30° 회전)
- 대단원 제목 박스: tcolorbox `enhanced` 모드 + 3-stop vertical 그라데이션(`mbmain!72 → mbmain → mbmain!70!black`) + `drop fuzzy shadow`. 34pt 흰 글자.
- `remember picture` 사용 시 **2회 컴파일** 필요

### 개념 페이지
- 상단 `\conceptbanner` — `개념 정리` 22pt + conceptcolor 라인 (STEP 배너와 동일 구조)
- 배너 끝↔첫 박스 간격: 1cm (`\conceptbanner` 끝의 `\vspace*{1cm}`)
- `\conceptheader{...}` + `\begin{defbox}...\end{defbox}` 박스로 소단원 구조
- 개념 박스 간 간격: `\vspace{1.8cm}` (예: 평행이동↔대칭이동 사이)

### Footer 시스템
- STEP 페이지: 컬러 라인 + 가운데 페이지 번호 + 우측 로고 (`steppage` 스타일, `\currentstepcolor` 사용)
- 개념 페이지: 동일한 디자인이되 conceptcolor(짙은 청색)로 통일
- 챕터 표지: `\thispagestyle{empty}` (footer 없음)

### STEP 페이지 좌/우 분할선
본문 STEP 페이지에 좌/우 컬럼 사이 검정 세로 분할선을 추가. 표지·개념 페이지에는 적용하지 않음. 단원 .tex 파일 preamble에 정의:
```latex
% 배너 첫 페이지용 (STEP X 표시 있음): 상단 -22mm
\newcommand{\stepsplitlinebanner}{%
  \begin{tikzpicture}[remember picture, overlay]
    \draw[black, line width=0.3pt]
      ($(current page.north)+(0,-22mm)$) --
      ($(current page.south)+(0,14.5mm)$);
  \end{tikzpicture}%
}
% 연속 페이지용 (\stepcontheader): 상단 -24mm (배너 없으므로 더 아래에서 시작)
\newcommand{\stepsplitlinecont}{%
  \begin{tikzpicture}[remember picture, overlay]
    \draw[black, line width=0.3pt]
      ($(current page.north)+(0,-24mm)$) --
      ($(current page.south)+(0,14.5mm)$);
  \end{tikzpicture}%
}

\let\origstepone\stepone
\renewcommand{\stepone}{\origstepone\stepsplitlinebanner}
\let\origsteptwo\steptwo
\renewcommand{\steptwo}{\origsteptwo\stepsplitlinebanner}
\let\origstepthree\stepthree
\renewcommand{\stepthree}{\origstepthree\stepsplitlinebanner}
\let\origstepcontheader\stepcontheader
\renewcommand{\stepcontheader}{\origstepcontheader\stepsplitlinecont}
```
- TikZ `remember picture` overlay → **2-pass 빌드 필수**
- 좌표 의미: 페이지 상단 컬러 라인 바로 아래(-22mm) ~ footer 컬러 라인 바로 위(+14.5mm)
- 첫 페이지(STEP X 배너 있음)와 연속 페이지의 상단 오프셋이 다름 (-22mm vs -24mm) — 배너 텍스트 유무에 따라 컬러 라인 위치 미세 차이 보정

## 콘텐츠 규약

### 문제 번호 / 뱃지 / 난이도
- 문제 번호는 `prob/repprob` 환경이 자동 부여 (3자리 연번 001~)
- 난이도 표시: `\dota` ●○○ / `\dotb` ●●○ / `\dotc` ●●●
- 뱃지: `\freq` 빈출 / `\essay` 서술형 / `\examvar` 기출변형
- 사용 예: `\begin{prob}[\dotb\;\freq]`

### 보기(선택지) 환경
- `\choices{1}{2}{3}{4}{5}` — 짧은 보기 (한 줄, 5개 가로 균등, 각 0.2·linewidth)
- `\choicesii{1}{2}{3}{4}{5}` — 중간 보기 (3+2 배치, 각 0.36·linewidth)
- `\choicesiii{1}{2}{3}{4}{5}` — 긴 보기 (2+2+1 배치, 각 0.5·linewidth)
- `\choicesv{1}{2}{3}{4}{5}` — 매우 긴 보기 (세로 5개)
- `\autochoices{1}{2}{3}{4}{5}` — 가장 긴 보기 폭 측정 후 자동 분기 (< 0.18·linewidth → choices, < 0.32 → ii, < 0.48 → iii, else v)
- 모든 매크로 시작 시 `\par\vspace{10pt}` — 문제↔보기 간격 확보

### STEP 단계 정의
- STEP 1 핵심 유형 — 교과서 정복용 기본/표준
- STEP 2 심화 유형 — 내신 실전
- STEP 3 최고난도 — 수능/모의 킬러급

### `\nob{...}`와 `\cond{...}` — 줄바꿈 방지
한 단어·하나의 조건·연결되는 하나의 수식은 항상 한 줄에 표기되도록 wrapper로 묶는다.
- `\nob{...}` — 임의 텍스트/수식 단위 (mbox wrapper)
- `\cond{...}` — "(단, ...)" 단서 전용

**적용 규약:**
- 축/좌표: `\nob{$x$축}`, `\nob{$y$축}`, `\nob{$x$좌표}`, `\nob{$y$좌표}`
- 축+방향 묶음: `\nob{$x$축 방향으로 $-1$}`
- 괄호 조건: `\nob{($a>2$)}`, `\nob{($k>0$)}`, `\nob{($\mathrm{O}$는 원점)}`
- 변수+조건: `\nob{$\mathrm{Q}(a,\,b)$\;($a>2$)}`
- TIP 박스 내 연결 수식: `\nob{$(x+\tfrac{1}{x})^{3}=x^{3}+\tfrac{1}{x^{3}}$}` — 수식 중간에서 안 끊어짐
- 단서 조건: `\cond{$x\neq 0$, $y>1$}` → "(단, x≠0, y>1)"

**주의:** `\nob`/`\cond` 내용이 컬럼 폭을 초과하면 overfull box. 너무 길면 자연 분리 지점에서 끊어 `\nob` 2개로.

### 인라인 분수 강조 — 디스플레이 수식 사용
줄 첫머리에 분수가 오거나 핵심 식이라 강조할 때는 인라인 `$\dfrac{}{}$`보다 디스플레이 `$$\dfrac{}{}$$`로 작성 — 자동으로 위·아래 여백 확보. 003·006이 표준 예시.

### 특수 요소 — 조건 박스
긴 조건문/규칙이 본문 문장과 구분되어야 할 때 `tcolorbox`로 묶음:
```latex
\par\vspace{4pt}
\begin{tcolorbox}[
  colback=mblightgray!55, colframe=mbline,
  boxrule=0.5pt, arc=3pt,
  left=8pt, right=8pt, top=4pt, bottom=4pt,
]
$n$이 홀수이면 ...\\
$n$이 짝수이면 ...
\end{tcolorbox}
```
주로 점 수열 규칙, 함수 분기 정의 같이 `n이 ~이면` 형식의 다중 조건에 사용.

## 디자인 의도 핵심 결정 사항 ("왜 이렇게 했는가")
- **세 간격 균형(prob↔prob, 마지막 prob↔하단 라인)**: 일률적 `\vfill`만 쓰면 마지막 셀 잔여 + 본문 외 빈공간 합산이 inter-prob 간격보다 작거나 컸음. `\probcolheight=17.5cm`가 두 값을 ~5cm로 같게 맞추는 sweet spot.
- **TIP↔첫문제 간격 축소**: `repprob` leading/trailing vspace를 14pt → **4pt** 로 줄임 (이전 ~1cm → ~0.5cm).
- **STEP 페이지 상하 컬러 라인 대칭**: 첫페이지 배너 아래 라인이 페이지 상단에서 ~26mm, footer 라인이 페이지 하단에서 ~26mm 떨어지도록 geometry 설정. 연속 페이지는 `\stepcontheader`의 invisible strut(22pt)이 라인 위치를 첫페이지와 동일하게 유지.
- **표지 가독성**: 워터마크 수식은 `mbmain` 옅은 톤(opacity ≤0.16) + 30° 회전(사선 분할선 NW→SE와 반대 방향, 증가 방향). 제목 박스는 enhanced 그라데이션 + fuzzy shadow로 입체감.

## 변경 가능 / 변경 금지 영역 (작업 시 필수 준수)

유형편 컨텐츠 작성·수정 시 **사용자 사전 승인 없이 절대 변경할 수 없는 영역**과 **자유롭게 수정 가능한 영역**을 구분.

### 🟢 변경 가능 영역 (사용자 승인 없이 수정 OK)
1. **표지 디자인의 내부 콘텐츠**
   - `\chapterintro`의 단원 번호·단원명·하위 주제 목록 텍스트
   - 워터마크 수식 종류·배치 (디자인 의도 유지 범위 내)
   - 단원 표지 워터마크/배경 미세 조정
2. **개념 페이지의 가운데 콘텐츠** (배너 제외)
   - `\conceptheader` 소단원명 텍스트
   - `\defbox` 안의 개념 정의·공식·설명문
   - `\defbox` 간 간격, 그림·표 삽입
   - 개념 설명 추가/삭제, 새 `defbox` 박스 추가
3. **STEP 본문의 문제 내용** (배너·분할선 제외)
   - `\typeheader{유형명}{TIP}`의 유형명·TIP 텍스트
   - 문제 본문 (`prob`/`repprob` 환경 안 내용)
   - 난이도 점(`\dotX`)·뱃지(`\freq` 등) 부착
   - 보기(`\choices` 등) 텍스트
   - 문제 수·순서·재배치 (단, 컬럼/페이지 구조는 기존 패턴 유지)

### 🔴 변경 금지 영역 (사용자 사전 승인 필수)
1. **상단 배너 디자인**
   - `\stepbanner`, `\stepone/two/three`, `\stepcontheader`의 구조·폰트·색·간격
   - "STEP X 부제 [태그]" 텍스트 배치, 배지 스타일
   - 컬러 라인(상단) 위치·두께·색
   - `\conceptbanner`의 구조도 동일
2. **하단 footer 디자인**
   - `\stepfooterblock`의 컬러 라인·페이지 번호·로고 배치
   - footer 위치·크기·색
3. **본문 좌/우 분할선** (§"STEP 페이지 좌/우 분할선" 참조)
   - `\stepsplitlinebanner` / `\stepsplitlinecont` 좌표 (-22mm/-24mm/+14.5mm)
   - 분할선 색·두께
4. **페이지 기본 좌표**
   - geometry 설정 (top/bottom/left/right margin, headheight, footskip)
   - `\probcolheight`, `\probcolwidth`
   - 셀 고정 높이 (`\probcellab`, `\probcellc`)
5. **컬럼 정렬 구조**
   - `\begin{minipage}[t][\probcolheight][t]{\probcolwidth}` + `\hfill` 패턴
   - `\vfill` 분배 패턴 (셀 사이 균등)
   - 좌/우 컬럼 N번째 문제 시작 위치 정렬

**왜 이렇게 구분?** 배너·분할선·footer·기본 좌표는 사용자가 픽셀 단위로 반복 조정해서 맞춰놓은 정렬임. 이를 흔들면 모든 페이지의 시각적 균형이 무너짐. 콘텐츠 영역은 자유롭게 수정해도 외부 정렬과 무관.

**작업 흐름:**
