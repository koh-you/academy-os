답지(해설지)의 풀이·부제·결구·solnote에 *본문의 우회 표현*을 그대로 옮기지 말 것. 답지는 *직접 표현* 의무.

**Why**: 답지는 학생이 *답을 확인하고 풀이를 이해하는 곳*. 표현을 꼬으면 학생이 답지에서도 *우회를 해독*해야 하는 부담이 생긴다. 본문은 우회로 학생을 *생각*하게 만들지만, 답지는 *명확하게 답을 알려주는 곳*. 마스터 즉시 지적 (2026-06-25, 동화고 7회차 v3.1 정정 작업 직후 — solution-author 에이전트가 본문 우회를 답지로 옮긴 사건 계기).

**How to apply**:
- 본문이 "서로 다른 실근의 개수가 $2$가 되도록" 이라면 → 답지는 "*중근을 갖는 조건*"으로 직접
- 본문이 "$x^3=1$의 실수가 아닌 근 중 하나를 $\omega$" 라면 → 답지는 "$\omega$는 $x^2+x+1=0$의 *한 허근*" 으로 직접
- 본문이 "허근을 갖지 않는다" 라면 → 답지는 "*모든 근이 실수*" 로 직접
- 답지 부제·answerbox 주변·solnote 결구도 모두 *직접 표현* 사용
- 본문에서 우회 표현으로 시작했으면, 답지 풀이 step 1에서 *교과 표준 용어로 환원* 후 진행
