# ★ 5 슬롯 (가)(나)(다) 조건 박스 의무화

**규칙**: ★ 5 슬롯은 *(가)(나)(다) 조건 박스* + 함수·매개변수 미정 출제 의무. 단순 단답형 (가)(나)(다) 조건 없는 발문은 ★ 5에서 회피.

**Why**: 마더텅 12·13·14·15회 8번 (4점 학평 21·30번급) 전수 분석 결과, *4문 중 4문 (100%)* 이 (가)(나)(다) 조건 박스 + 미정 함수 추론 형태. 조건 박스는 *3 단서를 분리 + 결합* 시키는 통찰 깊이의 본거지 — *기호 정의 차단 (A) + 정수성 (B) + 예외값 차단 (C) + 중복 회피 (D)* 4 카테고리 단서가 박스 안에 자연 동거. 

본 6회차까지 ★ 5 슬롯이 (가)(나)(다) 박스 없이 인라인 단서로 출제되어 조건 통합 깊이 부족. 마더텅 평균 depth 7.0 동등 도달했으나 통찰 깊이 정점 (8.5+) 빈도 낮음.

## 🔴 적용 기준 세분화 (2026-07-30 세션 105 마스터 확립)

종전 규칙은 "★ 5면 조건박스 의무·미충족 RED"였다. 그러자 **조건이 문장 구조에 자연스럽게 녹아 있는 슬롯**까지 RED가 되어 억지 박스를 강요하게 됐다. 적용 조건을 나눈다.

### ✅ 조건박스를 쳐야 하는 형태 — 대표 예시

> **$f(x)$ 는 다음 조건을 만족시킨다.**
> **(가)** …
> **(나)** …
> **(다)** …

**판별 신호**: 미정 대상(함수·수열·집합·매개변수)을 먼저 선언하고, 그것을 **결정하는 독립 단서를 여러 개 나열**하는 구조. 단서들이 서로 **다른 방향에서 대상을 조여** 통합해야 답이 나온다.

- 단서가 **2개 이상**이고 **서로 독립**이다 (하나를 지워도 나머지가 성립)
- 단서 각각이 **문장 하나로 떨어진다** (본문 서술에 녹이면 오히려 읽기 어렵다)
- 단서를 **결합**하는 것이 통찰의 본거지다

### ❌ 조건박스를 치면 오히려 나빠지는 형태

**조건이 전체 문항의 문장 구조에 자연스럽게 녹아 있는 경우.** 억지로 박스를 치면 문장을 잘라내야 하고, 서사가 끊긴다.

| 형태 | 예 | 처리 |
|---|---|---|
| **정의 → 대응 → 질문**이 한 흐름 | "부분집합 $X$ 에 점 $\mathrm{P}_X=(n(X),S(X))$ 를 대응시킨다" | 본문 서술 유지. 박스 X |
| **소재·상황 지문형** (`[상황]`) | 축소 제도기·탐조등 본그림자 | **`[상황]` condbox 로 충족** |
| 단서가 **1개**이거나 **종속** | "단, $S(\varnothing)=0$ 이다" | 인라인 `(단, …)` |
| 조건이 **소문항에 분산** | (1)(2)(3)이 각각 다른 조건을 씀 | 소문항이 박스 역할 |

### 판정 규칙

| 상황 | 판정 |
|---|:-:|
| 미정 대상 + 독립 단서 2개 이상을 나열하는 형태인데 박스가 없다 | 🔴 **RED** |
| 실세계 지문형이고 `[상황]` condbox 를 보유 | ✅ **충족** |
| 조건이 문장 구조에 녹아 있고 분리하면 서사가 끊긴다 | ✅ **면제** (사유를 draft 에 1행 기록) |
| ★ 4 슬롯 | 🟡 권장 |
| ★ 3 이하 | 회피 (오버킬) |

🔴 **면제를 남용하지 마라.** "녹아 있다"는 판단은 **단서를 박스로 분리해 봤을 때 문장이 깨지는지**로 검증한다. 분리해도 자연스러우면 박스를 쳐야 한다.

**적용 사례 (재현-1회 #15)**: 전체집합 $U$ 정의 → 부분집합 $A$ → 점 대응 → 원 $C$ 가 한 흐름으로 이어지고, `(단, $S(\varnothing)=0$)` 은 종속 단서 하나다. 분리하면 대응 관계 서술이 끊긴다 → **면제 판정**.
