# 수학만으로 정점 도달 가능해야 (2026-07-14 마스터 확립)

수학 시험지의 난이도 정점(star_premium ★ 5 최상위)이 **지문형 슬롯에서만 달성 가능**하고, **순수 수학형(발문에 지문 없는 수학 문제)이 구조적으로 정점에 못 도달**하면 그것은 시스템 결함.

**Why**:
- 학교 시험지·모의고사는 대부분 순수 수학형이 다수. 지문형은 예외
- 학교시험 대비 훈련 교재가 지문형에만 정점을 몰아넣으면 학생 훈련 목적 이탈
- 수학 자체의 통찰(다중 표현 전환·정의 심화·조건 분해)이 지문형 mechanism과 동등 가치여야 함
- 자기복제 방지·회차 다양화 정책으로 지문형 밀도 제한 시 순수 수학형이 정점을 채우지 못하면 회차별 난이도 저하

**How to apply**:
- 스코어 시스템(schema.md §2.16 v5.1 → v5.2) 개편 시 순수 수학형 정점 도달 경로 확보 의무
- 지문형 배타적 축 (N·T·F·P mechanism 특화)의 순수형 대체 경로 신설
- 신규 문항 출제 시 순수 수학형이 star_premium 도달 가능한지 검증 (2회 서술형 5문 중 3~4문이 순수형이어도 정점 comp 도달 가능)

**적용 사례 (2026-07-14 세션 36)**:
- 2회 서술형 정점 밀도 -5.4점 하락 (1회 대비) → 원인은 v5.1 지문형 편중
- schema.md v5.2 §2.16.9 신설 대응:
  - T 축 재정의 (mechanism → 표현 전환 확장, 대수↔기하↔집합↔논리)
  - F 축 재정의 (지문 학문성 → 수학 정의 정확성 확장)
  - **D 축 신설** (Decomposition Density, 조건 분해·재결합 밀도) — 순수 수학형 특화
- 결과: 순수 수학형이 T=2~3, F=2, D=2~3 획득 가능 → comp 30+ 도달

**원칙**: 수학 문제의 진정한 통찰은 mechanism에 종속되지 않는다. 다중 표현 전환·정의 심화·조건 결합·재구조화는 순수 수학에서도 정점 통찰이다.
