마스터 영구 정책 (2026-06-27): **자료 분석 시 발문 어구 추출 의무화**.

## 규칙

외부 자료 (시판 교재·공개 학평·마더텅·바이블·블랙라벨 등 *모든 외부 분석 대상*)를 분석할 때 **반드시 발문 어구를 추출**하여 `bank/발문어구사전.md`에 등재.

**Why**: 본 시스템 발문이 *학평·시판 표준에서 벗어나면* 학생이 발문 자체 해독에 자원 소비 → 사고 깊이 진입 차단. 어구 일관성이 사고 유도의 토대 ([[feedback_design_depth_proposals]] 제안 4).

**How to apply**:
- 자료 분석 호출 시 *발문 어구 추출 + 사전 등재*가 *분석 작업의 일부*
- 추출 누락 시 분석 *불완전* — 후속 결과물 신뢰도 감소
- 추출 항목: 매개변수 도입 / 자유도 한정 / 결과식 / 보기 ㄱㄴㄷ 종결 / 자기참조 / 표면 모순 등
- 등재 시 *마더텅 N회 #M*·*2024년 6월학평 #N* 등 표본 출처 인용

## 적용 대상 (영구)

| 작업 유형 | 어구 추출 의무 |
|---|---|
| 시판 교재 PDF 분석 | ✅ 의무 |
| 공개 학평·평가원 기출 분석 | ✅ 의무 |
| 마더텅·바이블·블랙라벨 등 미니모의고사 분석 | ✅ 의무 |
| 카탈로그 03·04 표본 검토 | ✅ 의무 (신규 표본 추가 시) |
| 본 시스템 자체 출제물 (1·2·3·4회차 등) | ❌ 적용 외 (검수 대상) |
| 내부 청사진·메모리·도구 코드 | ❌ 적용 외 |

## 자동 점검 (예정)

신규 회차 작성 또는 자료 분석 보고 시 다음 점검:
1. 어구 사전 *갱신 시간* 확인 — 분석 작업 후 변경 시간이 분석 시간보다 오래되면 RED
2. 분석 보고서에 *추출 어구 N건 등재* 명시 의무 (보고서 첫 줄)

본 응답 시점: 정책 정립 + 첫 시범 (마더텅 6회 어구 추출 작업 중).
