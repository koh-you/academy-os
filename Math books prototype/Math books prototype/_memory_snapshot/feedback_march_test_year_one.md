# 3월 모의고사 학년 매핑 정책 (2026-06-30 마스터 확립)

## 핵심
**매해 3월 실시 모의고사는 전년도 학년 과정 내용으로 출제**. 따라서 학년 표기보다 *교과 내용*으로 자산화 결정.

| 시험 표기 | 실제 출제 과정 |
|---|---|
| 고2 3월 학평 | **공통수학1·2** (전년도 고1 과정) |
| 고3 3월 학평 | **수학1·수학2** 등 (전년도 고2 과정) |
| 고1 3월 학평 | (전년도 중3 과정 + 일부 고1 도입) |

## 적용 방침
1. **고2 3월 학평**의 공통수학1 범위 문제 → **EX-HG-Y{년}M3-{단원}-{NNN}**로 자산화 OK (고1 학평과 동일 prefix)
2. 출제 단원이 공통수학1/2 범위인지 *내용 직접 확인*
3. 학년 표기는 sources에 메타로만 기록 (`원학년: 고2 3월학평`)

## 적용 사례 (2026-06-30 마더텅 미니모의)
- **2020년 3월학평 25번 (고2)**: 곱셈공식 (x²+y²+4z²=62) → 공통수학1 PL 범위 → EX-HG-Y2020M3-* 자산화 OK
- **2019년 3월학평 나형 25번 (고2)**: 다항식 나눗셈 → 공통수학1 PL 범위 → EX-HG-Y2019M3-* 자산화 OK
- **2022년 3월학평 1번 (고2)**: 다항식 차 → 공통수학1 PL 범위 → EX-HG-Y2022M3-* 자산화 OK

## 중복 판정 (각 문항 신중 비교)
새 학평 시점을 등재하더라도 [[feedback_no_duplicate_asset]] 5요소 비교 신중 적용. 출처 라벨이 다르더라도 (예: 2020년 3월 고2 vs 2020년 6월 고1) *발문이 같으면 중복* — 마더텅 같은 셀렉션 모음집이 동일 문제를 다른 회차에서 또 인용했을 가능성도 점검.
