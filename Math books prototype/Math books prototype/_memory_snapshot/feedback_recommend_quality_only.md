# 방안 추천 시 비용 고려 금지

방안·옵션·접근법을 추천하거나 비교 분석할 때, **비용·분량·작업 시간·세션 수·직관성·구현 편의성 등 *비용 관점* 일절 고려하지 말 것**. **오직 *질적으로 목표에 부합하는가*만** 기준으로 판단·추천한다.

## Why
마스터 명시 절대지침 (2026-06-23): "앞으로 방안을 추천할때 비용은 따지지말고 어떤 방안이 질적으로 더 목표에 부합하는지만 따져서 추천할것. 절대지침임." 본 프로젝트의 현재 목표는 [[project-overall-goal]]에 따라 *풍부·질 높은 데이터베이스 + 완벽한 교재 제작 시스템* 구축이며, 비용·편의 고려는 *질 절충*을 초래해 목표에서 멀어진다.

과거 위반 사례: S5 2단계에서 단순 합산 vs 가중 합산 비교 시 "직관성·결정 용이성"을 단순 합산의 장점으로 들었음. 가중 합산이 *진정 변별 측정*이라는 본질 목표에 더 부합함에도 비용 측면을 끌어와 판단을 흐림. "분량이 크다·1세션 초과 가능" 류 표현도 동일 위반.

## How to apply
- 방안 비교 시 *질적 본질*만 분석: 본 방안이 목표에 어떻게 더 가깝게 가는가? 본 방안이 무엇을 가능하게 하는가? 본 방안의 한계가 *질적 한계*인가 *비용 한계*인가?
- "직관성·이해 쉬움·구현 편의·시간 절약·분량 적음" 등은 *추천 근거에서 제외*. 필요하면 단순 사실 보고로만 별도 명시
- *추천*은 항상 "X가 목표 Y에 더 부합" 형식. "Z는 비용 측면 좋지만…"식 절충 추천 금지
- *진행 거부·미루기*도 비용 고려의 한 형태 — "분량 크니 다음 세션에" 같은 제안 금지. 마스터가 명시 *go* 한 작업은 완료까지 진행
- 본 절대지침은 [[project-overall-goal]] (질 높은 DB + 완벽 교재 시스템)이 변경되기 전까지 유효
