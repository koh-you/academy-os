## 마스터 명시 (2026-06-25 본 세션)

> "지금 시험지들이 직전 회차의 쌍둥이 형식으로 제작되고있어. 단순히 시험문제 요소를 조금 바꾸는 걸로는 안되. 지금 자산을 엄청난 비용을 들여서 구축했잖아. 직전 회차 시험지를 참고해서 만드는게 아냐. 구축한 자산을 이용해서 새로 시험지를 만들때마다 단원별 유형별 중요도를 새로 판단해서 새로 만드는거야."

> "물론 하다보면 같이 유형이 나올수도 있고 같은 형태의 문제들이 만들어지지. 그런데 시판교재를 봐봐. 어떤 책을 봐도 공통으로 실려있는 유형과 표현들이 당연히 중요한 기본틀 아니겠어? 그런 정도의 중복은 괜찮지만 이건 완전히 자기복제 아니야."

## 규칙

1. **직전 회차 .tex 참조 금지**: 디자인(style.sty·매크로·examheader)만 공유. 슬롯 발문·통찰 패턴은 *처음부터 자산 기반 재설계*.

2. **자산 기반 중요도 재판단**: 회차마다 다음 자산에서 단원별·유형별 중요도 *새로* 산출
   - `data/all-premium-samples.json` (1,326문 strict 풀)
   - `bank/시판책-사용빈도.md` (시판 8종 빈도)
   - `bank/4점-패턴-카탈로그/03-패턴-카탈로그.md` (1.x 핵심 패턴 + MS-* 본거지)
   - `bank/anchors/CM1-*.md` (단원별 ★ 1~5 앵커)
   - `bank/슬롯-추천*.md`

3. **시판 공통 = 기본 틀 (회차 누적 OK)**: 시판 4종 이상 + 마플시너지 공통 등장 유형은 매 회차 출제 가능. 단 *형태 변화* 필수.

4. **자기복제 정의** (다음 중 2개 이상 충족 시):
   - 직전 회차 같은 위치 슬롯 발문 *3 어절 이상 일치*
   - 통찰 유형 카드 동일
   - 슬롯 구조 동일 ((1)(2)·ㄱㄴㄷ·같은 매크로 패턴)
   - 매크로 사용 패턴 동일
