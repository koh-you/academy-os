**규칙**: 시험지의 각 구간 안에서 문제 순서는 **난이도(점수) 오름차순** 배열 의무.

**Why**: 마스터 명시 (2026-06-25): "객관식 내에서 문제 배열순서는 난이도 오름차순으로. 단답형 및 서술형도 마찬가지 난이도 오름차순으로 배열." 학생이 시험을 시작할 때 *쉬운 문제부터 만나* 자신감을 얻고, *어려운 문제는 뒤로* 갈수록 만나도록 — 시험 심리 표준.

**How to apply (v0.2, 11회차부터 — 단답·논술 통합)**:
- **객관식 구간** (★ 1~5, 보통 2.5·3·3.5·4·4.5·5점): 자리 순서 = 점수 오름차순
- **통합 서답 구간** (★ 3~5, 보통 4·4.5·5·5.5·6·6.5·7점): 자리 순서 = 점수 오름차순. 단답형·논술형 슬롯이 한 구간에 섞이나 *점수 오름차순*만 지키면 형식 무관
  - 예: 4점(단답) → 4.5점(단답) → 5점(논술) → 5.5점(논술) → 7점(논술)
- 같은 점수 내에서는 *단원 순서*(EQ → CB → MX) 또는 *통찰 난이도* 정도 정성 정렬

**옛 정책 (~10회차, 보존)**: 객관식 / 단답형 / 논술형 각 구간 안에서 오름차순 (3구간 분리 시대)

**9회차 v4.4 재배열 계획** (객관식 #1~#15):
| 자리 | 점수 | 기존 슬롯 | 단원 |
|---|---|---|---|
| 1 | 3 | #3 | EQ |
| 2~4 | 3.5 | #1·#2·#14 | EQ |
| 5~6 | 3.5 | #9·#8 | CB |
| 7~8 | 3.5 | #13·#15 | MX |
| 9~11 | 4 | #4·#5·#6 | EQ |

단답·논술은 v4.4 시점 이미 오름차순 OK.
