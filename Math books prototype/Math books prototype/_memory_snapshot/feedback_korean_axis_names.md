> **마스터 (2026-07-31 · 세션 106)**: 다른 평가방식들도 **코드명 말고 한글명으로 불러. 앞으로는.**
> **마스터 (2026-08-01 · 세션 107)**: 「앞으로 **작업상황 보고할 때 코드명 쓰지 마.**」

## 🔴 확대 적용 (2026-08-01) — 축 이름만이 아니라 **보고 전체**다

측정 축뿐 아니라 **작업 보고에 나오는 모든 내부 코드**를 한글 말로 푼다.

| 쓰지 마라 | **이렇게 말한다** |
|---|---|
| 판정자 V1·V2·W3 | **판정자 두 사람** · 「첫 판정」·「다시 잰 판정」 |
| 실험 A·B·C·E | **앵커 수 실험** · **형식 실험** · **안정성 실험** · **경계 규정 실험** |
| 통과선 T1·E1·E2 | **첫째 기준**… 또는 기준 내용을 그대로 말한다 |
| 밴드 A1~A5 | **★ 1~2 급 · ★ 3 급 · ★ 4 급 · ★ 5 급 · ★ 5 프리미엄 급** |
| 앵커 A5d·A3b | **함수 정점 앵커** 처럼 **무엇인지**로 부른다 |
| 태스크 #32·#33 | 태스크 **이름**으로 부른다 |
| 문항 Q01~Q20 | 「20문 중 다섯 문항」처럼 **수와 성격**으로 말한다 |

**Why:** 코드는 만든 사람에게만 자명하다. 마스터가 판단해야 하는 자리에서 코드로 말하면
**근거를 읽을 수 없다.** 보고가 암호가 되면 마스터가 검증할 수 없고, 검증되지 않으면 오류가 오래 산다.

🔴 **코드가 살아도 되는 곳은 파일·스크립트·CSV·YAML 필드뿐이다.**
사람이 읽는 글(대화 보고·문서 본문)에는 한글 이름을 쓴다.

**모든 난이도 측정 축을 한글 이름으로 부른다.** `SE1`·`SE2`·`T`·`P`·`E` 같은 코드는
대화·보고·문서 본문에서 쓰지 않는다.

| 계열 | 코드 (구) | **한글 이름** |
|---|---|---|
| 풀이 실행 | SE1a | **도구 개수** |
| | SE1b | **단원 넓이** |
| | SE1c | **도구 무게** |
| | SE2 | **사슬 길이** |
| | SE3 | **되짚기 횟수** |
| | SE4 | **갈래 수** |
| | SE5 | **확인 횟수** |
| | SE6 | **표준 경로 이탈** (강등) |
| 옛 8축 | N | **지문 밀도** |
| | L | **소문항 얽힘** |
| | T | **번역 통찰** |
| | H | **답 노출** (감점) |
| | R | **엄밀성** |
| | F | **서술 정확성** |
| | E | **조건 필수성** |
| | P | **예측 저항** |
| 신설 | — | **구성 깊이** (마스터 확정 2026-07-31) |

🔴 **축 M 은 이름을 확정하지 못했다.** `CLAUDE.md` 는 「1층 M (노동량 4축, 4~12점)」이라 하는데
채점 자료의 M 은 0~3 이다. **서로 다른 두 개일 수 있다.** 확인 전까지 이름을 붙이지 마라.

**Why:** 코드는 만든 사람에게만 자명하다. 마스터가 판단해야 하는 자리에서 코드로 말하면
근거를 읽을 수 없다. 실제로 「무슨 소린지 하나도 모르겠다」는 지적을 받았다.

**How to apply:**
- 코드가 꼭 필요한 곳은 **파일·스크립트·YAML 필드**뿐이다. 사람이 읽는 글에는 한글 이름을 쓴다
- 문서에서 코드를 병기해야 하면 **한글 이름을 앞에** 두고 코드를 괄호에 넣는다
- 축 이름이 뜻을 못 담으면 **이름을 바꾸자고 제안**한다. 코드로 도피하지 마라
