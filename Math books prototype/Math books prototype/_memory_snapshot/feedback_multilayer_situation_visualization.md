# 다층 상황부여 발문 시각화 우선순위 — 좌표평면 대응 도해 우선

**적용 범위**: ★ 4·5 다층 상황부여 발문의 시각 자료 설계

## 규칙

발문의 다층 상황부여를 시각화할 때, **수학 core를 좌표평면 위에 직접 대응 시각화**하는 방식이 **관용어·서사 요소를 시각화**하는 방식보다 이해도가 압도적으로 높음. 후자 우선 시 학생 이해 실패.

**우선순위**:
1. 🥇 **좌표평면 대응 도해** — 발문의 두 수학 대상(원 C₁·C₂, 두 궤도, 두 집합 등)을 좌표계 위에서 직접 관계(대응·파선·화살표)로 시각화
2. 🥈 **원리 도식** — 도구·현상의 원리를 개조식·다이어그램으로 (좌표 없이) 표현
3. ❌ **관용어 서사 시각화** — 강아지·펭귄·CCTV·사각형 두 개 등 서사 대상을 직접 그리려 시도 (이해 실패 빈발)

## Why

**2026-07-10 사도기 발문 5-트라이 사건**:
사도기 #16 [그림 2] 시각화를 5회 반복:
1. Asymptote 강아지 3원 (컴파일 캐시 이슈로 이전 pdf 유지 · 마스터: "강아지 아님")
2. 외부 도메인 강아지 실루엣 png (마스터: 방침 철회)
3. tikz 강아지 3원 + 얼굴 특징 (마스터: "알아볼 수 없어")
4. 와부고 [그림 4] 스타일 원본/확대 사각형 + 갈색 X자 링크 (마스터: "전혀 이해가 안가")
5. **v5 좌표평면 대응 도해 (C₁·C₂·P·Q·O·P·Q 파선)** → ✅ 승인

관용어 서사(강아지·구동예시 사각형)로 그림을 시도하면:
- 학생은 서사 자체를 이해하는 데 인지 부하 소진 → 수학 대상까지 도달 못함
- 그림에 의미 부여가 강제되어 오히려 수학 관계 왜곡
- 서사 그림의 완성도가 낮으면 "이게 뭐지" 혼란 유발

**좌표평면 대응 도해는**:
- 학생이 이미 익숙한 좌표계 위에서 수학 대상만 표시 → 즉시 이해
- 두 대상 관계(대응·파선)만 시각화 → 서사 부하 없음
- 발문 서사는 텍스트로만 유지, 그림은 순수 수학 관계

## How to apply

### 다층 상황부여 발문 시각 자료 설계 시:

1. **1순위 판단**: 수학 core에 대응 관계(원·집합·점 대응)가 있는가?
   - Yes → 좌표평면 대응 도해로 시각화 (예: C₁·C₂·P·Q + 파선)
   - No → 2순위 검토

2. **2순위 판단**: 원리·개념 도식이 필요한가?
   - Yes → 개조식 도해 (기계장치·구조도)
   - 예: 사도기 [그림 1] 4링크 평행사변형 구조

3. **3순위 (피할 것)**: 관용어 서사 자체를 그리려 하지 말 것
   - 강아지·펭귄·개기월식 등 서사 대상은 텍스트로만 언급
   - 그림은 수학 관계에 집중

### 서사·그림 역할 분리

발문 서사(층 1·2)와 그림(수학 관계 시각화)을 역할 분리:
- **텍스트**: 서사 설정·정의 박스·조건 (사도기 원리·케플러 궤도·학급 조사)
- **그림**: 수학 대상 관계 (좌표평면 위 두 원·두 궤도·대응 파선)
