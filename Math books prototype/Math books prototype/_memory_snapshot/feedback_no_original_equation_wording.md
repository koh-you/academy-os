# "원 방정식"·"원 부등식" 표현 금지

**RED**: 풀이·발문에서 "원 방정식"·"원 부등식"·"원식" 표현 금지. 학생 관점에서 "원"이 *도형의 원*(circle)처럼 보임.

**Why**: 마스터 명시 2026-07-02. 원본 관점의 "원 방정식"이란 의미로 쓴 것이지만 CM2 §도형의 방정식에서 다루는 "원의 방정식"과 혼동. 학생 자료는 명확해야 함.

**How to apply**:
- 치환·변환 문제에서 "원 방정식" → **함수 이름 부여** ("$f(t) = t^2 - 6t + k = 0$", "$f(t) = 0$") 또는 **명시**("$x$에 대한 사차방정식", "치환 전 방정식")
- 부등식 동일: "원 부등식" → "$f(x) < 0$" 또는 "$x$에 대한 부등식"
- "원식" → "주어진 식"·"$f(x)$"

**정정 예 (2회 #14 답지, 2026-07-02)**:
```
❌ 원 방정식이 실근을 갖지 않는 조건은 $t$-방정식이 ...
✅ $x$에 대한 사차방정식이 실근을 갖지 않는 조건은 $f(t) = 0$이 ...
```
- $t$-방정식에 함수 이름 부여: $f(t) = t^2 - 6t + k$
- "원 방정식" → "$x$에 대한 사차방정식"
