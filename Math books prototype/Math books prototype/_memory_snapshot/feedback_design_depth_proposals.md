마더텅 10회차 정밀 비교로 식별된 본 시스템의 *사고 깊이 유도* 갭을 보강하는 6가지 시스템 제안. 마스터 요청 2026-06-27.

**Why**: 본 EQ 미니모의고사 시범 1회차는 마더텅 10회차와 평균 depth_score 비교에서 -0.2 (6.4 vs 6.6)로 근접하나, *발문 수사·구조·구성의 정교함*에서 큰 갭이 식별됨. 표면 수치 점수만으로는 학생 사고 유도 능력 차이를 못 잡음. 본 6가지 제안은 마더텅 수준의 사고 깊이 유도 메커니즘을 본 시스템에 이식.

**How to apply**: 신규 출제 시 제안 1·3·4 우선 적용. 카탈로그·매크로 신설 후 검수 게이트 추가.

## 제안 1. 빈칸 채우기형 풀이 박스 카탈로그·매크로 🔴 최우선

- `style.sty`에 `\quizbox{...}` 매크로 신설 — 학생 풀이 동행 가이드형 박스
- 마더텅 #5 형식: "다음은 ~을 구하는 과정이다 [풀이 박스 본문 ... $\boxed{(가)}$ ... $\boxed{(나)}$, $\boxed{(다)}$이다.]"
- 카탈로그 03에 §6 "가이드 풀이 박스" 패턴 등재
- 출제 메커니즘 v1.0: ★ 5 슬롯 회차당 ≥ 1개 빈칸 채우기형 *의무*
- 예상 효과: depth_score +1.0 (학생을 풀이 사고에 강제 진입)

## 제안 2. 표면 모순 조건 카드 (I-VF·I-XU 결합)

- 발문에 *직관적 모순 같은 조건*으로 *통찰 강제 갱신* 패턴
- 예시 카드:
  - "제곱 = 음수" → 순허수 강제 (마더텅 #7 사례)
  - "한 허근 + 켤레합 음수" → 켤레쌍 강제 (마더텅 #4 사례)
  - "두 양의 정수해 + 곱>0 + 합<0" → 모순 → 조건 재해석
- 카탈로그 03 §4b (검증 부담)에 "표면 모순 발문" 카드 등재
- ★ 5 슬롯 회차당 ≥ 1개 권장

## 제안 3. 단서(\cond) 정밀화 규약 v1.0

각 발문 \cond는 4 카테고리 함정 차단 의무:
1. **기호 정의**: "$\bar{z}$는 $z$의 켤레복소수"
2. **정수성·실수성**: "$a$, $b$는 실수"
3. **예외값 명시**: "$\alpha \ne \beta$"
4. **중복 회피**: "점 $C$는 점 $A$도 아니고 점 $O_1$도 아님"

출제 메커니즘 v1.0 §단서 정교화 단계 추가. 검수 게이트: \cond 1개 이상 + 함정 차단 카테고리 ≥ 1 의무.

## 제안 4. 한국어 발문 표준 어구 사전

- `bank/발문어구사전.md` 신설 (학평 기출·시판 표준 어구만)
- 표준 어구: "~의 값을 구하시오" / "~라 할 때" / "다음은 ~을 구하는 과정이다" / "있는 대로 고른 것은?" / "~이 되도록 하는 ... 값들의 합"
- 출제 시 표준 어구만 사용 (창의 표현·직역체 회피)
- 예상 효과: 학생 체감 마더텅 동등 수준 발문 일관성

## 제안 5. 변수 명명 깊이 메트릭 신설 (depth_score 보완)

- 추가 메트릭 **naming_depth**: 발문 안 변수 명명 단계 수
- 예: "한 근 $-2$" → "네 실근 중 가장 큰 것 $b$" → "$a + b$의 값" = 명명 깊이 3
- 카탈로그 03에 메트릭 정의 + ★ 5 슬롯 명명 깊이 ≥ 2 권장

## 제안 6. 공개 학평 기출 통찰 카드 빈도 통계

- 공개 학평 기출 (정부 공개 자료 우선) 통찰 카드별 출현 빈도·깊이 *집계 통계만*
- `bank/통찰빈도-통계.md` 신설
- 본 시스템 출제 시 청사진 자동 생성 (시판 평균 부합)
- 통찰 카드 자체는 저작권 보호 외 (수학 교수 도구)
