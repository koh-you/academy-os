# 답지 작성 의무 자산 6종 (v2 통합, 2026-07-01)

**마스터 명시 (2026-07-01)**: "답지는 자산에 만들어 놓은 카탈로그에 입각해서 작성할것. 풀이 양식·답지 언어·그래프 전부 사용해서 만들어야 함."

**문제 발생**: 2026-07-01 2026-1학기-기말예상-1회 답지 작성 시, 1차 호출에서 카탈로그 09 + 영구 정책 9건만 명시 → 마스터 지적 → 2차 호출에서 5종 자산 추가. 반복 점검·재작업 발생. 마스터: "처음에 만들때부터 적용 못하나? 꼭 만들어 놓고 다시 점검하고 점검하고 그래야해?"

**개선**: `.claude/agents/solution-author.md` §"매 호출 시 의무 — 자산 카탈로그 6종 통합 정독"(v2) 등재로 *에이전트가 자동 정독*. 호출 프롬프트에 자산 누락되어도 본 게이트가 보완.

## 호출자 가이드 (claude·다른 에이전트)

solution-author 에이전트 호출 시 **자산 명시 불요** — v2 게이트로 자동 적용. 호출 프롬프트에는 다음만 명시:
- 본문 위치 + 답지 작성 위치
- 청사진(slot focus) 위치
- *작업 고유 요구사항* (특정 슬롯 처리·특이 사항)

자산 6종은 에이전트가 자동 정독. 호출자가 "카탈로그 09 + 영구 정책" 같은 *일부*만 명시하면 에이전트가 *나머지를 보완*.

## 자산 활용 보고 양식 (작업 완료 시)

에이전트는 다음 양식으로 자산 활용을 보고 의무. 보고에 6종이 모두 포함되지 않으면 작업 미완료 처리.

```
### 자산 카탈로그 6종 적용 상세
- ① 풀이 양식 카탈로그: 정독 완료. 매칭 슬롯·풀이 골격 차용 내용.
- ② 답지 세련도 09: 4축 13 패턴 카운트 (refinement_score_sol).
- ③ 발문 어구 사전: 표준 어구 치환 N건.
- ④ 비표준 어구 사전: RED 0건 + \solnote 표준 양식 분포.
- ⑤ RPM 언어사전: 매칭 공략법 슬롯·표준 어구 카운트.
- ⑥ 그래프 양식 카탈로그: 그래프 슬롯 점검·추가 슬롯.
```

## Why (시스템 결함 사이클 차단)

**기존 사이클**: 호출자가 자산 일부 누락 → 에이전트가 누락 자산 적용 안 함 → 마스터 지적 → 호출자가 보강 호출 → 에이전트 재작업. 사이클당 *반복 점검 2~3회* 발생.

**v2 게이트**: 에이전트가 *자동으로 6종 정독*. 호출자 누락 무관. 사이클당 *1회 완성*. 향후 답지 작성은 *처음부터* 6종 자산 모두 반영.

## How to apply

- solution-author 에이전트 호출 시 자산을 일일이 명시하지 않음 (v2 게이트가 자동 적용)
- 호출 프롬프트는 *작업 고유 요구사항*만 (본문 위치·청사진·특이사항)
- 에이전트가 6종 정독 후 자산 활용 보고 양식대로 보고
- 6종 중 *하나라도* 보고 누락 시 작업 미완료 — 보강 호출 요청
