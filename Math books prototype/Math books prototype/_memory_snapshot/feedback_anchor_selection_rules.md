# 앵커 선정 4규칙 (깊이 앵커 사다리)

사다리의 앵커는 **자(尺)** 다. 좋은 문항이 아니라 **견줄 수 있는 문항**을 앉힌다.

## 1. 🔴 단원 특유형을 앉히지 마라 — 견줄 수 있어야 한다
행렬의 진위판정 3항·케일리해밀턴, 경우의 수의 라틴방진·완전순열처럼
**다른 단원에 대응물이 없는 유형**은 앵커로 못 쓴다. 다른 단원 문항을 나란히 세워
「어느 쪽이 더 깊은가」를 물었을 때 답이 갈리지 않기 때문이다.
- MX A5d = #886 (3차 반대칭 행렬 → **조합적 셈으로 귀결**) 을 고른 이유
- CB A5e = #766 (원판 쌓기 → **조건을 스스로 다시 정의**) 을 고른 이유

## 2. 🔴 같은 밴드에 같은 통찰을 두 번 넣지 마라
넣으면 두 앵커가 한 점에 뭉쳐 **밴드 안이 좁아지고 눈금이 성글어진다.**
판정자가 서로 다른 단원의 두 앵커를 사실상 같은 문항으로 읽게 된다.
- 실제 적용: CB 후보 #765(말판 이동 · 4로 나눈 나머지)를 **A5a(복소수 거듭제곱 주기)와
  통찰이 겹친다**는 이유로 밀어냈다. 문항의 질 때문이 아니라 **사다리에서의 자리** 때문이다

## 3. 🔴 노동형을 정점에 앉히지 마라
**노동량과 깊이는 반대로 간다.** 판정자들이 독립적으로 관찰한 것 —
「손이 가장 많이 가는 문항이 가장 얕았다」. 실제 판별자는 **「해야 할 일이 지시되어 있는가」** 다.
- 나열·훑기가 풀이의 몸통이면 깊이가 아니라 **그 단원을 얼마나 훑었는지**를 잰다
- 관련: 조건을 하나 더 주면 **검산 눈금**이 되어 깊이가 실제로 깎인다

## 4. ✅ 고3 문항도 쓴다 — 도구가 범위 안이면
> **마스터 확정 (2026-08-01)**: 「고3 문항이라도 도구가 CM1 안이면 써.」

CB A5e(#766)의 원 출처는 **2010년 10월 학평 나형 25번(고3)** 이다.
쓰는 도구가 조합 $_n\mathrm{C}_r$ 과 경우 나누기뿐이라 CM1 범위 안이므로 채택했다.
🔴 다만 **등재할 때 원 출처를 병기**한다 — 나중에 「고1 학평 앵커」로 오독되면 안 된다.

**Why:** 앵커는 서수가 아니라 **급(級)** 을 말하는 자리다(밴드 라벨 앵커).
학년 표기가 아니라 **도구가 교육과정 안인가**가 자격을 정한다.
반대로 도구가 밖이면 같은 고1 문항이라도 못 쓴다 — 중복조합·중복순열이 주축인
#757·#762 는 그래서 사전 배제됐다.

## ✅ 후보 풀 — 고쟁이 + **블랙라벨** (마스터 확정 2026-08-01)

> 「**블랙라벨도 넣어**」

종전에는 고쟁이 STEP 3 만 봤다. 블랙라벨 정독 자산이 CM1·CM2 STEP 1~3 전부 있고
`bank/4점-패턴-카탈로그/14-CM1-시판-진정변별.md` 에 **단원별 STEP 3 채점표**까지 있는데
앵커로는 한 문도 쓰이지 않고 있었다.

- 자산: `bank/mechanism-데이터-블랙라벨-CM{1,2}-STEP{1,2,3}.md` · `-CM1-v2-통합.md`
- 같은 카탈로그가 **「블랙라벨이 시판 책 한계 깨뜨림」**(§5.1)이라 기록해 뒀다
- 🔴 **블랙라벨 등급 라벨도 아래 §5 3단 게이트를 그대로 통과시킨다.** 예외 없다

**계기** — 「원판 두 탑」(count **5**) 문항이 블랙라벨 단원 08 STEP 3 #12(p.96~97)에 있는데
**출처가 「고쟁이 CH08」로 잘못 적혀** 검증하는 쪽이 고쟁이 파일을 열고 「없다」고 답했다.
🔴 **번호만 옮기지 말고 교재명까지 옮겨라.** 출처가 한 칸 틀리면 검증은 없는 것을 확인한다.

## 🔴 5. 시판 앵커 채택 3단 게이트 (2026-08-01 전수 감사 후 신설)

시판(고쟁이) 문항을 앵커로 앉히기 전에 **반드시** 세 가지를 확인한다.

1. **「교육청 기출/변형」 표기 grep** → 있으면 **원 학평 문항을 특정해 사다리 전체와 대조**
   > 사고 사례 — CM2 A5d(#367)가 A4c(학평 2020.11 #29)와 **같은 문항**이었다.
   > 한 문항이 두 밴드의 대표를 겸했고 **그 경계는 정의상 0** 이었다. 판정자가 우연히 밟아서 나왔다
2. **문항별 손 분류 목록**(「★ 5 후보 / ★ 4 후보」)이 파일에 있는지 확인 → 있으면 그것을 따른다
   > 사고 사례 — CM2 A5e(#595)가 출처 파일의 **★ 4 후보** 목록에 있었다
3. 없으면 **실측 판정 문서와 대조** (`bank/mechanism-데이터-고쟁이-CM1-v2.md` 류)

### 🔴 등급 라벨을 근거로 쓰지 마라 — 셋 다 못 믿는다
| 라벨 | 실태 |
|---|---|
| `tier_mapping: STEP_3 → star_5_premium` | STEP 단위 **일괄 배정**. 프로젝트가 스스로 **「매우 관대」(정합 43% · 57% 하향)** 로 실측해 뒀다 |
| `star_premium: true` | **이름뿐이다.** CB 9문 전부 `depth_score` 7~8 로 8.5 문턱 아래 · 공통점은 `insight_score: 5` 하나 |
| 카탈로그 점수 | 동점이 많아(10문 중 7문 `8.67`) 자리를 못 가른다 |

### 🔴 premium 게이트도 정점을 못 가른다
`depth ≥ 8.5 + max=3 + count ≥ 5` 를 **엄격 적용하면 후보가 전멸**한다 —
#764 는 `8.4`·카드 1장, #766 은 `count 4` 로 **둘 다 탈락**한다.
기존 「통과」 기록은 **감쇠 미적용 + 같은 카드 이중 계상** 두 완화가 겹친 결과였다.
→ **정점 앵커는 게이트가 아니라 위 4규칙으로 고른다.**

## 🔴 6. 규칙은 기존 앵커에 소급 적용한다
CM1 사다리는 신규 후보 #765 를 「통찰 겹침」으로 걸렀으면서,
**이미 앉아 있던 A5a↔A5c 의 같은 겹침은 아무도 검사하지 않았다.**
규칙을 만들면 **그날로 전수 재검사**한다.

## 🔴 7. 판정자 소견도 원문으로 검증한다
본 검정 판정자 V1 의 「A5b·A5c 둘 다 이차함수+원」은 **사실이 아니었다**(A5c 에 원이 없다).
**없는 충돌을 기록하고 실재 충돌은 놓쳤다.** 소견은 단서이지 확인이 아니다.

## 🔴 8. 소재 한 줄은 장식이 아니라 자의 눈금이다
판정자는 앵커 표의 「소재」 한 줄로 견준다. 결정 통찰이 빠진 표기는 **오판을 만든다**.
> 사고 사례 — CM1 A5a 를 「주기 = 4로 나눈 나머지」로 적었는데 실제 도약은 **바깥 지수의 8주기**였다.
> 이 오기 때문에 **#765 를 틀린 이유로 배제하고 진짜 겹침(A5c)은 놓쳤다.**
> 전수 감사에서 같은 오기가 **6건** 나왔다.

**How to apply:**
- 후보를 고를 때 §5 3단 게이트를 먼저 통과시킨다
- 고른 뒤 위 4규칙으로 다시 거른다. 특히 **2번(통찰 충돌)은 문항만 봐서는 안 걸린다** —
  같은 밴드의 다른 앵커와 대조해야 드러난다
- 밀어낸 후보와 **밀어낸 이유를 사다리 문서에 남긴다.** 교체가 필요할 때 1순위 대체가 된다
