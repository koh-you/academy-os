# policy-no-textbook-recap — 교과 표준 회고 절대 금지 (방안 K v2.0)

**규칙**: 정의박스에 교과 표준 개념 (거리 공식·무게중심·부분집합 개수·집합 연산 정의·명제 대우 등) 회고 **자체 금지**. 유형별·답변방식별 star 상한 개념 폐기 · **모든 유형·답변방식에서 ★ 5 도달 가능**.

**Why**: 
- 세션 39 6회 정밀 재평가에서 발견 · 6회 #14 무게중심 정의박스·#16 부분집합 개수 정의박스가 교과 표준 개념 회고로 배점·star 부풀림
- 마스터 지시 (2026-07-13): "교과 표준 개념은 회고를 해 주면 안 돼"
- 학생이 교과에서 이미 학습한 개념을 시험지에서 회고 = 문항 신뢰도 저하 · 학습 저해
- 유형별·답변방식별 star 상한은 수학의 유연성 부정 · **문항 심층이 유일 결정 요인**

**How to apply**:
- 정의박스 사용 자체가 매우 제한적 · Deep 유형에서도 신 정의·확장 정의만 허용
- 교과 표준 개념 회고 (예: "무게중심의 좌표 = (x1+x2+x3)/3"·"부분집합의 개수 = 2^n") → RED
- 유형 (소재)·답변 방식 (선택형·서술형·지문형)과 star 무관
- 모든 유형에서 다중 조건·역방향·자취·다층 결합·다중 통찰로 ★ 5 도달 가능
