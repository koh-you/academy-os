**원본 pick 을 병렬로 돌리지 마라.** 통합관리 **C40**.

동시에 도는 작업자는 서로를 못 본다. **「이미 쓴 목록」은 과거만 담는다.**
🔴 **한 사람이 열일곱을 다 고른 뒤 변형 작업을 나눈다.**

**Why:** 세션 115 에 옛 11번과 16번이 **같은 원본(와부고 2019 1학기 기말 17번)을 골랐다.**
둘 다 「안 겹친다」고 **옳게** 보고했다 — 상대가 무엇을 고르는 중인지 볼 수가 없었다.
세션 114 에도 같은 사고가 났다 (7번·12번). **두 세션 연속이다.**

**How to apply:** 원본 pick 은 한 번에 한 사람. 고른 결과를 대조표에 **원본 회차**와 **원본 번호**를
**따로 칸으로** 적는다 (한 칸에 붙여 쓰면 눈으로 못 센다). 그다음에야 변형을 나눈다.
