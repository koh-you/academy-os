### 2. 영구 정책 신설·확립 (5건)

1. **[[feedback_exam_paper_template_v2]] v2.1 갱신** (2026-07-02): shipout FG 분할선 방식 + 상하우선 배치 + 0.46 minipage + `\raggedcolumns` + `\cond` 좁은 컬럼 사용 금지. 마스터 "이 형태가 기본 디자인 레이아웃이야" 명시. **단일 출처**: 예상 1·2회 폴더.

2. **EQ(고차방정식) 단원 나머지정리 = 세제곱 합차공식 only** (2026-07-02): "여러 가지 방정식과 부등식 (고차방정식)" 슬롯에 나머지정리 문제 배치하려면 반드시 허근을 갖는 이차식 나누기 + $\omega^3$ 관계 활용. 다른 나머지정리 형태(표준 $x-1$ 나머지, $x^2+1$ 4주기 등)는 PL(다항식) 단원 소속.

3. **problem 환경 `#1` 인자 사용** (2026-07-02): `\refstepcounter{probnum}` 폐기, `\setcounter{probnum}{#1}` + `#1.` 직접 표시. tex 배치 순서와 무관하게 명시된 번호 표시. → 상하우선 배치 필수 요건.

4. **문항 상하 우선 배치** (2026-07-02, 마스터 재차 확인): tex 순서 N, N+2, N+1, N+3 → 시각적 [N][N+2]/[N+1][N+3]. 학생이 좌측 열 세로로 읽고 우측 열 세로로 읽는 한국 시험지 표준.

5. **답지 `\raggedcolumns`** (2026-07-02): `\begin{multicols}{2}` 앞 필수. 마지막 페이지 열 균등화 해제 → 좌측 열 채운 뒤 우측 열 자연 흐름.
