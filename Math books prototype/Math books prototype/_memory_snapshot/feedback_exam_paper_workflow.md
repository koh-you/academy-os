**시험지(testpaper)** 제작 시 따르는 전용 워크플로우. 동화고 1학기기말 1·2회차에서 실전 검증된 8단계. 일반 교재(유형편·연습편·해설지)와는 디자인 정체성·배점 정합 요구가 다르므로 분리 운용.

## 시험지 정의

- 한 회차 = 25문 전후, 총점 100점 정확
- **구간 구조 (v0.2, 11회차부터, 2026-06-27)**: 객관식 + 통합 서답 2구간. `\examsection`은 객관식만. 통합 서답은 별도 헤더 없이 객관식 직후 이어붙임. 슬롯별 `\pointbadge`·`\choices`·`\finalans`로 형식 변별
- **옛 구간 (~10회차, 보존)**: 객관식 + 단답형 + 논술형 3구간 (각 \examsection)
- 문제지(`N회차-문제.tex`) + 답지(`N회차-답지.tex`) 2 PDF
- 별도의 `style.sty`에 시험지 매크로 일괄 정의 (예: `output/공통수학1/동화고-1학기기말-예상/style.sty`)
- **난이도 표기**: 시험지는 `\pointbadge{N}` 점수로 표기 — 100점 만점 정합 의무 ([[feedback-100-point-policy]])
- **유형교재(유형편·연습편)는 본 워크플로우 적용 외** — `\dota`·`\dotb`·`\dotc` 도트 표기. 점수 개념 없음. 100점 만점 정책 적용 외.

## 8단계 표준 워크플로우 (마스터 정의, v3.1 갱신 2026-06-21)

본 8단계는 **검수 3축** (난이도·교과과정 용어·세련도)을 모두 포함. 어느 한 축도 누락 금지.

1. **(축 1) v3.0 3층 모델 산정 (25문 전수)** — `bank/schema.md` v3.0 루브릭으로 1층 M(Mₛ·Mₖ·Mₐ·Mₜ) · 2층 I(8유형 통찰) · 3층 X(친숙도) → base★ → effective★
2. **(축 1) v3.1 세련도(refinement_score) 산정** — `bank/4점-패턴-카탈로그/03-패턴-카탈로그.md` 4축 30패턴 적용. ★ 4 의무 ≥ 2 / ★ 5 의무 ≥ 3
3. **드리프트 식별** — 적정 ★ 대비 ±1 이상 어긋난 문항 식별. 세련도 미달 슬롯 식별. 재출제·승급·강등·발문 보강·본문 교체 결정. **[[feedback-100-point-policy]]에 따라 다른 슬롯 보정으로 총합 유지**
4. **(축 2) 교과과정 내 용어 사용 검수 + 디자인 가이드 자동 검출** — `\sum`·`\cup`·`\cap`·`[a,b]`·"등차수열"·"비이웃"·**"분기"**·`\step` 안 디스플레이 뒤 텍스트 등 위반 grep + 패치. **인라인 행렬·긴 결과식의 디스플레이 분리 점검** ([[feedback-inline-matrix-display-split]]). 압축 신조어·비표준 학습 용어 0건 의무 ([[feedback-no-compressed-terms]])
5. **배점 5단 변별 매핑 + 100점 정합** — ★ 별·문항 형식별 차등 배점, 합 100점 정확 계산
6. **(축 1·2·3) 3종 에이전트 의무 병렬 호출** ([[feedback-auto-review-completed-work]] 단계 2.5):
   - `problem-review` v3.1 — 3층 모델·세련도·앵커·정합성·중복 패턴·디자인 위반 잔존 확인
   - `general-purpose` — 답지 보지 않고 독립 풀이 → 25/25 답 일치 확인 ([[feedback-independent-solve-no-quickgrid]])
   - `solution-author` — 답지 풀이 톤·자세도·step 분리·디자인 규칙 9개 적용 + 압축 신조어·"분기" 검출
7. **xelatex 2-pass 빌드 + 로그 0건** — Overfull/Underfull(badness≥2000)/폰트 누락 모두 0
8. **(축 3) 통합 보고** — 표 4종(v3.0/v3.1 점수표, 디자인 가이드, 분포 정합, 앵커 비교) + 빌드 상태. **검수 3축 분리 보고 의무**

## 시험지 특화 디자인 (`style.sty`)

| 매크로 | 용도 |
|---|---|
| `\pointbadge{N}` | 배점 뱃지 (5단 변별: 2.5/3/3.5/4/4.5/5/5.5점) |
| `\soltitle{번호}{제목}{배점}` | 답지 풀이 헤더 |
| `\step{N}` | 풀이 단계 박스 (hanging indent 적용 — 본문 시작 열 정렬) |
| `\finalans{}{$답$}` | 단답·논술 최종 답 박스 |
| `pagepair` 환경 | 2단 컬럼 페이지 (문제 2개씩 묶음) |
| `quickgrid` 환경 | 답지 첫 페이지 빠른 정답표 |
| `examheader` / `examsection` | 시험지/구간 헤더 |
| `\nob{...}` / `\cond{...}` | 줄바꿈 방지 wrapper |
| `\choices` / `\choicesii` / `\choicesv` | 보기 5지선다 (길이별) |
| `conditions` 환경 | 발문 (가)(나)(다) 조건 박스 |

## 발문 디스플레이 표준 (v3.1 신규, 2026-06-21)

긴 인라인 수식·행렬은 페널티 \binoppenalty=10000·\relpenalty=10000 환경에서 줄 끝 빈공간을 유발한다. 다음 표준 패턴을 적용한다.

```
[발문 짧은 텍스트] \cond{...}
$$ [인라인이면 너무 긴 행렬·등식·결과식] $$
\begin{conditions} (가) (나) (다) \end{conditions}   ← 있다면
\begin{choices} ... \end{choices}
```

- 디스플레이는 **발문 끝**에 배치 (디스플레이 뒤 짧은 텍스트 단독 금지 [[feedback-display-math-layout]])
- 인라인 행렬 `$A = \begin{pmatrix}...\end{pmatrix}$`이 컬럼 폭 초과하면 디스플레이로 분리
- 결과식 자체가 너무 길어 한 줄 안 들어가면 **두 번째 디스플레이로 분리** (#14 사례 — 정의식 디스플레이 + 결과식 디스플레이)
- 보기·조건 박스는 디스플레이 뒤에 자연 위치 (가이드 위반 아님)

## 시험지 보강 워크플로우 (v3.1 신규, 2026-06-21 동화고 2회차 사례)

검수 후 라벨 드리프트·세련도 미달이 발견되면 다음 보강 절차를 따른다.

1. **그룹 분류** — A(절차형 ★ 1~2) / B(표준 ★ 3~4) / C(변별 ★ 4.5+)
2. **그룹별 보강 안 작성** — A·B는 발문 보강(조건 추가·결과식 변경)으로 ★ 한 단계 상향. C는 카탈로그 패턴 적용으로 refinement_score 강화
3. **단계적 진행** — 한 번에 전체 25문 일괄보다 그룹 단위(5~14문) 분할이 안전
4. **답 mathjs 검증** — 보강한 모든 문항의 신규 답을 `scripts/math-verify.mjs` 또는 node + mathjs로 재검증
5. **본문 + 답지 동시 수정** — 발문·점수·보기·풀이 모두 정합
6. **100점 만점 유지** ([[feedback-100-point-policy]]) — 상향 점수만큼 다른 슬롯 강등으로 보정
7. **자동 재검수 1패스** — [[feedback-auto-review-completed-work]] 절차로 보강 후 즉시 재검수

## 시험지 vs 교재 차이점

- 시험지: 25문 한 회차 단일 단위. 100점 정확 합산 의무.
- 시험지: 한 출제 시즌(예: 동화고 기말 1·2회차) 안에서 회차 간 패턴 중복 회피 강제.
- 시험지: 객관식 + 통합 서답 2구간 구조 (v0.2, 11회차+) — 1~10회차는 옛 3구간. 별도 답지 PDF.
- 시험지: ★ 4·5는 `bank/anchors/CM1-{단원}.md`의 v3.1 세련도 앵커 2문과 비교 의무.
- 일반 교재: 단원·유형별 다수 문항, 페이지 분할 자유.

**Why:** 마스터가 동화고 기말 1·2·3회차 작업 후 명시 (2026-06-19). 2026-06-21에 v3.1 세련도 카탈로그가 추가되어 ★ 4·5 변별의 패턴 라이브러리 적용이 가능해짐. **배점 100점 정합 / 회차 간 패턴 중복 회피 / 시험지 디자인 매크로 / 세련도 의무**는 시험지에만 특화됨. 워크플로우를 별도 명명해 재사용 효율성 확보.

**How to apply:**
- 사용자 요청에 "시험지", "테스트지", "기말", "중간", "N회차", "예상 문제" 등이 등장하면 본 워크플로우 적용
- 새 시험지 작업 시 본 8단계 순서대로 진행
- 1·2회차 동화고 기말 작업이 reference 사례 (`output/공통수학1/동화고-1학기기말-예상/`)
- 5단 배점 매핑은 마스터 결정이 명시되지 않은 한 디폴트로 사용
- `style.sty`는 시험지 폴더마다 독립 보유 (테스트지 폴더 안에 같이 둠)
- 보강 시 [[feedback-100-point-policy]] 의무 적용
- 발문에 인라인 행렬·긴 결과식이 있으면 [[feedback-inline-matrix-display-split]]에 따라 디스플레이로 분리
