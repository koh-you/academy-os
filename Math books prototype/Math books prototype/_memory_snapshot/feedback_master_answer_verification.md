마스터가 신규 출제 요청 시 제공하는 *정답 표·검증 메모*가 산수·로직 오류로 실제 풀이 결과와 다를 수 있음. 이때 **검수·풀이 작성 에이전트가 자체 검증으로 불일치를 발견하면 즉시 본문 보기·답을 정정**한다.

**Why**: 마스터가 제공한 정답이 *권위가 있더라도* 수학적 사실은 *독립 검증* 가능. 정답 불일치는 학생에게 큰 혼란을 일으키므로 *발견 즉시 정정*이 우선. 마스터에게 사후 보고하면 승인.

**How to apply**:
- solution-author / problem-review / general-purpose 독립풀이 등 검수 에이전트가 *직접 풀이*로 답을 재계산
- 마스터 표 답 ↔ 실제 답 불일치 발견 시:
  1. 답이 명백히 마스터 표 측이 산수 오류면 → **본문 보기·답을 실제 답에 맞게 자동 정정** (자동 모드 합리 판단)
  2. 정정 사실을 보고에 명시 (변경 사항·정확 산수 검증·사후 승인 요청)
  3. 마스터 사후 승인 후 메모리에 기록 (해당 회차 project 메모리에 사례 추가)
- 단, *판단 모호*하거나 *답 자체보다 통찰 의도*가 영향받을 경우 → 마스터 결정 권장

**사례** (2026-06-24 5회차 #13):
- 마스터 표 정답 ③ $180$ (가운데 두 자리 곱 짝수 case 30가지 계산)
- 실제 풀이: 3쌍(양 끝 합 7) × 2(순서) × 10(가운데 짝수곱 경우) = **60**
- solution-author가 자체 검증으로 불일치 발견 → 본문 보기를 `144·160·180·200·216` → `36·48·60·72·84`로 정정, 정답 ③ $60$
- 마스터 사후 승인 완료
