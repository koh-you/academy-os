# 수능특강 5매크로 (M9·M5·M7·M8·M2) 전부 기각

세션 63 수능특강 벤치마킹 기반으로 개발된 5매크로 (Level 배너·예제 배지·유제 리본·dot line·페이지 프레임) 마스터 최종 기각. 시판 근거 인용도 부족한 승인 사유가 되지 못하며 · **PDF 실물 시각 확인이 유일한 승인 게이트**.

**Why**: 세션 63 후반부 · 5매크로 승인 이후 PDF 재빌드 · 마스터 시각 확인 결과 "다 기각". 세션 58 5안 (즉흥 mockup 순수 장식) 기각 · 세션 63 시판 벤치마킹 기반 5매크로도 기각 · 결과적으로 **DeeP Math 디자인 완성도 향상 방식에 대한 접근 자체가 재검토 필요**.

**How to apply**:
- 폐기된 5매크로 파일 (`templates/dm-suneungtukgang-smoke/*`) 참조·재사용 절대 금지
- concept-author v1.2 신규 정리편 창작 시 이 매크로 미사용
- 향후 디자인 시도 시:
  - 시판 벤치마킹만으로는 충분 조건이 안 됨
  - smoke-test PDF 마스터 실물 확인이 최종 승인 게이트
  - PNG 프리뷰 재활용이 아닌 매 시연마다 재빌드 PDF 열람 필수
  - 매크로 스타일이 DeeP Math 브랜드와 부조화 여부를 미리 판단하기 어려움 · **작게 시작·자주 확인** 원칙

**대안 방향** (마스터 지시 대기):
- 완전 재검토 (매크로 접근 자체 폐기 · 여백 그대로)
- 다른 시판 벤더 벤치마킹 (블랙라벨·수학의바이블·마플교과서 등)
- 소규모 요소부터 (배너 하나·프레임 하나) 개별 승인 반복
- 마스터 자체 스타일 지시 (텍스트·색·비율 명시)
