# 페이지 배치 유연 규칙 (Single Column 교재)

**좌우 분할 없이 (single column) 제작되는 교재의 페이지 배치는 문항 특성에 따라 유동 배치한다. 짧은 문제는 한 페이지에 여러 문항, 길거나 그림 있는 문제는 단독 배치.**

**Why:** 세션 55 (2026-07-20) 직선의 방정식 정리편 실전 배치에서 원 R-1·R-3 (짧은 발문·그림 없음) 각각 단독 페이지로 배치되어 페이지의 절반만 사용 · 학생 풀이 공간 낭비. 마스터 지적 "3번과 1번을 같은 페이지에 두문제 넣자 문제가 짧은데 한페이제 하나는 이상한거 같아". 반면 R-2 (긴 빈칸형·그림)는 단독 유지 필요.

**How to apply:**

## 1. 적용 범위

- **적용**: single column 교재 (좌우 분할 없음) · DeeP Math 정리편·유형편·연습편 본편
- **적용 예외**: multi-column 교재 (`\begin{multicols*}{2}`) · 답지 (2컬럼 조판) — 답지는 다른 규칙 (풀이 세로 흐름 고려)

## 2. 판정 기준 (문항 유형별 페이지 배치)

| 문항 유형 | 발문 길이 | 그림 | 풀이 공간 필요 | 배치 |
|---|---|---|---|---|
| **L3 · 실전 통찰형** | 길고 복잡 (200자↑) | 있음 | 넉넉히 | **단독 페이지** |
| **L3 · 실전 통찰형** | 짧음 (200자↓) | 없음 | 보통 | **최대 3문/페이지** |
| **L3 · 실전** | 중간 (200~300자) | 없음 | 보통 | **1~2문/페이지** (여백 판단) |
| **Level 1·2** | 짧음~중간 | 대체로 없음 | 보통 | **3~4문/페이지** (기존 규정) |
| **확인 (CHK)** | 짧음 | 없음 | 짧음 | 대표예제 페이지 하단 2문 (기존) |
| **개념 · 대표예제** | 발문+접근+풀이 | 옵션 | 넉넉히 | **1개념 or 1대표/페이지** |

## 3. 실전·L3 최대 3문/페이지 (마스터 갱신 · 세션 55)

**세션 55 지시 이력**:
1. "실전 기출 및 레벨 3 같이 난이도가 있고 문제풀이 공간이 많이 필요한 문항들은 최대 두문제까지만 한 페이지에 배치" (초기 상한 2문)
2. "직선 연습문제 lv 3 는 세문제 다 한페이지 넣는게 좋아보여. 문제 길이도 안길고 그림도 없잖아" (예외 요청)
3. **"최대 3문제 까지로 바꾸자"** (정책 상한 갱신 · 최종)

**최종 규정**:
- L3·실전은 **최대 3문/페이지** (상한)
- 4문 이상 배치 금지
- 문항 특성 (발문 길이·그림·풀이 공간)에 따라 1~3문 유연 배치

## 4. 재배정 규칙

페이지 재구성 시 문항 번호는 **재배치 순서에 따라 새 번호 부여**:
- 원 순서 (R-1, R-2, R-3) 유지 필요 없음
- 페이지 상단부터 순차 (1, 2, ...) 재번호
- 답지 quickgrid·dmsoltitle 번호도 함께 갱신
- 청사진 `page_layout` 필드 반영

## 6. 판단 흐름 (자동 판정 알고리즘)

1. **발문 길이 측정** (문자 수)
   - ≤ 200자: 짧음
   - 200~400자: 중간
   - > 400자: 길음
2. **그림 유무 조회** ([[feedback_figure_source_original_only]] · `bank/그림-원문-데이터.md` 참조)
3. **풀이 공간 필요도 예측** (통찰형 depth · 답 복잡도)
4. **페이지 배치 결정**:
   - 짧음 + 그림 없음 → 다른 짧은 문제와 페어링 (최대 3문/페이지)
   - 길음 or 그림 있음 → 단독 페이지
   - 중간 → 상황 판단 (여백 검토)
