# 답지 학습 정책 (2026-06-30 마스터 확립)

## 핵심
**시판 책에서도 답지는 공개자료로 제공되므로 저작권 문제 없음**. 답지를 함께 분석하여 *어떻게 문제를 풀어내고 설명하는지* 학습 의무.

## 학습 대상
- **풀이 전개 방법**: 단계 분배·논리 흐름·생략 vs 명시 균형
- **설명 방식**: 한국어 문장 구조·수식 도입 어구·결론 어구
- **답지 디자인 양식**: 박스·구분선·단계 라벨·강조 표기
- **그래프·도형 표현**: [[feedback_graph_extraction_study]] 별도

## 🌟 우선 학습 책 (2026-06-30 마스터 영구 지침)

**고쟁이 답지 전수 학습** = 우선 학습 책. 전 과목 (CM1·CM2·대수·미적·기하·확률통계) 공통.

| 자료 | 판정 사유 | 일시 |
|---|---|---|
| **마더텅 20분 미니모의 24회 답지** | 정식 해설지 아닌 *간이 풀이* (1-5줄 압축). 한자어 압축 빈도 높음. 우리 책 정책 [[feedback_solution_verbosity]] + [[feedback_natural_korean_wording]]와 충돌 | 2026-06-30 |

## 적용 범위

### 기존 등록 자산
**현재 bank/problems/ 3,845문 중 본문·풀이 등록은 OUT-* 81문뿐**. 나머지는 status: meta_only.

답지 학습은:
- ✅ 풀이 등재 의무는 아님 (저작권 회피)
- ✅ *분석·학습*은 의무 (우리 책 풀이 작성 시 모범 표본으로 활용)
- ✅ 답지 PDF가 자료 폴더에 있는지 확인, 있으면 학습 자료로 활용

### 신규 자산화
신규 자료 자산화 시 *답지 PDF 함께 변환·학습*:
1. 문제 PDF → 자산화
2. **답지 PDF → 함께 시각 추출, 풀이 전개·설명 양식 학습**
3. 학습 결과 → `bank/풀이-양식-카탈로그.md` (신설 예정) 누적

## How to apply
- 시판 책 PDF 처리 시 *답지 PDF도 함께 변환*
- 우리 책 풀이 작성 시 시판 책 답지의 *서술 방식 모범 표본* 참고
- 신규 단원 풀이 작성 전 해당 단원의 답지 양식 학습 우선
