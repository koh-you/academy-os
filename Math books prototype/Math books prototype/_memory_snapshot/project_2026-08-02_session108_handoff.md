# 세션 108 (2026-08-02) 마무리 상태

## 오늘 바뀐 것 — 큰 것 넷

**1. 재는 것은 네 가지다** — 깊이 · 연산 부담 · 해석·독해 부담 · 얽힘.
사다리 하나였던 「실행 부담」을 **셋으로 갈랐다.** 하나를 골라 대표로 삼지 않는다.
→ [[feedback_four_values_not_one_choice]]

**2. 얽힘은 개수를 센다** — 연결된 소문항·조건의 최대 개수. 틀렸을 때를 그려 보지 않는다.
연산 부담과 붙어 있던 것이 **95% → 55%** 로 떨어졌다. → [[feedback_entanglement_is_counting]]

**3. 눈금은 1.0 ~ 6.0** (5.0 이 상한이 아니다). ★ 5 프리미엄 = 5.0 초과 ~ 6.0.
🔴 **네 값의 평균은 시스템이 완성된 뒤에 쓴다.**

**4. 🔴🔴 사람처럼 쓴다 — 최우선 지침.** 통합관리 §0 신설.
지어낸 낱말 아홉을 폐기: 조각 · 단수 · 정본 · 사슬 · 분기 · 합류 · 먹인다 · 물린다 · 미끄러진다.
낱말 사전 `bank/용어-사전.md` + 검사기 `scripts/용어-검사.mjs` 신설. → [[feedback_speak_like_a_person]]

**5. 세는 법을 본줄 하나로 다시 세웠다** — 「세는 법 1~5」를 나란히 적어 둔 탓에
맨 앞 자격 줄이 본줄로 읽혔다. 이제 **본줄 하나**(묶어서 가장 큰 덩어리를 센다) + **딸린 자격 줄 표**다.
🔴 **소문항이 셋이라고 3 이 아니다** — 남남이면 1(B1j) · 둘만 이어지면 2(B2c) · 줄줄이면 3(B3o).

**6. 조건과 상황 설정을 갈랐다** (통합관리 C28) —
**조건 = 해석이 필요한 제시문이나 수식** · **상황 설정 = 무엇을 다루는지 알려 주는 말.**
「$f$ 의 최고차항의 계수는 1」은 **상황 설정이라 안 센다.** 🔴 **상자 안이냐 밖이냐는 상관없다.**

**7. 🔴🔴 결론을 먼저 정하고 측정을 거기 맞추지 마라** (통합관리 C27) —
[[feedback_measure_by_definition_not_conclusion]]
