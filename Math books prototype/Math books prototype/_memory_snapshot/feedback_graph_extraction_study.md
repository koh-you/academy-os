# 그래프 표현 학습 정책 (2026-06-30 마스터 확립)

## 핵심
**자료 분석 시 그래프 표현 방법을 정교하게 학습**. 우리 책 제작 시 그래프 오류 절대 금지. 학평·시판 답지의 그래프 모범 사례를 학습·재현.

## 학습 항목

| 항목 | 학습 포인트 |
|---|---|
| **좌표축 스케일** | 단위 길이, 가로·세로 비율, 격자 간격 |
| **그래프 길이** | 곡선·직선의 시작·끝점, x·y 범위 |
| **점선 사용 상황** | 보조선·관측선·평행선 vs 실선 |
| **텍스트 폰트** | 한글·영문 폰트 종류, 수식 italic, 라벨 폰트 |
| **텍스트 크기** | 좌표 라벨·곡선 라벨·각도 라벨의 크기 위계 |
| **필체** | 수식 폰트 (Computer Modern·Times·이태리), 한글 필체 |
| **표기 위치** | 좌표 라벨은 축 아래·왼쪽, $y=f(x)$ 라벨은 곡선 오른쪽 끝 등 |
| **좌표 표현** | $(a, b)$·$\mathrm{P}(a, b)$·O(원점) 표기, 점 마커 |

## How to apply

### 자료 분석 단계
시판 책·기출 PDF 자산화 시 *그래프 포함 문항*은:
1. 페이지 이미지에서 그래프 발견
2. **그래프 표현 양식 분석**: 위 8개 항목 모두 점검
3. **`bank/그래프-양식-카탈로그.md`** (신설 예정)에 모범 사례 누적
4. *비표준·열등 사례*도 기록 (회피 대상)

### 우리 책 제작 단계
그래프 작성 시:
1. 모범 사례 카탈로그 참조
2. TikZ 코드 작성 시 8개 항목 점검 체크리스트 적용
3. 빌드 후 시각 검사 — 학평 양식과 비교
