마스터 명시 2026-06-27: "앞으로 모든 자료에 코드명 버전명은 기록하지마"

**Why**: 학생·교사가 보는 학습자료에서 *내부 코드명* ("EQ-시범-1회차", "v1.0", "CM1-EQ" 등) 노출은 *시리즈 정체성*을 흐리고 비전문가에게 부담. 단순 식별 ("미니모의고사", "vol.1") 만으로 충분.

**How to apply**:

1. **헤더 박스 안 표기**: 단순 식별만 (예: "vol.1" / "미니모의고사")
2. **\examround**: 단순 라벨 ("미니모의고사" / "vol.1")
3. **\examheader 첫 인자**: 빈 또는 *의미 있는 부제* (코드명·버전 금지)
4. **\examheader 두 번째 인자 (푸터)**: 단원 + 문수 + 시간만 (예: "공통수학1 — 8문 / 20분")
5. **\answerheader**: 동일 규약 ("정답·해설" + "공통수학1 — 8문 / 20분")
6. **파일명**: 내부 관리용이므로 회차 번호 등 OK (예: `1회차-문제.tex`)
7. **폴더명**: 마스터 명시 없으면 그대로 유지 가능

**금지 예시**:
- ❌ `\examheader{EQ 미니모의고사 시범 1회차 v1.0}{공통수학1 — 방정식·복소수·부등식 (CM1-EQ) — 8문 / 20분 / 29점 / 학습자료}`
- ❌ `\examround = 동화고 1차` / `\examround = EQ 시범 1회차`
- ❌ 박스 안 "EQ 시범 1회차" / "vol.1 v1.0"

**허용 예시**:
- ✅ `\examheader{}{공통수학1 — 8문 / 20분}` + `\examround = 미니모의고사`
- ✅ 박스 우측 = "vol.1"
- ✅ `\answerheader{정답·해설}{공통수학1 — 8문 / 20분}`

**적용 외**: 청사진 yaml·메모리·내부 도구·자동화 스크립트·파일명·폴더명은 코드명 가능. 마스터 노출 자료(헤더·표지·답지 헤더·푸터)만 본 규약 적용.
