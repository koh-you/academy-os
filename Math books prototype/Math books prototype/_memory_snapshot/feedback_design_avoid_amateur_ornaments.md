**규칙**: 여백을 채우기 위한 목적의 순수 시각 장식(좌측 stripe·문항 dot·페이지 코너 오너먼트·챕터 색 세로 tab·문항 그룹 카드 프레임 등)은 마스터가 "허접·조잡"으로 강하게 기각. 시판 프로 교재(블랙라벨·마더텅·개념원리·RPM 등) 실제 페이지 시각 밀도·구성 요소를 정독·벤치마킹한 뒤 근거를 가지고 제안할 것.

**Why (세션 58 사건)**:
- 후보 A(좌측 골드 stripe + 문항 dot): "이상"이라며 기각
- 후보 신규 3종(코너 오너먼트 + 챕터 색 tab + 문항 그룹 카드): "너무나 허접하고 너무나 조잡해"라며 강한 기각
- 공통점: 모두 **콘텐츠 기능 없이 시각 채움만 목적**. 즉흥 mockup 기반 · 시판 교재 벤치마킹 없이 상상으로 그림

**대비**:
- 조건 박스(dmoptionbox · 후보 H): **채택**. (가)(나)(다)/ㄱㄴㄷ 조건을 명확히 구분하는 **콘텐츠 기능 매크로**라서 시각 목적이 아닌 학습 기능 목적

**How to apply**:
1. 여백 문제 지적 시 즉흥 mockup부터 그리지 말 것
2. 먼저 **시판 교재 PDF 정독** (`참고자료/`)으로 실제 프로들이 여백을 어떻게 다루는지 학습
3. 벤치마킹 결과를 근거로 제안 (예: "블랙라벨 p.42는 여백에 X를 배치했음. 우리 페이지도 유사 접근 가능")
4. **콘텐츠 기능 매크로 우선** (조건 박스처럼 학습 기능이 있는 것)
5. 순수 장식(도형·색선·프레임)은 시판 교재에서 실제 사용되는 경우에만 도입

**예외**: 마스터가 명시적으로 "장식이라도 좋다"고 지시한 경우만
