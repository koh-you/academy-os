# 축 프레임 대비 평면도형 여백 규약 (v2 · 신정책 2026-07-20)

**모든 TikZ 좌표평면 그림에서 평면도형(삼각형·사각형·다각형·닫힌 도형)은 좌표축 프레임의 80% 이하여야 한다. 즉 여백 ≥ 20% 필수.** 여백은 각 축 방향별로 (축 범위 - 콘텐츠 범위) / 축 범위로 계산.

**Why:** 세션 55 (2026-07-20 · 2차 갱신) 마스터 지적 "평면도형 그림은 좌표축의 전체 크기보다 항상 20% 이상 작게 그려" · 직선의 방정식 R-2에서 삼각형 OAB의 정점 A(14,2)가 x축 화살표 끝(14)에 도달·y축 축 안까지 채워져 도형이 좌표축을 넘어 튀어나오는 문제. **v1 정책 (여백 ≤ 15% GREEN)은 폐기**. 도형이 축을 뚫고 나가지 않도록 상한 부여.

**How to apply:**

## 1. 정량 기준 (여백 = (축 범위 - 콘텐츠 범위) / 축 범위)

| 여백 | 판정 | 조치 |
|---|---|---|
| ≥ 25% | GREEN | 통과 |
| 20~25% | YELLOW | 여유 축소 여지 |
| < 20% | RED | 축 확대 (콘텐츠 넘어감 · 도형이 축을 뚫음) |

각 축 (x·y) 별도 판정. 두 축 중 하나라도 RED 시 그림 RED.

## 1-1. v1→v2 정책 반전 이유

v1 (≤15% GREEN): 축 넓게 그리는 것 금지 (지면 낭비 우려)
v2 (≥20% GREEN): 도형이 축 뚫는 것 금지 (마스터 지적 · 시각적 정합성)

v2가 우선. 축 프레임을 콘텐츠보다 25% 이상 크게 잡아 도형이 축 안에서 여유롭게 놓이도록 함.

## 2. 조정 방법 2가지

### 방법 A: 축 tighten
콘텐츠 bbox의 min/max에 여백 5~10%를 더한 값으로 축 범위 축소. 라벨 오프셋 확보 필요 시 여백 15%까지 허용.

### 방법 B: scale 확대
scale 값을 올려 전체 그림 크기 확대. 페이지 폭 초과 여부 사전 점검 (`\linewidth` 대비).

**우선순위**: A → B 순. 두 방법 모두 적용 시 최대 채움.

## 3. scale 변경 시 재검수 의무

`scale=X` 값이 변경되면 반드시 재검수:
- **라벨 위치 재확인**: 스케일이 커지면 축 실선이 두꺼워 보여 라벨 겹침 두드러짐. `[above]`가 y축 위 점 (x≈0)에 대해 사용된 경우 특히 위험.
- **콘텐츠 bbox 재계산**: 관례상 축은 콘텐츠에 맞춰 설정되므로 scale 변경 자체는 여백 % 변하지 않으나, 확대 시 라벨 잘림·타 요소 겹침 여부 확인.

## 4. 자동 검증 도구

`scripts/figure-check.mjs` (세션 55 신설):
```bash
node scripts/figure-check.mjs <파일.tex>
```
- 축 tikzpicture 블록 파싱 → 축 실선·콘텐츠 점·라벨 위치 추출
- Check 1: 라벨-축 근접도 (RED/YELLOW/GREEN)
- Check 2: 프레임 채움 여백 % (RED/YELLOW/GREEN)
- exit code: 0 GREEN · 1 YELLOW · 2 RED

## 5. 위반 사례 (참고)

### 세션 54 R-2 (2024학년도 9월 고1 학평 20번)
- 콘텐츠 x 범위 [-8, 7] = 15 units · 축 [-9, 8.5] = 17.5 units · **여백 14.3%** (경계)
- 콘텐츠 y 범위 [0, 12] = 12 units · 축 [-1, 13.5] = 14.5 units · **여백 17.2% YELLOW**
- 세션 55 정정: 축 [-8.5, 7.8] × [-0.6, 13] · scale 0.32 → 0.4 · 여백 x 4.5% · y 11.6% GREEN

### 세션 54 R-3 (2019학년도 9월 고1 학평 29번)
- 콘텐츠 x 범위 [-2, 2] = 4 units · 축 [-3.3, 3.3] = 6.6 units · **여백 39.4% RED**
- scale=0.48 → 0.8 (세션 55) · 축은 미조정 · 여백은 동일 RED 상태
- 후속 조치: 축 tighten 필요 (다음 세션)
