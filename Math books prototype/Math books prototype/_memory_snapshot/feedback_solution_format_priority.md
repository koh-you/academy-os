# 답지 형식 우선순위 (영구 정책, 2026-06-30 마스터 명시)

> 답지 형식을 학평 형식보다 고쟁이 형식을 우선으로 할것

## 규칙

우리 책 답지 디자인은 **고쟁이 양식**을 *제1 우선* 학습·차용 표본으로 한다. 학평 양식은 *제2 보조* 표본.

## Why

마스터가 시판 책·기출 답지를 모두 분석한 결과, 고쟁이 양식이 우리 책 톤·풀이 자세도·디자인 정합도에 더 부합한다고 판단. 이전 학평 양식 단일 출처 [[feedback_graph_design_style]] (2026-06-28)는 *학평 그래프 디자인* 중심으로 정착했으나, 본 정책으로 *전체 답지 형식*의 우선순위가 뒤집힘.

학평 양식은 폐기 아님 — 고쟁이 양식에 부재한 경우 보조 표본으로 활용.

## How to apply

### 풀이 양식 (고쟁이 우선)
- 단계 라벨 없이 등호 정렬 식 변환 줄 위주 (단, 우리 책 단계 라벨은 별도 영구 폐지 [[feedback_step_label_deprecated]])
- 핵심 변환 전후에 *짧고 명확한* 한국어 설명
- `[다른 풀이]` 라벨 (박스 없이) — 본 풀이와 구분
- `[TIP]` 라벨 박스 — 보조 설명·변환 트릭
- 박스 강조 — 핵심 식·중간 결과 둘러쌈
- 답 표기 — `>> ⑤` 또는 우리 책 양식 `\answerbox`

### 그래프·도형 양식 (고쟁이 우선, 학평 흑백 only 폐기)
- *컬러 사용 OK* (보라·파랑·빨강 강조) — 기존 [[feedback_graph_design_style]] 흑백 only 폐기
- 정점 라벨 (점 옆 오른쪽 위)
- 길이 라벨 (변 옆)
- 도형 면 음영 (색깔로 면 구분)
- 핵심 강조 (빗변·대각선) — 컬러
- 선 굵기 자유 (학평 0.4pt 강제 폐기)

### 충돌 단일 출처 정정 (즉시 의무)
- [[feedback_graph_design_style]] — "학평 양식 단일 출처" 부분 정정 (고쟁이 우선으로 갱신)
- `bank/풀이-양식-카탈로그.md` — 우리 책 적용 후보 섹션 고쟁이 우선 명시
- `bank/그래프-양식-카탈로그.md` — 학평 우선 부분 고쟁이 우선으로 정정
