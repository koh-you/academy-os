# 라벨 배치 4대 규약 + 미세 조정 원칙

**2026-07-18 세션 48** DeeP Red 2회 정점 4문 삽화 iteration에서 마스터 확립.

## 4대 규약 (필수)

### 1. 라벨은 실선과 겹치면 안 됨
- 원·직선·축 등 **실선을 라벨이 통과하지 않아야** 함
- `fill=white` 사용 금지 (실선을 지워서 그래프 훼손). 위치 조정으로 해결
- 원 위 점의 라벨: 원 실선을 통과하지 않게 원의 안쪽 or 바깥쪽 명확
- 원 자체 라벨 (`C_1`, `C_2` 등): 원 실선과 이격 확보 (실선 위에 라벨 X)

### 2. 라벨끼리 겹치면 안 됨
- 두 라벨 간 좌표 이격 확보
- 특히 인접한 점의 라벨 (예: B 근처의 C_2)이 서로 방향 반대편 or 대각선 이격
- 라벨 폭·높이 · 폰트 크기 대비 좌표 유닛 계산 (scale에 종속)

### 3. 라벨은 표현 주체와 최대한 밀접
- 점 라벨은 점 바로 옆 (fp-dot과 인접)
- 원 라벨은 원 안·밖 관계 유지 (작은 원 라벨은 안 · 큰 원 라벨은 밖 · 마스터 확립)
- 다른 개체와 혼란 방지: 라벨이 다른 점·다른 원의 것으로 오인되지 않도록

### 4. 점선 겹침 불허 (v2 · 2026-07-22 세션 73 강화)
- **실선·점선 모두 라벨과 겹침 불허**. 세션 48 v1 "점선 살짝 허용"은 폐기
- 계기: L2-12 무리함수 그림 `y=√|x-1|` 라벨이 k=-3/4 점선과 겹쳐 시각 저해
- 회피 방법: 라벨을 곡선 끝단 등 **다른 요소가 없는 여백 지역**에 밀착
- 곡선 라벨 표준 위치: **오른쪽 갈래 끝점 옆** (`anchor=west`) 또는 왼쪽 갈래 끝점 위

## 미세 조정 원칙

- **마스터 지시 없이는 극단적 조정 금지**: anchor 방향 전체 변경 지양 · 좌표 미세 조정 (x·y ±0.1~0.5) 반복
- **한 번에 여러 요소 변경 금지**: 하나씩 순차 조정 · 시각 확인 후 다음
- **fppoint vs 별도 노드**:
  - fppoint 매크로 (자동 3pt offset): 표준 · 대부분 충분
  - 별도 fp-dot + fp-name 노드: 라벨 위치 미세 명시 필요 시 (밀착·특정 방향)

## anchor 활용 팁

- `south west`: 라벨 south west corner가 point → 라벨 텍스트는 point의 **north east** 방향 (오른쪽 위)
- `south east`: 라벨 south east corner가 point → 라벨 텍스트는 **north west** 방향 (왼쪽 위)
- `north west`: 라벨 north west corner가 point → 라벨 텍스트는 **south east** 방향 (오른쪽 아래)
- `north east`: 라벨 north east corner가 point → 라벨 텍스트는 **south west** 방향 (왼쪽 아래)
- `west`: 라벨 west가 point → 텍스트 **east** (오른쪽) · y 같음
- `east`: 라벨 east가 point → 텍스트 **west** (왼쪽) · y 같음
- (원 실선 방향 파악 후) 원 안 or 밖으로 라벨을 두려면 · 원 중심 방향의 반대편 (원 밖) 또는 원 중심 방향 (원 안)의 anchor 선택

**중요**: `east`·`west`·`north`·`south`는 tikz의 **anchor** 이름 · tikz의 **방향** 옵션은 `right`·`left`·`above`·`below` (offset 지원). fppoint 매크로에서 4번째 인자로 방향 옵션 (`above right=3pt` 형식) 사용.

## 원의 크기·좌표 조정 시 정합성

- 원 반지름 조정은 문제 조건 (x²+y²=r²)·답 정합 훼손 위험
- 원 위 점 (접점)이 원 실선 위에 정확히 있어야 개념 이해 정합
- 라벨 공간 부족은 라벨 위치 조정으로 해결 · 원 크기 조정 지양 (마스터 명시적 지시 시에만)
