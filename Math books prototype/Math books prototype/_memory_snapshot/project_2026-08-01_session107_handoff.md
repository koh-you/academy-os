# 세션 107 핸드오프 (2026-08-01)

세션 106 이 남긴 ⏭①「본 검정 — 모르는 문항을 사다리에 얹기」를 실행했다.

## 🔴🔴 세션 끝에 전제가 뒤집혔다 — 먼저 읽어라

**검정을 학평 문번을 정답표로 놓고 설계했는데, 그것이 폐기된 규칙이었다.**

> 마스터: 「문번으로 평가하는 건 이미 다 삭제했다」 · 「**사다리가 정답표로 충분해**」

되살아난 이유는 `bank/학평-공통앵커-규약-v1.md` 의 문번→밴드 표에 **폐기 표시가 없었기** 때문이다.
메모리에는 「문번은 깊이 신호가 아니다」가 있었지만 SSOT 에 옛 표가 살아 있어 조사할 때 그게 먼저 잡혔다.
→ [[feedback_ssot_routing_gap]] · 이번에 폐기 표시를 남겼다.

**따라서 아래 §「검정 결과」의 밴드 적중·A3 분석은 무효다.** 유효한 것은
잡음비 0.034 · 사다리 결함 2건 · 맹검 누수 · 판정자 지적이다.
새 기준: [[feedback_ladder_is_the_answer_key]] · `bank/앵커견주기-판정-명세-v1.md` **v2.0**

**밴드는 5개 유지** (마스터 확정 — A1+A2 병합하지 않음).

## 🔴 착수하자마자 나온 것 — 통과선이 잴 수 없는 상태였다

사전 등록된 통과선 셋 중 **둘이 정의가 없었다.**
- `잡음비 0.042` — 「잡음비」라는 낱말이 프로젝트 전체에 **2줄뿐**이고 계산식이 없었다
- `밴드 적중 8/12` — 12문은 특정되나 8/12 을 내는 집계 규칙이 없었다 (C1·C2 로 다시 세면 각 9/12)

세션 106 전반의 교훈 그대로다 — **명세 공백이 값을 지배한다.** 그래서 재기 전에 자를 먼저 확정했다.

**잡음비를 역산해 재현했다**: 일원배치 변량모형 분산성분비
`MSE / s2_item`, `s2_item = (k·s²_평균 − MSE)/k`. 절대값 채점 **0.067 을 소수점까지 재현**.
구현 `scripts/noise-ratio.mjs` · 명세 `bank/앵커견주기-판정-명세-v1.md` (사전 등록본).

🔴 **부수 발견**: `0.042` 는 **밴드 균등 12문에서만** 나온 값이다. 밴드가 치우친 20문에서는 **0.066** 으로
절대값 채점과 다르지 않다. 잡음비의 분모가 「문항이 얼마나 벌어져 있는가」라서
**상단에 몰린 표본은 사다리가 나빠서가 아닌 이유로 값이 커진다.**
→ 표본을 **밴드 균등으로 못박았다.** 다른 표본에서 잰 잡음비끼리 비교하지 않는다.
