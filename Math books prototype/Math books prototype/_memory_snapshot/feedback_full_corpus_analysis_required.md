# 자료 전수 분석 + 자산화 의무 (영구 정책, 2026-06-29 신설)

외부 자료(시판 책·PDF·기출)를 분석할 때 표본 분석 금지. 자료 전수를 분석하고 `bank/problems/`에 등재할 의무.

**Why**: 마스터 명시 (2026-06-29). 시판 자료 N문 분석 후 "N문 중 M문 표본으로 보고" 같은 표본 분석은 본 시스템의 자료 자산화 목표(풍부하고 질 높은 데이터베이스 [[project_overall_goal]])와 충돌. 분석된 자료가 자산으로 등재되지 않으면 다음 회차 출제 시 활용 불가 + 마스터가 다시 동일 분석 요청 발생.

**How to apply**:

1. **전수 원칙**: 외부 자료 N회분·N문이 있으면 전수 분석. "10회 중 1·2회만 표본"·"30문 중 5문 표본" 같은 표본 보고 금지.

2. **자산화 의무**: 분석된 문항은 반드시 `bank/problems/{prefix}-{단원}-{번호}.md` 양식으로 등재. SRC-AS-* (아샘) / EX-HG-* (학평) / EX-MO-* (수능 모의) 등 prefix 사용.

3. **분량 큰 자료 처리**: 분량이 한 세션 한계를 초과하면 *작업큐로 분할*하되 *표본으로 줄여 보고하지 않음*. 분할 회차·페이지를 기록하고 다음 세션 자동 진행.

4. **자산 신뢰도 의무**: 자동화 도구로 빈 골격 등재 시 → 등재 자체가 시스템 신뢰도 훼손. 본 세션 EX-HG 570문 빈 골격 회수 사건이 사례 ([[project_2026-06-29_session2_handoff]] §1.5).
   - 실패 자산 회수 OK > 빈 골격 보존 ✗
   - 한국어 OCR 한계로 자동 추출 실패 시 → β 워크플로우 (PDF → PNG → Read tool 시각 추출) 또는 마스터 직접 첨부 (대안 γ)

5. **단원 분류·★ 라벨 누락**: 등재 자체는 진행하되, `status: meta_only`로 표시 후 정독 시 보강.
