같은 시리즈 (예: 동화고 1·2·...·8회차)에서 *발문 단어만 교체한 자기복제*는 학생에게 *반복 학습* 의미 없음. 시판 4종+ 학평 strict 표본은 *발문 본질·통찰 구조·자유도 결합*이 매번 다름. 우리 시리즈도 *같은 통찰 카드 2개 이상 일치 + 같은 메타 + 발문 시그니처 유사*면 자기복제로 즉시 RED 차단.

**Why**: 마스터 명시 (2026-06-25, 검수 5종 결과 8회차 자기복제 RED 3건 검출 직후): "자기복제 금지 철저하게 지킬것." 검수 5종이 #7 (의자→책상 교란순열)·#17 (비이웃)·#16 (매개변수 부등식) 모두 7회차와 자기복제 검출 → 즉시 재출제.

**How to apply**:
- 출제 *전*: `series-insight-pool.mjs`로 시리즈 누적 카드 추출 → *미사용 카드 우선*. `cross-round-insight-check.mjs v2` (강화 — Jaccard ≥ 0.5 + 카드 ≥ 2 RED) 실행
- 출제 *후*: 같은 시리즈 직전 2회차와 비교 — 통찰 카드 ≥ 2개 일치 시 *재출제*
- *단어 치환 자기복제 회피*: 인물·사물·자리 명사를 *근본적으로 다른 발문*으로 교체 (단순 단어 치환 X)
- 메타 동형 회피: 같은 메타 (예: EQ-quad-ineq-param) + 같은 발문 시그니처 (정수해 N개 ⇒ 매개변수 합)는 다른 메타로 전환
