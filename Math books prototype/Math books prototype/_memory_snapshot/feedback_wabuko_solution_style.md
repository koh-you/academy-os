# 와부고 풀이 서술 10대 규칙 (S1~S10)

**적용 대상**: 모든 답지 풀이 서술 텍스트 (dm-answer-classic.sty v8 매크로 그대로 사용, 서술 스타일만 변경).

**Why (마스터 지시)**:
> "동료 선생님이 만들어 놓으신 교재를 정독하고 그 풀이에서 어떻게 풀이과정을 서술해 나가는지 학습해서 우리 답지 빌드 시스템에 차용하라. 수식과 수식은 어떻게 연결해 나가는지 · 줄바꿈은 언제 사용하는지 · 수식전개 과정은 좌우가 아닌 상하로 이루어지는지 · 한글의 사용빈도는 어떤지 · 문장 사이의 간격은 어떤지 · 그래프를 포함해서."

**시스템 도입 원칙**: 디자인·레이아웃·매크로는 **절대 건드리지 않음** (v8 유지). 서술 텍스트만 규칙 적용.

## 정독 결과 정체성

- **와부고 스타일**: 미니멀 절차 서술 + 상하 정렬 디스플레이 스텝 · **인라인 좌우 → 짧은 디스플레이 좌우 병렬 → 긴 유도만 상하** 3단계 위계
- **우리 팀 현재 스타일 (개정 대상)**: 친절 서사 서술 + `align*` 남용 + 확인 문장 반복 + 접속어("한편"·"이때"·"즉") 남용

## S1. 원자 압축 원칙

한 슬롯당 (한글 문장 : 디스플레이) = **1:1 원자 매칭 3~5쌍**. 6쌍 초과 시 서술이 지나치게 길어짐.

**정의**: **원자** = "한글 조건문 1개 + 수식 결론 1개" 쌍.

**How to apply**:
- 슬롯당 원자 3~5개 목표. 논리 스텝을 잘게 나누지 말 것
- 이미 다뤄진 조건을 재확인하는 문장 금지 ("$x=1$이므로 이 값을 대입하면" → "$x=1$을 대입하면")
- 자동 검수: `atomic-unit-ratio-check.py` · 6쌍 초과 → YELLOW · 8쌍 초과 → RED

## S2. 좌우 병렬 우선

두 결과 (좌표 쌍·해 쌍·값 쌍)는 `$$A,\qquad B$$` **한 줄**. `\begin{align*}` 세로 전개는 **한 줄에 못 담을 때만**.

**정독 예시** (22-1기말 12번): `$$x^2+y^2+40y-1200=0,\qquad x^2+y^2+20x-800=0$$`
**정독 예시** (22-1기말 14번): `$$f(0)=0,\quad f\!\left(\tfrac12\right)=275,\quad f(1)=500$$`

**How to apply**:
- 두 값 병렬 시 `\qquad` · 세 값 병렬 시 `\quad`
- 우리 팀 정정 예: 확인 11번 자기역함수 3줄 `align*` → 인라인 `$x(y-2)=2y+1$에서 $y=\dfrac{2x+1}{x-2}$` 1줄
- 자동 검수: `align-usage-audit.py` · 슬롯당 `align*` 사용 대안 가능 여부 판정

## S3. 접속어 팔레트 표준화

**권장 접속어** (원자 연결):
- 조건 이월: **"~에서"** · **"~이므로"**
- 결론 이월: **`$\therefore$`** (짧게)
- 이유 부기: **`\quad(\because \cdots)`** (인라인 소괄호)
- 등호 조건: **`\quad(\text{등호는 } t=1)`** (인라인 소괄호)

**남용 금지 접속어** (문단당 1회 최대):
- "즉" · "이때" · "한편" · "따라서" · "그러므로"

**금지 문어체·서사체**:
- "이 됩니다" · "얻어진다" · "구해진다" · "정리해 보면" → 대신 "이다" · "이므로"

**How to apply**:
- 자동 검수: `connector-count-check.py` · 문단당 남용 접속어 2회 이상 → YELLOW

## S4. 인라인 등호 연쇄 자유

짧은 계산은 인라인 **`$A=B=C$`** 자유 사용. 3개 등호까지 인라인 OK.

**정독 예시** (22-1기말 6번): `$h=\dfrac{|2\times(-1)+3-9|}{\sqrt{2^2+1^2}}=\dfrac{8}{\sqrt5}$`
**정독 예시** (22-2기말 2번): `$3=\dfrac{2\times4+b}{4-1}=\dfrac{8+b}{3}\quad\therefore\ b=1$` (한 줄 결말)

**How to apply**:
- 등호 4개 이상 · 각 스텝에 텍스트 필요 시만 디스플레이 승격

## S5. 이유·조건 소괄호 부기

이유·조건을 **`\quad(\because \cdots)`** · **`\quad(\text{등호는 } t=1)`** 소괄호로 인라인 부기. 별도 문장·별도 `\solnote` 박스 감축.

**정독 예시** (22-1기말 8번): `$$\overline{\mathrm{AP}}^2+\overline{\mathrm{BP}}^2 = 2\,\overline{\mathrm{PM}}^2+4\quad(\because\ \overline{\mathrm{AM}}=\sqrt2)$$`
**정독 예시** (22-2기말 9번): `$$t+\dfrac1t\ge2\quad(\text{등호는 } t=1,\ \text{즉 } x=2)$$`

## S6. `\begin{align*}` 사용 기준 (엄격)

**허용 조건 (모두 만족)**:
1. 3항 이상 유도이고
2. 한 줄에 담기 어려운 물리적 너비 초과이고
3. 각 항이 `&=` 등호 정렬로 자연 정렬 가능

**정렬 기호**: `&` 는 **등호(`=`) 에만** 정렬. `\Rightarrow` · `\iff` · `\leq` 정렬 금지.

**정독 예시** (내신 서술형 15): 3-집합 포함배제 공식 (수식 자체가 너비 초과). 이런 경우만 `align*`.

**How to apply**:
- 자동 검수: `align-usage-audit.py` · 슬롯당 `align*` 개수 표시 · 좌우 병렬 대체 가능 후보 자동 감지

## S7. 그래프 3위치 규정

풀이 안 그래프는 **다음 3위치 중 하나**:
- (a) **조건 정리 직후** (문제 조건을 재구조화한 그림)
- (b) **케이스 분할 직전** (여러 경우 시각화)
- (c) **결론 직전** (최종 값 시각 확인)

다른 위치 (풀이 최상단·풀이 최말단·랜덤) → RED.

**정독 예시** (22-1기말 9번): 조건 서술 → 그래프 → 다음 스텝 진행 (위치 a)
**정독 예시** (22-2기말 16번): 조건 정리 → 그래프 → 케이스 (i)(ii) (위치 b)

**How to apply**:
- 자동 검수: `graph-position-audit.py` · tikzpicture 앞뒤 문맥 감지

## S8. 케이스 색상 병기

케이스 (i)/(ii) 를 시각적으로 그래프 안에서 구분:
- (i) `black` 또는 `dm-navy`
- (ii) `dm-accent` (딥 버밀리언)

**정독 예시** (22-2기말 16번): 두 케이스 곡선을 색상 다르게 병기.

**How to apply**:
- 두 케이스 이상 그래프 · 색상 단일 사용 시 → YELLOW

## S9. 재도해 도입

원본 그림이 있어도 **풀이용 재도해 자유** (원본과 다른 정보량: 격자·보조점선·라벨 추가).

**정독 예시** (22-2기말 14번): 문제부 그림 + 풀이부 재도해 (격자·보조점선 추가)

**How to apply**:
- 원본 그림 필사만 하는 관행 해제
- 풀이 서술이 특정 보조선·격자를 참조하면 재도해 강제

## S10. 문단 간격 절제

**논리 원자 사이** = 자연 문단 (빈 줄 1개). 특수 매크로 없음.
**허용 매크로**:
- `\medskip` — case (i)/(ii)/(iii) 사이만
- `\smallskip` — 부기·이유 후 결론 앞만

**남용 금지**:
- 원자 사이 `\medskip`·`\smallskip` 남발
- 답박스 앞뒤 특수 여백 (자연 문단으로 충분)
