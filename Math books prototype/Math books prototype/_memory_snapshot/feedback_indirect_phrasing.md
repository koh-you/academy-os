발문에서 *개념을 직접 명시*하는 표현 회피. *우회 표현*으로 학생의 *개념 환원* 사고를 자극.

**Why**: 마스터 명시 2026-06-25 (7회차 v3 검수 후). 발문이 "중근을 갖는다"라고 직접 명시하면 학생은 *기억 호출*만 한다. "서로 다른 실근의 개수가 2이다"·"두 개의 실근만 갖는다"라고 우회하면 *개념 환원*을 거쳐 사고가 자극된다. 시판 ★ 5 변별 문제는 거의 모두 우회 표현.

**How to apply**:
- `bank/유형카탈로그/우회표현사전.md`에 직접 ↔ 우회 매핑 단일 출처
- ★ 5 슬롯은 우회 표현 권장 (YELLOW 경고)
- ★ 4 슬롯도 다양화 권장
- 우회 시 *수학적 동치성* 명확 (오해 X)
- `scripts/master-feedback-check.mjs`에 YELLOW grep ("중근을 갖도록"·"허근을 갖는다" 등)

**우회 표현 예시**:
- "중근을 갖는다" → "서로 다른 실근의 개수가 2이다" / "두 개의 실근만 갖는다"
- "허근을 갖는다" → "실수가 아닌 근을 갖는다" / "x³=1의 허근 중 하나"
- "모든 근이 실수" → "허근을 갖지 않는다" / "실근만 갖는다"
- "교집합 정수 N개" → "공통으로 만족시키는 정수가 N개" / "두 부등식이 함께 성립하는 정수가 N개"
