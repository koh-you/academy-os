### 4. 2회 #14 문제 교체 (지적 1 대응)
- **폐기 원문**: $x^4 - 4x^3 + 6x^2 - 4x + k = 0$ 실근 없음 → $k > 1$
- **신규**: $x^4 - 6x^2 + k = 0$ 실근 없음. $t = x^2$ 치환 → $t^2 - 6t + k = 0$, 근의 합 = 6 > 0이므로 두 음근 불가, 실근 없음 ⟺ 판별식 < 0 → **$k > 9$**
- **답지 #14 소제목**: "완전제곱꼴로 사차식 정리하기" → "사차방정식을 이차방정식으로 치환하기"
- **답지 언어 정정 (지적 3)**: "원 방정식이 실근을 갖지 않는 조건은..." → "$x$에 대한 사차방정식이 실근을 갖지 않는 조건은... $f(t) = 0$이..." + 함수 이름 부여
