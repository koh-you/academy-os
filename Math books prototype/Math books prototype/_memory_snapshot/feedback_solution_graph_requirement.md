**Rule (강제)**: 답지 풀이에서 다음 5 유형 (모의고사 해설 표본 기반) 은 반드시 그래프 (TikZ figure) 를 포함한다.

## 5 유형 · 그래프 필수 카탈로그

### 유형 1 · 곡선-직선 교점 개수 조건 (Curve-Line Intersection Count)

**대표**: 2024.9 #30 · 2023.9 #30 · 무리함수 답지 L2-12 (y=√|x-1| + y=x+k 세 점 만남)

**구조**: 매개변수 (k 등) 를 갖는 직선과 곡선의 교점 개수가 특정 값이 되도록 하는 매개변수 범위 · 여러 케이스 (접함·시작점·꼭짓점 통과 등) 로 나눔

**그래프 왜 필요**: 매개변수 변화에 따른 직선의 이동을 시각화. 여러 임계 상태 (접함·통과·시작점) 를 한 그림에 담아 케이스 동시 검토.

**그래프 구성**: 곡선 + 임계 직선 2~3개 (기준 케이스별) + 교점 표시 + 시작점·특수점 강조

### 유형 2 · 함수 최댓값·최솟값 (Extremum via Graph)

**대표**: 2024.3 고2 #30 · 2023.9 #28 (사각형 넓이 최대화)

**구조**: 조각함수·유리함수·무리함수의 최댓값·최솟값. 특히 정의역 구간이 제한되거나 임계점이 여러 개

**그래프 왜 필요**: 각 구간·경계값에서 함숫값 시각 비교. 텍스트로만 서술 시 어느 지점이 최대·최소인지 놓치기 쉬움.

**그래프 구성**: 함수 개형 + 정의역 경계 표시 + 최대·최소 위치 강조

### 유형 3 · 조각함수 개형 (Piecewise Function Shape)

**대표**: 2024.9 #29 · #30 (조각함수 형태 판별)

**구조**: `f(x) = √(x+1)` (x≤0), `-(√(-x)-3)` (x>0) 같은 조각함수. 각 조각의 연속성·기울기·경계점 확인 필요

**그래프 왜 필요**: 조각들이 이어지는지·불연속인지 시각적으로 확인. 각 조각의 곡선성·방향 서술만으로는 불명확.

**그래프 구성**: 각 조각 별도 그리기 + 경계점 (연속·불연속 원 표시) + 각 조각 시작·끝 점

### 유형 4 · 절댓값·무리함수 대칭 (Absolute·Radical Symmetry)

**대표**: 2024.3 고2 #14 · 무리함수 답지 L2-12 (y=√|x-1|)

**구조**: `y = f(|x|)` 또는 `y = |f(x)|` 형태의 절댓값 함수. 대칭 축 (y축·특정 세로선) 을 기준으로 좌우 반사

**그래프 왜 필요**: 좌우 대칭 관계를 시각적으로 확인. "두 갈래로 이루어짐" 만 텍스트로 서술 시 위치·개형 놓치기 쉬움.

**그래프 구성**: 두 갈래 (좌·우) + 대칭 축 (점선) + 만나는 시작점 강조

### 유형 5 · 역함수·대칭 관계 (Inverse Function·Symmetry)

**대표**: 2023.9 #20 · 2023.9 #16 (원과 곡선 위치 관계)

**구조**: 함수와 그 역함수의 교점 (y=x 위) · 두 곡선·직선의 3중 위치 관계

**그래프 왜 필요**: y=x 대칭 관계를 시각화. 3중 위치 관계는 텍스트 서술이 매우 복잡.

**그래프 구성**: 원 함수 + 역함수 + y=x 직선 (점선) + 교점 표시

## 판정 기준 (그래프 필요 vs 불필요)

### 그래프 필수 (RED)
- 문제 서술에 "그래프" · "교점 개수" · "만나지 않을" · "접할" · "세 점에서" · "위치 관계" 등장
- 곡선-직선·곡선-곡선 만남 조건
- 매개변수에 따른 교점 개수 변화
- 절댓값 함수·조각함수·역함수 등 특이 개형
- 최댓값·최솟값 (구간 제한 · 다중 임계)
- 원·타원 등 2차 곡선 위치 관계

### 그래프 불필요 (GREEN)
- 단순 방정식 풀이 (근·판별식·근과 계수)
- 대수 조작 (인수분해·전개·통분)
- 순열·조합 계산
- 나머지정리·부등식 단순 계산
- 집합 연산·명제 진리값
- 도형 정리 (예: 삼각형 조건 → 대수 조건만으로 결론)

## 그래프가 있으면 서술 압축 가능

**Before (그래프 없이 verbose)** — 무리함수 답지 L2-12 :
```
$y=\sqrt{|x-1|}$의 그래프는 $y=\sqrt{x-1}$ ($x \ge 1$)과 $y=\sqrt{-x+1}$ ($x<1$)의
두 갈래로 이루어지며 $(1,\, 0)$에서 만난다. 두 갈래는 $x=1$에 대하여 좌우 대칭이다.

직선 $y=x+k$와 세 점에서 만나려면 두 갈래 중 하나에 접하고 다른 갈래에서
두 점에서 만나거나, 두 갈래에서 각각 한 점씩 만나면서 세 번째 만남이 시작점에서
일어나야 한다.

오른쪽 갈래 $y=\sqrt{x-1}$과 직선의 접함 조건: ...
시작점 $(1,\, 0)$을 직선이 지날 때: ...
두 경계 사이의 범위에서 직선은 왼쪽 갈래 위에서 시작점을 지나고 오른쪽 갈래에서
두 점 만남을 만들어 총 세 점에서 만난다.
```

**After (그래프 + 압축 서술)**:
```
[그래프: y=√|x-1| 두 갈래 + 직선 y=x+k 임계 2개 (k=-3/4 오른쪽 접함, k=-1 시작점)]

두 경계값을 구한다.
- 오른쪽 갈래 접함: 판별식 = 0 에서 k = -3/4
- 시작점 (1, 0) 통과: 0 = 1 + k 에서 k = -1

그래프에서 두 경계값 사이의 범위 $-1<k<-\dfrac{3}{4}$ 에서 세 점 만남.
```
