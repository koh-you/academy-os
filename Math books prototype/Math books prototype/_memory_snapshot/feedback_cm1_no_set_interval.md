공통수학1 본문·풀이·해설에서 **집합 기호와 미적분 용어를 모두 사용 금지**.

## 금지 용어·기호

**집합·명제 용어**:
- $\cup$, $\cap$ (합집합·교집합 기호) — 공통수학2 "집합과 명제" 단원에서 처음 학습
- $[a, b]$, $(a, b)$, $[a, b)$, $(a, b]$ (구간 표기) — 미적분 용어
- "집합", "원소", "부분집합", "여집합" 등
- **"필요조건", "충분조건", "필요충분조건"** — 명제 단원 용어
- "명제", "가정", "결론", "진리집합", "역", "이", "대우"
- $\Leftrightarrow$ (동치 기호)

**공수2 도형의 방정식 용어**:
- "평행이동", "대칭이동" — 함수 그래프 이동 일반 용어로도 위반. 대신 "$y$축 방향으로 $k$만큼 옮긴"·"$x$축 위쪽으로 이동한" 등 자연어
- "내분점", "외분점"

**학교 수학 미사용 일반 용어**:
- **"분기"**, **"분기 함수"**, **"케이스"**, **"케이스 분류"** — 컴퓨터과학·논리학 용어. 학교 수학에서는 "경우", "경우 나누기"로 표현
- 대체: "분기 함수" → "범위 나눠 만남 분석" / "조건별 함수" / 풀이 본문에서는 그냥 "각 경우에"
- **"매개수"**, **"매개변수"** — 미적분(매개변수 표시)·확률(매개변수 추정) 등 이후 단원 용어. 공통수학에서 미사용
- 대체: "매개수 $k$" → "상수 $k$" / "주어진 실수 $k$" / 문맥상 그냥 "$k$"
- **"상한"**, **"하한"**, **"한계값"**, **"상계"**, **"하계"** — 해석학·미적분 supremum/infimum 용어. 학교 수학에서는 미사용
- 대체:
  - "상한" → "최댓값" / "오른쪽 값" / 또는 그 값을 직접 명시 (예: $a^2-8a$)
  - "하한" → "최솟값" / "왼쪽 값" / 또는 직접 명시 (예: $-16$)
  - "한계값" → "값" / 그냥 빼기
- **"한 값으로 고정"**, **"값을 정하지 않고"** — 변수를 특정 값에 묶거나 매개수의 자유도를 언급하는 추상적 표현. 학교 수학에서 어색
- 대체: 문장을 다시 구성해 ``$k$를 직접 구하는 대신 그러한 $k$가 존재할 $a$의 범위를 구한다''처럼 풀이의 목적 자체로 풀어쓰기

**집합론적 부정 표현** (학교 수학에서 어색):
- **"범위가 비어 있다 / 비어 있지 않다"**, **"비어 버린다"**, **"공집합"**, **"집합이 비어 있다"** — 집합론 용어. 학교 수학에서는 자연어로 풀어쓰기
- 대체:
  - "$k$의 범위가 비어 있지 않을 조건" → "조건을 만족하는 $k$가 적어도 하나 있을 조건"
  - "범위가 비어 버린다" → "조건을 만족하는 (값/근)이 하나도 없다"
  - "해집합이 비어 있다" → "조건을 만족하는 해가 없다"

**미적분 용어**:
- "구간" — 미적분에서 처음 등장 (공통수학에서는 미사용)
- "단조증가", "단조감소" — 미적분 함수의 증감 용어
- "연속", "불연속", "극한", "미분", "적분"

**기타 학년 외 용어**:
- 벡터, 행렬, 역함수, 합성함수, 명제 (공통수학2 또는 그 이후)

## 권장 대체 표현

| 금지 | 대체 |
|---|---|
| 닫힌구간 $[-1, 3]$ | $-1 \le x \le 3$ (부등식으로 풀어쓰기) |
| "구간 안" | "$-1$과 $3$ 사이" |
| "구간 왼쪽" | "$-1$보다 작을 때" |
| "구간 오른쪽" | "$3$보다 클 때" |
| $A \cup B$ | "두 조건을 모두 합치면" |
| $A \cap B$ | "두 조건을 모두 만족하려면" |
| "단조증가" | "$x$가 커질수록 $f$의 값도 커진다" |
| "단조감소" | "$x$가 커질수록 $f$의 값은 작아진다" |

## Why

학습 순서: **공통수학1 → 공통수학2 → 미적분 / 확률과 통계 / 기하**.
- 공통수학1 시점에서는 집합·명제 단원을 아직 학습 안 함
- 미적분 용어("구간", "단조증가")는 미적분에서 정의됨
- 풀이에 학습 전 개념·기호가 등장하면 학생이 이해 불가

## How to apply

- CM1 단원(PL/EQ/CB/MX)에서 출제·풀이·해설 작성 시 이 메모리 우선 적용
- 검수 에이전트(`problem-review`)도 본 규칙을 점검 항목으로 사용
- CM2 이상 단원에서는 단원별 학습 순서를 다시 확인 (RF의 경우 ST·FN 후속이므로 함수·역함수 가능)
- 관련 메모리: [[feedback-curriculum-terms]] (2022 개정 표준 용어 일반 규칙)
