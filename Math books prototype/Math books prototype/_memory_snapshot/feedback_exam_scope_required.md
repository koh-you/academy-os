**규칙**: 학교 시험 대비 시험지(예: 동화고 N회차) 출제 시 authoring 에이전트에게 **시험범위를 소단원 수준까지 정확히 명시**해야 한다.

단원 약자(PL·EQ·CB·MX)만으로는:
- EQ = "방정식과 부등식" 전체 (복소수와 이차방정식·이차함수와 이차방정식·여러 가지 방정식·여러 가지 부등식 모두 포함)
- PL = "다항식" 전체

같은 큰 단원 안에서 소단원별로 범위 안/밖이 갈리는 경우가 흔하므로 단원 약자만 주면 범위 외 출제 발생.

**Why** (2026-06-20 발견):

동화고 4회차 첫 출제 시 슬롯 표에 "PL", "EQ" 같은 단원 약자만 명시 → authoring 에이전트가 PL 7문(인수정리·나머지정리) + EQ 일부(복소근·사차치환 본질 이차) 출제 → 마스터 검토에서 시험범위 "여러 가지 방정식과 부등식부터 행렬" 밖 6문 + 너무 쉬운 1문 발견 → 7문 전면 재출제. 1.5시간 추가 작업 + 토큰 비용.

원인: 슬롯 표가 단원 약자 수준이라 authoring 에이전트가 PL 인수정리 = "다항식 단원의 정상 슬롯"으로 해석. 시험범위가 "다항식의 연산"을 제외한다는 정보 부재.

**How to apply** (시험지 출제 가이드 표준 양식):

1. **시험범위 섹션 (필수)**: authoring 프롬프트에 다음 형식으로 명시
```
## 시험범위 (필수 숙지)

**범위 안**:
- 단원·소단원 명시 (예: "여러 가지 방정식 — 삼차·사차방정식, 연립방정식")
- 단원·소단원 명시 (예: "여러 가지 부등식 — 이차·삼차·사차·연립·절댓값 부등식")
- ...

**범위 밖** (출제 시 반드시 회피):
- 단원·소단원 명시 (예: "다항식의 연산 — 인수정리·나머지정리 단독")
- 단원·소단원 명시 (예: "복소수와 이차방정식 — 복소수 자체·판별식·근과 계수의 관계")
- 단원·소단원 명시 (예: "이차함수와 이차방정식")
- ...
```

2. **슬롯 표 단원 코드 세분화**: 단순 "EQ"가 아닌 "EQ-MV" (여러 가지 방정식), "INEQ" (여러 가지 부등식) 등으로 표기

3. **본질 판정 가이드**: "사차방정식 치환 → 본질 이차방정식이면 시험범위 밖" 같은 본질 판정 명시. authoring 에이전트가 형식이 아닌 풀이 본질로 단원 판정하도록.

4. **사후 검수에 시험범위 자동 점검 추가**: problem-review 에이전트 프롬프트에 시험범위를 별도 항목으로 명시하고 각 문항이 범위 안/밖인지 표로 보고 의무.

**범위 모호 케이스**:
- 사차방정식 치환 (예: $(x^2+2x)^2 - 2(x^2+2x) - 24 = 0$) — 본질 이차방정식. 시험범위 "여러 가지 방정식 — 사차방정식"으로 보일 수 있으나 풀이가 이차방정식 한 번이면 범위 밖.
- 다항식 곱 전개 (예: $(1+2x)^2(1+x^2)^n$) — 본질 다항식 전개. CB(이항정리) 슬롯이라도 학생이 다항식 곱셈을 해야 한다면 PL 영향.
- 복소근 켤레 (예: $x = 2-i$ 두 근 + 켤레근 정리) — "여러 가지 방정식 (삼차)" 범위 안일 수 있으나 켤레근 정리는 "복소수와 이차방정식" 단원 → 마스터 확인 필요.
