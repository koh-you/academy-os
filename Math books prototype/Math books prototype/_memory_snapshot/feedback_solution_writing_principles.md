# 풀이 서술 5원칙 — 학생 자료 표준 (2026-07-11 확립)

## 배경

와부고 기출 분석 프로젝트 (참고자료/학교기출/고1/와부고/와부고 기출 분석/references/집필-기준.md)의 서술 원칙과 실제 풀이 표본을 분석하여 우리 답지·유형편 풀이 시스템에 편입. solution-author 에이전트 프롬프트 v1.5에 통합.

## 5대 원칙

### 원칙 1 — 미지수 선언 (풀이 첫 줄)
- 풀이 첫 문장은 미지수·기호를 즉시 설정 ("~을 구한다" 같은 서두 금지)
- 예: "$k$의 값을 구하기 위해" ✗ → "$k$의 값을 $k=a+b$로 두면" ✓
- 이유: 논리 흐름 시작점 명확화, 서두 군더더기 제거

### 원칙 2 — 접속어 논리 결합
- 각 문장은 "이므로 · 따라서 · 즉 · 그러므로" 등 접속어로 이전 문장과 결합
- **비약 금지**: 결과만 나열하지 않고 근거→결론 흐름 유지
- 예: "$k=3$이므로 $f(3)=0$이다. 따라서 $x-3$은 인수이다."

### 원칙 3 — 정의 전개 (공식 암기 지양)
- 정리·공식 명시: "점과 직선 사이의 거리 공식에 의하여"·"근과 계수의 관계에 의하여"
- **대칭이동은 공식 암기 X · 정의 전개 O**: "수직 이등분 = 수직 + 중점이 직선 위" 두 조건 유도
- **원의 방정식 = 중심과의 거리 = 반지름**: 정의로부터 유도

### 원칙 4 — 검산·최종답 형식
- 서술형은 풀이를 검산한 뒤 제시
- 마지막 답: `∴ $\text{답: } ___$` 형식 or `\answerbox{정답: ...}` 매크로
- 검증 문장 예: "따라서 $x=3$은 원 방정식을 만족시킨다."

### 원칙 5 — Critical Point 3함정 (★ 4·5 문항 의무)
- 난이도 ★ 4 이상 답지는 함정 3선 명시:
  - **① 실수 케이스 놓침** (음수·경계값 등)
  - **② 조건 누락** (`\begin{conditions}` 안의 (가)·(나)·(다) 중 일부 미적용)
  - **③ 계산·부등호 방향 오류**
- 매크로: `\criticalpoint{① ... ② ... ③ ...}` (style.sty · 오렌지 좌측 강조 바 + 옅은 회색 배경, v3.7.4 대비 개선)
- 항목 구분: `\quad` 금지 · **`\\` 사용** (각 함정 별도 줄, v3.7.4 가독성 개선)

### 원칙 5.1 — `\cplabel{...}` 언어 스타일 (v1.7, 2026-07-13 세션 35 마스터 지시)

라벨은 **자연 국어 서술** (동사·형용사·서술 어미 포함). 압축 명사구·프로그래밍 은어·수식-라벨 혼용 금지. 상세: [[bank/비표준-어구-사전.md]] §1.4f.

**핵심 대조**:
| ❌ 압축 신조어 (어떤 교재에도 없음) | ✅ 자연 국어 서술 |
|---|---|
| "외부 조건 부등호" | "등호는 원 위(접점)" |
| "$a=0$ 예외 처리" | "$a=0$인 경우 따로" |
| "경계 배제 조건" | "경계는 포함하지 않음" |
| "교점 좌표 유도 = 두 원 뺄셈" | "두 원의 방정식을 빼서 좌표 구하기" |
| "대우 = 원명제 진리값" | "원명제와 대우의 진리값은 같다" |
| "반례의 전제조건 검증" | "반례가 전제를 만족하는지 확인" |

**금지 패턴**:
- 압축 어미: "XX 처리·검증·필수·동시·재확인·도출"

## 부속 원칙 (표기·어투)

### 표기
- **수식-조사 붙임**: `$x$에` ✓ (공백 없음) / `$x$ 에` ✗
- **집합**: "집합 크기" ✗ → "집합의 원소의 개수" ✓
- **점·선분**: "점 $\mathrm{A}$"·"선분 $\overline{\mathrm{AB}}$" 명시
- **로마체**: 좌표점 이름은 `\mathrm{}` (예: $\mathrm{A}(2,3)$)

### 어투
- **평서형 종결**: "~이다·~한다·~된다" (경어 금지)
- **문장 길이**: 40자 이내 (짧게 · 명료하게)
- **능동형 우선**: "함수 $f$의" ✗ → "함수 $f$를 이용한" ✓

### 볼드 사용
- 발문·조건·보기·선택지에는 볼드 절대 금지
- 문항 번호·소문항 번호의 구조적 볼드만 허용 ([[feedback_no_textbf_in_solutions]] 정합)
