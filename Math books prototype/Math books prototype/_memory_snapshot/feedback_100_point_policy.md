시험지(testpaper) 점수 조정 시 **총점 100점 만점을 정확히 유지**한다. 라벨 드리프트(★ 재산정 vs 표시 배점 불일치)로 상향·하향이 발생할 때 다른 슬롯 점수 조정으로 합산을 유지.

**Why:** 마스터가 동화고 2회차 보강 작업 중 명시적으로 지적 (2026-06-21). 시험지 정체성은 "100점 만점"이며, 점수 분배가 바뀌어도 만점값은 신성. ★ 5 슬롯이 격상되어 점수도 격상되면 다른 곳에서 강등이 필수. 시험 채점 표준화·정합성·시험지 신뢰성 확보.

**예외:** 마스터가 명시적으로 "총점 105점·110점 OK"라고 지시한 경우만 100 외 만점 허용.

## How to apply

1. **점수 변경 발생 시점 점검**: 라벨 드리프트(★ 재산정 vs 배점 불일치)·세련도 미달·보강 안 적용 시 점수 변동 발생
2. **변동 합산 = 0 정확 유지**: 상향 +N점 = 하향 -N점
3. **변동 분배 우선순위**:
   - 상향 후보: 재산정 ★ > 배점인 슬롯 (★ 5인데 4.5점 등)
   - 하향 후보: 재산정 ★ < 배점인 슬롯 (★ 3인데 4점 등) · refinement_score 1 미달 슬롯
   - 둘 다 마무리 안 될 때 ★ 변별 슬롯(#20·#22·#23·#25 같은)에서 0.5점 조정
4. **0.5점 단위 미세 조정**: 시험지 배점은 0.5점 단위가 표준 (3·3.5·4·4.5·5·5.5점)
5. **헤더 점수 표시 갱신 (v0.2, 11회차부터)**: `\examsection{객관식 (...총 60.5점)}`만 실제 객관식 합과 일치. 통합 서답 구간은 헤더 없으므로 점수 합 표시 불요 (시험지 examheader의 "100점" 표기만 유지)
   - **옛 정책 (~10회차)**: \examsection 3개 (객관·단답·논술) 각 점수 합 표기 일치 의무

## 예시 (동화고 2회차, 2026-06-21)

상향 4건 + 하향 5건으로 100점 유지:
- 상향: #11(3.5→4.5, +1), #14(4.5→5, +0.5), #16(4→4.5, +0.5), #24(4.5→5, +0.5) = **+2.5점**
- 하향: #3(3.5→3, -0.5), #6(4→3.5, -0.5), #10(4→3.5, -0.5), #19(4→3.5, -0.5), #21(4→3.5, -0.5) = **-2.5점**
- 합: 0, 총점 100점 유지 ✓
- 헤더: 객관식 60.5 + 단답형 20 + 논술형 19.5 = 100점

## 점검 의무 (problem-review v3.1, **시험지 검수 시 한정**)

- `\examsection` 헤더 점수와 실제 \pointbadge 합 정확 일치
- 총합 100점 (마스터 지정 만점값)
- 라벨 드리프트 발견 시 보고서에 상향·하향 페어링 제안

유형교재 검수 시는 본 점검 항목 자동 스킵 — 그 대신 도트(\dota·\dotb·\dotc) 라벨이 ★ 재산정과 정합 의무.
