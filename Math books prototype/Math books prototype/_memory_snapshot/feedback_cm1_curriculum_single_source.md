**🔴 즉시 거부**:
- 역행렬 $A^{-1}$ — CM1 행렬 단원 범위 외
- 트레이스 $\text{tr}\,A$ — 풀어쓰기 "두 대각 성분의 합"
- 행렬식 $\det A$ — 풀어쓰기 "두 대각곱의 차"
- 두 종류 무리수 켤레 $\sqrt 2 + \sqrt 5$ — CM2 무리식 단원으로 미룸
- 집합 기호 $\cup, \cap, \setminus, \subseteq, \emptyset$ — CM2-ST 이후만
- 집합 카드 $\lvert X \rvert$ — "원소의 개수"
- 사건 집합 표기 $n(A_i \cap A_j)$ — "둘 다 일어나는 경우의 수"
- $\sum, \prod, \int, \lim$ + 벡터

**✅ 허용 (2026-06-24 마스터 추가 확립)**:
- **케일리해밀턴 정리 직접 인용** — 시중 교재 옵션 수준 도구로 답지·풀이 직접 인용 가능. 단 발문에 *유도 강요*는 신중.
