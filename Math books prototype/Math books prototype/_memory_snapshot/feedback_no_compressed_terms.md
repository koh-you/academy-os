답지·문제 본문에서 **압축 신조어·비표준 학습 용어**를 사용하지 않고 자연어로 풀어 쓴다.

## 1. 한자어 prefix 압축 신조어 (마스터 지적 2026-06-19)

"비~", "반~" 등으로 만든 비표준 명사:
- "비이웃" → "이웃하지 않는 / 서로 이웃하지 않게 / 서로 떨어져 있는"
- "비이웃 조합" → "어떤 두 명도 서로 이웃하지 않게 뽑는 경우"
- "비이웃 자리쌍" → "서로 이웃하지 않은 자리쌍"
- "비이웃 = 24 × 60" 같은 도입어 없는 명사형 결론 → "서로 이웃하지 않게 배열한 경우의 수 $= 24 \times 60$"

## 2. "분기" 류 비표준 학습 용어 (마스터 지적 2026-06-21)

답지 풀이·\soltitle 제목에서 "분기"라는 표현 금지:
- "두 케이스 분기" → "두 경우 나누기 / 두 경우로 나누어 푼다"
- "부호 분기" → "부호에 따라 경우를 나누어"
- "케이스 분기" → "경우 나누기 / 경우 분류"
- "x²=4 두 케이스 분기" (\soltitle 예시) → "x²=4 두 경우 나누기"

"분기"는 코딩·시스템 용어 결이며 동화고 1학년 학생이 이해하기에 비자연. 표준 표현 "경우 나누기"·"경우 분류"·"나누어 푼다"로.

## Why
마스터가 "비이웃이라는 말은 쓰지 않음"이라고 명시 (2026-06-19, 동화고 1회차 작업 중 지적), "분기라는 표현이 있어"라고 추가 지적 (2026-06-21, 동화고 2회차 검수 후). 학생 친화 답지는 자연스러운 한국어로 풀어 써야 가독성이 좋고 책 말투 정체성이 유지된다.

**Why:** 마스터가 "비이웃이라는 말은 쓰지 않음"이라고 명시 (2026-06-19, 동화고 1회차 작업 중 지적). 학생 친화 답지는 자연스러운 한국어로 풀어 써야 가독성이 좋고 책 말투 정체성이 유지된다. 학원/문제집 일부에서 "비이웃"을 약식 명사로 쓰지만, 본 프로젝트의 답지는 자연어 풀어쓰기 정체성을 따른다.

**How to apply:**
- 답지 작성·검수 시 `\soltitle` 제목, `\step` 본문, 결론 문장 어디에서도 "비이웃"·"분기" 등 grep으로 0건 확인
- solution-author 에이전트도 자연어 풀어쓰기로 작성·점검
- 자동 검수 절차 단계 2 디자인 가이드 항목에 추가 (CM1 범위 외 용어와 같은 위계로)
- problem-review의 "교과과정 내 용어 사용 검수" 축에 포함
