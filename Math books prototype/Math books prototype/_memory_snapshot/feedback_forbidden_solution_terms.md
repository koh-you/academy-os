# 답지·해설지 절대 금지 표현 (영구 정책)

마스터 명시 (2026-06-28, 7회차 답지 작업 중 두 차례 지적):

## 🔴 즉시 거부 표현 (본문·풀이·통찰 박스 모두)

### 1. 비교과 압축 신조어
- **"정수쌍"** → "두 정수의 순서쌍" / "두 정수해" / "두 정수해의 순서쌍"
- "실수쌍" / "자연수쌍" / "유리수쌍" 같은 동류 표현도 금지
- **Why**: 교과서·정규 교육과정에 없는 한자어식 압축 명사. 자연어 "두 ___의 순서쌍"으로 풀어쓰는 것이 표준.

### 2. 본 시스템 신조어 (살아남기·생존 메타포)
- **"살아남은"** / "살아남는" → "조건을 만족시키는" / "조건 (다)를 만족시키는"
- "살아남은 케이스" → "조건을 만족시키는 경우"
- "걸러진" / "제거된" 같은 메타포도 자제
- **Why**: 수학 풀이에 생물학적 메타포 부적절. 마스터 표현으로 "말도 안 되는 표현"이라 지적됨.

## 적용 범위
- `*-답지.tex` / `*-solution.tex` / `output/**/풀이*` / `solnote{...}` 박스
- 본문(`*-문제.tex`)에도 동일 적용
- 풀이 본문·통찰 박스·단계 마커 옆 본문 모두

## How to apply
- 풀이 작성·확장·검수 시 위 표현 발견 즉시 정정
- "정수쌍" → "두 정수해의 순서쌍" (자연어 펼쳐쓰기)
- "살아남은 ___" → "조건을 만족시키는 ___" 또는 "조건 (다)에 부합하는 ___"
- 새 표현이 의심되면 교과서·평가원 공개기출 표현을 우선 차용
- 검수 grep 키워드: `정수쌍`, `실수쌍`, `자연수쌍`, `살아남`, `생존`
