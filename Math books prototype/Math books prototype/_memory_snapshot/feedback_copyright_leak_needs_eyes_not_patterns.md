# 저작권 누출은 이름 규칙으로 못 막는다 — 눈으로 연다

2026-08-06 세션 116 에 **시판 교재 스캔 65개가 GitHub 에 올라가 있는 것**을 찾았다.

- `data/rpm_cm2/` 59장 — RPM 공통수학2 지면 (워터마크까지 찍혀 있었다)
- `data/rpm_toc_002·003.png` 2장 — 같은 책 안내 지면
- `mid-03~06.png` 4장 — 내신파이널 공통수학2 · **최상위에 굴러다녔다**

전부 세션 113 의 커밋 `ba790f4` 로 들어갔다. 그 커밋 이름이 **「파생물·캐시는 제외」**다.

## 왜 막지 못했나

세션 113 에 `참고자료/`·`data/pdf-pages-cache/`·`data/**/추출/` 같은 **갈래를 이름으로** 막고,
「새 파생물 폴더를 만들면 `.gitignore` 도 같이 본다」고 등재했다 ([[feedback_book_corpus_policy]]).
그런데 또 샜다. 샌 것이 **그 규칙이 보는 모양이 아니었기 때문**이다.

| 샌 것 | 왜 그물을 빠져나갔나 |
|---|---|
| `mid-03~06.png` | **폴더가 아니었다.** 최상위에 낱개로 놓인 파일이라 「새 폴더를 만들면」에 안 걸린다 |
| `data/rpm_cm2/` | 폴더이긴 한데 이름에 `추출`·`cache`·`scan` 이 없다. **막아 둔 이름과 안 닮았다** |

🔴 **이름으로 막는 규칙은 「내가 미리 떠올린 모양」만 막는다.** 안 떠올린 모양은 그냥 지나간다.
같은 병이 두 번 났다는 것은 규칙을 더 촘촘히 쓰는 것으로는 안 낫는다는 뜻이다.

## 어떻게 한다

**밖으로 내보내기 전에 — GitHub 에 밀 때 · 공유 폴더를 뜰 때 — 추적 중인 그림을 눈으로 연다.**

```bash
git ls-files | grep -E '\.(png|jpe?g|gif)$'
```

낯선 이름이 하나라도 있으면 **연다.** 시판 교재 지면은 한눈에 안다 —
머리글에 판형 이름이 찍혀 있고(`#내파공수2-중간고사`), 워터마크가 있고, 지면 전체가 통째로 들어 있다.

우리 것과 구별되는 표시:
- 우리 것 → `_prev-`·`_preview-`·`measure-`·`thick-`·`verify-` 처럼 **무엇을 하려고 뜬 것인지가 이름에 있다**
- 시판 것 → 쪽 번호만 있거나(`p-021.png`·`toc-002.png`) 책 약칭이 붙는다(`rpm_`·`mid-`)

## 함께 건 그물 (2026-08-06)

`.gitignore` 에 **최상위 그림을 통째로** 막았다. 우리 그림은 `figures/` 와 `output/` 안에만 산다.

```
data/rpm_*
/*.png
/*.jpg
/*.jpeg
/*.gif
```

이것은 보조다. **정본은 위의 눈으로 여는 절차다.**

## 치운 방법 (다시 필요할 때)

`git filter-repo --force --invert-paths --path <경로> …` 로 전 이력에서 지우고 강제로 밀었다.
커밋 아홉은 그대로 남았고 파일만 7,423 → 7,358 로 줄었다.
🔴 **밀기 전에 `git bundle create <파일> --all` 로 되돌릴 자리를 먼저 만든다.**
`git filter-repo` 는 끝나면 `origin` 을 지우므로 **다시 붙여야 한다.**
