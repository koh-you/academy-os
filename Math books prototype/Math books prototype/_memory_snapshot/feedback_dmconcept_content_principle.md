## 원칙 요약 (세션 81·85·86·88 통합)

1. **핵심 개념만 실을 것** — 시중 공통 기재 항목만
2. **핵심 개념이 넘칠 때만 페이지 추가** (`dmconceptcont`) — 콘텐츠 부족은 loose 유지
3. **외분** (평면좌표) 은 예외 — 교과과정 외 특강 유지 (세션 77 마스터)
4. **복원 아닌 상세한 기술** — 축약 콘텐츠 재편 시 원본 복사 금지 · 새롭게 상세 유도·직관·특수 케이스로 채움
5. **마스터 시각 확인 필수** — auto-tune 판정만 신뢰 금지 · 실 렌더 시각 확인
6. **간격 아닌 실 콘텐츠로 채움** (세션 88 신설) — vspace 30mm+ 잔존 = 재기술 대상. 실 콘텐츠(dmsub·dmexample·dmnote·dmexplain) 추가로 여백 해소

# 개념박스 (dmconcept) 콘텐츠 원칙

정리편 본편 dmconcept 안에는 **시중 교재 공통 기재 핵심 기본 개념**만 포함. 활용 개념·심화 내용은 대표예제·확인·Level에서 다룸.

## 원칙

**포함**:
- 정의 (개념 자체)
- 기본 성질 (직접 유도)
- 표준 공식 (교과서 필수)
- 시중 교재 (개념원리·RPM·고쟁이 STEP1) 개념 설명 페이지 공통 기재 사항

**제외**:
- 활용 개념 (예: "중점의 활용과 평행사변형")
- 심화 유형 (예: "무게중심의 최솟값")
- 조합 문제 풀이 팁 (dmnote·dmexplain으로도 안 됨)
- 특정 문제 해결 도구 (Level 1~3에서 다룸)

## 판정 기준 (시중 교재 교차 비교)

**최소 3권 시중 교재** 개념 설명 페이지 교차 비교:
- 개념원리
- RPM
- 고쟁이 STEP 1

**3권 공통 기재** = 포함 · **1~2권만 기재** = 제외 검토

## Why

**세션 81 마스터 지적** (2026-07-24):
> "c2 를 봐도 중점의 활용과 평행사변형은 기본 개념이 아니야. 박스를 채우기 위해서 필요에 의해서 넣으면 몰라도 지금 이미 세팅이 되어있는데 쓸데없는 내용을 넣으려고 작업을 하고있는거야. 핵심 기본 개념이란 시중교재 개념 설명페이지를 교차 비교했을때 공통기재 사항들이라고 판단하면되. 그거 외에는 없어도 상관없는거야."

**배경**:
- 세션 80~81에서 자동 튜닝 스크립트로 loose 박스 (여백 큰 박스) 자동 해소 시도
- 스크립트 상한 (parskip 2.0 · linespread 1.30) 도달 시 콘텐츠 확장 안내
- concept-author agent가 dmsub 신설 → 활용 개념 (평행사변형 대각선 성질) 추가
- 마스터가 활용 개념 삽입 부적절 지적

**결론**:
- **박스 안 채우기 위해 활용 개념 삽입 금지**
- 여백 남으면 남는 대로 · 콘텐츠 밀도가 자연스러운 게 우선
- 강제 확장 (dmsub 신설) 대신 여백 정합 유지

## How to apply

1. **신규 저술 시**:
   - 청사진 dmconcept 슬롯 정의부터 핵심 기본만 명시
   - dmsub 개수 = 시중 교재 공통 sub-section 개수
   - dmexample = 표준 계산 예시만 (특수 유형 X)
   - dmnote·dmexplain = 개념 확인용 팁만

2. **기존 파일 재검토** (세션 81+):
   - 8권 24 dmconcept 활용 개념 침투 감사
   - 활용 개념 감지 시 삭제 · Level 이동 or 폐기
   - 삭제 후 loose 상태 되어도 유지 (원칙 우선)

3. **자동 튜닝 스크립트** (`dmconcept-auto-tune.py`):
   - loose·very_loose 상태여도 콘텐츠 확장 제안 금지
   - vspace 자동 삽입만 유지 (콘텐츠 불변)

## 자동 검증 방향 (미래)

- `scripts/dmconcept-content-audit.py` (미래 개발):
  - 각 dmsub의 sub-section 제목을 시중 교재 개념 페이지 인덱스와 대조
  - "활용"·"응용"·"심화"·"특수" 키워드 감지 → RED
  - 마스터가 dmsub 제목만 봐도 판정 가능

## 세션 85·86 추가 정책

### 원칙 2 · 핵심 개념이 넘칠 때만 페이지 추가 (`dmconceptcont`)

**세션 85 마스터 확립**: 콘텐츠 부족으로 loose 상태여도 응용 개념 삽입 금지. 235mm 박스가 채워지지 않으면 그대로 유지. 반대로 핵심 개념이 정말 235mm를 초과할 때만 `dmconceptcont` 로 2페이지 분할.

**사례**:
- 02 직선 §점직선거리 c3 : dmconceptcont 8p 폐기 (핵심만으로 235mm 미만) → 1p 통합
- 02 직선 §직선의 방정식 c1 : `dmconceptcont` 사용 안 함 (핵심 dmsub 3개로 정합)

### 원칙 3 · 외분 (평면좌표) 예외

**세션 77 마스터 유지**: 평면좌표 §외분점 특강은 2022 개정 교과 밖이지만 `dmconceptcont` 로 유지. 학생에게 내분점 대응 관점 확장 목적. 다른 파일에는 응용 삽입 금지 원칙 그대로 적용.

### 원칙 4 · 복원 아닌 상세한 기술 (세션 86)

**세션 86 마스터 지시**: 축약 콘텐츠 재편 시 이전 dmexplain·dmnote를 그대로 복원하지 말고 **새롭게 상세한 유도·직관·특수 케이스로 작성**. 콘텐츠 확장 방향은:
- 개념 유도 상세 (예: 수직 조건 유도 · 피타고라스 정리)
- 기하 직관 (예: 점근선의 의미 · 기울기 tan θ)
- 특수 케이스 (예: 좌표축 평행 직선 · 원점 대칭)
- dmexample 구체 예 확대 (수치 대입 결과)

**사례** (세션 86):
- 02 c2 dmexplain 신설 : 수직 조건 `mm' = -1` 피타고라스 유도
- 03 c2 dmexplain 신설 : 판별식 이용 판정 · 실근 개수와 교점 대응
- 07 c2 dmexplain 신설 : 점근선의 직관적 의미

### 원칙 6 · 간격 아닌 실 콘텐츠로 채움 (세션 88 신설)

**세션 88 마스터 지적** (2026-07-26):
> "지금 루즈한 개념박스를 재기술로 채웠어. 어떤 경우에 재기술을 해야하는지 기준을 잡고 시스템에 적용시켜. 간격만으로 채울수 있는 여백이 아님."

**배경**: 세션 88 05 확장 시 concept-author agent가 c3·c4에 `\vspace{60.0mm}` 자동 삽입 → auto-tune "very_loose" 판정. 마스터가 "vspace로 여백 채우는 것은 잘못" 지적 → 실 콘텐츠 (dmsub·dmexample·dmnote) 추가로 정정.

**결과**: c3 dmsub 3→4 (조건 연산 진리집합 신설) · c4 dmsub 3→4 + dmexample (대우 원리·역/이 대우 관계·판정 예시 신설) · vspace 삭제 · GREEN 회복 (c3 +9.1mm · c4 +5.8mm).

## 재기술 (Rewrite) 트리거 기준 (세션 88 확립)

auto-tune 결과에 따른 조치 판단표:

| 여백 (mm) | vspace 삽입 | 판정 | 조치 |
|---|---|---|---|
| 5~15 | 없음 | **GREEN** | 없음 (표준 완료) |
| 15~25 | 없음 | LOOSE | parskip/linespread auto-tune (스크립트) |
| **>25** | **없음** | **VERY_LOOSE** | **재기술 대상** — 핵심 콘텐츠 추가 |
| **어떤 값이든** | **>30mm** | **REWRITE_URGENT** | **vspace 삭제 후 실 콘텐츠 재구성** |
| >100 | 0 | OVERFLOW | 콘텐츠 축소 or dmconceptcont 분할 |

### 재기술 절차 (5-step)

1. **핵심개념 목록 대조** — `bank/dmconcept-핵심개념-목록.md` 해당 소단원 정독
2. **누락 핵심 항목 식별** — 목록 vs 현 dmsub 대조 · 누락 목록화
3. **응용 침투 여부 확인** — 원칙 1 (핵심 vs 응용) 재판정 · 활용 유형 삽입 금지
4. **상위권 대상 재기술** — 원칙 4 (복원 아닌 상세한 기술) · 개념원리 원문 복사 X
5. **vspace 삭제 후 실 콘텐츠 삽입** — dmsub·dmexample·dmnote·dmexplain 활용

### 재기술 vs vspace 조정 판단

- **vspace 조정 (auto-tune 자동)**: 여백 5~25mm · 콘텐츠 밀도 정상 · parskip/linespread 미세 조정
- **재기술 (마스터 판단 필요)**: 여백 >25mm 또는 vspace >30mm · 콘텐츠 밀도 부족 · 핵심 개념 누락 가능성

### 자동 감지 (auto-tune v2.4 편입)

- **rewrite_candidate 컬럼**: `여백 >25mm OR vspace 삽입 >30mm` 조건 감지 시 flag
- **리포트 출력**: `--rewrite-candidates` 옵션으로 대상 목록만 분리 출력
- **판정 후 조치**: 마스터에게 재기술 필요 목록 보고 · concept-author 에이전트로 재편성

### 원칙 6 vs 원칙 2 관계

- **원칙 2** (넘칠 때만 페이지 추가): 콘텐츠 부족은 loose 유지 · 응용 삽입 금지
- **원칙 6** (간격 아닌 실 콘텐츠): 여백을 vspace로 채우지 말고 **누락된 핵심 콘텐츠** 발견 시 재기술

**두 원칙 조화**: 재기술은 **누락된 핵심 개념**을 채우는 것 · 응용 추가는 여전히 금지. 핵심 목록 대조 결과 누락 없음이면 loose 상태 유지.
