⚠️ **2026-06-30 갱신**: "단계" 표현은 *단계 라벨* (`\step{N}`·Step·[N단계])이 아니라 *식 변환 줄·논리 흐름 단위*를 의미한다. 단계 라벨 자체는 [[feedback_step_label_deprecated]] 영구 폐지. 본 정책은 *자세도* (verbosity)만 유지.

풀이는 **자세하고 친절할수록 좋다**. 컬럼 높이를 초과하면 **다음 페이지에 이어쓰기**.

## 규칙

- 식 변환 *줄마다* "왜 이렇게 푸는지" 짧은 자연어 설명 (수식만 나열 금지)
- 디스플레이 수식 `$$...$$`로 강조 (인라인으로 줄이지 말 것)
- 인접 식 변환이 연결되면 한두 줄 자연어 연결구 ("이를 ...과 합치면", "따라서") 사용
- 경계값·조건 분기는 명시적으로 표기 (분기는 `(i)·(ii)·(iii)` 사용 OK)
- 페이지가 부족하면 `\clearpage` 후 새 minipage에 "문제 N (계속)" 헤더

## 금지

- 풀이 압축 (디스플레이 → 인라인 강제 변환)
- 식 변환 줄 통합 (5줄을 3줄로 축약)
- 자연어 설명 삭제
- 🔴 **단계 라벨 사용** (`\step{N}`·Step 헤더 등 — [[feedback_step_label_deprecated]])

## Why

학생이 자기주도 학습할 때 풀이가 자세할수록 이해도 향상. 페이지 절약보다 풀이 명료성이 우선. 이전에 문제 4 풀이를 압축했다가 마스터 지적 받음.

## How to apply

- 본문 작성·수정 시 항상 자세 풀이 모드
- 컬럼 높이 초과 시 페이지 분할 우선 (압축은 최후 수단)
- `\probcolheight=16.8cm` 한계 인지하되, 한 문제 풀이가 길어지면 페이지 분할로 해결
- 답지 양식의 경우 좌·우 minipage 분할선 유지하되 "(계속)" 라벨로 이어붙이기
- 관련 메모리: [[feedback-cm1-no-set-interval]] (CM1 용어 제약)
