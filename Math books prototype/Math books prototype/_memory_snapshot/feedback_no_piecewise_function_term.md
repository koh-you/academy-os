**조각함수 · 조각 (piecewise piece 의미)** 사용 금지. 교과 외 용어이므로 학생 노출·내부 metadata·정독·정책 어디에도 사용 불가.

**Why:** 마스터 지시 (2026-07-22 세션 75). "조각함수 라는 말은 교과에 없는 말이므로 쓰면 안됨". 옵션 "구간별로 정의된 함수" 도 불가 — "구간" 은 **미적분** 용어 ([[feedback_no_calc2_terms_cm2]]). 관련: [[feedback_cm1_curriculum_single_source]] · [[feedback_term_check_all_zones]].

**How to apply:** 세션 75 확립 대체 표준 —

| 원 표현 | 대체 |
|---|---|
| 조각함수 | **두 식으로 정의된 함수** (또는 "여러 식으로 정의된 함수") |

| 왼쪽 조각·오른쪽 조각 | 왼쪽 식·오른쪽 식 |

| 이차 조각·일차 조각·무리 조각 | 이차식 부분·일차식 부분·무리식 부분 |
| 각 조각·이 조각·두 조각 | 각 식·이 식·두 식 |
| 조각별로 | 부분별로 |

| `$X$ 조각` (수식 뒤) | `$X$인 식` |
