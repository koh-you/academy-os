# "여사건"·"나쁜 경우의 수" 표현 사용 금지

**RED**: 시험지·답지·유형편 등 모든 학생 노출 자료에서 아래 표현 금지.
- `여사건` — 고3 확률과 통계 §확률 단원 용어. CM1은 "경우의 수"까지만.
- `나쁜 경우의 수` — 수학에 존재하지 않는 표현.

**Why**: 마스터 명시 2026-07-02. 학생 자료에 상위 과정 용어 사용 = CM1 교과과정 위반 (RED). "여사건" 개념 자체는 수학적으로 유효하나 CM1 범위 밖 용어. "나쁜 경우"는 애초에 없는 말.

**How to apply**:
- 발문·풀이·\soltitle·\solnote·quickgrid·헤더·answerbox 등 학생 노출 zone 전부 검사
- 대체:
  - "여사건을 이용하여" → "전체에서 [조건에 어긋난 경우]를 빼서"
  - "여사건이므로" → "구하는 경우의 수는 전체에서 [반대 조건 경우]를 빼서"
  - "여사건 조합" → "빼기 방법으로 세기"·"조건 어긋난 경우 빼기"
  - "나쁜 경우의 수" → "조건에 어긋난 경우의 수"·"조건 밖 경우의 수"
- 청사진 yaml `type:` 필드도 정정 (예: `자리배치-여사건` → `자리배치-빼기`)
