## 5-Step 작성 전 의무 체크

### Step 1. 이전 iteration archive + 참고자료 검색 (v1.1 강화)

**1-A. `bank/도해-카탈로그.md` 검색 (v1.1 신설 · 최우선)**:
- mechanism 유형 매칭 (M-01 팬터그래프·M-02 GPS·M-03 로봇팔·M-04 광학 반사 등)
- 승인 iteration TikZ 코드 발견 시 그대로 재사용
- 실패 iteration 목록 확인 (회피 사례)
- 미등록 mechanism이면 1-B로 진행

**1-B. `참고자료/` 폴더 검색**:
- `참고자료/학교기출/` — 학교 시험지에 이미 있는 그림
- `참고자료/공통수학{1,2}/` — 시판 교재
- `참고자료/대수-*` — 대수 라인 자료
- 시판 책·기출에 동일 개념 그림이 있으면 그 형태를 표준으로 참조
- 발견 시: 형태·구성·라벨 위치 그대로 반영

### Step 2. 웹 자료 조사 (외부)
- 기계 장치·물리 개념·역사적 도구·수학 개념 삽화는 **자체 지식만으로 판단 금지**
- WebSearch or WebFetch로 정확한 구조·원리 확인
- Wikipedia·MathWorld·공학 자료 등 신뢰 소스 우선
- 예: 사도기·시소·저울 등 물리 기구 → 실제 구조 조사 후 재현

### Step 3. 프로젝트 규정 확인 + 도해 유형 우선순위 (v1.1 강화)

**3-A. 도해 유형 우선순위** ([[feedback_multilayer_situation_visualization]] · v1.1 신설):

1. 🥇 **좌표평면 대응 도해** — 발문의 수학 대상 (원 C₁·C₂·두 궤도·두 집합) 관계 시각화
2. 🥈 **원리 도식** — mechanism 구조 (좌표평면 없음)
3. ❌ **관용어 서사 시각화** — 강아지·펭귄·CCTV 등 서사 대상 그리기 금지

**동시 사용 판정**:
- 발문에 자취·확대·평행이동·대응 mechanism 있음 → **두 도해 모두 필수**
- 자취 없는 mechanism → 원리 도식만 OK
- 순수 좌표 문제 → 좌표평면만

**3-B. 그림 종류별 단일 출처**:
| 그림 종류 | 확인 문서 |
|---|---|
| mechanism 도해 (팬터그래프·GPS·로봇팔 등) | **`bank/도해-카탈로그.md` (v1.1 신설)** |
| 좌표평면·함수 그래프 | `bank/그래프-양식-카탈로그.md` |
| 시험지·답지 레이아웃 | `templates/시험지-학교시험-v3.md`·`templates/답지-디자인-v2.md` |
| 유형편·연습편 | `templates/유형편-디자인.md` |
| 도형·기하 | `bank/그래프-양식-카탈로그.md` (도형 부분) |

관련 메모리도 확인:
- `feedback_multilayer_situation_visualization.md` — 좌표평면 우선순위
- `feedback_graph_extraction_study.md` — 그래프 표현 정교 학습
- `feedback_graph_design_style.md` — 학평 양식 (보조)
- `feedback_solution_format_priority.md` — 고쟁이 우선
- `feedback_asymptote_cache_verify.md` — Asymptote 검증

**주요 규정 예시** (그래프):
- **축 라벨**: `x`는 x축 아래 (S), `y`는 y축 왼쪽 (W). **화살표 끝(E·N)에 표기 금지**
- **곡선·직선·파선**: 좌표평면 안에서 시작·끝, **평면 밖 초과 금지**. 라인은 평면 끝까지 이어짐 (중간 끊기 금지)
- **좌표 라벨 위치**: 점 오른쪽 위, `y=f(x)` 라벨 곡선 오른쪽 끝점 옆

### Step 4. 문제 발문·정답 대조 자체 검수
- **발문과 그림 일치**: 발문의 설명("평행사변형 관절 구조" 등)이 그림에서 시각적으로 확인되는지
- **답 노출 없음**: 그림이 (1)(2)(3) 소문항의 답을 자명하게 드러내지 않는지
  - 특히 좌표·중심·반지름·각도 등 구체 수치 표시 시 위험
  - 발문에 주어진 정보(원의 방정식 등)는 표시 OK, 학생이 구해야 할 정보는 표시 금지
- **수학적 정확성**: 기계 장치 그림이면 실제 구동 원리 재현. 형태만 흉내내는 즉흥 그림 금지

### Step 5. 자동 도구 검증 + 마스터 시각 확인 (v1.2 강화 · 2026-07-22 세션 73)

**5-A. 자동 도구 2종 (v1.2 세션 73 · 관심사 분리)**:
```bash
node scripts/figure-check.mjs <문제.tex>            # 라벨·여백·도해 유형
node scripts/figure-effective-check.mjs <문제.tex>  # 실효 렌더링·프레임 채움
```
- `figure-check.mjs`: Check A (라벨-축 겹침) · Check B (여백) · ① 도해 유형 판정 · 관용어 서사 감지
- `figure-effective-check.mjs`: Check 1 (실효 두께) · Check 2 (점 실효 반경) · Check 3 (시리즈 일관성) · **Check 4 (무한 직선 프레임 채움 · v1.1 세션 73 신설)**
- **두 도구 모두 RED 0 통과 후에만 마스터 확인 요청 가능**

## Why (2026-07-10 세션 25 반복 실패 원인 분석)

세션 25에서 사도기 그림 관련 **4회 재작성**·**답 노출**·**축 라벨 규정 위반**·**평면 초과** 반복 발생. 원인:

1. **자료 조사 skip**: Step 1·2를 건너뛰고 자체 지식으로 사도기 구조 즉흥 설계 → 실제 사도기(4-rod X교차, 등간격 구멍 4개)와 다른 잘못된 구조 반복
2. **규정 확인 skip**: Step 3를 건너뛰고 축 라벨을 화살표 끝(E·N)에 표기 → 규정은 "x축 아래/y축 왼쪽"
3. **자체 검수 skip**: Step 4를 건너뛰고 그림 2에 C₂ 중심·반지름·눈금 다 표시 → 답 (1) 자명 노출
4. **평면 초과**: 파선을 좌표축 밖으로 연장 → 규정은 "평면 안에서 완결"
5. **발문 그림 불일치**: "평행사변형" 발문에 X-교차 그림 → 자체 검수 부재

이 5개 위반이 순차적으로 발견되어 4회 재작성 발생. **모든 위반이 작업 착수 전 5-step 체크로 방지 가능했음**.

## How to apply

**작업 착수 신호**: "그림을 그려줘"·"삽화 필요해"·"figure 만들자" 등 시각 요소 신규 작성 요청 시.

**진행 순서**:
1. 5-step 체크 각 항목 명시적 수행 (skip 금지)
2. 각 step 완료 여부를 마스터에게 짧게 보고 ("사도기 자료 조사 완료 · 규정 확인 완료 · ...")
3. 그 후에 asy·TikZ 코드 작성
4. 컴파일 후 파일 경로 안내 · 시각 확인 요청

**Skip 허용 예외**:
- 마스터가 명시적으로 "규정 무시" or "즉흥 그림 OK" 지시
- 기존 그림의 사소한 수정 (색·라벨 오타 정정 등)

**Skip 금지 상황** (반드시 5-step 이행):
- 신규 삽화 (물리 기구·기계·역사적 도구·인물 등)
- 좌표평면·함수 그래프·도형 그림
- 응용 문제의 상황 그림 (실생활 소재)
- 발문에 언급된 특정 도구·장치 재현
