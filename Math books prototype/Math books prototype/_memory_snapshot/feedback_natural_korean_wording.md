풀이·해설 한국어 문장은 **자연스럽고 일상적인 어법**으로 쓴다. 영어 수학 교재의 직역체나 컴퓨터 코드식 라벨링은 피한다.

## 회피할 표현 (마스터 지적 누적)

| 어색한 표현 | 자연스러운 대체 |
|---|---|
| **"종합 (m=2 조건):"** 같은 괄호 라벨 + 콜론 | "따라서 $m=2$가 되려면 ...여야 한다." 문장 끝맺음 |
| **"... 의 유일한 조합이어야 한다"** | "... 인 경우뿐이다" / "... 이어야 한다" |
| **"다른 조합은 가능하지 않다"** (앞 문장에 유일성 이미 표현된 경우) | 중복 문장이므로 삭제 |
| **"상한 1.", "상한 2."** 같은 번호 라벨 | "(i) $a^2-8a > -16$의 경우." / "(ii) ..." — 부등식 자체로 표기 |
| **"매개수 $k$를 고정하지 않고"** / **"$k$를 한 값으로 고정하지 않고"** | 문장을 다시 구성: "$k$의 값을 직접 구하는 것이 아니라, 그러한 $k$가 적어도 하나 있을 $a$의 범위를 구하는 데 풀이의 초점을 두는 것이 핵심" |
| **"$k$의 가능 범위가 비어 있지 않을 조건"** | "조건을 만족하는 $k$가 적어도 하나 있을 조건" |

## 원칙

1. **문장 끝맺음 우선** — "조건:" 콜론 + 수식 나열보다 "...여야 한다." "...뿐이다." 끝맺음
2. **중복 문장 제거** — 직전 문장에서 이미 강조된 내용을 다시 쓰지 않기
3. **수학적 객체 직접 명시** — "두 상한이" 같은 일반화 대신 "$a^2-8a$와 $\dfrac{7-3a}{2}$가"처럼 식 자체로
4. **풀이의 목적 자체로 풀어쓰기** — 추상적 용어("매개수의 자유도", "고정") 대신 "$k$를 직접 구하는 대신 $k$가 존재할 $a$의 범위를 구한다"
5. **자연스러운 연결구** — "따라서", "즉", "그러므로", "이를 풀면" 같은 평이한 연결사

## Why

마스터께서 2026-06-16~17 사이 풀이 본문 어법에 대해 6회 이상 지적 ("표현이 부자연스러워", "이상해", "필요없을 거 같아"). 학교 수학 풀이의 친절함은 자연스러운 한국어에서 나온다. 영어 직역체나 컴퓨터 코드식 라벨링은 학생 입장에서 부담만 된다.

## How to apply

- 풀이 본문 작성 시 [[feedback-cm1-no-set-interval]](용어)와 본 메모리(어법)를 함께 적용
- 검수(`problem-review`)에서도 본 메모리 기준 점검: "괄호 라벨 콜론", "유일한 조합이어야 한다", "다른 ~ 가능하지 않다" 같은 패턴 grep
- 새 풀이 작성 시 한 번 더 소리 내어 읽어보는 점검 (마스터 입장에서 자연스러운지)
