# 그림 조판 판정 규약 — 원문 준수 원칙

**원문(교재 혹은 기출 파일의 원본)에 그림이 있을 때만 우리 편집물에 그림을 조판한다. 원문에 그림이 없으면 임의로 그림을 추가하지 않는다.**

**Why:** 세션 55 (2026-07-20) 직선의 방정식 정리편 조판 중 subagent가 L3-1·L3-3에 원문 없는 TikZ 그림을 임의 추가한 사건. 마스터 지적 "야 원문에 그림이 없는데 왜 니가 마음대로 그림을 삽입해? 지워". 원문에 없는 그림 삽입 시 문제 성격 변경 · star_5_premium 통찰 정점 훈련 저해 (학생이 직접 좌표화 능력 훈련 기회 상실). 정리편 편집 편의로 그림을 추가하려는 유혹이 있으나 원문 형태 유지가 원칙.

**How to apply:**

## 1. "원문" 정의

- **교재 원본**: 개념원리·RPM·고쟁이·블랙라벨·마더텅 등 시판 교재의 실제 인쇄 발문·그림 (책 그 자체)
- **기출 원본**: 학평·수능·모의고사·EBS 시험지 원본 (교육청 배포 원본 PDF 그대로)

## 2. 원문 그림 유무 확인 3단계

**(1단계) `bank/mechanism-데이터-*.md`의 `problem_summary` 필드 대조**
- 원문 발문에 "그림과 같이 ~ 있다" 표현이 있는지 조회
- "그림에서 · 다음 그림 · 그림 참조" 등 그림 지시 표현 검색

**(2단계) `참고자료/` 안 원본 PDF 조회 (가장 확실)**
- 학평: `참고자료/고1 모의고사 기출 모음/YYYY/YYYY_M월_문제.pdf` 원본 페이지 확인
- 시판 교재: 정독 파일 인용 페이지 원본 조회
- 300dpi PDF 이미지로 확실히 확인

**(3단계) `solution_summary` 필드 참조**
- solution_summary에 "그림에서" · "위 그림" 언급 있으면 원문 그림 있음
- solution_summary가 "A(x, y)로 좌표화" 같이 풀이자가 좌표를 스스로 설정한다면 → **원문에 그림 없음** (원문은 순수 기하 서술)

## 3. 판정 → 조치

| 원문 그림 유무 | 발문에서 "그림과 같이" 있음 | 조치 |
|---|---|---|
| 있음 | 있음 | 우리 편집물에 그림 재현 (원본과 최대한 유사) |
| 있음 | 없음 (드묾) | 원문 발문 정확 확인 후 결정 |
| 없음 | 없음 | 그림 조판 금지 · 순수 문자 발문만 |
| 없음 | 있음 | 발문의 "그림과 같이" 표현 제거 필수 · 그림 없이 발문만 |

## 4. 그림 재현 시 준수 사항

원문에 그림이 있어 재현할 때:
- 원본 좌표·비율 최대한 유지
- 원본에 없는 요소 임의 추가 금지 (예: 원본에 축이 없으면 우리도 축 없음)
- 원본 라벨 배치 최대한 재현
- 세부 스타일 (선 두께·점 크기·라벨 위치)은 [[feedback_figure_point_size_rule]] · [[feedback_figure_design_system]] 등 프로젝트 표준 준수

## 5. 위반 사례 (세션 55)

- **L3-3 (고쟁이-STEP3-#115)**: problem_summary "AB=8, BC=16인 직사각형 ABCD의 내부 및 둘레 위의 점 P가 AP²-CP²=16" · solution_summary "A(0, 8), B(0, 0), ...로 좌표화" (풀이자 설정) → **원문 그림 없음** · 그러나 subagent가 신규 그림 조판. 마스터 지적 후 삭제.
- **L3-1 (고쟁이-STEP3-#113)**: problem_summary "직선 l1이 x축, y축과 만나는 점 A, B..." (그림 언급 없음) → **원문 그림 없음** · subagent가 "그림과 같이" 추가 + 신규 그림 조판. 마스터 지적 후 삭제 (발문의 "그림과 같이"도 함께 제거).

## 6. 관련 정책

- [[feedback_figure_authoring_protocol]] · 5-step 그림 조판 프로토콜 (archive → Commons → 참고자료 → TikZ → ❌AI)
- [[feedback_figure_design_system]] §4 · 삽화 삭제 절대 금지 (원본에 있는 그림은 함부로 삭제 금지)
- [[feedback_figure_frame_screen_fill]] · 축 프레임 채움 규약 (신정책 v2 · 여백 ≥20%)
- [[feedback_figure_point_size_rule]] · 점 크기 표준 규칙 (세션 55 신설)
- [[feedback_system_first_priority]] · 시스템 우선 원칙 (도구·규정·정책이 파일 정정보다 우선)

## 7. 자동 검증 도구 확장 예정

`scripts/figure-check.mjs`에 다음 축 추가 예정:
- Check C · 원문 대조 (source_id로 원 문제 은행 조회 · problem_summary에 그림 언급 없음이면 그림 조판 시 WARN)
- 신규 그림 추가 시 개발자에게 원문 확인 명시적 요구

## 8. 예외 (마스터 명시 승인 시에만)

- **학습 편의 목적 그림 추가**: 정리편 개념 슬롯 (C1·C2·C3)에서 개념 설명용 도해는 원문 무관 (별도 저자 조판 · 원본 문제와 무관)
- **답지 그림 재현**: 원문 그림이 있는 문항의 답지 풀이에서 축소 재현은 OK
- **마스터 명시 지시**: 마스터가 특정 문항에 그림 추가를 명시 지시한 경우
