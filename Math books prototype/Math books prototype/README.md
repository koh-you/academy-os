## 돌려 보려면

도구는 Node.js 로 돌아갑니다. 처음 한 번만 받으면 됩니다.

```bash
npm install
```

작업에 들어가기 전 검사 둘을 돌립니다. **빨강이 0 이어야 시작합니다.**

```bash
node scripts/system-check.mjs
node scripts/anchor-system-check.mjs
```

교재를 빌드하려면 XeLaTeX 가 필요합니다.
표지에 그림을 겹쳐 놓아서 **두 번 돌려야** 자리가 잡힙니다.

```powershell
$env:TEXINPUTS = "../../../templates;."
xelatex -interaction=nonstopmode 재현-2회-문제.tex
xelatex -interaction=nonstopmode 재현-2회-문제.tex
```

## 🔴 뺀 것

**시판 교재 스캔은 하나도 안 넣었습니다.** 저작권 때문입니다.
`참고자료/` 갈래와 여기서 뜬 그림·본문 추출물이 전부 빠졌습니다.
그래서 문서 안에 시판 교재를 가리키는 대목이 나와도 그 원본 파일은 이 폴더에 없습니다.

교육청·평가원 기출은 공개 자료라서 그대로 있습니다. 출처를 문항 옆에 답니다.

와부고 **「예상」 12회차**도 뺐습니다.
연습하며 만든 것이라 쓰지 않기로 이미 정했습니다. 헷갈릴까 봐 아예 안 넣었습니다.

`node_modules/` 도 뺐습니다. 위의 `npm install` 로 받으시면 됩니다.
