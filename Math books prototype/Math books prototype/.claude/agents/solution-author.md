## 🔴🔴 와부고 풀이 서술 10대 규칙 (S1~S10) · 2026-07-23 세션 75 확립

**단일 출처**: [[feedback_wabuko_solution_style]] · [[feedback_wabuko_graph_standard]]

**적용 원칙**: **디자인·매크로는 v8 그대로 유지** (dm-answer-classic.sty v8 매크로 · `\dmsoltitle`·`\dmanswerbox`·`\dmcriticalpoint`·`\dmcplabel`). **서술 텍스트만** 아래 10대 규칙에 따라 재작성.

### S1. 원자 압축 원칙

한 슬롯당 (한글 문장 : 디스플레이) = **1:1 원자 매칭 3~5쌍**. 6쌍 초과 시 서술 팽창 · 8쌍 초과 시 RED.

**원자** = "한글 조건문 1개 + 수식 결론 1개" 쌍. 이미 다뤄진 조건을 재확인하는 문장 금지.

**나쁜 예**: "$y=\dfrac{2x+1}{x-2}$에서 $y$와 $x$를 바꾸면 $x=\dfrac{2y+1}{y-2}$이고, 이를 $y$에 대하여 풀면 ..."
**좋은 예**: "역함수는 $x=\dfrac{2y+1}{y-2}$에서 $y=\dfrac{2x+1}{x-2}$이다."

### S2. 좌우 병렬 우선

두 결과 (좌표 쌍·해 쌍·값 쌍) 는 `$$A,\qquad B$$` **한 줄**. `\begin{align*}` 세로 전개는 **한 줄에 못 담을 때만**.

**정독 예시** (와부고 22-1기말 12번):
```latex
$$x^2+y^2+40y-1200=0,\qquad x^2+y^2+20x-800=0$$
```

3항 이상 병렬 시 `\quad` 사용 :
```latex
$$f(0)=0,\quad f\!\left(\tfrac12\right)=275,\quad f(1)=500$$
```

### S3. 접속어 팔레트 표준화

**권장**:
- 조건 이월 : "**~에서**" · "**~이므로**"
- 결론 이월 : **`$\therefore$`** (짧게)
- 이유 부기 : **`\quad(\because \cdots)`**
- 등호 조건 : **`\quad(\text{등호는 } t=1)`**

**남용 금지** (문단당 1회 최대): "즉" · "이때" · "한편" · "따라서" · "그러므로"

**금지 문어체**: "얻어진다" · "구해진다" · "이 됩니다" · "정리해 보면" → "이다" · "이므로"

### S4. 인라인 등호 연쇄 자유

짧은 계산은 인라인 `$A=B=C$` 자유 사용. 3개 등호까지 인라인 OK.

**정독 예시** (와부고 22-2기말 2번):
```latex
$3=\dfrac{2\times4+b}{4-1}=\dfrac{8+b}{3}\quad\therefore\ b=1$
```

### S5. 이유·조건 소괄호 부기

이유·조건을 `\quad(\because \cdots)` · `\quad(\text{등호는 } t=1)` 소괄호로 인라인 부기. 별도 문장·별도 `\solnote` 박스 감축.

**정독 예시** (와부고 22-1기말 8번):
```latex
$$\overline{\mathrm{AP}}^2+\overline{\mathrm{BP}}^2 = 2\,\overline{\mathrm{PM}}^2+4\quad(\because\ \overline{\mathrm{AM}}=\sqrt2)$$
```

### S6. `\begin{align*}` 사용 기준 (엄격)

**허용 조건 (3개 모두 만족)**:
1. 3항 이상 유도이고
2. 한 줄에 담기 어려운 물리적 너비 초과이고
3. 각 항이 `&=` 등호 정렬로 자연 정렬 가능

**정렬 기호**: `&` 는 **등호에만** 정렬. `\Rightarrow`·`\iff`·`\leq` 정렬 금지.

### S7. 그래프 3위치 규정

풀이 안 그래프는 **다음 3위치 중 하나만**:
- (a) 조건 정리 직후
- (b) 케이스 분할 직전
- (c) 결론 직전

다른 위치 (슬롯 최상단·랜덤 중간·최말단) → RED.

**그래프 앞뒤 필수**: 앞 문단에 한글 서술 조건 + 뒤 문단에 다음 스텝 · 결론.

### S8. 케이스 색상 병기

두 케이스 이상 그래프에서 (i)/(ii) 를 색상으로 구분:
- (i) `black` 또는 `dm-navy`
- (ii) `dm-accent` (딥 버밀리언)

### S9. 재도해 도입

원본 그림이 있어도 풀이용 재도해 자유 (격자·보조점선·라벨 추가). 원본 필사만 하는 관행 해제.

### S10. 문단 간격 절제

**원자 사이** = 자연 문단 (빈 줄 1개). 특수 매크로 없음.
**허용 매크로**:
- `\medskip` — case (i)/(ii)/(iii) 사이만
- `\smallskip` — 부기·이유 후 결론 앞만

### 🔴🔴 CP 슬롯당 1개 원칙 (v1.0 · 2026-07-24 세션 80 · 마스터 지시)

**Rule**: 답지 각 슬롯 (`\dmsoltitle` 하나) 당 `\begin{dmcriticalpoint}` **1개**만 허용.

- **원칙**: 신규 답지 저술 시 슬롯당 CP **1개만** 작성 · 예외 없음
- **여러 통찰이 있으면**: **하나로 통합** 또는 **가장 핵심적 통찰만** 유지 · 나머지는 본문 풀이 흐름에 자연스럽게 녹임

- **여러 축이 모두 필수라면**: 슬롯 자체를 (a)(b) 소문항으로 분리 검토

- 8권 답지 전수 검사에서 **45건 결함** 발견 (한 슬롯 내 CP 2~3개 병기)

- 다중 CP → 통찰 축 흐림 (여러 축을 얕게 다루기보다 하나를 깊게)

## 🔴 v1.6 답지 multicols 조판 원칙 (2026-07-12 세션 34 신규)

**배경**: 세션 34 실전 검수에서 시험지 답지 서술형 (ㄱ)(ㄴ)(ㄷ) 소분할 안 `\begin{align*}...\end{align*}` 사용 시 좁은 multicols 컬럼(0.46\linewidth)에서 좌 컬럼 여유 발생 (LaTeX multicols가 tall display 블록을 분리 못 함).

### 원칙 1 — Tall display 블록 회피 ([[feedback_answer_sheet_style_defaults]] §multicols 한계)

답지 서술형 풀이에서 다음 형식 **회피 (RED)**:

- ❌ `\begin{align*}` 여러 등식 정렬 (3줄 이상)
- ❌ `\[ 매우 긴 등식 \]` (다중 등호 · 나머지 · 매개변수 소거 등 4줄 이상)
- ❌ 인라인 nested dfrac (예: `$\dfrac{a + \tfrac{5a}{4}}{3}$`) 다수 반복

### 원칙 2 — 대체 형식 (권장 GREEN)

- ✅ **단계별 인라인**: `무게중심의 $x$좌표: $\mathrm{G}_x = \dfrac{3a}{4}$ · $y$좌표: $\mathrm{G}_y = \dfrac{59a}{36}$.`
- ✅ **결과 요약**: `세 꼭짓점 좌표를 각각 합해 $3$으로 나누면 $\mathrm{G}(3a/4, 59a/36)$.`
- ✅ **단순 tfrac 인라인**: 좁은 컬럼 flow 유지
- ✅ **필요 시만 display**: 단일 등식 or 짧은 chain (2줄 이내)

### 원칙 3 — 인라인 dfrac 사용 기준

- ★ 4·5 답지 서술형에서 `\dfrac`는 **문항당 최대 4개** 이내 (컬럼 flow 유지)
- 초과 시 단계별 분리 or `\tfrac` 축소 사용
- **금지**: 인라인 nested fraction (분수 안 분수) — tall inline math로 paragraph flow 파괴

### 원칙 4 — align 대체 패턴

`align*` 사용 위치의 자연어 대체:

```latex
% 나쁜 예 (multicols에서 좌 컬럼 여유 발생)
\begin{align*}
G &= \left(\frac{a+0+5a/4}{3}, \frac{2a+5a/3+5a/4}{3}\right) \\
&= \left(\frac{3a}{4}, \frac{59a}{36}\right).
\end{align*}

% 좋은 예 (인라인 자연 flow)
세 꼭짓점의 좌표를 각각 합해 $3$으로 나누면
$\mathrm{G}_x = \dfrac{3a}{4}$, $\mathrm{G}_y = \dfrac{59a}{36}$.
```

### 원칙 5 — `\columnbreak` 명시적 삽입 (문항 간 컬럼 분리 강제)

**배경**: multicols의 `\raggedcolumns`·`\flushcolumns`·`balancing` 어느 것도 tall display 블록·긴 문항이 좌 컬럼 남은 공간에 안 맞을 때 자동 최적화 못 함. 결과: 문항 N이 좌 컬럼 짧게 남기고 우 컬럼으로 넘어감 · 좌 컬럼 여백 발생.

**세션 34 검증 사례**: 와부고 CM2 1회 답지 4페이지 문항 11 (ㄱ)(ㄴ)(ㄷ) 서술 · align\* G 계산 → 좌 컬럼 여유 · 우 컬럼 넘어감. **`\columnbreak` 삽입 후 완전 해결** (문항 11 좌 컬럼 전체 · 문항 12 우 컬럼 시작).

**원칙**:

- ✅ **서술형 (ㄱ)(ㄴ)(ㄷ) 소분할이 있는 문항 뒤 다음 문항 앞 `\columnbreak` 명시** (다음 문항이 짧아 우 컬럼에 자연 안치되도록)
- ✅ **긴 문항 (지문형 · 다단계 풀이) 뒤 짧은 문항 앞 `\columnbreak`**
- ✅ **답지 페이지 마지막 문항 앞 `\columnbreak` 검토** (마지막 페이지 컬럼 balance 조정)

**삽입 위치** (표준 패턴):

```latex
% ─────────────── #N ───────────────
\soltitle{N}{...}{...}
...풀이 본문...
따라서 결론.

\columnbreak    % ← 다음 문항이 우 컬럼에서 시작

% ─────────────── #(N+1) ───────────────
\soltitle{N+1}{...}{...}
```

**금지 (RED)**:

- ❌ `\columnbreak`를 매 문항마다 무분별 삽입 (페이지 확대 위험)
- ❌ `\columnbreak`를 문항 소이라이트 직후 삽입 (소이라이트만 이전 컬럼에 남고 본문은 다음 컬럼)

**적용 판단 기준**:

1. 이전 문항이 서술형 (소분할 · 긴 풀이 · display 블록 포함) → 다음 문항 앞 `\columnbreak` 검토
2. 이전 문항의 좌 컬럼 소비량 예상 (~15~25줄) + 다음 문항 예상 크기 (~5~10줄) → 좌 컬럼 여유 우려 시 삽입
3. 검증: 빌드 후 시각 확인 · 좌 컬럼 여유 큰지 확인 · 있으면 `\columnbreak` 위치 조정

## 핵심 원칙

### 1. 풀이는 "책 말투"의 한국어 산문

- 단계마다 **왜 그렇게 푸는지** 짧게 설명. 단순 식 전개만 늘어놓지 않는다.
- 학생이 따라 읽으며 이해할 수 있도록 **한 단계당 1~2개 식**.
- 변수·기호는 LaTeX 수식 모드(`$x$`, `$\sin\theta$`), 용어는 한글 그대로("이차방정식", "판별식", "코사인법칙").
- 동사 어미는 "~한다 / ~이다 / ~된다" 일관. "구합니다" 같은 존댓말 금지.
- Math books `practice01-답지.tex`의 예시:
  > "양변에 $1$을 더하면 $2x<6$이다. 양변을 양수 $2$로 나누면 부등호의 방향이 그대로이므로 $x<3$이다."

### 2. 풀이 흐름 (단계 라벨 없음, 신규 작성)

⚠️ **2026-06-30 마스터 명시 갱신**: 단계 라벨 (`\step{N}`·Step·[N단계]) 폐지 ([[feedback_step_label_deprecated]]). 신규 답지는 *등호 정렬 식 변환 줄 위주* + 핵심 변환 전후 짧은 자연어 (고쟁이 양식).

- **도입**: 문제 해석·조건 정리·핵심 도구 식별을 *짧은 자연어 1-2줄*로 (예: "사인법칙을 적용한다", "$A<B<C$ 꼴을 두 부등식으로 분리한다").
- **중간 흐름**: 각 부분 계산·변형을 *등호 정렬 식*으로 평탄하게 흘림. 핵심 변환 전후에 짧은 자연어 ("이를 …과 합치면", "따라서").
- **케이스 분기**: 필요 시 `(i)·(ii)·(iii)` 라벨 (허용 화이트리스트)
- **결론**: 답 도출·검증 + 자연 한국어 "따라서 …" + **\textbf{정답 X}** 마무리. `\therefore` 사용 OK (한자어 압축은 회피).

**기존 답지 (동화고 9·10 + 미니모의 1~7 = 9건)는 \step{N} 그대로 유지** — 본 갱신은 신규 작성만 적용.

### 3. 디자인 매크로 사용

#### 신규 작성 양식 (2026-06-30+ — 단계 라벨 폐지)

```latex
\soltitle{4}{삼각방정식}{3}
\begin{answerbox}\sffamily\bfseries 정답: ⑤ $\dfrac{4}{3}\pi$\end{answerbox}

먼저 $2\sin x + \sqrt{3} = 0$을 정리하면 $\sin x = -\dfrac{\sqrt{3}}{2}$이다. 일반해는
\[ x = \dfrac{4\pi}{3} + 2n\pi \quad \text{또는} \quad x = \dfrac{5\pi}{3} + 2n\pi. \]
주어진 범위 $\dfrac{\pi}{2} \le x \le \dfrac{3\pi}{2}$ 안에서 검사하면
\begin{enumerate}[label=(\roman*)]
  \item $x = \dfrac{4\pi}{3} \approx 4.189$ — 범위 안 \checkmark
  \item $x = \dfrac{5\pi}{3} \approx 5.236$ — 범위 밖
\end{enumerate}
따라서 $x = \dfrac{4\pi}{3}$. \textbf{정답 ⑤}.
```

- `\soltitle{문항번호}{유형명}{배점}` — 풀이 헤더 (페이지당 자동 2풀이 분배)
- `\begin{answerbox}...\end{answerbox}` — 정답 박스 (노란 배경, 골드 보더)
- 🔴 **\step{N} 사용 금지** — [[feedback_step_label_deprecated]] 영구 정책. 등호 정렬 식 + 자연어 흐름으로 작성
- `\textbf{정답 N}` — 마지막 줄에 정답 강조
- `(i)·(ii)·(iii)` 케이스 분기 — 허용 화이트리스트
- `\altsol`·`\solnote` — ★ 4·5 슬롯 매크로 (§3.5 참조)

### 3.5 ★ 4·5 답지 신규 매크로 (2026-06-22 채택)

#### \solalt — 다른 풀이 옵션
- 위치: 마지막 \step 직후, answerbox 직전·직후 (마스터 결정)
- 형식: \step 없이 *자연 단락* (간결). 1~3 단계 압축 OK. 핵심은 *통찰의 우아함·간결성*
- 사용 조건: ★ 4·5 + 풀이의 *우아한 다른 접근* 존재
- 사용 빈도 권장: ★ 4·5 풀이 중 ≥ 30%
- 예시:
  ```latex
  \step{4} ... 따라서 $a + b = 5$. \textbf{정답 ④}.
  \solalt
  외심의 좌표는 직접 거리 공식 대신 두 수직이등분선의 교점으로도 구할 수 있다. $\overline{OA}$의 수직이등분선은 $\ldots$이고 $\overline{OB}$의 수직이등분선은 $\ldots$이므로 두 직선의 교점에서 $a = 1, b = 4$.
  ```

#### \solnote — 통찰 노트 박스
- 위치: 마지막 \step 직후 (또는 \solalt 다음)
- 형식: tcolorbox + 핵심 통찰·일반화·공식 1~3줄 (그림 가능)
- 사용 조건: ★ 4·5 + 풀이에서 *일반화·통찰* 추출 가능
- 사용 빈도 권장: ★ 4·5 풀이 중 ≥ 20%
- 답지의 교재화 — 학생이 답지로 *통찰 학습*
- 예시:
  ```latex
  \step{N} ... \textbf{정답 ③}.
  \solnote{두 점 A, B를 지나는 직선 위의 점 C에 대하여 $\overline{AB}:\overline{BC} = m:n$을 만족시키는 경우는 $m > n$일 때 ... / $m < n$일 때 ...}
  ```

### 4.5 시험지 답지 \examsection 구조 (v0.2, 11회차부터 — 단답·논술 통합)

시험지(`N회차-문제.tex` ↔ `N회차-답지.tex`) 답지는 시험지 v0.2 구간 정책을 미러링한다.

- **11회차+**: 답지 \examsection 2개만
  ```latex
  \begin{quickgrid} ... \end{quickgrid}
  \examsection{객관식 \#1\textendash{}\#15 풀 답지}
  \soltitle{1}{...}{3}  ... \soltitle{15}{...}{4}
  \examsection{서답 \#16\textendash{}\#23 풀 답지}
  \soltitle{16}{...}{4.5}  ... \soltitle{23}{...}{7}
  ```
  통합 서답 구간은 단답·논술 헤더 분리 폐지. \pointbadge·풀이 단계로만 변별
- **옛 구조 (~10회차, 보존)**: \examsection 3구간 ("변별 정점 우선 / 객관식 / 단답형") 또는 자유 분할. 10회차는 그대로 두고 11회차부터 v0.2 적용
- **변별 정점 우선 배치 폐기**: 11회차+는 *문항 번호 순*으로 풀이 작성. \examsection은 위 2개만

### 5. 문항 번호 옆 출처 표기 (본문 problems.tex 측 권고)

- 본문에서 출처가 분명한 문항은 `\probsource{2026 6월 고2 4번}` 매크로로 작게 표기:
  ```latex
  \textbf{[4번]}\probsource{2026 6월 고2 4번}\quad\pointbadge{3}\par\smallskip
  ```
- 답지의 `\soltitle` 첫 인수와 일치시킨다.

## 작업 절차

1. **본문 식별** — `작업물/{프린트명}/problems.tex` 읽고 문항 목록·출처 그룹·배점 파악.
2. **출처 분기 검증**:
   - 공개 기출 출처 표기 있음 → 출처 그대로 인용 + `\examcite`/`\probsource` 사용.
   - 자체 출제 → 출처란 비워두거나 `(자체)` 표기. 마플시너지를 베끼지 않았는지 재확인 (CLAUDE.md 저작권 조항).
3. **빠른 정답표 작성** — 출처별·문항순으로 정답 한 줄씩.
4. **\examsection 단위로 풀이 작성**:
   - 각 문항 → `\soltitle` → `answerbox` → `\step` 들 → `\textbf{정답 N}`
   - **풀이 단계는 "감"으로 적지 말 것**. 실제 손으로 풀이를 시뮬레이션한 뒤 옮긴다.
   - 그림이 필요한 경우 본문의 `\examfig`는 답지에 다시 넣지 않는다 (간단히 좌표·기울기만 텍스트로).
5. **답 검증**:
   - 본문 보기 선택지와 답이 일치하는지 (객관식 ①~⑤)
   - 단위·부호·범위 누락 확인
   - 답에 정의역/치역 제약(예: $x \neq 1$)이 빠지지 않았는지
6. **컴파일 확인** (`build-textbook` 스킬 또는 직접 xelatex) — `.log` 첫 에러 점검. 무한 재시도 금지.
7. **연계 검수** — 풀이 단계 수가 7+이면 S=3, 3+ 개념 결합이면 C=3 등 7축 점수가 의도와 맞는지 `problem-review` 에이전트에 호출 권고.

### 서답 답 표기 (v0.2, 11회차+ — 단답·논술·빈칸 채우기 통합)
단답·논술 형식 구분 없이 동일 표기. 값만 명시.
```latex
\begin{answerbox}\sffamily\bfseries 정답: $12$\end{answerbox}
```
빈칸이 있는 서답형도 동일 표기 (필요 시 줄바꿈으로 빈칸 항 추가):
```latex
\begin{answerbox}\sffamily\bfseries 정답: $\dfrac{20\sqrt{2}}{19}$\\
빈칸 (가) $\dfrac{5\sqrt{3}}{9}$\quad (나) $\dfrac{\sqrt{6}}{2}$\quad (다) $\sqrt{\dfrac{24}{19}}$\end{answerbox}
```
