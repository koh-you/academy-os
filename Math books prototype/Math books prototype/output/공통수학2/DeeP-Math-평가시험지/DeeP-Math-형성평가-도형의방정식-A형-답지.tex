\dmsoltitle{1}{두 점 사이의 거리에서 미지수 결정}
\begin{dmanswerbox}
정답: ③ $7$
\end{dmanswerbox}

두 점 $\mathrm{A}(3,\,a)$,\ $\mathrm{B}(a,\,3)$\ 사이의 거리의 제곱은
\[ \overline{\mathrm{AB}}^{\,2} = (a-3)^2 + (3-a)^2 = 2(a-3)^2. \]
$\overline{\mathrm{AB}} = 4\sqrt{2}$\ 에서 $2(a-3)^2 = 32$,\ $(a-3)^2 = 16$\ 이므로 $a=7$\ 또는 $a=-1$. 양수 조건에서 $\therefore\ a=7$.

% ═══════════════════════════════════════════════════════════════════════════
% Q02 · 4점 · 중점
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{2}{중점 좌표에서 두 미지수 결정}
\begin{dmanswerbox}
정답: ③ $7$
\end{dmanswerbox}

두 점 $\mathrm{A}(a,\,3)$,\ $\mathrm{B}(-4,\,b)$\ 의 중점의 좌표는
$$\left( \dfrac{a-4}{2},\ \dfrac{3+b}{2} \right) = (1,\,2).$$
두 좌표를 각각 비교하면 $a-4=2$\ 에서 $a=6$,\ $3+b=4$\ 에서 $b=1$\ 이므로 $\therefore\ a+b=7$.

% ═══════════════════════════════════════════════════════════════════════════
% Q03 · 4점 · 직선의 방정식과 y절편
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{3}{두 점을 지나는 직선의 $y$\ 절편}
\begin{dmanswerbox}
정답: ③ $1$
\end{dmanswerbox}

두 점 $\mathrm{A}(-2,\,5)$,\ $\mathrm{B}(3,\,-5)$\ 를 지나는 직선의 기울기는
\[ \dfrac{-5-5}{3-(-2)} = -2 \]
이고, 점 $\mathrm{A}$\ 를 지나므로 직선의 방정식은
\[ y-5 = -2(x+2),\quad y = -2x+1 \]
이다. $\therefore\ y$\ 절편은 $1$.

% ═══════════════════════════════════════════════════════════════════════════
% Q04 · 5점 · 두 직선의 평행·수직
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{4}{두 직선의 수직·평행 조건}
\begin{dmanswerbox}
정답: ③ $10$
\end{dmanswerbox}

직선 $bx-2y-1=0$\ 은 $y = \dfrac{b}{2}x - \dfrac{1}{2}$,\ 직선 $(b-1)x + y - 3 = 0$\ 은 $y = -(b-1)x + 3$\ 이다.

$y=ax+3$\ 이 첫 직선과 수직이므로 $a\cdot\dfrac{b}{2} = -1$,\ 즉 $ab = -2$. 둘째 직선과 평행이므로 $a = -(b-1) = 1-b$\ 이다.

두 식을 연립하면 $(1-b)b = -2$\ 에서 $b^2 - b - 2 = 0$,\ $(b-2)(b+1) = 0$\ 이므로 $b=2$\ 또는 $b=-1$\ 이다. 각각의 경우 $(a,\,b) = (-1,\,2)$\ 또는 $(2,\,-1)$\ 이다.

두 경우 모두 $\therefore\ a^2 + b^2 = 5$.

% ═══════════════════════════════════════════════════════════════════════════
% Q05 · 5점 · 원의 방정식 (존재 조건)
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{5}{일반형이 원이 되기 위한 존재 조건}
\begin{dmanswerbox}
정답: ④ $4$
\end{dmanswerbox}

$x^2 + y^2 + 2ax - 6y + a^2 + 3a - 4 = 0$\ 을 완전제곱 형태로 정리하면
\[ (x+a)^2 + (y-3)^2 = -\,(3a - 4) + 9 = -3a + 13. \]
원이 되려면 우변이 양수이어야 하므로 $-3a + 13 > 0$,\ 곧 $a < \dfrac{13}{3}$\ 이다.

자연수 $a$\ 는 $1,\,2,\,3,\,4$\ 이므로 최댓값은 $\therefore\ a = 4$.

% ═══════════════════════════════════════════════════════════════════════════
% Q06 · 5점 · 평행이동
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{6}{평행이동 규칙에서 두 미지수 결정}
\begin{dmanswerbox}
정답: ③ $-2$
\end{dmanswerbox}

점 $(1,\,-2)$\ 를 점 $(3,\,1)$\ 로 옮기는 평행이동은 $x$\ 축 방향으로 $2$,\ $y$\ 축 방향으로 $3$\ 만큼의 이동이다.

같은 평행이동으로 점 $(a,\,b)$\ 가 점 $(-1,\,4)$\ 로 옮겨지므로
$$a + 2 = -1,\qquad b + 3 = 4.$$
$a = -3$,\ $b = 1$\ 이므로 $\therefore\ a + b = -2$.

% ═══════════════════════════════════════════════════════════════════════════
% Q07 · 5점 · 두 거리의 비 조건
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{7}{두 거리의 비 조건에서 근의 합}
\begin{dmanswerbox}
정답: ③ $2$
\end{dmanswerbox}

두 거리의 제곱은
\[ \overline{\mathrm{AB}}^{\,2} = 16 + 4 = 20,\qquad \overline{\mathrm{BC}}^{\,2} = 1 + (a-1)^2. \]
$\overline{\mathrm{AB}} = 2\,\overline{\mathrm{BC}}$\ 에서 $\overline{\mathrm{AB}}^{\,2} = 4\,\overline{\mathrm{BC}}^{\,2}$\ 이므로
\[ 20 = 4\bigl( 1 + (a-1)^2 \bigr) \ \Longrightarrow\ (a-1)^2 = 4. \]
두 실근 $a = 3$,\ $a = -1$\ 의 합은 $\therefore\ 2$.

% ═══════════════════════════════════════════════════════════════════════════
% Q08 · 5점 · 정점 + 점과 직선 사이의 거리
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{8}{항상 지나는 점의 도출과 점-직선 거리 조건의 결합}
\begin{dmanswerbox}
정답: ① $-36$
\end{dmanswerbox}

직선 $x + ky - 2(k-1) = 0$\ 은 $k$\ 에 대하여 정리하면
\[ (x + 2) + k(y - 2) = 0. \]
$k$\ 의 값에 관계없이 성립하려면 $x + 2 = 0$,\ $y - 2 = 0$\ 이어야 하므로 항상 지나는 점은 $\mathrm{P}(-2,\,2)$\ 이다.

$\mathrm{P}(-2,\,2)$\ 와 직선 $x - 3y + a = 0$\ 사이의 거리가 $\sqrt{10}$\ 이므로
\[ \dfrac{|\,-2 - 6 + a\,|}{\sqrt{1 + 9}} = \sqrt{10}\ \Longrightarrow\ |a - 8| = 10. \]
$a = 18$\ 또는 $a = -2$\ 이므로 두 값의 곱은 $\therefore\ 18 \times (-2) = -36$.

% ═══════════════════════════════════════════════════════════════════════════
% Q09 · 5점 · 수선의 발
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{9}{점에서 직선에 내린 수선의 발의 좌표}
\begin{dmanswerbox}
정답: ③ $3$
\end{dmanswerbox}

직선 $2x - 3y - 1 = 0$\ 은 $y = \dfrac{2}{3}x - \dfrac{1}{3}$\ 로 기울기 $\dfrac{2}{3}$\ 이다. 점 $\mathrm{A}(0,\,4)$\ 를 지나고 이 직선과 수직인 직선의 기울기는 $-\dfrac{3}{2}$\ 이므로 그 방정식은
\[ y = -\dfrac{3}{2}x + 4,\quad \text{즉}\ \ 3x + 2y - 8 = 0. \]
두 직선을 연립하면
\[ \begin{cases} 2x - 3y = 1 \\ 3x + 2y = 8 \end{cases} \ \Longrightarrow\ x = 2,\ y = 1. \]
수선의 발은 $(2,\,1)$\ 이므로 $a = 2$,\ $b = 1$\ 이고 $\therefore\ a + b = 3$.

% ═══════════════════════════════════════════════════════════════════════════
% Q10 · 5점 · 원과 직선의 위치 관계 (접함)
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{10}{원과 직선이 접할 조건에서 두 값의 합}
\begin{dmanswerbox}
정답: ③ $-14$
\end{dmanswerbox}

원 $(x-2)^2 + (y+1)^2 = 10$\ 의 중심은 $(2,\,-1)$,\ 반지름은 $\sqrt{10}$\ 이다. 직선 $y = 3x + k$\ 는 $3x - y + k = 0$\ 이므로 중심과 직선 사이의 거리가 반지름과 같을 때 한 점에서 만난다.
\[ \dfrac{|3 \cdot 2 - (-1) + k|}{\sqrt{9 + 1}} = \sqrt{10}\ \Longrightarrow\ |k + 7| = 10. \]
$k = 3$\ 또는 $k = -17$\ 이므로 두 값의 합은 $\therefore\ 3 + (-17) = -14$.

% ═══════════════════════════════════════════════════════════════════════════
% Q11 · 5점 · 원 위 점에서의 접선
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{11}{원 위의 점에서의 접선의 방정식}
\begin{dmanswerbox}
정답: ④ $8$
\end{dmanswerbox}

원 $x^2 + y^2 = 13$ 위의 점 $(2,\,3)$\ 에서의 접선의 방정식은
\[ 2x + 3y = 13. \]
이 직선이 점 $(a,\,-1)$\ 을 지나므로 $2a + 3 \cdot (-1) = 13$,\ 곧 $2a = 16$\ 이므로 $\therefore\ a = 8$.

% ═══════════════════════════════════════════════════════════════════════════
% Q12 · 5점 · 원 밖의 점에서 그은 접선의 길이
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{12}{원 밖의 점에서 접선의 길이 (피타고라스 관점)}
\begin{dmanswerbox}
정답: ④ $2\sqrt{14}$
\end{dmanswerbox}

원 $(x+1)^2 + (y-3)^2 = 9$\ 의 중심은 $\mathrm{C}(-1,\,3)$,\ 반지름은 $3$\ 이다. 접점 $\mathrm{B}$\ 에서 $\overline{\mathrm{CB}} \perp \overline{\mathrm{AB}}$\ 이므로 직각삼각형 $\mathrm{ABC}$\ 에서
\[ \overline{\mathrm{AB}}^{\,2} = \overline{\mathrm{AC}}^{\,2} - \overline{\mathrm{CB}}^{\,2}. \]
$\overline{\mathrm{AC}}^{\,2} = (6+1)^2 + (-1-3)^2 = 49 + 16 = 65$,\ $\overline{\mathrm{CB}}^{\,2} = 9$\ 이므로
\[ \overline{\mathrm{AB}}^{\,2} = 65 - 9 = 56,\quad \therefore\ \overline{\mathrm{AB}} = 2\sqrt{14}. \]

% ═══════════════════════════════════════════════════════════════════════════
% Q13 · 5점 · 평행이동한 원과 직선의 접함
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{13}{평행이동한 원이 직선과 접할 조건}
\begin{dmanswerbox}
정답: ① $-31$
\end{dmanswerbox}

원 $x^2 + y^2 + 2x - 6y - 6 = 0$\ 을 완전제곱 형태로 정리하면
\[ (x+1)^2 + (y-3)^2 = 16, \]
중심은 $(-1,\,3)$,\ 반지름은 $4$\ 이다. 평행이동 $(x,\,y) \to (x+k,\,y-2)$\ 로 옮긴 원의 중심은 $(-1+k,\,1)$,\ 반지름은 $4$\ 로 유지된다.

이 원이 직선 $3x + 4y + 10 = 0$\ 과 접하려면 중심과 직선 사이의 거리가 반지름과 같아야 하므로
\[ \dfrac{|3(-1+k) + 4 + 10|}{\sqrt{9+16}} = 4\ \Longrightarrow\ |3k + 11| = 20. \]
$3k + 11 = 20$\ 또는 $3k + 11 = -20$\ 이므로 $k = 3$\ 또는 $k = -\dfrac{31}{3}$. 두 값의 곱은 $\therefore\ 3 \times \Bigl(-\dfrac{31}{3}\Bigr) = -31$.

% ═══════════════════════════════════════════════════════════════════════════
% Q14 · 5점 · 임의 직선에 대한 대칭이동
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{14}{임의 직선에 대한 대칭이동 (수직·중점)}
\begin{dmanswerbox}
정답: ③ $5$
\end{dmanswerbox}

두 점 $(3,\,4)$\ 와 $(p,\,q)$\ 가 직선 $y = -x + 2$\ 에 대하여 대칭이려면 두 조건이 필요하다.

먼저 두 점의 중점이 이 직선 위에 있어야 하므로
\[ \dfrac{q+4}{2} = -\,\dfrac{p+3}{2} + 2\ \Longrightarrow\ p + q = -3. \]
다음으로 두 점을 지나는 직선이 대칭축과 수직이어야 하므로 두 직선의 기울기의 곱이 $-1$\ 이다. 대칭축의 기울기가 $-1$\ 이므로 두 점을 잇는 직선의 기울기는 $1$\ 이고
\[ \dfrac{q - 4}{p - 3} = 1\ \Longrightarrow\ q - p = 1. \]
두 식을 연립하면 $p = -2$,\ $q = -1$\ 이므로 $\therefore\ p^2 + q^2 = 4 + 1 = 5$.

% ═══════════════════════════════════════════════════════════════════════════
% Q15 · 5점 · 대칭이동을 이용한 최단 거리
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{15}{직선에 대한 대칭점과 두 거리의 합의 최솟값}
\begin{dmanswerbox}
정답: ② $\sqrt{29}$
\end{dmanswerbox}

점 $\mathrm{P}$\ 가 직선 $y = x$\ 위에 있으므로 $\mathrm{A}(2,\,1)$\ 을 이 직선에 대하여 대칭이동한 점을 $\mathrm{A}'$\ 이라 하면 $\overline{\mathrm{AP}} = \overline{\mathrm{A}'\mathrm{P}}$\ 이다.

직선 $y = x$\ 에 대한 대칭이동은 $(x,\,y) \to (y,\,x)$\ 이므로 $\mathrm{A}(2,\,1)$\ 의 대칭점은 $\mathrm{A}'(1,\,2)$\ 이다. 따라서
\[ \overline{\mathrm{AP}} + \overline{\mathrm{BP}} = \overline{\mathrm{A}'\mathrm{P}} + \overline{\mathrm{BP}} \ge \overline{\mathrm{A}'\mathrm{B}}, \]
등호는 $\mathrm{P}$\ 가 선분 $\overline{\mathrm{A}'\mathrm{B}}$\ 위에 있을 때 성립한다.
\[ \overline{\mathrm{A}'\mathrm{B}} = \sqrt{(6-1)^2 + (4-2)^2} = \sqrt{25 + 4} = \sqrt{29}, \]
$\therefore\ \overline{\mathrm{AP}} + \overline{\mathrm{BP}}$\ 의 최솟값은 $\sqrt{29}$\ 이다.

% ═══════════════════════════════════════════════════════════════════════════
% Q16 · 5점 · 무게중심
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{16}{무게중심의 두 좌표에서 두 미지수 결정}
\begin{dmanswerbox}
정답: ③ $10$
\end{dmanswerbox}

삼각형 $\mathrm{ABC}$\ 의 무게중심은 세 꼭짓점 좌표의 평균이므로
$$\dfrac{-1 + p + 5}{3} = 4,\qquad \dfrac{2 + 3 + 1}{3} = q.$$
첫 식에서 $p + 4 = 12$,\ 곧 $p = 8$\ 이고 둘째 식에서 $q = 2$\ 이므로 $\therefore\ p + q = 10$.

% ═══════════════════════════════════════════════════════════════════════════
% Q17 · 5점 · 세 직선이 이루는 직각삼각형
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{17}{세 직선이 직각삼각형을 이룰 조건}
\begin{dmanswerbox}
정답: ③ $\dfrac{1}{2}$
\end{dmanswerbox}

세 직선의 기울기는 각각 $L_1$\ 이 $2$,\ $L_2$\ 가 $-1$,\ $L_3$\ 가 $a$\ 이다.
$L_1$\ 과 $L_2$\ 의 기울기 곱은 $2 \times (-1) = -2 \neq -1$\ 이므로 두 직선은 수직이 아니다. 직각이 되려면 $L_3$\ 가 $L_1$\ 또는 $L_2$\ 와 수직이어야 한다.

$L_3 \perp L_1$\ 인 경우: $a \cdot 2 = -1$,\ 곧 $a = -\dfrac{1}{2}$.

$L_3 \perp L_2$\ 인 경우: $a \cdot (-1) = -1$,\ 곧 $a = 1$.

두 경우 모두 세 직선이 실제로 삼각형을 이루는지 확인해야 한다. $a = -\dfrac{1}{2}$\ 일 때 $L_3: y = -\dfrac{1}{2}x + 3$\ 은 $L_1$·$L_2$\ 와 각각 다른 점에서 만나므로 삼각형이 만들어진다. $a = 1$\ 일 때도 $L_3: y = x + 3$\ 은 $L_1$·$L_2$\ 와 각각 다른 점에서 만나 삼각형이 만들어진다.

$\therefore$ 모든 $a$\ 의 합은 $-\dfrac{1}{2} + 1 = \dfrac{1}{2}$.

% ═══════════════════════════════════════════════════════════════════════════
% Q18 · 6점 · 학평 · 평행이동한 두 원과 공통접선 (verbatim_kichul)
% ═══════════════════════════════════════════════════════════════════════════
\dmsoltitle{18}{평행이동한 두 원의 공통접선 조건}
\begin{dmanswerbox}
정답: ③ $12$
\end{dmanswerbox}

원 $C:(x-1)^2 + y^2 = r^2$\ 의 중심은 $\mathrm{O}_1(1,\,0)$,\ 반지름은 $r$\ 이다. 평행이동에 의해 원 $C'$\ 의 중심은 $\mathrm{O}_2(1+a,\,b)$,\ 반지름은 $r$\ 로 같다.

조건 (가)에서 원 $C'$\ 이 원 $C$\ 의 중심 $\mathrm{O}_1(1,\,0)$\ 을 지나므로
\[ (1 - (1+a))^2 + (0 - b)^2 = r^2\ \Longrightarrow\ a^2 + b^2 = r^2. \tag{$\ast$} \]

조건 (나)에서 직선 $4x - 3y + 21 = 0$\ 이 두 원에 모두 접하려면 두 중심에서 이 직선까지의 거리가 모두 $r$\ 이어야 한다.

$\mathrm{O}_1$\ 에서의 거리:
\[ \dfrac{|4 \cdot 1 - 3 \cdot 0 + 21|}{\sqrt{16 + 9}} = \dfrac{25}{5} = 5 = r. \]
따라서 $r = 5$\ 이고, $(\ast)$\ 에서 $a^2 + b^2 = 25$.

$\mathrm{O}_2$\ 에서의 거리:
\[ \dfrac{|4(1+a) - 3b + 21|}{5} = 5\ \Longrightarrow\ |4a - 3b + 25| = 25. \]
$4a - 3b + 25 = 25$\ 또는 $4a - 3b + 25 = -25$\ 이므로 $4a - 3b = 0$\ 또는 $4a - 3b = -50$.

$a$,\ $b$\ 가 양수이므로 뒤의 경우 $4a - 3b = -50$\ 은 $b$\ 가 상당히 커야 하는데, $a^2+b^2=25$\ 에서 $b \le 5$\ 이므로 $4a - 3b \ge -15$. 따라서 $4a - 3b = -50$\ 은 불가능하다.

$4a - 3b = 0$\ 에서 $b = \dfrac{4a}{3}$\ 이고 $a^2 + b^2 = 25$\ 에 대입하면
\[ a^2 + \dfrac{16a^2}{9} = 25\ \Longrightarrow\ \dfrac{25a^2}{9} = 25\ \Longrightarrow\ a^2 = 9. \]
양수 조건에서 $a = 3$,\ $b = 4$\ 이므로 $\therefore\ a + b + r = 3 + 4 + 5 = 12$.

\begin{dmcriticalpoint}
\dmcplabel{조건 (가)는 두 중심 사이의 거리가 반지름과 같음을 의미하고, 조건 (나)는 두 중심이 같은 거리를 두고 직선에 접함을 의미한다}: 두 조건을 결합하면 반지름을 먼저 구할 수 있어 나머지 미지수를 순차로 결정할 수 있다.
\end{dmcriticalpoint}

% Q19 · 6점 · 학평 · 대칭이동과 외접원 (verbatim_kichul)

\dmsoltitle{19}{대칭이동과 두 삼각형의 외접원 반지름 곱}
\begin{dmanswerbox}
정답: ③ $32$
\end{dmanswerbox}

점 $\mathrm{A}(a,\,2)$\ 를 직선 $y = x$\ 에 대하여 대칭이동한 점은 $\mathrm{B}(2,\,a)$,\ 점 $\mathrm{B}$\ 를 $x$\ 축에 대하여 대칭이동한 점은 $\mathrm{C}(2,\,-a)$\ 이다.

먼저 삼각형 $\mathrm{ABC}$\ 의 외접원 반지름 $r_1$\ 을 구한다. $\mathrm{B}$\ 와 $\mathrm{C}$\ 는 $x$\ 좌표가 $2$\ 로 같으므로 선분 $\overline{\mathrm{BC}}$\ 는 세로 선분 $x = 2$\ 위에 있고, 이 선분의 수직이등분선은 가로 직선 $y = 0$\ 이다. 한편 $\mathrm{A}$\ 와 $\mathrm{B}$\ 는 직선 $y = x$\ 에 대하여 서로 대칭이므로 $\overline{\mathrm{AB}}$\ 의 수직이등분선은 곧 직선 $y = x$\ 이다.

두 수직이등분선의 교점이 외심이므로 외심은 $y = x$\ 와 $y = 0$\ 의 교점 $\mathrm{O}_1(0,\,0)$,\ 즉 원점이다. 따라서
\[ r_1 = \overline{\mathrm{O}_1\mathrm{A}} = \sqrt{a^2 + 4}. \]

다음으로 삼각형 $\mathrm{AOC}$\ 의 외접원 반지름 $r_2$\ 를 구한다. 세 꼭짓점은 $\mathrm{A}(a,\,2)$,\ $\mathrm{O}(0,\,0)$,\ $\mathrm{C}(2,\,-a)$\ 이다.

직선 $\mathrm{OA}$\ 의 기울기는 $\dfrac{2}{a}$,\ 직선 $\mathrm{OC}$\ 의 기울기는 $\dfrac{-a}{2}$\ 이므로 두 기울기의 곱은
\[ \dfrac{2}{a} \times \dfrac{-a}{2} = -1. \]
따라서 $\overline{\mathrm{OA}} \perp \overline{\mathrm{OC}}$\ 이고, 삼각형 $\mathrm{AOC}$\ 는 $\mathrm{O}$\ 에서 직각인 직각삼각형이다.

직각삼각형에서 외접원의 반지름은 빗변의 절반과 같으므로 빗변 $\overline{\mathrm{AC}}$\ 의 길이의 절반이 $r_2$\ 이다.
\[ \overline{\mathrm{AC}}^{\,2} = (a-2)^2 + (a+2)^2 = 2a^2 + 8. \]
따라서
\[ r_2 = \dfrac{\sqrt{2a^2 + 8}}{2} = \dfrac{\sqrt{2}\,\sqrt{a^2 + 4}}{2}. \]

두 반지름의 곱은
\[ r_1 \cdot r_2 = \sqrt{a^2 + 4} \cdot \dfrac{\sqrt{2}\,\sqrt{a^2 + 4}}{2} = \dfrac{\sqrt{2}\,(a^2 + 4)}{2}. \]
$r_1 \cdot r_2 = 18\sqrt{2}$\ 이므로
\[ \dfrac{\sqrt{2}\,(a^2 + 4)}{2} = 18\sqrt{2}\ \Longrightarrow\ a^2 + 4 = 36\ \Longrightarrow\ \therefore\ a^2 = 32. \]

\begin{dmcriticalpoint}
\dmcplabel{$\mathrm{AOC}$\ 가 원점에서 직각인 삼각형이므로 외접원의 반지름은 빗변 $\overline{\mathrm{AC}}$\ 의 절반이다}: 대칭이동으로 옮긴 세 점의 위치 관계를 이용하면 두 외접원의 반지름을 좌표 계산 없이 짧게 구할 수 있다.
\end{dmcriticalpoint}

% Q20 · 6점 · 학평 · 원 위의 점과 삼각형의 넓이 (verbatim_kichul)

\dmsoltitle{20}{원 위 점에서 삼각형 넓이가 자연수가 될 조건}
\begin{dmanswerbox}
정답: ③ $12$
\end{dmanswerbox}

두 점 $\mathrm{A}(0,\,\sqrt{3})$,\ $\mathrm{B}(1,\,0)$\ 을 지나는 직선의 방정식은
\[ \dfrac{x-0}{1-0} = \dfrac{y - \sqrt{3}}{0 - \sqrt{3}}\ \Longrightarrow\ \sqrt{3}\,x + y - \sqrt{3} = 0. \]
$\overline{\mathrm{AB}}$\ 의 길이는
\[ \overline{\mathrm{AB}} = \sqrt{1 + 3} = 2. \]

원 $C: (x-1)^2 + (y-10)^2 = 9$\ 의 중심을 $\mathrm{Q}(1,\,10)$,\ 반지름을 $3$\ 이라 하자. 원 위의 점 $\mathrm{P}$\ 에서 직선 $\mathrm{AB}$\ 까지의 거리를 $h$\ 라 하면 삼각형 $\mathrm{ABP}$\ 의 넓이는
\[ S = \dfrac{1}{2} \cdot \overline{\mathrm{AB}} \cdot h = h. \]

중심 $\mathrm{Q}$\ 에서 직선 $\mathrm{AB}$\ 까지의 거리는
\[ d = \dfrac{|\sqrt{3} \cdot 1 + 10 - \sqrt{3}|}{\sqrt{3 + 1}} = \dfrac{10}{2} = 5. \]
원 위의 점 $\mathrm{P}$\ 에서 이 직선까지의 거리 $h$\ 는 $\mathrm{P}$\ 가 원 위를 움직일 때 $d - 3 \le h \le d + 3$,\ 곧 $2 \le h \le 8$\ 이다.

넓이 $S = h$\ 가 자연수가 되려면 $h$\ 는 $2,\,3,\,4,\,5,\,6,\,7,\,8$\ 중 하나이다.

각 $h$\ 값에 대해 대응하는 점 $\mathrm{P}$\ 의 개수를 살펴본다. 중심 $\mathrm{Q}$\ 를 지나고 직선 $\mathrm{AB}$\ 에 수직인 지름을 그리면 이 지름의 양 끝점에서 직선까지의 거리가 각각 $d + 3 = 8$,\ $d - 3 = 2$\ 로 최대와 최소이다. 그 사이의 $h$\ 값 $3,\,4,\,5,\,6,\,7$\ 각각에 대하여 원 위의 대응하는 점은 좌·우 대칭인 두 점씩 존재한다.

따라서 $h = 2$\ 일 때 $1$\ 개,\ $h = 8$\ 일 때 $1$\ 개,\ $h = 3,\,4,\,5,\,6,\,7$\ 일 때 각각 $2$\ 개씩이므로 모두 합하면 $1 + 1 + 5 \cdot 2 = \therefore\ 12$.

\begin{dmcriticalpoint}
\dmcplabel{직선까지의 거리가 넓이를 결정하므로 원 위 점을 세는 문제는 거리 $h$\ 가 가능한 값의 개수와 각 값에 대응하는 점의 개수 문제로 옮겨진다}: 최대·최소 거리에서는 대응 점이 각 $1$\ 개, 그 사이 값에서는 각 $2$\ 개임에 주의하여 세어야 한다.
\end{dmcriticalpoint}
