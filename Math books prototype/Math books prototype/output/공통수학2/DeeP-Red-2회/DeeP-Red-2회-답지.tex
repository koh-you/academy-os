\soltitle{1}{③ $24$}{5}

직선 $y = x + 1$ 위의 점을 $\mathrm{P}(a,\ a + 1)$로 놓자. 두 점 $\mathrm{A}(-2,\ 3)$, $\mathrm{B}(4,\ 5)$과의 거리제곱을 각각 계산하면
\[ \overline{\mathrm{AP}}^{\,2} = (a+2)^{2} + (a-2)^{2}, \]
\[ \overline{\mathrm{BP}}^{\,2} = (a-4)^{2} + (a-4)^{2}. \]

두 값을 더해 정리한다.
\[ \overline{\mathrm{AP}}^{\,2} + \overline{\mathrm{BP}}^{\,2} = 4a^{2} - 16a + 40 = 4(a - 2)^{2} + 24. \]

$a = 2$일 때 최솟값 $24$를 얻는다.

% ─────────────── #2 ───────────────
\soltitle{2}{③ $2\sqrt{10}$}{5}

각 근호 안의 식을 완전제곱으로 정리하면
\[ x^{2} + y^{2} + 8x - 6y + 25 = (x+4)^{2} + (y-3)^{2}, \]
\[ x^{2} + y^{2} - 4x - 2y + 5 = (x-2)^{2} + (y-1)^{2}. \]

따라서 주어진 식은 점 $(x, y)$에서 두 고정된 점 $\mathrm{A}(-4,\ 3)$, $\mathrm{B}(2,\ 1)$까지의 거리의 합이다. 두 거리의 합의 최솟값은 두 점 사이의 거리이므로
\[ \overline{\mathrm{AB}}^{\,2} = 6^{2} + 2^{2} = 40. \]
따라서 $\overline{\mathrm{AB}} = 2\sqrt{10}$.

% ─────────────── #3 ───────────────
\soltitle{3}{③ $5$}{5}

두 점 $\mathrm{A}(-10,\ -8)$, $\mathrm{B}(8,\ 4)$에 대하여 $x$좌표의 변화량은 $\Delta x = 8 - (-10) = 18$, $y$좌표의 변화량은 $\Delta y = 4 - (-8) = 12$이다. $18$과 $12$의 최대공약수는 $6$이다.

선분 $\mathrm{AB}$를 $6$ 등분하는 각 등분점의 좌표는
\[ \left(-10 + 3t,\ -8 + 2t\right)\quad (t = 0,\ 1,\ 2,\ \dots,\ 6) \]
로 모두 격자점이다. 총 $7$개의 격자점 중 양 끝점 $\mathrm{A}$($t = 0$)와 $\mathrm{B}$($t = 6$)를 제외하면 $7 - 2 = 5$개.

% ─────────────── #4 ───────────────
\soltitle{4}{③ $142$}{5}

$A = \{a, b, c, d\}$ (서로 다른 네 양수)의 두 원소를 뽑아 합·곱을 만든다. 서로 다른 두 원소의 쌍은 ${}_{4}\mathrm{C}_{2} = 6$가지이므로 $B$, $C$의 원소가 각각 $6$개인 것과 부합한다.

$B = \{7,\ 9,\ 10,\ 12,\ 13,\ 15\}$에서 두 원소 합의 최솟값 $7$은 두 최소 원소의 합, 최댓값 $15$는 두 최대 원소의 합이다. 원소를 $a < b < c < d$라 하면 $a + b = 7$이고 $c + d = 15$이다.

또한 $C = \{10,\ 14,\ 16,\ 35,\ 40,\ 56\}$의 두 원소 곱의 최솟값 $10$은 $ab$, 최댓값 $56$은 $cd$이므로 $ab = 10$이고 $cd = 56$이다.

$a + b = 7$과 $ab = 10$에서 $a$, $b$는 이차방정식 $t^{2} - 7t + 10 = 0$의 두 근이므로 $\{a, b\} = \{2,\ 5\}$. $c + d = 15$와 $cd = 56$에서 $c$, $d$는 $t^{2} - 15t + 56 = 0$의 두 근이므로 $\{c, d\} = \{7,\ 8\}$. 따라서 $(a, b, c, d) = (2, 5, 7, 8)$.

$B$·$C$의 나머지 값도 확인하면 $2 + 7 = 9$, $2 + 8 = 10$, $5 + 7 = 12$, $5 + 8 = 13$, $7 + 8 = 15$이고 $2 \cdot 7 = 14$, $2 \cdot 8 = 16$, $5 \cdot 7 = 35$, $5 \cdot 8 = 40$, $7 \cdot 8 = 56$으로 모두 일치.

따라서
\[ a^{2} + b^{2} + c^{2} + d^{2} = 4 + 25 + 49 + 64 = 142. \]

\soltitle{5}{① $-2$}{5}

$A \subset B$와 $B \subset A$가 동시에 성립하므로 $A = B$. 두 집합 $A = \{2,\ a^{2} + 2\}$와 $B = \{6,\ a^{2} + a\}$가 서로 같으려면 $\{2,\ a^{2}+2\} = \{6,\ a^{2}+a\}$.

원소 $2$가 $B$에 있어야 하므로 $a^{2} + a = 2$, 즉 $a^{2} + a - 2 = 0$이고 $(a+2)(a-1) = 0$에서 $a = -2$ 또는 $a = 1$.

또한 원소 $6$이 $A$에 있어야 하므로 $a^{2} + 2 = 6$, 즉 $a^{2} = 4$이고 $a = \pm 2$.

두 조건을 동시에 만족하는 값은 $a = -2$.

% ─────────────── #6 ───────────────
\soltitle{6}{③ $36$}{5}

조건 (나)에서 $A^{c} \cap B^{c} = (A \cup B)^{c} = \{1, 2, 10\}$이므로
\[ A \cup B = U - \{1,\ 2,\ 10\} = \{3,\ 4,\ 5,\ 6,\ 7,\ 8,\ 9\}. \]
$S(A \cup B) = 3 + 4 + 5 + 6 + 7 + 8 + 9 = 42$.

조건 (가)에서 $A \cap B = \{5,\ 7\}$이므로 $S(A \cap B) = 12$. 원소의 합에 대한 포함배제에 의해
\[ S(A) + S(B) = S(A \cup B) + S(A \cap B) = 54. \]

조건 (다) $S(A) = 2 S(B)$를 이용하면 $3 S(B) = 54$, 즉 $S(B) = 18$이고
\[ S(A) = 36. \]

% ─────────────── #7 ───────────────
\soltitle{7}{③ $5$}{5}

원 $x^{2} + y^{2} - 4x + 2y - 11 = 0$을 표준형으로 정리하면
\[ (x - 2)^{2} + (y + 1)^{2} = 16. \]
중심은 $\mathrm{C}(2,\ -1)$.

원의 넓이를 두 직선으로 $4$ 등분하려면 두 직선이 모두 원의 중심 $\mathrm{C}$를 지나고 서로 수직이어야 한다.

직선 $y = ax$가 $\mathrm{C}(2,\ -1)$을 지나므로 $-1 = 2a$, 즉 $a = -\dfrac{1}{2}$.

직선 $y = bx + c$도 $\mathrm{C}(2,\ -1)$을 지나므로 $-1 = 2b + c$. 두 직선이 수직이려면 $ab = -1$이므로 $-\dfrac{1}{2} b = -1$에서 $b = 2$. 그러면 $c = -1 - 2 \cdot 2 = -5$.

$abc$의 값은
\[ \left(-\dfrac{1}{2}\right) \cdot 2 \cdot (-5) = 5. \]

% ─────────────── #8 ───────────────
\soltitle{8}{③ $-1$}{6}

직선 $mx - y - 2m - 3 = 0$을 $m$에 대해 정리하면
\[ m(x - 2) - (y + 3) = 0. \]
$m$의 값에 관계없이 성립하려면 $x - 2 = 0$이고 $y + 3 = 0$이므로 이 직선은 항상 점 $\mathrm{Q}(2,\ -3)$을 지난다.

점 $\mathrm{Q}(2,\ -3)$은 사각형 $\mathrm{ABCD}$($y$ 범위 $1 \le y \le 3$) 아래쪽에 있다. 이 점을 지나는 직선이 사각형과 만나는 극단은 사각형의 꼭짓점을 지날 때이다.

$\mathrm{Q}$에서 네 꼭짓점까지의 기울기를 각각 구한다.
\begin{itemize}[leftmargin=1.2em, itemsep=1pt]
\item $\mathrm{A}(-2, 3)$: $\dfrac{3-(-3)}{-2-2} = -\dfrac{3}{2}$
\item $\mathrm{B}(-4, 1)$: $\dfrac{1-(-3)}{-4-2} = -\dfrac{2}{3}$
\item $\mathrm{C}(3, 1)$: $\dfrac{1-(-3)}{3-2} = 4$
\item $\mathrm{D}(6, 3)$: $\dfrac{3-(-3)}{6-2} = \dfrac{3}{2}$
\end{itemize}

$\mathrm{Q}$에서 사각형이 놓인 위쪽을 바라볼 때 왼쪽 끝 방향은 꼭짓점 $\mathrm{B}$까지의 기울기 $-\dfrac{2}{3}$, 오른쪽 끝 방향은 꼭짓점 $\mathrm{D}$까지의 기울기 $\dfrac{3}{2}$이다. 두 극단 사이(예: $m = 0$)에서는 직선이 사각형 아래를 수평에 가깝게 지나 사각형과 만나지 못한다.

따라서 사각형과 만나는 조건은 $m \ge \dfrac{3}{2}$ 또는 $m \le -\dfrac{2}{3}$. 즉 $p = \dfrac{3}{2}$, $q = -\dfrac{2}{3}$이고
\[ pq = \dfrac{3}{2} \cdot \left(-\dfrac{2}{3}\right) = -1. \]

% ─────────────── #9 ───────────────
\soltitle{9}{⑤ $2\pi$}{6}

무게중심 $\mathrm{G}$의 좌표를 $(X,\ Y)$로 놓자. 세 점 $\mathrm{A}(4,\ -1)$, $\mathrm{B}(-1,\ -5)$, $\mathrm{P}(a,\ b)$의 무게중심이 $\mathrm{G}$이므로
\[ X = \dfrac{4 + (-1) + a}{3},\quad Y = \dfrac{-1 + (-5) + b}{3}. \]
$a$, $b$에 대하여 정리하면
\[ a = 3X - 3,\quad b = 3Y + 6. \]

점 $\mathrm{P}(a,\ b)$가 원 $x^{2} + y^{2} = 9$ 위를 움직이므로 $a^{2} + b^{2} = 9$이다. 대입하면
\[ (3X - 3)^{2} + (3Y + 6)^{2} = 9. \]
양변을 $9$로 나누면
\[ (X - 1)^{2} + (Y + 2)^{2} = 1. \]

따라서 $\mathrm{G}$는 중심 $(1,\ -2)$, 반지름 $1$인 원 위를 움직이고, 이 원의 둘레(도형의 길이)는
\[ 2\pi \cdot 1 = 2\pi. \]

% ─────────────── #10 ───────────────
\soltitle{10}{③ $5$}{6}

명제 $p \to q$가 참이려면 조건 $p$의 진리집합 $[-1,\ 3]$의 모든 원소가 부등식 $ax^{2} + 2ax - 4 \le 0$을 만족해야 한다. $f(x) = ax^{2} + 2ax - 4 = a(x+1)^{2} - a - 4$로 놓고 $a$의 부호로 나눈다.

\solpart{i} $a = 0$: $f(x) = -4 \le 0$이 모든 $x$에서 성립. 조건 만족.

\solpart{ii} $a > 0$: $f$는 아래로 열린 포물선. 꼭짓점 $x = -1$이 최소, 범위 $-1 \le x \le 3$ 위 최댓값은 $x = 3$에서 $f(3) = 9a + 6a - 4 = 15a - 4$.
$15a - 4 \le 0$이려면 $a \le \dfrac{4}{15}$. 양의 정수 $a$는 없음.

\solpart{iii} $a < 0$: $f$는 위로 열린 포물선. 꼭짓점 $x = -1$이 범위 $-1 \le x \le 3$에 속하므로 이 범위 위 최댓값은 꼭짓점에서 $f(-1) = -a - 4$.
$-a - 4 \le 0$이려면 $a \ge -4$. 음의 정수 $a$는 $a = -1,\ -2,\ -3,\ -4$.

세 경우를 합하면 정수 $a = -4,\ -3,\ -2,\ -1,\ 0$의 다섯 개.

% ─────────────── #11 ───────────────
\soltitle{11}{③ $31$}{6}

$n(A \cap B)$의 최댓값과 최솟값을 구한다.

\solpart{i} 최댓값: 교집합은 각 집합의 부분집합이므로 $n(A \cap B) \le n(A) = 27$이고 $n(A \cap B) \le n(B) = 22$. 두 부등식에서
\[ n(A \cap B) \le 22. \]
$B \subset A$일 때 등호가 성립한다.

\solpart{ii} 최솟값: 합집합의 크기는 전체집합의 크기 이하이므로 $n(A \cup B) \le 40$. 원소의 개수에 대한 포함배제에서
\[ n(A \cap B) = n(A) + n(B) - n(A \cup B). \]
따라서 $n(A \cap B) \ge 27 + 22 - 40 = 9$.
$A \cup B = U$일 때 등호가 성립한다.

따라서 최댓값과 최솟값의 합은 $22 + 9 = 31$.

% ─────────────── #12 ───────────────
\soltitle{12}{④ $2\pi + 4$}{6}

원 $x^{2} + y^{2} - 4y = 0$의 표준형은 $x^{2} + (y-2)^{2} = 4$이므로 중심 $(0, 2)$, 반지름 $2$. $x$축으로 $3$, $y$축으로 $1$만큼 평행이동하면 원 $C$는 중심 $\mathrm{C}(3, 3)$, 반지름 $2$이다. 중심 $\mathrm{C}$에서 직선 $x - y - 2 = 0$까지의 거리는
\[ d = \dfrac{|3 - 3 - 2|}{\sqrt{2}} = \sqrt{2}. \]

수선의 발을 $\mathrm{M}$, 현의 끝점을 $\mathrm{A}$, $\mathrm{B}$라 하면 직각삼각형 $\mathrm{CMA}$에서 $\overline{\mathrm{MA}} = \sqrt{r^{2} - d^{2}} = \sqrt{2}$이다. $\overline{\mathrm{CM}} = \overline{\mathrm{MA}} = \sqrt{2}$이므로 이등변 직각삼각형이고 $\angle\mathrm{ACM} = 45^\circ$, 따라서 중심각 $\angle\mathrm{ACB} = 90^\circ$.

중심각 $90^\circ$ 부채꼴의 넓이는 $\dfrac{1}{4}\pi r^{2} = \pi$이고, 직각을 낀 두 변이 $r = 2$인 직각삼각형 $\mathrm{CAB}$의 넓이는 $\dfrac{1}{2}\cdot 2\cdot 2 = 2$. 따라서 작은 활꼴 넓이 $S_{\text{작}} = \pi - 2$, 큰 부분 $S_{\text{큰}} = 4\pi - (\pi - 2) = 3\pi + 2$이므로
\[ S_{\text{큰}} - S_{\text{작}} = 2\pi + 4. \]

% ─────────────── #13 ───────────────
\soltitle{13}{$33$}{6}

$n(A^{c} \cap B^{c} \cap C) = n(C - (A \cup B))$이다. 원소의 개수에 대해 다음이 성립한다.
\[ n(A \cup B \cup C) = n(A \cup B) + n(C - (A \cup B)). \]

즉
\[ n(A^{c} \cap B^{c} \cap C) = n(A \cup B \cup C) - n(A \cup B). \]
$n(A \cup B \cup C) = 40$이므로 $n(A^{c} \cap B^{c} \cap C) = 40 - n(A \cup B)$.

이제 $n(A \cup B)$의 범위를 구한다.

\solpart{1} 최솟값: $n(A \cup B) \ge \max\{n(A),\ n(B)\} = 17$. $A \subset B$일 때 등호가 성립.

\solpart{2} 최댓값: $n(A \cup B) \le n(A) + n(B) = 30$이고 $n(A \cup B) \le n(A \cup B \cup C) = 40$이므로 $n(A \cup B) \le 30$. $A \cap B = \varnothing$일 때 등호가 성립.

따라서 $17 \le n(A \cup B) \le 30$이고 $n(A^{c} \cap B^{c} \cap C) = 40 - n(A \cup B)$이므로
\[ 10 \le 40 - n(A \cup B) \le 23. \]

$M = 23$, $m = 10$이므로
\[ M + m = 23 + 10 = 33. \]

③ \cplabel{두 중심을 모두 사용해야 한다}: 수직이등분선 위 $\mathrm{M}$의 양쪽에 각각 중심이 존재하므로 두 값의 합을 구해야 한다.%
