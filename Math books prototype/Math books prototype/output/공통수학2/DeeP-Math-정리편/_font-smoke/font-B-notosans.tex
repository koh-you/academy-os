\dmex{1}{중심이 직선 위에 있고 두 점을 지나는 원}

\begin{dmproblem}
중심이 직선 $y = 3x - 5$ 위에 있고 두 점 $(1,\, 2)$,\ $(5,\, -2)$를 지나는 원의 방정식을 구하시오.
\end{dmproblem}

\begin{dmapproach}
중심이 직선 $y = 3x - 5$ 위에 있으므로 중심의 좌표를 $(a,\, 3a - 5)$로 놓는다. 원 위의 두 점에서 중심까지의 거리가 같음을 이용하여 $a$의 값을 구한다.
\end{dmapproach}

\begin{dmsolution}
원의 중심을 $\mathrm{C}(a,\, 3a - 5)$라 하면 두 점 $(1,\, 2)$,\ $(5,\, -2)$에서 $\mathrm{C}$까지의 거리는 서로 같으므로
\begin{equation*}
  (a - 1)^2 + (3a - 7)^2 = (a - 5)^2 + (3a - 3)^2
\end{equation*}
양변을 전개하여 정리하면
\begin{equation*}
  10a^2 - 44a + 50 = 10a^2 - 28a + 34
\end{equation*}
\begin{equation*}
  16a = 16
\end{equation*}
이므로 $a = 1$이고, 중심은 $\mathrm{C}(1,\, -2)$, 반지름의 제곱은
\begin{equation*}
  r^2 = (1 - 1)^2 + (2 + 2)^2 = 16
\end{equation*}
따라서 구하는 원의 방정식은
\begin{equation*}
  (x - 1)^2 + (y + 2)^2 = 16
\end{equation*}
\dmanswer{$(x - 1)^2 + (y + 2)^2 = 16$}
\end{dmsolution}
