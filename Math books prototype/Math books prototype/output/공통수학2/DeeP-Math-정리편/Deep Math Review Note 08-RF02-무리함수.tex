\dmsub{1}{무리식의 뜻과 성질}

근호 안에 문자가 포함된 식 가운데 유리식으로 나타낼 수 없는 식을 \dmstrong{무리식}이라 한다.

예를 들어 $\sqrt{x + 1}$,\ $\dfrac{1}{\sqrt{x} - 1}$과 같은 식은 무리식이다.

무리식의 값이 실수가 되려면
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item 근호 안의 식의 값이 $0$ 이상이어야 한다.
  \item 분모에 있는 무리식은 $0$이 되면 안 된다.
\end{itemize}
따라서 무리식 $\sqrt{f(x)}$의 값이 실수가 되도록 하는 $x$의 값의 범위는 $f(x) \ge 0$\ 을 만족시키는 $x$의 값의 범위이다.

\dmsub{2}{분모의 유리화}

분모에 무리식이 있을 때 분자와 분모에 $0$이 아닌 같은 무리식을 곱하여 분모를 유리식으로 바꾸는 것을 \dmstrong{분모의 유리화}라 한다. 이때 다음과 같은 켤레무리식을 곱하는 것이 편리하다.
\begin{equation*}
  \frac{1}{\sqrt{a} + \sqrt{b}} = \frac{\sqrt{a} - \sqrt{b}}{(\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b})} = \frac{\sqrt{a} - \sqrt{b}}{a - b} \quad (a \ne b)
\end{equation*}
$\sqrt{a} + \sqrt{b}$와 $\sqrt{a} - \sqrt{b}$처럼 서로 곱하여 유리식이 되는 두 무리식을 서로 \dmstrong{켤레무리식}이라 한다.

\dmsub{3}{무리식의 사칙연산}

무리식의 덧셈과 뺄셈은 통분한 뒤 분자를 정리하고, 곱셈과 나눗셈은 분자와 분모를 각각 곱하거나 유리화한 뒤 정리한다. 계산 결과에 무리식이 포함된 경우 결과의 분모는 항상 유리화하여 나타낸다.

\begin{dmnote}
$\sqrt{a} \times \sqrt{b} = \sqrt{ab}$는 $a \ge 0$,\ $b \ge 0$일 때만 성립한다. 근호 안의 부호와 정의역 조건을 반드시 함께 확인한다.
\end{dmnote}

\dmsub{4}{조건식과 무리식의 값}

$x + y$,\ $xy$처럼 대칭식이 조건으로 주어지면 구하려는 무리식을 그 대칭식의 꼴로 변형한 뒤 대입한다. 유리화가 필요한 경우에는 먼저 켤레무리식을 곱하여 근호를 정리한 뒤 조건을 대입한다.

\end{dmconcept}

\dmex{1}{무리식의 유리화와 값 계산}

\begin{dmproblem}
$x = \sqrt{3}$\ 일 때, $\dfrac{\sqrt{x + 1} - \sqrt{x - 1}}{\sqrt{x + 1} + \sqrt{x - 1}}$의 값을 구하시오.
\end{dmproblem}

\begin{dmapproach}
분모의 켤레무리식 $\sqrt{x + 1} - \sqrt{x - 1}$\ 을 분자와 분모에 곱하여 유리화한다. 정리한 결과에 $x = \sqrt{3}$\ 을 대입한다.
\end{dmapproach}

\begin{dmsolution}
분자와 분모에 켤레무리식 $\sqrt{x + 1} - \sqrt{x - 1}$\ 을 곱하면 분모는 $(x + 1) - (x - 1) = 2$이고, 분자는
\begin{equation*}
  (\sqrt{x + 1} - \sqrt{x - 1})^{2} = 2x - 2\sqrt{x^{2} - 1}
\end{equation*}
이므로 주어진 식은 $x - \sqrt{x^{2} - 1}$이다.

$x = \sqrt{3}$\ 에서 $x^{2} - 1 = 2$이므로
\begin{equation*}
  x - \sqrt{x^{2} - 1} = \sqrt{3} - \sqrt{2}
\end{equation*}
\dmanswer{$\sqrt{3} - \sqrt{2}$}
\end{dmsolution}

\dmex{2}{무리식의 유리화로 인접 항이 상쇄되는 합}

\begin{dmproblem}
함수 $f(x) = \dfrac{1}{\sqrt{x} + \sqrt{x + 1}}$에 대하여 $f(1) + f(2) + f(3) + \cdots + f(99)$의 값을 구하시오.
\end{dmproblem}

\begin{dmapproach}
각 항을 유리화하면 두 제곱근의 차의 꼴이 되어 이웃한 항끼리 소거된다. 첫 항과 마지막 항만 남기고 값을 정리한다.
\end{dmapproach}

\begin{dmsolution}
분자와 분모에 $\sqrt{x + 1} - \sqrt{x}$를 곱하여 유리화하면 $f(x) = \sqrt{x + 1} - \sqrt{x}$이다.

이웃한 항끼리 소거되므로
\begin{align*}
  f(1) + f(2) + \cdots + f(99)
  &= (\sqrt{2} - \sqrt{1}) + (\sqrt{3} - \sqrt{2}) + \cdots + (\sqrt{100} - \sqrt{99}) \\
  &= \sqrt{100} - \sqrt{1} = 9
\end{align*}
\dmanswer{$9$}
\end{dmsolution}

\begin{dmconcept}{2}{무리함수와 그래프}
% dmconcept-auto-tune (v1.0)
\setlength{\parskip}{1.8mm plus 1.9mm minus 0mm}\linespread{1.27}\selectfont%

\dmsub{1}{무리함수의 뜻과 정의역}

$y$가 $x$에 대한 무리식으로 나타나는 함수를 \dmstrong{무리함수}라 한다. 무리함수에서 정의역이 명시되지 않을 때는 근호 안의 식의 값이 $0$ 이상이 되도록 하는 $x$의 값 전체의 집합을 정의역으로 삼는다.

예를 들어 $y = \sqrt{2x - 4}$의 정의역은 $2x - 4 \ge 0$, 즉 $x \ge 2$인 실수 전체이다.

\dmsub{2}{$y = \sqrt{x}$의 그래프}

무리함수 $y = \sqrt{x}$는 이차함수 $y = x^{2}$ ($x \ge 0$)의 역함수이다. 두 그래프는 직선 $y = x$에 대하여 서로 대칭이다.
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item 정의역은 $x \ge 0$인 실수, 치역은 $y \ge 0$인 실수 전체이다.
  \item 원점 $\mathrm{O}$에서 시작하여 오른쪽으로 갈수록 증가하는 곡선이다.
  \item $x$의 값이 커지면 곡선의 기울기는 완만해진다.
\end{itemize}

\dmsub{3}{$y = \sqrt{ax}$의 그래프 ($a \ne 0$)}

$a > 0$이면 무리함수 $y = \sqrt{ax}$의 그래프는 원점에서 시작하여 제 $1$ 사분면에 있는 곡선이다. $a < 0$이면 정의역이 $x \le 0$이 되어 그래프는 원점에서 시작해 왼쪽으로 뻗어 나가는 제 $2$ 사분면 위의 곡선이 된다.

또한 $y = -\sqrt{x}$의 그래프는 $y = \sqrt{x}$의 그래프를 $x$축에 대하여 대칭이동한 것이고, $y = \sqrt{-x}$의 그래프는 $y$축에 대하여 대칭이동한 것이다. $y = -\sqrt{-x}$의 그래프는 두 대칭이동을 모두 거친 것으로 원점 대칭이다.

\dmsub{4}{$y = \sqrt{a(x - p)} + q$의 표준형}

무리함수 $y = \sqrt{a(x - p)} + q$의 그래프는 $y = \sqrt{ax}$의 그래프를 $x$축의 방향으로 $p$만큼, $y$축의 방향으로 $q$만큼 평행이동한 것이다. 따라서
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item 그래프의 시작점은 $(p,\, q)$이다.
  \item $a > 0$이면 시작점에서 오른쪽 위로 뻗어 나가고, $a < 0$이면 왼쪽 위로 뻗어 나간다.
  \item 정의역과 치역은 시작점과 그래프의 방향에서 바로 읽을 수 있다.
\end{itemize}

\begin{dmnote}
일반형 $y = \sqrt{ax + b} + q$가 주어지면 근호 안을 $a(x - p)$의 꼴로 정리하여 시작점 $(p,\, q)$를 먼저 찾는 것이 계산의 출발점이다. 정의역과 치역은 이 시작점만 잡으면 그림 없이도 결정된다.
\end{dmnote}

\end{dmconcept}

\dmex{3}{무리함수의 정의역, 치역, 시작점}

\begin{dmproblem}
다음 무리함수의 정의역, 치역을 각각 구하고 그래프의 시작점의 좌표를 구하시오.

\smallskip

$(1)\ y = \sqrt{2x + 4} + 1$
\qquad
$(2)\ y = -\sqrt{2 - x} - 1$
\end{dmproblem}

\begin{dmapproach}
근호 안을 $a(x - p)$의 꼴로 정리하면 무리함수의 표준형 $y = \sqrt{a(x - p)} + q$가 얻어진다. 시작점은 $(p,\, q)$이고, 정의역과 치역은 시작점과 그래프의 방향에서 바로 결정된다.
\end{dmapproach}

\begin{dmsolution}
\dmsubprob{1} $y = \sqrt{2(x + 2)} + 1$이므로 시작점은 $(-2,\, 1)$이고 오른쪽 위로 뻗어 나간다. 따라서
\[ \text{정의역: } \{x \mid x \ge -2\}, \quad \text{치역: } \{y \mid y \ge 1\}. \]

\dmsubprob{2} $y = -\sqrt{-(x - 2)} - 1$이므로 시작점은 $(2,\, -1)$이고 왼쪽 아래로 뻗어 나간다. 따라서
\[ \text{정의역: } \{x \mid x \le 2\}, \quad \text{치역: } \{y \mid y \le -1\}. \]
\dmanswer{\begin{tabular}[t]{@{}l@{}}$(1)$ 정의역 $\{x \mid x \ge -2\}$, 치역 $\{y \mid y \ge 1\}$, 시작점 $(-2,\, 1)$\\[0.4ex] $(2)$ 정의역 $\{x \mid x \le 2\}$, 치역 $\{y \mid y \le -1\}$, 시작점 $(2,\, -1)$\end{tabular}}
\end{dmsolution}

\dmex{4}{시작점과 지나는 점을 이용한 계수 결정}

\begin{dmproblem}
무리함수 $y = -\sqrt{ax + b} + c$의 그래프가 다음 두 조건을 만족시킬 때, 상수 $a$,\ $b$,\ $c$\ 의 값을 각각 구하시오.
\begin{dmoptionbox}
(가) 그래프의 시작점은 $(-2,\, 1)$이다.

(나) 그래프가 점 $(0,\, -1)$을 지난다.
\end{dmoptionbox}
\end{dmproblem}

\begin{dmapproach}
시작점을 표준형에 대입하여 근호 안이 $a(x + 2)$의 꼴이 되도록 정리한 뒤, 지나는 점을 대입하여 남은 상수를 결정한다.
\end{dmapproach}

\begin{dmsolution}
시작점이 $(-2,\, 1)$이므로 표준형을 $y = -\sqrt{a(x + 2)} + 1$\ 로 놓는다.

점 $(0,\, -1)$을 대입하면 $-1 = -\sqrt{2a} + 1$에서 $\sqrt{2a} = 2$,\ $\therefore\ a = 2$.

근호 안을 전개하면 $a(x + 2) = 2x + 4$이므로 $b = 4$,\ $c = 1$이다.
\dmanswer{$a = 2,\ b = 4,\ c = 1$}
\end{dmsolution}

\dmex{5}{무리함수의 그래프와 직선의 위치 관계}

\begin{dmproblem}
무리함수 $y = \sqrt{4 - 2x}$의 그래프와 직선 $y = -x + k$의 위치 관계가 다음과 같도록 하는 상수 $k$의 값 또는 범위를 각각 구하시오.

\vspace{3mm}

\noindent$(1)$ 서로 다른 두 점에서 만난다.\hfill$(2)$ 오직 한 점에서 만난다.\hfill$(3)$ 만나지 않는다.\hfill\null
\end{dmproblem}

\begin{dmapproach}
표준형으로 정리하여 시작점과 그래프의 방향을 파악한 뒤, 직선이 시작점을 지나는 경우와 곡선에 접하는 경우 두 경계를 조사한다. 두 경계 사이의 $k$의 값을 그래프로 비교하여 교점의 개수를 결정한다.
\end{dmapproach}

\begin{dmsolution}
$y = \sqrt{-2(x - 2)}$이므로 시작점은 $(2,\, 0)$이고 왼쪽 위로 뻗는다.

(i) 직선이 시작점 $(2,\, 0)$을 지날 때 : $0 = -2 + k$,\ $\therefore\ k = 2$.

(ii) 직선이 곡선에 접할 때 : $\sqrt{4 - 2x} = -x + k$의 양변을 제곱하면 $x^{2} - (2k - 2)x + k^{2} - 4 = 0$이고, 판별식 $\dfrac{D}{4} = (k - 1)^{2} - (k^{2} - 4) = -2k + 5 = 0$에서 $k = \dfrac{5}{2}$.

\vspace{3mm}

두 경계 $k = 2$,\ $k = \dfrac{5}{2}$\ 를 기준으로 직선을 이동시키며 교점의 개수를 정리하면
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item $2 \le k < \dfrac{5}{2}$\ 일 때 서로 다른 두 점에서 만난다.
  \item $k < 2$ 또는 $k = \dfrac{5}{2}$\ 일 때 한 점에서 만난다.
  \item $k > \dfrac{5}{2}$\ 일 때 만나지 않는다.
\end{itemize}
\dmanswer{$(1)$ $2 \le k < \dfrac{5}{2}$ \quad $(2)$ $k < 2$ 또는 $k = \dfrac{5}{2}$ \quad $(3)$ $k > \dfrac{5}{2}$}
\end{dmsolution}

\dmex{6}{무리함수의 역함수}

\begin{dmproblem}
무리함수 $f(x) = \sqrt{4x - 2} + 1$의 역함수 $f^{-1}(x)$를 구하고, 그 정의역과 치역을 각각 구하시오.
\end{dmproblem}

\begin{dmapproach}
근호를 이항한 뒤 양변을 제곱하여 $x$를 $y$에 대한 식으로 나타낸다. 원래 함수의 치역이 역함수의 정의역, 원래 함수의 정의역이 역함수의 치역이 되는 것을 이용한다.
\end{dmapproach}

\begin{dmsolution}
$f(x)$의 정의역은 $x \ge \dfrac{1}{2}$,\ 치역은 $y \ge 1$이다.

$y - 1 = \sqrt{4x - 2}$의 양변을 제곱하면 $(y - 1)^{2} = 4x - 2$에서 $x = \dfrac{(y - 1)^{2}}{4} + \dfrac{1}{2}$\ 이므로 $x$와 $y$를 바꾸어
\begin{equation*}
  f^{-1}(x) = \dfrac{(x - 1)^{2}}{4} + \dfrac{1}{2}
\end{equation*}

$\therefore$ 정의역 $\{x \mid x \ge 1\}$,\ 치역 $\left\{y \,\middle|\, y \ge \dfrac{1}{2}\right\}$\quad$(\because\ f$의 치역·정의역과 각각 일치$)$.
\dmanswer{\begin{tabular}[t]{@{}l@{}}$f^{-1}(x) = \dfrac{(x - 1)^{2}}{4} + \dfrac{1}{2}$\\[0.4ex] 정의역 $\{x \mid x \ge 1\}$, 치역 $\left\{y \,\middle|\, y \ge \dfrac{1}{2}\right\}$\end{tabular}}
\end{dmsolution}

상수 $a$,\ $b$에 대하여 함수
\begin{equation*}
  f(x) = \begin{cases} -(x - a)^{2} + b & (x \le a) \\ -\sqrt{x - a} + b & (x > a) \end{cases}
\end{equation*}
와 서로 다른 세 실수 $\alpha$,\ $\beta$,\ $\gamma$가 다음 두 조건을 만족시킨다.
\begin{dmoptionbox}
(가) 방정식 $\{f(x) - \alpha\}\{f(x) - \beta\} = 0$을 만족시키는 실수 $x$의 값은 $\alpha$,\ $\beta$,\ $\gamma$뿐이다.

(나) $f(\alpha) = \alpha$,\ $f(\beta) = \beta$
\end{dmoptionbox}
