\begin{dmconcept}{1}{직선의 방정식}
% 세션 86 (마스터 지시) : 좀 더 상세한 기술 · 유도·직관·특수 케이스 확대
\setlength{\parskip}{2.0mm plus 2.1mm minus 0mm}\linespread{1.30}\selectfont%

\dmsub{1}{한 점과 기울기가 주어진 직선}

기울기가 $m$\ 이고 점 $(x_1,\, y_1)$\ 을 지나는 직선의 방정식은
\begin{equation*}
  y - y_1 = m(x - x_1)
\end{equation*}
이다. 이 직선의 $y$절편이 $n$\ 이면 $y = mx + n$의 꼴로 나타나며 이를 직선의 \dmstrong{기울기$\cdot$$y$절편 표준형}이라 한다.

\begin{dmexplain}
기울기 $m$\ 은 $x$\ 가 $1$\ 만큼 증가할 때 $y$\ 의 증가량이며, 직선이 $x$축의 양의 방향과 이루는 각의 크기를 $\theta$\ 라 하면 $m = \tan \theta$\ 이다. 한 점과 기울기가 결정되면 직선이 유일하게 정해진다.
\end{dmexplain}

\begin{dmexample}
점 $(2,\, -1)$\ 을 지나고 기울기가 $3$\ 인 직선의 방정식은 $y + 1 = 3(x - 2)$, 즉 $y = 3x - 7$이다.
\end{dmexample}

\dmsub{2}{두 점을 지나는 직선}

두 점 $\mathrm{A}(x_1,\, y_1)$,\ $\mathrm{B}(x_2,\, y_2)$ ($x_1 \ne x_2$)를 지나는 직선의 기울기는 두 좌표 차이의 비 $\dfrac{y_2 - y_1}{x_2 - x_1}$\ 이고, 방정식은
\begin{equation*}
  y - y_1 = \frac{y_2 - y_1}{x_2 - x_1}(x - x_1)
\end{equation*}
이다. $x_1 = x_2$\ 이면 두 점이 같은 $x$좌표를 가지므로 $y$축에 평행한 직선 $x = x_1$이다.

\begin{dmexample}
두 점 $(1,\, 2)$,\ $(4,\, 8)$\ 을 지나는 직선은 기울기 $\dfrac{8 - 2}{4 - 1} = 2$\ 이므로 $y - 2 = 2(x - 1)$, 즉 $y = 2x$이다.
\end{dmexample}

\dmsub{3}{$x$절편과 $y$절편이 주어진 직선}

$x$절편이 $a$,\ $y$절편이 $b$\ 인 직선 ($a \ne 0$,\ $b \ne 0$)의 방정식은
\begin{equation*}
  \frac{x}{a} + \frac{y}{b} = 1
\end{equation*}
이다. 이 식을 절편형이라 한다.

\begin{dmnote}
절편형은 두 점 $(a,\, 0)$,\ $(0,\, b)$를 지나는 직선의 방정식을 두 점 공식으로 정리해 얻는다. 좌표축에 평행한 직선은 절편형이 정의되지 않아 $y = c$나 $x = c$\ 꼴로 따로 다룬다.
\end{dmnote}

\vspace{45.0mm}% dmconcept-auto-tune vspace (v2.0)
\end{dmconcept}

\dmex{1}{내분점과 한 점을 지나는 직선}

\begin{dmproblem}
두 점 $\mathrm{A}(7,\, -3)$,\ $\mathrm{B}(2,\, -8)$을 이은 선분 $\overline{\mathrm{AB}}$를 $3 : 2$로 내분하는 점과 점 $(5,\, 2)$를 지나는 직선의 방정식을 구하시오.
\end{dmproblem}

\begin{dmapproach}
먼저 내분점의 좌표를 내분점 공식으로 구한 뒤, 그 점과 주어진 다른 한 점을 지나는 직선의 방정식을 두 점 공식으로 세운다.
\end{dmapproach}

\begin{dmsolution}
선분 $\overline{\mathrm{AB}}$를 $3 : 2$로 내분하는 점의 좌표는
\begin{equation*}
  \left( \frac{3 \cdot 2 + 2 \cdot 7}{5},\ \frac{3 \cdot (-8) + 2 \cdot (-3)}{5} \right) = (4,\, -6).
\end{equation*}
두 점 $(4,\, -6)$,\ $(5,\, 2)$의 기울기는 $\dfrac{2-(-6)}{5-4} = 8$이므로 직선은 $y - 2 = 8(x - 5)$이다.

$\therefore\ y = 8x - 38$.
\dmanswer{$y = 8x - 38$}
\end{dmsolution}

\dmex{2}{삼각형의 넓이를 이등분하는 직선}

\begin{dmproblem}
세 점 $\mathrm{A}(-2,\, 4)$,\ $\mathrm{B}(-1,\, 2)$,\ $\mathrm{C}(3,\, 4)$를 꼭짓점으로 하는 삼각형 $\mathrm{ABC}$에서 점 $\mathrm{A}$를 지나고 삼각형 $\mathrm{ABC}$의 넓이를 이등분하는 직선의 방정식을 구하시오.
\end{dmproblem}

\begin{dmapproach}
꼭짓점 $\mathrm{A}$를 지나면서 삼각형의 넓이를 이등분하는 직선은 대변 $\overline{\mathrm{BC}}$의 중점을 지난다. 중선이 삼각형을 밑변이 같고 높이가 같은 두 삼각형으로 나누기 때문이다.
\end{dmapproach}

\begin{dmsolution}
꼭짓점 $\mathrm{A}$\ 를 지나 넓이를 이등분하는 직선은 중선 $\overline{\mathrm{AM}}$\ 이다$\quad(\because\ \text{밑변·높이 동일})$.

중점 $\mathrm{M} = \left( \dfrac{-1+3}{2},\ \dfrac{2+4}{2} \right) = (1,\, 3)$\ 이므로 기울기는 $\dfrac{3-4}{1-(-2)} = -\dfrac{1}{3}$.

$\therefore\ y - 4 = -\dfrac{1}{3}(x+2)$,\ 즉 $y = -\dfrac{1}{3}x + \dfrac{10}{3}$.
\dmanswer{$y = -\dfrac{1}{3}x + \dfrac{10}{3}$}
\end{dmsolution}

\begin{dmconcept}{2}{두 직선의 위치 관계}
% 세션 86 (마스터 지시) : 좀 더 상세한 기술 · dmsub 세분화 + 유도 · 케이스 확대
\setlength{\parskip}{0.2mm plus 0.3mm minus 0mm}\linespread{1.04}\selectfont%

\dmsub{1}{두 직선의 위치 관계}

한 평면 위에서 서로 다른 두 직선의 위치 관계는 다음 세 가지 중 하나이다.
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item \dmstrong{평행하다} : 만나지 않는다.
  \item \dmstrong{일치한다} : 모든 점이 두 직선 위에 있어 하나의 직선처럼 다루어진다.
  \item \dmstrong{한 점에서 만난다}.
\end{itemize}
두 직선의 방정식을 연립한 방정식의 해의 개수가 순서대로 $0$개,\ 무수히 많음,\ 한 개인 경우에 대응한다.

\dmsub{2}{표준형의 평행 조건과 수직 조건}

두 직선 $y = mx + n$과 $y = m'x + n'$에 대하여
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item \dmstrong{평행} $\Longleftrightarrow m = m'$이고 $n \ne n'$
  \item \dmstrong{일치} $\Longleftrightarrow m = m'$이고 $n = n'$
  \item \dmstrong{수직} $\Longleftrightarrow mm' = -1$
\end{itemize}
평행 조건에서 기울기가 같으면 두 직선은 결코 만나지 않거나 완전히 겹치므로 $y$절편의 일치 여부로 두 경우를 가른다.

\begin{dmexplain}
수직 조건 유도: 두 직선을 원점을 지나도록 평행이동해 얻은 $y = mx$,\ $y = m'x$와 직선 $x = 1$의 두 교점 $\mathrm{P}(1, m)$,\ $\mathrm{Q}(1, m')$이 원점 $\mathrm{O}$와 이루는 삼각형에서 $\angle\mathrm{POQ} = 90^\circ$이므로 피타고라스 정리에서 $mm' = -1$이 얻어진다.
\end{dmexplain}

\dmsub{3}{일반형 두 직선의 위치 관계 판별}

두 직선의 방정식이 일반형 $ax + by + c = 0$과 $a'x + b'y + c' = 0$ ($a$,\ $b$가 동시에 $0$은 아님 · $a'$,\ $b'$도 마찬가지) 으로 주어지면 계수 비교로 위치 관계를 판별한다.
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item 평행 : $\dfrac{a}{a'} = \dfrac{b}{b'} \ne \dfrac{c}{c'}$
  \item 일치 : $\dfrac{a}{a'} = \dfrac{b}{b'} = \dfrac{c}{c'}$
  \item 한 점에서 만난다 : $\dfrac{a}{a'} \ne \dfrac{b}{b'}$
  \item 수직 : $aa' + bb' = 0$
\end{itemize}

\begin{dmexample}
$2x - y + 3 = 0$과 $x + 2y - 5 = 0$은 $2 \cdot 1 + (-1) \cdot 2 = 0$이므로 서로 수직이다.
\end{dmexample}

\begin{dmnote}
표준형은 $y$축에 평행한 직선 ($x = a$ 꼴 · 기울기 정의 불가) 을 다루지 못하지만 일반형은 이 경우도 포함해 통합해 판별할 수 있다. 방정식이 일반형으로 주어지면 굳이 표준형으로 바꾸지 말고 계수 비교로 바로 판별하는 편이 안전하다.
\end{dmnote}

\end{dmconcept}

\dmex{3}{수직이등분선의 방정식}

\begin{dmproblem}
두 점 $\mathrm{A}(-1,\, 3)$,\ $\mathrm{B}(3,\, -5)$를 이은 선분 $\overline{\mathrm{AB}}$의 수직이등분선의 방정식이 $x + ay + b = 0$일 때, 상수 $a$,\ $b$에 대하여 $ab$의 값을 구하시오.
\end{dmproblem}

\begin{dmapproach}
수직이등분선은 선분의 중점을 지나고 원래 선분에 수직이다. 중점의 좌표를 구하고, 직선 $\mathrm{AB}$의 기울기의 음의 역수를 기울기로 하는 직선의 방정식을 세운다.
\end{dmapproach}

\begin{dmsolution}
중점 $\mathrm{M} = (1,\, -1)$,\ 기울기 $\dfrac{-5-3}{3-(-1)} = -2$에서 수직이등분선의 기울기는 $\dfrac{1}{2}$이다.

방정식은 $y + 1 = \dfrac{1}{2}(x - 1)$,\ 즉 $x - 2y - 3 = 0$.

$x + ay + b = 0$과 비교하면 $a = -2$,\ $b = -3$이므로 $ab = 6$.
\dmanswer{$6$}
\end{dmsolution}

\dmex{4}{세 직선이 삼각형을 이루지 않을 조건}

\begin{dmproblem}
세 직선 $x - y = 0$,\ $x + y = 2$,\ $5x - ky = 15$가 삼각형을 이루지 않도록 하는 상수 $k$의 값을 모두 구하시오.
\end{dmproblem}

\begin{dmapproach}
세 직선이 삼각형을 이루지 않는 경우는 (i) 어느 두 직선이 서로 평행하거나 (ii) 세 직선이 한 점에서 만나는 경우이다. 두 경우로 나누어 $k$의 값을 모두 찾는다.
\end{dmapproach}

\begin{dmsolution}
세 직선 $l_1 : x - y = 0$,\ $l_2 : x + y = 2$,\ $l_3 : 5x - ky = 15$\ 의 기울기는 각각 $1$,\ $-1$,\ $\dfrac{5}{k}$\ 이다$\quad(k \ne 0)$.

\dmemph{(i) 두 직선이 평행한 경우} $l_3 \mathbin{/\!/} l_1$: $\dfrac{5}{k} = 1$이므로 $k = 5$. $l_3 \mathbin{/\!/} l_2$: $\dfrac{5}{k} = -1$이므로 $k = -5$.

\dmemph{(ii) 세 직선이 한 점에서 만나는 경우} 두 직선 $l_1$과 $l_2$의 교점 $(1,\, 1)$이 $l_3$ 위에 있으면 $5 - k = 15$이므로 $k = -10$.

$\therefore\ k = 5$ 또는 $k = -5$ 또는 $k = -10$.
\dmanswer{$k = 5$,\ $k = -5$,\ $k = -10$}
\end{dmsolution}

\begin{dmconcept}{3}{점과 직선 사이의 거리}
% 세션 85 (마스터 지시) : 정점·삼각형 넓이 응용 삭제 · dmconceptcont 8p 폐기 · 1p 통합

\dmsub{1}{점과 직선 사이의 거리}

좌표평면 위의 점 $\mathrm{P}$에서 이 점을 지나지 않는 직선 $\ell$에 내린 수선의 발을 $\mathrm{H}$라 할 때, 선분 $\overline{\mathrm{PH}}$의 길이를 점 $\mathrm{P}$와 직선 $\ell$ 사이의 거리라 한다. 점 $\mathrm{P}(x_1,\, y_1)$과 직선 $ax + by + c = 0$ 사이의 거리 $d$는
\begin{equation*}
  d = \frac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}
\end{equation*}
이다. 특히 원점과 직선 $ax + by + c = 0$ 사이의 거리는 $\dfrac{|c|}{\sqrt{a^2 + b^2}}$이다.

\begin{dmexplain}
공식을 사용하기 위해서는 직선의 방정식을 반드시 $ax + by + c = 0$의 꼴로 먼저 정리한다. 직선이 $y = mx + n$의 꼴이면 $mx - y + n = 0$으로 옮겨 계수 $a = m$,\ $b = -1$,\ $c = n$을 대입한다. 분모 $\sqrt{a^2 + b^2}$은 직선의 법선벡터 $(a, b)$의 길이이고, 분자 $|ax_1 + by_1 + c|$의 부호는 점이 직선의 어느 쪽에 놓이는지를 나타내므로 두 점이 같은 부호이면 두 점이 직선을 기준으로 같은 쪽에 있다.
\end{dmexplain}

\begin{dmexample}
점 $(2,\, -1)$\ 과 직선 $3x + 4y - 1 = 0$ 사이의 거리는 $\dfrac{|3 \cdot 2 + 4 \cdot (-1) - 1|}{\sqrt{9 + 16}} = \dfrac{1}{5}$이다.
\end{dmexample}

\begin{dmexample}
원점과 직선 $2x - y + 5 = 0$ 사이의 거리는 $\dfrac{|5|}{\sqrt{4 + 1}} = \sqrt{5}$이다. 직선이 $y = mx + n$의 꼴이면 $mx - y + n = 0$으로 옮겨 대입한다.
\end{dmexample}

\dmsub{2}{평행한 두 직선 사이의 거리}

두 직선 $\ell$,\ $\ell'$이 평행할 때 한 직선 위 임의의 점과 나머지 직선 사이의 거리는 어느 점을 택해도 항상 같다. 이 값을 두 직선 사이의 거리라 하며, 좌표가 간단한 점 (좌표축과의 교점 등) 을 택해 점과 직선 사이의 거리 공식을 그대로 적용해 얻는다.

\begin{dmexample}
두 평행 직선 $3x + 4y + 1 = 0$,\ $3x + 4y - 9 = 0$에서 첫 직선 위의 점 $\left(-\dfrac{1}{3},\, 0\right)$을 택해 둘째 직선까지의 거리는 $\dfrac{|3 \cdot (-1/3) + 4 \cdot 0 - 9|}{\sqrt{9 + 16}} = 2$이다.
\end{dmexample}

\begin{dmnote}
두 평행 직선의 방정식이 $x$,\ $y$의 계수까지 완전히 같은 꼴 $ax + by + c = 0$,\ $ax + by + c' = 0$으로 정리되어 있으면 첫 직선 위 좌표가 간단한 점을 대입한다. 두 직선의 계수가 다르면 한쪽 방정식을 상수배해 계수를 맞춘 뒤 진행하면 된다.
\end{dmnote}

\dmex{5}{점과 직선 사이의 거리의 조건}

\begin{dmproblem}
점 $(2,\, 3)$과 직선 $y = \dfrac{3}{4}x + \dfrac{k}{2}$ 사이의 거리가 $2$일 때, 모든 상수 $k$의 값의 합을 구하시오.
\end{dmproblem}

\begin{dmapproach}
주어진 직선을 일반형 $ax + by + c = 0$으로 정리한 뒤, 점과 직선 사이의 거리 공식에 대입한다. 절댓값 방정식이 얻어지므로 부호에 따라 두 근이 나오고, 두 근의 합은 계수 관계로부터 바로 얻어진다.
\end{dmapproach}

\begin{dmsolution}
주어진 직선을 정리하면 $3x - 4y + 2k = 0$\ 이다. 점 $(2,\, 3)$\ 과 이 직선 사이의 거리는
\begin{equation*}
  \frac{|3 \cdot 2 - 4 \cdot 3 + 2k|}{\sqrt{3^2 + 4^2}} = \frac{|2k - 6|}{5} = 2
\end{equation*}
에서 $|2k - 6| = 10$,\ 즉 $2k - 6 = \pm 10$\ 이므로 $k = 8$ 또는 $k = -2$.

$\therefore$ 모든 $k$의 합 $= 6$.
\dmanswer{$k$의 값의 합은 $6$}
\end{dmsolution}

\end{dmsolution}

좌표평면의 제 $1$ 사분면에 있는 두 점 $\mathrm{A}$,\ $\mathrm{B}$와 원점 $\mathrm{O}$에 대하여 삼각형 $\mathrm{OAB}$의 무게중심 $\mathrm{G}$의 좌표는 $(8,\, 4)$이고, 점 $\mathrm{B}$와 직선 $\mathrm{OA}$ 사이의 거리는 $6\sqrt{2}$이다. 다음은 직선 $\mathrm{OB}$의 기울기가 직선 $\mathrm{OA}$의 기울기보다 클 때, 직선 $\mathrm{OA}$의 기울기를 구하는 과정이다.

\begin{dmoptionbox}
선분 $\overline{\mathrm{OA}}$의 중점을 $\mathrm{M}$이라 하자.

점 $\mathrm{G}$가 삼각형 $\mathrm{OAB}$의 무게중심이므로 $\overline{\mathrm{BG}} : \overline{\mathrm{GM}} = 2 : 1$이고, 점 $\mathrm{B}$와 직선 $\mathrm{OA}$ 사이의 거리가 $6\sqrt{2}$이므로 점 $\mathrm{G}$와 직선 $\mathrm{OA}$ 사이의 거리는 \dmemph{(가)}이다.

직선 $\mathrm{OA}$의 기울기를 $m$이라 하면 점 $\mathrm{G}$와 직선 $\mathrm{OA}$ 사이의 거리는
\begin{equation*}
  \frac{\text{\dmemph{(나)}}}{\sqrt{m^2 + (-1)^2}}
\end{equation*}
이고, \dmemph{(가)}와 같다. 즉,
\begin{equation*}
  \text{\dmemph{(나)}} = \text{\dmemph{(가)}} \times \sqrt{m^2 + 1}
\end{equation*}
이다. 양변을 제곱하여 $m$의 값을 구하면 $m$에 관한 이차방정식의 두 근이 얻어진다. 이때 직선 $\mathrm{OG}$의 기울기가 $\dfrac{1}{2}$이므로 직선 $\mathrm{OA}$의 기울기는 \dmemph{(다)}이다.
\end{dmoptionbox}

\vspace{3mm}

위의 (가), (다)에 알맞은 수를 각각 $p$,\ $q$라 하고, (나)에 알맞은 식을 $f(m)$이라 할 때, $\dfrac{f(q)}{p^2}$의 값을 구하시오.
