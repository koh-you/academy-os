% ─────────────── 확인 1 ───────────────
\dmsoltitle{1}{점 통과와 기울기 조건 결합}
\begin{dmanswerbox}
정답: $m+n=5$
\end{dmanswerbox}

$x$\ 축의 양의 방향과 이루는 각의 크기가 $45^{\circ}$\ 인 직선의 기울기는 $1$\ 이므로 $m - 2 = 1$\ 에서 $m = 3$\ 이다. 이 직선이 점 $(2,\, -1)$\ 을 지나므로
\[ -1 = 1 \cdot 2 - n - 1 = 1 - n \]
에서 $n = 2$\ 이다. 따라서 $m + n = 5$\ 이다.

% ─────────────── 확인 2 ───────────────
\dmsoltitle{2}{내분점·중점을 지나는 직선의 $x$\ 절편}
\begin{dmanswerbox}
정답: $x$\ 절편 $= 2$
\end{dmanswerbox}

선분 $\overline{\mathrm{AB}}$\ 의 $2 : 1$ 내분점 $\mathrm{P}$\ 의 좌표는
\[ \left( \dfrac{2 \cdot 5 + 1 \cdot (-1)}{3},\ \dfrac{2 \cdot 0 + 1 \cdot 3}{3} \right) = (3,\, 1) \]
이고 선분 $\overline{\mathrm{BC}}$\ 의 중점 $\mathrm{Q}$\ 의 좌표는 $\left( 1,\, -1 \right)$\ 이다. 두 점을 지나는 직선의 기울기는 $\dfrac{1-(-1)}{3-1} = 1$\ 이므로 방정식은 $y - 1 = 1 \cdot (x - 3)$, 즉 $y = x - 2$\ 이다. $y = 0$\ 을 대입하면 $x$\ 절편은 $2$\ 이다.

% ─────────────── 확인 3 ───────────────
\dmsoltitle{3}{꼭짓점과 대변 중점을 지나는 직선의 계수합}
\begin{dmanswerbox}
정답: $a+b=-7$
\end{dmanswerbox}

꼭짓점 $\mathrm{A}$\ 를 지나면서 삼각형 $\mathrm{ABC}$\ 의 넓이를 이등분하는 직선은 대변 $\overline{\mathrm{BC}}$\ 의 중점 $\mathrm{M}$\ 을 지난다. $\mathrm{M}$\ 의 좌표는
\[ \left( \dfrac{5+(-1)}{2},\ \dfrac{-5+1}{2} \right) = (2,\, -2). \]
두 점 $\mathrm{A}(3,\, 3)$\ 과 $\mathrm{M}(2,\, -2)$\ 를 지나는 직선의 기울기는 $\dfrac{-2-3}{2-3} = 5$\ 이므로 방정식은
\[ y - 3 = 5(x - 3),\quad \text{즉}\quad y = 5x - 12. \]
따라서 $a = 5$,\ $b = -12$\ 이고 $a + b = -7$\ 이다.

% ─────────────── 확인 4 ───────────────
\dmsoltitle{4}{절편형과 절편 조건}
\begin{dmanswerbox}
정답: $y=-\dfrac{1}{2}x-1$
\end{dmanswerbox}

$y$\ 절편을 $b$($b \ne 0$)라 하면 $x$\ 절편은 $2b$\ 이므로 절편형 $\dfrac{x}{2b} + \dfrac{y}{b} = 1$\ 에 점 $(6,\, -4)$\ 를 대입하면
\[ \dfrac{6}{2b} + \dfrac{-4}{b} = -\dfrac{1}{b} = 1 \quad\therefore\ b = -1. \]
$x$\ 절편은 $-2$\ 이므로 방정식은 $\dfrac{x}{-2} + \dfrac{y}{-1} = 1$, 곧 $y = -\dfrac{1}{2}x - 1$\ 이다.

% ─────────────── 확인 5 ───────────────
\dmsoltitle{5}{수직 조건과 $y$\ 절편}
\begin{dmanswerbox}
정답: $y$\ 절편 $= \dfrac{5}{3}$
\end{dmanswerbox}

직선 $3x - y + 2 = 0$\ 의 기울기는 $3$\ 이므로 수직인 직선의 기울기는 $-\dfrac{1}{3}$\ 이다. 점 $(2,\, 1)$\ 을 지나므로 방정식은
\[ y - 1 = -\dfrac{1}{3}(x - 2),\quad \text{즉}\quad y = -\dfrac{1}{3}x + \dfrac{5}{3}. \]
따라서 $y$\ 절편은 $\dfrac{5}{3}$\ 이다.

% ─────────────── 확인 6 ───────────────
\dmsoltitle{6}{수직이등분선의 방정식}
\begin{dmanswerbox}
정답: $y=-2x+4$
\end{dmanswerbox}

선분 $\overline{\mathrm{AB}}$\ 의 중점 $\mathrm{M}$\ 의 좌표는 $\left( \dfrac{-1+3}{2},\ \dfrac{1+3}{2} \right) = (1,\, 2)$\ 이다. 직선 $\mathrm{AB}$\ 의 기울기는 $\dfrac{3-1}{3-(-1)} = \dfrac{1}{2}$\ 이므로 수직이등분선의 기울기는 $-2$\ 이다. 방정식은
\[ y - 2 = -2(x - 1),\quad \text{즉}\quad y = -2x + 4. \]

% ─────────────── 확인 7 ───────────────
\dmsoltitle{7}{세 직선이 삼각형을 이루지 않을 조건 · 경우 분석}
\begin{dmanswerbox}
정답: $a$\ 의 값의 합 $= -2$
\end{dmanswerbox}

세 직선 $l_1 : 2x + y + 1 = 0$,\ $l_2 : x - y + 2 = 0$,\ $l_3 : ax - y = 0$\ 의 기울기는 각각 $-2$,\ $1$,\ $a$\ 이다.

\dmemph{(i) 두 직선이 평행한 경우} $l_3$\ 와 $l_1$\ 이 평행: $a = -2$. $l_3$\ 와 $l_2$\ 가 평행: $a = 1$. 두 경우 모두 $l_3$\ 의 $y$\ 절편 $0$\ 이 나머지 두 직선의 $y$\ 절편과 다르므로 실제로 평행한 서로 다른 직선이다.

\dmemph{(ii) 세 직선이 한 점에서 만나는 경우} $l_1$\ 과 $l_2$\ 의 교점은 $2x + y = -1$\ 과 $x - y = -2$\ 를 더해 $3x = -3$, 즉 $(-1,\, 1)$\ 이다. 이 점을 $l_3$\ 가 지나면 $-a - 1 = 0$\ 에서 $a = -1$\ 이다.

세 값의 합은 $-2 + 1 + (-1) = -2$\ 이다.

% ─────────────── 확인 8 ───────────────
\dmsoltitle{8}{세 직선이 이루는 직각삼각형 조건}
\begin{dmanswerbox}
정답: $a$\ 의 값의 합 $= -\dfrac{5}{4}$
\end{dmanswerbox}

세 직선 $l_1 : x + 2y - 6 = 0$,\ $l_2 : 4x - 3y - 12 = 0$,\ $l_3 : ax + y - 1 = 0$\ 에서 $l_1$\ 과 $l_2$\ 는 이미 $1 \cdot 4 + 2 \cdot (-3) = -2 \ne 0$\ 이므로 서로 수직이 아니다. 따라서 직각삼각형이 되려면 $l_3$\ 가 $l_1$ 또는 $l_2$\ 와 수직이어야 한다.

$l_3 \perp l_1$: $a \cdot 1 + 1 \cdot 2 = 0$\ 에서 $a = -2$\ 이다.
$l_3 \perp l_2$: $a \cdot 4 + 1 \cdot (-3) = 0$\ 에서 $a = \dfrac{3}{4}$\ 이다.

따라서 합은 $-2 + \dfrac{3}{4} = -\dfrac{5}{4}$\ 이다.

% ─────────────── 확인 9 ───────────────
\dmsoltitle{9}{평행한 두 직선 사이의 거리}
\begin{dmanswerbox}
정답: $k$\ 의 값의 합 $= 2$
\end{dmanswerbox}

직선 $x + 2y + 1 = 0$ 위의 한 점 $(-1,\, 0)$\ 을 잡으면, 이 점과 직선 $x + 2y + k = 0$ 사이의 거리는
\[ \dfrac{|-1 + k|}{\sqrt{1 + 4}} = \dfrac{|k - 1|}{\sqrt{5}}. \]
이 값이 $4\sqrt{5}$\ 이므로 $|k - 1| = 20$\ 이고 $k = 21$ 또는 $k = -19$\ 이다. 두 값의 합은 $2$\ 이다.

% ─────────────── 확인 10 ───────────────
\dmsoltitle{10}{수직 조건 + 원점 거리 조건}
\begin{dmanswerbox}
정답: $4x-3y+5=0$ 또는 $4x-3y-5=0$
\end{dmanswerbox}

직선 $3x + 4y + 1 = 0$\ 의 방향과 수직인 직선의 방정식은 $4x - 3y + c = 0$ 꼴이다. 원점으로부터의 거리가 $1$\ 이므로
\[ \dfrac{|c|}{\sqrt{16 + 9}} = 1,\quad \dfrac{|c|}{5} = 1,\quad c = \pm 5. \]
따라서 방정식은 $4x - 3y + 5 = 0$ 또는 $4x - 3y - 5 = 0$\ 이다.

% ─────────────── 확인 11 ───────────────
\dmsoltitle{11}{세 점 삼각형 넓이 조건으로 미지수 결정}
\begin{dmanswerbox}
정답: $a = 5$ 또는 $a = -\dfrac{17}{3}$
\end{dmanswerbox}

$\overline{\mathrm{AB}} = \sqrt{(3-1)^2 + (-1-2)^2} = \sqrt{13}$\ 이고 직선 $\mathrm{AB}$\ 의 기울기가 $-\dfrac{3}{2}$\ 이므로 방정식은 $3x + 2y - 7 = 0$\ 이다. 점 $\mathrm{C}(a,\, 4)$\ 와 이 직선 사이의 거리는
\[ h = \dfrac{|3a + 8 - 7|}{\sqrt{13}} = \dfrac{|3a + 1|}{\sqrt{13}}. \]
넓이는 $S = \dfrac{1}{2} \cdot \sqrt{13} \cdot h = \dfrac{|3a+1|}{2} = 8$\ 에서 $|3a + 1| = 16$\ 이므로 $a = 5$ 또는 $a = -\dfrac{17}{3}$\ 이다.

% ─────────────── 확인 12 ───────────────
\dmsoltitle{12}{수선의 발 좌표의 곱}
\begin{dmanswerbox}
정답: $ab=6$
\end{dmanswerbox}

직선 $x + 3y - 9 = 0$\ 의 기울기는 $-\dfrac{1}{3}$\ 이므로 이 직선에 수직이고 점 $\mathrm{A}(6,\, 11)$\ 을 지나는 직선의 기울기는 $3$\ 이다. 방정식은
\[ y - 11 = 3(x - 6),\quad \text{즉}\quad 3x - y - 7 = 0. \]
$y = 3x - 7$\ 을 $x + 3y - 9 = 0$\ 에 대입하면 $x + 3(3x - 7) - 9 = 0$\ 에서 $10x = 30$\ 이므로 $x = 3$\ 이고 $y = 2$\ 이다. 따라서 $\mathrm{H}(3,\, 2)$\ 이고 $ab = 6$\ 이다.

\end{multicols*}

% ─────────────── L1-1 ───────────────
\dmsoltitle{1}{중점을 지나는 직선과 좌표축이 이루는 삼각형}
\begin{dmanswerbox}
정답: $S=\dfrac{32}{3}$
\end{dmanswerbox}

두 점 $(-4,\, 2),\ (6,\, 8)$\ 의 중점의 좌표는 $(1,\, 5)$\ 이다. 이 점을 지나고 기울기가 $-3$\ 인 직선의 방정식은
\[ y - 5 = -3(x - 1),\quad y = -3x + 8. \]
이 직선의 $x$\ 절편은 $3x = 8$\ 에서 $\dfrac{8}{3}$\ 이고 $y$\ 절편은 $8$\ 이므로 점 $\mathrm{P}\!\left( \dfrac{8}{3},\, 0 \right)$,\ $\mathrm{Q}(0,\, 8)$\ 이다. 따라서
\[ S = \dfrac{1}{2} \cdot \dfrac{8}{3} \cdot 8 = \dfrac{32}{3}. \]

% ─────────────── L1-2 ───────────────
\dmsoltitle{2}{절편형과 절편의 합 조건 · 좌표축과 이루는 넓이}
\begin{dmanswerbox}
정답: $S=18$
\end{dmanswerbox}

$x$\ 절편을 $a$ ($a \ne 0$)라 하면 $y$\ 절편은 $-a$\ 이므로 절편형에서
\[ \dfrac{x}{a} + \dfrac{y}{-a} = 1,\quad \text{즉}\quad x - y = a. \]
점 $(-2,\, 4)$\ 를 지나므로 $-2 - 4 = a$\ 에서 $a = -6$\ 이다. 이 직선의 $x$\ 절편은 $-6$,\ $y$\ 절편은 $6$\ 이므로 두 좌표축과 이 직선으로 둘러싸인 삼각형의 넓이는
\[ S = \dfrac{1}{2} \cdot |{-6}| \cdot |6| = 18. \]

% ─────────────── L1-3 ───────────────
\dmsoltitle{3}{무게중심과 한 꼭짓점을 지나는 직선}
\begin{dmanswerbox}
정답: $y=-x+1$
\end{dmanswerbox}

삼각형 $\mathrm{ABC}$\ 의 무게중심 $\mathrm{G}$\ 의 좌표는
\[ \left( \dfrac{2+(-3)+7}{3},\ \dfrac{4+(-1)+(-6)}{3} \right) = (2,\, -1) \]
이다. 두 점 $\mathrm{G}(2,\, -1)$\ 과 $\mathrm{C}(7,\, -6)$\ 을 지나는 직선의 기울기는 $\dfrac{-6-(-1)}{7-2} = -1$\ 이므로 방정식은
\[ y - (-1) = -(x - 2),\quad \text{즉}\quad y = -x + 1. \]

% ─────────────── L1-4 ───────────────
\dmsoltitle{4}{세 점이 한 직선 위에 있을 조건}
\begin{dmanswerbox}
정답: $y=2x+1$
\end{dmanswerbox}

두 점 $\mathrm{A}(1,\, 3)$,\ $\mathrm{B}(a,\, 5)$\ 를 지나는 직선의 기울기와 두 점 $\mathrm{A}(1,\, 3)$,\ $\mathrm{C}(3,\, 2a+3)$\ 을 지나는 직선의 기울기가 서로 같아야 하므로
\[ \dfrac{5-3}{a-1} = \dfrac{(2a+3)-3}{3-1} = a. \]
정리하면 $2 = a(a-1)$, 즉 $a^2 - a - 2 = 0$\ 이고 $(a-2)(a+1) = 0$\ 이다. $a > 0$\ 이므로 $a = 2$\ 이다. 기울기는 $2$\ 이고 $\mathrm{A}(1,\, 3)$\ 을 지나므로 방정식은
\[ y - 3 = 2(x - 1),\quad \text{즉}\quad y = 2x + 1. \]

% ─────────────── L1-5 ───────────────
\dmsoltitle{5}{수직과 내분점 결합}
\begin{dmanswerbox}
정답: $y=-3x+2$
\end{dmanswerbox}

직선 $\mathrm{AB}$\ 의 기울기는 $\dfrac{4-1}{6-(-3)} = \dfrac{1}{3}$\ 이므로 수직인 직선의 기울기는 $-3$\ 이다. 선분 $\overline{\mathrm{AB}}$\ 의 $1 : 2$ 내분점의 좌표는
\[ \left( \dfrac{1 \cdot 6 + 2 \cdot (-3)}{3},\ \dfrac{1 \cdot 4 + 2 \cdot 1}{3} \right) = (0,\, 2) \]
이므로 방정식은 $y - 2 = -3(x - 0)$, 즉 $y = -3x + 2$\ 이다.

% ─────────────── L1-6 ───────────────
\dmsoltitle{6}{평행 · 통과 · 수직 세 조건에서 세 미지수 결정}
\begin{dmanswerbox}
정답: $a+b+c=2$
\end{dmanswerbox}

직선 $ax - 4y - c = 0$\ 이 $x - 2y - 5 = 0$\ 과 평행하려면 계수비 $\dfrac{a}{1} = \dfrac{-4}{-2}$\ 에서 $a = 2$\ 이다. 이제 직선은 $2x - 4y = c$\ 이고 점 $(3,\, 1)$\ 을 지나므로
\[ 2 \cdot 3 - 4 \cdot 1 = c \quad\therefore\ c = 2. \]
다음으로 $2x - 4y - 2 = 0$\ 이 $4x - by + 3 = 0$\ 과 수직이려면
\[ 2 \cdot 4 + (-4) \cdot (-b) = 8 + 4b = 0 \quad\therefore\ b = -2. \]
$\therefore\ a + b + c = 2 + (-2) + 2 = 2$.

% ─────────────── L1-7 ───────────────
\dmsoltitle{7}{수직이등분선 두 조건에서 두 미지수 결정}
\begin{dmanswerbox}
정답: $a^2+b^2=40$
\end{dmanswerbox}

수직이등분선의 조건은 두 가지이다. 첫째, 선분 $\overline{\mathrm{AB}}$\ 의 중점이 그 직선 위에 있어야 한다. 중점 $\left( \dfrac{a+4}{2},\ \dfrac{2+b}{2} \right)$\ 를 $x + 2y - 5 = 0$\ 에 대입하면
\[ \dfrac{a+4}{2} + (2+b) - 5 = 0,\quad \text{즉}\quad a + 2b = 2. \]
둘째, 직선 $\mathrm{AB}$\ 가 이 수직이등분선과 수직이어야 한다. 수직이등분선의 기울기 $-\dfrac{1}{2}$\ 의 음의 역수 $2$\ 가 직선 $\mathrm{AB}$\ 의 기울기이므로
\[ \dfrac{b-2}{4-a} = 2,\quad \text{즉}\quad 2a + b = 10. \]
두 식을 연립하면 $a = 6$,\ $b = -2$\ 이다. 따라서 $a^2 + b^2 = 36 + 4 = 40$\ 이다.

% ─────────────── L1-8 ───────────────
\dmsoltitle{8}{수직이등분선에 대한 대칭점}
\begin{dmanswerbox}
정답: $\mathrm{B}(3,\,2)$
\end{dmanswerbox}

$\mathrm{B}$\ 는 직선 $x + 3y + 1 = 0$\ 에 대한 점 $\mathrm{A}(1,\, -4)$\ 의 대칭점이므로, $\mathrm{A}$\ 에서 이 직선에 내린 수선의 발을 $\mathrm{H}$\ 라 두고 $\mathrm{H}$\ 가 $\overline{\mathrm{AB}}$\ 의 중점임을 이용한다. 수선의 기울기는 원 직선의 기울기 $-\dfrac{1}{3}$\ 의 음의 역수 $3$\ 이므로 수선의 방정식은
\[ y + 4 = 3(x - 1),\quad 3x - y - 7 = 0. \]
원 직선과 연립하면 $x + 3(3x - 7) + 1 = 0$\ 에서 $x = 2,\ y = -1$\ 이므로 $\mathrm{H}(2,\, -1)$\ 이다. $\mathrm{H}$\ 를 중점으로 대칭시키면
\[ \mathrm{B}_x = 2 \cdot 2 - 1 = 3,\qquad \mathrm{B}_y = 2 \cdot (-1) - (-4) = 2 \]
이므로 $\mathrm{B}(3,\, 2)$\ 이다.

% ─────────────── L1-9 ───────────────
\dmsoltitle{9}{정점을 지나는 직선}
\begin{dmanswerbox}
정답: $2x+y-7=0$
\end{dmanswerbox}

주어진 방정식을 $k$\ 에 대해 정리하면
\[ (2x - y - 5)k + (x + y - 4) = 0 \]
이므로 $k$\ 의 값에 관계없이 항상 지나는 점은 두 방정식 $2x - y - 5 = 0$\ 과 $x + y - 4 = 0$\ 의 해이다. 연립하면 $3x - 9 = 0$\ 에서 $x = 3$\ 이고 $y = 1$\ 이다. 즉 $\mathrm{P}(3,\, 1)$\ 이다. 기울기가 $-2$\ 이고 $\mathrm{P}$\ 를 지나는 직선의 방정식은
\[ y - 1 = -2(x - 3),\quad \text{즉}\quad 2x + y - 7 = 0. \]

% ─────────────── L1-10 ───────────────
\dmsoltitle{10}{한 점에서 두 직선까지의 거리가 같을 조건}
\begin{dmanswerbox}
정답: $a=7$
\end{dmanswerbox}

점 $(a,\, 3)$\ 과 두 직선 $2x - y + 1 = 0$,\ $x + 2y - 1 = 0$ 사이의 거리가 서로 같으므로
\[ \dfrac{|2a - 3 + 1|}{\sqrt{5}} = \dfrac{|a + 6 - 1|}{\sqrt{5}},\quad |2a - 2| = |a + 5|. \]
$2a - 2 = a + 5$\ 에서 $a = 7$\ 이고 $2a - 2 = -(a + 5)$\ 에서 $3a = -3$,\ $a = -1$\ 이다. 양수 조건에서 $a = 7$\ 이다.

% ─────────────── L1-11 ───────────────
\dmsoltitle{11}{세 점을 꼭짓점으로 하는 삼각형의 넓이}
\begin{dmanswerbox}
정답: $S=3$
\end{dmanswerbox}

$\overline{\mathrm{BC}} = \sqrt{(4-2)^2 + (2-0)^2} = 2\sqrt{2}$\ 이고 직선 $\mathrm{BC}$\ 의 기울기가 $1$\ 이므로 방정식은 $x - y - 2 = 0$\ 이다. 점 $\mathrm{A}(3,\, 4)$\ 와 이 직선 사이의 거리는
\[ h = \dfrac{|3 - 4 - 2|}{\sqrt{2}} = \dfrac{3}{\sqrt{2}}. \]
$\therefore\ S = \dfrac{1}{2} \cdot 2\sqrt{2} \cdot \dfrac{3}{\sqrt{2}} = 3$.

% ─────────────── L1-12 ───────────────
\dmsoltitle{12}{내분점을 지나는 수직 직선과 좌표축이 이루는 삼각형}
\begin{dmanswerbox}
정답: $S=36$
\end{dmanswerbox}

선분 $\overline{\mathrm{AB}}$\ 의 $2 : 1$ 내분점 $\mathrm{C}$\ 의 좌표는
\[ \left( \dfrac{2 \cdot 9 + 1 \cdot (-3)}{3},\ \dfrac{2 \cdot (-4) + 1 \cdot 2}{3} \right) = (5,\, -2). \]
직선 $\mathrm{AB}$\ 의 기울기는 $\dfrac{-4-2}{9-(-3)} = -\dfrac{1}{2}$\ 이므로 이 직선에 수직인 직선의 기울기는 $2$\ 이다. $\mathrm{C}$\ 를 지나는 방정식은
\[ y - (-2) = 2(x - 5),\quad \text{즉}\quad y = 2x - 12. \]
$x$\ 절편은 $6$,\ $y$\ 절편은 $-12$\ 이므로 이 직선과 두 좌표축으로 둘러싸인 삼각형의 넓이는 $\dfrac{1}{2} \cdot 6 \cdot 12 = 36$\ 이다.

\dmsoltitle{1}{두 직선의 교점을 지나는 직선}
\begin{dmanswerbox}
정답: $a=9$
\end{dmanswerbox}

두 직선의 교점을 지나는 직선의 방정식을
\[ (3x + 2y - 5) + k(3x + y - 1) = 0 \]
으로 놓으면 이를 정리하여
\[ (3 + 3k)x + (2 + k)y - (5 + k) = 0. \] 이 직선이 $2x - y + 4 = 0$\ 과 수직이려면
\[ (3 + 3k) \cdot 2 + (2 + k) \cdot (-1) = 0,\quad 6 + 6k - 2 - k = 0 \]
에서 $5k = -4$,\ $k = -\dfrac{4}{5}$\ 이다. 대입하면 $\dfrac{3}{5}x + \dfrac{6}{5}y - \dfrac{21}{5} = 0$, 즉 $x + 2y - 7 = 0$\ 이다. 이 직선이 점 $(a,\, -1)$\ 을 지나므로 $a - 2 - 7 = 0$\ 에서 $a = 9$\ 이다.
% ─────────────── L2-2 ───────────────
\dmsoltitle{2}{세 직선이 삼각형을 이루지 않을 조건 · 세 값의 곱}
\begin{dmanswerbox}
정답: $a$\ 의 값의 곱 $= \dfrac{1}{6}$
\end{dmanswerbox}

세 직선 $l_1 : 2x - y = 4$,\ $l_2 : 3x + 2y = -1$,\ $l_3 : x - ay = 0$\ 의 기울기는 각각 $2$,\ $-\dfrac{3}{2}$,\ $\dfrac{1}{a}$\ 이다.

\dmemph{(i) 두 직선이 평행한 경우} $l_3 \mathbin{/\!/} l_1$: $\dfrac{1}{a} = 2$\ 에서 $a = \dfrac{1}{2}$. $l_3 \mathbin{/\!/} l_2$: $\dfrac{1}{a} = -\dfrac{3}{2}$\ 에서 $a = -\dfrac{2}{3}$.

\dmemph{(ii) 세 직선이 한 점에서 만나는 경우} $l_1$\ 과 $l_2$\ 의 교점은 $4x - 2y = 8$,\ $3x + 2y = -1$\ 을 더해 $7x = 7$, 즉 $(1,\, -2)$\ 이다. 이 점을 $l_3$\ 가 지나면 $1 - a \cdot (-2) = 0$\ 에서 $a = -\dfrac{1}{2}$\ 이다.

세 값의 곱은
\[ \dfrac{1}{2} \cdot \left( -\dfrac{2}{3} \right) \cdot \left( -\dfrac{1}{2} \right) = \dfrac{1}{6} \]
이므로 답은 $\dfrac{1}{6}$\ 이다.
% ─────────────── L2-3 ───────────────
\dmsoltitle{3}{평행 · 수직 조건의 두 실수 값}
\begin{dmanswerbox}
정답: $\alpha-\beta=-\dfrac{4}{3}$
\end{dmanswerbox}

두 직선 $l_1 : 2x - ky + 1 = 0$\ 과 $l_2 : (k+1)x - y + k = 0$\ 에 대하여

\dmemph{평행 조건} $\dfrac{2}{k+1} = \dfrac{-k}{-1}$\ 에서 $2 = k(k+1)$,\ $k^2 + k - 2 = 0$,\ $(k+2)(k-1) = 0$\ 이므로 $k = -2$ 또는 $k = 1$\ 이다. 이때 상수항 비 $\dfrac{1}{k}$\ 가 앞의 비와 달라 실제로 평행한 서로 다른 직선이 되는 값을 확인하면 두 값 모두 유효하며 문제 조건에서 $\alpha$\ 가 유일한 값이면 $\alpha = -2$\ 이다.

\dmemph{수직 조건} $2(k+1) + (-k)(-1) = 0$\ 에서 $2k + 2 + k = 0$,\ $3k = -2$\ 이므로 $\beta = -\dfrac{2}{3}$\ 이다.

따라서 $\alpha - \beta = -2 - \left( -\dfrac{2}{3} \right) = -\dfrac{4}{3}$\ 이다.

% ─────────────── L2-4 ───────────────
\dmsoltitle{4}{두 도형의 넓이를 동시에 이등분하는 직선}
\begin{dmanswerbox}
정답: $y=-x+\dfrac{5}{2}$
\end{dmanswerbox}

직사각형의 두 대각선의 교점이 그 도형의 중심이며, 이 중심을 지나는 직선은 그 직사각형의 넓이를 이등분한다. 첫 번째 직사각형의 중심은
\[ \left( \dfrac{-3+0}{2},\ \dfrac{2+6}{2} \right) = \left( -\dfrac{3}{2},\ 4 \right) \]
이고, 두 번째 직사각형의 중심은
\[ \left( \dfrac{3+7}{2},\ \dfrac{-4+(-1)}{2} \right) = \left( 5,\ -\dfrac{5}{2} \right) \]
이다. 두 점을 지나는 직선의 기울기는
\[ \dfrac{-\dfrac{5}{2} - 4}{5 - (-\dfrac{3}{2})} = \dfrac{-\dfrac{13}{2}}{\dfrac{13}{2}} = -1 \]
이고 방정식은 $y - 4 = -\left( x + \dfrac{3}{2} \right)$, 즉 $y = -x + \dfrac{5}{2}$\ 이다.
% ─────────────── L2-5 ───────────────
\dmsoltitle{5}{정점을 지나는 직선과 직사각형의 만남 조건}
\begin{dmanswerbox}
정답: $k=1$
\end{dmanswerbox}

주어진 방정식을 $k$\ 에 대해 정리하면 $k(x + 3) = y + 1$\ 이므로, 실수 $k$\ 에 관계없이 이 직선은 점 $\mathrm{P}(-3,\, -1)$\ 을 항상 지난다. $\mathrm{P}$\ 에서 직사각형의 네 꼭짓점 $(2,1)$, $(3,1)$, $(3,4)$, $(2,4)$\ 를 잇는 기울기는 각각
$$\dfrac{2}{5},\qquad \dfrac{1}{3},\qquad \dfrac{5}{6},\qquad 1$$
이다. 직선이 직사각형과 만나려면 기울기 $k$\ 가 이 네 값 중 최솟값 $\dfrac{1}{3}$\ 과 최댓값 $1$ 사이에 있어야 하므로 최댓값은 $k = 1$\ 이다.

\begin{dmcriticalpoint}
\dmcplabel{정점에서 도형을 훑는 두 극단 기울기가 만남 조건의 경계이다}: 시계 방향과 반시계 방향의 양쪽 극단에서 직선이 도형 경계에 닿을 때가 각각 최솟값·최댓값이다.
\end{dmcriticalpoint}

% ─────────────── L2-6 ───────────────
\dmsoltitle{6}{두 사각형 넓이 차와 두 직선의 기울기 곱}
\begin{dmanswerbox}
정답: $y=-\dfrac{3}{4}x+6$
\end{dmanswerbox}

선분 $\overline{\mathrm{BA}}$\ 는 두 점 $\mathrm{B}(4,\, 6)$,\ $\mathrm{A}(4,\, 0)$\ 을 잇는 $x=4$ 위의 선분이므로 이 위의 두 점을 $\mathrm{D}(4,\, d)$,\ $\mathrm{E}(4,\, e)$($0 < e < d < 6$)로 놓는다. 직선 $\mathrm{OD}$\ 의 기울기는 $\dfrac{d}{4}$\ 이고, 직선 $\mathrm{CE}$\ 는 두 점 $\mathrm{C}(0,\, 6)$\ 과 $\mathrm{E}(4,\, e)$\ 를 지나므로 기울기가 $\dfrac{e - 6}{4}$\ 이다. 두 기울기의 곱이 $-\dfrac{15}{16}$\ 이므로
\[ \dfrac{d}{4} \cdot \dfrac{e - 6}{4} = -\dfrac{15}{16},\quad \text{즉}\quad d(6 - e) = 15. \tag{$\ast$}\]

교점 $\mathrm{F}$\ 의 좌표는 두 직선 $y = \dfrac{d}{4}x$\ 와 $y = 6 + \dfrac{e-6}{4}x$\ 의 연립에서
\[ \dfrac{d - e + 6}{4}\, x_{\mathrm{F}} = 6,\quad x_{\mathrm{F}} = \dfrac{24}{d - e + 6}. \]

직사각형 $\mathrm{OABC}$\ 는 두 직선 $\mathrm{OD}$,\ $\mathrm{CE}$\ 에 의해 네 조각으로 나누어진다. 사각형 $\mathrm{OAEF}$\ 는 삼각형 $\mathrm{OAD}$($=2d$)에서 삼각형 $\mathrm{FDE}$($=\dfrac{1}{2}(d-e)(4-x_{\mathrm{F}})$)를 뺀 부분이고, 사각형 $\mathrm{BCFD}$\ 는 사다리꼴 $\mathrm{OCBD}$($=24-2d$)에서 삼각형 $\mathrm{OCF}$($=3x_{\mathrm{F}}$)를 뺀 부분이다.
넓이 차 조건 $[\mathrm{OAEF}] - [\mathrm{BCFD}] = 4$\ 에 대입하면
\[ 4d - 24 - \dfrac{1}{2}(d - e)(4 - x_{\mathrm{F}}) + 3 x_{\mathrm{F}} = 4. \]

$(\ast)$\ 로부터 $d = \dfrac{15}{6 - e}$\ 를 위 식에 대입해 $e$\ 에 대한 방정식으로 정리하면 $e = 3$\ 이다. 이때 $(\ast)$\ 에서 $d = \dfrac{15}{3} = 5$\ 이므로 $\mathrm{D}(4,\, 5),\ \mathrm{E}(4,\, 3)$\ 이다.

따라서 직선 $\mathrm{CE}$\ 는 두 점 $\mathrm{C}(0,\, 6)$,\ $\mathrm{E}(4,\, 3)$\ 을 지나므로 방정식은
\[ y - 6 = \dfrac{3 - 6}{4 - 0}(x - 0),\quad \text{즉}\quad y = -\dfrac{3}{4}x + 6. \]

\emph{검산}: $\mathrm{OD}$\ 의 기울기 $\dfrac{5}{4}$\ 와 $\mathrm{CE}$\ 의 기울기 $-\dfrac{3}{4}$\ 의 곱은 $-\dfrac{15}{16}$ ($\ast$ 만족). 교점 $x_{\mathrm{F}} = \dfrac{24}{5 - 3 + 6} = 3$,\ $y_{\mathrm{F}} = \dfrac{15}{4}$\ 이므로 $[\mathrm{OAEF}] = 10 - \dfrac{1}{2} \cdot 2 \cdot 1 = 9$,\ $[\mathrm{BCFD}] = 14 - 9 = 5$. 넓이 차는 $9 - 5 = 4$\ 로 조건에 부합한다.

\begin{dmcriticalpoint}
\dmcplabel{두 수직 선분 위의 점은 $y$\ 좌표만 매개변수로 삼아 수직 조건과 넓이 조건을 두 미지수 방정식으로 잇는다}: 선분 $\overline{\mathrm{BA}}$\ 가 $x = 4$ 위에 있으므로 $\mathrm{D}(4,\, d)$·$\mathrm{E}(4,\, e)$\ 로 두면 두 조건이 $d$·$e$\ 의 연립으로 정돈된다.
\end{dmcriticalpoint}

% ─────────────── L2-7 ───────────────
\dmsoltitle{7}{세 직선이 직각삼각형을 이룰 조건}
\begin{dmanswerbox}
정답: $a$\ 의 값의 합 $= -\dfrac{1}{2}$
\end{dmanswerbox}

세 직선 $l_1 : x + 2y = 3$,\ $l_2 : 2x - 3y - 12 = 0$,\ $l_3 : ax + y = 1$\ 에서 $l_1$\ 과 $l_2$\ 의 계수를 이용한 수직 조건 $1 \cdot 2 + 2 \cdot (-3) = -4 \ne 0$\ 이므로 두 직선은 서로 수직이 아니다. 따라서 직각삼각형이 되려면 $l_3$\ 가 $l_1$ 또는 $l_2$\ 와 수직이어야 한다.

$l_3 \perp l_1$: $a \cdot 1 + 1 \cdot 2 = 0$\ 에서 $a = -2$\ 이다.
$l_3 \perp l_2$: $a \cdot 2 + 1 \cdot (-3) = 0$\ 에서 $a = \dfrac{3}{2}$\ 이다.

두 값의 합은 $-2 + \dfrac{3}{2} = -\dfrac{1}{2}$\ 이다.

\begin{dmcriticalpoint}
\dmcplabel{두 고정 직선의 수직 여부를 먼저 확인하면 나머지 한 직선이 어디와 수직이어야 하는지가 정해진다}: 계수 곱합을 사전 확인해 두면 경우 분류가 두 갈래로 자연스럽게 좁혀진다.
\end{dmcriticalpoint}

% ─────────────── L2-8 ───────────────
\dmsoltitle{8}{무게중심을 지나면서 특정 점과의 거리가 최대인 직선}
\begin{dmanswerbox}
정답: $x$\ 절편 $= \dfrac{5}{3}$
\end{dmanswerbox}

삼각형 $\mathrm{ABC}$\ 의 무게중심 $\mathrm{G}$\ 의 좌표는
\[ \left( \dfrac{4+1+(-2)}{3},\ \dfrac{3+5+(-2)}{3} \right) = (1,\, 2) \]
이다. $\mathrm{G}$\ 를 지나는 직선 중 점 $\mathrm{A}(4,\, 3)$\ 과의 거리가 최대인 직선은 $\overline{\mathrm{AG}}$\ 에 수직인 직선이다. 직선 $\mathrm{AG}$\ 의 기울기는 $\dfrac{3-2}{4-1} = \dfrac{1}{3}$\ 이므로 수직인 직선의 기울기는 $-3$\ 이다. 방정식은
\[ y - 2 = -3(x - 1),\quad \text{즉}\quad y = -3x + 5. \]
$y = 0$\ 을 대입하면 $x$\ 절편은 $\dfrac{5}{3}$\ 이다.

\begin{dmcriticalpoint}
\dmcplabel{정점을 지나는 직선에서 외부 고정점까지의 거리 최댓값은 두 점을 잇는 방향에 수직일 때 달성된다}: 기준점과 고정점 사이의 거리는 일정하고, 이 방향에 수직인 순간 그 거리가 그대로 점-직선 거리가 된다.
\end{dmcriticalpoint}

% ─────────────── L2-9 ───────────────
\dmsoltitle{9}{이차함수의 그래프와 직선 사이 거리 최솟값}
\begin{dmanswerbox}
정답: $k=-8$
\end{dmanswerbox}

이차함수의 그래프 위의 점 $\mathrm{P}(t,\, t^2 - 4t + 6)$\ 에서 직선 $2x - y + k = 0$\ 까지의 거리는
\[ d(t) = \dfrac{|2t - (t^2 - 4t + 6) + k|}{\sqrt{5}} = \dfrac{|t^2 - 6t + 6 - k|}{\sqrt{5}}. \]
분자의 이차식 $g(t) = t^2 - 6t + 6 - k = (t - 3)^2 - 3 - k$\ 는 $t = 3$\ 일 때 최솟값 $-3 - k$\ 를 가진다.

직선이 이차함수 그래프보다 아래쪽에 있다는 조건은 $g(t) > 0$\ 이 모든 $t$\ 에서 성립함을 뜻하므로 $-3 - k > 0$,\ 즉 $k < -3$\ 이다. 이때 절댓값을 벗기면 $|g(t)| = g(t)$\ 이므로 $d(t)$\ 의 최솟값은 $t = 3$\ 에서
\[ d_{\min} = \dfrac{-3 - k}{\sqrt{5}} = \sqrt{5}. \]
정리하면 $-3 - k = 5$,\ $k = -8$\ 이며 이는 $k < -3$\ 을 만족한다.

\begin{dmcriticalpoint}
\dmcplabel{곡선과 직선 사이 거리의 최솟값은 접선 조건에서 나온다}: 접선 $y = 2x + t$\ 를 원 이차함수와 연립한 이차방정식 $x^2 - 6x + (6 - t) = 0$\ 의 판별식 $=0$\ 에서 $t = -3$\ 이 나와 접점은 $(3,\, 3)$\ 이며 접선 $y = 2x - 3$\ 과 평행한 직선 $y = 2x + k$ 사이 거리를 계산해도 같은 답에 이른다.
\end{dmcriticalpoint}

% ─────────────── L2-10 ───────────────
\dmsoltitle{10}{두 직선의 자동 수직과 직각이등변삼각형}
\begin{dmanswerbox}
정답: $k+S=17$
\end{dmanswerbox}

두 직선 $kx - y = 0$\ 과 $x + ky = 0$\ 의 일반형 계수를 이용한 수직 조건 $k \cdot 1 + (-1) \cdot k = 0$\ 이 항상 성립하므로 두 직선은 실수 $k$\ 의 값에 관계없이 서로 수직이며, 두 직선 모두 원점을 지난다. 따라서 삼각형 $\mathrm{OAB}$\ 는 $\angle\mathrm{AOB} = 90^{\circ}$\ 인 직각삼각형이다.

$\angle\mathrm{AOB}$\ 를 이등분하는 직선이 선분 $\overline{\mathrm{AB}}$\ 를 수직이등분한다는 조건은 $\overline{\mathrm{OA}} = \overline{\mathrm{OB}}$, 즉 이 직각삼각형이 이등변임을 뜻한다. 두 직선 $y = kx$\ 와 $y = -\dfrac{x}{k}$\ 를 직선 $x + 2y = 10$\ 에 대입해 교점을 구하면
\begin{align*}
  \mathrm{A} &: x + 2kx = 10,\ x = \dfrac{10}{1+2k},\\
  \mathrm{B} &: x - \dfrac{2x}{k} = 10,\ x = \dfrac{10k}{k-2}.
\end{align*}
$\overline{\mathrm{OA}} = \overline{\mathrm{OB}}$\ 에서 원점까지의 거리 제곱이 같으므로
\[ (1+2k)^2 = (k-2)^2 \]
이다. $k < 0$\ 이므로 $1 + 2k = k - 2$\ 에서 $k = -3$\ 이다.

$k = -3$\ 일 때 $\mathrm{A}(-2,\, 6)$\ 이고 $\mathrm{B}(6,\, 2)$\ 이므로 원점까지의 두 거리는 다음과 같다.
\[ \overline{\mathrm{OA}} = \overline{\mathrm{OB}} = 2\sqrt{10}. \]
두 직선이 서로 수직이므로
\[ S = \dfrac{1}{2} \cdot 2\sqrt{10} \cdot 2\sqrt{10} = 20. \]
따라서 $k + S = -3 + 20 = 17$\ 이다.

\begin{dmcriticalpoint}
\dmcplabel{일반형 $kx - y = 0$\ 과 $x + ky = 0$\ 은 $k$ 값과 무관하게 수직이다}: 두 직선의 계수를 대입한 수직 조건 $k \cdot 1 + (-1) \cdot k = 0$\ 이 항상 성립한다.
\end{dmcriticalpoint}

% ─────────────── L2-11 ───────────────
\dmsoltitle{11}{세 직선이 좌표평면을 네 부분으로 나눌 조건}
\begin{dmanswerbox}
정답: $a+b=\dfrac{9}{2}$
\end{dmanswerbox}

서로 다른 세 직선이 좌표평면을 네 부분으로 나누는 것은 세 직선이 모두 서로 평행할 때이다 (두 개는 평행하고 하나만 다른 방향이면 여섯 부분, 세 개가 서로 다른 방향이면 여섯 부분, 한 점에서 만나면 여섯 부분).

세 직선의 기울기가 모두 같아야 하므로 세 방정식 $ax + y + 5 = 0$,\ $2x + by - 4 = 0$,\ $x + 2y + 3 = 0$\ 의 기울기 $-a$,\ $-\dfrac{2}{b}$,\ $-\dfrac{1}{2}$\ 이 서로 같다. 이로부터
\[ -a = -\dfrac{1}{2}\ \Rightarrow\ a = \dfrac{1}{2},\quad -\dfrac{2}{b} = -\dfrac{1}{2}\ \Rightarrow\ b = 4. \]
따라서 $a + b = \dfrac{1}{2} + 4 = \dfrac{9}{2}$\ 이다.

\begin{dmcriticalpoint}
\dmcplabel{좌표평면을 네 부분으로 나누는 경우는 세 직선이 모두 평행할 때뿐이다}: 두 직선만 평행하면 여섯 부분, 세 방향이 모두 다르면 세 교점을 만들어 일곱 부분이 된다.
\end{dmcriticalpoint}

% ─────────────── L2-12 ───────────────
\dmsoltitle{12}{삼각형의 내심과 원점 사이의 거리}
\begin{dmanswerbox}
정답: $\overline{\mathrm{OP}}=\sqrt{34}$
\end{dmanswerbox}

세 변의 길이는
\begin{align*}
  \overline{\mathrm{BC}} &= \sqrt{10^2 + (-5)^2} = 5\sqrt{5},\\
  \overline{\mathrm{CA}} &= \sqrt{4^2 + 8^2} = 4\sqrt{5},\\
  \overline{\mathrm{AB}} &= \sqrt{6^2 + 3^2} = 3\sqrt{5}
\end{align*}
이므로 길이비는 $\overline{\mathrm{BC}} : \overline{\mathrm{CA}} : \overline{\mathrm{AB}} = 5 : 4 : 3$\ 이다. 내심 $\mathrm{P}$\ 의 좌표는 각 꼭짓점 좌표에 대변 길이를 무게로 가중한 평균이므로
\begin{align*}
  \mathrm{P}_x &= \dfrac{5 \cdot 6 + 4 \cdot 0 + 3 \cdot 10}{12} = 5,\\
  \mathrm{P}_y &= \dfrac{5 \cdot 0 + 4 \cdot (-3) + 3 \cdot (-8)}{12} = -3
\end{align*}
이므로 $\mathrm{P}(5,\, -3)$\ 이고 $\overline{\mathrm{OP}} = \sqrt{25 + 9} = \sqrt{34}$\ 이다.

\begin{dmcriticalpoint}
\dmcplabel{좌표평면 위 내심의 좌표는 각 꼭짓점 좌표를 대변 길이로 가중한 평균이다}: 세 변으로부터 같은 거리인 점이 내심이라는 같은 거리 조건이 이 가중 평균으로 표현된다.
\end{dmcriticalpoint}

\dmsoltitle{1}{공통부분을 제외한 넓이 등식과 두 삼각형의 등적}
\begin{dmanswerbox}
정답: $l_2$\ 의 기울기 $=-\dfrac{4}{3}$
\end{dmanswerbox}

두 삼각형 $\mathrm{ACP}$\ 와 $\mathrm{BDP}$\ 가 겹치지 않는 부분이 사각형 $\mathrm{ABDC}$ 안에서 차지하는 넓이를 비교하면, 두 삼각형이 같은 넓이라는 조건은 다음의 등적 조건과 같다.
\[ [\triangle\mathrm{OAB}] = [\triangle\mathrm{OCD}]. \]
왜냐하면 두 삼각형 $\mathrm{OAB}$\ 와 $\mathrm{OCD}$\ 에서 각각 겹치는 사각형 $\mathrm{ABPC}$·$\mathrm{ABDP}$(교차 영역)를 빼면 두 삼각형 $\mathrm{ACP}$·$\mathrm{BDP}$\ 가 나오기 때문이다.

$\overline{\mathrm{OA}} = 2\,\overline{\mathrm{AC}}$\ 이므로 $\mathrm{A}(2a,\, 0)$,\ $\mathrm{C}(3a,\, 0)$\ 이라 두자. $l_1$\ 의 기울기가 $-3$\ 이고 $\mathrm{A}$\ 를 지나므로 $y$\ 절편은 $6a$\ 이고 $\mathrm{B}(0,\, 6a)$\ 이다. 등적 조건 $\dfrac{1}{2} \cdot 2a \cdot 6a = \dfrac{1}{2} \cdot 3a \cdot \overline{\mathrm{OD}}$\ 에서 $\overline{\mathrm{OD}} = 4a$\ 이다. 따라서 $\mathrm{D}(0,\, 4a)$\ 이고 $l_2$\ 의 기울기는
\[ \dfrac{4a - 0}{0 - 3a} = -\dfrac{4}{3}. \]

\begin{dmcriticalpoint}
\dmcplabel{공통 영역을 빼는 관점으로 두 문제 삼각형의 등적을 두 큰 삼각형의 등적으로 바꾼다}: 겹치는 사각형을 각각 빼면 문제의 두 삼각형이 나오므로 등식이 그대로 옮겨간다.
\end{dmcriticalpoint}

\dmsoltitle{2}{자동 수직인 두 직선과 직각이등변삼각형}
\begin{dmanswerbox}
정답: $S=\dfrac{16}{5}$
\end{dmanswerbox}

두 직선 $y = 3x$\ 와 $y = -\dfrac{1}{3}x$\ 의 기울기의 곱은 $-1$\ 이므로 두 직선은 원점에서 서로 수직이다. 세 직선으로 이루는 도형이 이등변삼각형이려면 이 원점 꼭짓점의 각이 밑각이 아닌 꼭지각이 되어야 한다. 이때 도형은 원점을 꼭지각으로 하는 직각이등변삼각형이 된다.

$y = 3x$\ 와 $y = mx + 2$\ 의 교점 $\mathrm{A}$\ 의 좌표는
\[ 3x = mx + 2,\quad x = \dfrac{2}{3 - m},\ y = \dfrac{6}{3 - m} \]
이므로 $\overline{\mathrm{OA}} = \sqrt{10} \cdot \dfrac{2}{|3 - m|}$\ 이다. $y = -\dfrac{1}{3}x$\ 와 $y = mx + 2$\ 의 교점 $\mathrm{B}$\ 의 좌표는
\[ -\dfrac{x}{3} = mx + 2,\quad x = -\dfrac{6}{3m + 1},\ y = \dfrac{2}{3m + 1} \]
이므로 $\overline{\mathrm{OB}} = \sqrt{10} \cdot \dfrac{2}{|3m + 1|}$\ 이다. $\overline{\mathrm{OA}} = \overline{\mathrm{OB}}$\ 에서 $|3 - m| = |3m + 1|$\ 이고 $m > 0$\ 이므로 $3 - m = 3m + 1$($m < 3$\ 의 범위에서)에서 $m = \dfrac{1}{2}$\ 이다.

$m = \dfrac{1}{2}$\ 일 때 $\overline{\mathrm{OA}} = \sqrt{10} \cdot \dfrac{2}{5/2} = \dfrac{4\sqrt{10}}{5}$\ 이고 넓이는
\[ S = \dfrac{1}{2} \cdot \overline{\mathrm{OA}}^{\,2} = \dfrac{1}{2} \cdot \dfrac{160}{25} = \dfrac{16}{5}. \]

\begin{dmcriticalpoint}
\dmcplabel{원점 꼭짓점이 항상 직각이므로 이등변 조건은 곧 직각이등변 조건이다}: 두 직선의 기울기 곱이 $-1$\ 이라 원점 꼭지각은 $90^{\circ}$\ 이고, 이때 $\overline{\mathrm{OA}} = \overline{\mathrm{OB}}$\ 가 이등변 조건이다.
\end{dmcriticalpoint}

\dmsoltitle{3}{거리 제곱의 차 조건과 직선 자취}
\begin{dmanswerbox}
정답: $4\sqrt{5}$
\end{dmanswerbox}

$\mathrm{A}(0,\, 8)$,\ $\mathrm{B}(0,\, 0)$,\ $\mathrm{C}(16,\, 0)$,\ $\mathrm{D}(16,\, 8)$\ 로 좌표를 잡고 $\mathrm{P}(x,\, y)$($0 \le x \le 16$,\ $0 \le y \le 8$)라 하면
\begin{align*}
  \overline{\mathrm{AP}}^{\,2} - \overline{\mathrm{CP}}^{\,2} &= \{x^2 + (y-8)^2\}\\
  &\quad - \{(x-16)^2 + y^2\}.
\end{align*}
이차항이 소거되어 이 값은 $32x - 16y - 192$\ 이므로 조건 $= 16$\ 에서 $2x - y - 13 = 0$\ 이 자취이다. 이 직선이 직사각형과 만나는 두 점은 $y = 0$\ 일 때 $\left( \dfrac{13}{2},\, 0 \right)$\ 이 변 $\overline{\mathrm{BC}}$ 위 점이고, $y = 8$\ 일 때 $\left( \dfrac{21}{2},\, 8 \right)$\ 이 변 $\overline{\mathrm{AD}}$ 위 점이다. 두 점 사이의 거리는
\[ \sqrt{\left( \dfrac{21}{2} - \dfrac{13}{2} \right)^2 + 8^2} = \sqrt{16 + 64} = 4\sqrt{5}. \]

\begin{dmcriticalpoint}
\dmcplabel{두 거리 제곱의 차의 자취는 직선이다}: 전개하면 $x^2$\ 과 $y^2$\ 의 항이 서로 상쇄되어 결과가 $x$\ 와 $y$\ 에 대한 일차식으로 남는다.
\end{dmcriticalpoint}

\dmsoltitle{1}{두 삼각형의 넓이 등식과 밑변·높이}
\begin{dmanswerbox}
정답: $a=\dfrac{26}{5}$
\end{dmanswerbox}

두 직선 $y = -x + 10$\ 과 $y = 3x - 6$\ 의 $y$\ 축·$x$\ 축과의 교점을 각각 구하면 $\mathrm{A}(0,\, 10)$,\ $\mathrm{B}(2,\, 0)$\ 이다. 두 직선의 교점 $\mathrm{C}$\ 는 $-x + 10 = 3x - 6$\ 에서 $x = 4$\ 이고 $y = 6$\ 이므로 $\mathrm{C}(4,\, 6)$\ 이다.

두 삼각형 $\mathrm{ABD}$\ 와 $\mathrm{ABC}$\ 는 밑변 $\overline{\mathrm{AB}}$\ 를 공통으로 가진다. 넓이가 같으려면 두 꼭짓점 $\mathrm{C}$,\ $\mathrm{D}$\ 의 직선 $\mathrm{AB}$\ 까지의 거리가 같아야 한다. 직선 $\mathrm{AB}$\ 는 두 점 $(0,\, 10)$\ 과 $(2,\, 0)$\ 을 지나므로 방정식 $5x + y - 10 = 0$\ 이다. 점 $\mathrm{C}(4,\, 6)$\ 과 점 $\mathrm{D}(a,\, 0)$\ 의 이 직선까지의 거리는 각각
\[ \dfrac{|20 + 6 - 10|}{\sqrt{26}} = \dfrac{16}{\sqrt{26}},\quad \dfrac{|5a - 10|}{\sqrt{26}}. \]
$a > 2$\ 이므로 $5a - 10 > 0$\ 이고, 두 거리가 같으려면 $5a - 10 = 16$\ 에서 $a = \dfrac{26}{5}$\ 이다.

\begin{dmcriticalpoint}
\dmcplabel{점-직선 거리의 절댓값 등식은 두 부호 경우로 나뉜다}: 두 꼭짓점이 직선의 같은 쪽 또는 반대쪽에 있는 경우로 나뉘며, $a > 2$\ 라는 조건이 그중 하나만 유효로 만든다.
\end{dmcriticalpoint}

% ─────────────── 실전 2 (원 R-3 · 2017 이차곡선) ───────────────
\dmsoltitle{2}{이차곡선-직선 거리 최솟값의 이중 최적화}
\begin{dmanswerbox}
정답: 최댓값 $=\dfrac{4\sqrt{5}}{5}$
\end{dmanswerbox}

이차함수 위의 점 $\mathrm{P}(t,\ t^2 - 2at - 20)$\ 에서 직선 $2x - y - 12a = 0$\ 까지의 거리는
\begin{align*}
  d(t) &= \dfrac{|2t - (t^2 - 2at - 20) - 12a|}{\sqrt{5}}\\
       &= \dfrac{|{-t^2 + 2(a+1)t + (20 - 12a)}|}{\sqrt{5}}.
\end{align*}
$g(t) = -t^2 + 2(a+1)t + (20 - 12a)$\ 로 두면 $t = a+1$\ 에서 최댓값이
$$g(a+1) = a^2 - 10a + 21 = (a-3)(a-7)$$
이다. $3 < a < 7$\ 에서 $(a-3)(a-7) < 0$\ 이므로 모든 $t$\ 에 대해 $g(t) < 0$\ 이다.

이때 $|g(t)|$\ 의 최솟값은 $g$\ 의 최댓값의 절댓값과 같아
$$f(a) = \dfrac{-(a-3)(a-7)}{\sqrt{5}} = \dfrac{-(a-5)^2 + 4}{\sqrt{5}}.$$
$3 < a < 7$\ 의 범위에서 $a = 5$\ 일 때 최댓값 $\dfrac{4}{\sqrt{5}} = \dfrac{4\sqrt{5}}{5}$\ 를 가진다.

\begin{dmcriticalpoint}
\dmcplabel{절댓값 안 이차식이 부호를 바꾸지 않아야 꼭짓점에서 최솟값이 된다}: $g(t) < 0$\ 이 모든 $t$\ 에서 성립하면 $|g(t)|$\ 의 최솟값은 $g$\ 의 최댓값의 절댓값과 같아 $g$\ 의 꼭짓점에서 거리가 최소가 된다.
\end{dmcriticalpoint}

\dmsoltitle{3}{무게중심의 중선 성질과 점-직선 거리}
\begin{dmanswerbox}
정답: $\dfrac{f(q)}{p^2}=\dfrac{5}{14}$
\end{dmanswerbox}

\dmemph{(가) 결정.} 중점 $\mathrm{M}$\ 이 직선 $\mathrm{OA}$ 위에 있어 $\mathrm{M}$\ 에서 이 직선까지 거리가 $0$\ 이고, 무게중심 $\mathrm{G}$\ 가 선분 $\overline{\mathrm{BM}}$\ 을 $2 : 1$\ 로 내분하므로 $\overline{\mathrm{BG}} : \overline{\mathrm{GM}} = 2 : 1$\ 이다. 점 $\mathrm{B}$\ 의 거리는 $\mathrm{G}$\ 의 거리의 $3$\ 배이므로 $\mathrm{G}$\ 와 직선 $\mathrm{OA}$ 사이의 거리는 $\dfrac{6\sqrt{2}}{3} = 2\sqrt{2}$\ 이다. 곧 (가) $= p = 2\sqrt{2}$\ 이고 $p^2 = 8$\ 이다.

\dmemph{(나) 결정.} 직선 $\mathrm{OA}$\ 의 기울기를 $m$\ 이라 하면 직선 $\mathrm{OA}$\ 의 방정식은 $mx - y = 0$\ 이므로 점 $\mathrm{G}(8,\, 4)$\ 와 이 직선 사이의 거리는
\[ \dfrac{|8m - 4|}{\sqrt{m^2 + 1}}. \]
이 값이 (가) $= 2\sqrt{2}$\ 와 같아야 하므로 (나) 자리에 놓이는 식은 이 분수의 분자이다. 즉 $f(m) = |8m - 4|$\ 이다.

\dmemph{(다) 결정.} $\dfrac{|8m - 4|}{\sqrt{m^2 + 1}} = 2\sqrt{2}$\ 의 양변을 제곱하여 정리하면
$$(8m - 4)^2 = 8(m^2 + 1),\qquad 7m^2 - 8m + 1 = 0.$$
$(7m - 1)(m - 1) = 0$\ 에서 $m = \dfrac{1}{7}$ 또는 $m = 1$\ 이다. 직선 $\mathrm{OG}$\ 의 기울기가 $\dfrac{1}{2}$\ 이고 직선 $\mathrm{OA}$\ 의 기울기가 직선 $\mathrm{OB}$\ 의 기울기보다 작아야 하므로 $\mathrm{OA}$\ 의 기울기 $q < \dfrac{1}{2}$\ 이고 $q = \dfrac{1}{7}$\ 이다.
