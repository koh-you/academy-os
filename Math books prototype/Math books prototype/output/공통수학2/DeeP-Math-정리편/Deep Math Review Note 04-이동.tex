\begin{dmconcept}{1}{평행이동}
% 세션 85 (마스터 지시) : dmsub 3·4 응용 침투 삭제 → auto-tune 재조정
\setlength{\parskip}{2.0mm plus 2.1mm minus 0mm}\linespread{1.30}\selectfont%

\dmsub{1}{점의 평행이동}

좌표평면 위의 점 $\mathrm{P}(x,\, y)$\ 를 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼 옮긴 점을 $\mathrm{P}'$\ 이라 하면
\begin{equation*}
  \mathrm{P}'(x + a,\, y + b)
\end{equation*}
이다. 이와 같은 이동을 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼의 \dmstrong{평행이동}이라 한다.

\begin{dmexplain}
$x$축의 방향으로 $a$만큼 옮긴다는 것은 $a > 0$이면 오른쪽, $a < 0$이면 왼쪽으로 $|a|$만큼 옮긴다는 뜻이다. $y$축의 방향으로 $b$만큼 옮기는 것도 부호에 따라 위·아래가 갈린다. 두 방향의 이동은 서로 순서를 바꾸어도 결과가 같으므로, $x$좌표와 $y$좌표에 각각 $a$,\ $b$\ 를 더하기만 하면 된다.
\end{dmexplain}

\begin{dmexample}
점 $(2,\, -1)$\ 을 $x$축의 방향으로 $3$만큼, $y$축의 방향으로 $4$만큼 평행이동한 점의 좌표는 $(2 + 3,\, -1 + 4) = (5,\, 3)$이다.
\end{dmexample}

\begin{dmnote}
평행이동에서는 이동 전 점과 이동 후 점을 잇는 벡터가 항상 $(a,\, b)$\ 로 같다. 따라서 어떤 두 점의 이동 전후 좌표를 알면 이동량 $a$,\ $b$\ 가 유일하게 결정된다.
\end{dmnote}

\dmsub{2}{도형의 평행이동}

방정식 $f(x,\, y) = 0$이 나타내는 도형을 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼 평행이동한 도형의 방정식은
\begin{equation*}
  f(x - a,\, y - b) = 0
\end{equation*}
이다. 즉 원래 방정식의 $x$ 대신 $x - a$\ 를, $y$ 대신 $y - b$\ 를 대입하여 얻는다.

\begin{dmexplain}
원래 도형 위의 점 $\mathrm{P}(x,\, y)$\ 를 옮긴 점을 $\mathrm{P}'(x',\, y')$\ 이라 하면 $x' = x + a$,\ $y' = y + b$이므로 $x = x' - a$,\ $y = y' - b$이다. $\mathrm{P}$\ 가 원 도형 위에 있으므로 $f(x,\, y) = 0$, 즉 $f(x' - a,\, y' - b) = 0$\ 이 성립한다. 이는 $\mathrm{P}'$\ 이 방정식 $f(x - a,\, y - b) = 0$이 나타내는 도형 위에 있다는 뜻이다.
\end{dmexplain}

\begin{dmnote}
점을 이동할 때는 좌표에 $+a$,\ $+b$\ 를 더하지만 도형의 방정식을 이동할 때는 반대로 $-a$,\ $-b$\ 를 대입한다. 이 방향의 차이는 위 유도에서 원 도형의 방정식이 이동 전 좌표 $(x,\, y) = (x' - a,\, y' - b)$\ 로 표현되는 데에서 나온다.
\end{dmnote}

\end{dmconcept}

\dmex{1}{두 점의 대응으로 결정되는 평행이동과 직선의 이동}

\begin{dmproblem}
점 $(-3,\, 4)$\ 를 점 $(-1,\, 1)$\ 로 옮기는 평행이동에 의해 직선 $3x - y + 2 = 0$이 직선 $ax - y + b = 0$으로 옮겨질 때, 상수 $a$,\ $b$\ 에 대하여 $a + b$의 값을 구하시오.
\end{dmproblem}

\begin{dmapproach}
두 점 $(-3,\, 4)$\ 와 $(-1,\, 1)$의 대응을 이용하여 이동의 크기 $(p,\, q)$를 구한 다음, 직선의 방정식에서 $x$ 대신 $x - p$,\ $y$ 대신 $y - q$\ 를 대입하여 이동한 직선을 얻는다.
\end{dmapproach}

\begin{dmsolution}
$(x,\, y) \to (x + p,\, y + q)$\ 라 하면 $(-3 + p,\, 4 + q) = (-1,\, 1)$에서
\begin{equation*}
  p = 2,\qquad q = -3.
\end{equation*}
$3x - y + 2 = 0$에 $x \to x - 2$,\ $y \to y + 3$을 대입하면
\begin{equation*}
  3(x - 2) - (y + 3) + 2 = 0 \quad\Longrightarrow\quad 3x - y - 7 = 0.
\end{equation*}
$a = 3$,\ $b = -7$이므로 $\therefore\ a + b = -4$.
\dmanswer{$-4$}
\end{dmsolution}

\dmex{2}{원의 평행이동과 계수 결정}

\begin{dmproblem}
평행이동 $(x,\, y) \to (x + 3,\, y - 4)$에 의해 원 $x^2 + y^2 + 4x - 2y + a = 0$이 원 $(x - 1)^2 + (y + b)^2 = 3$으로 옮겨질 때, 상수 $a$,\ $b$\ 의 값을 각각 구하시오.
\end{dmproblem}

\begin{dmapproach}
주어진 원의 방정식을 표준형으로 정리하여 중심과 반지름을 구하고, 평행이동에 의해 중심이 어떻게 옮겨지는지 대응시킨다. 반지름의 길이는 평행이동으로 변하지 않는다.
\end{dmapproach}

\begin{dmsolution}
$x^2 + y^2 + 4x - 2y + a = 0$을 표준형으로 정리하면
\begin{equation*}
  (x + 2)^2 + (y - 1)^2 = 5 - a\quad(\because\ \text{중심 } (-2,\, 1),\ r^2 = 5 - a).
\end{equation*}
중심을 $(3,\, -4)$만큼 이동하면 $(1,\, -3)$이고 $(x - 1)^2 + (y + b)^2 = 3$과 대조하여
\begin{equation*}
  -b = -3,\qquad 5 - a = 3.
\end{equation*}
$\therefore\ a = 2,\ b = 3$.
\dmanswer{$a = 2$,\ \ $b = 3$}
\end{dmsolution}

\dmchecktitle

\dmcheck{3}{%
원 $x^2 + y^2 + 6x + 2y + 8 = 0$을 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼 평행이동한 원이 원 $x^2 + y^2 - 4x - 4y + 6 = 0$과 일치할 때, 상수 $a$,\ $b$\ 에 대하여 $ab$의 값을 구하시오.%
}

\dmcheck{4}{%
직선 $4x + 3y - 5 = 0$을 $y$축의 방향으로 $k$만큼 평행이동한 직선이 원 $(x - 1)^2 + y^2 = 4$\ 에 접할 때, 양수 $k$의 값을 구하시오.%
}

\begin{dmconcept}{2}{원점$\cdot$좌표축$\cdot$직선 $y = x$에 대한 대칭이동}
% 세션 86 (마스터 지시) : 좀 더 상세한 기술 · 유도·직관·성질 확대
\setlength{\parskip}{1.2mm plus 1.3mm minus 0mm}\linespread{1.19}\selectfont%

\dmsub{1}{점의 대칭이동}

좌표평면 위의 점 $\mathrm{P}(x,\, y)$\ 를
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item $x$축에 대하여 대칭이동한 점: $(x,\, -y)$
  \item $y$축에 대하여 대칭이동한 점: $(-x,\, y)$
  \item 원점에 대하여 대칭이동한 점: $(-x,\, -y)$
  \item 직선 $y = x$\ 에 대하여 대칭이동한 점: $(y,\, x)$
  \item 직선 $y = -x$\ 에 대하여 대칭이동한 점: $(-y,\, -x)$
\end{itemize}
이다. 어떤 대칭이든 두 번 반복하면 원래 점으로 돌아온다.

\begin{dmexplain}
$x$축·$y$축 대칭은 대응하는 축 위의 좌표를 그대로 두고 나머지 좌표의 부호만 뒤집는 것이다. 원점 대칭은 두 축에 대한 대칭을 잇달아 적용한 결과와 같으므로 두 좌표가 모두 부호가 바뀐다. 직선 $y = x$\ 대칭은 두 좌표를 맞바꾸는 것이고, $y = -x$\ 대칭은 맞바꾸는 동시에 부호까지 뒤집는 것이다.
\end{dmexplain}

\dmsub{2}{도형의 대칭이동}

방정식 $f(x,\, y) = 0$이 나타내는 도형을 각각의 방식으로 대칭이동한 도형의 방정식은
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item $x$축 대칭: $f(x,\, -y) = 0$
  \item $y$축 대칭: $f(-x,\, y) = 0$
  \item 원점 대칭: $f(-x,\, -y) = 0$
  \item 직선 $y = x$\ 대칭: $f(y,\, x) = 0$
  \item 직선 $y = -x$\ 대칭: $f(-y,\, -x) = 0$
\end{itemize}
이다. 점의 대칭이동에서 얻은 대응 좌표를 처음 주어진 방정식의 $x$,\ $y$ 자리에 대입하여 얻는다.

\begin{dmexplain}
원래 도형 위 점 $\mathrm{P}(x,\, y)$\ 의 $x$축 대칭점을 $\mathrm{P}'(x',\, y') = (x,\, -y)$라 하면 $x = x'$,\ $y = -y'$이다. $\mathrm{P}$\ 가 원래 도형 위에 있으므로 $f(x,\, y) = 0$, 즉 $f(x',\, -y') = 0$이 성립한다. 이는 대칭이동된 도형이 $f(x,\, -y) = 0$임을 뜻한다. 다른 대칭에도 같은 방식으로 대응 좌표를 대입하면 나머지 방정식이 얻어진다.
\end{dmexplain}

\begin{dmnote}
어떤 도형을 축이나 원점 또는 직선 $y = x$\ 에 대해 대칭이동한 결과가 원래 도형과 일치하면 그 도형은 대응 대상에 대해 \dmstrong{대칭}이라 한다. 예를 들어 $y = x^2$은 $y$축에 대해 대칭이므로 $x \to -x$로 바꾸어도 방정식이 변하지 않는다.
\end{dmnote}

\end{dmconcept}

\dmex{3}{두 대칭점을 지나는 직선의 방정식}

\begin{dmproblem}
점 $(4,\, 6)$\ 을 $x$축에 대하여 대칭이동한 점을 $\mathrm{P}$,\ $y$축에 대하여 대칭이동한 점을 $\mathrm{Q}$\ 라 할 때, 두 점 $\mathrm{P}$,\ $\mathrm{Q}$\ 를 지나는 직선의 방정식을 구하시오.
\end{dmproblem}

\begin{dmapproach}
$x$축과 $y$축에 대한 대칭의 정의를 이용하여 두 점 $\mathrm{P}$,\ $\mathrm{Q}$\ 의 좌표를 구하고, 두 점을 지나는 직선의 방정식을 세운다.
\end{dmapproach}

\begin{dmsolution}
$x$축 대칭은 $y$부호만, $y$축 대칭은 $x$부호만 바꾸므로
\begin{equation*}
  \mathrm{P}(4,\, -6),\qquad \mathrm{Q}(-4,\, 6).
\end{equation*}
두 점을 지나는 직선의 기울기는
\[ \dfrac{6 - (-6)}{-4 - 4} = -\dfrac{3}{2} \]
이고 $\mathrm{P}(4,\, -6)$을 지나므로
\begin{equation*}
  y + 6 = -\tfrac{3}{2}(x - 4) \quad\Longrightarrow\quad y = -\tfrac{3}{2}x.
\end{equation*}
\dmanswer{$y = -\dfrac{3}{2}x$}
\end{dmsolution}

\dmex{4}{평행이동과 대칭이동의 결합}

\begin{dmproblem}
직선 $y = 3x + 2$\ 를 $x$축의 방향으로 $a$만큼 평행이동한 후 원점에 대하여 대칭이동한 직선이 점 $(2,\, 1)$을 지날 때, 상수 $a$의 값을 구하시오.
\end{dmproblem}

\begin{dmapproach}
$x$축의 방향으로 $a$만큼의 평행이동은 주어진 방정식에서 $x$ 대신 $x - a$\ 를 대입하고, 원점에 대한 대칭이동은 그 방정식의 $x$,\ $y$\ 를 각각 $-x$,\ $-y$\ 로 바꾸는 것이다. 순서에 유의하여 이동을 적용한 뒤 점 $(2,\, 1)$을 대입한다.
\end{dmapproach}

\begin{dmsolution}
$y = 3x + 2$에 $x \to x - a$\ 를 대입하면
\begin{equation*}
  y = 3(x - a) + 2.
\end{equation*}
다시 원점 대칭으로 $x \to -x$,\ $y \to -y$\ 를 대입하면
\begin{equation*}
  -y = 3(-x - a) + 2 \quad\Longrightarrow\quad y = 3x + 3a - 2.
\end{equation*}
$(2,\, 1)$을 대입하면 $1 = 6 + 3a - 2$에서 $3a = -3$.\ $\therefore\ a = -1$.
\dmanswer{$-1$}
\end{dmsolution}

}

\dmcheck{8}{%
원 $x^2 + y^2 - 4x = 0$을 $y$축에 대하여 대칭이동한 후 $y$축의 방향으로 $1$만큼 평행이동한 원이 직선 $y = mx - 2$\ 에 접할 때, 상수 $m$의 값을 구하시오.%
}

\begin{dmconcept}{3}{점과 직선에 대한 대칭이동}
% 세션 85 (마스터 지시) : 개념원리 §03 구조 정합화 · y=x·y=-x는 c2로 이관
\setlength{\parskip}{1.4mm plus 1.5mm minus 0mm}\linespread{1.21}\selectfont%

\dmsub{1}{점 $(p,\, q)$에 대한 대칭이동}

점 $\mathrm{P}(x,\, y)$\ 를 점 $(p,\, q)$에 대해 대칭이동한 점을 $\mathrm{P}'(x',\, y')$이라 하면 점 $(p,\, q)$가 선분 $\mathrm{P}\mathrm{P}'$의 중점이므로
\begin{equation*}
  x' = 2p - x, \quad y' = 2q - y
\end{equation*}
이다. 즉 $\mathrm{P}'(2p - x,\, 2q - y)$이다. 대응하여 방정식 $f(x,\, y) = 0$이 나타내는 도형을 점 $(p,\, q)$에 대해 대칭이동한 도형의 방정식은 $f(2p - x,\, 2q - y) = 0$이다.

\begin{dmexplain}
중점 조건 $\dfrac{x + x'}{2} = p$,\ $\dfrac{y + y'}{2} = q$를 $x'$,\ $y'$에 대해 풀면 $x' = 2p - x$,\ $y' = 2q - y$가 얻어진다. 특별히 $(p,\, q) = (0,\, 0)$이면 원점에 대한 대칭이 되어 결과 $(-x,\, -y)$와 정확히 일치한다.
\end{dmexplain}

\begin{dmexample}
점 $(3,\, -2)$\ 를 점 $(1,\, 2)$에 대하여 대칭이동한 점의 좌표는 $(2 \cdot 1 - 3,\, 2 \cdot 2 - (-2)) = (-1,\, 6)$이다.
\end{dmexample}

\dmsub{2}{직선 $\ell$에 대한 대칭이동}

점 $\mathrm{P}(x,\, y)$\ 를 직선 $\ell$에 대하여 대칭이동한 점을 $\mathrm{P}'(x',\, y')$이라 하면 다음 두 조건이 성립한다.
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item 선분 $\mathrm{P}\mathrm{P}'$의 중점이 직선 $\ell$ 위에 있다.
  \item 선분 $\mathrm{P}\mathrm{P}'$이 직선 $\ell$과 수직이다.
\end{itemize}
이 두 조건을 미지수 $x'$,\ $y'$에 대한 연립방정식으로 풀어 $\mathrm{P}'$의 좌표를 구한다.

\begin{dmexplain}
직선 $\ell$의 기울기가 $m$이면 $\overline{\mathrm{P}\mathrm{P}'}$의 기울기는 수직 조건에서 $-\dfrac{1}{m}$이다. 또한 $\mathrm{P}\mathrm{P}'$의 중점 좌표를 $\ell$의 방정식에 대입한 식이 성립한다. 두 식은 $x'$,\ $y'$에 대한 연립일차방정식이 되어 $\mathrm{P}'$의 좌표가 유일하게 결정된다. 특수 직선 $y = x$나 $y = -x$의 경우에는 연립을 거치지 않고 두 좌표의 맞바꿈으로 바로 얻을 수 있다.
\end{dmexplain}

\begin{dmexample}
점 $(1,\, 4)$\ 를 직선 $y = x + 1$에 대해 대칭이동한 점을 $\mathrm{P}'(x',\, y')$\ 이라 하면 중점 조건 $\dfrac{4 + y'}{2} = \dfrac{1 + x'}{2} + 1$과 수직 조건 $\dfrac{y' - 4}{x' - 1} = -1$을 연립해 $\mathrm{P}'(3,\, 2)$를 얻는다.
\end{dmexample}

\begin{dmnote}
점에 대한 대칭이동은 대응점의 중점이 그 점이 되고, 직선에 대한 대칭이동은 대응점을 잇는 선분이 그 직선을 수직이등분한다. 특별히 대상이 원점 또는 좌표축·직선 $y = \pm x$일 때는 앞선 개념에서 배운 결과가 그대로 얻어져 이 두 공식은 특수 케이스를 자연스럽게 포함한다.
\end{dmnote}

\end{dmconcept}

\end{dmproblem}

\begin{dmapproach}

\end{dmapproach}

\end{equation*}
$\therefore$ 최솟값은 $\overline{\mathrm{AB}'} = \sqrt{6^2 + (-5)^2} = \sqrt{61}$.
\dmanswer{$\sqrt{61}$}
\end{dmsolution}

\dmex{6}{직선에 대한 대칭이동}

\begin{dmproblem}

\end{dmproblem}

\begin{dmapproach}
$\mathrm{P}'(a,\, b)$\ 라 하고, 선분 $\overline{\mathrm{P}\mathrm{P}'}$의 중점이 직선 $y = 2x - 3$ 위에 있다는 조건과 두 점을 잇는 선분이 이 직선에 수직이라는 조건을 각각 세워 연립한다.
\end{dmapproach}

\begin{equation*}
  \tfrac{4 + b}{2} = 2 \cdot \tfrac{1 + a}{2} - 3 \quad\Longrightarrow\quad 2a - b = 8.
\end{equation*}
$\overline{\mathrm{P}\mathrm{P}'} \perp \ell$에서 기울기의 곱이 $-1$이므로
\begin{equation*}
  \tfrac{b - 4}{a - 1} \cdot 2 = -1 \quad\Longrightarrow\quad a + 2b = 9.
\end{equation*}
두 식을 연립하면 $a = 5,\ b = 2$.\ $\therefore\ \mathrm{P}'(5,\, 2)$.
\dmanswer{$\mathrm{P}'(5,\, 2)$}
\end{dmsolution}

두 양수 $a$,\ $b$\ 에 대하여 원 $\mathrm{C} : (x - 1)^2 + y^2 = r^2$\ 을 $x$축의 방향으로 $a$만큼, $y$축의 방향으로 $b$만큼 평행이동한 원을 $\mathrm{C}'$\ 이라 하자. 두 원 $\mathrm{C}$,\ $\mathrm{C}'$\ 이 다음 조건을 만족시킬 때, $a + b + r$의 값을 구하시오. (단, $r$\ 는 양수이다.)

\begin{dmoptionbox}
(가) 원 $\mathrm{C}'$\ 은 원 $\mathrm{C}$의 중심을 지난다.

(나) 직선 $4x - 3y + 21 = 0$은 두 원 $\mathrm{C}$,\ $\mathrm{C}'$\ 에 모두 접한다.
\end{dmoptionbox}%
}
