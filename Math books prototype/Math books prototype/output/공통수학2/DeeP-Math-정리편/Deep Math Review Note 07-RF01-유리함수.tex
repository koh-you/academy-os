\begin{dmconcept}{1}{유리식}

\dmsub{1}{유리식의 뜻과 성질}

두 다항식 $A$,\ $B$ ($B \ne 0$)에 대하여 $\dfrac{A}{B}$ 꼴로 나타낼 수 있는 식을 \dmstrong{유리식}이라 하며, 분모가 $0$이 되지 않는 값에서만 정의된다. 다항식도 $B$가 상수인 경우로 볼 수 있으므로 유리식에 포함된다.

유리식의 분모와 분자에 $0$이 아닌 같은 다항식을 곱하거나 나누어도 그 값은 변하지 않는다.
\begin{equation*}
  \frac{A}{B} = \frac{A \times C}{B \times C} = \frac{A \div D}{B \div D} \quad (C \ne 0,\ D \ne 0)
\end{equation*}
공통인수로 나누어 간단히 하는 것을 \dmstrong{약분}이라 하고, 더 이상 약분되지 않는 유리식을 \dmstrong{기약분수식}이라 한다.

\dmsub{2}{유리식의 사칙연산}

두 유리식의 사칙연산은 다음과 같이 정의한다.
\begin{itemize}[leftmargin=8mm, itemsep=0.5mm, topsep=1mm]
  \item 덧셈·뺄셈: $\dfrac{A}{C} \pm \dfrac{B}{C} = \dfrac{A \pm B}{C}$. 분모가 다르면 통분한다.
  \item 곱셈: $\dfrac{A}{B} \times \dfrac{C}{D} = \dfrac{AC}{BD}$
  \item 나눗셈: $\dfrac{A}{B} \div \dfrac{C}{D} = \dfrac{A}{B} \times \dfrac{D}{C} = \dfrac{AD}{BC}$ ($C \ne 0$)
\end{itemize}
계산 결과가 기약분수식이 될 때까지 분자와 분모를 인수분해하여 공통인수를 소거한다.

\dmsub{3}{부분분수 분해}

분모가 두 다항식의 곱으로 인수분해되는 유리식은 다음과 같이 두 유리식의 차로 나타낼 수 있다.
\begin{equation*}
  \frac{1}{AB} = \frac{1}{B - A}\left(\frac{1}{A} - \frac{1}{B}\right) \quad (A \ne B)
\end{equation*}
이 변형을 \dmstrong{부분분수 분해}라 한다.

항 여러 개의 합에 적용하면 이웃한 항끼리 소거되어 처음과 끝의 몇 항만 남는다. 우변을 통분해 좌변과 일치함을 확인하는 방법으로 항상 검증할 수 있다.

\dmsub{4}{비례식과 조건식에서 유리식의 값}

비례식 $a : b : c = p : q : r$가 주어지면 실수 $k$에 대하여 $a = pk$,\ $b = qk$,\ $c = rk$로 놓고 대입해 값을 구한다. 조건이 대칭식이면 유리식을 대칭식 꼴로 변형해 대입한다.

\end{dmconcept}

\dmex{1}{부분분수 분해와 계수 결정}

\begin{dmproblem}
등식
\begin{equation*}
  \dfrac{1}{x(x + 1)(x + 3)} = \dfrac{a}{x} + \dfrac{b}{x + 1} + \dfrac{c}{x + 3}
\end{equation*}
이 $x$에 대한 항등식일 때, 상수 $a$,\ $b$,\ $c$에 대하여 $a + b + c$의 값을 구하시오.
\end{dmproblem}

\begin{dmapproach}
우변을 통분하여 좌변과 같아지도록 분자를 비교한다. $x$에 특정한 값을 대입하는 방법을 함께 활용하면 각 상수를 빠르게 구할 수 있다.
\end{dmapproach}

\begin{dmsolution}
우변을 통분한 분자와 좌변의 분자를 비교하면
\begin{equation*}
  a(x + 1)(x + 3) + bx(x + 3) + cx(x + 1) = 1.
\end{equation*}

$x = 0,\, -1,\, -3$을 차례로 대입하면
\begin{equation*}
  3a = 1,\qquad -2b = 1,\qquad 6c = 1
\end{equation*}
에서 $a = \dfrac{1}{3},\ b = -\dfrac{1}{2},\ c = \dfrac{1}{6}$이다.

$\therefore\ a + b + c = \dfrac{1}{3} - \dfrac{1}{2} + \dfrac{1}{6} = 0$
\dmanswer{$0$}
\end{dmsolution}

\dmex{2}{부분분수로 인접 항이 상쇄되는 합}

\begin{dmproblem}
자연수 $n$에 대하여
\begin{equation*}
  \frac{1}{1 \cdot 3} + \frac{1}{3 \cdot 5} + \frac{1}{5 \cdot 7} + \cdots + \frac{1}{(2n - 1)(2n + 1)}
\end{equation*}
의 값을 $n$을 이용하여 나타내시오.
\end{dmproblem}

\begin{dmapproach}
각 항을 부분분수 분해하여 두 유리식의 차로 나타내면 이웃한 항끼리 소거되어 첫 항과 마지막 항만 남는다.
\end{dmapproach}

\begin{dmsolution}
분모가 연속된 두 홀수의 곱이므로 각 항은
\begin{equation*}
  \frac{1}{(2k - 1)(2k + 1)} = \frac{1}{2}\left(\frac{1}{2k - 1} - \frac{1}{2k + 1}\right)
\end{equation*}
로 분해된다. 이를 대입하면 이웃한 항끼리 소거되어 첫 항과 마지막 항만 남으므로
\begin{equation*}
  \text{(주어진 합)} = \frac{1}{2}\left(1 - \frac{1}{2n + 1}\right) = \frac{1}{2}\cdot\frac{2n}{2n + 1} = \frac{n}{2n + 1}.
\end{equation*}
\dmanswer{$\dfrac{n}{2n + 1}$}
\end{dmsolution}

\begin{dmconcept}{2}{유리함수와 그래프}
% 세션 84 : 넘침 정정 · parskip·linespread 절제 (원 1.4mm/1.20 → 1.0mm/1.15)
\setlength{\parskip}{1.0mm plus 1.1mm minus 0mm}\linespread{1.16}\selectfont%

\dmsub{1}{유리함수의 뜻과 정의역}

$y$가 $x$에 대한 유리식으로 나타나는 함수 $y = f(x)$를 \dmstrong{유리함수}라 한다. 정의역이 명시되지 않을 때는 분모를 $0$으로 만드는 $x$의 값을 제외한 실수 전체를 정의역으로 삼는다.

\dmsub{2}{유리함수 $y = \dfrac{k}{x}$의 그래프}

$k \ne 0$인 상수 $k$에 대하여 유리함수 $y = \dfrac{k}{x}$의 그래프는 정의역이 $x \ne 0$인 실수 전체, 치역이 $y \ne 0$인 실수 전체이며, $k > 0$이면 제 $1$·제 $3$ 사분면, $k < 0$이면 제 $2$·제 $4$ 사분면에 두 갈래로 나뉘어 그려진다. 그래프는 원점에 대해 점대칭이고 두 직선 $y = x$,\ $y = -x$에 대해 선대칭이며, $x$축과 $y$축을 \dmstrong{점근선}으로 갖는다.

$x$의 절댓값이 커지면 곡선이 $x$축에 한없이 가까워지고, $x$가 $0$에 가까워지면 곡선이 $y$축에 한없이 가까워진다. 이렇게 곡선이 한없이 가까워지는 직선을 그래프의 점근선이라 한다.

\dmsub{3}{$y = \dfrac{k}{x - p} + q$ 표준형}

유리함수 $y = \dfrac{k}{x - p} + q$의 그래프는 $y = \dfrac{k}{x}$의 그래프를 $x$축의 방향으로 $p$만큼, $y$축의 방향으로 $q$만큼 평행이동한 것이다. 정의역은 $x \ne p$, 치역은 $y \ne q$이며 점근선은 두 직선 $x = p$,\ $y = q$이고 대칭 중심은 두 점근선의 교점 $(p,\, q)$이다.

\begin{dmexample}
$y = \dfrac{2}{x - 1} + 3$의 그래프는 $y = \dfrac{2}{x}$의 그래프를 $x$축의 방향으로 $1$만큼, $y$축의 방향으로 $3$만큼 평행이동한 것이다. 점근선은 $x = 1$,\ $y = 3$이고 대칭 중심은 $(1,\, 3)$이다.
\end{dmexample}

\dmsub{4}{일반형 $y = \dfrac{ax + b}{cx + d}$의 표준형 변형}

일반형 $y = \dfrac{ax + b}{cx + d}$ ($c \ne 0$,\ $ad - bc \ne 0$)는 분자를 분모로 나누어 $y = \dfrac{k}{x - p} + q$ 꼴로 변형한 뒤 위의 표준형 성질을 적용해 분석한다. 이때 점근선은 두 직선 $x = -\dfrac{d}{c}$와 $y = \dfrac{a}{c}$이다.

\begin{dmexample}
$y = \dfrac{2x + 5}{x + 1}$을 정리하면 $y = \dfrac{2(x + 1) + 3}{x + 1} = \dfrac{3}{x + 1} + 2$이므로 점근선은 $x = -1$,\ $y = 2$이고 대칭 중심은 $(-1,\, 2)$이다.
\end{dmexample}

\begin{dmnote}
$ad - bc = 0$이면 분자가 분모의 상수배가 되어 함수가 상수로 축약되므로 유리함수 그래프가 되기 위해서는 $ad - bc \ne 0$이 반드시 필요하다.
\end{dmnote}

\dmsub{5}{유리함수의 역함수}

$c \ne 0$,\ $ad - bc \ne 0$일 때 $y = \dfrac{ax + b}{cx + d}$는 일대일대응이므로 역함수가 존재한다. $y = \dfrac{ax + b}{cx + d}$에서 $x$와 $y$를 서로 바꾼 뒤 $y$에 대하여 풀면 역함수
\begin{equation*}
  y = \dfrac{-dx + b}{cx - a}
\end{equation*}
를 얻는다. 역함수의 그래프는 원함수의 그래프를 직선 $y = x$에 대하여 대칭이동한 것이다.

\end{dmconcept}

\dmex{3}{일반형에서 표준형으로 변형하기}

\begin{dmproblem}
유리함수 $y = \dfrac{-x + 5}{x - 2}$의 그래프는 유리함수 $y = \dfrac{a}{x}$의 그래프를 $x$축의 방향으로 $b$만큼, $y$축의 방향으로 $c$만큼 평행이동한 것이다. 이때 상수 $a$,\ $b$,\ $c$의 값을 각각 구하시오.
\end{dmproblem}

\begin{dmapproach}
분자를 분모로 나누어 $y = \dfrac{k}{x - p} + q$ 꼴로 만들면 이 그래프는 $y = \dfrac{k}{x}$를 $x$축의 방향으로 $p$,\ $y$축의 방향으로 $q$만큼 평행이동한 것이다. 계수를 비교하여 $a$,\ $b$,\ $c$를 구한다.
\end{dmapproach}

\begin{dmsolution}
분자에서 분모를 뽑아내면
\begin{equation*}
  \frac{-x + 5}{x - 2} = \frac{-(x - 2) + 3}{x - 2} = \frac{3}{x - 2} - 1.
\end{equation*}
이 그래프는 $y = \dfrac{3}{x}$의 그래프를 $x$축의 방향으로 $2$만큼,\ $y$축의 방향으로 $-1$만큼 평행이동한 것이므로
$$a = 3,\qquad b = 2,\qquad c = -1.$$
\dmanswer{$a = 3,\ b = 2,\ c = -1$}
\end{dmsolution}

\dmex{4}{정의역이 제한된 유리함수의 치역}

\begin{dmproblem}
유리함수 $y = \dfrac{-2x + 4}{x - 1}$의 정의역이 $\{x \mid -1 \le x < 1 \text{ 또는 } 1 < x \le 2\}$일 때, 치역을 구하시오.
\end{dmproblem}

\begin{dmapproach}
일반형을 표준형으로 변형하여 대칭 중심(점근선의 교점)과 감소·증가 방향을 파악한 뒤, 정의역의 각 구간에서 함숫값이 어떻게 변화하는지 살펴 경계값을 대입해 치역을 구한다.
\end{dmapproach}

\begin{dmsolution}
표준형으로 변형하면
\begin{equation*}
  y = \frac{-2x + 4}{x - 1} = \frac{-2(x - 1) + 2}{x - 1} = \frac{2}{x - 1} - 2
\end{equation*}
이므로 점근선은 $x = 1,\ y = -2$이고 두 구간 모두에서 함수는 감소한다.

$-1 \le x < 1$에서 $x = -1$이면 $y = -3$이고,\ $x$가 $1$에 가까워지면 $y$는 한없이 작아지므로 $y \le -3$.

$1 < x \le 2$에서 $x$가 $1$에 가까워지면 $y$는 한없이 커지고,\ $x = 2$이면 $y = 0$이므로 $y \ge 0$.

$\therefore\ \text{치역} = \{y \mid y \le -3 \text{ 또는 } y \ge 0\}$
\dmanswer{$\{y \mid y \le -3 \text{ 또는 } y \ge 0\}$}
\end{dmsolution}

\dmex{5}{유리함수 그래프의 대칭 중심과 대칭축}

\begin{dmproblem}
다음 물음에 답하시오.

\vspace{3mm}

\dmsubprob{1} 유리함수 $y = \dfrac{ax - 2}{x + 1}$의 그래프가 점 $(b,\, 5)$에 대하여 대칭일 때, 상수 $a$,\ $b$의 값을 각각 구하시오.

\dmsubprob{2} 유리함수 $y = \dfrac{2x + 1}{x - 1}$의 그래프가 두 직선 $y = x + a$와 $y = -x + b$에 대하여 대칭일 때, 상수 $a$,\ $b$의 값을 각각 구하시오.
\end{dmproblem}

\begin{dmapproach}
$(1)$ 유리함수의 그래프가 어떤 점에 대하여 대칭이면 그 점은 그래프의 대칭 중심, 즉 두 점근선의 교점이다. 표준형으로 변형하여 점근선을 구하고 좌표를 비교한다.

$(2)$ 유리함수의 대칭축인 두 직선은 대칭 중심을 지나며 기울기가 각각 $1$과 $-1$이다. 대칭 중심의 좌표를 두 직선의 식에 대입하여 상수를 결정한다.
\end{dmapproach}

\begin{dmsolution}
\dmsubprob{1} $y = \dfrac{ax - 2}{x + 1} = a - \dfrac{a + 2}{x + 1}$이므로 대칭 중심은 $(-1,\, a)$이다. 이 점이 $(b,\, 5)$와 일치하므로
$$b = -1,\qquad a = 5.$$

\dmsubprob{2} $y = \dfrac{2x + 1}{x - 1} = 2 + \dfrac{3}{x - 1}$이므로 대칭 중심은 $(1,\, 2)$. 이 점이 두 직선 $y = x + a,\ y = -x + b$ 위에 있으므로
$$2 = 1 + a,\qquad 2 = -1 + b$$
에서 $a = 1,\ b = 3$.
\dmanswer{\begin{tabular}[t]{@{}l@{}}$(1)\ a = 5,\ b = -1$\\[0.4ex] $(2)\ a = 1,\ b = 3$\end{tabular}}
\end{dmsolution}

\dmex{6}{역함수가 자기 자신과 같을 조건}

\begin{dmproblem}
유리함수 $f(x) = \dfrac{ax + 3}{x - 1}$에 대하여 $f = f^{-1}$이 성립할 때, 상수 $a$의 값을 구하시오.
\end{dmproblem}

\begin{dmapproach}
유리함수 $y = \dfrac{ax + b}{cx + d}$의 역함수가 자기 자신과 같으면 계수 사이에 $a + d = 0$이 성립한다. 이는 $f \circ f(x) = x$가 항등식이 되도록 하는 조건에서 유도된다.
\end{dmapproach}

\begin{dmsolution}
$f(x) = \dfrac{ax + 3}{x - 1}$에서 분모의 상수항은 $d = -1$이다. 역함수가 자기 자신과 같을 조건 $a + d = 0$에 대입하면 $a = 1$.

$a = 1$일 때 $f(x) = \dfrac{x + 3}{x - 1}$이므로 검산해 보면
\begin{equation*}
  (f \circ f)(x) = \frac{(x + 3) + 3(x - 1)}{(x + 3) - (x - 1)} = \frac{4x}{4} = x \quad(\because\text{ 분자·분모에 } x-1 \text{ 곱함})
\end{equation*}
이 성립하여 $f = f^{-1}$이 확인된다.
\dmanswer{$1$}
\end{dmsolution}
