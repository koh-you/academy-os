\examsection{객관식 \#1\textendash{}\#6 풀 답지}

\soltitle{1}{사차방정식 — 공통인수 추출과 인수분해}{3}
\begin{answerbox}\sffamily\bfseries 정답: ③ $2$\end{answerbox}
\step{1} 좌변에서 \emph{공통인수 $x$}를 추출한다.
\[ x^4 - 2x^3 - x^2 + 2x = x \cdot (x^3 - 2x^2 - x + 2). \]
\step{2} 셋째 인수를 \emph{묶어서 인수분해}한다.
\[ x^3 - 2x^2 - x + 2 = x^2 (x - 2) - (x - 2) = (x - 2)(x^2 - 1) = (x - 2)(x - 1)(x + 1). \]
\step{3} 따라서 좌변은
\[ x^4 - 2x^3 - x^2 + 2x = x(x - 2)(x - 1)(x + 1). \]
네 실근은 $0, 2, 1, -1$.
\step{4} 모든 실근의 합은
\[ 0 + 2 + 1 + (-1) = 2. \]
정답은 $\textbf{③}$.
\solnote{고차방정식은 \emph{공통인수 추출} 후 \emph{묶어서 인수분해}하는 단계적 도구가 표준. 본 문제는 $x$ 추출 후 셋째 인수에서 $x^2(x-2) - (x-2)$ 묶음이 자연스럽게 발견된다. 근과 계수의 관계 ($-x^3$의 계수 $-2$ → 네 근의 합 $2$)로 \emph{한 줄 검증}도 가능.}

\soltitle{2}{절댓값 부등식 — 두 부등식의 공통 범위}{3}
\begin{answerbox}\sffamily\bfseries 정답: ③ $5$\end{answerbox}
\step{1} 우변 $x + 4$가 \emph{양수}여야 절댓값 부등식이 의미를 가진다. 곧 $x > -4$.
\step{2} 절댓값 부등식을 두 부등식으로 풀어쓴다.
\[ -(x + 4) < 2x - 1 < x + 4. \]
\step{3} \textbf{좌 부등식}: $-x - 4 < 2x - 1 \;\Longrightarrow\; -3 < 3x \;\Longrightarrow\; x > -1$.
\step{4} \textbf{우 부등식}: $2x - 1 < x + 4 \;\Longrightarrow\; x < 5$.
\step{5} 종합하면 $-1 < x < 5$. 정수 $x = 0, 1, 2, 3, 4$로 \emph{$5$개}.
정답은 $\textbf{③}$.
\solnote{$|A| < B$ 꼴은 \emph{$B > 0$}을 자동 전제로 $-B < A < B$로 환원되는 표준 도구. 우변에 $x$가 포함되어도 같은 형식이지만 \emph{$x + 4 > 0$ 조건}을 잊지 말아야 한다. 본 문제는 자동 만족 ($x > -1 > -4$)이라 추가로 경우를 나눌 필요가 없다.}

\soltitle{3}{이차부등식 — 해와 계수의 역방향 환원}{3}
\begin{answerbox}\sffamily\bfseries 정답: ⑤ $-2$\end{answerbox}
\step{1} 이차부등식의 해가 $-4 \le x \le b$이므로 좌변은 \emph{근이 $-4$와 $b$인 이차식}으로 인수분해된다.
\[ x^2 + ax - 12 = (x + 4)(x - b). \]
\step{2} 전개하면
\[ (x + 4)(x - b) = x^2 + (4 - b)x - 4b. \]
\step{3} 양변 계수 비교.
\begin{itemize}\setlength{\itemsep}{0pt}
\item 상수항: $-4b = -12 \;\Longrightarrow\; b = 3$.
\item $x$의 계수: $a = 4 - b = 4 - 3 = 1$.
\end{itemize}
\step{4} 따라서
\[ a - b = 1 - 3 = -2. \]
정답은 $\textbf{⑤}$.
\solnote{이차부등식의 \emph{해의 범위}이 주어지면 좌변이 \emph{두 근을 가지는 이차식}으로 \emph{역방향 인수분해}되는 표준 도구. 학생은 일반적인 \emph{해 → 계수} 방향이 아닌 \emph{계수 → 해} 방향에 익숙하므로 *역방향 사고*가 핵심 변별. 상수항 식으로 $b$를 \emph{먼저} 결정한 뒤 $a$가 자동으로 결정되는 \emph{단방향 미정계수}가 절약 도구.}

\soltitle{4}{사차 부등식 — 미지수 분기와 정수해 카운팅}{4}
\begin{answerbox}\sffamily\bfseries 정답: ③ $35$\end{answerbox}
\step{1} 자연수 $a \ge 2$일 때 $\sqrt{a} > 1$이므로 인수의 부호를 분석한다.
\[ (x^2 - 1)(x^2 - a) = (x - 1)(x + 1)(x - \sqrt{a})(x + \sqrt{a}). \]
\step{2} 음수가 되는 영역은 \emph{인수 4개 중 음수가 홀수 개}인 영역. 부호 분석으로
\[ -\sqrt{a} < x < -1 \text{ 또는 } 1 < x < \sqrt{a}. \]
\step{3} 두 영역이 \emph{대칭}이므로 정수해 개수는 한 영역의 정수 개수의 \emph{$2$배}.
\step{4} 한 영역 $1 < x < \sqrt{a}$의 정수 개수가 $1$이 되도록 자연수 $a$를 분기.
\begin{itemize}\setlength{\itemsep}{0pt}
\item $a = 2$: $1 < x < \sqrt{2} \approx 1.41$. 정수 $0$개. ✗
\item $a = 3$: $1 < x < \sqrt{3} \approx 1.73$. 정수 $0$개. ✗
\item $a = 4$: $1 < x < 2$. 정수 $0$개 (열린 범위). ✗
\item $a = 5$: $1 < x < \sqrt{5} \approx 2.24$. 정수 $\{2\}$. $1$개 ✓
\item $a = 6, 7, 8$: $1 < x < \sqrt{a}$, $\sqrt{a} \in (2.4, 2.9)$. 정수 $\{2\}$. $1$개 ✓
\item $a = 9$: $1 < x < 3$. 정수 $\{2\}$ (3 제외). $1$개 ✓
\item $a = 10$: $1 < x < \sqrt{10} \approx 3.16$. 정수 $\{2, 3\}$. $2$개 ✗
\end{itemize}
\step{5} 만족하는 자연수 $a = 5, 6, 7, 8, 9$. 합은
\[ 5 + 6 + 7 + 8 + 9 = 35. \]
정답은 $\textbf{③}$.
\solnote{사차 부등식의 \emph{대칭성} (홀수 차 없음 → $\pm x$ 대칭)을 활용해 한 영역만 카운팅 후 $\times 2$로 절약하는 게 핵심 도구. 미정계수 추적은 \emph{경계 정수}가 포함되는지 ($\sqrt{a}$가 정수 $3$일 때 제외)가 경우 나누기의 정점. \emph{닫힌 범위이 아닌 열린 범위}이라 $a = 4$의 $x = 2$가 제외됨에 주의.}

\soltitle{5}{연립 이차부등식 — 공통 정수해의 표면 모순}{4}
\begin{answerbox}\sffamily\bfseries 정답: ① $0$\end{answerbox}
\step{1} 두 부등식을 인수분해한다.
\[ (\text{가}): (x - 3)(x - k) \le 0, \qquad (\text{나}): (x + k)(x - 2) \le 0. \]
\step{2} 자연수 $k$이므로 $k \ge 1$. 두 부등식의 해를 $k$ 값에 따라 분기한다.
\step{3} \textbf{$k \ge 3$일 때.} (가) 해 $3 \le x \le k$, (나) 해 $-k \le x \le 2$. 공통 영역 $3 \le x$이면서 $x \le 2$ → 공집합. ✗
\step{4} \textbf{$k = 2$일 때.} (가) 해 $2 \le x \le 3$, (나) 해 $-2 \le x \le 2$. 공통 $\{2\}$. 정수 개수 $1$. ✗ ($\ge 3$ 위반)
\step{5} \textbf{$k = 1$일 때.} (가) 해 $1 \le x \le 3$, (나) 해 $-1 \le x \le 2$. 공통 $\{1, 2\}$. 정수 개수 $2$. ✗ ($\ge 3$ 위반)
\step{6} 모든 자연수 $k$에서 공통 정수해의 개수가 $3$ 이상이 되지 않는다. \emph{조건을 만족시키는 $k$가 존재하지 않으므로} 합은
\[ \text{(공집합의 합)} = 0. \]
정답은 $\textbf{①}$.
\solnote{\emph{표면 모순} 발문 — 두 부등식이 \emph{대칭적으로 보이지만} 자연수 $k$의 부호 구조에서 (가)는 \emph{양쪽으로 좁아지는} 닫힌 범위, (나)는 \emph{왼쪽으로 늘어나는} 구간이라 공통이 \emph{$\{1, 2\}$의 일부}로 좁아지는 함정. $k$가 늘수록 (가)는 좁아지고 (나)는 늘어나지만, \emph{두 닫힌 범위의 교집합이 결코 $3$개 정수에 도달할 수 없다}는 자연 한계가 결정적.}

\soltitle{6}{사차방정식 — \[보기\] 진위 판별과 $X = x^2$ 치환}{4}
\begin{answerbox}\sffamily\bfseries 정답: ③ ㄱ, ㄷ\end{answerbox}
\step{1} $X = x^2 \ge 0$으로 치환하면 $X^2 + aX + b = 0$. 두 근 $X_1$, $X_2$.
\step{2} \textbf{ㄱ.} $b > 0$ + $a < -2\sqrt{b}$. 판별식 $a^2 - 4b > 4b - 4b = 0$? 자세히, $a^2 > 4b$ (∵ $a < -2\sqrt{b}$, $|a| > 2\sqrt{b}$). 따라서 $D > 0$, 두 $X$ 서로 다름. 합 $-a > 0$ (∵ $a < 0$), 곱 $b > 0$ → 두 $X$ 양수. 네 근 $\pm\sqrt{X_1}, \pm\sqrt{X_2}$ 서로 다른 실근. \textbf{ㄱ은 참}.
\step{3} \textbf{ㄴ.} 네 근 모두 실수 = 두 $X$ 모두 \emph{$0$ 이상}. 곱 $X_1 X_2 = b \ge 0$. $b = 0$일 때 ($X = 0$이 근, 사차근 $x = 0$) 도 네 근 모두 실수 가능. 따라서 $b \ge 0$은 정확하지만 \emph{$b > 0$은 거짓}이다 (예: $x^4 - x^2 = 0$의 네 근 $0, 0, 1, -1$ 모두 실수, $b = 0$). \textbf{ㄴ은 거짓}.
\step{4} \textbf{ㄷ.} 두 실근과 두 허근 = 두 $X$ 중 하나는 양수 (실근에서), 다른 하나는 음수 (허근에서). 곱 $X_1 X_2 = b < 0$. \textbf{ㄷ은 참}.
\step{5} ㄱ, ㄷ만 참이므로 정답은 $\textbf{③}$.
\solnote{$X = x^2$ 치환은 사차방정식의 \emph{표준 환원} 도구. ㄱ·ㄷ은 \emph{두 $X$의 부호}로 곧장 판정되지만 ㄴ은 \emph{$b = 0$ 경계 케이스}에서 거짓 — 이중근 $x = 0$이 포함되는 함정. \emph{필요충분조건} 분석에서 \emph{경계 등호}를 놓치지 않는 것이 변별 핵심.}

\examsection{서답 \#7\textendash{}\#8 풀 답지}

\soltitle{7}{미지수 부등식 — 정수해의 소수 카운팅과 자기참조}{4}
\begin{answerbox}\sffamily\bfseries 정답: $78$\end{answerbox}
\step{1} 좌변을 \emph{완전제곱식 환원}한다.
\[ x^2 - 6x + (k - 4) = (x - 3)^2 + (k - 13). \]
\step{2} 부등식은 $(x - 3)^2 \le 13 - k$. 해가 존재하려면 $13 - k \ge 0$, 곧 $k \le 13$.
\step{3} 해는 $3 - \sqrt{13 - k} \le x \le 3 + \sqrt{13 - k}$. 자연수 $k$에 대해 각 $k$의 해 범위와 그 안의 정수 중 소수의 개수를 계산한다.
\step{4} \emph{소수}는 $2, 3, 5, 7, 11, 13, \ldots$ ($1$은 소수 아님).
\step{5} 각 $k$를 점검한다.
\begin{itemize}\setlength{\itemsep}{0pt}
\item $k = 1$: $\sqrt{12} \approx 3.46$, 해 $[-0.46, 6.46]$. 정수 $0, 1, 2, 3, 4, 5, 6$. 소수 $2, 3, 5$ — \emph{$3$개} ✓
\item $k = 2$: $\sqrt{11}$, 해 $[-0.32, 6.32]$. 정수 $0\sim6$. 소수 $3$개 ✓
\item $k = 3$: 해 $[-0.16, 6.16]$. 정수 $0\sim6$. 소수 $3$개 ✓
\item $k = 4$: 해 $[0, 6]$. 정수 $0\sim6$. 소수 $3$개 ✓
\item $k = 5$: 해 $[0.17, 5.83]$. 정수 $1\sim5$. 소수 $2, 3, 5$ — $3$개 ✓
\item $k = 6$: 해 $[0.35, 5.65]$. 정수 $1\sim5$. 소수 $3$개 ✓
\item $k = 7$: 해 $[0.55, 5.45]$. 정수 $1\sim5$. 소수 $3$개 ✓
\item $k = 8$: 해 $[0.76, 5.24]$. 정수 $1\sim5$. 소수 $3$개 ✓
\item $k = 9$: 해 $[1, 5]$. 정수 $1\sim5$. 소수 $3$개 ✓
\item $k = 10$: $\sqrt{3} \approx 1.73$, 해 $[1.27, 4.73]$. 정수 $2, 3, 4$. 소수 $2, 3$ — $2$개 ✓
\item $k = 11$: 해 $[1.59, 4.41]$. 정수 $2, 3, 4$. 소수 $2$개 ✓
\item $k = 12$: 해 $[2, 4]$. 정수 $2, 3, 4$. 소수 $2, 3$ — $2$개 ✓
\item $k = 13$: 해 $\{3\}$. 정수 $3$. 소수 $1$개. \emph{$\ge 2$ 위반} ✗
\end{itemize}
\step{6} 만족하는 자연수 $k = 1, 2, \ldots, 12$. 합은
\[ 1 + 2 + \cdots + 12 = \frac{12 \cdot 13}{2} = 78. \]
답은 $\textbf{78}$.
\solnote{미지수 $k$가 \emph{좌변 계수와 결과 조건} 양쪽에 등장하는 \emph{자기참조 부등식}. 완전제곱식 환원으로 해의 범위이 \emph{$3$ 중심·폭 $2\sqrt{13-k}$} 구조임을 발견. $k$ 증가에 따라 해의 범위 폭이 \emph{좁아지지만} 소수 $2, 3$이 \emph{좁아져도 살아남는} 자연 변별이 핵심. 경계 $k = 13$에서 단일점 $\{3\}$만 남아 소수 $1$개로 차단되는 함정.}

\soltitle{8}{연립방정식 — 합·곱 환원과 미정계수 카운팅}{4}
\begin{answerbox}\sffamily\bfseries 정답: $8$\end{answerbox}
\step{1} 두 식을 \emph{합과 곱} 형태로 환원한다. $x + y = a$ 양변 제곱 후 $x^2 + y^2 = a^2 - 2xy = b$로부터
\[ 2xy = a^2 - b \;\Longrightarrow\; xy = \frac{a^2 - b}{2}. \]
\step{2} $x$와 $y$는 이차방정식 $t^2 - at + (a^2 - b)/2 = 0$의 두 근.
\step{3} \textbf{서로 다른 두 자연수} 해 조건. 판별식이 \emph{양의 완전제곱수}이고 두 근이 자연수.
\[ D = a^2 - 4 \cdot \frac{a^2 - b}{2} = a^2 - 2(a^2 - b) = 2b - a^2. \]
$D = m^2$ ($m \ge 1$, $a$와 같은 홀짝성) 으로 놓으면
\[ b = \frac{a^2 + m^2}{2}, \qquad t = \frac{a \pm m}{2}. \]
\step{4} 두 근 자연수 조건: $a + m$, $a - m$ 모두 \emph{양의 짝수}. 곧 $a$와 $m$ 홀짝 일치, $m < a$ ($a - m \ge 2$).
\step{5} 자연수 $a$, $b$에 $b \le 30$ 제약을 적용해 분기 카운팅.
\begin{itemize}\setlength{\itemsep}{0pt}
\item $a = 3$ ($m = 1$ 홀): $b = (9 + 1)/2 = 5$. 두 근 $1, 2$. $b \le 30$ ✓.
\item $a = 4$ ($m = 2$ 짝): $b = (16 + 4)/2 = 10$. 두 근 $1, 3$. ✓.
\item $a = 5$ ($m = 1, 3$ 홀): $b = 13$ (두 근 $2, 3$), $17$ (두 근 $1, 4$). 둘 다 ✓.
\item $a = 6$ ($m = 2, 4$ 짝): $b = 20$ (두 근 $2, 4$), $26$ (두 근 $1, 5$). 둘 다 ✓.
\item $a = 7$ ($m = 1, 3, 5$ 홀): $b = 25$ (두 근 $3, 4$), $29$ (두 근 $2, 5$), $37$ (둘 다 자연수이나 $b > 30$ ✗).
\item $a = 8$ ($m = 2, 4, 6$ 짝): $b = 34$ ($b > 30$ ✗), $40$ ✗, $50$ ✗.
\end{itemize}
\step{6} 순서쌍 $(a, b)$의 개수는
\[ 1 + 1 + 2 + 2 + 2 = 8. \]
답은 $\textbf{8}$.
\solnote{대칭 연립방정식 $\{x + y = a, x^2 + y^2 = b\}$는 \emph{한 이차방정식의 두 근}으로 환원되어 \emph{합·곱 → 판별식 → 미정계수 추적}의 표준 도구가 적용된다. 정수해 조건은 \emph{$2b - a^2$이 완전제곱수}이고 \emph{$a$와 $m$ 홀짝 일치}로 \emph{이중 미정계수 $(a, m)$ 카운팅}으로 환원되는 게 핵심. $b \le 30$의 자연 상한이 $a \le 7$로 미정계수를 \emph{유한 범위에 압축}한다.}
