\soltitle{1}{경우의 수의 합의 법칙 다루기}{2}
\begin{answerbox}정답: ③ $10$\end{answerbox}

두 주사위의 눈을 $(a,\,b)$라 하자. 차가 $3$인 경우의 순서쌍 $(a,b)$는
\[ (1,4),\,(2,5),\,(3,6),\,(4,1),\,(5,2),\,(6,3) \]
의 $6$가지이다. 차가 $4$인 경우의 순서쌍 $(a,b)$는
\[ (1,5),\,(2,6),\,(5,1),\,(6,2) \]
의 $4$가지이다. 두 경우는 동시에 일어나지 않으므로 합의 법칙에 의하여
\[ 6 + 4 = 10. \]

\soltitle{2}{이웃하지 않는 순열 다루기}{2}
\begin{answerbox}정답: ④ $72$\end{answerbox}

$5$개의 문자 B, R, E, A, D에서 자음은 B, R, D, 모음은 E, A이다. 모음끼리 이웃하지 않도록 하려면 먼저 자음 $3$개를 일렬로 배열한 다음 자음 사이와 양 끝의 $4$자리 중 $2$자리에 모음 $2$개를 끼워 넣으면 된다.

자음 $3$개의 배열의 수는
\[ 3! = 6. \]
자음 사이와 양 끝 $4$자리에 두 모음을 끼워 넣는 방법의 수는
\[ {}_4\mathrm{P}_2 = 4 \times 3 = 12. \]
그러므로 구하는 경우의 수는
\[ 6 \times 12 = 72. \]

\soltitle{3}{연립부등식의 정수해 다루기}{2}
\begin{answerbox}정답: ⑤ $3$\end{answerbox}

연립부등식 $\,-3x + 5 \le 2x + 7 < -x + 15\,$을 두 부등식으로 분리하여 푼다.

먼저 $-3x + 5 \le 2x + 7$에서
\begin{align*}
-5x &\le 2, \\
x &\ge -\tfrac{2}{5}.
\end{align*}
다음으로 $2x + 7 < -x + 15$에서
\begin{align*}
3x &< 8, \\
x &< \tfrac{8}{3}.
\end{align*}
두 부등식의 공통 해를 구하면 $-\tfrac{2}{5} \le x < \tfrac{8}{3}$이다. 이를 만족시키는 정수 $x$는
\[ 0,\;1,\;2 \]
이고 그 합은
\[ 0 + 1 + 2 = 3. \]

\soltitle{4}{행렬의 곱과 성분 대응 다루기}{2}
\begin{answerbox}정답: ③ $7$\end{answerbox}

$A = \begin{pmatrix} 2 & 3 \\ 4 & 5 \end{pmatrix}$, $B = \begin{pmatrix} a & 1 \\ 0 & b \end{pmatrix}$이므로
\[ AB = \begin{pmatrix} 2a & 2 + 3b \\ 4a & 4 + 5b \end{pmatrix}. \]
이 결과가 $\begin{pmatrix} 10 & 8 \\ 20 & 14 \end{pmatrix}$과 같으므로 $(1,1)$ 성분에서
\[ 2a = 10,\quad a = 5. \]
$(1,2)$ 성분에서
\[ 2 + 3b = 8,\quad b = 2. \]
$(2,1)$·$(2,2)$ 성분도 이 값에서 성립한다. 그러므로
\[ a + b = 5 + 2 = 7. \]

\soltitle{5}{순열·조합의 방정식 다루기}{2}
\begin{answerbox}정답: ④ $1$\end{answerbox}

$(n+1) \times {}_n\mathrm{P}_2 = 210$에서 ${}_n\mathrm{P}_2 = n(n-1)$이므로
\[ (n+1)\,n\,(n-1) = 210. \]
연속한 세 자연수의 곱이 $210$인 경우는
\[ 5 \times 6 \times 7 = 210 \]
뿐이므로 $n = 6$이다.

${}_9\mathrm{C}_r = {}_9\mathrm{C}_4$에서 조합의 성질에 의하여
\[ r = 4 \quad \text{또는} \quad r = 9 - 4 = 5. \]
조건에서 $r \ne 4$이므로 $r = 5$이다. 그러므로
\[ n - r = 6 - 5 = 1. \]

\soltitle{6}{켤레복소수 근과 계수 관계 다루기}{2}
\begin{answerbox}정답: ③ $52$\end{answerbox}

계수가 실수인 삼차방정식 $x^3 + x^2 + ax + b = 0$의 한 근이 $1 + i$이므로 켤레복소수 $1 - i$도 이 방정식의 근이다.

두 허근을 근으로 하는 이차식은
\begin{align*}
&\bigl(x - (1+i)\bigr)\bigl(x - (1-i)\bigr) \\
&\quad = (x-1)^2 - i^2 = x^2 - 2x + 2.
\end{align*}
남은 실근을 $\alpha$라 하면
\[ x^3 + x^2 + ax + b = (x^2 - 2x + 2)(x - \alpha). \]
우변을 전개하면
\[ x^3 - (\alpha + 2)x^2 + (2\alpha + 2)x - 2\alpha \]
이므로 계수를 비교하면
\begin{align*}
-(\alpha + 2) &= 1 \;\Rightarrow\; \alpha = -3, \\
a &= 2\alpha + 2 = -4, \\
b &= -2\alpha = 6.
\end{align*}
그러므로
\[ a^2 + b^2 = (-4)^2 + 6^2 = 16 + 36 = 52. \]

\soltitle{7}{연립이차방정식 인수분해 다루기}{2}
\begin{answerbox}정답: ③ $256$\end{answerbox}

$x = \alpha$, $y = \beta$가 연립방정식의 해이므로 이 두 식을 만족시키는 $(x, y)$의 값 각각에 대해 $\alpha^2 \beta^2 = x^2 y^2$의 값을 구한 뒤 최댓값을 취한다.

첫째 식 $x^2 + xy - 2y^2 = 0$을 인수분해하면
\[ (x + 2y)(x - y) = 0. \]
그러므로 $x = -2y$ 또는 $x = y$이다.

$(\!$ⅰ$)$ $x = y$일 때 둘째 식에 대입하면
\[ y^2 + 2y^2 + 3y^2 = 6y^2 = 24, \]
즉 $y^2 = 4$, $x^2 = 4$이므로
\[ \alpha^2 \beta^2 = x^2 y^2 = 16. \]

$(\!$ⅱ$)$ $x = -2y$일 때 둘째 식에 대입하면
\[ 4y^2 - 4y^2 + 3y^2 = 3y^2 = 24, \]
즉 $y^2 = 8$, $x^2 = 32$이므로
\[ \alpha^2 \beta^2 = 256. \]

두 경우 중 최댓값은 $256$이다.

\soltitle{8}{절댓값을 포함한 부등식 다루기}{2}
\begin{answerbox}정답: ⑤ $5$\end{answerbox}

$\mathrm{A}(1)$, $\mathrm{B}(-2)$, $\mathrm{P}(x)$이므로
\[ \overline{\mathrm{AP}} = |x - 1|,\quad \overline{\mathrm{BP}} = |x + 2|. \]
부등식 $2|x-1| + |x+2| < 7$을 절댓값 안의 부호에 따라 나누어 푼다.

$(\!$ⅰ$)$ $x \ge 1$일 때 부등식은
\[ 2(x-1) + (x+2) = 3x < 7, \]
즉 $x < \tfrac{7}{3}$이므로 $1 \le x < \tfrac{7}{3}$. 정수 $x$는 $x = 1, 2$.

$(\!$ⅱ$)$ $-2 \le x < 1$일 때 부등식은
\[ 2(1-x) + (x+2) = 4 - x < 7, \]
즉 $x > -3$이므로 $-2 \le x < 1$. 정수 $x$는 $x = -2, -1, 0$.

$(\!$ⅲ$)$ $x < -2$일 때 부등식은
\[ 2(1-x) - (x+2) = -3x < 7, \]
즉 $x > -\tfrac{7}{3}$이므로 $-\tfrac{7}{3} < x < -2$. 정수 $x$는 없다.

이상에서 조건을 만족시키는 정수 $x$는 $-2, -1, 0, 1, 2$의 $5$개이다.

\soltitle{9}{도로망의 최단경로 셈 다루기}{2}
\begin{answerbox}정답: ③ $27$\end{answerbox}

각 교차점에 $\mathrm{A}$로부터 최단거리로 도달하는 방법의 수는 그 점의 왼쪽에 인접한 점에서 오는 방법의 수와 아래에 인접한 점에서 오는 방법의 수의 합이다. 이 규칙으로 왼쪽 아래에서부터 순서대로 각 교차점의 값을 구한다.

\begin{center}
\begin{tikzpicture}[line width=0.5pt, font=\footnotesize, scale=0.75]
  \draw (0, 0) grid (2, 2);
  \draw (1, 2) grid (3, 4);
  \foreach \x/\y/\v in {0/0/1, 1/0/1, 2/0/1, 0/1/1, 1/1/2, 2/1/3, 0/2/1, 1/2/3, 2/2/6, 3/2/6, 1/3/3, 2/3/9, 3/3/{15}, 1/4/3, 2/4/{12}, 3/4/{27}} {
    \node[fill=white, inner sep=0.8pt] at (\x, \y) {$\v$};
  }
  \node[anchor=north east, inner sep=3pt] at (-0.05, -0.05) {$\mathrm{A}$};
  \node[anchor=south west, inner sep=3pt] at (3.05, 4.05) {$\mathrm{B}$};
\end{tikzpicture}
\end{center}

$\mathrm{A}$의 왼쪽 열($x=0$)과 아래 행($y=0$)의 값은 모두 $1$이다. 두 사각형이 이어 붙는 점 $(3, 2)$는 왼쪽 $(2, 2)$의 값 $6$만 이어받으므로 $6$이다. 위쪽 사각형의 왼쪽 열($x=1$)도 아래에서만 값을 받아 $3, 3$이다.

이렇게 순차적으로 계산하면 $\mathrm{B}$에서의 최단경로의 수는
\[ 12 + 15 = 27. \]

\soltitle{10}{전체에서 이웃한 경우 빼기}{2}
\begin{answerbox}정답: ④ $56$\end{answerbox}

두 학생을 $9$개의 의자 중 서로 다른 두 의자에 앉히는 전체 경우의 수는
\[ {}_9\mathrm{P}_2 = 9 \times 8 = 72. \]

이 중 두 학생이 이웃한 의자에 앉는 경우의 수를 구하자. 이웃한 두 의자의 쌍은 $(1,2)$, $(2,3)$, $\ldots$, $(8,9)$의 $8$가지이고, 각 쌍에 두 학생을 배치하는 방법은 $2!$가지이므로
\[ 8 \times 2 = 16. \]

따라서 두 학생 사이에 적어도 하나의 빈 의자가 있는 경우의 수는 전체 $72$가지에서 이웃한 경우 $16$가지를 빼서
\[ 72 - 16 = 56. \]

\soltitle{11}{삼차방정식의 세 실근 조건 다루기}{3}
\begin{answerbox}정답: ④ $4$\end{answerbox}

$x^3 + (6-a)x^2 + (a^2-6a)x - a^3$에 $x = a$를 대입하면
\begin{align*}
&a^3 + (6-a)a^2 + (a^2 - 6a)a - a^3 \\
&\quad = a^3 + 6a^2 - a^3 + a^3 - 6a^2 - a^3 = 0
\end{align*}
이므로 $x = a$는 항상 이 방정식의 근이다. 조립제법 또는 다항식의 나눗셈으로 인수분해하면
\begin{align*}
&x^3 + (6-a)x^2 + (a^2-6a)x - a^3 \\
&\quad = (x - a)(x^2 + 6x + a^2).
\end{align*}

서로 다른 세 실근을 가지려면 이차식 $x^2 + 6x + a^2 = 0$이 서로 다른 두 실근을 가지며, 그 두 근 모두 $a$와 달라야 한다.

$(\!$ⅰ$)$ 판별식 조건:
\[ D/4 = 9 - a^2 > 0 \;\Rightarrow\; -3 < a < 3. \]

$(\!$ⅱ$)$ $x = a$가 이차식의 근이 아니어야 하므로
\[ a^2 + 6a + a^2 = 2a(a+3) \ne 0, \]
즉 $a \ne 0$이고 $a \ne -3$이다.

$-3 < a < 3$에서 $a \ne 0$인 정수 $a$는
\[ a = -2,\; -1,\; 1,\; 2 \]
이므로 모든 정수 $a$의 곱은
\[ (-2) \times (-1) \times 1 \times 2 = 4. \]

\soltitle{12}{지불 방법과 지불 금액의 수 다루기}{3}
\begin{answerbox}정답: ③ $162$\end{answerbox}

$1000$원 지폐, $5000$원 지폐, $10000$원 지폐를 사용하는 장수를 각각 $x$, $y$, $z$라 하면
\[ 0 \le x \le 3,\quad 0 \le y \le 6,\quad 0 \le z \le 3. \]

$\bullet$ 지불 방법의 수. $(x, y, z)$의 전체 경우는
\[ 4 \times 7 \times 4 = 112 \]
이고, $(0, 0, 0)$인 경우는 $0$원을 지불하는 경우이므로 제외하여
\[ a = 112 - 1 = 111. \]

$\bullet$ 지불 금액의 수. $10000 = 2 \times 5000$이므로 $y' = y + 2z$로 놓으면 $y'$는 $0$부터 $12$까지의 모든 정수값이 가능하다. 지불 금액을 $1000$원 단위로 나타내면
\[ x + 5y' \quad (0 \le x \le 3,\; 0 \le y' \le 12). \]

각 $y'$에 대하여 $x + 5y'$의 값은 $5y'$, $5y'+1$, $5y'+2$, $5y'+3$의 $4$가지이므로 $y' = 0, 1, \ldots, 12$를 통틀어 $13 \times 4 = 52$가지의 서로 다른 값을 얻는다. $0$원은 제외하여
\[ b = 52 - 1 = 51. \]

그러므로
\[ a + b = 111 + 51 = 162. \]

\soltitle{13}{다항식의 값 다루기(근 대입 트릭)}{2}
\begin{answerbox}정답: ③ $30$\end{answerbox}

$f(x) = x^4 - x^3 + 2x^2 - x - 4$라 하면 네 근이 $a$, $b$, $c$, $d$이므로
\[ f(x) = (x - a)(x - b)(x - c)(x - d). \]
$x = -2$를 대입하면
\begin{align*}
f(-2) &= (-2 - a)(-2 - b)(-2 - c)(-2 - d) \\
&= (-1)^4 (a + 2)(b + 2)(c + 2)(d + 2) \\
&= (a + 2)(b + 2)(c + 2)(d + 2).
\end{align*}

직접 계산하면
\[ f(-2) = 16 + 8 + 8 + 2 - 4 = 30. \]
그러므로
\[ (a+2)(b+2)(c+2)(d+2) = 30. \]

\soltitle{14}{사차방정식의 허근과 행렬 다루기}{3}
\begin{answerbox}정답: ② $-6$\end{answerbox}

$x^4 + 2x^3 + 3x^2 - 2x - 4 = 0$의 인수분해를 위해 $x = 1$과 $x = -1$을 대입하면 각각 값이 $0$이므로 $(x - 1)(x + 1) = x^2 - 1$이 인수이다. 나눗셈에 의해
\begin{align*}
&x^4 + 2x^3 + 3x^2 - 2x - 4 \\
&\quad = (x^2 - 1)(x^2 + 2x + 4).
\end{align*}

두 허근은 $x^2 + 2x + 4 = 0$의 근이므로 근과 계수의 관계에서
\[ \alpha + \beta = -2,\quad \alpha\beta = 4. \]

$X = \begin{pmatrix} \alpha & 1 \\ 1 & \beta \end{pmatrix}$이므로
\[ X^2 = \begin{pmatrix} \alpha^2 + 1 & \alpha + \beta \\ \alpha + \beta & 1 + \beta^2 \end{pmatrix}. \]

$X^2$의 모든 성분의 합은
\begin{align*}
&(\alpha^2 + 1) + (\alpha + \beta) + (\alpha + \beta) + (1 + \beta^2) \\
&\quad = (\alpha^2 + \beta^2) + 2(\alpha + \beta) + 2.
\end{align*}
여기서
\[ \alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = 4 - 8 = -4 \]
이므로
\[ -4 + 2(-2) + 2 = -6. \]

\soltitle{15}{연립부등식 해집합 조건 다루기}{3}
\begin{answerbox}정답: ④ $a > 0$\end{answerbox}

각 이차부등식을 인수분해한다.

$(\!$ⅰ$)$ $x^2 - (a+2)x + 2a \le 0$은
\[ (x - 2)(x - a) \le 0. \]
$(\!$ⅱ$)$ $x^2 + (a+4)x + 4a \le 0$은
\[ (x + 4)(x + a) \le 0. \]

두 부등식의 해집합의 공통 부분이 존재하지 않을 조건을 구한다. $a$의 값을 세 경우로 나누어 각 경우에 공통 해의 유무를 판정한다.

$(\!$가$)$ $a > 0$인 경우. 첫째 부등식의 해는 $2$와 $a$ 사이의 값이므로 모두 양수, 즉 $x > 0$. 둘째 부등식의 해는 $-4$와 $-a$ 사이의 값이므로 모두 음수, 즉 $x < 0$. 두 해집합은 서로 만나지 않으므로 공통 해가 존재하지 않는다.

$(\!$나$)$ $a = 0$인 경우. 첫째 해는 $0 \le x \le 2$, 둘째 해는 $-4 \le x \le 0$이므로 $x = 0$이 공통 해로 존재한다. 따라서 문제의 조건에 맞지 않는다.

$(\!$다$)$ $a < 0$인 경우. 첫째 해는 $a$와 $2$ 사이의 값으로 $x = 0$을 포함하고, 둘째 해는 $-4$와 $-a > 0$ 사이의 값으로 $x = 0$을 포함한다. 그러므로 $x = 0$이 공통 해가 되어 문제의 조건에 맞지 않는다.

이상에서 공통 해가 존재하지 않는 경우는 $(\!$가$)$뿐이므로 구하는 $a$의 값의 범위는
\[ a > 0. \]

\soltitle{16}{나머지정리 확장 — 세제곱 관계 다루기}{3}
\begin{answerbox}정답: ③ $27$\end{answerbox}

$x^2 - 2x + 4 = 0$의 한 허근을 $\omega$라 하자. $(x + 2)(x^2 - 2x + 4) = x^3 + 8$이므로
\[ \omega^3 + 8 = 0,\quad \text{즉}\ \omega^3 = -8. \]

$x^7 - 40x + 3$을 $x^2 - 2x + 4$로 나눈 몫을 $Q(x)$, 나머지를 $R(x) = ax + b$라 하면
\[ x^7 - 40x + 3 = (x^2 - 2x + 4)\,Q(x) + ax + b. \]

이 등식에 $x = \omega$를 대입하면 $\omega^2 - 2\omega + 4 = 0$이므로
\[ \omega^7 - 40\omega + 3 = a\omega + b. \]

$\omega^7 = (\omega^3)^2 \cdot \omega = (-8)^2 \cdot \omega = 64\omega$이므로 위 식은
\[ 64\omega - 40\omega + 3 = a\omega + b, \]
곧 $24\omega + 3 = a\omega + b$. $(a - 24)\omega + (b - 3) = 0$인데 $\omega$가 허수이므로 실수부분과 허수부분 각각이 $0$이어야 한다. 그러므로 $a = 24$, $b = 3$이다.

따라서 $R(x) = 24x + 3$이고
\[ R(1) = 24 + 3 = 27. \]

\soltitle{17}{색깔 공을 상자에 분배하는 경우의 수 다루기}{3}
\begin{answerbox}정답: ④ $630$\end{answerbox}

각 상자에는 같은 색의 공을 최대 $1$개까지 넣으므로 빨간 공 $2$개를 넣는 방법과 파란 공 $3$개를 넣는 방법은 각각
\[ {}_7\mathrm{C}_2 = 21,\quad {}_7\mathrm{C}_3 = 35 \]
가지이다.

두 색 공이 모두 들어 있는 상자의 개수를 $k$라 하자. 조건은 $k < 2$, 즉 $k = 0$ 또는 $k = 1$이다.

$(\!$ⅰ$)$ $k = 0$인 경우. 빨간 공이 놓인 상자와 파란 공이 놓인 상자가 겹치지 않는다. 먼저 빨간 공 $2$개를 놓을 상자 $2$개를 정하고(${}_7\mathrm{C}_2 = 21$가지) 남은 $5$개의 상자에서 파란 공 $3$개를 놓을 상자 $3$개를 정한다(${}_5\mathrm{C}_3 = 10$가지):
\[ 21 \times 10 = 210. \]

$(\!$ⅱ$)$ $k = 1$인 경우. 두 색 공이 모두 놓인 상자 $1$개를 정하고($7$가지), 그 상자를 제외한 $6$개 중 빨간 공만 놓일 상자 $1$개를 정하고($6$가지), 앞서 정한 상자 두 개를 제외한 $5$개 중 파란 공만 놓일 상자 $2$개를 정한다(${}_5\mathrm{C}_2 = 10$가지):
\[ 7 \times 6 \times 10 = 420. \]

합의 법칙에 의하여
\[ 210 + 420 = 630. \]

\soltitle{18}{짝수·홀수 카드 이웃하지 않는 배치 다루기}{3}
\begin{answerbox}정답: ③ $2016$\end{answerbox}

두 이웃한 카드의 곱이 짝수라는 조건은 홀수 카드끼리 이웃하지 않는다는 조건과 같다. 카드 $2$$\sim$$8$ 중 홀수는 $3, 5, 7$의 $3$개, 짝수는 $2, 4, 6, 8$의 $4$개이다.

$7$장 중 $6$장을 택해 나열하므로 남겨두는 카드에 따라 두 경우로 나눈다.

$(\!$ⅰ$)$ 남겨두는 카드가 홀수인 경우. 남는 카드는 홀수 $2$개, 짝수 $4$개. 먼저 짝수 $4$개를 배열하면 $4! = 24$가지이고, 짝수 사이와 양 끝의 $5$자리 중 $2$자리를 골라 홀수 $2$개를 순서대로 배치하면 ${}_5\mathrm{P}_2 = 20$가지이다.

남겨두는 홀수 카드는 $3$개 중 하나이므로 $3$가지이고, 각 경우에 대하여 위 배열이 가능하므로
\[ 3 \times 24 \times 20 = 1440. \]

$(\!$ⅱ$)$ 남겨두는 카드가 짝수인 경우. 남는 카드는 홀수 $3$개, 짝수 $3$개. 먼저 짝수 $3$개를 배열하면 $3! = 6$가지이고, 짝수 사이와 양 끝의 $4$자리 중 $3$자리를 골라 홀수 $3$개를 순서대로 배치하면 ${}_4\mathrm{P}_3 = 24$가지이다.

남겨두는 짝수 카드는 $4$개 중 하나이므로 $4$가지이고, 각 경우에 대하여
\[ 4 \times 6 \times 24 = 576. \]

합의 법칙에 의하여
\[ 1440 + 576 = 2016. \]

\soltitle{19}{점과 직선의 개수 세기 다루기}{3}
\begin{answerbox}정답: ③ $5$\end{answerbox}

$15$개의 점 가운데 두 점을 이어 얻는 서로 다른 쌍의 수는
\[ {}_{15}\mathrm{C}_2 = 105. \]
오직 두 점을 지나는 직선의 개수를 $z$, 오직 세 점을 지나는 직선의 개수를 $x$, 오직 네 점을 지나는 직선의 개수를 $y$라 하면 조건에서 $x = 10$이고
\[ z + x + y = 60. \]

한편 각 직선 위의 점의 쌍의 수는 두 점을 지나는 직선이면 $1$, 세 점을 지나는 직선이면 ${}_3\mathrm{C}_2 = 3$, 네 점을 지나는 직선이면 ${}_4\mathrm{C}_2 = 6$이므로
\[ z \cdot 1 + x \cdot 3 + y \cdot 6 = 105. \]

$x = 10$을 대입하면 두 식은
\begin{align*}
z + y &= 50, \\
z + 6y &= 105 - 30 = 75.
\end{align*}
두 식의 차에서
\[ 5y = 25,\quad y = 5. \]
따라서 오직 네 점만을 지나는 직선의 개수는 $5$이다.

\soltitle{20}{행렬 곱의 성분 해석 다루기}{3}
\begin{answerbox}정답: ③ $\tfrac{24}{25}BA$의 $(1,2)$ 성분\end{answerbox}

내년 수출용 자동차 $P$의 생산량은 올해의 $20\%$ 증가이고 그 중 $80\%$를 판매하므로 실제 판매 대수는
\[ 250 \times 1.2 \times 0.8 = 250 \times \tfrac{24}{25}. \]
마찬가지로 내년 수출용 자동차 $Q$의 판매 대수는
\[ 300 \times \tfrac{24}{25}. \]

내년의 판매가격은 올해와 같으므로 $P$는 $1800$만 원, $Q$는 $2500$만 원. 내년 수출용 자동차 총 예상 판매 금액은
\begin{align*}
&250 \cdot \tfrac{24}{25} \cdot 1800 + 300 \cdot \tfrac{24}{25} \cdot 2500 \\
&\quad = \tfrac{24}{25}\bigl(250 \cdot 1800 + 300 \cdot 2500\bigr).
\end{align*}

한편 행렬의 곱 $BA$에서 $(1, 2)$ 성분은 $B$의 $1$행(수출용 행 $(250,\,300)$)과 $A$의 $2$열(올해 판매가격 열 $\begin{pmatrix} 1800 \\ 2500 \end{pmatrix}$)의 곱으로
\[ (BA)_{12} = 250 \cdot 1800 + 300 \cdot 2500. \]

따라서 내년 수출용 자동차의 총 예상 판매 금액은 $\dfrac{24}{25} BA$의 $(1, 2)$ 성분이다.

\soltitle{21}{행렬의 거듭제곱 주기성 다루기}{3}
\begin{answerbox}정답: ③ $220$\end{answerbox}

$A = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$의 거듭제곱을 계산하면
\begin{align*}
A^2 &= \begin{pmatrix} -1 & 0 \\ 0 & -1 \end{pmatrix} = -E, \\
A^3 &= -A, \\
A^4 &= E.
\end{align*}
즉 $A^k$는 지수 $k$가 $4$씩 늘어날 때마다 값이 반복되므로 $A^m = A^n$이 성립할 필요충분조건은 두 자연수 $m$, $n$을 $4$로 나눈 나머지가 같은 것이다.

$1$부터 $44$까지의 자연수를 $4$로 나눈 나머지별로 분류하면
\begin{align*}
\text{나머지 } 1&:\; 1, 5, 9, \ldots, 41 \;\to\; 11\text{개}, \\
\text{나머지 } 2&:\; 2, 6, 10, \ldots, 42 \;\to\; 11\text{개}, \\
\text{나머지 } 3&:\; 3, 7, 11, \ldots, 43 \;\to\; 11\text{개}, \\
\text{나머지 } 0&:\; 4, 8, 12, \ldots, 44 \;\to\; 11\text{개}.
\end{align*}

각 부류 안에서 $m > n$인 두 원소를 뽑는 방법은 조합의 수이므로
\[ 4 \times {}_{11}\mathrm{C}_2 = 4 \times 55 = 220. \]

\soltitle{22}{두 이차함수 축의 위치 결정과 값 계산}{3}
\begin{answerbox}정답: ③ $144$\end{answerbox}

조건 $(\!$가$)$에서 모든 실수 $x$에 대하여 $f(x) \le 0$이므로 $f$는 이차항 계수가 음수이고 최댓값이 $0$이다. 마찬가지로 $g$는 이차항 계수가 양수이고 최솟값이 $0$이다. 따라서
\[ f(x) = -A(x - \alpha)^2,\qquad g(x) = B(x - \beta)^2 \]
로 놓을 수 있다. $(A > 0, B > 0)$

조건 $(\!$나$)$에서 범위 $k - 2 \le x \le k + 2$의 $f$의 최댓값과 $g$의 최솟값이 같아야 하는데, $f$의 최댓값은 $0$ 이하이고 $g$의 최솟값은 $0$ 이상이므로 두 값은 모두 $0$이어야 한다. 이는 $f$의 축 $\alpha$와 $g$의 축 $\beta$가 모두 이 범위에 속할 때만 가능하므로
\[ \max(\alpha,\,\beta) - 2 \le k \le \min(\alpha,\,\beta) + 2. \]
$k$의 최솟값이 $0$, 최댓값이 $1$이므로
\[ \max(\alpha,\,\beta) = 2,\qquad \min(\alpha,\,\beta) = -1. \]

조건 $(\!$다$)$의 방정식 $f(x) = f(0)$을 풀면
\[ -A(x - \alpha)^2 = -A \alpha^2 \;\Longleftrightarrow\; x(x - 2\alpha) = 0 \]
이므로 근은 $x = 0$과 $x = 2\alpha$이고 두 근의 합은 $2\alpha$이다. 이 값이 음수라야 하므로 $\alpha < 0$. 따라서 $\alpha = -1$, $\beta = 2$.

$f(1) = -A(1 + 1)^2 = -4A = -2$에서 $A = \tfrac{1}{2}$.
$g(1) = B(1 - 2)^2 = B = 2$.
그러므로
\[ f(x) = -\tfrac{1}{2}(x + 1)^2,\qquad g(x) = 2(x - 2)^2. \]

값을 대입하면
\[ f(5) = -\tfrac{1}{2}(6)^2 = -18,\qquad g(11) = 2(9)^2 = 162. \]
따라서
\[ f(5) + g(11) = -18 + 162 = 144. \]

\soltitle{23}{이차함수 근 개수 조건과 완전제곱 판정}{3}
\begin{answerbox}정답: ④ $66$\end{answerbox}

$x$에 대한 이차방정식
\[ \{x - f(k)\}\{x - g(k)\} = 0 \]
의 두 근은 $f(k)$와 $g(k)$이다. 이 두 값이 서로 달라야 하고 그 두 근이 $0$과 $6$이어야 하므로 다음 두 경우 중 하나이다.
\begin{align*}
&\text{(A)}\; f(k) = 0,\; g(k) = 6, \\
&\text{(B)}\; f(k) = 6,\; g(k) = 0.
\end{align*}

$g$는 이차함수이므로 방정식 $g(k) = 0$의 서로 다른 실근 개수는 최대 $2$, 마찬가지로 $g(k) = 6$의 서로 다른 실근 개수도 최대 $2$이다. 경우 (A)와 (B)가 만족되는 $k$의 총 개수가 홀수 $3$이 되려면 한쪽에서는 서로 다른 실근이 $2$, 다른 한쪽에서는 서로 다른 실근이 $1$이 되어야 한다.

이차항 계수가 $1$인 $g$에 대하여 $g(k) = 0$의 근이 $1$개(중근)이면 $g$는 완전제곱꼴이므로
\[ g(x) = (x - \gamma)^2. \]
이때 $g(k) = 0 \iff k = \gamma$이고, 경우 (B)는 $k = \gamma$ 하나뿐. 이 $k$에서 $f(\gamma) = 6$이어야 한다.

경우 (A)에서 $g(k) = 6$은 $(k - \gamma)^2 = 6$이므로 $k = \gamma \pm \sqrt{6}$의 서로 다른 두 실근을 갖는다. 이 두 값 모두에서 $f(k) = 0$이어야 하므로 $f$의 두 근이 $\gamma - \sqrt{6}$, $\gamma + \sqrt{6}$이고 $f$의 축은 $\gamma$이다. 이차항 계수를 $c$라 하면
\[ f(x) = c\{(x - \gamma)^2 - 6\}. \]
$f(\gamma) = -6c = 6$에서 $c = -1$이므로
\[ f(x) = -(x - \gamma)^2 + 6. \]

주어진 조건 $f(3) = 6$을 대입하면 $-(3 - \gamma)^2 + 6 = 6$이므로 $\gamma = 3$이다. 따라서
\[ g(x) = (x - 3)^2,\qquad f(x) = -(x - 3)^2 + 6. \]

값을 대입하면
\[ g(9) = 36,\qquad f(9) = -36 + 6 = -30. \]
그러므로
\[ g(9) - f(9) = 36 - (-30) = 66. \]
