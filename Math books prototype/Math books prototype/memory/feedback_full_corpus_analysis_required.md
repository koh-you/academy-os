# 🔴 자료 분석 전수 원칙 + 자산화 영구 정책 (2026-06-29 마스터 명시)

## 사건

2026-06-29 아샘 짱 내신 FINAL 공통수학1 기말고사 분석에서 분석자(클로드)가 다음 부적절 분석:
- 1·2회차만 전수 라벨링, 3~10회차는 표본·요약 라벨링
- 부록 4회분도 표본 요약
- 분석된 슬롯 중 4건만 `bank/problems/SRC-AS-*` 등재, 나머지 ★ 4·5 후보 미등재

마스터 직접 지적: "앞으로 자료를 분석할때는 전수 분석이 원칙. 표본분석 금지. 또 분석된 자료는 반드시 자산화 할것." (마스터 정정: "자산" → "자료")

## 영구 정책

### 적용 범위
- **시판 책·기출·외부 PDF 정독** (주된 대상)
- 본 시스템 내부 미등재 자료 분석
- 모든 *자료* 평가·라벨링 (분석된 결과물은 *자산*으로 등재)

### 의무 사항
1. **전수 분석 원칙**: PDF·문서 정독 시 *모든 문항*을 ★·M·I·X·통찰 유형 라벨링 의무. "표본 N문" / "회차당 ~문 추정" 등 요약 단정 금지.
2. **자산화 의무**: 분석된 문항은 *반드시* `bank/problems/{prefix}-{단원}-{번호}.md` 등재. 보고서에서 식별만 하고 등재 누락 금지.
3. **양이 많으면 작업 분할**: 한 번에 못 끝낼 분량이면 *작업큐로 분할 + 마스터에게 진행 상황 보고* — 표본으로 줄여서 보고하는 것 금지.
4. **분석 보고서**: 전수 분석 완료 후 작성. 일부 분석으로 임시 보고서 송신 금지 (마스터 명시적 임시 요청이 아닌 한).

### Why
본 시스템 목표 ([[project_overall_goal]]): *풍부하고 질 높은 데이터베이스* + *완벽한 교재 제작 시스템*. 데이터베이스 풍부화의 직접 수단이 자산화. 표본 분석은 *데이터 누락*이며 자산 누적 곡선 정체 원인. 시판 책 한 권 정독 시 230~260문 자산이 누락되는 것은 시스템 목표 위반.

### How to apply
- 시판 PDF 정독 요청 시 → 전수 라벨링 작업큐 신설 → 모든 문항 `bank/problems/`에 등재
- 부분 작업으로 분할 시 → TaskCreate로 명시적 큐잉 + 마스터에게 진행 상황 보고
- 보고서 "★ 5 strict 후보 N문" 식별 시 → 그 N문은 *반드시* 같은 세션 또는 후속 작업으로 자산화
