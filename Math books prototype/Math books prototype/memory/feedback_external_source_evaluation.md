# 🔴 외부 자료 평가 절차 영구 정책 (2026-06-29 마스터 신뢰도 의구심 후 확립)

## 사건

2026-06-29 아샘 짱 내신 FINAL 공통수학1 기말고사 분석에서 분석자(클로드)가 다음 오류 단정:
- "부록 2·3·4회 (행렬의 곱셈) → 2022 개정 CM1 범위 외 → RED"

실제 본 시스템 단일 출처 (`bank/CM1-교과과정.md` §1):
- **MX 행렬과 그 연산** | 행렬 성분·같은 행렬·덧셈·뺄셈·실수배·**곱셈**·**거듭제곱**·단위행렬·영행렬·연립일차방정식의 행렬 표현·$AB \neq BA$ 비가환성 인지·**케일리해밀턴 정리 인용 허용**

→ 행렬 곱셈·거듭제곱·케해는 모두 CM1 정규 범위. 분석자가 본 시스템 단일 출처를 직접 명시하면서도 *그 내용을 확인하지 않고* 외부 지식으로 단정한 것이 사건의 본질.

마스터 직접 지적: "rpm 정독만으로도 알 수 있었을텐데 그게 지금 보고가 된다고하면 그동안 수집 작성한 자산 신뢰도에 대해 심각한 의구심이 듬."

## 영구 정책

### 적용 범위
- 시판 책·기출·외부 PDF 정독·분석·평가·보고

### 의무 사항
1. **단일 출처 6종 의무 grep**: 평가 전 `bank/CM1-교과과정.md` + `bank/schema.md` + `bank/anchors/{단원}.md` + `bank/마스터-지적/INDEX.md` + `bank/4점-패턴-카탈로그/` + `bank/CM1-교과과정.md` §3.0 직접 grep.
2. **외부 지식 단정 금지**: "교과 범위 외" / "RED" / "2022 개정 X 제외" 등 표현은 단일 출처 줄 번호 인용 의무.
3. **충돌 시 단일 출처 우선**: 외부 지식이 더 정확해 보여도 분석자 자체 판단 우회 금지. 단일 출처가 틀렸다고 판단되면 *마스터에게 단일 출처 검토 요청*.
4. **자가 점검 체크리스트**: 보고서 송신 전 [[bank/외부자료-평가-절차]] §3 5항목 점검.

### Why
본 시스템의 신뢰도는 *단일 출처 일관성*에서 발생. 분석자가 외부 지식으로 단일 출처를 우회하면 자산(3,225문 등록 문항·앵커·검수 도구) 전체 신뢰도가 흔들림. 마스터의 의구심은 정당.

### How to apply
- 시판 자료 PDF 정독 요청 시 [[bank/외부자료-평가-절차]] 5단계 의무 적용
- 보고서에 단일 출처 줄 번호 인용 없는 RED 단정은 RED (자체 RED)
- 보고서 송신 전 자가 점검 통과 의무
