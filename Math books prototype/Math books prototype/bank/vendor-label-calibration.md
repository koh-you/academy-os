# 벤더 라벨 → 시스템 ★ 회귀 매핑 v1.0

## 목적

시판 교재의 벤더 자체 난이도 라벨(BASIC/NORMAL/TOUGH·●중/상/사고력·STEP 1/2/3 등)이 프로젝트 시스템 ★ (schema.md v3.8 3층 M·I·X 모델)과 얼마나 일치·괴리하는지 실측 데이터로 정량화. 두 방향 활용:

1. **자동 첫 판정**: 새 시판 교재를 정독할 때 벤더 라벨만 보고 시스템 ★ 첫 값을 배정
2. **캘리브레이션 지표**: 벤더별 라벨 신뢰도 (표준편차·이상치 비율) 산출 → 벤더별 가중치

## 실측 데이터 요약

**표본**: 쎈 CM2-GM 평면좌표 35문 + 마플시너지 CM2-GM 평면좌표 35문 = **70문 실측**
**정독 파일**: [`bank/mechanism-데이터-쎈-CM2-GM-평면좌표.md`](mechanism-데이터-쎈-CM2-GM-평면좌표.md) · [`bank/mechanism-데이터-마플시너지-CM2-GM-평면좌표.md`](mechanism-데이터-마플시너지-CM2-GM-평면좌표.md)

## Ⅰ. 쎈 (SSEN) 벤더 라벨 매핑

### 원 라벨 체계

- **단계**: A단계 기본다잡기 · B단계 유형뽀개기 · C단계 실력굳히기
- **부가 마킹**: 대표문제 · ● 중 · ● 상 · 서술형 · 사고력의 기술 아이콘 · 교육청 기출

### 실측 회귀 (표본 35문)

| 벤더 라벨 | 표본 수 | 실측 ★ 분포 | 최빈 ★ | 예측 함수 |
|---|---|---|---|---|
| A단계 기본 | 5 | ★ 1×4 · ★ 2×1 | **★ 1** | `A → ★ 1 (신뢰도 80%)` |
| B단계 대표문제 | 10 | ★ 2×4 · ★ 3×4 · ★ 4×2 | **★ 2~3** | `B단계 대표 → ★ 2.8 (편차 0.7)` |
| B단계 ● 상 | 5 | ★ 3×2 · ★ 4×3 | **★ 4** | `B단계 상 → ★ 3.6 (편차 0.5)` |
| C단계 (일반) | 5 | ★ 3×2 · ★ 4×3 | **★ 3~4** | `C 일반 → ★ 3.6 (편차 0.5)` |
| C단계 사고력 아이콘 | 6 | ★ 4×4 · ★ 5×2 | **★ 4** | `C 사고력 → ★ 4.3 (편차 0.5)` |
| C단계 교육청 기출 | 4 | ★ 4×3 · ★ 5×1 | **★ 4** | `C 교육청 → ★ 4.3 (편차 0.5)` |

### 회귀 함수 요약 (쎈)

```
쎈_star_predict(label) =
  if label == "A단계 기본":           1  (신뢰도 80%)
  elif label == "B단계 대표문제":      3  (편차 0.7 · ★ 2도 30% 확률)
  elif label == "B단계 ● 중":          3  (예측, 실측 부족 → 회귀 미확정)
  elif label == "B단계 ● 상":          4  (편차 0.5)
  elif label == "C단계 사고력·교육청":  4  (편차 0.5)
  elif label == "C단계 서술형":         원 판정 유지 (형식 라벨)
  else:                                3  (기본)
```

### 쎈 이상치 (실측 예측 편차 ≥ 1)

- **쎈-0072** (C단계 서술형): 예측 ★ 3~4 · 실측 ★ 4 · **정합**
- **쎈-0083** (C단계 사고력): 예측 ★ 4 · 실측 ★ 5 premium · **premium은 별도 판정 필요**
- **쎈-0032** (B단계 대표): 예측 ★ 3 · 실측 ★ 2 · **-1 편차** (표준 절차 · 통찰 부재)

**신뢰도 등급**: **B급** (편차 0.5~0.7 · 표본 35 · 70% 정합)

## Ⅱ. 마플시너지 (Mapl Synergy) 벤더 라벨 매핑

### 회귀 함수 요약 (마플시너지)

```
마플_star_predict(label) =
  if label == "BASIC":               2  (편차 0.5 · ★ 1도 40% 확률)

  elif label == "TOUGH":             4  (편차 0.5 · ★ 3도 17% 확률, ★ 5도 8%)
  elif label == "STEP 2 서술형":     4  (편차 0.0, 표본 부족)
  elif label == "STEP 3 일등급":     4  (편차 0.7 · ★ 5도 40% 확률)
  else:                              3
```

### 마플시너지 이상치 (실측 예측 편차 ≥ 1)

- **마-0006** (BASIC, 학평 4번): 예측 ★ 2 · 실측 ★ 1 · **-1 편차**
- **마-0042** (TOUGH, 학평): 예측 ★ 4 · 실측 ★ 3 · **-1 편차** (내분점 표준 계산 · TOUGH 과대 라벨링)
- **마-0037** (TOUGH, 빈칸 유도): 예측 ★ 4 · 실측 ★ 3 · **-1 편차** (빈칸 유도로 학생 부담↓)

## Ⅲ. 벤더 간 비교

### 라벨 신뢰도 비교

| 벤더 | 최다 라벨 수준 | 표본 정합률 | 편차 (평균) | 이상치 비율 | 등급 |
|---|---|---|---|---|---|
| **쎈** | 3~4 층 (A/B중/B상/C) | 70% | 0.7 | 8% (35 중 3) | **B급** |
| **마플시너지** | 3층 (BASIC/NORMAL/TOUGH) + STEP 2/3 | 74% | 0.5 | 14% (35 중 5) | **A급** |

**해석**:
- 마플시너지 라벨링 정합률이 근소 우세 (74% vs 70%)
- **다만 마플시너지는 학평 문제 라벨링에서 STEP 3·TOUGH를 과대 부여**하는 편향 관찰 (마-0037·0042·0115). "학평 원문"이라는 이유만으로 최상위 라벨 부여 경향.
- **쎈은 자체 편입 특수 예제 (0083)에서 premium 임계 안정적으로 도달**. 반면 마플시너지는 학평 원문에 의존.

### 최상위 (★ 5) 예측 정확도

| 라벨 | 실측 ★ 5 이상 비율 | 라벨 커버 |
|---|---|---|
| 쎈 C단계 사고력+교육청 | 20% (10 중 2) | 낮은 예측력 |
| 마플시너지 STEP 3 | 40% (5 중 2) | 중간 예측력 |
| 마플시너지 TOUGH | 8% (12 중 1) | 낮은 예측력 |
| **쎈 SPECIAL TIP 편입 (특수 표시)** | 100% (1 중 1) | **높은 예측력** (표본 1, 확대 필요) |

### premium 예측

두 교재 모두 **벤더 라벨만으로는 premium 예측 불가**. schema.md v3.8 이중 게이트 (depth_score ≥ 8.5 + max=3 + count≥5 + signal_ref P 카드 2개) 실측 계산 필수.

**단, 첫 판정 heuristic**:
- 쎈: **SPECIAL TIP 예제로 편입된 문항**이 premium 후보 (0083 근거, 표본 확대 필요)
- 마플시너지: **모의고사 핵심유형 + 학평 문번 25번 이상 + 3D 도형·킬러 그림**이 premium 후보 (0088 근거)

## Ⅳ. `scripts/star-classify.mjs` v1.1 확장 스펙

### 현재 (v1.0)

정답률 → tier 매핑 (schema.md §2 v3.0 캘리브레이션 기반):

```
correct_rate < 25%     → star_5_premium
correct_rate 25~45%    → star_5
correct_rate 45~65%    → star_4
correct_rate 65~85%    → star_3
correct_rate > 85%     → 배제
```

또는 마더텅 미니모의 (정답률 미수록 시):

```
score=4점 + 번호 27~30 or 20~22 → star_5_premium
score=4점 + 번호 17~19, 23~26   → star_5
score=4점 + 번호 14~16          → star_4
score=3점 + 번호 12~15          → star_3~4
score=3점 + 번호 초반           → star_3
score=2점 + 초반                → star_1~2
```

### v1.1 신규 축 (벤더 라벨)

```
vendor_star_predict(publisher, label, unit) = {

  if publisher == "쎈":
    if label matches "A단계":         return {star: 1, confidence: 0.8}
    if label matches "B단계 대표":     return {star: 3, confidence: 0.4, alt: [2]}
    if label matches "B단계 ● 상":     return {star: 4, confidence: 0.6, alt: [3]}
    if label matches "C단계 사고력":   return {star: 4, confidence: 0.7, alt: [5]}
    if label matches "C단계 교육청":   return {star: 4, confidence: 0.75}
    if label matches "SPECIAL TIP":   return {star: 5, confidence: 0.9, premium_flag: true}

  elif publisher == "마플시너지":
    if label == "BASIC":              return {star: 2, confidence: 0.6, alt: [1]}
    if label == "NORMAL":             return {star: 3, confidence: 0.7, alt: [4]}
    if label == "TOUGH":              return {star: 4, confidence: 0.75, alt: [3, 5]}
    if label == "STEP 2 서술형":       return {star: 4, confidence: 0.9}
    if label == "STEP 3 일등급":       return {star: 4, confidence: 0.4, alt: [5, 3]}
    if label == "STEP 3 + 학평 25번+": return {star: 5, confidence: 0.85, premium_flag: true}

  return {star: null, confidence: 0}
}
```

**신뢰도(confidence) 활용**:
- confidence ≥ 0.75 → 자동 첫 판정 (수동 검증 후순위)
- confidence 0.5~0.75 → 첫 판정은 배정하되 스팟체크 필요
- confidence < 0.5 → 수동 판정 강제

**alt (대안 ★)**: 실측 편차 ≥ 1 발생 시 대안으로 재분류 (수동 검증 시)

## Ⅶ. 파일럿 한계 · 향후 개선

### 표본 편향

- **단원 편향**: CM2-GM 평면좌표 1개 소단원만 실측. 다른 단원 (특히 CM1-CB·CM1-MX·CM2-FN)에서 벤더 라벨 특성 다를 가능성
