## §2. RPM 유형 해결 공략법 표준 (R-공략)

> **핵심**: 각 유형 앞에 *해결 공략법 박스*가 위치. 본 시스템은 답지의 \soltitle 또는 \solnote 도입에 채택 가능.

### §2.1 다항식의 연산 (1장)
| 유형 | 공략법 표준 |
|---|---|
| **R-K01** 다항식의 덧셈과 뺄셈 | 다항식의 덧셈과 뺄셈은 다음과 같은 순서로 계산한다. (i) 괄호가 있는 경우 괄호를 푼다. (ii) 동류항끼리 모아서 간단히 정리한다. |
| **R-K02** 다항식의 전개식에서 계수 구하기 | 다항식의 전개식에서 특정한 항의 계수를 구할 때에는 분배법칙을 이용하여 특정한 항이 나오도록 각 다항식에서 하나씩 선택하여 곱한다. |
| **R-K03** 곱셈 공식을 이용한 다항식의 전개 | 곱셈 공식을 이용하여 식을 전개할 때에는 곱셈 공식들 중 어느 공식을 이용하는 꼴인지 확인한다. |
| **R-K04** 공통부분이 있는 다항식의 전개 | (1) 공통부분을 한 문자로 놓고 곱셈 공식을 이용한다. (2) $()()()()$의 꼴 → 공통부분이 생기도록 짝을 지어 전개한 후 곱셈 공식을 이용한다. |
| **R-K05** 곱셈 공식의 변형 — 문자 2개 | (1) $a^2 + b^2 = (a+b)^2 - 2ab = (a-b)^2 + 2ab$. (2) $(a+b)^2 = (a-b)^2 + 4ab$. (3) $a^3 \pm b^3 = (a \pm b)^3 \mp 3ab(a \pm b)$ |
| **R-K06** $x \pm \dfrac{1}{x}$의 꼴 | (1) $x^2 + \dfrac{1}{x^2} = \left(x + \dfrac{1}{x}\right)^2 - 2 = \left(x - \dfrac{1}{x}\right)^2 + 2$. (2) $x^3 + \dfrac{1}{x^3} = \left(x + \dfrac{1}{x}\right)^3 - 3\left(x + \dfrac{1}{x}\right)$ ... 참고: $x^2 - px + 1 = 0$의 꼴의 조건식이 주어진 경우에는 $x \ne 0$이므로 양변을 $x$로 나누어 $x + \dfrac{1}{x} = p$의 꼴로 변형한다. |
| **R-K07** 곱셈 공식의 변형 — 문자 3개 | $a^2 + b^2 + c^2 = (a+b+c)^2 - 2(ab+bc+ca)$, $a^3 + b^3 + c^3 = (a+b+c)(a^2+b^2+c^2 - ab-bc-ca) + 3abc$ |
| **R-K08** 곱셈 공식을 이용한 수의 계산 | 곱셈 공식을 이용할 수 있도록 식을 변형하거나 하나의 수를 두 수의 합 또는 차로 나타낸다. |
| **R-K09** 다항식의 나눗셈 — 몫과 나머지 | 다항식의 나눗셈은 각 다항식을 내림차순으로 정리한 다음 자연수의 나눗셈과 같은 방법으로 계산한다. 이때 나머지는 상수이거나 나머지의 차수는 나누는 식의 차수보다 낮다. |
| **R-K10** 다항식의 나눗셈 — $A = BQ + R$ | 다항식 $A$를 다항식 $B$ ($B \ne 0$)로 나누었을 때의 몫을 $Q$, 나머지를 $R$라 하면 $A = BQ + R$. |
| **R-K11** 몫과 나머지의 변형 | 다항식 $f(x)$를 $x + \dfrac{b}{a}$ ($a \ne 0$)로 나누었을 때의 몫을 $Q(x)$, 나머지를 $R$라 하면 ... → $f(x)$를 $ax + b$로 나누었을 때의 몫은 $\dfrac{1}{a} Q(x)$, 나머지는 $R$이다. |
| **R-K12** 조립제법 | 다항식을 일차식으로 나누었을 때의 몫과 나머지를 구할 때에는 조립제법을 이용하면 편리하다. |
| **R-K13** 특수한 식의 변형 | (1) $a^2 + b^2 + c^2 - ab - bc - ca = \dfrac{1}{2}\{(a-b)^2 + (b-c)^2 + (c-a)^2\}$. (2) $a^2 + b^2 + c^2 + ab + bc + ca = \dfrac{1}{2}\{(a+b)^2 + (b+c)^2 + (c+a)^2\}$ |
| **R-K14** 곱셈 공식의 도형 활용 | 주어진 도형의 선분의 길이를 문자로 놓고 길이, 넓이, 부피 등을 이 문자로 나타낸 후 곱셈 공식을 이용한다. |

### §2.2 항등식과 나머지정리 (2장)
| 유형 | 공략법 표준 |
|---|---|
| **R-K15** 미정계수 — 계수 비교법 | 주어진 식을 전개하여 내림차순으로 정리한 후 양변의 동류항의 계수를 비교한다. |
| **R-K16** 미정계수 — 수치 대입법 | 계산이 간단한 식을 얻을 수 있도록 적당한 수를 미정계수의 개수만큼 대입한다. |
| **R-K17** 조건을 만족시키는 항등식 | (1) $x$, $y$에 대한 관계식이 주어진 경우 → 주어진 관계식을 한 문자에 대하여 정리한 후 등식에 대입하면 그 문자에 대한 항등식이 된다. (2) $x$에 대한 방정식이 $k$의 값에 관계없이 항상 $\alpha$를 근으로 갖는 경우 → 방정식에 $x = \alpha$를 대입하면 $k$에 대한 항등식이 된다. |
| **R-K18** 항등식에서 계수의 합 | $(x+a)^n = a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n$의 꼴 → 양변에 적당한 수를 대입하여 계수에 대한 식을 세운다. |
| **R-K19** 일차식으로 나누었을 때의 나머지 | 다항식 $f(x)$를 $x - a$로 나누었을 때의 나머지 ⇒ $f(a)$ |
| **R-K20** 이차식으로 나누었을 때의 나머지 | (1) 다항식 $f(x)$를 이차식으로 나누었을 때의 나머지는 상수이거나 일차식이므로 나머지를 $ax + b$ ($a$, $b$는 상수)로 놓는다. (2) 다항식 $f(x)$를 $(x - \alpha)(x - \beta)$로 나누었을 때의 나머지 → $f(\alpha)$, $f(\beta)$의 값을 이용한다. |
| **R-K21** 삼차식으로 나누었을 때의 나머지 | 다항식 $f(x)$를 삼차식으로 나누었을 때의 나머지는 상수이거나 이차 이하의 다항식이므로 나머지를 $ax^2 + bx + c$ ($a$, $b$, $c$는 상수)로 놓는다. |
| **R-K22** $f(ax + b)$를 $x - \alpha$로 나누는 경우 | 다항식 $f(ax + b)$를 $x - \alpha$로 나누었을 때의 나머지 ⇒ $f(a\alpha + b)$ |
| **R-K23** 몫을 $x - \alpha$로 나누는 경우 | 다항식 $f(x)$를 $x - \alpha$로 나누었을 때의 몫이 $Q(x)$, 나머지가 $R$이면 $f(x) = (x - \alpha)Q(x) + R$이고, $Q(x)$를 $x - \beta$로 나누었을 때의 나머지는 $Q(\beta)$이다. |
| **R-K24** 인수정리 — 일차식 | 다항식 $f(x)$가 $x - \alpha$로 나누어떨어진다. ⇒ $f(\alpha) = 0$ |
| **R-K25** 인수정리 — 이차식 | 다항식 $f(x)$가 $(x - \alpha)(x - \beta)$로 나누어떨어진다. ⇒ $f(\alpha) = 0$, $f(\beta) = 0$ |
| **R-K26** 조립제법과 항등식 | 조립제법을 연속으로 이용하면 내림차순으로 정리한 식에서 미정계수를 구할 수 있다. |
| **R-K27** 수의 나눗셈에서 나머지정리의 활용 | 자연수 $A$를 자연수 $B$로 나누었을 때의 나머지는 $A$를 $x$에 대한 다항식, $B$를 $x$에 대한 일차식으로 나타낸 후 나머지정리를 이용하여 구한다. |

### §2.3 인수분해 (3장)
| 유형 | 공략법 표준 |
|---|---|
| **R-K28** 인수분해 공식을 이용한 다항식의 인수분해 | 인수분해 공식: $(1) a^2+b^2+c^2+2ab+2bc+2ca = (a+b+c)^2$, $(2) a^3 \pm 3a^2b + 3ab^2 \pm b^3 = (a \pm b)^3$, $(3) a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$, $(4) a^4 + a^2b^2 + b^4 = (a^2+ab+b^2)(a^2-ab+b^2)$, $(5) a^3+b^3+c^3-3abc = (a+b+c)(a^2+b^2+c^2-ab-bc-ca)$. |
| **R-K29** 공통부분이 있는 다항식의 인수분해 | (1) 공통부분을 한 문자로 치환한 후 인수분해한다. (2) $()()()()  + k$의 꼴의 식 → 공통부분이 생기도록 짝을 지어 전개한 후 치환한다. |
| **R-K30** $x^4 + ax^2 + b$ 꼴의 인수분해 | (1) $x^2 = X$로 치환하여 인수분해한다. (2) 이차항 $ax^2$을 분리하여 $A^2 - B^2$의 꼴로 변형한 후 인수분해한다. |
| **R-K31** 여러 개의 문자가 포함된 다항식의 인수분해 | (1) 차수가 가장 낮은 한 문자에 대하여 내림차순으로 정리한 후 인수분해한다. (2) 모든 문자의 차수가 같으면 어느 한 문자에 대하여 내림차순으로 정리한 후 인수분해한다. |
| **R-K32** 순환하는 꼴의 다항식의 인수분해 | $a$, $b$, $c$의 차수가 같으면서 순환하는 꼴의 다항식은 한 문자에 대하여 내림차순으로 정리한 후 인수분해한다. |
| **R-K33** 인수정리를 이용한 다항식의 인수분해 | 삼차 이상의 다항식 $f(x)$는 다음과 같은 순서로 인수분해한다. (i) $f(\alpha) = 0$을 만족시키는 $\alpha$의 값을 구한다. (ii) 조립제법을 이용하여 $f(x)$를 $x - \alpha$로 나누었을 때의 몫 $Q(x)$를 구한 후 $f(x) = (x - \alpha) Q(x)$의 꼴로 나타낸다. (iii) $Q(x)$가 더 이상 인수분해되지 않을 때까지 인수분해한다. ($f(\alpha) = 0$을 만족시키는 $\alpha$의 값은 $\pm \dfrac{(\text{상수항의 약수})}{(\text{최고차항의 계수의 약수})}$ 중에서 찾을 수 있다.) |

| **R-K35** 인수분해를 이용한 식의 값 구하기 | 곱셈 공식과 인수분해 공식을 이용하여 식을 변형한 후 주어진 조건을 식에 대입한다. |

## §2.8 연립일차부등식 (8장)

|---|---|
| **R-K96** 연립일차부등식의 풀이 | (i) 각각의 일차부등식을 푼다. (ii) 각 부등식의 해를 수직선 위에 나타낸다. (iii) 공통부분을 찾아 주어진 연립부등식의 해를 구한다. |
| **R-K97** $A < B < C$의 꼴의 부등식 | $A < B < C$의 꼴의 부등식은 연립부등식 $\{A < B; B < C\}$의 꼴로 고쳐서 푼다. |
| **R-K98** 특수한 해를 갖는 연립일차부등식 | (1) 해가 없는 경우 → 각 부등식의 해를 수직선 위에 나타내었을 때 공통부분이 없다. (2) 해가 하나뿐인 경우 → 공통부분이 한 점뿐이다. |
| **R-K99** 연립일차부등식의 해가 주어진 경우 | 각 일차부등식을 풀고, 주어진 연립부등식의 해와 비교하여 미정계수를 구한다. |
| **R-K100** 연립일차부등식이 해를 갖거나 갖지 않는 경우 | (1) 해를 갖는 경우 → 공통부분이 있도록 각 부등식의 해를 수직선 위에 나타낸다. (2) 해가 없는 경우 → 공통부분이 없도록 각 부등식의 해를 수직선 위에 나타낸다. |
| **R-K101** 연립일차부등식의 활용 | (i) 구하려는 것을 미지수 $x$로 놓는다. (ii) 주어진 조건을 이용하여 연립부등식을 세운다. (iii) 연립부등식을 풀고 구한 해가 문제의 조건에 맞는지 확인한다. |
| **R-K102** $\|ax + b\| < c, \|ax + b\| > c$의 꼴 | (1) $\|ax+b\| < c$ → $-c < ax+b < c$. (2) $\|ax+b\| > c$ → $ax+b < -c$ 또는 $ax+b > c$. |
| **R-K103** $\|ax + b\| < cx + d$의 꼴 | 절댓값 기호 안의 식의 값이 0이 되는 $x$의 값을 기준으로 범위를 나누어 푼다. |
| **R-K104** 절댓값 기호가 두 개인 부등식 | 두 일차식 $f(x), g(x)$에 대하여 $f(a) = 0, g(b) = 0$ ($a < b$)일 때, $\|f(x)\| + \|g(x)\| < c$의 꼴의 부등식 → $x$의 값의 범위를 $x < a$, $a \le x < b$, $x \ge b$로 나누어 푼다. |
| **R-K105** 절댓값 기호를 포함한 부등식의 해가 없거나 무수히 많은 경우 | (1) $\|ax+b\| < c$의 해가 없다 → $c \le 0$. (2) $\|ax+b\| > c$의 해가 모든 실수 → $c < 0$. |

| **R-K107** 연립일차부등식의 활용 — 과부족 | (1) 물건을 한 사람에게 $k$개씩 나누어 주는 경우 → 사람의 수를 $x$로 놓는다. (2) 한 의자에 $n$명씩 앉으면 $k$개의 의자가 남는 경우 → 의자의 개수를 $x$로 놓고 마지막에는 최소 1명에서 최대 $n$명까지 앉을 수 있음을 이용한다. |

## §2.9 이차부등식과 연립이차부등식 (9장)
| 유형 | 공략법 표준 |
|---|---|
| **R-K108** 그래프를 이용한 부등식의 풀이 | (1) $f(x) > 0$ → $y = f(x)$의 그래프가 $x$축보다 위쪽에 있는 부분의 $x$의 값의 범위. (2) $f(x) > g(x)$ → $y = f(x)$의 그래프가 $y = g(x)$의 그래프보다 위쪽에 있는 부분의 $x$의 값의 범위. |
| **R-K109** 이차부등식의 풀이 | 이차방정식 $f(x) = 0$의 판별식 $D$라 할 때 (1) $D > 0$이면 $f(x)$를 인수분해하거나 근의 공식을 이용한다. (2) $D \le 0$이면 $f(x) = a(x-p)^2 + q$의 꼴로 변형한다. |
| **R-K110** 절댓값 기호를 포함한 이차부등식 | $\|A\| = \{A \,(A \ge 0); -A \,(A < 0)\}$임을 이용하여 절댓값 기호를 없앤다. |
| **R-K111** 해가 주어진 이차부등식 | (1) 해가 $\alpha < x < \beta$이고 $x^2$의 계수가 1인 이차부등식 → $(x-\alpha)(x-\beta) < 0$. (2) 해가 $x < \alpha$ 또는 $x > \beta$ ($\alpha < \beta$)이고 $x^2$의 계수가 1인 이차부등식 → $(x-\alpha)(x-\beta) > 0$. |
| **R-K112** 부등식 $f(x) < 0$과 $f(ax+b) < 0$의 관계 | $f(x) = p(x-\alpha)(x-\beta)$이면 $f(ax+b) = p(ax+b-\alpha)(ax+b-\beta)$. $f(x) < 0$의 해가 $\alpha < x < \beta$이면 $f(ax+b) < 0$의 해는 $\alpha < ax+b < \beta$를 만족시키는 $x$의 값의 범위. |
| **R-K113** 이차부등식의 해가 한 개일 조건 | (1) $ax^2 + bx + c \ge 0$의 해가 한 개일 조건 → $a < 0, b^2 - 4ac = 0$. (2) $ax^2 + bx + c \le 0$의 해가 한 개일 조건 → $a > 0, b^2 - 4ac = 0$. |
| **R-K114** 이차부등식이 해를 가질 조건 | $ax^2 + bx + c > 0$이 해를 가질 조건 (1) $a > 0$ → 이차부등식은 항상 해를 갖는다. (2) $a < 0$ → $b^2 - 4ac > 0$. |
| **R-K115** 이차부등식이 항상 성립할 조건 | 모든 실수 $x$에 대하여 (1) $ax^2 + bx + c > 0$ 성립 → $a > 0, D < 0$. (2) $ax^2 + bx + c \ge 0$ 성립 → $a > 0, D \le 0$. (3) $ax^2 + bx + c < 0$ 성립 → $a < 0, D < 0$. (4) $ax^2 + bx + c \le 0$ 성립 → $a < 0, D \le 0$. |
| **R-K116** 이차부등식이 해를 갖지 않을 조건 | $ax^2 + bx + c > 0$이 해를 갖지 않을 조건 → 모든 실수 $x$에 대하여 $ax^2 + bx + c \le 0$ 성립 → $a < 0, b^2 - 4ac \le 0$. |
| **R-K117** 제한된 범위에서 항상 성립하는 이차부등식 | (1) $\alpha \le x \le \beta$에서 $f(x) > 0$ 항상 성립 → $\alpha \le x \le \beta$에서 $f$의 최솟값 $> 0$. (2) $\alpha \le x \le \beta$에서 $f(x) < 0$ 항상 성립 → $\alpha \le x \le \beta$에서 $f$의 최댓값 $< 0$. |
| **R-K118** 두 그래프의 위치 관계 — 특정 범위에서 성립 | (1) $f$가 $g$보다 위쪽 → $f(x) > g(x)$의 해. (2) $f$가 $g$보다 아래쪽 → $f(x) < g(x)$의 해. |
| **R-K119** 두 그래프의 위치 관계 — 항상 성립 | (1) $f$가 항상 위쪽 → 모든 실수 $x$에 대하여 $f(x) > g(x)$ 성립. (2) $f$가 항상 아래쪽 → 모든 실수 $x$에 대하여 $f(x) < g(x)$ 성립. |
| **R-K120** 이차부등식의 활용 | (i) 주어진 조건에 맞게 부등식을 세운다. (ii) 부등식을 풀어 해를 구한다. 이때 미지수의 값의 범위에 주의한다. |
| **R-K121** 연립이차부등식의 풀이 | (i) 주어진 각 부등식의 해를 구한다. (ii) (i)에서 구한 해의 공통부분을 구한다. |
| **R-K122** 절댓값 기호를 포함한 연립부등식 | 양수 $k$에 대하여 (1) $\|f(x)\| < k$ → $-k < f(x) < k$. (2) $\|f(x)\| > k$ → $f(x) < -k$ 또는 $f(x) > k$. |
| **R-K123** 해가 주어진 연립이차부등식 | 각 부등식의 해의 공통부분이 주어진 해와 일치하도록 수직선 위에 나타내고 미지수의 값의 범위를 구한다. |
| **R-K124** 연립이차부등식의 활용 | (i) 주어진 조건에 맞게 부등식을 세운다. (ii) 각 부등식의 해를 구한 후 공통부분을 구한다. |
| **R-K125** 이차방정식의 근의 판별과 이차부등식 | $D$ 값에 따른 근의 판별 + 이차부등식 결합. |
| **R-K126** 이차방정식의 실근의 부호 | (1) 두 근이 모두 양수 → $D \ge 0, \alpha + \beta > 0, \alpha\beta > 0$. (2) 두 근이 모두 음수 → $D \ge 0, \alpha + \beta < 0, \alpha\beta > 0$. (3) 두 근이 서로 다른 부호 → $\alpha\beta < 0$. |
| **R-K127** 이차방정식의 실근의 위치 | (1) 두 근이 모두 $p$보다 크다 → $D \ge 0, f(p) > 0, -\dfrac{b}{2a} > p$. (2) 두 근이 모두 $p$보다 작다 → $D \ge 0, f(p) > 0, -\dfrac{b}{2a} < p$. (3) 두 근 사이에 $p$가 있다 → $f(p) < 0$. |

| **R-K132** 수형도를 이용하는 경우의 수 | 규칙성을 찾기 어려운 경우의 수를 구할 때에는 수형도를 이용한다. 이때 중복되거나 빠진 것이 없도록 주의한다. |
| **R-K133** 지불 방법의 수와 지불 금액의 수 | (1) 단위가 다른 화폐의 개수가 각각 $l, m, n$일 때, 지불하는 방법의 수 → $(l+1)(m+1)(n+1) - 1$. (2) 만들 수 있는 금액이 중복되는 경우가 있을 때, 지불 금액의 수 → 큰 단위의 화폐를 작은 단위의 화폐로 바꾸어 생각한다. |
| **R-K134** 도로망에서의 경우의 수 | (1) 동시에 갈 수 없는 길 → 합의 법칙 이용. (2) 연이어 갈 수 있는 길 → 곱의 법칙 이용. |
| **R-K135** 색칠하는 방법의 수 | 인접한 영역이 가장 많은 영역에 색칠하는 경우의 수를 먼저 구한 후 각 영역에 칠할 수 있는 색의 개수를 차례로 구하여 곱한다. |
| **R-K136** 이웃하는 순열의 수 | (i) 이웃하는 것을 한 묶음으로 생각하여 일렬로 나열하는 경우의 수를 구한다. (ii) 한 묶음 안에서 자리를 바꾸는 경우의 수를 구한다. (iii) (i)과 (ii)의 경우의 수를 곱한다. |
| **R-K137** 이웃하지 않는 순열의 수 | (i) 이웃해도 상관없는 것을 일렬로 나열하는 경우의 수를 구한다. (ii) (i)에서 나열한 것의 사이사이와 양 끝에 이웃하지 않는 것을 나열하는 경우의 수를 구한다. (iii) (i)과 (ii)의 경우의 수를 곱한다. |
| **R-K138** 자리에 대한 조건이 있는 순열 | 특정한 자리에 대한 조건이 있는 경우 → 특정한 자리에 오는 것을 먼저 나열한 후 나머지를 나열한다. |
| **R-K139** "적어도 ~"의 조건이 있는 순열 | (사건 $A$가 적어도 한 번 일어나는 경우의 수) $=$ (모든 경우의 수) $-$ (사건 $A$가 일어나지 않는 경우의 수). |
| **R-K140** 순열을 이용한 자연수의 개수 | (1) 주어진 조건에 따라 기준이 되는 자리부터 먼저 배열하고, 나머지 자리에는 남은 숫자들을 배열한다. (2) 맨 앞자리에는 0이 올 수 없음에 주의한다. |
| **R-K141** 사전식 배열에 의한 경우의 수 | 문자열을 알파벳순으로 배열하거나 수를 크기순으로 나열하는 경우 → 먼저 정해진 문자 또는 숫자를 나열하고, 나머지 자리에 올 수 있는 순열의 수를 구한다. |

## §2.11 조합 (11장)
| 유형 | 공략법 표준 |
|---|---|
| **R-K142** $_nC_r$의 계산 | $_nC_r = \dfrac{_nP_r}{r!} = \dfrac{n!}{r!(n-r)!}$. $_nC_0 = 1, _nC_n = 1, _nC_r = _nC_{n-r}$. |
| **R-K143** $_nC_r$를 이용한 증명 | $_nC_r = \dfrac{n!}{r!(n-r)!}$임을 이용하여 주어진 등식이 성립함을 증명한다. |
| **R-K144** 조합의 수 | 서로 다른 $n$개에서 순서를 생각하지 않고 $r$개를 택하는 경우의 수 → $_nC_r$. |
| **R-K145** "적어도 ~"의 조건이 있는 조합 | (사건 $A$가 적어도 한 번 일어나는 경우의 수) $=$ (모든 경우의 수) $-$ (사건 $A$가 일어나지 않는 경우의 수). |
| **R-K146** 특정한 것을 포함하거나 포함하지 않는 조합 | (1) 특정한 $k$개를 포함하여 뽑는 경우의 수 → $_{n-k}C_{r-k}$. (2) 특정한 $k$개를 제외하고 뽑는 경우의 수 → $_{n-k}C_r$. |
| **R-K147** 뽑아서 나열하는 경우의 수 | $m$개 중에서 $n$개를 뽑아 일렬로 나열하는 경우의 수 → $_mC_n \times n!$. |
| **R-K148** 직선의 개수 | (1) 어느 세 점도 일직선 위에 있지 않은 서로 다른 $n$개의 점으로 만들 수 있는 직선의 개수 → $_nC_2$. (2) 일직선 위에 있는 서로 다른 $n$ ($n \ge 2$)개의 점으로 만들 수 있는 직선의 개수 → 1. |
| **R-K149** 대각선의 개수 | $n$각형의 대각선의 개수는 $n$개의 꼭짓점 중 2개를 택하여 만들 수 있는 선분의 개수에서 변의 개수를 뺀 것과 같다. → $_nC_2 - n$. |
| **R-K150** 다각형의 개수 — 꼭짓점 | (1) 어느 세 점도 일직선 위에 있지 않은 서로 다른 $n$개의 점이 있을 때 (1) 3개의 점을 꼭짓점으로 하는 삼각형의 개수 → $_nC_3$. (2) 4개의 점을 꼭짓점으로 하는 사각형의 개수 → $_nC_4$. (2) 일직선 위에 있는 서로 다른 $n$개의 점으로는 다각형을 만들 수 없다. |
| **R-K151** 다각형의 개수 — 변 | $m$개의 평행선과 이와 평행하지 않은 $n$개의 평행선이 만날 때 생기는 평행사변형의 개수 → $_mC_2 \times _nC_2$. |
| **R-K152** 분할하는 경우의 수 | 서로 다른 $n$개의 물건을 $p$개, $q$개, $r$개 ($p + q + r = n$)의 세 묶음으로 나누는 경우의 수 (1) $p, q, r$가 모두 다른 수인 경우 → $_nC_p \times _{n-p}C_q \times _rC_r$. (2) $p, q, r$ 중 어느 두 수가 같은 경우 → $_nC_p \times _{n-p}C_q \times _rC_r \times \dfrac{1}{2!}$. (3) $p, q, r$가 모두 같은 수인 경우 → $_nC_p \times _{n-p}C_q \times _rC_r \times \dfrac{1}{3!}$. |
| **R-K153** 분배하는 경우의 수 | $n$묶음으로 나누어 $n$명에게 나누어 주는 경우의 수 → ($n$묶음으로 나누는 경우의 수) $\times n!$. |
| **R-K154** 대진표 작성하기 | 주어진 그림을 보고 분할하는 경우의 수를 이용하여 대진표를 작성하는 경우의 수를 구한다. |

## §2.12 행렬 (12장)
| 유형 | 공략법 표준 |
|---|---|
| **R-K155** 행렬 구하기 | 행렬 $A$의 $(i, j)$ 성분 $a_{ij}$가 식이나 설명으로 주어진 경우에는 뜻에 따라 $a_{ij}$의 $i, j$에 각각 1, 2, 3, $\ldots$을 대입하여 행렬의 성분을 구한다. |
| **R-K156** 두 행렬이 서로 같을 조건 | $\begin{pmatrix} a & b \\ c & d \end{pmatrix} = \begin{pmatrix} p & q \\ r & s \end{pmatrix}$이면 $a = p, b = q, c = r, d = s$. |
| **R-K157** 행렬의 덧셈, 뺄셈, 실수배 | (1) 행렬의 덧셈, 뺄셈, 실수배는 행렬의 성분의 덧셈, 뺄셈, 실수배를 이용하여 계산한다. (2) 행렬을 포함하는 등식 → 이항하여 간단히 정리한 다음 행렬을 대입한다. |
| **R-K158** 조건을 만족시키는 행렬 | 행렬 $A, B$에 대한 두 등식이 주어진 경우 → $A, B$에 대한 연립방정식으로 생각하여 $A$ 또는 $B$를 소거한다. |
| **R-K159** 행렬의 변형 | $A = \begin{pmatrix} a_{11} \\ a_{21} \end{pmatrix}, B = \begin{pmatrix} b_{11} \\ b_{21} \end{pmatrix}, C = \begin{pmatrix} c_{11} \\ c_{21} \end{pmatrix}$에 대하여 $xA + yB = C$이면 $a_{11}x + b_{11}y = c_{11}, a_{21}x + b_{21}y = c_{21}$. |
| **R-K160** 행렬의 곱셈 | (1) 두 행렬 $A, B$의 곱 $AB$는 $A$의 열의 개수와 $B$의 행의 개수가 서로 같을 때만 정의된다. (2) $\begin{pmatrix} a & b \\ c & d \end{pmatrix}\begin{pmatrix} x & u \\ y & v \end{pmatrix} = \begin{pmatrix} ax+by & au+bv \\ cx+dy & cu+dv \end{pmatrix}$. |
| **R-K161** 행렬의 곱셈의 변형 | 이차정사각행렬 $A$에 대하여 $A\begin{pmatrix}a \\ b\end{pmatrix} = \begin{pmatrix}p \\ q\end{pmatrix}, A\begin{pmatrix}c \\ d\end{pmatrix} = \begin{pmatrix}r \\ s\end{pmatrix}$이면 $A\begin{pmatrix}a+c \\ b+d\end{pmatrix} = A\begin{pmatrix}a \\ b\end{pmatrix} + A\begin{pmatrix}c \\ d\end{pmatrix} = \begin{pmatrix}p+r \\ q+s\end{pmatrix}$. |
| **R-K162** 행렬의 거듭제곱 | 자연수 $m, n$에 대하여 (1) $A^{n+1} = A^n A$. (2) $A^m A^n = A^{m+n}, (A^m)^n = A^{mn}$. |
| **R-K163** 행렬의 곱셈에 대한 성질 | 두 행렬 $A, B$에 대하여 일반적으로 $AB \ne BA$이므로 행렬에서는 곱셈 공식, 인수분해 공식을 적용할 수 없다. → $(A-B)^2 \ne A^2 - 2AB + B^2$, $(A-B)^2 = A^2 - AB - BA + B^2$. |
| **R-K164** 단위행렬의 성질 | 같은 꼴의 정사각행렬 $A$와 단위행렬 $E$에 대하여 (1) $AE = EA = A$. (2) $E^n = E$. (3) $(A \pm E)(A^2 \mp A + E) = A^3 \pm E$. |
| **R-K165** $A^n$의 추정 | $A^2, A^3, \ldots$을 차례대로 구하여 $A^n = E$를 만족시키는 자연수 $n$의 최솟값을 찾은 다음 $A^n$의 규칙성을 이용한다. |
| **R-K166** 행렬의 곱셈의 여러 가지 성질 | (1) $A \ne O, B \ne O$이지만 $AB = O$인 경우가 있다. (2) $AB = AC, A \ne O$이지만 $B \ne C$인 경우가 있다. |
