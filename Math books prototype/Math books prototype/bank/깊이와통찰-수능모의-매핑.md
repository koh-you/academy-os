## 2. 마스터 통찰 — 학원 자체 시험 정답률 정규화 (cohort_type)

### 2.1 문제

학원 자체 시험은 **표본 작음(수십~수백) + 상위권 편향**으로 정답률 절대값이 실제 전국 학평보다 5~15%p 높음. 26문항 샘플 평균 67%는 전국 학평 평균(~50%)보다 높음.

→ **절대값을 ground truth로 쓰면 안 됨**. schema v1.4.3 §10.6 cohort_type=`academy_internal` 정규화 절차 적용.

### 2.2 정규화 절차 (schema §10.6 인용)

```
[1] 같은 cohort(예: 메인 파일 150문항) 정답률 전체 수집
[2] mean / std / percentile 산정
[3] 각 문항 z-score = (r_i - mean) / std
[4] z → 상대 ★ 매핑
    z > +1.0   → 상대 ★1 (상위 16% — 쉬움)
    +0.3 ~ +1.0 → 상대 ★2
    -0.3 ~ +0.3 → 상대 ★3 (평균 부근)
    -1.0 ~ -0.3 → 상대 ★4
    z < -1.0   → 상대 ★5 (하위 16% — 어려움)
[5] external_labels에 actual_correct_rate(raw) / relative_difficulty_z / cohort_normalized_star 기록
```

### 2.3 유형별 정규화 (선택 — 표본 풍부 시)

유형마다 평균 정답률 다름 (예: 다항식 덧셈 85%, 인수분해 65%). cohort 내 같은 유형 표본 ≥ 20이면 유형 단위 분리 정규화 권장.

## 5. 마더텅 자료와 교차 매핑 절차

### 5.1 공통점 — 같은 학평 회차 문항 보유

| 자료       | 학평 회차 표기                        | 라벨                    |
| ---------- | ------------------------------------- | ----------------------- |
| 마더텅     | 표기 (예: "2024년 6월학평 28번(고1)") | ★ 1~4 + 배점           |
| 깊이와통찰 | 표기 (예: "2024년 9월 고1 1번/2점")   | 정답률 + 시판 책 페이지 |

→ 같은 학평 회차의 같은 문항이 양쪽에 있을 가능성 있음 (변형 정도 차이).

### 5.2 교차 매핑 알고리즘

```
for each 깊이와통찰 문항 d_i:
  학평 회차·번호 추출 (예: 2024.09 고1 1번)
  마더텅 자료에서 같은 회차·번호 검색
  if 매칭 발견:
    마더텅 ★ vs 깊이와통찰 상대 ★ 비교
    delta_meta = motherteng_star - di_cohort_star
    flag:
      |delta| ≤ 1 → 정합 (양쪽 라벨 일관)
      |delta| = 2 → 주의 (변형 정도 차이로 추정)
      |delta| ≥ 3 → mismatch (라벨 드리프트 또는 변형 큼)
```

### 5.3 교차 calibration의 가치

- **마더텅 ★ vs 깊이와통찰 정답률** → 출판사 추정과 학원 실측의 일관성 검증
- 정합 시 양쪽 라벨 동시 신뢰 → calibration ground truth 강화
- mismatch 발견 시 → 변형 정도 또는 라벨 드리프트 보고

## 6. 작업 흐름

### 6.1 단계별 진행

```
[Phase 1] 메인 파일 150문항 메타 추출 (현재 26문항 진행 — 124문항 남음)
   ↓
[Phase 2] 메인 150문항 cohort 분포 산정 (mean / std / 유형별)
   ↓ z-score → 상대 ★ 산정
[Phase 3] DI-2026M-001~150 문항 bank/problems/에 status: meta_only 등록
        external_labels.cohort_type = academy_internal
        external_labels.relative_difficulty_z + cohort_normalized_star 채움
   ↓
[Phase 4] 마더텅 자료와 교차 매핑 (회차·번호 매칭)
   ↓
[Phase 5] (1)~(13) 파일 확장 진행 (시기 신뢰도순)
        우선순위: 메인 > (1) 2024 > (2) 2023 > ... (최신부터)
   ↓
[Phase 6] schema §10.4 calibration log 1차 분석
```

### 6.2 우리 책 슬롯 활용

- **상대 ★3 + 빈도 ≥ 2** = 우리 책 ★3 슬롯 후보 1순위
- **상대 ★4·★5** = 우리 책 ★4·★5 슬롯 + 앵커 후보
- 시판 책 유사 출처(예: 라이트쎈 50p 327)는 우리 카탈로그(01-다항식.md 등)의 T-code 출처 풀에 추가 가능 → 카탈로그 v0.5 갱신

## 7. 보유 자료 비교 — 깊이와통찰 vs 마더텅

| 항목           | 깊이와통찰 (≈2,010)       | 마더텅 (1,585)   |
| -------------- | -------------------------- | ---------------- |
| 정답률         | **있음** (학원 자체) | 없음             |
| ★ 라벨        | 없음                       | ★1~4            |
| 학평 회차      | 표기                       | 표기             |
| 배점           | 표기                       | 표기             |
| 시판 책 페이지 | **표기**             | 없음             |
| 단원 구분      | 혼합 (공수1+공수2)         | 공수1만          |
| 시기           | 2004~2026 (22년)           | 2003~2024 (22년) |
| 우리 8축 입력  | 정규화 z-score → 상대 ★  | 마더텅 ★ + 배점 |

→ **상호 보완**. 같은 학평 회차 문항을 양쪽 자료에서 발견하면 교차 calibration → 가장 정확한 ground truth.
