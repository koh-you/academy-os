# 1. A5d — MX 행렬

## 1.1 현행: 고쟁이 CM1-CH10-STEP3 #880 (본문 p.227 · `교육청 기출`)

**요지** — 크기가 다른 두 도로망 그림. 작은 것은 $\mathrm{P_1,P_2}$(위) → $\mathrm{Q_1,Q_2}$(아래), 큰 것은 $\mathrm{R_1,R_2}$(위) → $\mathrm{S_1,S_2}$(아래). 이차정사각행렬 $A$ 의 $(i,j)$ 성분을 $a_{ij}=(\mathrm{P}_i$ 에서 도로를 따라 $\mathrm{Q}_j$ 까지 최단 거리로 가는 방법의 수$)$ 라 할 때, $\mathrm{R_1}\to\mathrm{S_2}$ 최단경로 수와 **같은 것**은? (5지선다: ① $2A$ 의 $(1,2)$ ② $A^2$ 의 $(1,2)$ ③ $A^2$ 의 $(2,1)$ ④ $A$ 의 $(1,2)\cdot(2,2)$ ⑤ $A$ 의 $(1,2)\cdot(2,1)$) → **정답 ②**

**무엇을 스스로 만들어야 하는가**
1. 큰 도로망이 **작은 도로망을 두 번 이어붙인 것**임을 그림에서 알아본다 (발문은 한마디도 하지 않는다)
2. $\mathrm{R_1}\to\mathrm{S_2}$ 경로는 반드시 이음매의 두 마디 중 하나를 지난다 → 곱의 법칙 + 합의 법칙으로 분해
3. 그 합 $\sum_k a_{1k}a_{k2}$ 가 **행렬 곱 $A^2$ 의 $(1,2)$ 성분의 정의 그 자체**임을 잇는다

**게이트** — score 9.00 ✓ · max 3 ✓ · count 5 ✓ → 표면상 통과. **엄격 적용 시 count 2 → 탈락** (§0.3).

## 1.3 실전 대결 후보 2문 (직접 풀었다)

### 후보 A — 블랙라벨 09 #02 (본문 p.110 · 답 $n=11$)

두 이차정사각행렬 $A=(a_{ij})$, $B=(b_{ij})$ 에 대하여 $a_{ij}-a_{ji}=0$, $b_{ij}+b_{ji}=0$ 이고 $A-2B=\begin{pmatrix}1&1\\1&1\end{pmatrix}$. $A^n-C=B^n$ 을 만족시키는 행렬 $C$ 의 모든 성분의 합이 $2^{12}$ 일 때 자연수 $n$.

**무엇을 스스로 만들어야 하는가**
1. $b_{ij}+b_{ji}=0$ 에서 $i=j$ 를 대입해 **$b_{11}=b_{22}=0$** 을 끌어낸다 (발문에 없다 · 유일하게 낯선 지점)
2. 성분 비교 → $a_{12}-2b_{12}=1$ 과 $a_{12}+2b_{12}=1$ → $b_{12}=0$, 즉 **$B=O$** — 굳이 준 $B$ 가 사라진다
3. $A=\begin{pmatrix}1&1\\1&1\end{pmatrix}$ 의 $A^n=2^{\,n-1}A$ 를 스스로 찾는다 → 성분합 $2^{\,n+1}=2^{12}$

**게이트** — score **8.20 < 8.5** ✗ · max 3 ✓ · count 5 ✓ → **탈락**

**4규칙**

| 규칙 | 판정 |
|---|---|
| ① 견줄 수 있을 것 | △ — 케해·진위판정은 아니나, 「행렬 조건 → 성분 연립 → 거듭제곱 규칙」은 **MX 의 표준 문법**이다. 견주면 단원 숙련도를 재게 된다 |
| ② 같은 통찰 중복 | 🔴 △ — 2단계 「조건만으로 미지 대상의 형태를 확정」이 **A5a(차수 확정)와 같은 계열**이다. 3단계 $A^n=2^{n-1}A$ 는 A5c(주기)에 약하게 닿는다. 한 문항이 A5 두 자리와 겹친다 |
| ③ 노동형 금지 | ✅ 짧다 |
| ④ 교과 안 | ✅ 행렬의 상등·곱·거듭제곱뿐. `A^{-1}`·`tr A` 없음 |

🔴 결정적 약점: 2단계의 「$B=O$ 붕괴」는 **통찰이 아니라 성분 비교의 결과**다. 학생이 MX 표준 절차를 밀기만 하면 저절로 도달한다 — 판별자 「해야 할 일이 지시되어 있는가」에서 **지시돼 있다**.

### 후보 B — 블랙라벨 09 #03 (본문 p.110 · 답 3)

$A=\begin{pmatrix}0&0\\1&-1\end{pmatrix}$ 에 대하여 (가) $AM=MA$ (나) $M$ 의 모든 성분의 합이 4 (다) $M$ 의 모든 성분은 음이 아닌 정수 — 를 만족시키는 이차정사각행렬 $M$ 의 개수.

**무엇을 스스로 만들어야 하는가** — $M=\begin{pmatrix}a&b\\c&d\end{pmatrix}$ 로 놓고 $AM=MA$ 를 성분 연립 ($b=0$, $d=a-c$) → 합 조건에 넣으면 **$c$ 가 상쇄되어 $2a=4$** (놀람은 이 한 점) → $c\in\{0,1,2\}$ → 3개.

**게이트** — score 8.20 ✗ → **탈락**

**4규칙** — ③ ✅ · ④ ✅ 이나 **① △ (가환 $M$ 세기는 MX 관용 유형) · 깊이 층이 하나뿐이라 A5 급이 아니다** (A3~A4 급). 답이 3이라는 것 자체가 얕음의 신호.

### 후보 A — 블랙라벨 08 #12 「원판 두 탑」 (본문 p.97 · 답 4235)
