# 결과 — 앵커 자료를 통일한 것이 결정적이었다

사전 등록: `실험F-사전등록-v1.md` (결과 보기 전 작성)

## 1. 네 묶음 비교

| 묶음 | 앵커 자료 | 경계 설명 | **일치** | 최상위 등급 사용 |
|---|---|:-:|:-:|:-:|
| 지난 비교군 | 원본 시험지 열람 | 없음 | 14/20 **70%** | 2문 · 3문 |
| 지난 시험군 | 원본 안 봄 | 있음 | 15/20 **75%** | 1문 · 1문 |
| **이번 비교군** | **발췌본** | 없음 | **20/20 · 100%** | 2문 · 2문 |
| **이번 시험군** | **발췌본** | 있음 | 19/20 **95%** | 1문 · 1문 |

## 2. 🔴 사전 등록 기준 판정 — 경계 설명은 **효과 없다**

| # | 기준 | 실측 | |
|:-:|---|---|:-:|
| 1 | 시험군이 비교군보다 **+10%p 이상** | **−5%p** (95% vs 100%) | ❌ |
| 2 | 시험군 최상위 등급 **한 사람당 2문 이상** | **1문 · 1문** | ❌ |
| 3 | 「견줄 상대가 없다」 0건 | 0건 | ✅ |

**경계 설명은 일치율을 올리지 못했고, 오히려 낮췄다.** 그리고 **최상위 등급을 닫는다.**

🔴 **앵커 자료를 통일해도 최상위가 1문으로 붕괴한 것이 반복됐다.**
→ 붕괴 원인은 앵커 접근이 아니라 **경계 설명 문장 자체**임이 확정됐다.

**경계 설명을 사다리에 넣지 않는다.** 초안은 `경계규정-W1.md`·`-W2.md` 에 기록으로만 남긴다.

## 3. 🔴 그러나 진짜 성과는 다른 데서 나왔다

**앵커 자료를 발췌본으로 통일한 것 하나로 일치율이 70% → 100% 로 뛰었다.**

이번 세션에서 시도한 개입은 셋이었다.

| 무엇을 바꿨나 | 일치율 |
|---|---|
| 앵커를 6문 → 40문으로 늘림 | 75% → 75% (변화 없음) |
| 정점 앵커 5건 교체 | 75% → 70% |
| 경계 설명 추가 | 70% → 75% (교락 있음) · 100% → 95% (교락 없음) |
| **앵커 자료 통일 (발췌본)** | **70% → 100%** |

🔴 **네 문항 중 한 문항이 갈리던 원인은 앵커 수도, 앵커 품질도, 경계 설명 부재도 아니었다.
채점자마다 앵커를 다르게 파악한 것이었다.**

같은 앵커를 저마다 원본 시험지에서 제 나름대로 읽으니 **자가 사람마다 달랐다.**
발췌본이 그것을 하나로 만들었다.

## 4. 🔴 이 100% 를 그대로 믿지 마라

**세 가지 유보를 단다.**

1. **채점자가 사람이 아니라 프로그램이다.** 같은 문서를 읽은 두 프로그램은
   **서로 독립이 아닐 수 있다.** 100% 는 「과제가 잘 정의됐다」는 뜻일 수도,
   「둘이 같은 방식으로 읽었다」는 뜻일 수도 있다
2. **같은 20문을 다섯 번째 쓴다.** 문항이 소진돼 간다
3. 🔴 **비교군도 경계 기준을 스스로 만들어 냈다** — 발췌본에 대조쌍(차수를 주는 문항과 안 주는 문항)이
   나란히 실려 있어 한 채점자가 **「발판을 빼앗는가」로 눈금을 지어냈다**고 적었다.
   즉 두 묶음의 차이가 그만큼 흐려졌다. **차이가 없다고 「경계 설명이 무용하다」로 읽으면 안 된다** —
   다만 최상위 등급이 닫히는 것은 별개의 확실한 해다

**→ 새 문항으로 다시 재야 확정된다.**

## 5. 경계 설명이 판정을 어디로 옮겼나

두 묶음이 갈린 6문항이 **거의 전부 아래로** 갔다.

| 문항 | 비교군 → 시험군 |
|:-:|---|
| 6문 중 5문 | **한 등급 아래로** (★ 5 급 → ★ 4 급 등) |
| 1문 | 한 등급 위로 |

경계 설명이 **판정을 전반적으로 깎는다.** 특히 최상위를 닫는다.

## 6. 채점자들이 짚은 자의 결함 (네 명 공통)

| 지적 | 몇 명 |
|---|:-:|
| **★ 1~2 급이 너무 넓다** — 20문 중 6~7문을 삼킨다 | 3명 |
| **단원이 같은 앵커가 없어 지시를 못 지켰다** (복소수·항등식·절댓값 부등식) | 2명 |
| **빈칸 채우기가 등급을 흐린다** | 2명 |
| **시판 앵커 4문은 한 번도 쓰이지 않았다** | 1명 |
| 말로 옮긴 그림이 원본보다 얕다 | 2명 |

🔴 두 번째가 **앵커를 몇 개 둘 것인가의 진짜 물음**이다 — 일치율이 아니라 **견줄 상대가 있느냐**.
