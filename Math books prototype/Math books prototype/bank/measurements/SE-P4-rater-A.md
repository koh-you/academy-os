### #4 — 두 점 A(0,4)·B(4,0)과 점 P(x,y) · 보기 ㄱㄴㄷ

- **SE1 = 3** : `GM-01`(두 점 사이 거리) · `ST-04`(조건의 진리집합) · `ST-05`(필요·충분조건 판정)
  - GM-01 근거: "$\overline{\mathrm{AP}}^{2}=x^{2}+(y-4)^{2},\qquad \overline{\mathrm{BP}}^{2}=(x-4)^{2}+y^{2}$"
  - ST-04 근거: "두 조건의 진리집합이 모두 직선 $y=x$ 이므로"
  - ST-05 근거: "$x^{2}+y^{2}=2xy$ 는 $x=y$ 이기 위한 필요충분조건이다"
  - 안 셈: $(x-y)^2=0$ 으로 묶는 것 — 곱셈공식 수준의 조작. `GM-02`(ㄷ의 두 직선 교점 논증)도 안 셈 — 반례 하나로 이미 끝나므로 **가장 짧은 경로에 불필요**
- **SE2 = 3** : 거리식 → 진리집합 동치 → 포함관계 판정. 근거 연쇄 "$\overline{\mathrm{AP}}^{2}-\overline{\mathrm{BP}}^{2}=8x-8y$" → "이 조건도 $x=y$ 와 같다" → "따라서 충분조건이다"
  - ㄱ·ㄴ·ㄷ 는 **병렬 3판정**이라 사슬이 아니다. 최장 갈래(ㄴ) 기준
- **SE3 = 0** : 발문이 "옳은 것을 모두 고른 것은?" — 각 보기를 정방향 진위 확인. ㄷ의 반례 P(0,0) 도 진리집합 $y=x$ 를 이미 알고 그 위의 한 점을 댄 것이라 역산이 아니다
  - 근거: "점 $\mathrm{P}(0,\,0)$ 은 $\overline{\mathrm{AP}}=\overline{\mathrm{BP}}=4$ 이면서 $x+y=0\ne 4$ 이다"
- **SE4-a = 0 / SE4-b = 0 / SE4-c = 0** : 세 값 일치. 답지 전체에 「경우로 나누면·두 가지·각각에 대하여」 표지어가 **한 곳도 없다**. 보기 3개는 case-split 이 아니라 **병렬로 주어진 세 명제**
- **SE5 = 0** (모호) : 인용 가능한 확인 문장은 "그러나 $x=y$ 를 만족시키는 점은 직선 $y=x$ 위에 무수히 많으므로 역은 성립하지 않는다" 뿐인데, ㄴ은 **충분조건**만 물었으므로 역 확인 없이도 논증이 닫힌다 → 「확인하지 않으면 논증이 끝나지 않는」 지점에 해당하지 않아 0
- **SE6 = 1** : ㄴ이 실제로는 필요충분조건인데 발문은 "충분조건이다"로 묻는다. 표준 유형은 충분(비필요)일 때 충분조건을 묻는다 — **종료점이 어긋난다**
  - 근거(답지 헤더 rev11): "ㄴ 은 실제로 필요충분조건이나 발문이 충분조건으로 물었고, 필요충분조건이면 충분조건이기도 하므로 참"
- **판정 불가 항목**: 없음 (SE5 는 0 으로 확정하되 근거가 「없음」이라는 성격이라 모호 표시)

### #6 — n(A∪B)=17 · n(A∩B)=3 · n(A)는 n(B)의 배수

- **SE1 = 3** : `ST-03`(원소 개수·포함배제) · `ST-01`(부분집합) · **[미등재] 약수·배수 논증**
  - ST-03 근거: "$n(A)+n(B)=n(A\cup B)+n(A\cap B)=17+3=20$"
  - ST-01 근거: "$A\cap B$ 는 $A$ 와 $B$ 의 부분집합이므로 $n(A)\ge 3$, $n(B)\ge 3$"
  - 미등재 근거: "$d$ 는 $d$ 의 약수이기도 하므로 두 수의 합인 $20$ 의 약수이다" — `bank/도구-카테고리.md` 에 **정수(약수·배수) 도구 코드가 없다**. 대조표 결손
- **SE2 = 3** : 포함배제(합=20) → 배수조건을 약수조건으로 변환 → 후보 열거. ST-01 의 하한은 이 사슬에 **병렬 투입**되는 제약이라 사슬 길이를 늘리지 않는다
- **SE3 = 1** : 미지 $d$ 를 조건에서 역산. 근거 "$n(B)=d$ 라 하면 $n(A)=20-d$ 이고, 조건 (나)에서 $d$ 는 $20-d$ 의 약수이다"
- **SE4-a = 3? / SE4-b = 1 / SE4-c = 1**
  - a 근거: "$20$ 의 약수 $1,\,2,\,4,\,5,\,10,\,20$ 중 이 범위에 드는 것은 $d=4,\,5,\,10$"
  - b 근거: 「$d$ 의 값을 정해야 한다」는 판단 1회
  - c 근거: "$(n(A),\,n(B))=(16,\,4),\ (15,\,5),\ (10,\,10)$" — 세 쌍 모두 $20-d$ 대입뿐. **앞 갈래의 계산을 그대로 재사용**
  - 셋이 다른 이유 + a 에 물음표를 단 이유: 이것은 **분기가 아니라 부정방정식의 해 열거**다. v1.2 문면은 "분기에서 갈라진 갈래" 라 규정하므로 분기 지점이 없으면 a=0 이어야 하는데, 실기출 #10 「이등변삼각형 3경우 = 3」 전례를 따르면 a=3 이다. **명세에 「해 열거」와 「case-split」의 구분이 없다**
- **SE5 = 2** : (i) 하한 — "$A\cap B$ 는 $A$ 와 $B$ 의 부분집합이므로 $n(A)\ge 3$, $n(B)\ge 3$" (ii) 상한 — "$20-d$ 는 $d$ 의 배수이면서 양수이므로 $20-d\ge d$ 에서 $3\le d\le 10$"
  - 안 셈: "세 쌍 모두 $n(A)$ 가 $n(B)$ 의 배수이다" — d가 20의 약수이면 20-d의 약수임이 **이미 동치**라 잉여 확인
- **SE6 = 1** : 집합 단원 표준 경로(포함배제로 개수 범위)에서 **정수의 약수 논증으로 갈아타는 지점**이 시중 표준 유형에 없다. 근거는 위 SE1 미등재 인용과 같은 문장
- **판정 불가 항목**: **SE4-a** — 「해 열거 vs 분기」 구분 부재로 0 과 3 이 모두 정당화된다

### #7 — 두 원의 공통현이 존재하도록 하는 정수 k

- **SE1 = 2** : `GM-03`(원의 방정식·완전제곱) · `GM-04`(두 원의 위치 관계)
  - GM-03 근거: "$x$ 에 대한 항을 완전제곱 꼴로 묶으면 $(x-k)^{2}+y^{2}=4$"
  - GM-04 근거: "그 조건은 중심 사이의 거리가 두 반지름의 차와 합 사이에 있는 것"
  - 안 셈: 중심 사이 거리 — "두 중심 사이의 거리는 $|k|$ 이다" 는 두 중심이 모두 $x$ 축 위라 **대입 수준**이지 GM-01 호출이 아니다
- **SE2 = 3** : 완전제곱(중심·반지름) → 위치 관계 부등식 → 정수 열거. 근거 "$3-2<|k|<3+2,\qquad 곧\ 1<|k|<5$"
- **SE3 = 1** : "공통현이 존재하도록 하는 정수 $k$ 의 개수" — 결과 조건에서 $k$ 역산. 근거 "공통현이 존재할 조건은 두 원이 서로 다른 두 점에서 만날 조건과 같다"
- **SE4-a = 2 / SE4-b = 1 / SE4-c = 1**
  - a·b 근거: 절댓값 $|k|$ 를 벗기는 지점 1회 · 갈래 $k>0$·$k<0$ 2개
  - c 근거: "$|k|=2,\,3,\,4$ 에서 $k=\pm 2,\ \pm 3,\ \pm 4$" — **부호 대칭이라 한쪽 계산이 나머지를 덮는다** → 묶어 1
  - 셋이 다른 이유: 갈래는 부호 2 갈래지만 나눔 판단은 1회이고 실제 계산은 대칭이라 1
- **SE5 = 1** : 경계 배제 — "점선으로 그린 두 원은 각각 $|k|=1$ 일 때 안으로 접하고 $|k|=5$ 일 때 밖으로 접하여 만나는 점이 하나뿐이므로 공통현이 생기지 않는다. 두 경계는 제외한다"
- **SE6 = 0** : 「두 원이 서로 다른 두 점에서 만날 조건 → 중심거리 부등식 → 정수 개수」는 시중 표준 유형 그대로다. "공통현" 이라는 **어휘만 바뀌었고 경로는 어긋나지 않는다**. 어휘 낯섦을 SE6 으로 셀 근거 문장은 답지에 없다
- **판정 불가 항목**: 없음

### #10 — 두 직선까지의 거리의 합이 4인 점이 나타내는 도형의 넓이

- **SE1 = 2** : `GM-02`(점과 직선 사이의 거리 · 평행·수직 판정) · **[CM1-EQ-06] 절댓값 방정식**
  - GM-02 근거: "$d_{1}=\dfrac{|3x-4y+5|}{5},\qquad d_{2}=\dfrac{|4x+3y-10|}{5}$"
  - EQ-06 근거: "두 식 $3x-4y+5$, $4x+3y-10$ 의 부호가 같으면 두 식의 합의 절댓값이 $20$ 이고 부호가 다르면 두 식의 차의 절댓값이 $20$"
  - GM-02 는 평행선 사이 거리 계산에서 재사용되지만 **같은 도구의 반복이라 1**
- **SE2 = 4** : 가장 짧은 경로(별해) 기준 — 거리식 → 조건의 절댓값 표현 → 수직·교점 → 대각선 → 넓이
  - 근거: "$3\cdot 4+(-4)\cdot 3=0$ 이므로 두 직선 $l_{1}$, $l_{2}$ 는 서로 수직이고, 두 식을 연립하면 교점은 $(1,\,2)$ 이다" → "두 대각선은 각각 $l_{1}$, $l_{2}$ 위에 놓이고 길이가 모두 $8$ 이다" → "$\dfrac{1}{2}\cdot 8\cdot 8=32$"
- **SE3 = 1** : "$d_{1}+d_{2}=4$ 를 만족시키는 점 $\mathrm{P}$ 전체" — 조건에서 점을 역산하는 자취. 근거 "조건 $d_{1}+d_{2}=4$ 는 $|3x-4y+5|+|4x+3y-10|=20$"
- **SE4-a = 4? / SE4-b = 1 / SE4-c = 2**
  - a 근거: "$7x-y=25,\quad 7x-y=-15,\ x+7y=35,\quad x+7y=-5$" — 네 직선 = 네 갈래
  - b 근거: 「두 식의 부호를 나눠야 한다」 판단 1회
  - c 근거: **합 꼴과 차 꼴은 서로 다른 방정식**이라 재사용 불가 → 2. 각 꼴 안의 우변 부호 뒤집기는 재사용 가능 → 묶임
  - a 에 물음표를 단 이유: **규약 §2-1(가장 짧은 경로)과 SE4 가 충돌**한다. 별해로 재면 절댓값 분해를 아예 하지 않으므로 SE4 는 a=b=c=0 이 된다. 다만 별해는 "두 대각선은 각각 $l_{1}$, $l_{2}$ 위에 놓이고" 라는 **도형의 형상을 이미 전제**하므로 단독으로는 논증이 닫히지 않는다고 보고 주 경로로 측정했다
- **SE5 = 1** : 도형 확정 — "이웃한 두 변이 수직이고 마주 보는 두 변 사이의 거리가 모두 같으므로 이 도형은 한 변의 길이가 $4\sqrt{2}$ 인 정사각형이고"
  - 안 셈: "네 직선 … 의 일부이고" 의 유효 영역 확인 — **인용할 검증 문장이 답지에 없다**(규약 §2-3에 따라 값을 만들지 않음)
- **SE6 = 1** : 「점과 직선 사이의 거리」는 표준이나 **두 직선까지의 거리의 합이 일정한 자취**는 시중 표준 유형 밖이다. 근거 "$|3x-4y+5|+|4x+3y-10|=20$"
- **판정 불가 항목**: **SE4 전체** — 짧은 경로 규약을 그대로 적용하면 0, 주 경로면 (4,1,2). 두 값의 차가 §3 판정 「2 이상 = 기준 모호」에 걸린다

### #12 — 넓이가 최소일 때 PA·PB

- **SE1 = 3** : `GM-02`(직선의 절편 형식) · `ST-07`(절대부등식 · 산술기하) · `GM-01`(두 점 사이 거리)

  - ST-07 근거: "산술평균과 기하평균의 관계에서 $1=\dfrac{2}{a}+\dfrac{3}{b}\ \ge\ 2\sqrt{\dfrac{6}{ab}}$"
  - GM-01 근거: "$\overline{\mathrm{PA}}=\overline{\mathrm{PB}}=\sqrt{2^{2}+3^{2}}=\sqrt{13}$"
- **SE2 = 4** : 절편식+P 대입 → 산술기하 하한 → 등호 조건으로 $a,b$ 확정 → 거리·곱
  - 근거 연쇄: "$\dfrac{2}{a}+\dfrac{3}{b}=1$" → "$ab\ge 24$" → "$\dfrac{2}{a}=\dfrac{3}{b}=\dfrac{1}{2}$ 에서 $\mathrm{A}(4,\,0),\ \mathrm{B}(0,\,6)$" → "$\overline{\mathrm{PA}}\cdot\overline{\mathrm{PB}}=13$"
- **SE3 = 1** : 넓이 최소라는 결과에서 두 절편을 역산. 근거 "넓이가 최소인 것은 등호가 성립할 때이고, 이때 …"
- **SE4-a = 0 / SE4-b = 0 / SE4-c = 0** : 세 값 일치. 분기 표지어 없음. 기울기 음수가 발문에 못박혀 부호 갈래조차 생기지 않는다 ("조건 (가)에서 기울기가 음수이고 … 두 절편은 모두 양수이다")
- **SE5 = 1** : 산술기하 적용 전제 확인 — "$\dfrac{2}{a}>0$, $\dfrac{3}{b}>0$ 이므로"
  - 등호 성립 조건은 **답을 정하는 계산**이라 SE3 에 넣고 여기서 이중 계상하지 않았다
- **SE6 = 1** : 표준 경로의 종료점은 넓이 최솟값 12 인데, 이 문항은 **등호 성립 조건이 정하는 두 절편**에서 다시 한 걸음 나간다
  - 근거(답지 헤더 rev10): "#12 종료점 변경: 넓이 최솟값 12 → 등호 성립 조건이 정하는 두 절편에서 PA·PB = 13"
- **판정 불가 항목**: 없음

### #15 — 부분집합을 점으로 옮겨 원의 안팎 가리기 (3소문항)
