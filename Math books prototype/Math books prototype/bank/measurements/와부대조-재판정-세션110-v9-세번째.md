# 세 번째 판정 — v9

## 1. 🔴 세 번 고쳤고 세 번 다 내려갔다

| 안 | 무엇 | 맹검 값 | 판정자 |
|:-:|---|:-:|---|
| **v1** | 자체 창작 · 진리집합·공집합 융합 | **4.90** | R1·R2·R3 |
| **v2** | 학평 #21 최소 변형 (보기형을 소문항으로) | **4.70** | S1·S2·S3 |
| **v3** | 학평 2026.3 고2 #28 · **계단식으로 이음** | **4.33** | T1·T2·T3 |

**고칠 때마다 낮아졌다.** 겨눈 것은 5.5~5.7 이었다.

🔴 **판을 건너뛴 견주기는 조심해야 한다.** 이번 판은 전체가 낮게 나왔다 (실기출 평균 4.06 → **3.93**).
같은 판 안에서 견주면 —

| | v2 판(S) | v3 판(T) |
|---|:-:|:-:|
| 우리 15번 | 4.70 | **4.33** |
| 실기출 12번 | 4.53 | 4.43 |
| 실기출 14번 | 4.40 | 4.50 |

v2 는 실기출 12·14번 **위**였고, v3 는 그 **아래**다. **판 흔들림을 걷어내도 내려갔다.**

## 2. 왜 내려갔나 — 판정자 셋이 같은 것을 짚었다

| 판정자 | 값 | 적은 말 |
|:-:|:-:|---|
| T1 | 4.4 | (1)(2)가 표와 원소를 넘겨도 (3)의 단조 조건은 새로 논증 |
| T2 | 4.3 | **(2)가 후보 집합을 넘겨 줘 깊이가 깎인다** |
| T3 | 4.3 | **(2)가 가장 큰 집합을 넘겨 (3)이 확인 작업으로 내려온다** |

🔴 **셋 중 둘이 「(2)가 (3)을 확인 작업으로 만든다」고 적었다.**

### 내가 세운 잣대가 성글었다

세션 110 에 이렇게 못 박았다 — 「앞이 넘기는 것은 **대상**이지 **논법**이 아니다」
([[feedback_subitems_pass_objects_not_arguments]]). v3 는 그 잣대를 통과했다. 넘긴 것이 집합이니 대상이다.

**그런데 대상도 크기가 있다.**

| | 실기출 15번 (5.53) | 우리 v3 (4.33) |
|---|---|---|
| (1)이 넘기는 것 | 부등식 $0<a^{2}+b^{2}<16$ — **후보를 좁힐 뿐** | 일의 자리 표 |
| (2)가 넘기는 것 | 겹침 세는 식 | **후보 집합 $\{1,3,5,7,9\}$ 자체** |
| (3)이 하는 일 | 판 셋을 새로 겹친다 | **다섯 개를 하나씩 확인한다** |

🔴 **후보를 「좁히는 것」과 「나열해 주는 것」은 다르다.** 뒤가 유한 확인으로 내려앉으면 깊이가 사라진다.
잣대를 이렇게 고쳐야 한다 — **넘긴 뒤에도 뒤 소문항의 경우의 수가 열려 있어야 한다.**

🔴 **프리미엄 한 칸을 빼면 두 회차가 거의 완전히 포갠다.**

판정자 일치는 **79%** (셋 다 같은 칸). 세 판 내리 79 · 68 · 79 · **79** 다.

## 4. 🔴 만드는 힘의 한계 — 이제 실측이다

> **마스터 (2026-08-03)**: 「밴드가 있고 없고가 문제가 아니라 **문제 창작 능력이 한계 있는 거 아냐?**」

**네 판·판정자 열둘이 쌓였다.**

| | 실기출 | 우리 |
|---|:-:|:-:|
| 프리미엄 (네 판) | 1 · 1 · 1 · **1** | 0 · 0 · 0 · **0** |
| 가장 높은 값 | 5.63 · 5.63 · 5.53 · **5.53** | 5.20 · 5.33 · 5.40 · **5.03** |

- **잣대는 꼭대기를 안다.** 실기출 15번은 **네 판 전부**에서 34문 중 꼭대기였고 값이 5.5~5.6 에 모였다
- **우리는 네 판 전부 0 이다.** 방식을 세 번 바꿨는데도 그렇다 —
  자체 창작 → 원본 최소 변형 → 계단식 재구성
- 🔴 **세 번의 시도가 모두 다른 원인으로 실패했다.**
  v1 은 층이 없어서, v2 는 안 이어져서, v3 는 이어 준 것이 너무 커서

**한 방향으로 못 밀고 있다. 고칠 때마다 다른 데가 무너진다.**

## 5. 마스터가 정할 것

| 길 | 무엇을 하나 |
|:-:|---|
| **가** | **네 번째를 시도한다** — 잣대를 고쳐서 (「넘긴 뒤에도 경우의 수가 열려 있어야 한다」) |
