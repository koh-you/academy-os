# 실험 C — 안정성 (사전 등록)

**묻는 것**: 자가 시간이 지나도 같은가. 같은 문항을 다시 얹으면 같은 칸에 놓이는가.

🔴 **판정 4축 중 유일하게 한 번도 측정하지 않은 축이다.**
재현성만 있고 안정성이 없으면 **「그날의 자」**다.

## 1. 설계

| 항목 | 값 |
|---|---|
| **대상** | 본 검정과 **같은 20문** — `bank/measurements/본검정-맹검지-20문-v1.md` |
| **자** | 🔴 **수리된 사다리** (CM2 19문 · CM1 21문) |
| **판정자** | **V3 · V4** — 신규 2인. V1·V2 산출물을 보지 않는다 |
| **맹검** | 회차·문번·배점·단원 제거된 전사본. 밴드 구성 비공개 |
| **비교 대상** | V1 · V2 (2026-08-01 · 수리 전 사다리) |
| 신규 문항 | **0** · 정점 밴드 소모 **0** |

### 🔴 자가 바뀐 구간과 안 바뀐 구간을 나눈다

수리에서 바뀐 것은 **전부 A5 밴드**다 (CM2 A5c 제거 · A5d·A5e 교체 / CM1 A5a·A5d 교체).
A1~A4 앵커는 **한 문도 바뀌지 않았다.**

| 구간 | 자 | 무엇을 재는가 |
|---|---|---|
| **V1·V2 가 A1~A4 로 판정한 문항** | **불변** | 🔴 **순수 안정성** — 판정 대상 |
| V1·V2 가 A5 로 판정한 문항 | 변경됨 | 자 변경 효과 포함 — **참고 보고**, 판정 대상 아님 |

## 2. 지표

🔴 **1차 지표 = 이산 일치율** (「가장 가까운 앵커」가 같은 문항의 비율).
연속 잡음비는 쓰지 않는다 — 판정자가 `A3~A4` 중점 표기를 쓰면 **불일치가 반으로 접힌다**(SSOT §2).

이번 한 번의 실행에서 **두 값이 동시에 나온다.**

| 지표 | 계산 |
|---|---|
| **재현성** | V3 ↔ V4 이산 일치율 |
| **안정성** | 각 문항에서 {V3,V4} 의 최빈 밴드 ↔ {V1,V2} 의 최빈 밴드 일치율 (동률이면 불일치로 센다 — 보수적) |

## 3. 🔴 통과선 (관측 전 고정 · 관측값에서 만들지 않는다)

| # | 기준 | 값 | 근거 |
|:-:|---|---|---|
| **T1** | **안정성 ≥ 재현성 − 10%p** | 상대 | 같은 자·같은 문항이면 **시점 간 일치가 판정자 간 일치보다 나빠서는 안 된다.** 둘 다 이번 실행에서 나오므로 관측값 승격이 아니다 |
| **T2** | **안정성 ≥ 60%** (A1~A4 구간) | 절대 | 5밴드 우연 일치 20% 의 **3배**. 이보다 낮으면 자라고 부를 수 없다 |
| **T3** | 「견줄 상대가 없다」 **0건** | 절대 | 판정 4축 ④ 적용 가능성 (SSOT §3-C) |

**셋 다 만족해야 통과.** 하나라도 미달이면 원인을 규명하고 고쳐서 다시 잰다 — 폐기가 아니다.

## 4. 🔴 미리 밝혀 두는 한계

1. **「시점」이 짧다.** 세션 안에서 재는 것이라 엄밀한 시간 간격이 아니다.
   이번 값은 **하한**으로 읽는다 — 간격이 길어지면 나빠질 수는 있어도 좋아질 이유는 없다
2. **맹검 누수가 양쪽 실행에 공통이다.** 앵커를 확인하러 원문 PDF 를 열면 표본 문항이 함께 보인다
   (V1·V2 에서 3문 노출). V3·V4 도 같은 조건이므로 **두 실행의 차이에는 편향을 주지 않는다**
3. **A5 구간은 판정하지 않는다** — 자가 바뀌었다. 새 A5 앵커의 밴드 적합성은 별도로 확인해야 한다
4. **판정자가 사람이 아니라 에이전트다.** 「시점 간」이 사실상 「독립 실행 간」이다
