## 0. 총론 — 전략 1은 무엇을 다르게 하는가

### 0.1 전략 1의 정의

**전략 1 (다중 제약)** = 지문 안에 서로 다른 물리·상황 제약을 **2~3개** 자연스럽게 제시하고, 학생이 각 제약을 수식화한 뒤 **동시에** 만족시켜야 답이 유일해지도록 설계.

- 각 제약은 **독립적으로 수식화 가능**해야 함 (제약 하나가 다른 하나를 자동 함의하면 실질 1개)
- 제약 **결합**이 답의 유일성을 낳음 (하나만으로는 무한 해·모호한 상태)
- 지문의 각 제약은 **소재의 자연 요구**여야 함 (인위 삽입은 학생이 "왜 이 조건이 있나" 의문)

### 0.2 왜 전략 1인가 (다른 전략과의 차별화)

| 전략 | 깊이 원천 | 지문 부담 | 검수 난이도 | 채택 |
|---|---|---|---|---|
| **1 다중 제약** | 제약 결합의 유일해 논증 | 중 (제약 2~3개 자연 삽입) | 중 (제약 독립성·정합성) | ✅ 세션 36 |
| 2 역방향 모델링 | 물리 파라미터를 결과로부터 역산 | 중~상 | 상 (지문 논리↔수학 논리 정합) | 보류 |
| 3 파라미터 임계점 | 연속 → 이산 (질적 전환) | 상 (구간 서술) | 상 (스스로 임계값 발견) | 보류 |

전략 1은 **소재 부담과 검수 부담이 균형**을 이루며, 이미 와부고 2025 #17에서 원형이 검증됨.

### 0.3 얕은 지문 vs 다중 제약 지문 판정 기준

| 축 | 얕은 지문 | 다중 제약 지문 |
|---|---|---|
| **제약 개수** | 1개 (Object → Math 직결) | 2~3개 (Object → C1·C2·[C3] → Math) |
| **제약 관계** | 순차 (Math 조건이 그대로 답) | 결합 (각각 부분 정보 · 결합해야 유일) |
| **각 제약 필요성** | 하나 빼도 답 불변 | 하나 빼면 답 무한·불가능 |
| **학생 사고** | 조건 수식화 → 계산 | 조건 3개 수식화 → 교집합·연립 → 유일화 논증 |
| **★ 등급** | ★ 3~4 | ★ 4~5 (특히 5 최상위) |

**자동 판정**: 답에 도달하기 위해 사용한 조건 수를 세라. 3개 미만이면 얕음. 3개 이상 결합이면 다중 제약.

## 1. 다중 제약의 원형 (Archetype) 4종

### AR1 — 세 원의 공동 교점 (Trilateration Archetype)

**구조**: 세 원 $C_1$·$C_2$·$C_3$이 공통점을 갖거나 두 원씩 교점이 특정 관계를 만족.
- 제약 A: $C_1 \cap C_2 \ne \emptyset$
- 제약 B: $C_2 \cap C_3 \ne \emptyset$
- 제약 C: 세 교점이 특정 조건 (일직선·삼각형 넓이 등)

**소재**: GPS 삼변측량 (S03)·지진 진앙 (S04)·다중 CCTV (S06)

**답 유일화 논리**: 두 원 교점은 2점 후보, 세 번째 원이 그중 하나 결정.

**CM2 매핑**: GM (원의 방정식·두 원 위치관계) + ST (교집합 원소 수)

### AR2 — 궤도·경로 위의 필충 관계 (Orbit + Necessity)

**구조**: 대상이 궤도·경로 위에서 움직이며 두 관측 조건이 필충 관계로 얽힘.
- 제약 A: 궤도 전체가 관측 영역 안 ($X \subset S$)
- 제약 B: 두 궤도가 동시 관측 가능 ($n(X \cap Y) \ge 1$)
- 제약 C: 명제 "A ⇒ B"의 진리값 판정

**소재**: 와부고 2025 #17 (케플러 행성 궤도)·인공위성 관측 (S09)·달의 위상 관측

**답 유일화 논리**: 부분집합 조건 + 교집합 조건 + 명제 진리값의 3층 결합. 각 조건이 파라미터 공간을 좁혀 유일 답.

**CM2 매핑**: GM (원·집합) + ST (부분집합·명제·필충)

### AR3 — 도구·기계의 이중 관절 제약 (Dual Joint)

**구조**: 도구·기계가 2관절 이상 연결되어 각 관절이 독립적으로 회전·움직임.
- 제약 A: 관절 1의 거리 조건 ($\overline{\mathrm{OE}} = r_1$)
- 제약 B: 관절 2의 거리 조건 ($\overline{\mathrm{EP}} = r_2$)
- 제약 C: 끝점의 목표 도달 조건 (원·궤적·집합 위 위치)

**소재**: 2관절 로봇 팔 (S11)·팬터그래프 (S01)·크레인·다관절 조명 시스템

**답 유일화 논리**: 두 원의 교점 (제약 A·B) → 목표 조건 (제약 C)이 유일 파라미터 결정.

**CM2 매핑**: GM (원·자취) + FN (자취 방정식)

### AR4 — 규칙 반복 + 상태 조건 (Iterated Rule + State)

**구조**: 활동·놀이가 여러 회 반복되며 각 단계 상태가 조건 얽힘.
- 제약 A: 1회 시행 규칙 (뽑기·자리 배치·경로 선택)
- 제약 B: 상태 유지 조건 (특정 원소·인접 관계·중복 제한)
- 제약 C: 최종 도달 상태 (총합·순서·홀짝 등)

**소재**: 카드 뽑기 활동·시간표 배정·사다리타기·순열 반복

**답 유일화 논리**: 단계별 경우의 수 곱 → 상태 조건 필터 → 최종 상태 조건 통과.

**CM1 매핑**: CB (순열·조합·경우의 수) + EQ·PL (조건식)

## 2. 4-Step 다중 제약 설계 절차

### Step 1 — 수학 골격 확정 (Math Skeleton Freeze)

**목표**: 소재를 씌우기 전에 수학적 뼈대를 정확히 잡는다.

1. 슬롯 청사진에서 target ★·통찰 카드·M 프로파일 확인
2. 답이 유일해지기 위한 **조건 목록**을 열거 (2~3개)
3. mathjs로 조건 결합 → 답 검증
4. **제약 독립성 확인**: 제약 하나 뺐을 때 답이 무한·불가능이 되는지 (되면 진짜 독립)

**출력**: 조건 A·B·[C]와 각 조건의 수식화·최종 답이 명시된 Math Skeleton 문서.

**시간**: 슬롯당 10~15분

**예시 (#17)**:
- 제약 A: $A \subset S$ ⇒ $r_A \le \min(2, 2, 8, 8) = 2$
- 제약 B: $B \subset S$ ⇒ $r_B \le \min(6, 5, 4, 5) = 4$
- 제약 C: $r_A + r_B \ge \sqrt{(6-2)^2+(5-2)^2} = 5$
- 결합: A·B·C 세 조건이 파라미터 $(r_A, r_B)$ 공간을 좁힘

### Step 2 — 소재 셀렉션 (Source Match)

**목표**: 수학 골격에 자연스럽게 3개 제약이 붙는 소재를 [`bank/실생활지문-카탈로그.md`](실생활지문-카탈로그.md)에서 셀렉트.

**셀렉션 기준**:
- 소재의 **자연 제약**이 수학 골격의 제약과 매칭 (인위 삽입 없이 지문에서 이유가 명확)
- 소재가 회차 안 다른 슬롯과 중복 아님 (`cross-round-insight-check` 준수)
- Archetype 4종 중 어느 것에 해당하는지 라벨링

**출력**: 소재 코드 (S01~S13) + Archetype 코드 (AR1~AR4)

**예시 (#17)**: S09 (인공위성 관측)·AR2 (궤도+필충)

### Step 3 — 지문 서술 (Narrative Weaving)

**목표**: 3층 구조 안에 제약을 자연 삽입.

**층별 배치**:
| 층 | 역할 | 제약 담기 |
|---|---|---|
| **층 1 (Frame)** | 소재 세계관·정리 소개 | (제약 자체는 없음. 왜 이 제약이 자연스러운지 배경 제공) |
| **층 2 (Object)** | 구체 대상·좌표 설정 | 제약 A·B의 물리적 필요성 명시 (예: "궤도 전체가 관측 영역 안에 있어야") |
| **층 3 (Math)** | 수식·조건 | 제약 A·B·[C]의 수식 명시 (`$A \subset S$` 등) |

**필수 원칙**:
- 각 제약은 **독립 문장·독립 정의 박스**로 서술 (한 문장에 두 제약 압축 금지)
- **정의 박스** 활용 — 새 개념(필충·전 궤도 관측 가능 등)은 박스 분리
- 제약 A → B → C 순서는 **논리 의존**을 따름 (C가 A·B를 전제하면 뒤에)
- 지문 총 길이 **300~450자 범위** (450자 초과 시 소문항 나누기 검토)

**출력**: `.tex` 지문 초안

### Step 4 — 검수 (Verification)

**목표**: 제약 독립성·유일성·자연성 3축 확인.

**체크리스트 10항** (§3 참조)

**자동 도구**:
- `node scripts/master-feedback-check.mjs <문제.tex> <답지.tex> <청사진.yaml>` — 마스터 지적 어구
- `node scripts/cm1-curriculum-check.mjs` (CM1) / 수동 검수 (CM2) — 교과 범위
- 독립풀이 에이전트 — 지문만 보고 답 도달 가능한지 검증

**출력**: 검수 리포트 (제약 3개 카운트·독립성 확인·유일해 검증)

## 3. 다중 제약 검수 체크리스트 (10항)

지문형 슬롯 완성 후 다음 10항 자체 점검. 하나라도 미충족 시 재설계.

### 제약 구조 (C1~C4)

**C1 제약 개수**: 서로 다른 제약이 **2개 이상 (★ 4)** · **3개 이상 (★ 5)** 명시되어 있는가?

**C2 제약 독립성**: 제약 하나 뺐을 때 답이 유일이 아니게 되는가?
- 방법: 제약별로 순서대로 제거해 mathjs 재검증
- 하나 빼도 답 불변 → 그 제약은 실질 무의미 → 재설계

**C3 제약 결합 필연성**: 3개 제약을 각각 수식화 후 **동시 만족**시켜야만 답이 나오는가?
- 순차 계산으로 풀리면 (제약 A로 값 → 제약 B로 다음 값 → 제약 C로 답) 얕음
- 파라미터 공간 좁혀나가는 논증이 필요해야 함

**C4 제약의 자연성**: 각 제약이 소재의 **자연 요구**인가 (인위 삽입 아님)?
- 지문 안에 "왜 이 조건이 필요한가"의 서사가 있어야 함
- 예: "궤도 전체가 관측 영역 안" = 관측이라는 소재의 자연 요구
- 예: "$r_A + r_B \ge 5$" 조건 = 필충 관계 조사의 자연 요구

### 지문 서술 (N1~N3)

**N1 층 구조**: Frame → Object → Math 3층이 명확히 구별되는가?
- Frame 없이 바로 Math (예: "다음 부등식이…")는 지문형 아님
- Object 부재 (관용어 수준 언급만) → 학교 기출 수준 미달

**N2 정의 박스**: 새 개념·복합 조건은 정의 박스 분리되어 있는가?
- 필충·전 궤도 관측 가능·2관절 로봇 팔의 도달 가능 등
- 정의 박스 없이 본문에 압축 → 학생 읽기 부담 폭증

**N3 지문 길이**: 300~450자 범위인가?
- 300자 미만: 지문형 미달 (단순 배경 설명 수준)
- 450자 초과: 소문항 (1)(2)(3)으로 나누기 검토

### 수학적 정합 (M1~M3)

**M1 답의 유일성**: mathjs로 답이 정확히 하나임을 확인했는가?

**M2 조건 소거의 mathjs 재검증**: 각 제약 소거 시 답 무한·불가능임을 확인했는가?

**M3 교과 범위**: 각 제약이 CM1·CM2 교육과정 범위 안인가?
- 자동: `cm1-curriculum-check.mjs`·`permanent-policy-check.mjs`
- 수동: 극선·삼각부등식·매개변수·회전변환 등 RED 어구 grep

## 4. Before/After 사례집 — 얕은 지문 → 다중 제약 지문 재설계

### 사례 A — 와부고 CM2 1회 #14 (거울 반사) 재설계

**Before** (현재 상태, 얕음):
- 층 1: 광학 반사 법칙 (Frame)
- 층 2: 광원 $\mathrm{A}(0,2)$·거울 $\ell_a: ax-y-2a^2=0$
- 층 3: (1) 상 $\mathrm{P}$의 좌표 유도 → (2) 자취 → (3) 다른 원 위 점과 최단거리

**얕은 이유**: 제약 실질 1개 (대칭이동 조건). (3)의 원 $C'$은 추가 제약이나 자취 자체와 결합되지 않고 별도 최단거리 계산.

**After 재설계 (다중 제약, AR2)**:
- 제약 A: 대칭이동 조건 ($\overline{\mathrm{AP}}$의 중점이 $\ell_a$·$\mathrm{AP} \perp \ell_a$)
- 제약 B: **거울의 회전 제한 조건** ($a$가 $[-2, 2]$ 범위) — 물리적 회전 각도 제한
- 제약 C: **상 $\mathrm{P}$가 특정 원 안에 항상 존재하는 조건** — 조명 시스템 안전 영역

**재설계 지문 (핵심 부분)**:
```
관찰자의 눈을 보호하기 위해 상 P는 항상 영역
S = {(x,y) | x^2 + (y-2)^2 ≤ 4} 안에 있어야 한다.
평면거울 ℓ_a는 실수 a (단, |a| ≤ 2)에 따라 회전한다.

(3) a가 [-2, 2] 범위에서 움직일 때 상 P의 자취가 안전 영역 S 안에
     완전히 포함됨을 (2)의 자취 방정식과 함께 서술하시오.
```

**개선점**: 제약 3개 (반사·거울 회전 제한·안전 영역 포함)가 자연스럽게 결합. 학생은 (i) 자취 방정식 유도 (ii) $a$ 범위에서 자취의 파라미터화 (iii) 자취가 원 $S$ 안에 완전 포함됨을 논증.

### 사례 B — 와부고 CM2 1회 #16 (2관절 로봇 팔) 재설계

**Before** (현재 상태, AR3 근접이나 얕음):
- 층 1: 2관절 로봇 팔 소개
- 층 2: 위팔·아래팔 길이
- 층 3: (1) 도달 가능 범위 (2) 특정 위치 팔꿈치 좌표 (3) $\mathrm{P}$가 원 위 움직일 때 자취

**얕은 이유**: 제약 A·B ($\overline{\mathrm{OE}}=3$·$\overline{\mathrm{EP}}=5$)는 있지만, (3)의 원 $x^2+y^2=25$가 추가 제약이 아니라 단순 궤적 조건. 임계값 (경계 $r \in [2, 8]$)을 문제가 미리 알려줌.

**After 재설계 (다중 제약, AR3)**:
- 제약 A: 위팔 길이 $\overline{\mathrm{OE}} = 3$
- 제약 B: 아래팔 길이 $\overline{\mathrm{EP}} = 5$
- 제약 C: **작업 대상의 위치 조건** — 로봇 팔이 조립할 부품이 특정 원 위 (예: $x^2+y^2 = 25$) 있고, 팔꿈치 $\mathrm{E}$가 **다른 작업물의 방해 영역**과 겹치지 않아야 함
  - 방해 영역: 원 $x^2 + (y-3)^2 \le 1$

**재설계 지문 (핵심 부분)**:
```
작업 대상 부품은 원 x^2 + y^2 = 25 위를 움직인다.
동시에 팔꿈치 E는 다른 작업물의 방해 영역
D = {(x,y) | x^2 + (y-3)^2 ≤ 1} 안에 들어가면 안 된다.

(3) 손 끝 P가 부품 원 위를 움직일 때, 팔꿈치 E가 방해 영역 D를 피하도록
     P의 좌표 범위를 (1), (2)의 결과와 함께 서술하시오.
```

**개선점**: 제약 3개 (위팔·아래팔·방해 영역 회피)가 결합. 학생은 (i) 자취 방정식 (ii) 자취 위 점의 방해 영역 판정 (iii) 원 위 점의 범위 논증.

- $B = \{(x,y) | (x-6)^2+(y-5)^2 = r_B^2\}$

**층 3 (Math)** — 정의 박스 + 3소문항:
- 정의: 전 궤도 관측 가능 ($X \subset S$)·동시 관측 가능 ($n(A \cap B) \ge 1$)
- (1) $A \subset S$·$B \subset S$ 조건: $r_A \le 2$·$r_B \le 4$
- (2) 필충 관계 판정: $p$ ⇔ $q$? ($p$: 동시 관측 · $q$: $r_A + r_B \ge 5$)
- (3) 명제 $R$의 진리값과 대우

### 5.2 다중 제약 라벨링

| 제약 | 내용 | 소문항 |
|---|---|---|
| C_A | $A \subset S$ (전 궤도 관측) | (1) |
| C_B | $B \subset S$ (전 궤도 관측) | (1) |
| C_AB | $n(A \cap B) \ge 1$ (동시 관측) | (2) |
| C_R | 명제 $R$: (C_A ∧ C_B) ⇒ C_AB | (3) |

**결합 필연성**:
- (2)에서 C_A·C_B·C_AB가 결합되어야 $r_A + r_B \ge 5$가 필충 조건임을 판정 가능

## 6. 실패 사례·주의 (재발 방지)

### 6.1 제약이 실질 1개인 위장 다중 제약

**증상**: 제약 A·B·C 3개 나열되나 실제로는 A ⇒ B ⇒ C가 순차 함의.

**예시**: "① 두 원이 접함 ② 반지름 합 = 5 ③ 한 원의 반지름이 3"
- ①·②·③은 순차 계산 (③ → ②로 다른 반지름 2 → ① 접점 자동)

**대응**: 각 제약이 파라미터 공간을 **독립적으로** 좁히는지 mathjs로 검증. 순차 함의면 재설계.

### 6.2 소재-수학 정합 실패 (지문이 이상함)

**증상**: 학생이 "이 상황에서 왜 이 조건이 필요한가"에 답할 수 없음.

**예시**: 로봇 팔에 "$xy \le 4$" 같은 대수 제약을 인위 삽입 — 물리적 의미 없음.

**대응**: 각 제약이 소재의 자연 요구인지 재검토. 인위적이면 다른 소재 셀렉트.

### 6.3 지문 길이 폭증 (500자 초과)

**증상**: 제약 3개를 자연스럽게 서술하려다 지문이 500자 초과.

**대응**:
- 정의 박스로 개념 분리 (본문 길이 축소)
- 그림·좌표 도해 삽입으로 언어 부담 축소
- 그래도 초과 시 제약 2개로 축소 (★ 5 → ★ 4 강등 감수)

### 6.4 지문형 남발 (회차 밸런스) — v1.1 정책 개편 (2026-07-14 세션 36)

**v1.0 정책**: 회차당 지문형 다중 제약 슬롯 ≤ 2문 권장.

**v1.0 문제점 (2회 사례에서 확인)**:

**v1.1 정책 (schema.md v5.2 §2.16.9 D 축 신설 후)**:

**지문 부담 점수** (슬롯별):
