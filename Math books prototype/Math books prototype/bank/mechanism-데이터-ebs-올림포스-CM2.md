# EBS 올림포스 전국연합학력평가 기출문제집 (2025) — 공통수학2 정독 데이터

## 구성 및 정책

**섹션 4단계 구조** (챕터마다 반복):
1. **개념 짚어보기** — 개념 요약 (문제 없음) → **정독 제외**
2. **개념 확인 문제** — EBS 자체 편집 기본 (tier star_1·2) → **정독 제외** (RPM 교과서 정복하기로 star_1·2 pool 확보 · 중복 불요)
3. **내신 & 학평 유형 연습** — 학평 기출 발췌 (원문 배점 기반 tier)
4. **1등급 도전** — 킬러 큐레이션 → **star_5_premium** 확정

**tier 라벨링 정책** (캘리브레이션 v1.3 · 2026-07-16 마스터 확립):
- 단일 출처: `bank/textbook-tier-calibration.md`
- **모의고사 배점 기반 매핑** (③ 유형연습):
  - 2점 → star_1·2
  - 3점 → star_3
  - 4점 → star_4·5 (혼재)
- **1등급 도전** (④) = star_5_premium 확정 (배점 무관)
- **정답률 필드 없음** (2026-07-16 마스터 확인) → 배점 규칙 단독 적용

**저작권 준수**: 원문 발문·풀이 전사 금지 · 100~200자 요약 · YAML 필드만 기록
