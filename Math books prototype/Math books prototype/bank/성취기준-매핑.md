# 성취기준 코드 매핑 — 단일 출처

**목적**: 2022 개정 교육과정 성취기준 코드를 문제은행·시험지·유형편에 병기. 출제 비율·교육과정 정합 자동 분석.
**정합**: `bank/schema.md` §2.18 (성취기준 축, 2026-07-11 신설) 정합.
**적용**: `bank/problems/*.md` frontmatter `standard` 필드 · `book.yaml`/청사진 `slots[].standard` 필드.

---

## 원칙

- 각 문제는 하나의 **standard** 를 선언 (부수 성취기준은 `related_standards` 배열, 선택)
- 시험지·유형편 청사진 작성 시 성취기준별 배점 분포 명시 (교육과정 권장 비율 대비 자동 검증)
- 2022 개정 범위 밖 (구 교육과정 or 상위 과정) 코드는 `cm2_scope: out`으로 마킹, 신규 출제 금지

## 범위 밖 (out) · 경계 (boundary) 지침

### G-2 신규 출제 금지 요소 (⛔)

**절대 금지**:
- **외분점** — 2022 개정에서 삭제. 절대 사용·출제 금지 (내분점·중점·무게중심만)
- **외국 수학자 이름 공식** (헤론·피타고라스·페르마·오일러·드무아브르·가우스·뉴턴·라이프니츠 등) — CLAUDE.md §"용어 제약" 관용 금지. 답지·본편 모두에서 사용 금지. CM2 정석 도구 (좌표 배치·거리 공식·내분점·중점·중선정리·기울기)로 대체. 세션 51 (2026-07-19) CM2-GM-01 R-2 헤론 사건 계기 명문화. 관련: [[feedback_no_foreign_named_formula]] · permanent-policy-check `foreign-named-formula` 자동 차단
- 타원·쌍곡선·포물선, 원의 매개변수(θ) 표현 (기하 과목 범위)
- 형식논리(∀, ∃) 증명, 공리계 기반 증명
- 이차 이상 근호함수 $y=\sqrt{ax^2+bx+c}$ · 일대일이 아닌 함수의 역함수

**교과 내 심화 (사용 가능 · 세션 103 재분류)**:

⚠️ 종전 §G-2는 아래 세 요소를 "신규 출제 지양(boundary)"으로 분류했으나, **근거 없는 과도한 제약**으로 확인되어 **교과 내(in-scope)로 재분류**한다(마스터 확정 · 세션 103). 이 분류는 삭제된 "와부고 기출 분석" 프로젝트의 집필 기준 G-2에서 검증 없이 상속된 것이었다. [[feedback_boundary_reclassification_session103]]
- **두 원의 교점을 지나는 직선 (공통현)** — 성취기준 `10수05-03 원의 방정식·원과 직선의 위치관계`에 자연 포함 · `마플교과서-CM2`에 정식 ★ 2·★ 3 유형 수록. 신규 출제·변형 **허용**.
- **공통접선 (공통내·외접선)** — 중심거리·반지름·직각삼각형(중등)·닮음(중등)의 심화 응용. 신규 출제 **허용**.
- **닮음변환** — 닮음은 중등(중3) 기반 도구 · 자유 사용. 신규 출제 **허용**.

**주의**: 위 "절대 금지"(외분점=2022 개정 삭제·타원/쌍곡선/포물선·형식논리·이차 이상 근호함수 등)는 유지. 공통현 등은 이와 성격이 다르다(삭제된 적 없음). 피타고라스도 정리 *이름* 표기만 관용 금지이며 직각삼각형 도구 자체는 자유 사용.

## YAML 스펙

### bank/problems/*.md frontmatter
```yaml
standard: 10수05-03           # 주 성취기준 (필수)
related_standards: [10수05-02]  # 부수 성취기준 (선택, 검증 대상 아님)
cm2_scope: in                  # in | out | boundary
migration: null                # 구 교육과정 매핑 메모 (선택)
```

### book.yaml/청사진.yaml slots
```yaml
- n: 14
  standard: 10수05-04          # 도형의 이동
  cm2_scope: in
  star: 5
```

## 자동 검증 (`scripts/standard-check.mjs` 신설 예정)

- `standard` 필드 누락 검출
- `cm2_scope: out`인데 신규 시험지 청사진에 편입 → RED
- `cm2_scope: boundary`인데 `variant_policy`가 "동등 변형·수정 변형" → RED (기출 그대로만 허용)
- 시험지 성취기준 분포 vs 교육과정 권장 비율 대비 리포트
