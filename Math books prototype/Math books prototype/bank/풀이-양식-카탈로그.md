# 풀이 양식 카탈로그

마스터 영구 정책 [[feedback_answer_key_learning]] (2026-06-30) 적용. 시판 책·기출 답지(공개자료)에서 풀이 전개·설명 방식·답지 디자인을 학습해 우리 책 답지 작성 모범 표본으로 활용.

## 🔴 우선순위 (2026-06-30 마스터 명시)

**고쟁이 양식 > 학평 양식** ([[feedback_solution_format_priority]] 영구 정책). 고쟁이 답지 양식이 *제1 우선* 차용 표본. 학평 양식은 *제2 보조* 표본.

## 🔴 우리 책 단계 라벨 폐지 (2026-06-30 마스터 명시)

[[feedback_step_label_deprecated]] — `\step{N}`·Step 헤더·[N단계] 한국어 라벨 *전면 폐지*. 풀이는 등호 정렬 식 변환 줄 위주 + 핵심 변환 전후 자연어 설명. 분기 `(i)·(ii)·(iii)`·`[다른 풀이]`·`[TIP]`은 허용.

## 학습 항목

### 1. 풀이 단계 분배
- 발문 해독 → 핵심 변환 → 계산 → 답 결론
- 각 단계 평균 분량 (한국어 줄 수)
- 단계 라벨 (`Step 1`·`①`·`(가)`·없음)

### 2. 한국어 서술 양식
- 도입 어구 (예: "주어진 조건에서…", "…이므로")
- 결론 어구 (예: "따라서…", "구하는 값은…")
- 수식 도입 어구 (예: "다음과 같이 정리할 수 있다", "양변에 …을 대입하면")
- 자연어 vs 한자어 비율

### 3. 수식 디자인
- 인라인 vs 디스플레이 비율
- 수식 정렬 (`align`·`gather`·중앙·좌측)
- 박스·강조 표기 (답 박스·핵심 식 박스)

### 4. 그래프·도형 표현
- [[feedback_graph_extraction_study]] + `bank/그래프-양식-카탈로그.md` 별도

### 5. 답 표기
- `**답**: ⑤ 5` (객관식)·`**답**: 12` (단답)·박스
- 추가 해설 (다른 풀이·관련 개념) 위치

## 표본 누적

(자료 자산화 진행하면서 누적. 각 항목은 출처·발문 ID·관찰 사항 기록)

### 마더텅 20분 미니모의 24회 답지 (MM-Y2026-S/)

**1차 학습 (회 7, 2026-06-30) — 풀이 양식 특징**:
- **답 표기**: ✓ 표시 + 답 번호 (객관식) 또는 답 숫자 (단답)
- **풀이 분량**: 1-5줄 (짧고 압축). 정식 해설지가 아니라 *간이 풀이* 형식
- **수식 vs 한국어 비율**: 수식 70% / 한국어 30%
- **결론 어구**: `∴` (therefore) 기호 일관 사용. "따라서 …이다."로 마무리
- **도입 어구**: 발문 핵심 식 그대로 가져와 변형 시작 (예: "$\overline{z} = \dfrac{z^2}{4i}$에서 $4i\overline{z} = z^2$")
- **수식 표기**: 인라인 위주, 디스플레이는 식 변환 줄에만
- **분기 양식**: 다층 분기 시 `(i) a < 3인 경우` `(ii) a = 3인 경우` 등 소제목 사용
- **근과 계수 활용**: 명시적 호출 ("이차방정식의 근과 계수의 관계에 의하여 $\alpha+\beta = \dots$")
- **치환**: 식 도입 후 즉시 변환 결과 표시 (계산 과정 생략 많음)
- **그림 보충**: 도형 문제에서도 그림 재게재 없음 (문제편 참조 의존)

**우리 책 적용 후보**:
- ✅ `∴` 결론 어구 — 자연스러운 한국어 변환: "따라서 …이다." 권장
- ✅ 분기 소제목 `(i)·(ii)·(iii)` — 우리 책 \step{N} 시스템과 호환
- ⚠️ 압축 양식 (1-5줄) → 우리 책 정책 [[feedback_solution_verbosity]] (자세히 + 압축 금지)와 충돌. 마더텅 양식 *그대로 차용 금지*. 풀이 단계를 *자세히 풀어 쓸 것*
- ❌ 한자어 압축 ("같다 → 동일") 사용 — 우리 책 [[feedback_natural_korean_wording]] 위반. 자연 한국어로 풀어쓰기
- ❌ 발문 인용 시 변수만 보여주는 양식 — 우리 책은 발문 맥락 한국어로 재진술 권장

### 학평 답지
*(우선 마더텅 답지 학습 후 평가원·EBS 답지 등 추가 예정)*

### 🌟 고쟁이 공통수학1 2025 답지 (GJ-CM1-S/)

**1차 학습 (p.2-5, 다항식 단원, 2026-06-30 세션 7) — 풀이 양식 특징**:

**답 표기**:
- 모든 풀이 마지막에 `>>` 화살표 + 보기 번호 (객관식) 또는 숫자 (단답): `>> ⑤` `>> 4`
- 객관식 보기는 동그라미 숫자 `①② ③④ ⑤`

**풀이 단계 분배**:
- 단계 라벨 *없음* (Step·①·(가) 같은 라벨 사용 안 함)
- 등호 정렬 식 변환 줄 나열 위주 (수직 정렬)
- 한국어 설명은 *짧고 명확* — 핵심 변환 직전·직후에만
- ★ 어려운 문제는 5-7줄로 펼침 (마더텅보다 자세)

**한국어 서술**:
- `∴` 결론 어구 — 거의 모든 마지막 줄에 일관 사용
- 도입 어구: 자주 *없음* (바로 식 변환 시작)
- 결론 어구: `따라서 …`, `구하는 값은 …`
- 핵심 조건 인용 시: `이때 …의 계수는`, `… (?)에 대하여 …` (한국어 압축 최소화)

**수식 디자인**:
- 박스 강조 — 핵심 식·중간 결과를 `□` 박스로 둘러쌈 (#010 `x²+x+1` 박스)
- 다항식 나눗셈 — 세로 나눗셈 양식으로 정렬 (#017·#019·#022·#023)
- 분수 — `\dfrac{}{}` 우선, 짧은 인라인은 `1/x²` 양식
- 인라인 vs 디스플레이 — 풀이 본문은 디스플레이(=등호 줄) 위주, 인라인은 식 인용 시

**박스·라벨 종류**:
- `[TIP]` 빨간 라벨 박스 — 풀이 옆에 추가 설명·자주 등장하는 변환 트릭 (#018·#019·#025)
- `[다른 풀이]` 라벨 — 박스 없이 *라벨만* 표시, 본 풀이와 구분 (#018·#019·#020·#021·#022·#026)

**우리 책 적용 후보** *(2026-06-30 마스터 명시 정정: 고쟁이 양식 우선)*:
- ✅ **단계 라벨 없음 (전면 차용)** — 우리 책도 단계 라벨 전면 폐지 ([[feedback_step_label_deprecated]]). 풀이는 등호 정렬 식 변환 줄 + 핵심 변환 전후 자연어 설명
- ✅ `∴` 결론 → 자연 한국어 "따라서 …이다." 권장 (한자어 압축은 회피)
- ✅ 박스 강조 — 핵심 식·중간 결과 강조 양식 차용 (`\highlight`·`\boxed`)
- ✅ `[다른 풀이]` 라벨 — `\altsol` 매크로 신설 권장 (박스 없이 라벨만)
- ✅ `[TIP]` 박스 — 우리 책 `\solnote` 비법 박스와 정합 (이미 보유)
- ✅ 답 표기 `>> ⑤` 양식 — 우리 책 `\answerbox` 양식과 정합 (마지막 줄에 답)
- ⚠️ 한국어 압축 (도입 어구 없음) → 우리 책은 도입 어구 *명시* (자세히 + 압축 금지, [[feedback_solution_verbosity]])
- ❌ 한자어 압축 ("∴" 자체 사용·"이때") → 자연 한국어 "따라서", "여기서"로 풀어쓰기

**2차 학습 (p.9-30, 다항식 + 항등식·나머지정리 단원, 2026-06-30 세션 7) — 추가 발견 양식**:

**조립제법 표 양식**:
- 점선 격자 안에 계수·결과 정렬 (synthetic division)
- 격자 폭 자동 조정, 세로선 점선
- 결과 행 아래에 인수분해 결과 표기 (`P(x) = (x - a)Q(x)`)
- 우리 책 적용: `\polydiv` 매크로 권장 (templates/figures/ 또는 mathbook-problems.sty 신규)

**다항식 세로 나눗셈 양식**:
- 박스 안에 정렬된 식 (overhead bar 위에 몫 + 세로로 정렬된 나머지 단계)
- 우리 책 적용: `\longdiv` 매크로 권장

**조건 분기 자연어 명시**:
- `조건 (가)에서 …`, `조건 (나)에서 …` — 발문 조건 라벨을 풀이에 자연어로 인용
- 풀이가 자연스럽게 분기됨 (단계 라벨 없이도 학생이 흐름 추적 가능)
- ✅ 우리 책 적용 (자연어 분기는 단계 라벨 폐지 정책 [[feedback_step_label_deprecated]]와 정합)

**분기 라벨 일관 사용**:
- `(i)·(ii)·(iii)` 케이스 분기 — 빈도 높음
- 분기 안에 들여쓰기·여백 없이 평탄 흐름

**도형 그림 양식**:
- 컬러+흑백 혼용 (모든 도형이 컬러는 아님)
- 작은 도형은 흑백 단순, 큰 도형은 컬러 음영
- 정점 라벨: 점 옆 (오른쪽 위 또는 위)
- 변 길이 라벨: 변 옆 가까운 쪽
- 보조선·중점·내접원: 점선 또는 얇은 실선

**[다른 풀이] 빈도**:
- 거의 모든 ★ 4·5 문제에 [다른 풀이] 1-2개 제공
- 본 풀이와 분리 — 라벨만 (박스 없음)
- ✅ 우리 책 적용: 정점 슬롯에 [다른 풀이] 매크로 (`\altsol`) 권장

**3차 학습 (p.31-178, 방정식·부등식·경우의수·행렬 전 단원, 2026-06-30 세션 7) — 양식 전수 확인**:

전 단원 (다항식·항등식·복소수·이차방정식·이차함수·여러방정식·여러부등식·경우의수·행렬) 풀이 양식 **동일** 확인.
- 단계 라벨 없음, 등호 정렬, ∴ 결론, `[다른 풀이]`·`[TIP]` 일관
- 단원별 특화 양식:
  - **경우의 수**: 도로망 격자 그림 (컬러 사용, 회색+노랑), 분기 (i)·(ii)·(iii) 빈도 정점
  - **행렬**: 행렬 표기 박스 강조, (i)·(ii)·(iii) 분기 행렬 케이스
  - **함수**: 함수 그래프 흑백 위주 (도형은 컬러 빈도 높음), 곡선 옆 `y=f(x)` 라벨
- 응답 비율 표 일관 등장 (퍼센트 분포 — 정답률 cohort 자료, 우리 책 외부 자료)
