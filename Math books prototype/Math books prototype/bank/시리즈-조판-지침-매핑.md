## §3. 시리즈별 매크로 세트

### exam (시험지) — `style.sty` 기반

**필수 매크로 (임의 신설·재정의 금지)**:

| 매크로 | 용도 | 정의 위치 |
|---|---|---|
| `\begin{pagepair}...\end{pagepair}` | 페이지 상하 페어 컨테이너 | style.sty |
| `\probpair{...}{...}` | 좌우 균등 분배 자동 | style.sty (savebox) |
| `\begin{problem}{N}{s}` | 문항 환경 (N=번호, s=선택형) | style.sty |
| `\pointbadge{N}` | 배점 뱃지 (2·2.5·3·...·13) | style.sty |
| `\begin{conditions}...\end{conditions}` | (가)(나)(다) 조건 박스 | style.sty |
| `\begin{quickgrid}...\end{quickgrid}` | 답지 정답 그리드 (5×N) | style.sty |
| `\examheader{제목}{부제}` | 시험지 헤더 (파일별 재정의 가능) | style.sty |

**보기 매크로 4종 선택 규칙 (⚠️ 절대 준수 · `choices-macro-selection-check.mjs` 자동 검증)**:

| 매크로 | 배치 | 용도 | 판정 기준 |
|---|---|---|---|
| **`choices`** | 한 줄 강제 폭 균등 · ① 왼쪽 · ③ 중앙 · ⑤ 오른쪽 | **짧은 숫자 5개·짧은 식 5개** | 각 원소 char 길이 ≤ 3 (예: `$3$`·`$5$`·`①`·`ㄱ`) |
| `choices32` | 3-2 두 줄 (`\\[12pt]`) | 좌표·분수 등 중간 길이 5개 | 각 원소 char 길이 4~10 (예: `$(0,-3)$`·`$\dfrac{1}{3}$`) |
| `choicesii` | 2-2-1 (3줄) | 중간~긴 5개 (평범 텍스트+수식) | 각 원소 char 길이 11~25 |
| `choicesv` | 5줄 세로 | 긴 부등식·긴 수식 전용 | 각 원소 char 길이 > 25 or `\dfrac`·`\sqrt` 포함 시 폭 초과 |

**판정 우선순위**: `choices` → `choices32` → `choicesii` → `choicesv`. 짧은 것을 무조건 선호 · 공간 초과 시에만 다음 단계로.

**5인자 문법 강제** (choicesii·choicesv·choices32):
```latex
\begin{choicesii}
{$-3-3\sqrt{5}$}
{$-2-\sqrt{5}$}
{$0$}
{$2+\sqrt{5}$}
{$3+3\sqrt{5}$}
\end{choicesii}
```

**❌ 존재하지 않는 매크로 (사용 시 컴파일 오류)**:
- `\begin{cond}` → 정답: `\begin{conditions}`
- `\begin{step}` → 정답: `\dmstep{n}` (답지에만)
- `\begin{soltitle}` → 정답: `\soltitle{번호}{제목}{배점}` (명령어)
