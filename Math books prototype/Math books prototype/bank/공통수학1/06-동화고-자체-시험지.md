| # | 단원 | 핵심 개념 | 배점 |
|---|---|---|---|
| 1 | 이차방정식 | 유리수 계수 + 한 근 $1 - \sqrt{2}$ → 켤레무리수 + 근과 계수의 관계 + $a + b$, $ab$, $a - b$ 결정 | 8점 |
| 2 | 복소수 | $z = \dfrac{(1+\sqrt{2}i)(\sqrt{2}+i)}{(\sqrt{2}-i)(\sqrt{2}+i)} = i$ 정리 → $i^n$ 주기성 → $n$ 결정 (정답 $n = 78$) | 10점 |
| 3 | 이차함수 최대·최소 활용 | 직육면체 부피 + $x$의 범위 + 완전제곱식 → 최댓값 900 | 10점 |

| 5 | 복소수 + 켤레 활용 | $z\bar{z}, z + \bar{z}$ 조건 → $a^2 = 3b^2$ + $4b^2 - 4\sqrt{3}b + 3 = 0$ → $z = \dfrac{3 + \sqrt{3}i}{2}$ | 10점 |

- **22번**: 이차식 $f(x)$ + 일차식 $g(x)$ + 조건 (가)(나)(다) + 모든 실수 부등식 → $k + f(k) - g(k)$
- **23번**: $f(x) = x^2 + 3x - 10$ + 조건부 $g(x)$ + 부등식 $g(x) \ge m(x - 5)$ 정수해 10개 → $a + \beta$
- **21번**: $A = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ + $A^m = A^n$ 만족 $42$ 이하 순서쌍 개수
- **20번**: 자동차 회사 매출 행렬 응용 (실생활)
