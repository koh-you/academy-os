마스터 결정대로 ★3·4 우선. 마더텅 ★ → 우리 ★ 환산표:

| 마더텅 ★ | 우리 ★ (예상 범위) | 본문 등록 정책 |

## 6. 메타 등록 (1,585문항 전체) — 스키마와 절차

### 6.1 메타만 등록되는 문항의 YAML 최소 스펙

본문이 등록되지 않은 ★1·★2 마더텅 문항도 외부 라벨·빈도 calibration에 필수. 다음 최소 YAML을 `bank/problems/CM1-{단원}-{일련번호}.md`로 등록.

```yaml
---
id: CM1-PL-001                          # 단원 내 일련번호
unit: 공통수학1 / 01-다항식
type: PL-T01                            # 우리 통합 T-code (본 인덱스 §4 매핑)
type_in_source: "I-1-01"                # 마더텅 단원/유형 코드
status: meta_only                       # 본문 미등록 — 외부 라벨·빈도 calibration용
external_labels:
  - source: 마더텅 2025 공통수학1
    label_star: 1                       # 마더텅 ★ (1~4)
    score_points: 2                     # 학평 배점
    exam_year: 2024
    exam_session: "9월학평"
    exam_grade: 고1
    exam_number: 4
    type_in_source: "유형 01"
    page_in_source: 30
    actual_correct_rate: null           # 추후 EBSi 흡수 시 채움
frequency: 2                            # 같은 패턴 출제 횟수 (3.2 빈도 자동 산정)
grade_origin: 고1
created: 2026-06-14
---
```

`scores` (8축)·`raw_total`·`star`·`anchors`·`anchor_diff`·`audience_fit`·`calibration` 필드는 **status: meta_only** 단계에서는 생략. 본문 등록(`status: draft`) 시점에 채움.

### 6.2 status 흐름 확장 (v1.4 메타 등록 단계 추가)

기존 `draft / reviewed / approved` 외에 **`meta_only`** 단계를 둠. schema v1.4.2 보강 예정.

| status | 의미 | YAML 필드 |
|---|---|---|
| meta_only | 외부 라벨·빈도만 등록, 본문·8축 채점 미수행 | id / unit / type / external_labels / frequency / grade_origin |
| draft | 본문 + 8축 채점 + 앵커 + audience_fit 모두 채움 | 위 + scores / raw_total / star / anchors / anchor_diff / audience_fit / calibration |
| reviewed | `problem-review` 통과 | review_log 1행 추가 |
| approved | 마스터 컨펌, 책 출제 가능 | (변경 없음) |

### 6.3 빈도(`frequency`) 자동 산정 규칙

마더텅 1,585문항 메타 등록 완료 시점에 동일 패턴 출제 횟수를 집계해 산정.

| 같은 (unit, type) 조합 출제 수 | frequency 값 | 의미 |
|---|---|---|
| 1회 | 1 (희귀) | 단발 출제 — 본문 등록 후순위 |
| 2~4회 | 2 (빈출) | 본문 등록 우선 |
| 5회 이상 | 3 (필수) | 본문 등록 최우선, 앵커 후보 |

집계 자동화 스크립트(`scripts/bank-frequency.mjs`) 추후 작성.

## 7. 정답률 흡수 절차 (★3·★4·★5 우선)

마스터 결정대로 마더텅 메타 등록 완료 → 정답률 흡수 연속 진행.

### 7.1 흡수 대상

- 마더텅 ★★☆ + ★★★ + 최고난도 ≈ **200~300문항** (단원 균등 분배)
- 출제 연도 2018~2024 우선 (EBSi 데이터 신뢰도 높음)

### 7.2 정답률 출처 우선순위

| 우선순위 | 출처 | 비고 |
|---|---|---|
| 1 | EBSi 가채점 통계 | 학평 직후 누적, 표본 수만~수십만 |
| 2 | 자이스토리·기출의바이블 표기 정답률 | 출판사가 EBSi+사설학원 흡수해 표기 |
| 3 | 사설 학원 추정 (메가스터디·대성·이투스) | 회원 한정 데이터, 표본 작음 |
| 4 | 마더텅 ★ 라벨에서 역산 | 정답률 없을 때 최종 fallback (schema §10.2 CASE 2) |

### 7.3 정답률 → 우리 ★ 환산

schema §10.2 (a) 표 그대로 적용. 80%↑=★1 / 60~80%=★2 / 40~60%=★3 / 20~40%=★4 / 20%↓=★5. 가중치 0.7로 마더텅 ★·배점 압도.

## 8. 작업 흐름 요약

```
[1] 1차 메타 등록 (1,585문항 status: meta_only)

        ↓
```
