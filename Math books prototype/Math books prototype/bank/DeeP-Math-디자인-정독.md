### 시리즈별 관찰 결과

#### 수능특강 (녹색 톤)

**색상**: 짙은 녹색 `#5B7F3F`~`#6B8E4E` (배너·강조) · 옅은 녹색 `#E6ECDD` (라벨 배경)

**개념 페이지 (page 8·10)**
- 챕터 배너: 좌상단 각진 사각(`01`) + 옆에 부제(`지수와 로그`)
- 큰 프레임: 페이지 전체를 둘러싸는 밝은 회색 라운드 프레임
- 소단원 번호·제목: 녹색 sans bold (`5. 로그`·`6. 로그의 밑의 변환`)
- 정의: 산세리프 없이 (1)(2) 개조식 · 수식은 별 줄에 들여쓰기
- 부속 라벨: `예` (녹색 알약 배경 · 흰 글자) · `참고`·`설명` (동일 스타일 · 옅은 톤)
- 여러 예시가 흐름으로 이어짐 · 여백 여유

**예제·유제 페이지 (page 11·12)**
- 예제 배너: 좌측 각진 녹색 사각(`예제 4`) + 우측 옅은 알약(문제 제목) · 두 부분 연결
- 문제 본문: 배너 아래 · 5지 선다는 한 줄에 5개
- `길잡이` / `풀이`: 좌측 옅은 녹색 알약 라벨 · 우측 본문
- 정답: 우측 하단 원문자
- 유제 배너: 예제와 유사 · 좌측 각진 녹색 · 우측 회색 알약
- 유제 번호: 원형 녹색 배지 (7·8) · 왼쪽 여백에 세로 점선

#### RPM (에머랄드/청록 톤)

**색상**: 청록 `#5A9E9E`~`#7DB8B8` (배너·강조) · 옅은 청록 `#D4EAEA` (배경)

**개념 페이지 (page 6)**
- 챕터 배너: 좌상단 각진 청록 사각(`01`) + 옆에 흰색 큰 글씨(`평면좌표`)
- 우측 상단 알약: `개념 훑기` (연회색 배경 + 하늘색 아이콘)
- 소단원 라벨: `유형 01`·`유형 02` (좌측 청록 알약)

**교과서 문제 정복하기 (page 7)**
- 상단 큰 배너: 짙은 청록 각진 사각(`교과서 문제`) + 옅은 청록 부제(`정복하기`)
- 우측 상단 알약: `정답 및 풀이 002쪽`
- 문제 번호: 청록 각진 사각(`0001`·`0002`) 왼쪽 · 문제 본문 오른쪽
- 소단원 번호 알약: `01 1`·`01 2`·`01 3` (짙은 청록 각진 · 흰 번호)
- 우측 세로 인덱스 탭: `평면좌표` (짙은 청록)

**유형 익히기 (page 8)**
- 유형 배너: 크게 `유형 01` · `유형 02` (짙은 청록 각진 사각)
- 부속 라벨: 각 유형 안 `대표문제`·`중요` (작은 알약)
- 3열 원형 문제 번호 (숫자만) · 5지 선다 한 줄

#### 개념원리 (청록·라운드 톤)

**색상**: 청록 `#5A9E9E` · 옅은 청록 · 크림/베이지 배경 (KEY Point)

**필수 예제 (page 11)**
- 필수 배너: 좌측 라운드 원형(`필수 01`) + 옆 큰 sans 제목(`두 점 사이의 거리`)
- 우측: 얇은 크림 알약(`더 다양한 문제는 RPM 공통수학 2 8쪽`)
- 배너 아래 옅은 청록 라운드 사각형 (문제 본문 배경 · 스카이 상단선)
- `풀이`: 좌측 작은 sans 라벨 · 우측 본문 (아래 여백 넉넉)
- **KEY Point 박스**: 라운드 원형 배지(`KEY Point`) + 크림 배경 라운드 사각형 안에 핵심 공식
- 확인 문제: 좌측 라운드 원형(`확인 체크 1`) + 우측 본문 (3문 · 각 문항 사이 여백)

**필수 예제 2 (page 12)**
- 유사 구조 · 두 번째 개념 예제
- 좌측 라운드 원형(`필수 02·03`) + 우측 큰 제목
- 우측에 작은 그래프 삽화 (좌표평면 · fp 스타일 유사)

### 종합 인상

- 세 시리즈 모두 **좌상단 각진 챕터 배너 + 큰 프레임** 공통
- 개념 페이지는 **1개 소개념 = 큰 여유 공간** 방향 (수능특강·개념원리)
- 부속 라벨은 **알약(pill) or 라운드 사각** · 짧은 sans 텍스트
- 예제/필수 문제는 **좌측 배지 + 우측 제목·본문**
- 색은 **한 시리즈당 3~4색** 통일 (짙은·옅은·본문·강조)

## 2. DeeP Math 디자인 결정 사항

### 2.1 페이지 크기 · 컬럼

- **A4** (210 × 297 mm) · 마스터 확정
- **single column** (개념 페이지 넓이 확보 · 벤치마킹 3종 모두 single)
- geometry: `top=22mm, bottom=22mm, left=20mm, right=20mm` (좌우 대칭)

### 2.2 색 팔레트 (5색 · 퍼플 톤)

마스터 지시 "퍼플 톤" 반영 · 수능특강 녹색 → 퍼플로 치환.

| 이름 | Hex | 용도 |
|---|---|---|
| `dm-primary` | `#5B2C6F` | 짙은 퍼플. 챕터 배너·유형 배너·라벨 배경·주제목 |
| `dm-light` | `#E8DAEF` | 옅은 퍼플. 개념 박스 배경·부속 라벨 |
| `dm-accent` | `#F4ECF7` | 아주 옅은 퍼플. KEY Point 배경·풀이 배경 |
| `dm-ink` | `#222222` | 본문 텍스트 (검정 유사) |
| `dm-highlight` | `#A93226` | 붉은 톤 강조 (핵심 공식·중요 결론) |

**대비 계산**:
- `dm-primary #5B2C6F` on white: 명도비 8.5:1 (WCAG AAA)
- `dm-ink #222222` on `dm-accent #F4ECF7`: 명도비 15.3:1 (AAA)
- `dm-highlight #A93226` on white: 명도비 5.8:1 (AA)

### 2.3 폰트 (xelatex 한글)

- 본문: **나눔명조** 또는 시스템 기본 (`\setmainhangulfont{NanumMyeongjo}`)
- 제목·라벨: **나눔고딕 Bold** 또는 시스템 sans (`\setsanshangulfont{NanumGothic}`)
- 수식: `newtxmath` (기본)
- 번호·배지: sans bold · 흰 글자 (배지 위)

### 2.4 헤더·푸터

- **헤더**: 좌상단 챕터 배너(작게) · 우상단 시리즈 라벨(`DeeP Math`)
- **푸터**: 하단 좌측 시리즈 서브(`깊이와 통찰 · 공통수학2 정리편`) · 하단 우측 페이지 번호

## 3. 매크로 명세 (`templates/deep-math.sty` v1.0)

### 3.1 색·페이지 기본

- `dm-primary`·`dm-light`·`dm-accent`·`dm-ink`·`dm-highlight` (5색)
- geometry A4 · single column
- fancyhdr 헤더·푸터

### 3.2 챕터 배너

```latex
% \dmchapter{01}{평면좌표}
%   각진 퍼플 사각 안 흰 번호 + 옆에 짙은 퍼플 큰 sans 제목
%   페이지 상단 · 각 챕터 첫 페이지
\dmchapter{01}{평면좌표}
```

### 3.3 개념 페이지 (`dmconcept` 환경)

```latex
% \begin{dmconcept}{1}{두 점 사이의 거리}
%   개념 요약 페이지 1p 전체 · 좌측 라운드 원형 번호 + 우측 큰 제목
%   내부에서 dmexample·dmnote·dmexplain 사용
% \end{dmconcept}
```

부속 라벨 3종:
- `\begin{dmexample} ... \end{dmexample}` — 예 (짙은 퍼플 알약 배경)
- `\begin{dmnote} ... \end{dmnote}` — 참고 (옅은 퍼플)
- `\begin{dmexplain} ... \end{dmexplain}` — 설명 (아주 옅은 퍼플)

### 3.4 KEY Point 박스

```latex
% \begin{dmkeypoint} ... \end{dmkeypoint}
%   개념 페이지 하단 or 예제 하단 · 핵심 공식 강조
%   원형 좌측 배지 "KEY Point" + 옅은 퍼플 배경 라운드 사각형
```

### 3.5 대표 예제

```latex
% \dmtypebanner{01}{두 점 사이의 거리}
%   대표 예제 상단 배너 (좌 각진 퍼플 사각 + 우 옅은 알약)
%
% \begin{dmrepresentative}{1}
%   문제 본문
% \end{dmrepresentative}
%
% \begin{dmapproach} 길잡이 본문 \end{dmapproach}
% \begin{dmsolution} 풀이 본문 \end{dmsolution}
```

### 3.6 확인 문제

```latex
% \dmcheck{1} 확인 문제 본문 (하단 · 2~3문)
%   좌측 라운드 원형 "확인 체크 N" + 우측 본문
```

### 3.7 연습 레벨 배너

```latex
% \dmlevel{1}  →  Level 1 배너 (기본)
% \dmlevel{2}  →  Level 2 배너 (심화)
% \dmlevel{3}  →  Level 3 배너 (도전)
```

### 3.8 실전유형 맛보기

```latex
% \dmrealtype  →  실전유형 맛보기 배너 (학평 소스)
```

### 3.9 유형 요약 박스

```latex
% \begin{dmtypesummary}
%   유형 요약 · 예제 위 or 아래에 배치
% \end{dmtypesummary}
```
