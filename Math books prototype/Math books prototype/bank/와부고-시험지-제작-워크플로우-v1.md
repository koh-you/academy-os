## 일곱 걸음

### 1. 실기출을 고른다

같은 과목·같은 학기·같은 시기의 회차를 고른다.
🔴 **과목을 확인하라** — 공통수학2 는 **고1** 과목이다. 고2 폴더에 없다.

`참고자료/학교기출/고1/와부고/2025/2학기/중간/…공통수학2…문제.pdf`

### 2. 실기출을 읽고 뼈대를 뽑는다

| 무엇 | 세션 109 실측 (와부고 2025 2학기 중간) |
|---|---|
| 문항 수 | **17** (선택형 12 + 서술형 5) |
| 만점 | **100** |
| 배점 | 선택형 4.5→5.5 (계 60.0) · 서술형 6.0·8.0·8.0·8.0·10.0 (계 40.0) |
| 시험범위 | 점과 좌표 ~ 집합 (🔴 **명제가 없다**) |
| 특징 | 긴 지문 + 실물 사진 + 정의 박스형이 **둘** (#16·#17) |

🔴 **배점이 인쇄돼 있는지 확인하라.** 2025 회차는 원본 미인쇄이고, 우리가 본 소수 배점은
**학원 편집본이 붙인 값**이다 (`bank/와부고-출제-페르소나-v1.md:23`). 초록색 `[4.5점]` 은
같은 색 `[와부고 2025]` 태그와 한 벌이다.

### 3. 🔴 맹검 대조 판정 — 두 회차를 섞어서 잰다

**이것이 이 워크플로우의 심장이다.**

```
node scripts/맹검지-tex에서-뽑기.mjs <우리 문제.tex> --json   # 우리 17문
      + 실기출 17문
      → 섞어서 맹검지 34문
      → 판정자 둘에게 따로 (봉인표 비공개)
      → 두 회차의 급 분포를 나란히
```

**지우는 것** — 배점 · 문항 번호 · 출처 · 시험지 머리말.
🔴 **배점은 두 회차의 꼴이 달라 출처가 드러난다. 반드시 지운다.**

🔴 **발문을 손으로 옮겨 적지 마라.** 세션 109 에 네 번 옮겨 적었고, 그것이
「판정한 것과 나가는 것이 어긋나는」 자리였다. `맹검지-tex에서-뽑기.mjs` 를 쓴다.

**판정 방법**은 통합기준이다 — 「이 문항은 어느 앵커와 같은 급인가」 하나를 내놓고,
그 하나를 정할 때 **깊이 · 연산 부담 · 해석·독해 부담** 셋을 본다 (통합관리 C29).

### 5. 다섯 기준으로 다시 짠다

**통합관리 C32.** 소문항을 단독 문항 수준으로 짠다.

| | 기준 |
|:-:|---|
| 1 | 소문항마다 **다른 도구**를 꺼낸다 |
| 2 | 앞 소문항은 **재료만 주고 방법은 안 준다** |
| 3 | 대발문에 **번역 장치**를 하나 심는다 — 수식으로 어떻게 쓰는지는 알려 주지 않는다 |
| 4 | 🔴 **마지막 소문항은 정의로부터 학생이 조건을 스스로 세우게 한다** |
| 5 | **소문항 배점**을 찍는다 (불균등 · 앞은 가볍게) |

🔴 **넷째가 가장 자주 깨진다.** 판정 물음 한 줄 — **「학생이 스스로 만들어야 하는 것이 무엇인가.」**

**난이도를 올리는 지렛대 셋** (세션 109 에 실제로 먹힌 것)

| 지렛대 | 실측 |
|---|---|
| **묻는 방향을 뒤집는다** — 구하던 것을 조건으로 주고, 조건이던 것을 구하게 | 9번 2.40 → **4.10** · 14번 2.85 → **4.15** |
| **매개변수를 살려 둔다** | 진리집합 모양이 셋으로 나뉜다 |
| **관문을 하나 세운다** — 문제가 안 알려 주는 한 걸음 | 11번 「접선의 길이」를 $\overline{\mathrm{PC}}^2-r^2$ 로 |

**🔴 최상단(★ 5 프리미엄)으로 올리는 것 — 단일 출처 `bank/최상단-출제-구조-v1.md`** (2026-08-04 세션 111 신설)

> **마스터 지시**: 「**학평기출을 만드는 구조를 출제 시스템에 안착시켜야 해.**」

학평 최상위 문항 **스물아홉**을 두 번에 나눠 뜯어봤고, 읽은 사람이 서로를 몰랐는데 **같은 것이 나왔다.**

| | 무엇 |
|:-:|---|
| 1 | 🔴 **마지막에 따져야 할 후보를 누가 만드나.** 학생이 **경계까지** 잡으면 최상단이다. 문제가 후보를 주면 내려간다 |
| 2 | 🔴 **갈래가 몇인지 알려 주면 급이 내려간다** (학평 2020.11 #30 이 가장 뒤 자리인데 한 칸 아래인 까닭) |
| 3 | **조건의 생김새가 푸는 방법을 드러내지 않는다** (조건이 차의 꼴이면 「빼서 지워라」가 보인다) |
| 4 | **후보를 줄여 주는 조건을 발문에 쓰지 않는다** |

🔴 **우리 세 번째 안이 죽은 자리가 1번 그대로다** — 「(2)가 후보 집합을 넘겨줘서 (3)이 확인 작업이 된다」.
🟡 **아직 못 박지 않았다** — 표본이 한 생김새에 뭉쳤고 읽은 사람이 각각 하나다. 상세는 그 문서 §5.

**중간 난이도(★ 4)를 올리는 방안 넷**

> **한 문항이 두 값을 요구하고, 두 값이 서로 다른 도구에서 나온다.**

🔴 **두 값이 같은 도구에서 나오면 안 오른다.** 세션 109 실측 —
6번은 $n(A)+n(B)=20$ 한 줄에서 $M$ 과 $N$ 이 한꺼번에 나왔고,
13번은 (가)가 수직이등분선을 주어 (나) 없이도 수선의 발이 나왔다. 둘 다 3.9 언저리였다.

🔴 **조건을 두 줄로 나누는 것만으로는 부족하다. 두 줄이 서로 다른 층을 걸어야 한다.**
(보기 — (가)는 개수 층, (나)는 원소 층)

### 🔴 금지 셋

1. **계산 더럽히기** — 무리수·큰 수 심기는 **질 저하**다
2. **개수 세기로 노동 늘리기** — 최상급에서 카운팅 결론식 금지
3. **소문항 늘리기** — 개수는 난이도가 아니다

### 8. 🔵 자리를 값 순으로 늘어놓는다 (2026-08-05 세션 115 신설)

평균이 맞아도 **자리가 어긋나 있을 수 있다.**
재현-2회는 −0.10 으로 맞았는데 옛 11번이 **3.30 인 채로 5.4점을 달고 열한 번째**에 있었다.
옛 4번(4.30)보다 한 점 가벼웠다.

**하는 일**
1. 선택형을 맹검 실측값 순으로 세운다
2. 배점을 자리 순서대로 다시 매긴다 (와부고는 4.5 → 5.5)
3. 정답 자리를 다시 센다 — 값만 보고 세우면 **이음이 셋 넘게 생긴다** (통합관리 C33)
4. 값이 판정자 흔들림(±0.3) 안에서 붙어 있는 자리에서만 순서를 바꿔 이음을 끊는다
5. 문제지·답지·대조표를 함께 고친다

🟢 **본문을 한 글자도 안 고치므로 판정값이 그대로 따라온다. 다시 재지 않는다.**
🔴 **문항 주석 안의 「N번」 이 통째로 낡는다.** 파일 머리에 「옛 → 새」 대응표를 박아 둔다.

## 🔴 문항별 에이전트를 쓸 때

문항마다 에이전트를 붙이면 깊게 파는 대신 **시험지 전체가 안 보인다.**

세션 109 에 작업자들이 각자 「안 겹친다」고 했는데 모아 놓으니 —
- **접함이 다섯 문항**이었다 (~~마스터가 셋으로 줄이라 확정~~ → 🔴 **2026-08-03 해제**, 아래 참조)

> 🔴🔴 **접함 제한 해제 (2026-08-03 세션 110 · 마스터)**: 「**접함 제한은 해제.**」
>
> **까닭 — 제한이 값을 치르게 하는 것이 실측으로 확인됐다.** 프리미엄 문항을 세 번 만들려 했는데
> 도형의 방정식 쪽 정점급 원본이 **최근 네 해 거의 전부 접함**이라 그 갈래가 통째로 막혀 있었다
> (`_scratch/재설계-15번-v2-원본pick-제안.md`). 세 번 다 집합 쪽으로 우회했고 세 번 다 못 닿았다
> (4.90 · 4.70 · 4.33 — `bank/measurements/와부대조-재판정-세션110-v9-세번째.md`).
>
> 🔴 **해제이지 권장이 아니다.** 접함을 늘리라는 뜻이 아니라, **개수로 막지 않는다**는 뜻이다.
> 겹침 점검은 그대로 한다 — 같은 수학이 두 번 나오면 여전히 결함이다.
> 세는 것과 겹치는 것은 다르다. **다섯 문항이 저마다 다른 일을 하면 다섯이어도 된다.**
- 17번 첫 안이 **11번과 같은 수학**이었다 (두 원에 그은 접선의 길이가 같은 점의 자취)

🔴 **시험지 전체의 도구 목록을 주고 대조표를 내게 한다. 마지막에 한 번 더 전체를 훑는다.**
🔴 **제안과 적용을 나눈다** — 여럿이 같은 파일을 동시에 고치면 서로 덮어쓴다.
제안서는 문항마다 따로 쓰게 하고, 적용은 하나가 차례로 한다.
