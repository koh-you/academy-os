\pairheader{BT-002}

\begin{multicols}{2}
\itemhead{문항 A}

원 $(x-2)^2 + y^2 = 9$ 위의 두 점 $\mathrm{A}$, $\mathrm{B}$를 지나는 선분 $\mathrm{AB}$를 접는 선으로 하여 원을 접었더니 $x$축과 점 $(4, 0)$에서 접하였다.

\vspace{0.5em}

직선 $\mathrm{AB}$의 방정식을 $x + ay + b = 0$이라 할 때, $a + b$의 값을 구하시오.

\columnbreak

\itemhead{문항 B}

원 $x^2 + (y+3)^2 = 16$ 위의 두 점 $\mathrm{A}$, $\mathrm{B}$를 지나는 선분 $\mathrm{AB}$를 접는 선으로 하여 원을 접었더니 $y$축과 점 $(0, -2)$에서 접하였다.

\vspace{0.5em}

직선 $\mathrm{AB}$의 방정식을 $y = mx + n$ $(m > 0)$이라 할 때, $m \times n$의 값을 구하시오.
\end{multicols}

\vspace{0.5em}

\vspace{0.5em}

$\overline{\mathrm{AB}} = 4$가 되는 모든 양수 $r$의 곱을 구하시오.
