# 2026-07-30 평행 기호는 `\para` (기울어진 `//`)

## 지적 원문
> 16번에 평행 기호는 // 이어야 해

## 본질

한국 고등학교 교과서의 평행 기호 표준은 **기울어진 `//`** 이다. LaTeX 기본 `\parallel` 은 **수직 두 막대(∥)** 로 렌더링되어 교과서 표기와 다르다.

프로젝트 표준 매크로가 이미 존재했다:

```latex
% templates/style.sty:917
% ── 한국 교과서식 기울어진 평행 기호 (∥ 대체) ──
% \parallel 은 두 수직 막대, 한국 교과서는 기울어진 // 형태가 표준
\newcommand{\para}{\mathbin{/\mskip-5mu/}}
```

**즉 규약 부재가 아니라 규약 미시행 사건이다.** 주석까지 달아 정의해두고 정작 콘텐츠 작성 시 `\parallel` 을 썼다.

## ⚠️ 답지 작성 시 주의

`templates/DeeP-Math-v6/dm-answer-classic.sty` 는 **`style.sty` 를 로드하지 않는다.** 답지에서 `\para` 를 쓰려면 프리앰블에 정의를 직접 넣어야 한다. 넣지 않으면 `Undefined control sequence` 로 빌드가 깨진다.

- `master-feedback-check.mjs` 가 `\parallel` 을 RED로 자동 차단 (본 파일 frontmatter).
