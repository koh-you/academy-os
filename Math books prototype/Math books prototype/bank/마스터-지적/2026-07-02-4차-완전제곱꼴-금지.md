# 2026-07-02 4차 완전제곱꼴 사차식 CM1 출제 금지

## 지적 원문
> 2회차 14번 문제는 미분을 이용한 4차 함수 그래프 추론으로 봐야함. 4차 완전 제곱꼴은 고1에서 다루지 않음. 변경 요청

## 본질
- **4차 완전제곱꼴 인식**: $x^4 - 4x^3 + 6x^2 - 4x + 1 = (x-1)^4$ 같은 이항계수 $\binom{4}{k}$ 나열식은 학생 관점에서 "완전제곱꼴 인식 → 평행이동" 관점으로 풀이해야 자연스러움.
- 이는 사실상 **4차 함수의 그래프 추론 = 미분·미적분Ⅰ 범위**, CM1 밖.
- $(x-1)^4 \ge 0$의 극값 부등식 자체가 4차 그래프 감각.
- 학생 관점에서 CM1 범위 도구 (이차 판별식·치환·인수분해)로 접근 매우 불편.

## 발생 지점
- **2회 #14 (2026-07-02 정정 이전)**:
  ```
  $x^4 - 4x^3 + 6x^2 - 4x + k = 0$이 실근을 갖지 않도록 하는 실수 $k$의 값의 범위는?
  ```
  선지: $k > 0$, $k > 1$, $k > 2$, $k \ge 1$, $k > 4$ → 답 ② $k > 1$

## 정정 완료 (2026-07-02)
- **신규 2회 #14**:
  ```
  $x^4 - 6x^2 + k = 0$이 실근을 갖지 않도록 하는 실수 $k$의 값의 범위는?
  ```
  선지: $k > 6$, $k > 7$, $k > 8$, $k > 9$, $k > 10$ → 답 ④ $k > 9$
- **신규 답지 #14**: `\soltitle{사차방정식을 이차방정식으로 치환하기}`
  - $t = x^2 \ge 0$ 치환 → $t^2 - 6t + k = 0$
  - 두 t근의 합 = 6 > 0이므로 두 t근 모두 음수 불가 → "실근 없음 ⟺ 판별식 < 0"
  - $36 - 4k < 0 \Rightarrow k > 9$
