## 지적의 본질

같은 시리즈에서 *발문 단어만 교체한 자기복제* (의자 → 책상·학생 → 사람·이름 A·B·C → P·Q·R 등)는 학생에게 *반복 학습* 의미 없음. 시판 4종+ 학평 strict 표본은 *발문 본질·통찰 구조·자유도 결합*이 매번 다름. 우리 시리즈도 *같은 통찰 카드 2개 이상 일치 + 같은 메타*면 자기복제로 RED 차단.

마스터 *극한* 강도 명시: "자기복제 금지 철저하게 지킬것." → 검출 도구 강화 + 마스터-지적 RED 등록 + 출제 메커니즘 G4'(자기복제 판정) RED 의무.

## 자기복제 판정 기준 (v1.0)

| 신호 | 임계값 | 등급 |
|---|---|---|
| 같은 슬롯 위치 + 같은 메타 + 통찰 카드 ≥ 2개 일치 | 강 | 🔴 RED |
| 같은 슬롯 위치 + 단어 치환 후 *발문 본질* 동일 (예: 의자 → 책상, 학생 이름 변경) | 강 | 🔴 RED (수동 검수 의무) |
| 다른 슬롯 위치 + 통찰 카드 ≥ 3개 일치 (시리즈 누적) | 강 | 🔴 RED |
| 같은 슬롯 위치 + 통찰 카드 1개 일치 | 약 | 🟡 YELLOW |
| 메타 유형 동일 + 발문 구조 (자유도·분기·결합) 유사 | 약 | 🟡 YELLOW |
