## 지적의 본질

마스터의 본 지적은 *표면 결함*과 *구조 결함* 두 층으로 구성:

**표면 결함**: "정확히 N개" 표현이 7회차 v2 본문 #15·#18·#20 세 슬롯에 반복 등장. 발문 다양성 부족 + 마스터 의향과 충돌.

**구조 결함**: 마스터의 *이전* 지적("정확히 안 하기로 했다")이 메모리에 등록되지 않았고, 워딩사전 §2.5가 오히려 "정확히 N개"를 *표준 어구로 권장*하고 있어 시스템이 마스터 의향과 *반대로* 작동. 검수 에이전트도 본 표현을 통과시킴.

본 지적 등록은 *표면 결함 차단* + *구조 결함 해소* 동시 목적.

## 차단 키워드 명세 (regex)

```
정확히\s*\$?\d+\$?\s*개            # "정확히 5개", "정확히 $5$개"
정확히\s*\$?\d+\$?\s*(이|가|로)\s*(되|있)  # "정확히 5가 되도록", "정확히 3이 있는"
개수가\s*정확히                     # "개수가 정확히 N"
정확히\s*[일이삼사오육칠팔구십]+\s*(개|로)  # "정확히 한 개", "정확히 둘로"
```

**적용 제외**: 일반 부사로서의 "정확히" (예: "정확히 풀어라", "값을 정확히 계산", "정확히 답하시오"). *수 + 개* 결합 형태만 RED.

## 대안 표현 (마스터 의향 추정)

| 금지 | 대안 |
|---|---|
| "개수가 **정확히** 5가 되도록 하는" | "개수가 5인" / "개수가 5가 되도록 하는" (정확히 빼기) |
| "**정확히** 한 개의 해" | "오직 한 개의 해" / "단 한 개의 해" |
| "**정확히** 5개의 정수" | "5개의 정수" (그냥 수 명시) |
| "**정확히** N개가 존재" | "$N$개가 존재" |

워딩사전 §2.5 표준 어구 "정확히 N개" → **금지 변형으로 격하**. 대안으로 *수 직접 명시*.

근거: 한국 고교 수학 교과서 표준에서 "정확히"는 *과잉 강조*. "개수가 5인" 형태가 더 자연스럽고 명확.
