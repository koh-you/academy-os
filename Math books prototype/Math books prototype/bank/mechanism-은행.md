## 근본 원리 (Meta-Mechanism 7개)

모든 정점 문항이 공유하는 심층 원리 (소스 5개 공통 발견):

### Meta-M1. 조건 재해석 (표면 → 실질)
- 표면 조건 개수 < 실질 조건 개수 (gap 2~3개)
- 학생이 자발적으로 발굴하는 암묵 조건
- **판정**: 표면 조건 걷어내면 표준 유형인가? YES면 정점 아님

### Meta-M2. 자유도 확보 (학생 판단 지점 4+)
- 초기 설정 자유 (좌표계 선택 등)
- 풀이 경로 자유 (다중 접근 가능)
- **금지**: 서술형 소문항 (1)(2)(3) 스크립트화 (자유도 봉쇄)

### Meta-M3. 경계값 비교
- 전체 함수 분석 → 몇 개 경계값만 비교
- 예: 포함관계 P⊂Q ⟺ 끝점 비교 (p_min≥q_min ∧ p_max≤q_max)
- 접선 조건 ⟺ 중심 거리 = 반지름

### Meta-M4. 논리-기하-대수 다중 번역
- 명제 (논리) ↔ 진리집합 (집합) ↔ 좌표 영역 (기하) ↔ 부등식 (대수)
- 학생이 자유롭게 넘나들어야 함

### Meta-M5. 최적화 논리
- "모든 P에 대해 d(P) ≥ k" ⟺ k ≤ inf d(P)
- 한정자 (∀·∃) ↔ 연산 방향 (inf·sup)

### Meta-M6. 함정 이중성
- 표면 함정 (공식 적용 오류·부등호 방향) — ★ 4 학생이 뚫음
- 깊은 함정 (개념 혼동·필요vs충분·최대vs최소) — ★ 5만 뚫음

### Meta-M7. 연속-이산 결합
- 원·자취 (연속) + 격자점·정수 조건 (이산)
- 정수 자유도 카운트 (예: mod n 열거)

## GM (도형의 방정식) Mechanism 13개

### GM-M1. 대칭 변환의 자취
- **원리**: 점을 직선·점·축에 대해 대칭 → 매개변수 소거 → 자취 방정식
- **심층 도달 조건**:
  - 매개변수 3+ 값 case 처리
  - 자취가 원·직선·포물선인지 학생이 발견 (형태 명시 금지)
  - 역방향 (parabola focus-directrix property 등)
- **자유도**: 대칭 순서 선택·매개변수 선택
- **앵커**: WBG-2025M #14 · #11 · 평가원 대칭 문항
- **오답 유도**: 대칭점 좌표 실수·역방향 인식 미부족

### GM-M2. 원-직선 위치 관계 (거리 부등식·판별식)
- **원리**: `|ax+by+c|/√(a²+b²)` vs `r` 비교
- **심층 조건**:
  - 두 원과 동시 조건 (교집합)
  - 매개변수 정수 카운트
  - 접선·불만·불통 3 case
- **자유도**: 거리 공식 vs 판별식 선택
- **앵커**: WBG-2025M #7·#10 · 블랙라벨 · EBS 올림포스 · 평가원
- **오답 유도**: 부등호 방향·경계 포함 여부

### GM-M3. 두 원의 근축 (공통접선·교점)
- **원리**: 두 원 방정식 뺄셈 → 근축 (직선)
- **심층 조건**:
  - 근축 + 정수 자유도 결합 (mod n)
  - 근축 + 조건 여러 개
  - 물리 현상 (개기월식 3원 등)
- **자유도**: 근축 발견 자유·해석 방향
- **앵커**: WBG-2025M #17 개기월식·WBG-2025M #9 두 원 교점·평가원 학평 다수
- **오답 유도**: 근축 개념 인식 없이 연립 시도

### GM-M4. 매개변수 정점·직선족
- **원리**: 매개변수 관해 정리 → 무관계수 원리 → 정점 도출
- **심층 조건**:
  - 정점 + 접선 개수 조건
  - 정점 + 원 위치 판정
  - 다층 매개변수 소거
- **자유도**: 정점 찾기·활용 방향
- **앵커**: 블랙라벨 GM-01-17
- **오답 유도**: 매개변수 남긴 채 계산

### GM-M5. 무게중심·중선의 성질
- **원리**: 세 점의 거리 제곱 합 최소 = 무게중심
- **심층 조건**:
  - 무게중심 + 정수 좌표 제약 (이산)
  - 무게중심 + 원 위 조건
  - 무게중심 궤적
- **자유도**: 무게중심 발견·활용
- **앵커**: 블랙라벨 GM-01-02
- **오답 유도**: 무게중심 성질 인식 없이 각 점 독립 처리

### GM-M6. 자취 방정식 유도 (M6 결과 재조합)
- **원리**: 조건 → 좌표 표현 → 매개변수 소거 → 자취
- **심층 조건**:
  - 자취가 예상과 다른 도형 (원 아닌 직선 등)
  - 자취 + 정수 조건 결합
  - 표면적 다중 조건 → 하나의 자취로 축약 (M3)
- **자유도**: 자취 도출 경로·매개변수 선택
- **앵커**: WBG-2025M #14·#11
- **오답 유도**: 자취 형태 발문에 노출 (금지)

### GM-M7. 접선 조건 (거리=반지름·판별식=0)
- **원리**: 원-직선 접선 3 조건 (거리·판별식·기하 대칭)
- **심층 조건**:
  - 공통 접선 (외접·내접·수 판정)
  - 접선 + 자취 결합
  - 접선 + 정수 카운트
- **자유도**: 접선 조건 도출 방식
- **앵커**: EBS 올림포스 고난도·평가원
- **오답 유도**: 하나의 조건만 확인 (외접 접선 놓침)

### GM-M8. 도형 이동·닮음 변환 (평행·대칭·회전·닮음)
- **원리**: 이동·대칭 규칙 · 닮음비 (넓이비=닮음비²)
- **심층 조건**:
  - 이중 대칭·다층 이동
  - 기구학 링크 (평행사변형 링크→고정 닮음비)
  - 자취 대응 관계
- **자유도**: 이동 순서·닮음 중심 선택
- **앵커**: WBG-2025M #16 사도기·#3·평가원
- **오답 유도**: 닮음비→넓이비 잘못 (1차 vs 2차)

### GM-M9. 원주각·기하 정리
- **원리**: 원주각·중심각·접선각 관계
- **심층 조건**:

- **앵커**: 평가원·EBS 올림포스

### GM-M10. 최적화 (거리·둘레·넓이 최소)
- **원리**: 대칭점 반사→최단경로 (톨레미 부등식)

- **자유도**: 반사점 선택·경로 설계
- **앵커**: WBG-2025M #11 삼각형 둘레·고쟁이 GM-246
- **오답 유도**: 각 거리 독립 최적화 (합산 최소 아님)

### GM-M11. 정수 좌표·격자점 (연속-이산 결합)
- **원리**: 도형 + 격자점 조건 → 이산 카운트

- **앵커**: WBG-2025M #15·평가원
- **오답 유도**: 격자점 조건 놓침·경계 포함 실수

### GM-M12. 좌표계 선택 자유도

## ST (집합과 명제) Mechanism 9개

### ST-M1. 진리집합-포함관계 번역 (경계 비교)
- **원리**: p→q ⟺ P⊂Q ⟺ 경계값 비교 (p_min≥q_min ∧ p_max≤q_max)
- **심층 조건**:
  - 매개변수 포함 (p 또는 q 하나 이상)
  - 경계 포함/미포함 (등호 처리)
  - 필요·충분 판정 다중
- **자유도**: 경계 비교 vs 수직선 vs 경우 분류
- **앵커**: 고쟁이 ST-386·ST-391·평가원 학평 다수
- **오답 유도**: 필요·충분 역·경계 포함 오류

### ST-M2. 명제 동치 변환 (대우·역·이·필충)
- **원리**: p→q ≡ ¬q→¬p (대우) ≡ ¬p∨q ≡ ¬(p∧¬q)
- **심층 조건**:
  - 다중 명제 (∀·∃) 결합
  - 반례 발견 (∀ 명제 거짓 판정)
  - 필충 vs 충분 판정
- **자유도**: 어느 동치형 사용할지 선택
- **앵커**: 고쟁이 ST-391·ST-410
- **오답 유도**: 역과 대우 혼동

### ST-M3. 벤 다이어그램-대수 번역 (포함배제)
- **원리**: 세 집합 7영역 분할 → 미지수 배정 → 연립 부등식
- **심층 조건**:
  - 3중 교집합 조건
  - 최댓값·최솟값 (정수 계획법)
  - 조건 다층 (합·교·차·여 결합)
- **자유도**: 미지수 배정 순서·조건 우선순위
- **앵커**: WBG-2025M #6·고쟁이·평가원
- **오답 유도**: 7영역 정의 오류·중복 계산

### ST-M4. 부분집합 조건·자유도 카운트
- **원리**: n(X)=k 조건 + 원소별 자유 선택 → 조합 (2^n · nCk)
- **심층 조건**:
  - 원소별 X 전용·Y 전용·공유 3-상태 case
  - 조건 3+ 결합 (X⊂A · X∩B=... 등)
  - 순서쌍 (X, Y) 카운트
- **자유도**: 조건 순서·case 분리 방식
- **앵커**: WBG-2025M #8 부분집합·평가원 학평
- **오답 유도**: case 누락·중복 계산

### ST-M5. 여집합·드모르간 법칙
- **원리**: (A∪B)^c = A^c ∩ B^c · 중첩 집합식 축약
- **심층 조건**:
  - 다층 중첩 (4+ 연산)
  - 항등식 발견 후 축약 (예: (A∪B)∩(A∪B^c) = A)
- **자유도**: 축약 순서·전개 방향
- **앵커**: WBG-2025M #5·고쟁이 ST-388
- **오답 유도**: 각 부분식 독립 전개→계산 폭발

### ST-M6. 3중 교집합·격자점 조합
- **원리**: 3개 원·집합 교집합 → 격자점 조합 카운트
- **심층 조건**:
  - 각 원 중심·반지름 매개변수화
  - 격자점 개수 → 원 위치 역방향 도출
  - 3중 조합 (원 3개 상호 관계)
- **자유도**: 격자점 카운트 접근·역방향 도출
- **앵커**: WBG-2025M #15
- **오답 유도**: 3중 아닌 2중만 계산

### ST-M7. 명제 반례 (∀ ↔ ∃)
- **원리**: ∀ 명제 거짓 → ∃ 반례 · ∃ 명제 참 → 예시
- **심층 조건**:
  - 반례 구성 (특정 값·case)
  - 반례가 조건 전제 만족 확인
  - 필충 판정 반례
- **자유도**: 반례 선택·전제 검증
- **앵커**: WBG-2025M #10 명제 판별·고쟁이 ST-391
- **오답 유도**: 반례가 전제 미만족 (엉뚱한 반례)

### ST-M8. 절대부등식·경우 분류
- **원리**: 절댓값 부등식·산술기하평균 부등식 (CM2 범위 내)
- **심층 조건**:
  - 조건 다중 절댓값
  - 최대·최소 경계
  - 부호 case 분리
- **자유도**: case 분리 vs 그래프
- **앵커**: 평가원·EBS 올림포스
- **오답 유도**: 경우 누락·경계 처리

### ST-M9. 논리 판정 다층 (필충·역·대우 결합)
- **원리**: 여러 명제 참·거짓 판정 · 각 명제가 다른 명제에 영향
- **심층 조건**:
  - 3+ 명제 상호 관계
  - 대우·역·이 판정 다중
  - 진리집합 관계 다층
- **자유도**: 판정 순서·논리 결합
- **앵커**: WBG-2025M #10 명제 판별·평가원 학평·고쟁이 ST-410
- **오답 유도**: 명제 하나에 매몰

## Mechanism 조합 방식 (정점 3문 설계 원칙)

### 정점 문항 자격 (composite ≥ 33)
정점 3문은 다음 중 하나 방식으로 구성:

**패턴 A. 단일 Mechanism 심층**
- 하나의 mechanism을 3~4 심층 조건 모두 충족
- 예: WBG-2025M #16 사도기 (GM-M13 물리 mechanism + M8 닮음 변환)

**패턴 B. 2 Mechanism 결합**
- 다른 카테고리 mechanism 2개 결합 (예: 자취 + 정수)
- 예: WBG-2025M #14 (GM-M1 대칭 자취 + GM-M11 격자점)

**패턴 C. 3+ Mechanism 결합 (최상위)**
- 3+ mechanism 통합 · Meta-M4 다중 번역 필수
- 예: WBG-2025M #15 (GM-M11 격자점 + ST-M3 벤 + ST-M6 3중 교)

## 자유도 지표 (Meta-M2 정량화)

**자유도 지표** = 학생 판단 지점 수 · 3+ 이상이 정점 조건

| 요소 | 값 |
|---|---|
| 소문항 (1) 발문에 결과 형태 노출 ("자취가 원") | -2 |
| 소문항 (2) 발문에 (1) 결과 완전 명시 | -1 |
| 소문항 (3) 발문에 스크립트 지시 ("(2) 결과를 이용하여") | -1 |
| 학생이 mechanism 발견해야 함 | +2 |
| 학생이 접근 방법 선택 | +2 |
| 초기 좌표계·매개변수 선택 자유 | +1 |
| 자유도 3+ 정점 조건 · < 3이면 RED |

## 회차 순환 원칙 (mechanism 다양성)

- 각 mechanism별 `usage_count` 필드 관리
- 다음 회차 선택 시 usage_count 낮은 순
- 회차당 정점 3문 = 서로 다른 3 mechanism
- 회차 간 3회 이내 재사용 금지

## 활용 방식 (agent v1.6 강제 참조)

mechanism_ref:

    - "물리 mechanism 자체 수학 정합"
    - "지문 mechanism → 근축 수학 core 활용"
