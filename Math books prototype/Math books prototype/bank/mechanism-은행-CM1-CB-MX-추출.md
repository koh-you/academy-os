## CB (경우의 수 · 순열·조합) Mechanism 8개

### CB-M1. 부등식·방정식 정수해 카운트 (경우 분류)
- **원리**: 부등식·방정식 조건을 만족하는 정수 순서쌍을 경우별 분류 후 합산
- **심층 조건**:
  - 다변수 부등식/방정식 ($x+3y \le 10$, $x+3y+2z=18$ 형태)
  - 음수/양수/0 포함 범위 제약
  - 기하학적 조건과 결합 (대각선 길이·부피)
- **자유도**: 경우 분류 기준점 선택 (최상위 변수부터)
- **앵커**: 고쟁이-CM1-CH08-STEP2-#636, #639, #641, #642, #644, #645 · STEP3-#673
- **오답 유도**: 음수 개수 누락·경계값 중복 계산

### CB-M2. 격자 최단경로 (제약 조건)
- **원리**: 격자 도로망에서 특정 지점 우회·필경유 조건 하 최단경로 수 계산
- **심층 조건**:
  - 공사·침수 영역 우회 (경로 수 0 처리)
  - 3개 이상 지점 필경유 (경로 분할 곱셈)
  - 같은 지점 2번 이상 통과 금지
- **자유도**: 경로 분할 기준점 선택
- **앵커**: 고쟁이-CM1-CH08-STEP2-#649 · STEP3-#668, #682
- **오답 유도**: 우회 지점 이웃을 실수로 차단·경로 분할 순서 누락

### CB-M3. 지도·도형 색칠 (인접 다름)
- **원리**: 인접 영역·변 공유 도형이 서로 다른 색을 가져야 한다는 조건에서 칠하기 방법의 수
- **심층 조건**:
  - 같은 색 허용/금지 조건 결합 (A·C 같은 색 vs 다른 색)
  - 환형·직선 배치·복잡 인접 관계
  - 특정 영역 고정 색 조건
- **자유도**: 첫 칠하기 영역 선택·대칭성 활용
- **앵커**: 고쟁이-CM1-CH08-STEP2-#666, #667 · STEP3-#677, #679
- **오답 유도**: 인접성 오인 (대각을 인접으로)·경우 중복 계산

### CB-M4. 자릿수·자연수 카운트
- **원리**: 범위·자릿수·배수 조건 자연수를 자릿수별로 분류 카운트
- **심층 조건**:
  - 자릿수 범위 제약 (100~400, 각 자리 숫자 모두 다름)
  - 배수 조건 (홀수·3의 배수)
  - 순위 결정 (작은 수부터 몇 번째)
- **자유도**: 분류 기준 선택 (일의 자리 먼저 vs 백의 자리 먼저)
- **앵커**: 고쟁이-CM1-CH08-STEP2-#637, #656, #664, #665
- **오답 유도**: 자릿수 범위 오인·홀짝 판정 실수

### CB-M5. 약수·배수·포함배제
- **원리**: 정수 조건을 배수·약수로 인수분해 · 포함-배제 원리로 집합 크기 계산
- **심층 조건**:
  - 소인수분해 및 약수 개수 공식 $\tau(n) = (e_1+1)\cdots(e_k+1)$
  - 최대공약수 조건·배수의 합집합
  - 여사건 (6의 약수 없음)
- **자유도**: 포함-배제 항 순서
- **앵커**: 고쟁이-CM1-CH08-STEP2-#640, #653, #654, #657, #659 · STEP3-#658
- **오답 유도**: 약수 공식 오용·겹침 중복 계산

### CB-M6. 수형도·조건부 배치 (카탈랑·derangement)
- **원리**: 순차 선택·제약 조건·금지 쌍을 수형도로 전개 → 경로 수 (완전순열, 이웃 금지 등)
- **심층 조건**:
  - 각자 자기 것 아닌 배치 (완전순열 $D_n$)
  - 부분 완전순열 + 추가 제약
  - 승패 누적 조건 (항상 A승 ≥ B승) → 카탈랑 수
- **자유도**: 수형도 분기점 선택
- **앵커**: 고쟁이-CM1-CH08-STEP2-#646, #647, #648 · STEP3-#670
- **오답 유도**: 금지 조건 재확인 부족·첫 단계 필수 분기 누락

### CB-M7. 다항식·약수·곱 항의 개수
- **원리**: 다항식 전개식의 서로 다른 항 개수·약수 개수·곱 결과의 서로 다른 값을 곱의 법칙·조합론으로 계산
- **심층 조건**:
  - $(x-y)^3(a+b+c)^2$ 전개 후 겹치는 항 제외
  - 카드 곱의 약수 개수
  - 서로 다른 순서쌍 곱 값의 개수
- **자유도**: 중복 판정 기준
- **앵커**: 고쟁이-CM1-CH08-STEP2-#651, #657
- **오답 유도**: 약수 공식 적용 범위 오인·중복 항 재계산

### CB-M8. 원형 배치·회전 대칭·나머지 순환
- **원리**: 원형 배치·원판 회전·나머지 순환 조건에서 배치 경우의 수
- **심층 조건**:
  - 나머지 분류 (mod 분류에 의한 홀수 추출)
  - 원판·원형 좌표 조건 ($a-1 < b-3$)
  - 숫자 나열에서 특정 숫자 제외
- **자유도**: mod 분류 기준 또는 원판 case 분류
- **앵커**: 고쟁이-CM1-CH08-STEP2-#650 · STEP3-#675
- **오답 유도**: 순환 구간 오인·제외 숫자 재계산

## MX (행렬의 뜻과 연산) Mechanism 9개

### MX-M1. 행렬 정의·서로 같은 행렬 (성분 연립)
- **원리**: $A=B$ 조건에서 대응 성분이 같다는 원리로 미지수 식을 연립
- **심층 조건**:
  - 4식 연립 (2×2 행렬의 각 성분 조건)
  - 이차식 계수 비교·홀짝 케이스 분리 ($i+j$ 홀짝)
  - 대칭식 항등화 ($x=y=z$ 도출)
- **자유도**: 연립식 정리 순서
- **앵커**: 고쟁이-CM1-CH10-STEP2-#819, #821, #823
- **오답 유도**: 성분 대응 오류·홀짝 케이스 누락

### MX-M2. 행렬 연산 인수분해 (AB=BA 유도)
- **원리**: 행렬 연산 식을 인수분해하여 교환법칙 조건 $AB=BA$ 유도 또는 성분 조건 도출
- **심층 조건**:
  - $(A-B)(A-2B) = A^2 - 3AB + 2B^2$ 형태 전개
  - $(A+B)(A-B) = A^2 - B^2$ 성립 ⇒ $AB=BA$ 필요 조건
  - 성분 4식 연립 → 이차방정식 근계 활용
- **자유도**: 인수분해 형태 선택
- **앵커**: 고쟁이-CM1-CH10-STEP2-#840, #841, #843, #849, #850 · STEP3-#879
- **오답 유도**: 교환법칙 무시 (($A-B)^2$ 오용)

### MX-M3. 거듭제곱 일반항·주기 순환
- **원리**: $A^n$ 거듭제곱을 계산하여 주기 또는 일반항 패턴 도출
- **심층 조건**:
  - 주기 2·3·4·6 등 ($A^2=E$, $A^3=E$, $A^3=-E$)
  - 삼각행렬의 귀납적 일반항
  - 부호 교대 합 또는 등차 합계
- **자유도**: 귀납 기저 선택·합 계산 순서
- **앵커**: 고쟁이-CM1-CH10-STEP2-#832, #833, #837 · STEP3-#887, #891
- **오답 유도**: 주기 오인·합 공식 오용

### MX-M4. 케일리-해밀턴 형식 ($A^2 = aA + bE$)
- **원리**: $A^2 = aA + bE$ 형태에서 $A^n$을 $A$와 $E$의 선형결합으로 표현 · **마스터 확립 (2026-06-24): 답지·풀이 직접 인용 허용**
- **심층 조건**:
  - $A^2 = 5A$ ⇒ $A^n = 5^{n-1}A$ 도출
  - $A^2 = 2A - E$ ⇒ 대입 반복 (고차항 축약)
  - 벡터 상 적용: $A^{100}(v) = 5^{99}A(v)$
  - $B = 2E - A$ + $A^2 = 5A$ ⇒ $B^2$, $B^3$ 계산
- **자유도**: 대입 순서 선택
- **앵커**: 고쟁이-CM1-CH10-STEP2-#837, #854, #858, #861, #862, #865, #868 · STEP3-#883
- **오답 유도**: 선형결합 계수 오산·벡터 상 대입 실수

### MX-M5. 단위행렬 조건·거듭제곱 축약
- **원리**: $A^3 = -E$·$A^4 = E$ 같은 단위행렬 거듭제곱 조건에서 고차 지수를 저차로 축약
- **심층 조건**:
  - $A^6 + A^7 = -4A - 4E$에서 $A^{12} + A^{13}$ 계산 (양변에 $A^6$)
  - $(A-E)^3$ 반복 계산
  - 생성원 활용: $\omega^3 = 1$, $\omega^2 + \omega + 1 = 0$
- **자유도**: 양변 곱하기 기준·축약 형태 선택
- **앵커**: 고쟁이-CM1-CH10-STEP2-#858~#867, #869 · STEP3-#884, #885
- **오답 유도**: 주기 길이 오인·복소수 근의 성질 미숙

### MX-M6. 선형결합·열벡터 상 (Image Mapping)
- **원리**: $A(v) = w$ 형태에서 $A^2(v)$, $A^n(v)$ 계산 또는 열벡터 선형결합으로 미지수 도출
- **심층 조건**:
  - 두 상 벡터 조건 결합: $Av = w_1$, $A^2 v = w_2$ ⇒ $A$의 성분 도출
  - 선형결합 대입 연립
  - 순환 패턴: $A(0;8) = (-2)^n(2;-1)$ 주기 구조
- **자유도**: 선형결합 기저 벡터 선택
- **앵커**: 고쟁이-CM1-CH10-STEP2-#852, #853, #855, #856, #857 · STEP3-#887
- **오답 유도**: 기저 벡터 외적 (독립성 확인 누락)·순환 주기 오인

### MX-M7. 진위판정·조건부 논증 (참·거짓 검증)
- **원리**: 3개 보기의 참·거짓을 행렬 조건식 대입과 반례 검증으로 판정
- **심층 조건**:
  - 명제 $AB=A \Rightarrow A^{100}+B^{100}=A+B$ 논증
  - 반례 찾기: $A^2=O$ (영행렬 아님) 반례 존재
  - 거듭제곱 성질 홀짝 판정
  - 세 조건 결합
- **자유도**: 검증 순서·반례 구성 방법
- **앵커**: 고쟁이-CM1-CH10-STEP2-#871, #873, #875, #876, #877, #878 · STEP3-#884, #885, #888, #889, #890, #892, #893
- **오답 유도**: 반례 충분히 검증하지 않음·특정 조건만 확인 후 빠져나감

### MX-M8. 정의된 연산·함수 (Custom Operation)
- **원리**: $f(X,Y) = XY - YX$, $X * Y = (X-Y)(X+Y)$, $d(X)$ 같은 새로운 연산을 정의하고 조건 판정
- **심층 조건**:
  - 대괄호곱 (commutator): $[A,B] = AB - BA = -[B,A]$
  - 곱셈 정의 변형: $f(A+B, A-B) = -2f(A,B)$ 도출
  - 판별식 형 정의: $f(X) = ad - bc$
  - 최소 자연수 정의: $d(A) = \min\{n: A^n = E\}$
- **자유도**: 연산 성질 증명 순서
- **앵커**: 고쟁이-CM1-CH10-STEP2-#872, #873, #874 · STEP3-#888
- **오답 유도**: 연산 정의 혼동·조건 누락 검증

### MX-M9. 특수 구조·조합 + 행렬 상 (격자 도로망·반대칭·주기 재귀)
- **원리**: 격자 도로망 경로 수 = 행렬 곱 성분·반대칭 행렬 정수 성분 카운팅·조건부 재귀 수열 주기
- **심층 조건**:
  - 격자 경로 수: $R_1 \to S_2$ 경로 = $A^2$의 (1,2) 성분 (조합적 해석)
  - 반대칭 ($a_{ij} = -a_{ji}$) + 대각선 성분 = 0 + 정수해 개수 $x^2 + y^2 + z^2 = 9$
  - 조건부 재귀: $B_{2k} = A^{2k} B_{2k-1}$ (주기 8 도출)
  - 교대 합
- **자유도**: 도로망 해석·주기 계산 방법
- **앵커**: 고쟁이-CM1-CH10-STEP3-#880, #886, #894, #895
- **오답 유도**: 행렬 곱 성분 의미 오인·주기 길이 오산·정수해 부호 누락
