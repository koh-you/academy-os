# 도구 카테고리 (Tool Categories) — 단일 출처

**목적**: 시험지·유형편 정점 문항(★ 4·5)의 **수학 도구 다양성**을 정량 관리.
**정합**: `bank/schema.md` §2.17 (도구 축, 2026-07-11 신설) 정합.
**적용**: `book.yaml` / 청사진 `slots[].primary_tool` 필드 값 · `tool-diversity-check.mjs` 검증 대상.

---

## 원칙

- 각 슬롯은 하나의 **primary_tool** 만 선언 (부수 도구는 secondary_tools 배열, 검증 대상 아님).
- 시험지 1회분 정점 문항(★ ≥ 4)에서 같은 primary_tool 반복 **≤ 1**. 초과 시 tool-diversity-check RED.
- 정점 3~4문의 도구가 서로 다르면 학생 훈련 효과 · 채점자 변별력 모두 극대화.

---

## CM1 (공통수학1)

### CM1-PL (다항식)
- `PL-01` 다항식의 연산 (전개·정리)
- `PL-02` 인수분해 (공식·묶기·치환)
- `PL-03` 나머지정리·인수정리
- `PL-04` 항등식·미정계수법
- `PL-05` 세제곱·이항 공식 활용

### CM1-EQ (방정식과 부등식)
- `EQ-01` 복소수 연산·이차방정식 근
- `EQ-02` 판별식·근과 계수의 관계
- `EQ-03` 이차함수 그래프·접선
- `EQ-04` 고차방정식 인수분해·근
- `EQ-05` 연립방정식 (대입·소거·치환)
- `EQ-06` 여러 가지 부등식 (분수·절대값·이차)
- `EQ-07` 연립부등식·해의 조건

### CM1-CB (경우의 수)
- `CB-01` 순열 (일렬·조건)
- `CB-02` 조합 (선택·분할)
- `CB-03` 순열+조합 결합 (자리+선택)
- `CB-04` 여사건·배제 (CM1 밖 여사건 어구 금지, 자연어 서술 도구는 허용)

### CM1-MX (행렬)
- `MX-01` 행렬의 덧셈·뺄셈·상수배
- `MX-02` 행렬의 곱셈·거듭제곱
- `MX-03` 케일리해밀턴 정리 활용
- `MX-04` 연립일차방정식의 행렬 표현

## CM2 (공통수학2)

### CM2-GM (도형의 방정식)
- `GM-01` 두 점 사이 거리·내분·외분
- `GM-02` 직선의 방정식 (기울기·수직·평행)
- `GM-03` 원의 방정식·접선
- `GM-04` 두 원의 관계 (교점·접함·포함)
- `GM-05` 도형의 이동 (평행이동·대칭이동)
- `GM-06` 자취의 방정식
- `GM-07` 부등식의 영역 (학교마다 유무 상이)

### CM2-ST (집합과 명제)
- `ST-01` 집합의 표현·부분집합
- `ST-02` 집합의 연산 (∪, ∩, −, ^c)
- `ST-03` 집합의 원소 개수 (포함배제)
- `ST-04` 명제와 조건·진위 판정
- `ST-05` 필요조건·충분조건·필요충분조건
- `ST-06` 명제의 역·대우·귀류법
- `ST-07` 절대부등식 (산술·기하평균은 상위 과정, CM2에서 코시-슈바르츠 정도만)

### CM2-FN (함수)
- `FN-01` 함수의 정의·그래프
- `FN-02` 합성함수
- `FN-03` 역함수·그래프의 대칭성
- `FN-04` 절댓값 그래프

### CM2-RF (유리·무리함수)
- `RF-01` 유리식 계산·부분분수
- `RF-02` 유리함수 그래프 (점근선·평행이동)
- `RF-03` 무리식 계산·유리화
- `RF-04` 무리함수 그래프

## 사용 예시

### book.yaml
```yaml
slots:
  - number: 14
    star: 5
    unit: CM2-GM
    primary_tool: GM-06         # 자취의 방정식
    secondary_tools: [GM-03]    # 원의 방정식 (부수)
  - number: 15
    star: 5
    unit: CM2-ST
    primary_tool: ST-05         # 필요·충분조건
    secondary_tools: [ST-01, ST-04]
```

### tool-diversity-check 판정
- 정점 문항(★ ≥ 4)의 primary_tool 리스트 추출
- 같은 카테고리 (예: `GM-04`) 반복 ≥ 2 → RED
- 모두 서로 다름 → GREEN

## 확장 원칙

- **신규 도구 추가**: 도구 카테고리 신설 시 본 파일에 등재 후 schema.md §2.17 참조 유지
- **카테고리 세분화**: 학년/난도별 세분화 필요 시 하위 코드 (예: `GM-04a` 외접·`GM-04b` 교차) — 신중 검토
- **폐기**: 교육과정 개정 등으로 사용 안 하는 카테고리는 삭제선 표시 (~~카테고리명~~) + 폐기 사유
