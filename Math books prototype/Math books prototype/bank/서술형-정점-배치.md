## 0. 총론 — 서술형 5문의 정점 밀도 원칙

### 0.1 배경 (세션 36 마스터 확립)

와부고 CM2 1회 서술형 5문 (평균 comp 34.6, premium 4문) vs 2회 5문 (평균 30.4, premium 3문) 비교에서 **-5.4점 gap 발견**. 원인은 v5.1 지문형 편중과 자기복제 방지 정책 결합.

**마스터 원칙**: *"수학 시험지에서 수학만으로 난이도의 정점을 찍을 수 없다면 그건 잘못된거야."*

→ 서술형 정점은 **지문형 슬롯 개수에 종속되면 안 됨**. 순수 수학형 슬롯도 정점 comp 도달 가능한 배치 전략 필요.

### 0.2 서술형 5문 정점 밀도 목표 (v1.0)

**시험지 1회분 서술형 5문**:

| 지표 | 목표 | 판정 |
|---|---|---|
| 서술형 총 composite (v5.2) | ≥ 150 | 총합 관리 |
| 서술형 최소 composite | ≥ 24 (★ 5 진입) | 하한 관리 |
| 서술형 평균 composite | ≥ 30 | 평균 관리 |
| star_premium 서술형 | ≥ 3문 (comp ≥ 33) | 정점 개수 |
| 통찰 카드 ≥ 3 슬롯 | ≥ 3문 (v5.2 D=2+) | 통찰 밀도 |

  total_composite: 150

  premium_count: 3
  insight_card_ge3_count: 3

## 1. 배치 전략 (서술형 5문 조합)

### 1.1 조합 A — 지문형 우세형 (1회 유형)

**구성**: 지문형 3~4문 + 순수 수학형 1~2문
**예상 comp**: 지문형 각 32~43, 순수형 각 24~30
**총 comp**: ~170~200
**Narrative load**: 2.0~3.0점 (§지문형-심화-카탈로그 §6.4 v1.1)
**적합**: 마스터가 지문형 소재 여유 있을 때, 시리즈 시작 회차

**리스크**: 독해 부담 폭증, 소재 발굴 부담

### 1.2 조합 B — 균형형 (권장 기본)

**구성**: 지문형 2문 + 순수 수학형 3문 (모두 D=2+)
**예상 comp**: 지문형 각 33~42, 순수형 각 27~33 (v5.2 D 축)
**총 comp**: ~150~170
**Narrative load**: 1.4~2.0점
**적합**: 대부분 회차, 자기복제 방지·소재 다양화 균형

**핵심**: 순수 수학형 3문이 D=2~3 획득으로 정점 진입 가능하도록 설계

### 1.3 조합 C — 순수 수학형 우세형 (v5.2 신규 옵션)

**구성**: 지문형 1문 + 순수 수학형 4문 (다중 표현 전환 + 조건 분해)
**예상 comp**: 지문형 33~40, 순수형 각 28~34 (v5.2 T·F·D 활성)
**총 comp**: ~150
**Narrative load**: 0.7~1.0점
**적합**: 소재 발굴 부담 큰 시기 or 자기복제 방지 매트릭스 강제 시

**핵심**: 순수 수학형 4문 모두 v5.2 T=2~3, F=2, D=2~3 획득 설계 필수

### 1.4 조합 D — 극단 지문형 회피형 (2026-07-14 신설)

**구성**: 지문형 0문, 순수 수학형 5문 (모두 D=2+ or T=3 or R_total=4+)
**예상 comp**: 각 27~34
**총 comp**: ~145~160
**Narrative load**: 0점
**적합**: 지문형 소재 완전 소진, 반복 회차 (예: 5회차 이상 시리즈), 학교 시험지 스타일 (실기출 대부분 순수형)

**리스크**: 서술형이 계산 서술로 흐르면 D=0~1 감소. 각 슬롯이 D·T·F·R 조합으로 정점 도달 설계 세심 필요.

## 2. 순수 수학형 정점 도달 프로토콜 (v5.2 기반)

### 2.1 T=2 획득 조건 (표현 전환 통찰)

순수 수학형 슬롯에서 T=2 도달하려면 다음 중 하나 이상:

1. **대수 ↔ 기하 전환**: 방정식 → 자취·거리·넓이·위치관계
2. **집합 ↔ 논리 전환**: 진리집합 → 명제·필충·역대우
3. **부등식 ↔ 영역 전환**: 부등식 조건 → 좌표평면 영역
4. **조합 ↔ 카운트 전환**: 부분집합 조건 → 원소 개수 계산
5. **함수 ↔ 그래프 전환**: 함수 표현 → 그래프 성질

**예시**: 2회 #14 부분집합 X 조건 → 조건 (가)(나)(다)를 원소 카운트 문제로 전환. T=2 획득.

### 2.2 T=3 획득 조건 (multi-representation chain)

3+ 표현 chain 형성:

1. **자취 → 위치관계 → 명제**: 자취 유도 → 원과 자취의 위치관계 → 명제 진리값 판정
2. **집합 → 카운트 → 조합 최적화**: 조건 만족 부분집합 → 개수 → 최대·최소 원소 합
3. **방정식 → 자취 → 영역 부등식**: 매개변수 소거 → 자취 방정식 → 자취 영역 부등식

**예시**: 2회 #15 자취·거리 최댓값 → 원 위 점 P → 자취 유도 → 두 원 사이 거리 관계. 3단 chain. T=3 획득.

### 2.3 F=2 획득 조건 (수학 정의 정확성)

다음 중 하나 이상 명시:
1. **필요충분 관계** 명확 서술 (양방향 화살표·"⟺")
2. **경계 처리** 명시 ($\le$ vs $<$·열림·닫힘)
3. **존재성** 논증 (해가 있음을 보이는 조건)
4. **유일성** 논증 (판별식·대칭 이용)
5. **동등성** 명시 (동치 조건 여러 개)

**예시**: 2회 #17 팬터그래프 (3) 자취 영역 포함 → $k \le 10/3$ 경계 명시. F=2 획득.

### 2.4 D=2 획득 조건 (조건 다층 결합)

- 조건 3+ 개 발문에 나열
- 각 조건이 여러 소문항 (1)(2)(3)에서 재사용
- 소문항 간 참조 표기 명시 ("(1)의 결과를 이용하여")

**예시**: 2회 #14 조건 (가)(나)(다) → (1)에서 (가)(나) 분석, (2)에서 (가)(나)(다) 결합. D=2 획득.

### 2.5 D=3 획득 조건 (상호 참조 그래프)

- 조건 분해 → 재결합 → 상호 참조 형성
- 소문항 (1)↔(2)↔(3) 상호 종속 (역방향 참조 포함)
- 조건 각각이 최소 2번 이상 소문항에서 사용

**예시** (설계 목표): #17 팬터그래프 (1) 대응 규칙 → (2) 자취 → (3) 자취 영역 포함. 각 조건이 다음 소문항에서 재사용 + 역방향 참조.
