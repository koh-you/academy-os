# bank-query 활용 가이드

> 본 가이드는 `scripts/bank-query.mjs` 활용 사례 모음. 마스터의 일상 검색·필터링 패턴을 정리.

---

## 1. 기본 사용법

```bash
node scripts/bank-query.mjs --help                  # 전체 옵션
node scripts/bank-query.mjs --unit CM2-RF --star 4  # CM2-RF 단원 ★ 4 문항
```

옵션:
- `--unit <CM1-PL | CM2-RF ...>` — 단원 필터
- `--type <T-code>` — T-code 필터 (예: T19, EQ-T23)
- `--star <1-5>` — 상대 ★
- `--freq <1-3>` — frequency (1=희귀, 2=빈출, 3=필수)
- `--rate-min <0.0-1.0>` — 정답률 최소
- `--rate-max <0.0-1.0>` — 정답률 최대
- `--status <meta_only | draft | approved>` — 상태
- `--source <DI | OUT>` — 출처 prefix
- `--cohort <파일명>` — cohort_unit
- `--csv <output.csv>` — CSV 저장
- `--limit <N>` — 결과 최대

## 2. 자주 쓰는 검색 패턴

### 2.1 출제 슬롯 후보 검색

#### 필수 패턴 (frequency=3) 위주
```bash
# CM1-EQ 단원의 ★ 4 필수 패턴
node scripts/bank-query.mjs --unit CM1-EQ --star 4 --freq 3 --limit 20
```
- **활용**: 우리 책의 ★ 4 슬롯에 출제할 핵심 빈출 패턴 찾기

#### 변별력 있는 문항 (정답률 50% 부근)
```bash
# 정답률 40~60% 사이 CM2-GM ★ 4 (학평 평균 변별 구간)
node scripts/bank-query.mjs --unit CM2-GM --star 4 --rate-min 0.4 --rate-max 0.6 --limit 30
```
- **활용**: 학평에서 학생 절반이 풀고 절반이 못 푼 변별력 있는 문항

#### 최고난도 풀
```bash
# CM2-RF ★ 5 (정답률 20% 이하)
node scripts/bank-query.mjs --unit CM2-RF --star 5 --rate-max 0.2 --limit 15
```
- **활용**: ★ 5 슬롯 = "1등급 도전" 문제

### 2.2 단원·유형별 풀 확인

#### 특정 T-code 풀 전수
```bash
# CM2-GM의 T19 (두 점 사이의 거리) 모두
node scripts/bank-query.mjs --unit CM2-GM --type T19 --limit 50
```

#### 출처별 확인
```bash
# 마스터 책(OUT-*)만
node scripts/bank-query.mjs --unit CM2-RF --source OUT --status approved

# 깊이와통찰 학평(DI-*)만
node scripts/bank-query.mjs --unit CM2-GM --source DI --star 5 --limit 20
```

### 2.3 CSV export (Excel·Google Sheets 활용)

```bash
# CM2-RF 단원의 모든 ★ 별 후보를 CSV로
node scripts/bank-query.mjs --unit CM2-RF --csv data/cm2-rf-all.csv --limit 200

# 필수 패턴(★ 4·★ 5) CSV
node scripts/bank-query.mjs --star 4 --freq 3 --csv data/star4-essential.csv --limit 200
```
- CSV 컬럼: `id, unit, type, star, rate, freq, status, typeName`

### 2.4 cohort별 검색 (깊이와통찰 시기별)

```bash
# 메인 cohort (2024.10~2026.06 학평)
node scripts/bank-query.mjs --cohort "260614_수능&모의 공통.pdf" --star 4 --limit 30

# 2007 이전 cohort (옛 교육과정 — 참고용)
node scripts/bank-query.mjs --cohort "260614_수능&모의 공통(13).pdf" --limit 20
```

## 3. 실전 시나리오

### 시나리오 A — 신규 책 슬롯 후보 일괄 추출

```bash
# 1) 마스터 책 yaml에 맞춘 자동 추천
node scripts/recommend-slots-by-book.mjs output/공통수학1/새책.book.yaml

# 2) 추가로 본인이 검색 필터링
node scripts/bank-query.mjs --unit CM1-EQ --star 3 --freq 3 --rate-min 0.5 --rate-max 0.8 --csv data/cm1-eq-star3.csv
```

### 시나리오 B — 출제 검증 (앵커 비교)

```bash
# 신규 출제한 문제 → 같은 단원·★ 앵커 5문과 비교
node scripts/anchor-compare.mjs --file bank/problems/OUT-새책-001.md

# 또는 가상 점수로 ★ 예측
node scripts/anchor-compare.mjs --unit CM1-EQ --star 4 --scores '{"C":2,"S":3,"D":3,"K":1,"A":2,"T":2}'
```

### 시나리오 C — 단원 보충 우선순위 확인

```bash
# CM1-MX (행렬, 학평 비중 0.5%) 풀 전수 확인
node scripts/bank-query.mjs --unit CM1-MX --limit 30

# CM1-CB (경우의 수, 학평 비중 0.6%) ★ 별
node scripts/bank-query.mjs --unit CM1-CB --star 4 --limit 30
node scripts/bank-query.mjs --unit CM1-CB --star 5 --limit 30
```

## 5. 자동화 도구와의 연결

| 검색 결과 활용 | 다음 단계 |
|---|---|
| `--csv`로 export | Excel·Google Sheets에서 추가 필터링 |
| 슬롯 후보 ID 확보 | `book.yaml`의 `slots[].problem_id`에 등록 |
| `--unit + --star`로 단원 풀 파악 | `recommend-slots-by-book.mjs`로 자동 추천 |
| 신규 출제 → `anchor-compare.mjs` | 앵커 5문 비교 → ★ 검증 |
