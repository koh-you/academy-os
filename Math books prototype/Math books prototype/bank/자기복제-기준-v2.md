# 자기복제 cross-round 판정 기준 v2.0 (2026-06-27)

> **마스터 명시 (2026-06-27, 미니모의고사 1·2회차 비교 정교화 제안 7)**: "통찰 카드 ≥ 2 일치"만으로는 자기복제 판정 과민. 본질이 다르면 카드 일치는 자연. 본 v2.0 기준으로 *본질 일치 우선* 판정.

## 0. v1.0 vs v2.0

v1.0 기준 (2026-06-25): 직전 회차와 *통찰 카드 ≥ 2 일치* → RED (cross-round-insight-check.mjs).

**문제점**: 핵심 카드 (I-CON·I-EQV·I-MI)는 *전체 슬롯의 80% 이상에 활성*되어 카드 일치가 *통계적 우연*. 본질이 매우 다른 두 슬롯도 일상적으로 ≥ 2 카드 일치.

**v2.0 갱신 (2026-06-27)**: *본질 시그니처*를 도입하여 *진정한 자기복제*만 판정.

## 1. 자기복제 판정의 3축 (v2.0)

| 축 | 기준 | 검출 도구 |
|---|---|---|
| 1. **시그니처 일치** | 입력·결과·자유도 3원조 모두 일치 | `scripts/signature-check.mjs` |
| 2. **본질 카드 일치** | *주 통찰 카드* (보조 X) ≥ 3 일치 | `scripts/cross-round-insight-check.mjs` |
| 3. **명명·자유도 패턴 일치** | 변수 명명 단계·자유도 분기 패턴 일치 | (수동 점검 또는 LLM 검수) |

### 1.1 RED 판정 (즉시 차단)

**3축 모두 일치 + 본질 다름 입증 부재** → 자기복제 RED.

### 1.2 YELLOW 판정 (검토 권장)

- 축 1만 일치 + 본질 카드 ≤ 2 일치 → 본질 검토 후 OK 가능
- 축 2만 일치 + 시그니처 다름 → 본질 카드는 자연 일치 → OK
- 축 3만 일치 + 다른 축 미일치 → 검토 후 OK 가능

### 1.3 GREEN 판정 (자동 통과)

3축 중 ≥ 2축 미일치 → 자기복제 X.

## 1.5 🔴 자기복제 vs 반복학습 — 구분 기준 (2026-07-30 세션 105 마스터 확립)

### 정의

> **자기복제**: **발문까지 완벽히 같아서** 학생이 *"이거 똑같은 문제네"* 라고 **인식하는** 상황.
> **반복학습**: 같은 유형·시그니처가 다시 나오지만 학생이 **새로 풀어야** 하는 상황.

**시험지 회차를 늘려 나가면 같은 유형의 반복은 필연이다. 그때마다 자기복제로 결함 판정을 낼 수는 없다.** 판정의 기준점은 **"학생 체감"** 이며, 유형·시그니처 재사용 자체는 결함이 아니다.

### 판정 = 학생이 보는 것만 센다

| 층위 | 자기복제 판정에 | 이유 |
|---|:-:|---|
| **발문 문장 구조·종결어** | ✅ 포함 | 학생이 첫 30초에 읽는 것 |
| **소재·상황 설정** | ✅ 포함 | "그 문제"로 기억되는 단위 |
| **숫자·계수만 다름** | ✅ **즉시 RED** | 치환은 재출제가 아니다 |
| **보기 3칸의 역할 배치** (보기형) | ✅ 포함 | 학생이 훑는 구조 |
| **선택지 구성 방식** | 🟡 참고 | 관례 범위면 제외 |
| **풀이 mechanism** | ✅ 포함 (역방향) | **다르면 반복학습 쪽으로 강하게 이동** |
| **시그니처(S1~S13)** | ❌ 제외 | 페르소나가 **의무화**한 축이다. 재사용이 설계 |
| **통찰 유형 라벨** | ❌ 제외 | 단원이 좁으면 자연 일치 |
| **점 이름 (P·Q·O·A·B)** | ❌ 제외 | 관용 표기 |
| **기준 도형 ($y=x$·원점·좌표축)** | ❌ 제외 | 단원 기본 도구. 회피하면 교과를 벗어난다 |
| **시그니처 표준 어구** | ❌ 제외 | 예: S2 불변량을 보기형으로 물으면 "값에 관계없이 항상 … 위에 있다"는 거의 필연 |

🔴 **핵심**: mechanism이 교체됐다면 표층 일치 몇 건으로 자기복제 판정을 내리지 마라. 반대로 **mechanism이 같으면 표층을 아무리 바꿔도 자기복제다.**

### 회차 거리 가중 (근접 회차일수록 체감이 크다)

같은 발문을 **연속·근접 회차에서 접했을 때 체감이 훨씬 크다.** 동일 유사도라도 거리에 따라 판정을 달리한다.

| 회차 거리 | 가중 | 판정 |
|---|---|---|
| **직전 회차** (N-1) · **같은 슬롯 번호** | ×2.0 | 표층 2축 일치만으로도 RED 검토 |
| 근접 (N-2 ~ N-3) | ×1.5 | 표층 3축 일치 시 YELLOW |
| 원거리 (N-4 이상) | ×1.0 | 기존 3축 기준 그대로 |
| 다른 계보 (예상 ↔ 재현) | ×1.2 | 대상 학생이 같으면 거리 무관하게 체감됨 |

**같은 슬롯 번호**는 독립 가중 요소다. 학생이 두 시험지를 나란히 놓으면 같은 자리의 문항을 먼저 견준다.

### 반복학습으로 허용되는 형태 (결함 아님)

1. **같은 시그니처 · 다른 mechanism** — 예: S1(정수 개수)을 원의 조건 / 두 원 위치관계 / 부등식 정수해로 각각 구현
2. **같은 단원 도구 · 다른 종료점** — 예: AM-GM 을 넓이 최솟값 / 절편 곱 / 거리 곱으로 종료
3. **같은 통찰 유형 · 다른 진입** — I-CON 재사용은 CM2 범위에서 불가피
4. **관용 표기·기본 도형 공유** — 점 이름, $y=x$, 원점, 조건박스 형식

### 판정 절차

1. `cross-round-insight-check` · `structure-signature-check` · 4-gram 유사도로 **후보 추림**
2. 🔴 **수치를 판정으로 쓰지 마라** — 아래 §1.6 참조
3. 후보에 대해 **학생 체감 층위만** 대조 (위 표의 ✅ 항목)
4. **mechanism 동일 여부**를 최종 판정축으로 삼는다
5. 회차 거리·슬롯 번호 가중 적용

## 1.55 대조 예시 — 같은 회차 안에서 판정이 갈린 두 슬롯 (세션 105 실측)

기준만 있고 예시가 없으면 다음 회차가 또 갈린다. **#11(반복학습) ↔ #3(자기복제)** 를 나란히 둔다.

### ✅ 반복학습 — 재현-1회 #11 vs 예상 1회 #11

| 축 | 예상 1회 #11 | 재현 #11 | |
|---|---|---|---|
| 발문 | 삼각형 APQ의 **둘레가 최소**일 때 무게중심 G | 선분 AB의 **1:3 내분점** P → $y=x$ 대칭 → Q | 🟢 다름 |
| mechanism | **이중 반사** → 최단경로 → 무게중심 자취 | 내분점 좌표 → 대칭 → **문자 소거** → 공선 퇴화 | 🟢 **완전 교체** |
| 점 이름 P·Q·O | 동일 | 동일 | ❌ 제외 (관용) |
| 직선 $y=x$ | 동일 | 동일 | ❌ 제외 (S3 기본 축) |
| "관계없이 항상 … 직선 위에" | 있음 | 있음 | ❌ 제외 (S2 보기형 표준 어구 — 204슬롯 중 4건뿐인 건 S2 보기형이 드물어서다) |
| 선택지 5종 배열 | 동일 | 동일 | 🟡 관례 |

→ **표층 일치분이 전부 시그니처·관례 필연**이고 mechanism이 교체됨. **반복학습. 현상 유지.**
(4-gram 17.4% / draft 측정 6.0% — 어느 쪽도 판정 근거가 아니다)

### 🔴 자기복제 — 재현-1회 #3 vs 예상 1·8·10·11·12회

| 축 | 예상 회차 (5개) | 재현 #3 | |
|---|---|---|---|
| 발문 구조 | "전체집합 $U$의 … 부분집합 … [집합식] **와 항상 같은 집합은?**" | **동일** | 🔴 |
| 종결 어구 | 5회차 공유 | 동일 | 🔴 각인 단위 |
| 선택지 | 집합식 5개 | 동일 | 🔴 |
| 소재 | 추상 집합 | 동일 | 🔴 |
| mechanism | 대수 간소화 (드모르간·분배·차집합 변환) | **동일 + 마지막 한 단계**($(A\cap B)\subset C$ 적용) | 🟡 **주 도구 공유** |
| 회차 분포 | **12회차 중 5회차** · 10·11·12회 **3연속** | — | ×1.5 |

→ **mechanism 주 도구가 같은데 표층을 바꾸지도 않았다. 자기복제. 재출제 대상.**
→ 반복학습 허용 형태 4종에 모두 미해당 ("같은 시그니처·다른 mechanism" ✗ · "같은 도구·다른 종료점" ✗)

### 판정 요약

> **mechanism 교체 + 표층 일치가 관례·시그니처 필연 → 반복학습**
> **mechanism 주 도구 공유 + 표층 전면 일치 → 자기복제**

## 1.6 🔴 4-gram 유사도의 한계 — 수치를 판정으로 쓰지 마라

**실측 사례 (세션 104~105)**:

| 사례 | 4-gram | 실제 |
|---|---:|---|
| 구 #10 vs 예상 1회 #10 | **11.1%** | mechanism **사실상 동일** (S4 제거판) — 교체 판정은 의미 판정으로만 가능했다 |
| 신 #4 vs 예상 2회 #4 | 14.8% → **17.9%** (재출제로 **상승**) | 실제로는 5축 중 4축 교체. 상승분은 S10·S11 관용구("~는 ~이기 위한 ~조건이다"×3)가 만드는 **지표 하한** |
| #3 vs 10회 Q5 | **40.7%** (전 슬롯 1위) | 프레임 포화 — 이 경우는 지표가 실체와 일치 |

**결론**:
- 유사도는 **후보 추림용**이다. **판정은 의미 층위에서** 한다
- **정규화 정의가 다르면 절대값이 2~3배 달라진다.** 회차 내 상대 순위만 신뢰하라
- 조건을 라틴 문자로 압축한 발문은 구조 정규화에서 본문이 사라져 **낮게 나온다** (역설적으로 압축이 지표를 낮춘다)
- 🔴 **높은 수치 = 자기복제도 아니고, 낮은 수치 = 안전도 아니다**

## 1.7 🔴🔴 검사 풀이 둘이다 — 우리 회차 / 실기출 (2026-07-30 세션 105 신설)

### 왜 신설하는가 — 배선 누락으로 복제를 놓쳤다

§1.1~§1.6 은 전부 **우리 회차끼리**의 비교다. **실기출과의 복제는 검사 축에 아예 없었다.** 그 결과:

> SIMULATOR [와부] NO.1 의 **#16 · #17** 이 와부고 2025 실기출 #16 · #17 의 **실질 복제**로 제작되었고,
> 충실도 루브릭 **18/18 만점**을 받고 통과했다. 17문 중 15문이 실기출 특정 문항과 대응했다.
> 상세: `bank/와부고-실기출-대조-분석-v1.md` · [[feedback_fidelity_rubric_rewards_copying]]

규칙(§1.5 학생 체감 기준)은 **이미 실재했다.** 실기출을 향해 겨눠져 있지 않았을 뿐이다 — [[feedback_ssot_routing_gap]] 의 전형이다.

### 두 풀은 규칙이 정반대다

| | 검사 풀 A — **우리 회차끼리** | 검사 풀 B — **실기출 대비** |
|---|---|---|
| 학생의 처지 | 우리 교재 여러 회차를 **모두 푼다** | 실기출을 이미 봤을 수 있다 |
| 유형·시그니처 반복 | 허용 (§1.5 반복학습) | ✅ **권장** — 대비의 목적 그 자체 |
| **mechanism 반복** | 🔴 자기복제 (§1.5 L62) | ✅ **허용** — 해법 훈련이 곧 대비다 |
| 금지되는 것 | mechanism 동일 · 발문 구조 동일 | **실질 복제 4축** (아래) |

🔴 **같은 단어 「동형」이 두 풀에서 다른 뜻이다.** 풀 A 에서 mechanism 반복은 결함이고, 풀 B 에서는 권장이다. 혼동하면 대비 교재를 만들 수 없다.

### 판별 기준 = 효용 (마스터 확정)

> **시험지의 목적은 학교 시험 대비이고, 대비란 같은 유형에 익숙해지는 것이다.**
> 따라서 판단 기준은 **"학생이 이 문항을 풀어 얻은 것이 시험장에서 재사용되는가"** 다.

| | 학생이 얻는 것 | 시험장 재사용 | 판정 |
|---|---|:-:|---|
| **재사용 가능한 지식** — 수학 도구·해법 절차 (외심·공통외접선·자취 결정·원의 방정식) | 도구가 훈련된다 | ✅ | **권장** |
| **그 문항 고유물** — 장치·서사·기호 조합·발문 문장 | 그 문항의 답·수치 기억 | ❌ 그 문제는 다시 안 나온다 | 🔴 **금지** |

🔴 **저작권 경계도 같은 선에서 갈린다** — 유형·해법은 보호 대상이 아니고, 발문·기호·서사의 실질 복제만 위험하다. 교육 효용과 법적 위험이 같은 선을 가리키는 것은 그 선이 옳다는 신호다.

### 실질 복제 4축 (풀 B 판정)

실기출과 다음이 겹치면 실질 복제다. **판정은 학생 체감** — *"이건 **그 문제**다"* vs *"이건 **그 유형**이다"*.

| # | 축 | 실패 실례 (재현-1회) |
|:-:|---|---|
| 1 | **소재·서사** | 사도기(寫圖器) → 「축소 제도기」는 번역어 수준 차이 · 개기월식 → 탐조등은 둘 다 「광원-차폐물-그림자」 |
| 2 | **기호·점 이름 조합** | 삼각형 **`APB`·`BRC`** 가 문자 단위로 동일 · `C_2`·`C_2'`·`l_1` |
| 3 | **소문항 발문 문장** | 「두 원 $C_1$, $C_2$ 의 방정식을 각각 구하시오」 **완전 동일** |
| 4 | **특징적 용어·정의 박스** | 「본그림자」 · 공통접선 정의 박스 배치 |

**합격 조건**: 4축 중 **2개 이상 겹치면 🔴 실질 복제 → 재출제.** 1개만 겹치고 그것이 보편 표기(점 이름 `A`·`B` 등)라면 🟡 허용.

### 🔴 장치는 유형이 아니다 (팬터그래프 실례)

「같은 간격 구멍 4개 × 막대 4개 + 한 직선 위 세 점 + 평행 두 쌍 + $1:2$ 축소」는 **팬터그래프의 정의 그 자체**다. 소재 명칭·기호·문장을 바꿔도 학생은 *"그 장치 문제"* 로 인식한다.

- ❌ **불가**: 수학 구성을 유지하고 포장만 바꾸는 것 — 장치가 곧 mechanism 이자 소재이므로 4축 중 2개(소재·mechanism)가 동시에 겹친다
- ✅ **가능**: 수학 도구를 교체 (세션 105 조치 — 팬터그래프 → **외심·외접원**)

판별 물음: **「이것은 학생이 다른 문제에도 쓸 수 있는 도구인가, 이 문항에만 있는 장치인가?」**

### ⚠️ §1.55 전제 정정 — 예상 12회차는 학생 실전용이 아니다

§1.55 의 대조 예시는 `2026-2학기-와부고-예상-중간-1~12회` 를 비교 풀로 썼다. 그런데 마스터 확인(세션 105):

> 기존 12회차는 완성도가 낮은 시스템으로 **시스템 구축 도중 연습용으로 만들어 본 회차**다. **학생 실전용이 아니고 내부 테스트용**이다.

따라서 그 12회차에 대해서는 **「학생 체감」 전제가 성립하지 않는다** — 학생이 본 적이 없으므로 자기복제 판정의 근거가 될 수 없다. §1.55 의 판정은 **기준 확립을 위한 예시로만** 읽고, 그 결과를 결함 이력으로 쓰지 마라. 정확한 지침을 세우는 일 자체는 여전히 중요하다.

### 도구 상태

- 4-gram Jaccard(`cross-round-*-check`)는 **우리 회차끼리만** 돈다. 풀 B 는 **사람이 4축으로** 판정한다 (§1.6 — mechanism 복제를 지표가 못 잡는다)
- 대조는 **반드시 원본 PDF 1차 소스**로 한다. 파생 요약본으로는 발문 문장 일치를 볼 수 없다

## 2. 본질 카드 vs 보조 카드 분리

각 슬롯의 통찰 카드를 *주 통찰* 1~2개와 *보조 통찰* 1~3개로 분리.

| 분류 | 정의 | 자기복제 판정 시 |
|---|---|---|
| **주 통찰** | 핵심 변별 도구 (해결의 *결정적 단계*) | RED 판정에 포함 |
| **보조 통찰** | 부수적 통찰 (자연 동반 카드) | RED 판정에서 제외 |

**주 통찰 식별 기준**:
- 슬롯의 *최대 깊이* depth=3 활성 카드는 주 통찰
- 풀이의 *결정적 환원*에 사용된 카드는 주 통찰
- 다른 카드는 보조

## 3. 본 시스템 사례 적용

### 사례 A: 1회차 #7 vs 2회차 v2 #7

- 1회차 #7 카드: {EQV, XU, CON, VF, PD, RT}
- 2회차 v2 #7 카드: {EQV, CON, RT, VF, MI, BW, PD}

**v2.0 판정**:

- 주 통찰 (2회차 v2 #7): {EQV (완전제곱식 환원), MI (해 분기), BW (역방향)}
- 공통 주 통찰: ∅ — **GREEN** ✓

### 사례 B: 2회차 v3 #3 vs #8 (회차 내)

- #3 카드: {EQV, PD, CON}
- #8 카드: {EQV, PD, XU, CON, VF, MI}
- 공통: {EQV, PD, CON} = 3개

**v2.0 판정**:
- 시그니처: 둘 다 *연립방정식 + 합·곱 + 양정수 자유도* — 시그니처 일치 (RED)
- 본질: 동일 패턴의 단순 vs 복합 버전 (★ 3 vs ★ 5) — *시그니처 일치*가 본질 다름보다 우선
- **v2.0 판정**: RED (시그니처 일치)

→ signature-check.mjs가 검출한 결과와 일치.

## 4. 운영 규약

### 4.1 출제 시

- 신규 슬롯 작성 시 *주 통찰*과 *보조 통찰* 분리 명시 (청사진 YAML)
- 직전 회차 슬롯과 *주 통찰* 공통 ≥ 3개면 본질 검토 의무
- 본질 다름이 *명확*하면 청사진에 `essence_diff: true` + 본질 차이 설명 1줄

### 4.2 검수 시

- `scripts/signature-check.mjs` RED 시 *즉시 차단* (재출제)
- `scripts/cross-round-insight-check.mjs` v1.0 RED 시 *본질 카드 분리 재검토*
  - 주 통찰 공통 ≥ 3개 + 시그니처 일치 → RED 확정
  - 주 통찰 공통 ≤ 2개 → YELLOW 격하 후 진행 가능
- problem-review 에이전트 자기복제 점검 항목 갱신

### 4.3 도구 갱신 예정

- `scripts/cross-round-insight-check.mjs` v2.0 (예정): 본 v2.0 기준 적용
  - 입력: 본문.tex + 직전 회차.tex + 청사진.yaml (주 통찰 명시)
  - 판정: 3축 모두 일치 시 RED, 그 외 YELLOW/GREEN
- 본 응답 시점: 정책 정립만. 도구는 신규 회차 작성 시 동시 출시
