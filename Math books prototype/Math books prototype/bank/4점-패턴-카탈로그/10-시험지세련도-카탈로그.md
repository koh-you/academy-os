## 0. v0.1 카테고리 분류 (2026-06-22 외부 학교 표본 보강 결과)

기존 14 패턴 + C 카테고리 2 신규 = **총 16 패턴**. 적용성 기준 분류.

### 카테고리 A — 외부 학교·우리 책 보편 (6 패턴, 시판 검증)
시판/외부 학교/우리 책 시험지 모두 적용. 시험지의 *기초 정합* 의무.

- **E1.1 총 100점 정확** (의무) — 외부 학교 표본도 100점 표준
- **E1.4 \pointbadge 명시** — 외부 학교는 "[N점]" 또는 직접 점수 표기. 형식만 다름
- **E2.2 단원 골고루** — 외부 학교도 시험범위 골고루 출제
- **E2.3 발문 워딩 다양** — 외부 학교도 자동 적용
- **E3.2 ★ 곡선 (ease-in → 변별)** — 외부 학교도 첫 ★ 1~2, 마지막 ★ 5 변별 (2024 동화고 #1·#2 ★ 2 → #14·#15 ★ 5)
- **E4.4 답지 정합** — 모든 시험지 표준

### 카테고리 B — 우리 책 양식 정책 (8 패턴, 마스터 정책으로 효력)
외부 학교 양식과 다르나 *우리 책 디자인 정책*으로 효력. 외부 학교 시험지에서는 *해당 없음*.

- **E1.2 5단 배점 매핑 (★ × 형식 → 2.5~5.5)** — 외부 학교는 3·3.3·3.7·3.8 등 *세분화* 사용. 우리 책 5단 매핑은 [[feedback-exam-paper-workflow]] 정책
- **E1.3 ★ 분포 균형 (★ 1·2: 8~10 / ★ 3: 8~10 / ★ 4: 5~7 / ★ 5: 2~3)** — 외부 학교는 학교마다 다름. 우리 책 audience 기반 정책
- **E2.1 회차 간 패턴 중복 회피** — 우리 책 동화고 시리즈 1·2회차 정책. 외부 학교는 매년 시행이라 *해당 없음*
- **E3.1 객관식 + 통합 서답 2구간** (v0.2, 2026-06-27) — 외부 학교는 2구간 (선택·논술) 분리. 우리 책 v0.2는 객관식 + 통합 서답 2구간 (단답·논술 헤더 분리 폐지). 통합 서답은 \examsection 없이 객관식 직후 이어붙임
- **E3.3 구간별 ★ 범위 정합** — 우리 책 2구간 기반 (객관 ★ 1~5 / 통합 서답 ★ 3~5)
- **E4.1 시험지 매크로 일관** — 우리 책 LaTeX 매크로 정책
- **E4.2 보호 영역 변동 0** — 우리 책 디자인 정책
- **E4.3 시험범위 명시** — [[feedback-exam-scope-required]] 우리 책 정책 (외부 학교도 시험범위 명시하지만 양식 다름)

### 카테고리 C — 외부 학교 양식 옵션 (2 패턴 신규, 우리 책 채택 검토)
외부 학교 시험지의 *추가 양식 옵션*. 우리 책 채택 시 *교육·신뢰도* 향상 기대.

- **E5.1 평가담당 도장란** — 외부 학교 표본 (2024 동화고): 상단 우측에 "평가담당 / 부장 / 교감 / 교장" 도장 칸. 학교 시험지 *공식성* 강화. **우리 책 미채택 권장** (우리 책은 학원·교재이지 학교 공식 시험지가 아님)
- **E5.2 논술형 안내문** — 외부 학교 표본 (2024 동화고 논술형): "다음은 논술형 문항(논술형1~논술형4)입니다. 풀이나 설명 없이 답만 쓰는 경우는 정답으로 인정하지 않습니다." 논술형 시작에 *안내문 표시*. **우리 책 채택 검토 권장** — 학생이 논술형 답안 형식을 명확히 인지

## 1. 4축 정의

### 축 E1 — 총점·배점 정합 (Score Integrity)
**100점 정확** + 5단 배점 매핑 + ★ 분포 균형. 시험지의 *기초 정합* 의무 ([[feedback-100-point-policy]]). **4 패턴**.

### 축 E2 — 회차 간·내 다양성 (Pattern Diversity)
회차 간·내 패턴 중복 회피 + 단원 골고루 + 발문 워딩 다양. *학생이 같은 풀이 반복하지 않게*. **3 패턴**.

### 축 E3 — 구간 구조 (Section Structure)
객관식 + 통합 서답 2구간 (v0.2, 11회차부터) + ★ 곡선 (ease-in → 변별) + 구간별 정합. *시험지의 흐름*. **3 패턴**.

### 축 E4 — 디자인 정합 (Design Integrity)
시험지 매크로 일관 + 보호 영역 변동 0 + 시험범위 명시 + 답지 정합. *시험지의 디자인 정체성*. **4 패턴**.

## 2. 축 E1 — 총점·배점 정합 (4 패턴)

### E1.1 총 100점 정확
- **정의**: 시험지 전체 배점 합 = 100점 정확. 0.5점 단위 미세 조정 허용
- **표본**: 1회차-문제.tex examheader "25문항 · 100점" + 객관식 구간 60.5점 + 단답·논술 39.5점 = 100점
- **위반 신호**: 합산이 95~99 또는 101~105점 (정확 100점 아님). examheader와 실제 합 불일치
- **보강 절차**: 점수 변동 시 상향·하향 페어링으로 총합 유지 ([[feedback-100-point-policy]])
- **유형편·연습편은 적용 외**: 점수 개념 없음 (도트 `\dota`·`\dotb`·`\dotc`)

### E1.2 5단 배점 매핑 (★ × 형식 → 점수)
- **정의**: [[feedback-exam-paper-workflow]] 5단 매핑 표 준수
- **매핑 표 (v0.2, 11회차부터 적용 — 단답·논술 통합)**:
  | ★ × 형식 | 배점 |
  |---|---|
  | ★ 1 객관 | 2.5점 |
  | ★ 2 객관 | 3점 |
  | ★ 3 객관 | 3.5~4점 |
  | ★ 3 서답 (통합) | 4점 |
  | ★ 4 객관 | 4~4.5점 |
  | ★ 4 서답 (통합) | 4.5~5점 |
  | ★ 5 객관 | 5점 |
  | ★ 5 서답 (통합) | 5.5~7점 (v3.4 상대 배점: 6·6.5·6.7·7점 신설) |
- **참고 (~10회차 옛 정책)**: 3구간 매핑 (★ 4 단답 4.5 / ★ 4 논술 5 / ★ 5 단답 5 / ★ 5 논술 5.5). 10회차는 옛 정책 산출물로 보존
- **표본**: 1회차 #1 ★ 3 객관 = 3점 / #6 ★ 5 객관 = 5점 / #5 ★ 4 객관 = 3.5점 (옛 정책 표본)
- **위반 신호 (v0.2)**: 통합 서답 슬롯에 ★ 1·2 배점 / ★ 3에 5점 / ★ 1에 4점 등 명백한 매핑 어긋남

### E1.3 ★ 분포 균형
- **정의**: 시험지 25문 ★ 분포가 시험지의 audience (book.yaml)와 정합. 일반 시험지 권장 분포:
  - ★ 1·2: 8~10문 (기본)
  - ★ 3: 8~10문 (표준)
  - ★ 4: 5~7문 (변별)
  - ★ 5: 2~3문 (최상위 변별)
- **표본**: 1회차 25문 ★ 분포 (시험지 자체 검수에서 확인)
- **위반 신호**: ★ 1·2가 ≤ 5문 (어려움 과대) 또는 ★ 5가 ≥ 5문 (변별 과다)
- **분포 정합**: book.yaml의 `audience` 디폴트 분포 ±5%p 이내

### E1.4 \pointbadge{N} 모든 문제 명시
- **정의**: 모든 문제에 `\pointbadge{N}` 매크로로 배점 표시. 학생이 *시간 분배* 가능
- **표본**: 1회차 문제 1~25 전수 \pointbadge 명시
- **위반 신호**: 일부 문제 \pointbadge 누락

## 3. 축 E2 — 회차 간·내 다양성 (3 패턴)

### E2.1 회차 간 패턴 중복 회피
- **정의**: 같은 시즌(예: 동화고 기말 1·2·3회차) 내 *같은 통찰 패턴* 중복 회피. 학생이 *회차 풀면 다음 회차도 같은 풀이* 시 변별력 ↓
- **표본**: 동화고 1·2회차 — 1회차 #1 (연립부등식 해 비교), 2회차는 다른 통찰
- **위반 신호**: 1회차·2회차 모두 *행렬 주기 1.9* 동일 패턴 사용
- **점검 방법**: 시험지 25문 각각의 *주 통찰 1개* 식별 → 다른 회차와 중복 여부 grep
- **참조**: [[feedback-exam-paper-workflow]] §"회차 간 패턴 중복 회피"

### E2.2 단원 골고루
- **정의**: 시험지가 *모든 출제 범위 단원*에 골고루 분포 (시험범위 한정). CM1 4단원이 시험범위면 PL·EQ·CB·MX 모두 출제
- **표본**: 1회차 — CM1 4단원 + 시험범위 확인 (관련 메모리 [[feedback-exam-scope-required]])
- **위반 신호**: 한 단원에 ≥ 70% 집중 (다른 단원 누락) — 시험범위 어긋남
- **참조**: 시험범위 소단원·소목 명시 [[feedback-exam-scope-required]]

### E2.3 같은 회차 내 발문 워딩 중복 회피
- **정의**: 한 시험지 25문 내 *같은 발문 워딩 패턴*이 ≥ 5회 반복 금지
- **위반 예시**:
  - "다음 조건을 모두 만족시킬 때" 패턴이 7번 (회차 내 과다)
  - "최댓값을 구하시오" 발문이 10번 (다양성 ↓)
- **표본**: 1회차 발문 워딩 — 다양 ("최솟값/최댓값/개수/값/합" 등 골고루)
- **점검 방법**: 시험지 25문 발문 1~2단어 추출 → 빈도 카운트

## 4. 축 E3 — 구간 구조 (3 패턴)

### E3.1 객관식 + 통합 서답 2구간 (\examsection은 객관식만, v0.2)
- **정의 (v0.2, 11회차부터)**: 시험지가 2구간으로 구분. `\examsection{객관식 (배점 합 N점)}` 헤더로 객관식 구간 시작. **통합 서답 구간은 별도 \examsection 헤더 없이 객관식 직후 이어붙임** — 슬롯별 \pointbadge로만 형식·배점 변별
- **옛 정의 (~10회차)**: 3구간 (객관·단답·논술 각 \examsection). 10회차는 옛 정책 표본
- **표본 (옛 정책, 보존)**: 1회차 — 객관식 (1~16, 60.5점) + 단답형 (17~22) + 논술형 (23~25)
- **위반 신호 (v0.2)**: 통합 서답 구간에 별도 \examsection 헤더 / 단답·논술을 두 구간으로 분리 / 객관식과 서답이 섞임

### E3.2 ★ 곡선 (ease-in → 변별)
- **정의**: 첫 1~2 문항은 ★ 1·2 ease-in (학생 안정화), 마지막 1~2 문항은 ★ 5 변별. 중간은 ★ 2~4 균형
- **표본**: 1회차 #1 ★ 3 + #2 ★ 2 (객관식 시작 보통) → #6 ★ 5 (객관식 중반 변별) → 서답 마지막 #25 ★ 5
- **위반 신호**: 첫 문제부터 ★ 5 (학생 충격) / 마지막 문제가 ★ 1 (변별 없음)

### E3.3 구간별 ★ 범위 정합 (v0.2)
- **정의 (v0.2, 11회차부터)**: 2구간 적정 ★ 범위
  - **객관식**: ★ 1~5 (전체 범위)
  - **통합 서답**: ★ 3~5 (★ 1·2 부적합 — 풀이 분량·답 확실성 정합)
- **옛 정의 (~10회차)**: 객관 ★ 1~5 / 단답 ★ 2~5 / 논술 ★ 3~5 (3구간 분리)
- **표본 (옛 정책, 보존)**: 1회차 객관 ★ 2.5~5점, 단답 6문 (★ 3·4·4.5), 논술 3문 (★ 4·5)
- **위반 신호 (v0.2)**: 통합 서답 슬롯에 ★ 1·2 출제 / 객관식이 ★ 4·5만으로 채워짐 (ease-in 부재)

## 5. 축 E4 — 디자인 정합 (4 패턴)

### E4.1 시험지 매크로 일관 사용
- **정의**: `\examheader`·`\examsection`·`pagepair`·`problem`·`\pointbadge`·`\choices`·`conditions` 등 시험지 매크로 일관
- **표본**: 1회차-문제.tex — 매크로 일관 사용
- **위반 신호**: `\textbf{[N번]}` 직접 표기 (매크로 우회) / 보기 매크로 누락

### E4.2 보호 영역 변동 0 (디자인 가이드 9항목)
- **정의**: 시험지 매크로의 *시각적 디자인* (배너·footer·페이지 분할선·페이지 기본 좌표) 변동 0. *콘텐츠만 변경*
- **표본**: 1회차-답지.tex vs 2회차-답지.tex — 디자인 매크로 동일 (style.sty 공유)
- **위반 신호**: 시험지마다 디자인 매크로 변경 (시각적 일관성 ↓)
- **참조**: CLAUDE.md §"변경 가능 / 변경 금지 영역"

### E4.3 시험범위 명시 ([[feedback-exam-scope-required]])
- **정의**: 시험지 examheader 또는 별도 안내에 *시험범위*를 단원·소단원·소목 수준으로 명시
- **표본**: 1회차 examheader — "공통수학1" + "1학기 2차 지필평가 대비" (범위 안내 권장)
- **위반 신호**: 시험범위 명시 누락 → 범위 외 출제 위험

### E4.4 답지 정합 (시험지 ↔ 답지)
- **정의**: 시험지 25문 ↔ 답지 25 풀이 ↔ 빠른 정답표 25 정답이 *모두 일치*
- **표본**: 1회차-문제.tex 25문 + 1회차-답지.tex 25 풀이 + quickgrid 25 답 = 정합
- **위반 신호**: 시험지 26문이지만 답지 25 풀이 (1문 누락) / 보기 선택지 ⑤가 답이지만 답지엔 ③ (불일치)
- **자동 검수**: 빌드 후 답지 quickgrid + 시험지 \pointbadge 카운트 비교

## 6. 시험지 세련도 점수 산정 (refinement_score_exam)

### 점수 산정
- 시험지 1회차 전체의 *모든 축 패턴 적용 여부* 평가
- $\text{refinement\_score\_exam}$ = (적용된 패턴 개수) / 14 × 100점 만점
- **기준**:
  - **90+**: 우수 시험지
  - **75~89**: 표준 시험지
  - **60~74**: 보강 권장
  - **<60**: 재출제 권장

### 시험지 의무 패턴 (v0.1)
- E1.1 100점 정확 ([[feedback-100-point-policy]])

- E3.1 객관식 + 통합 서답 2구간 구분 (v0.2, 11회차부터)
- E4.2 보호 영역 변동 0
- E4.3 시험범위 명시

위 7 패턴은 시험지 *최소 요건*. 모두 충족 시 ★ 표준 시험지.

### E5.1 평가담당 도장란 (외부 학교 양식, 우리 책 미채택 권장)
- **정의**: 학교 시험지 상단 우측에 "평가담당 / 부장 / 교감 / 교장" 4칸 도장란

- **신호**: 학원 시험지 표본에서 발견 시 외부 학교 양식 *모방* — 우리 책 정체성과 불일치 가능

- **정의**: 논술형 구간 시작에 *안내문* 명시 — 답안 형식·채점 기준의 학생 인지 강화
- **표본**: 2024 동화고 평가원안지 논술형 시작 페이지:
  > "※ 다음은 논술형 문항(논술형1~논술형4)입니다. 풀이나 설명 없이 답만 쓰는 경우는 정답으로 인정하지 않습니다. 꼭 정답을 이끌어 내는 과정에서 필요한 식과 설명을 표기하기 바랍니다."
