### 5.1 산출물

- **`scripts/sample-search.mjs`** — JSON 검색 CLI

### 5.2 build 명령

```powershell
node scripts/build-premium-samples.mjs                          # 기본 출력 (data/cm1-premium-samples.json)
node scripts/build-premium-samples.mjs --out data/cm1-2.json    # 다른 경로 출력
node scripts/build-premium-samples.mjs --verbose                # 표 헤더 인식 로그 출력
```

### 5.3 검색 명령

```powershell
# 9.00 TOP 14문 전체
node scripts/sample-search.mjs --top

# CM1-PL 단원 + EQV·PD·CON 모두 포함 + 깊이 3
node scripts/sample-search.mjs --insights EQV,PD,CON --unit CM1-PL --min-depth 3

# CM1-MX 단원 strict 슬롯
node scripts/sample-search.mjs --unit CM1-MX --strict --stats

# 1등급마스터 ★ 5 최상위 + JSON 형식
node scripts/sample-search.mjs --source 1등급마스터 --premium --format json

# I-XU (단원 결합) 포함된 슬롯
node scripts/sample-search.mjs --any-insight XU --premium --limit 20
```

옵션 전체: `--insights LIST` (AND) · `--any-insight LIST` (OR) · `--unit` · `--source` · `--min-depth` · `--min-count` · `--min-score` · `--premium` · `--strict` · `--top` · `--limit` · `--format json|table|md` · `--stats`.

### 5.4 활용 워크플로우 (신규 ★ 5 출제)
1. 목표 통찰 결합 결정 (예: EQV·CON·MI 깊이 3)
2. `sample-search.mjs --insights EQV,CON,MI --min-depth 3 --unit CM1-EQ` 실행 → 표본 슬롯 풀
3. 동일 패턴 2~3문 추출 → 통찰 *형태*만 차용한 신규 슬롯 작성 (절차 복사 X)
4. `scripts/insight-depth-check.mjs <신규.tex>` 휴리스틱 검증
5. `problem-review` v3.4 에이전트 호출
