## 0.5 통찰형 카탈로그와의 차이

| 측면 | 통찰형 (★ 4·5, 03 카탈로그) | 절차형 (★ 3, 본 카탈로그) |
|---|---|---|
| 세련도 본질 | **통찰의 위장 정교함** | **도구 호출의 명확성** |
| 출제자 의도 | 학생이 통찰을 *발견* | 학생이 도구를 *호출* |
| 적용 임계 | ★ 4 (refine ≥ 2), ★ 5 (refine ≥ 3) **의무** | ★ 3 (refine ≥ 1) **권장** (v0.1은 의무화 아님) |
| 통찰 수 | I-XU·BW·RT·EQV·MI·PD·SYM·CON 중 2~4개 | 0~1개 (절차 위주) |
| ★ 5 가능 | 가능 | **불가능** (절차형 ★ 4 천장, schema.md v3.0) |

**핵심 구별**: 절차형 ★ 3은 *발문이 도구를 호출하는 신호*를 학생에게 명확히 주어야 한다. 호출 신호 없이 학생을 헤매게 하는 절차형은 ★ 3 아닌 *★ 2 강등 후보*. 호출 신호 + 한 단계 변형은 ★ 3 표준. 호출 신호 + 통찰 1개 + 한 단계 변형은 ★ 3·4 경계.

## 1. 4축 정의

### 축 P1 — 도구 호출의 명확성 (Tool Invocation)
발문이 *어떤 표준 도구*를 써야 할지 학생에게 명확한 신호를 줌. ★ 3 절차형의 *진입점* 결정 축. 6 패턴 후보 (P1.1~P1.6).

### 축 P2 — 단계 분배의 균형 (Step Distribution)
풀이가 *진입점 → 표준 도구 적용 → 단계 분배 → 답*까지 3~5단계로 균형 잡힘. 한 단계가 5개 이상의 식 변환을 요구하면 균형 깨짐 (학생 막힘). 2 패턴 (P2.1·P2.2).

### 축 P3 — 시각화·표현 도구 (Visualization)
그래프·점근선·수직선 등 *대수 외* 도구로 직관 보조. 절차형 ★ 3의 변별력 핵심 — 시각화 없으면 식만으로 막힘. 2 패턴 (P3.1·P3.2).

### 축 P4 — 변형의 안정성 (Variation Stability)
표준 형태에서 *한 단계만* 변형 (매개변수 추가·단서·케이스 분기). 과도한 변형은 ★ 4 (통찰형 카탈로그)로 진입. 3 패턴 (P4.1~P4.3).

## 2. 축 P1 — 도구 호출 명확성 (6 패턴)

### P1.1 점근선·수직선 시각화 우선 호출 (RF·GM·EQ 공통, v0.1 시판 표본 보강)
- **정의**: 유리함수·이차함수·도형 발문에서 *점근선·수직선·정점*을 먼저 시각화하라는 신호
- **시판 표본 (일품 22개정)**:
  - **일품 08 #13 (★ 3)**: $y = \frac{a}{x+b} + c$의 그래프 그림 + 점근선 $x = -1$, $y = 2$ → $a+b+c$. *그래프 + 점근선 명시*
  - **일품 08 #14 (★ 3)**: $f(x) = \frac{-2x+k}{x+1}$ 평행이동 후 $g$와 일치 + 점근선 교점 ∈ $f$ → $k$
  - **일품 08 #15 (★ 3)**: $y = \frac{bx+1}{x+a}$ 그래프가 점 $(1, -2)$에 대해 대칭 → 대칭점 = 점근선 교점
  - **일품 09 #10 (★ 3)**: 직선 $y = ax+b$ 그림 + $y = b\sqrt{-ax}$ 그래프 개형 매칭
  - **일품 09 #12 (★ 3)**: $f(x) = \sqrt{-2x+a} + b$ 그래프 + $f(ab)$
- **참조용 자체 사례**: OUT-04-005·006·010·011·028
- **출제 응용**: 점근선을 *그림* 또는 *발문 텍스트*로 직접 주면 학생이 도구를 즉시 호출
- **세련도 신호**: "그래프의 두 점근선이 $\ldots$이고" + 통과점 1개 = 매개변수 결정 표준
- **★ 4 진입 회피**: 점근선이 *위장*되면 1.13(점근선 교점 도형, RF 통찰형)으로 격상. 본 P1.1은 점근선이 *명시*된 경우만

### P1.2 판별식 호출 (D ≥ 0 / D < 0 / D = 0) (EQ·RF·FN 공통, v0.1 시판 표본 부족)

- **참조용 자체 사례**:

### P1.3 근과 계수의 관계·환원식 호출 (EQ·RF, v0.1 시판 표본 보강)
- **정의**: 이차방정식의 두 근·합·곱이 등장하는 발문 → 근과 계수의 관계 호출. 또는 복합 분수식의 *환원* (안쪽 → 바깥)
- **시판 표본**:
  - **일품 08 #06 (★ 3)**: $\frac{x}{1 + \frac{3}{x+1}} = x + a + \frac{b}{x+4}$ → $b - 2a$. *복합 분수 환원*
  - **일품 08 #14 (★ 3)**: 점근선 + 평행이동 후 점근선 교점 ∈ 원 함수 → 매개변수
  - **일품 09 #15 (★ 3)**: $\sqrt{x+1}$ 그래프를 평행이동 → 역함수 구하기. *평행이동 환원*
- **참조용 자체 사례**:

- **출제 응용**: 이차방정식의 두 근에 *조건*(범위·합·곱) 또는 분수식의 *환원* 신호
- **세련도 신호**: "해가 $\alpha<x<\beta$"·"두 교점의 좌표"·"두 근의 합"·복합 분수식 워딩

### P1.4 산술기하 평균 (AM-GM) 호출 (RF·EQ, v0.1 시판 표본 보강)
- **정의**: 곱이 일정한 두 양수의 *합·둘레의 최솟값* 발문 → 산술기하 평균
- **시판 표본**:
  - **일품 08 #11 (★ 3)**: $y = \frac{8}{x}$의 그래프 위의 점 P + 원점과 점 P 사이의 거리의 최솟값. *거리² $= x^2 + 64/x^2 \ge 2 \cdot 8 = 16$ → 최솟값 4*. AM-GM 표준
- **참조용 자체 사례**: OUT-04-004 (★ 3): 직사각형 OHPK 둘레 최솟값 (일품 #11과 유사)

- **세련도 신호**: "직사각형의 둘레", "두 양수의 합 최솟값", "원점과 점 사이의 거리 최솟값" 워딩

### P1.5 정의역 끝점 + 단조성 (RF·FN·M·EQ, v0.1 시판 표본 보강)
- **정의**: 제한된 정의역 ($\{x \mid a \le x \le b\}$)에서 *최댓값·최솟값* → 단조성 인식 + 끝점 매칭
- **시판 표본**:
  - **일품 08 #15 (★ 3)**: $y = \frac{bx+1}{x+a}$의 그래프가 점 $(1, -2)$ 대칭 + 정의역 $2 \le x \le 4$에서 최댓값·최솟값 곱
  - **일품 08 #17 (★ 3)**: $f(x) = \frac{x+a}{bx+3}$의 역함수 $g$ + $g(2) = 1, (f \circ f)(1) = 3$ → $f(4)$. *역함수 단조성*
  - **일품 09 #13 (★ 3)**: $f(x) = \sqrt{-2x+5} - 1$ 정의역 $A$ + $g(x) = \sqrt{4x-1} + k$ 치역 $B$ + $A \cap B$ 정수 4개 → $k$ 범위. *정의역·치역 + 정수 매칭*
  - **일품 09 #14 (★ 3)**: $y = \sqrt{x+4} + 2a$ 치역 + 정의역 $-7 \le x \le -1$에서 $f(x) = -\sqrt{a(x-1)} + 1 - a$의 최댓값·최솟값
- **참조용 자체 사례**: OUT-04-007 (★ 3) · OUT-test02-006 (★ 3)
- **출제 응용**: "정의역 $\{x \mid \ldots\}$에서의 최댓값·최솟값" 발문은 단조성·정점 위치 신호
- **세련도 신호**: "$\{x \mid a \le x \le b\}$에서 최댓값이 $M$, 최솟값이 $m$" / "정의역 ∩ 치역에 속하는 정수의 개수" 워딩

### P1.6 표준 비례식·환원식 호출 (RF·EQ, v0.1 시판 표본 보강 — 풍부)

## 3. 축 P2 — 단계 분배의 균형 (2 패턴)

### P2.1 3~4단계 균형 풀이
- **정의**: 진입점 → 도구 적용 (1~2단계) → 단계 분배 → 답까지 *균형 잡힌 흐름*. ★ 3 절차형 표준
- **표본 사례**:
  - OUT-04-005·006·010·011 (★ 3): 점근선 인식 → 매개변수 식 → 통과점 대입 → 답. 4단계 균형
  - OUT-test02-004·006·009 (★ 3): 발문 도구 호출 → 부등식 변환 → 부호 분석 → 매개변수 범위. 4단계 균형
- **세련도 기준**: 한 단계가 *5개 식 변환 이상* 또는 *2개 도구 동시 호출*은 균형 깨짐 → 학생 막힘 → ★ 3 부적합 (★ 2 강등 또는 ★ 4 격상 검토)

### P2.2 케이스 분기 후 통합 (절댓값·범위, v0.1 시판 표본 보강)
- **정의**: 절댓값·범위 조건은 *명확한 케이스 분기 → 각 케이스 표준 풀이 → 통합*. 분기 단계가 *균형*되어야 ★ 3
- **시판 표본**:
  - **일품 09 #01 (★ 3)**: $-3 \le x \le 1$일 때 $\sqrt{(1-x)^2} - \sqrt{(x+3)^2}$ 간단히. *절댓값 분기 + 범위 매칭* — $|1-x| - |x+3|$ → $(1-x) - (x+3)$ ($1-x \ge 0, x+3 \ge 0$)
- **참조용 자체 사례**: OUT-test02-005·008 (★ 3, 절댓값 분기 표본)
- **세련도 기준**: 케이스 수 ≤ 3 권장. 4개 이상은 ★ 3 부적합 (★ 4 또는 학생 부담 과대)

## 4. 축 P3 — 시각화·표현 도구 (2 패턴)

### P3.1 함수 그래프 명시 발문 (RF·M·FN·EQ, v0.1 시판 표본 보강)
- **정의**: 발문에 *그래프 자체*가 등장 (TikZ 그림). 학생이 그래프 *읽기* 능력으로 진입
- **시판 표본**:
  - **일품 08 #13 (★ 3)**: $y = \frac{a}{x+b} + c$의 그래프 그림 → 매개변수 결정
  - **일품 09 #10 (★ 3)**: 직선 $y = ax+b$ 그림 + $y = b\sqrt{-ax}$ 그래프 개형 매칭 (5지선다)
  - **일품 09 #11 (★ 3)**: 세 함수 $y = \sqrt{ax}$·$y = \sqrt{x}$·$y = \sqrt{-bx}$ 그래프 그림 + $|a+b| - |a-b| = -1$ → $a$
  - **일품 09 #12 (★ 3)**: $f(x) = \sqrt{-2x+a} + b$ 그래프 그림 + $f(ab)$
- **참조용 자체 사례**: OUT-04-005·010
- **출제 응용**: 그래프 명시 = *시각 진입점* 강력 호출. 학생 부담 ↓
- **세련도 신호**: "다음 그림과 같이" / "$y=\ldots$의 그래프이다" / "오른쪽 그림과 같을 때" 워딩 + 그림

### P3.2 점근선·정점·교점 시각화 필수 (RF·EQ)
- **정의**: 발문에 그래프가 없어도, *풀이가 점근선·정점·교점 시각화*를 *강제*. 학생이 마음의 그림을 그려야 진입
- **예시**:
  - OUT-04-006·011·028 (★ 3): 점근선 위치를 텍스트로만 명시 → 학생이 그래프 마음으로 그림
  - OUT-test02-006 (★ 3): 정의역 $-1 \le x \le 2$ + 이차함수 → 정점·끝점 시각화 필요
- **출제 응용**: 점근선·정점 *위치*가 풀이의 핵심 → 시각화 강제
- **세련도 신호**: 발문에 "점근선 $x=\ldots$, $y=\ldots$" / "정의역 $\{x \mid \ldots\}$에서 최댓값·최솟값" 등 *위치 정보*

## 5. 축 P4 — 변형의 안정성 (3 패턴)

### P4.1 매개변수 1~2개 추가
- **정의**: 표준 형태 ($y=k/x$ 등) + 매개변수 1~2개 ($a, b, c$ 등)로 학생이 *역추적* 진행
- **예시**:
  - OUT-04-005 ($y=(bx-c)/(x+a)$, 3 매개변수): 점근선 + 통과점 → 3 방정식
  - OUT-04-011·028 (3 매개변수): 동일 형식
- **★ 3 적합**: 매개변수 1~3개 표준
- **★ 2 강등 후보**: 매개변수 0개 (표준 형태 그대로) — 단순 계산
- **★ 4 격상 후보**: 매개변수 ≥ 4개 또는 매개변수가 *통찰*을 위장 → 통찰형 카탈로그로 진입

### P4.2 단서 1개 추가 ("(단, ~)")
- **정의**: 표준 발문 + 단서 1개 (분기 케이스 제거 또는 정의역 제한)
- **예시**:
  - OUT-04-001 (★ 3): 복합 분수 정리 + "단, $x \ne 0, \pm 1$" (분모 0 케이스 제거)
  - OUT-04-004 (★ 3): "단, $\mathrm{O}$는 원점" (그림 보조)
- **★ 3 적합**: 단서 1개로 풀이가 *한 케이스로 좁혀짐*
- **세련도 신호**: "(단, ~)" 단서가 *케이스 분기 제거*에 기여

### P4.3 표준 도구 호출 신호 워딩
- **정의**: 발문 워딩이 *표준 도구를 호출하는 신호*를 명확히 줌
- **예시 워딩 (도구별)**:
  - "모든 실수에서 부등식이 성립" → 판별식 < 0
  - "만나지 않음" / "접함" → 판별식 < 0 / = 0
  - "두 점에서 만남" → 판별식 > 0 + 근과 계수
  - "최댓값·최솟값" + 정의역 → 단조성·정점
  - "곱 일정 + 합 최솟값" → AM-GM
  - "비례식" → 비례상수 도입
  - "역함수의 값" → $f(x) = $ 값 풀이 또는 역함수 식
  - "점근선이 $\ldots$" → 점근선 위치 우선
- **★ 3 적합**: *호출 워딩 1개* 명시
- **★ 4 진입 회피**: 호출 워딩이 *위장* 또는 *없음*이면 통찰형 카탈로그로
