## 2.1 — (가)(나)(다) 조건 박스

### 표준 어구
> 다음 조건을 만족시킨다.
>
> (가) ~
> (나) ~

### 변형 어구
- "다음 조건을 만족시키는 ~"
- "다음 두 조건을 만족시킨다." (조건 2개 시 명시)
- 박스 라벨이 (가)(나) → 2층 결합 / (가)(나)(다) → 3층 결합

### 결합 단서
- "(다) $B(2)>0$" 같은 **부호 단서**가 추가 (3.3 패턴) → 케이스 잘라냄
- "(단, $a, b$는 상수이다)" 박스 밖 단서

### 예시 문장
- P-01 (2026 6월 고1 21번): "삼차다항식 $A(x)$와 이차다항식 $B(x)$는 최고차항의 계수가 모두 1이고 다음 조건을 만족시킨다. (가) $A(x)B(x)$는 $x^2-2x+1$로 나누어떨어진다. (나) $\{B(x)\}^2$을 $x^2-3x+2$로 나눈 몫이 $Q(x)$이고 나머지는 $16x-16$이다. (다) $B(2)>0$"
- M-04 (마더텅 #211): 다항 인수분해 통찰형 박스 형식

### 적용 단원
- PL ★ 5의 표준 (다항식 다중 나눗셈)
- EQ ★ 5 (분기 함수 정의)
- MX ★ 5 (행렬 다중 등식)
- CB 출현 빈도 낮음 (CB는 발문 자체에 조건 풀어쓰기 선호)

### 금지 변형
- 박스 안에 풀이 단계 안내 (예: "이때 $a=$ 빈칸을 채우시오") → 빈칸 유도형 → 통찰 위장 깨짐 (4.4)

## 2.2 — "모든 ~의 값의 합"

### 표준 어구
- "~을 만족시키는 모든 ~의 값의 합"
- "~이 되도록 하는 모든 ~의 합"
- "조건을 만족시키는 모든 정수 ~의 합"

### 변형 어구
- "모든 실수 $a$의 값의 합"
- "모든 자연수 $n$의 값의 합"
- "조건을 만족시키는 ~의 값을 모두 더한 값"
- "(p, q는 서로소) ~를 만족시키는 모든 (p, q) 쌍에 대한 p+q의 합"

### 결합 단서
- "(단, $a$는 정수이다)" — 정의역 제한
- "(단, $\frac{q}{p}$는 기약분수)" — 답 형식 제한

### 예시 문장
- E-01 (2026 6월 고1 15번): "정수해의 개수가 2일 때, 모든 정수 $a$의 값의 합은?"
- E-09 (2025 6월 #120): "조건을 만족시키는 ~의 모든 합"
- E-17 (동화고 논술): "조건을 만족시키는 50 이하 자연수 $n$의 개수를 구하시오"

### 적용 단원
- EQ (가장 빈번 — 매개변수 결정 후 합)
- CB (조건 만족 순서쌍 개수의 합)
- PL 일부

### 금지 변형
- "최댓값" → 합과 의미 다름. 마지막 답 형식 결정 시점에 명확히 구분

## 2.3 — "~의 개수가 ~가 되도록 하는"

### 표준 어구
- "~의 개수가 $N$이 되도록 하는 ~"
- "서로 다른 실근의 개수가 $N$이 되도록 하는 ~"
- "정수해의 개수가 $N$일 때, ~"

### 변형 어구
- "서로 다른 두 점에서 만날 때" → 교점 개수 2
- "서로 다른 세 실근을 가질 때" → 실근 개수 3
- "정확히 $N$개의 ~를 만족시키는"

### 결합 단서
- "(단, ~)" — 개수 결정 조건의 정의역
- "두 자연수의 순서쌍 $(a, b)$의 개수"

### 예시 문장
- E-09 (#120, ★ 5 정답률 37%): "$4x^2-2\{f+g\}x+fg$가 서로 다른 실근 1개를 가지고, $4k^2-2\{f+g\}k+fg$가 서로 다른 실근 3개를 가질 때, ~"
- E-19 (동화고 #23, ★ 5): "정수 $x$의 개수가 10이 되도록 하는 $m$의 값의 범위"
- C-04 (마더텅 #087): "사물함 배정의 경우의 수"

### 적용 단원
- EQ (실근 개수, 정수해 개수)
- CB (배치 경우의 수)
- MX 일부 (순서쌍 개수)

### 금지 변형
- "이상" "이하" → "정확히"로 명시 (등호 강조가 핵심)

## 2.4 — "관계없이 항상"

### 표준 어구
- "모든 실수 $m$의 값에 관계없이 항상 한 점에서 만날 때"
- "임의의 ~에 대하여 ~"

### 변형 어구
- "어떤 ~을 택하더라도"

### 적용 단원
- EQ (항등식 도출)
- 빈도 낮음 (5문 미만)

### 예시 문장
- 2026 6월 고1 9번 (참고용): "실수 $m$의 값에 관계없이 항상 한 점에서 만날 때, 두 상수 $a, b$에 대하여 $a+b$의 값은?"

### 금지 변형
- "~할 때마다" → 의미 모호. "관계없이"가 정형

## 2.5 — "정확히 N개" — 🔴 **금지로 격하 (2026-06-25 마스터 지적)**

> **🔴 마스터 지적 (2026-06-25)**: 동화고 7회차 v2 #15·#18·#20에서 "정확히 N이 되도록" 발문 반복 사용. "정확히" 자체 과잉 강조이며, 한국 교과서 표준은 *수만 명시*하는 형태가 더 자연스럽고 명확.
> **자동 차단**: `scripts/master-feedback-check.mjs` + `bank/마스터-지적/2026-06-25-정확히-N-금지.md`

### ~~표준 어구~~ → **🔴 금지**
- ~~"정확히 ~개의 정수해를 갖도록 하는"~~ ❌
- ~~"서로 다른 ~의 개수가 정확히 $N$"~~ ❌

### 대안 어구 (마스터 의향)
- "정수해의 개수가 $5$인" (수만 명시, 정확히 X)
- "정수해의 개수가 $5$가 되도록 하는"
- "서로 다른 ~의 개수가 $N$"
- "오직 한 개의 해" / "단 한 개의 해" (한 개 강조 시)
- "한 점에서만 만날 때"
- "유일한 ~"

### 결합 단서
- 한국 교과서 표준 발문에서 "정확히"는 *과잉 강조*. *수만 명시*해도 "**정확히 그 수**" 의미로 해석되는 게 자연스러움.
- 모호하다고 느낄 때는 "~인" 또는 "~가 되도록 하는" 형태로 *문법 구조*로 명확히 표현.

### 예시 문장 (대안)
- E-01 (2026 6월 #15): "정수해의 개수가 2일 때" (이미 정확히 X 형태)
- E-09 (2025 6월 #120): "서로 다른 실근 1개를 갖고" (이미 정확히 X 형태)
- C-01 (2025 9월 #81): ~~"B와 C가 같은 요일에 강의를 듣는 날이 정확히 하루"~~ → "B와 C가 같은 요일에 강의를 듣는 날이 하루"

### 적용 단원
- 모든 단원 (개수 조건 표준)

### 금지 변형
- ~~"있도록" → "정확히 ~개가 되도록"으로 명시~~ → "있도록"은 *문맥에 따라 명확*. 단순 "있도록"이 "1개 이상"으로 약화될 우려는 *조건문 구조*로 해결 (예: "~인 ~의 개수가 5인 조건을 만족시키는")
- 🔴 "정확히 N이 되도록" 형태 일체 금지

### 정정 이력
- 2026-06-25 v1.1 — 마스터 지적 후 표준 → 금지 격하. 대안 어구 명시

## 2.7 — "(단, ~)" 단서

### 표준 어구
- "(단, $a, b$는 상수이다.)"
- "(단, $a > 0$)"
- "(단, $\frac{p}{q}$는 기약분수)"

### 변형 어구
- "이때 $a, b$는 ~"
- "여기서 ~"

### 결합 단서
- 발문 끝에 위치 — 본문에 녹이지 않음

### 예시 문장
- E-02 (2026 6월 #18): "(단, $\frac{2\sqrt 3}{3}-1 < \overline{BF} < \frac{2\sqrt 3}{3}$)" — **정의역 위장 (1.6)**
- E-08 (2025 6월 #111): "(단, $a, b$는 상수)"
- M-12 (1등급 #829): "(단, $m > n$인 100 미만 자연수)"

### 적용 단원
- 모든 단원 (44% 출현)
- 단서가 본질 정보를 위장하는 1.6 패턴과 결합 시 ★ 5 표준

### 금지 변형
- 본문 안에 풀어쓰기 → 단서 위치가 시각적으로 분리되어야 풀이가 자연스럽게 단서 호출

## 2.8 — "최댓값/최솟값" + 합·곱

### 표준 어구
- "최댓값을 $M$, 최솟값을 $m$이라 할 때, $M+m$"
- "최댓값과 최솟값의 합"
- "최댓값의 최솟값" (이중)

### 변형 어구
- "가장 큰 값과 가장 작은 값"
- "$f$의 최댓값이 $a$, 최솟값이 $b$일 때"

### 결합 단서
- "이차함수" / "닫힌구간 $[a, b]$" — 함수 표준형 호출

### 예시 문장
- E-05 (2025 9월 #79): "$f=a(x-b)^2$ + 구간 $[k, k+2]$에서 max-min$=g(k)$"
- E-07 (2025 9월 #90): "사각형 ACDB의 넓이의 최댓값과 최솟값의 합"
- M-02 (2008 9월 학평): "$f(x)=ax^2+bx+c$의 최솟값이 3일 때"

### 적용 단원
- EQ (이차함수 표준)
- MX 일부 (이차함수 결합)

### 금지 변형
- "max" "min" 영문 표기 → 한글 "최댓값" "최솟값" 표준

## 2.9 — 그림 + "다음 그림과 같이"

### 표준 어구
- "다음 그림과 같이 ~"
- "그림과 같이 ~"

### 변형 어구
- "[그림]" 박스 + 발문 본문에 "이때"

### 결합 단서
- 그림이 매개변수 위치·도형 결합을 시각 제공
- "(단, $\frac{2\sqrt 3}{3}-1 < \overline{BF} < \frac{2\sqrt 3}{3}$)" — 그림과 단서 함께 (1.6 + 2.9)

### 예시 문장
- E-02 (2026 6월 #18): 정사각형 + 정삼각형 결합 그림
- E-19 (동화고 #23): piecewise 그래프 + 직선
- P-12 (1등급 #069): 반원 호 그림
- P-13 (1등급 #064): 두 원 그림

### 적용 단원
- EQ (도형 매개변수화), PL (도형↔대수 환원)
- CB 일부 (영역 색칠), MX 일부 (좌표 변환)

### 금지 변형
- 그림 없이 발문만으로 도형 묘사 시도 → 매개변수 위치 모호 → 풀이 분기 폭발
