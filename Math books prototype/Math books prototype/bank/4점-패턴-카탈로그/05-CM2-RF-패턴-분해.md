## 2. CM2-RF 특화 신규 패턴 6종 (정의)

### R-A 자기역함수 조건 = 계수 관계 폐쇄식 (RF)
- **정의**: $f(f(x))=x$ 또는 $(f\circ f)(x)=x$ 조건이 본질적으로 계수 사이의 폐쇄식 (예: $a+c=0$ 형태)으로 환원
- **예시**:
  - OUT-04-042 (★ 5): $f(x)=\frac{ax+b}{x-c}$ + $f\circ f=x$ → $a+(-c)=0$ → $a=c$. 추가 두 점 통과로 매개변수 결정
  - OUT-04-026 (★ 4): $f(x)=\frac{ax+b}{x+c}$ + $f\circ f=x$ + $f(0), f(1)$
  - OUT-04-027 (★ 4): 위와 동일 + 서술형
- **출제 응용**: 자기역함수 조건을 직접 *말하지 않고* $f\circ f=x$로 표기. 학생이 조건의 의미(역함수와 자신이 같음)를 해석해야 함
- **워딩 형태**: "$(f\circ f)(x) = x$를 만족시키고…"
- **함정**: 학생이 두 점 통과만 보고 매개변수 결정으로 가면 케이스 폭발. 자기역함수 조건을 *먼저* 써야 차원 축소

### R-B 합성함수 주기 (분수꼴) (RF)
- **정의**: $f^n = \underbrace{f\circ\cdots\circ f}_n$의 표현이 주기 $T$를 가짐 (예: $f^3 = x$ → 주기 3). $n$을 $T$로 나눈 잉여류로 환원
- **예시**:
  - OUT-04-018 (★ 4): $f(x)=\frac{x}{1-x}$의 $f^{10}$ — 주기 발견 후 계수 합
  - OUT-04-019 (★ 4): $f(x)=\frac{1}{1-x}$의 $f^{1001}(2)$ — 주기 3
  - OUT-04-020 (★ 4): $f(x)=\frac{x}{x+1}$의 $f^k(a) = \frac{2}{333}$ → $a, k$ 시스템
- **출제 응용**: 분수꼴 함수 중 $f\circ f\circ f = x$ 또는 $\frac{x+n}{1+nx}$ 형태로 환원되는 함수가 표준
- **함정**: 학생이 $f^2, f^3$를 계산해보지 않고 거듭제곱으로 전개 시도 → 식 폭발
- **MX 1.9와의 차이**: 행렬 1.9는 $A^n = E$ 폐쇄식. RF R-B는 *합성함수*의 폐쇄식. 표현이 분수라 인식이 더 어려움

### R-C 점근선·교점·도형 결합 (RF)
- **정의**: 유리함수의 점근선 교점이 도형의 꼭짓점·중심 역할 + 직선과의 교점이 추가 꼭짓점 → 넓이·거리 계산
- **예시**:
  - OUT-04-041 (★ 5): 점근선 + 직선 + 거리 최솟값 (점근선의 평행선 활용)
  - OUT-04-046 (★ 5): 점근선 교점이 삼각형의 한 꼭짓점, 두 교점이 나머지
  - OUT-04-024 (★ 4): 원점이 삼각형 꼭짓점 (특수 케이스)
  - OUT-04-048 (★ 5): 두 유리함수의 점근선이 사각형 ACBD의 대각선 결정
- **출제 응용**: $y = \frac{k}{x-p} + q$의 점근선 $(p, q)$를 *명시하지 않고* 도형 조건만 제시. 학생이 점근선 위치를 *발견*해야 함
- **함정**: 학생이 점근선 무시하고 두 교점만으로 넓이 시도 → 다른 꼭짓점이 점근선 교점인 것을 놓침
- **CM1-1.8(도형↔대수)과의 차이**: 1.8은 길이↔곱셈공식. R-C는 그래프 *구조 자체*가 도형 — 점근선이 보이지 않는 꼭짓점

### R-D 함수 양쪽 부등식 → 치역 결정 (RF)
- **정의**: $ax \le f(x) \le bx$ 형태 양쪽 부등식이 모든 $x \in I$에서 성립 → $a, b$가 $f(x)/x$의 치역 끝점
- **예시**:
  - OUT-04-045 (★ 5): $ax \le \frac{2x}{x+1} \le bx$ + $b-a$ 최솟값
- **출제 응용**: 함수 $f(x)/x$의 그래프를 그려 치역 범위 결정. 점근선이 또 등장 (R-C 연계)
- **함정**: 학생이 부등식을 *대수적으로* 풀려 함 → 인수분해 시도 → 막힘. 함수의 그래프 시각화 필요
- **워딩 형태**: "모든 양의 실수 $x$에 대하여 부등식 $\ldots$가 성립할 때, $b-a$의 최솟값"

### R-E 거듭제곱 합 점화 (RF·PL)
- **정의**: $x^k + \frac{1}{x^k}$ 형태 거듭제곱 합이 $x + \frac{1}{x}$ 또는 $x^2 + \frac{1}{x^2}$ 같은 낮은 차수의 합으로 점화 (예: $(x^2+\frac{1}{x^2})(x^3+\frac{1}{x^3}) = x^5+\frac{1}{x^5} + x + \frac{1}{x}$)
- **예시**:
  - OUT-04-014 (★ 4): $x^2+\frac{1}{x^2}=7$ → $x^5+\frac{1}{x^5}$
  - (참고) CM1-PL의 P-12 (1등급 #069): 닮음 → $a^3 - \frac{1}{a^3}$ 자연 출현
- **출제 응용**: $x^2 + \frac{1}{x^2}$ 값 1개를 주고 더 높은 거듭제곱의 합 요구
- **함정**: 학생이 $x$의 실제 값을 구하려 함 → 무리수 → 막힘. 거듭제곱 *합*을 점화로 풀어야
- **CM1-1.8과의 차이**: 1.8은 도형 환원으로 자연 출현. R-E는 단독 대수 점화

### R-F 연분수 분해 (RF)
- **정의**: 유리수를 연분수 (continued fraction) 형태로 분해. 본질은 *유클리드 호제법*과 동일하지만 표현이 분수
- **예시**:
  - OUT-04-016 (★ 4): $\frac{27}{10} = a + \cfrac{1}{b + \cfrac{1}{c + \frac{1}{d}}}$
- **출제 응용**: 분수를 연분수로 표현하라는 *조건*은 거의 항등식 — 분해 알고리즘 자체가 통찰
- **함정**: 학생이 연분수 표현을 *시도*해본 적이 없으면 진입 불가. 출제 빈도 낮음 (★ 4 보더라인)
- **★ 5 부적합**: 통찰이 1개 (알고리즘 인식)이라 ★ 4 천장. ★ 5는 R-F + 다른 패턴 결합 필요

### R-G 절댓값 분기 함수의 역함수 (RF·FN)
- **정의**: $f(x) = \frac{x}{1+|x|}$ 같이 $|x|$를 포함한 함수의 역함수는 $x > 0$, $x < 0$ 두 분기로 분리해서 구해야 함
- **예시**:
  - OUT-04-044 (★ 5): $f(x)=\frac{x}{1+|x|}$ + $g(\frac{1}{3}) + g(-\frac{1}{2})$
- **출제 응용**: 한 입력에서 역함수 값을 구할 때 *부호*에 따라 다른 분기 사용
- **함정**: 학생이 $|x|$를 무시하고 $f^{-1}$을 통째로 구하려 함 → 식 폭발. 분기해서 따로 구해야
- **FN 단원과 공유**: 절댓값 함수의 역함수는 FN의 표준 통찰. RF에서는 유리식과 결합되어 출현

### ★ 5 신규 출제 (refine ≥ 3 의무)
