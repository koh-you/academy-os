# Task #2~#3 Agent 병렬 프롬프트 사양 (다음 세션 진입용)

## 사용 시점
다음 세션에서 모의고사 11회 + 교재 11종 + 학교기출 분석을 Agent 병렬로 진행할 때 그대로 사용.

## 모의고사 Agent 프롬프트 템플릿 (general-purpose)

각 모의고사 PDF당 1개 Agent. 총 11개 동시 호출.

### Agent 설명 (description)
`모의고사 4점 통찰형 후보 식별 — [회차명]`

### Agent 프롬프트 본문 (prompt)
```
당신은 수학 교재 제작 프로젝트의 표본 후보 추출 에이전트입니다. 다음 PDF에서 공통수학1(CM1) 범위 4점 자리 통찰형 문항만 식별해 메타 인덱스를 작성합니다.

## 컨텍스트
프로젝트는 수능 모의고사 4점급 "세련된" 출제 패턴 카탈로그를 구축 중입니다. 카탈로그는 (a) 조건 위장 (b) 발문 워딩 (c) 다층 결합 (d) 함정 설계 4축으로 패턴을 분해합니다. 본 작업은 분해 대상이 될 50문 표본을 모으는 단계입니다.

## 분석 대상
- PDF 경로: 참고자료/대수-수능모고/<파일명> (또는 참고자료/<파일명>)
- 회차: [회차명]
- 범위: CM1 (PL 다항식 / EQ 방정식부등식 / CB 경우의수 / MX 행렬)
- 고3 공통과목 PDF는 1~22번이 공통과목이므로 그 범위만 검토. 수1·수2 범위 문항은 제외.
- 고1·고2 PDF는 1~30번 모두 CM1 범위.

## 작업 단계
1. Read 도구로 PDF를 페이지 단위로 정독 (페이지 범위 적절히 분할).
2. 4점 자리만 식별: 시험지에 "[4점]" 명시된 문항.
3. 통찰형 vs 단순형 판정:
   - 통찰형 = I-XU(단원결합)·BW(역방향)·RT(표현전환)·EQV(동치변환)·MI(다중해석)·PD(패턴발견)·SYM(대칭)·CON(조건통합) 중 최소 1개 적용된 문항
   - 단순형 제외 기준:
     - 빈칸 유도형(과정 안내가 풀이를 노출시키는 형식)
     - 단순 계산형(공식 적용 후 큰 수 계산만 요구)
     - 단순 인수분해·전개만 요구
4. CM1 단원 분류 (PL/EQ/CB/MX). 도형 융합 문항은 PL·EQ 중 본질에 가까운 쪽으로.
5. 각 후보를 다음 메타로 기록:
   - 출처 (회차·번호 [점])
   - 단원
   - 발문 요지 (1줄, 본문 전사 금지)
   - 추정 통찰 유형 (1~3개)
   - 추정 ★ (M·I·X 직관 추정 — schema.md v3.0 참조)
   - 세련도 포인트 (워딩·식·구조 중 어디가 세련의 핵심인가)

## 산출물
다음 마크다운 표를 반환:
```
### [회차명] 후보 N문

| # | 번호 [점] | 단원 | 발문 요지 | 통찰 유형 | 추정 ★ | 세련도 포인트 |
|---|---|---|---|---|---|---|
| 1 | 14 [4] | PL | ... | I-EQV·I-RT | ★ 4 | ... |
...

총 식별 N문 / 단원 분포: PL N · EQ N · CB N · MX N
```

## 제약
- PDF 본문 전사 금지. 발문 요지는 원리·구조만 한 줄로 압축.
- 빈칸 유도형은 "통찰을 풀이 단계로 분해해 안내"하므로 제외 (수능 4점급 세련도와 다름).
- 단답형 4점(26~30번)도 동등하게 검토.
- 단원 분류 애매할 시 본질 단원으로 분류 + "(도형 융합)" 같은 주석 추가.

## 참조 파일
- bank/schema.md (v3.0 통찰 8유형·M·I·X 정의)
- bank/4점-패턴-카탈로그/00-표본풀-정의.md (표본 풀 기준)
- bank/4점-패턴-카탈로그/01-표본-후보-50문.md (시범 1회 결과 — A1 섹션 양식 참고)

분석이 끝나면 위 표 양식 결과만 반환하세요. 다른 설명·요약 불필요.
```

## 교재 Agent 프롬프트 템플릿 (general-purpose)

각 교재당 1개 Agent. 총 11개. PDF가 대용량일 수 있어 페이지 범위 분할 필요.

### Agent 설명
`교재 4점급 통찰형 후보 추출 — [교재명]`

### Agent 프롬프트 본문
```
당신은 수학 교재 제작 프로젝트의 표본 후보 추출 에이전트입니다. 다음 교재 PDF에서 공통수학1 ★ 4·5급 통찰형 문항을 식별해 메타 인덱스를 작성합니다.

## 컨텍스트
[모의고사 프롬프트와 동일]

## 분석 대상
- PDF 경로: 참고자료/공통수학 1/<교재폴더 또는 파일명>
- 교재 특성: [교재별 — 예: "쎈 공통수학1 — STEP 3 단계만 검토" / "블랙라벨 — 전체 검토 후 최난도만"]
- 범위: 다항식·방정식부등식·경우의수·행렬 4단원 모두

## 작업 단계
1. 교재 목차 페이지를 먼저 정독해 단원·STEP 구조 파악.
2. 다음 챕터/섹션만 추출 대상:
   - **쎈**: STEP 3 (최상위)
   - **마플시너지**: STEP 3 "행복한 1등급"
   - **블랙라벨·일품·절대등급·1등급마스터·일등급수학·플래티넘·고쟁이 III·짱 중요한내신**: 전체 검토 후 ★ 4·5급만
   - **마더텅·EBS 전국연합기출**: 4점 자리 기출만
3. 통찰형 vs 단순형 판정 기준은 모의고사와 동일.
4. 각 단원에서 강한 후보 1~2문씩 추출 (단원 균형 의식).
5. 메타 양식은 모의고사와 동일.

## 산출물
[모의고사와 동일 양식]

## 제약
- 본문 전사 금지.
- 한 교재에서 너무 많이 추출하지 않음 — 4단원 × 2문 = 8문 이내 권장.
- 단원이 명확하지 않거나 응용·심화에 융합된 문항은 본질 단원으로 분류.
```
