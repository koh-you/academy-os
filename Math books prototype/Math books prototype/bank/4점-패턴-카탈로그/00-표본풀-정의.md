# 수능 4점급 패턴 카탈로그 — 표본 풀 정의 (v2 확정, 2026-06-21)

> **상태**: 마스터 합의 완료. Task #2 (모의고사 후보 추출) 진입 가능.

## 목적
공통수학1 신규 출제·검수 시 "★ 산정상 4·5라도 세련도가 모자란" 문제와 "수능 4점급 세련된" 문제의 격차를 메우기 위한 패턴 카탈로그 구축. 본 문서는 카탈로그의 표본 풀(50문)을 어디에서 어떤 기준으로 뽑을지 정의한다.

세련도 4축:
1. **조건 위장** — 본질을 식·기호·함수 표현 뒤에 숨김 (예: $f(x)$가 어떤 함수와 동일·근의 위치로 조건 인코딩)
2. **발문 워딩** — 직설을 회피, 추론을 강제 (예: "다음 조건을 만족시키는 ~의 개수")
3. **다층 결합** — (가)·(나) 조건 분리, 둘 결합해야 풀이 진입
4. **함정 설계** — 자연스러운 오답이 강하게 유도되는 구조

## 자동 선정 알고리즘 (안)
```
입력: 표본 풀 카테고리 (A·B·C) + 필터 조건
1. PDF 메타 스캔
   - A: 회차·문제번호·점수표시("[4점]")·정답률(EBSi 공개분)
   - B: 페이지·번호·난이도표시(★/STEP/등급) — PNG OCR 또는 색인 수동
   - C: 회차·문제번호·정답률
2. 1차 필터 — 4점 자리 또는 최상위 단계
3. 2차 필터 — 통찰형 (단순 계산형 제외)
   - 발문 길이가 짧고 조건이 단순한 문항 → 제외 후보
   - 그래프·표·(가)(나) 박스가 있는 문항 → 우선 포함
4. 단원 코드 분류 (PL/EQ/CB/MX)
5. 단원 균형 맞춰 50문 셀렉
6. 인덱스 마크다운 산출 (출처·번호·★·예상 통찰유형·간단설명 — 본문 전사 금지)
```

**한계**: 통찰형 vs 계산형 자동 분류는 OCR 정확도 한계로 100% 자동화는 어려움 → 1·2차 필터 자동 + 3차 필터(통찰형 판정)는 클로드가 PDF 페이지를 직접 읽으며 수동 판정.
