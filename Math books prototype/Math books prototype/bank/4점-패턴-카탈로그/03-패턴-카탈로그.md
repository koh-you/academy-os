## 축 1 — 조건 위장 기법 (10 패턴)

### 1.1 보조다항식 도입 (PL)
- **정의**: $P(k)=g(k)/h(k)$ 형태 조건에서 $h(x)P(x)-g(x)$가 인수정리 적용 가능한 새 다항식으로 환원
- **예시**:
  - P-09 (마플 #0286): $P(k)=1/k$ ($k=1,2,3,4$) → $xP(x)-1$이 4개 근 보유
  - P-10 (블랙 STEP3-08): $f(k)=k/(k+1)$ → $g(x)=(x+1)f(x)-x$가 5점에서 0
- **출제 응용**: $f(k)$ 값이 분수·유리식 형태로 주어진 표현 식 보존. 보조다항식의 근 개수 = 입력 점 개수
- **워딩 형태**: "$P(k)=\frac{1}{k}$ ($k=1,2,3,4$)일 때 $P(6)$의 값" — 분수 표현 그대로 발문에 등장

### 1.2 음수 제곱 → 허근 신호 (EQ)
- **정의**: $(\cdot)^2 < 0$ 또는 $(\cdot)^2 = -k$ ($k>0$) 조건은 본질적으로 "두 근이 켤레 복소수" 신호
- **예시**:
  - E-09 (#120): 4차식의 판별식 분기로 실근 1개 ∧ 3개 동시
  - GM-4 (1등급 #471): $(2\alpha+2\beta-\gamma)^2=-144$
  - 2025 6월 #119: $(2\alpha+2\beta-\gamma)^2=-81$
- **출제 응용**: 비대칭 조건을 음수 등호로 위장 → 자연스러운 케이스 분기 (실근 vs 허근)
- **워딩 형태**: 직접적인 "허근"·"복소수" 언급 회피, 음수 등호만 노출

### 1.3 $\{P\}^2$로 차수·계수 위장 (PL)
- **정의**: 원본 다항식 $P$의 정보를 $P(x)^2$로 차수·계수 확대해 표현
- **예시**:
  - P-05 (#118): $\{P\}^2$을 $x^2-4x-5$로 나눈 몫·나머지
  - P-06 (#148): $\{P\}^2-\{Q\}^2 = (P-Q)(P+Q)$ 분해
  - GM-3 (1등급 #143): $\{P+2\}^2 = (x-a)(x+a)(x^2+5)+9$ 좌·우 짝수차 비교
- **출제 응용**: 인수정리 대입 시 두 값에서 같은 절댓값 → 부호 분기. $P(0) \ne P(4)$ 같은 단서로 분기 제거

### 1.4 합성식 변수 환원 (PL·EQ)
- **정의**: $A(x) = (B(x))^4 - 2(B(x))^3 - \ldots$ 형태로 합성. 본질은 $B(x)$의 결정과 $A$의 표현
- **예시**:
  - P-02 (#28 2026 6월 고1): $A = (B)^4 - 2(B)^3 - (B)^2 + 2B$ + $A(1)=24, A(2)=0$
- **출제 응용**: 4차·6차 표현 위장이지만 $B$ 결정 후 1차·2차 환원
- **워딩 형태**: "최고차항 계수가 1인 일차다항식 $B(x)$" — 합성 깊이는 $B$의 차수만큼만 증가

### 1.5 그래프·집합 위장 (EQ)
- **정의**: 함수의 그래프 특성을 집합 표기 $\{x: \ldots\}$로 위장
- **예시**:
  - E-11 (#150): $X=\{x: |f|=1\}, Y=\{x: |g|=1\}$ + $n(X\cap Y)=3, n(X\cup Y)=4$
  - E-19 (동화고 #23): 3구간 piecewise $g$ + $g(x) \ge m(x-5)$ 정수해 10개
- **출제 응용**: 집합 카드 조건이 본질적으로 그래프와 직선의 교점 개수 → 위치 동시 결정
- **워딩 형태**: 집합 표기·$n(X)$·교집합·합집합 용어가 함수 그래프 분석 신호

### 1.6 정의역 단서로 매개변수 범위 위장 (EQ)
- **정의**: 본 발문 끝의 "(단, ~)" 또는 매개변수 부등식 단서가 사실은 풀이의 본질 정보
- **예시**:
  - E-02 (#18 2026 6월 고1): $\frac{2\sqrt 3}{3}-1 < \overline{BF} < \frac{2\sqrt 3}{3}$
- **출제 응용**: 매개변수 정의역을 명시해야 풀이가 한 케이스로 좁혀짐. 단서 없으면 케이스 폭발
- **워딩 형태**: "(단, $\frac{2\sqrt 3}{3}-1 < \overline{BF} < \frac{2\sqrt 3}{3}$)" — 단서가 답을 한정

### 1.7 다중 자기참조 (EQ)
- **정의**: 매개변수 $k$가 함수의 입력값이자 결과값으로 동시에 등장
- **예시**:
  - E-15 (동화고 #14): $f(0)=k$ + $f(x)=kx$ 두 근 — $k$가 함수의 상수항이자 직선의 기울기
  - E-18 (동화고 #22): $f-g \ge f(k)-g(k)$ — $k$가 최솟값 위치 자기 참조
- **출제 응용**: 자기참조가 새 방정식을 자동 생성. 풀이는 자기참조를 인식하는 데서 시작
- **워딩 형태**: 같은 문자 $k$가 식과 점·값에 동시 등장

### 1.8 도형↔대수 환원 (PL)
- **정의**: 도형 길이를 대수식 (특히 곱셈공식)으로 환원
- **예시**:
  - P-07 (#59): 직육면체 모서리 $(\overline{AB}+\overline{BF})^2$ 곱셈공식
  - P-12 (1등급 #069): 반원 호 위 조건 → 닮음 → $a^3-1/a^3$ 자연 출현
  - P-13 (1등급 #064): 두 원 넓이 차 → $-\pi xy$ → 곱셈공식 한 줄
- **출제 응용**: 도형 조건이 곱셈공식 $(a+b)^2$·$(a-b)^2$·$a^3 \pm b^3$를 호출. 닮음·피타고라스로 환원

### 1.9 행렬 주기성 위장 (MX)
- **정의**: $A^n$의 성분이 특정 패턴 (등비·교대·다항)을 따름. 본질은 $A$의 최소다항식 주기
- **예시**:
  - M-03 (#210): $A^n$의 $(1,2)$ 성분이 $2^4-2^5+2^6-2^7+2^8$ — 등비 합 형태
  - M-08 (EBS 1등급 02): 두 행렬 $A, B$ 각자 주기 발견 후 $B^4 A^9$ 곱 분리
  - M-11 (1등급 #826): $A^4=E$ 주기 + 배수 조건 + 범위 양 끝 탐색
  - M-12 (1등급 #829): $A^3=-E \to A^6=E$ + 부호 동기화
- **출제 응용**: 주기 $n$ 발견 → 거듭제곱 mod $n$ → 잉여류 카운트

### 1.10 케일리해밀턴 위장 (MX) — **⚠️ CM1 비활성 (2026-06-24 마스터 확립)**
- **🔴 CM1 출제 비활성**: 마스터 결정 2026-06-24. **공통수학1 행렬 단원에서 케일리해밀턴 정리 자체를 학생이 알고 *유도*하도록 강요하는 출제 금지**. 시중 교재에 옵션으로 수록되어 있지만 정식 교과과정 외. 본 패턴을 *★ 5 진입 신호*로 가중하지 말 것.
- **CM1 허용 형태**: 학생이 식 $A^2 = pA + qE$를 *유도*하지 않고 *받아쓰기*만 하면 OK (즉 발문에 식이 직접 주어진 경우). 답지에 "케일리해밀턴 정리에 의하면" 명시 절대 금지 — "주어진 식 양변에 $A$를 곱하면" 형태로만 표현 가능.
- **CM2 이상 단원에서는 정의 유지** (CM2-RF·CM2-GM 등에서 단원 친숙도가 다름):
- **정의 (legacy, CM2 이상 한정)**: $A^2 = pA + qE$ 형태 폐쇄식을 직접 주지 않고 $A^2 - 2aA = O$ 같은 부분 식으로 위장
- **예시 (CM2 이상 한정)**:
  - M-02 (#209): $A^2 - 2aA = O$ + 이차함수 $f=ax^2+bx+c$ 최솟값 3
  - M-04 (#211): $AB+B=A, ABA-A^2=E$ → $AB=BA$ 도출
  - M-06 (#287): $A^2-A+E=O, B^2+2B=O$ → 양쪽 최소다항식 동시
- **CM1 대안 패턴 (권장)**:
  - $A^2 = pA + qE$ 형태의 식을 *발문에 직접 제시* + 행렬 곱셈 직접 계산으로 검증
  - $A^n$ 거듭제곱은 작은 $n$ 계산 + 패턴 추측 (1.9 주기성) 으로 환원
  - 성분 합·성분별 비교 같은 직접 계산 패턴 우선

### 1.11 자기역함수 폐쇄식 (CM2-RF, v1.1 추가, v1.5 시판 표본 보강)
- **정의**: $f(f(x)) = x$ 또는 $(f \circ f)(x) = x$ 또는 $f = f^{-1}$ 조건이 본질적으로 계수 사이의 폐쇄식 (예: 분수꼴 $f(x) = \frac{ax+b}{x+c}$에서 $a + c = 0$ 또는 $a = -c$)으로 환원
- **시판 표본 (일품 22개정)**:
  - **일품 08 #21 [1등급 비밀노트] (★ 5)**: $f(x) = \frac{bx}{x+a}$ + (가) $f = f^{-1}$ + (나) 두 점근선 교점 $\overline{\mathrm{OP}} = 3\sqrt{2}$ → $ab$
  - **일품 08 #22 [서술형] (★ 4)**: $f(x) = \frac{ax}{x+b}$ + 역함수 그래프가 두 직선 $y = x+2, y = -x+8$에 대해 대칭 → $f^{-1}(4)$
  - **일품 08 #24 [1등급] (★ 5)**: $f(x) = \frac{x-a}{x+2}$ + (가) $f^{-1}(x) = f(x-3) + b$ + (나) 직선 $x=-1$이 $f \circ f$의 한 점근선 → $a - b$
  - **일품 09 #19 (★ 4)**: $f(x) = \sqrt{x-12}$ + $(f^{-1} \circ g)(x) = 4x$ + 역함수 합성 분석 → AB 길이
- **참조용 자체 사례**: OUT-04-042·026·027 (시판과 동일 통찰)
- **출제 응용**: 자기역함수 조건을 *말하지 않고* $f\circ f=x$로만 표기. 학생이 의미(역함수와 자신이 같음 → 계수 폐쇄식) 해석 필요
- **워딩 형태**: "모든 정의역에서 $(f\circ f)(x)=x$를 만족시키고…" / "$f = f^{-1}$" / "$y = f^{-1}(x)$의 그래프가 직선 $y = \ldots$에 대해 대칭"
- **함정**: 두 점 통과만으로 매개변수 결정 시도 → 케이스 폭발. 자기역함수 조건을 *먼저* 써야 차원 축소

### 1.17 절댓값·분기 함수의 역함수 (CM2-RF·CM2-FN, v1.1 추가, v1.5 시판 표본 보강 + 일반화)

### 1.18 대칭이동을 이용한 최단거리 (반사 원리, CM2-GM, v1.2 추가)
- **정의**: 두 점 사이 *경유점*이 직선(축·일반 직선)·도형 위에 있을 때, 한 점을 그 직선·도형에 대해 *대칭이동* → 두 점을 잇는 직선과의 교점이 최단 경로. 다중 경유점은 다중 대칭
- **예시**:
  - 쎈 0468 (대표·★ 4): A(1,4), B(6,2) + y축 위 P, x축 위 Q → AP+PQ+QB 최솟값. *두 점 모두 두 축 대칭*
  - 쎈 0481 (★ 5): 당구공 반사 모델 (270×150 직사각형) → 벽 3번 반사. *네 번 대칭으로 직선 거리화*
  - 쎈 0488 [교육청 기출, ★ 5]: A(-4,4), B(5,3) + x축 위 P,Q + y=1 위 R → AP+PR+RQ+QB 최솟값. *다중 축에 대해 다중 대칭*
  - 쎈 0472 (★ 4): 두 원 위 점 + x축 위 P → AP+BP 최솟값. *원의 중심으로 환원 + 대칭*
- **출제 응용**: 거리 합·둘레의 *최솟값* 발문 = 반사 원리 신호. 경유점 N개 → N회 대칭
- **함정**: 학생이 매 경유점을 매개변수로 설정 → 미적분 도구 시도 → 막힘 (CM2 범위 외). 반사 원리 인식 못 하면 진입 불가
- **insights_used 표준 라벨**: I-RT (도형 거리 → 직선 거리화) + I-EQV (반사 = 대칭) + (★ 5) I-MI (다중 경유점 다중 대칭)
- **CM1-1.8과의 차이**: 1.8(도형↔대수)은 길이↔곱셈공식 환원. 1.18은 길이↔*대칭 도형* 환원

### 1.19 반복 대칭이동의 자취·주기 (CM2-GM, v1.2 추가)
- **정의**: 점 P를 두 가지 이상 변환(원점·y=x·x축·y축 등)으로 반복 적용 → 자취가 *주기 T*를 가짐 (보통 T=2,3,4,6,8). $P_n$ 결정은 $n \bmod T$의 잉여류로
- **예시**:
  - 쎈 0430 (★ 4): $P_1(-4,5)$ → 원점·y=x 교대 반복 → $P_{2025}$. *주기 4 발견*

- **출제 응용**: 두 변환의 *합성 주기*가 핵심. 학생이 $P_1, P_2, \ldots, P_T$ 직접 계산 → 패턴 발견 → 잉여류
- **함정**: 학생이 $P_n$을 *공식*으로 시도 → 변환 합성 표현 폭발. 직접 몇 단계 계산 후 *주기 인지*가 핵심
- **insights_used 표준 라벨**: I-PD (주기 발견) + (★ 5) I-MI (분기 케이스) + I-CON (조건 통합)
- **CM2-RF 1.12와의 차이**: 1.12는 *분수꼴 합성함수*의 주기. 1.19는 *점·도형*의 주기. 형식은 유사하나 대상이 다르고, 1.19는 *대칭이동*이라는 단원 특화 도구

### 1.20 평행이동·대칭이동의 합성 역산 (CM2-GM, v1.2 추가)

### 1.22 두 도형 평행이동 후 공통부분 형상·극값 (CM2-GM, v1.2 추가)

- **정의**: 함수가 주어진 정의역에서 *일대일대응*이 되도록 매개변수 결정. 본질은 *단조성 + 정의역·치역 끝점 매칭*. 분기 함수는 *분기 경계 연결성*도 추가

  - 일품 #07 (★ 4): $X = \{x \mid x \ge a\}, Y = \{y \mid y \ge -1\}$ + $f(x) = x^2 - 6x + 7$ 일대일대응 → $a$ 결정. *끝점 매칭* + 정점 위치
  - 일품 #08 [1등급, ★ 5]: 유한 집합 $X = \{0, 1, 2\} \to Y = \{2, 3, 4\}$ + $f(x) = ax^2 + bx + c$ ($a > 0$) 일대일대응 → $a - b + c$ 최댓값. *유한 일대일 분배* + 매개변수
  - 일품 #09 [서술형, ★ 5]: 정의역·공역 $\mathbb{R}$ + 분기 함수 ($|x| \ge 2$ → $2x$ / $|x| \le 2$ → $ax^2 + bx - 4a$) 일대일대응 $a$ 범위. *분기 함수의 연결 조건 + 양쪽 단조성*
- **출제 응용**: 정의역·치역의 *끝점 매칭* + (분기 함수면) *분기 경계 함숫값 일치 + 양쪽 단조 방향 일치*
- **함정**: 학생이 단조성만 확인 → 끝점 매칭 누락 → 매개변수 모든 값 받음 → 답 부정형
- **insights_used 표준 라벨**: I-EQV (일대일대응 = 단조성 + 끝점 매칭 동치) + (분기 함수면) I-MI (분기 케이스 분기) + (유한 집합) I-CON (배치 조건 통합)

### 1.24 함수방정식 (조건식만으로 함숫값 결정) (CM2-FN, v1.3 추가)
- **정의**: $f(x+y) = f(x) + f(y)$ / $f(xy) = f(x) + f(y)$ / $f(x)f(y) = f(x+y) + f(x-y)$ / $f(10n+k) = f(n) + k$ 등 *함수방정식*만으로 $f$의 특수값 결정. 본질은 *특수값 대입 ($x=0, x=y, x=-y$ 등)* → 점화식 발견
- **예시**:
  - 일품 #19 [서술형, ★ 4]: $f(xy) = f(x) + f(y)$ + $f(8) = 6$ → $f(1/8) + f(1) + f(4)$. *$x=y=1$ 대입으로 $f(1)=0$ → $f(2^k) = 2k$*
  - 일품 #20 (★ 4): $f(x)f(y) = f(x+y) + f(x-y)$ + $f(1) = 1$ → $f(4)$. *$x=y=0$, $x=y=1$ 등 다중 대입*
  - 일품 #21 [1등급 서술형, ★ 5]: $g \circ g = I$ + $2f(x) + f(g(x)) = 5x + 4$ → $3f(6) + 5g(6)$. *함수방정식 + 자기역함수 결합 (1.11과 융합)*
  - 일품 사고력 #04 [1등급, ★ 5]: $f(0) = 0$ + $f(10n + k) = f(n) + k$ → 보기 ㄱㄴㄷ. *자릿수 분해 점화* — $f(123) = f(12) + 3 = f(1) + 2 + 3 = 0+2+3 = 6$
- **출제 응용**: 함수방정식 좌·우변에 *특정 값 대입* → 새 식 → 점화식 발견 → 일반항 결정
- **함정**: 학생이 $f$를 *명시적*으로 구하려 함 (다항함수·일차함수 가정) → 식 폭발. *특수값 대입*이 핵심
- **insights_used 표준 라벨**: I-PD (점화식 패턴 발견) + I-EQV (특수값 대입 = 조건의 동치 변환) + (★ 5) I-CON (여러 조건 통합)

### 1.25 반복 합성 함수 (절댓값꼴) 자취·넓이 (CM2-FN, v1.3 추가)
- **정의**: $f(x) = |x - c| - d$ 같은 절댓값 함수의 $f^n$의 *자취*가 절댓값의 *접힘*으로 자기 닮음 복잡화 → 자취·넓이의 *점화식* 발견
- **예시**:
  - 일품 사고력 #06 (★ 5): $f(x) = |x-1| - 1$ + $f^1 = f, f^{n+1} = f \circ f^n$ + $f(1) + f^2(1) + \cdots + f^{10}(1)$. *직접 몇 단계 계산 후 주기·점화 패턴 발견*
  - 일품 사고력 #12 [1등급+, ★ 5]: 같은 $f(x) = |x-1| - 1$ + $y = f^n(x)$ 그래프와 x축으로 둘러싼 도형 넓이 $= an^2 + b$ → $a^2 + b^2$. *자취의 기하적 자기 닮음 + 넓이 일반항 점화*
- **출제 응용**: 절댓값 함수의 합성 → 자취가 *V자 접힘 반복* → *자기 닮음 패턴* 발견 → 점화식
- **함정**: 학생이 $f^2(x), f^3(x)$를 *식*으로 계산 → 분기 폭발 (절댓값 차수에 따라 분기 수 $2^n$). *그래프 시각화 + 자기 닮음 인식*이 핵심
- **insights_used 표준 라벨**: I-PD (자취 점화 패턴 발견) + I-RT (식 → 그래프 환원) + (★ 5) I-SYM (자기 닮음 활용)
- **CM2-RF 1.12와의 차이**: 1.12는 *분수꼴* 합성의 *주기 (T 발견)*. 1.25는 *절댓값꼴* 합성의 *자기 닮음 자취*. 1.12는 잉여류로, 1.25는 *점화식*으로 환원

### 1.26 함수와 역함수의 교점 (y=x 대칭성 활용) (CM2-FN, v1.3 추가)
- **정의**: *단조증가* 함수 $f$와 역함수 $f^{-1}$의 교점은 $y = x$ 위에만 존재 → $f(x) = x$ 다항방정식으로 환원. *단조 아닌* 경우 일반 교점도 가능 → 케이스 분기
- **예시**:
  - 일품 #25 [서술형, ★ 5]: $f(x) = \frac{1}{10} x^2 + a$ ($x \ge 0$) 역함수 $g$ + $f(x) = g(x)$ 서로 다른 양의 실근 *두 개* $a$ 합. *단조증가 ($x \ge 0$) → $f(x) = x$ 환원* + 두 근 조건
  - 일품 #27 [1등급, ★ 5]: 그림 그래프 + $f(f(x)) = f(x)$ 모든 실근의 합. *$f$의 부동점 통찰 (1.26 변형)*
  - 일품 사고력 #11 (★ 5): $f, g$ 일대일대응 + $(g \circ f^{-1})(a) = g^{-1}(b)$ → $a + b$ 최대·최소 합. *역함수 합성의 동치 변환*
- **출제 응용**: 교점 = $y = x$ 위 한정 통찰 → $f(x) = x$ 다항방정식으로 환원
- **함정**: 학생이 $f(x) = f^{-1}(x)$ 직접 시도 → $f^{-1}$ 구하기 + 양변 풀이 → 식 복잡화. *기하적 통찰* ($y = x$ 대칭) 인식 필요
- **insights_used 표준 라벨**: I-SYM ($y = x$ 대칭성) + I-EQV (교점 = $f(x) = x$ 해 동치) + (단조 아닌 경우 또는 $f \circ f = f$ 변형) I-MI (일반 교점 케이스 분기)
- **CM2-RF 1.11과의 차이**: 1.11은 *자기역함수 조건* ($f \circ f = x$가 *조건*). 1.26은 *역함수 교점*이 *결과* — 다른 통찰 (계수 폐쇄식 발견 vs 교점의 기하적 의미 발견)

### 1.27 부등식·조건 → 진리집합 환원 (CM2-ST, v1.4 추가)
- **정의**: 부등식·등식 조건 $p, q, r, \ldots$를 *진리집합* (수직선 범위·구간·점 집합)으로 환원해 $P \subset Q$·$P \cap Q$·$P \cup Q$ 등의 집합 연산으로 분석. 명제 진위·충분필요 판단의 *근본 도구*
- **예시**:
  - 일품 06 1등급 #04 [1등급, ★ 5]: 세 조건 $p: 0 \le x \le 5, q: x \ge a, r: x \ge 3$ + 명제 $(p \text{이고 } q) \to r$ 참 + 명제 $r \to (p \text{또는 } q)$ 참 → $a$ 범위 결정. *진리집합 $P, Q, R$ 환원 + 포함관계로 매개변수 양 끝점 결정*
  - 일품 06 1등급 #10 [1등급, ★ 5]: 세 조건 $p: x^2+x-2 \ne 0, q: x^2-2x+a \ne 0, r: 2x+b \ne 0$ + $p, q$가 $r$의 *충분조건이나 필요조건은 아님* → $a + b$. *부등식의 부정(≠) → 진리집합 차집합*
  - 일품 06 사고력 #01 [1등급+, ★ 5]: $p: x^2 - ax > x - a, q: ax + a - 1 < 0$ + 명제 $q \to \sim p$의 역이 참인 $a$ 범위 $\alpha < a < \beta$ → $\alpha + \beta$. *이차부등식 진리집합 + 역명제 진위*
- **출제 응용**: 명제 단원의 *기본 도구*. 모든 충분필요·진위 판단의 출발점
- **함정**: 학생이 조건을 *명제 형식*으로만 다룸 → 진리집합 환원 누락 → 매개변수 결정 식 폭발
- **insights_used 표준 라벨**: I-RT (조건 → 집합 표현 전환) + I-EQV (진리집합 포함관계 = 명제 진위 동치)

### 1.28 진리집합 포함관계 chain (충분·필요·필요충분 결정, CM2-ST, v1.4 추가)
- **정의**: 3 이상의 조건의 *진리집합 chain* ($P \subset Q \subset R$ 등)으로 매개변수 결정. 충분조건·필요조건·필요충분조건의 *방향*과 *집합 포함관계*의 *동치*를 활용

### 1.29 자기참조 집합 닫힘 + 주기 발견 (CM2-ST, v1.4 추가)
- **정의**: 집합 $A$가 *자기 자신을 참조하는 생성 규칙*을 만족 (예: $a \in A \Rightarrow \frac{1}{1-a} \in A$). 규칙 반복으로 *닫힘 주기* 발견 → 원소 개수 최솟값

### 1.30 부분집합 카드·합·곱 조건 결합 카운트 (CM2-ST, v1.4 추가)

### 1.31 새로운 집합 연산 정의 + 동치 변환 (CM2-ST, v1.4 추가)
- **정의**: 출제자가 *새로운 집합 연산* ($A * B$, $A \triangle B$ 등)을 정의 → 해당 연산의 *동치 변환* 또는 *카드 추론*

### 2.12 변수 명명 깊이 (naming_depth 메트릭, v3.7 신설, 2026-06-27)

  - 본 1회차 #7 (깊이 3): "방정식의 두 양수 해 $a$, $b$" → "두 해의 합 $a + b$" → "$a^2 + b^2$의 값"

### 4.6 명제의 부정·역·대우 분배 오류 (CM2-ST, v1.4 추가)
- **정의**: 학생이 명제 연산을 잘못 분배 — $\sim(p \wedge q) = \sim p \wedge \sim q$ (잘못, 정답은 $\sim p \vee \sim q$, 드모르간) 또는 *역과 대우 혼동*
- **표본**:

  - 일품 06 #06·07 (★ 5): 역·대우 진위 보기 — 일부 학생은 *역과 대우의 진위가 같다*고 잘못 (정답: *원명제와 대우*가 진위 같음)
- **자연 오답**: $\sim(p \wedge q) \overset{?}{=} \sim p \wedge \sim q$ 또는 $\sim(p \vee q) \overset{?}{=} \sim p \vee \sim q$
- **출제 응용**: 부정 분배·역·대우 진위 판별 시 *드모르간*과 *원명제 ↔ 대우* 동치를 학생이 *기계적으로* 적용하지 않고 *원리* 이해 필요

### 4.7 충분조건·필요조건 방향 혼동 (CM2-ST, v1.4 추가)
- **정의**: $p \to q$ ⟺ $P \subset Q$ ⟺ "$p$는 $q$의 충분조건" 등치 chain에서 *방향*을 잘못 매핑. 학생이 $P \subset Q$를 *$Q$가 $p$의 충분조건*으로 잘못
- **표본**:
  - 일품 06 #09 (★ 5): "$n(A \cup B) \le n(A)$는 $A \subset B$이기 위한 *필요조건*이다" 진위 — 학생이 충분/필요 혼동
  - 일품 06 #11 (★ 5): "$|x| < 1$이 $x < 1$의 *충분조건이지만 필요조건은 아니다*" — 정확한 방향 인식 필수
  - 일품 사고력 #02 (★ 5): 점수 표 (충분조건 1점, 필요조건 10점, 필요충분 100점) — 방향 혼동 시 점수 합 잘못
- **자연 오답**: $P \subset Q$일 때 "$q$가 $p$의 충분조건"으로 잘못 답
- **출제 응용**: 충분·필요 단일 방향 명제의 *진위 분기* 또는 *점수 시스템*으로 방향 혼동 변별
- **mnemonic 권장**: *작은 집합이 충분조건* ($P \subset Q$면 $p$가 더 강한 조건 → 충분)

### 4b.2 "개수가 $N$인" 조건 — 경계 다중 점검 (EQ·CB)
- **🔴 워딩 RED 금지**: 발문에 **"정확히 $N$"** 표현 사용 금지 ([[feedback_no_exactly_n]]·bank/마스터-지적/2026-06-25-정확히-N-금지.md). 본 패턴의 *카운트 한정 의미*는 **"개수가 $N$인"**·**"$N$개가 존재"**·**"오직 한 개"** 어구로만 표현.
- **정의**: 발문이 "정수해의 개수가 $N$인"·"두 근이 모두 자연수인" 등으로 *카운트 한정*을 부여하여 *$N$ 도달과 $N \pm 1$ 차단을 동시* 강제. 경계 부등호를 한 칸씩 옮겨 *$N-1$과 $N+1$ 모두 차단*되는 매개변수 범위를 산출.
- **표본**:
  - 9회차 #16 ($x^2 \le 25 \cap |x-k| \le 2$ 정수해 ≥ 3, $\sum k$): 정수해 카운트 후 경계 부등호 분기 검증
  - 마더텅 #340 ($\le 2$ 정수해 개수가 5인 자연수 $k$): 정수해 5개 도달 + 6개 차단 *양쪽* 점검
  - 1등급마스터 #334 (자연수 자유도 + 오직 한 정수): 경계 다중 검증
- **자연 오답**: 한쪽 경계만 점검 (예: $N$ 도달만, $N+1$ 차단 잊음) → 매개변수 범위가 1~2 칸 길어짐
- **출제 응용**: *카운트 한정 워딩*으로 학생에 *양쪽 경계 점검* 의무 부여. ★ 4 단답·★ 5 논술의 표준. **발문 어구는 워딩사전 §"카운트 한정" 우회 표현 의무 사용**.

### 4b.3 매개변수 범위 분기 + 각 범위 답 따로 (EQ·MX)
- **정의**: 매개변수 $k$의 범위 ($k > 0, k = 0, k < 0$ 등)별로 *답 자체가 다름*. 학생이 모든 범위 답을 *별도 계산 후 통합* (또는 한 범위만 조건 만족).
- **표본**:
  - 1등급마스터 #138 (매개변수 $a$ 부호별 사차방정식 근 개수)
  - 9회차 #4 ($|x-1| + |x-k| \ge k+1$ 모든 $x$): $k$ 범위별 좌변 최솟값이 다름 → 각 범위에서 부등식 점검
- **자연 오답**: 한 범위만 계산 (예: $k > 0$만) → 다른 범위 답 누락
- **출제 응용**: 매개변수에 *명시적 범위 단서 없음* (학생이 분기 발견 의무). ★ 4 객관식~단답 적합.

### 4b.4 여사건 vs 직접 카운트 일치 확인 강제 (CB)
- **정의**: 카운트 문제를 *직접*과 *여사건* 둘 다 가능한데 정답 합이 다르면 어느 쪽이 옳은지 *분기 누락 점검*. 답이 "여사건 = 전체 − 직접"으로 환원되거나, 학생이 직접·여사건 중 *함정 없는 쪽*을 선택해야 함.
- **표본**:
  - 9회차 #9 (1~9 카드 3장 짝수 ≥ 2장): 직접 (짝수 2장·3장) vs 여사건 (전체 − 짝수 0·1장). 답이 같은지 점검은 학생의 *케이스 누락 검증* 기제
  - 마더텅 #211 ("적어도 ~" 양형): 직접 케이스 합 vs 여사건 단일 계산
- **자연 오답**: 직접 카운트에서 한 케이스 (예: 짝수 3장) 누락 → 답 1~2 부족
- **출제 응용**: "적어도 $k$", "정확히 $k$ 이상" 워딩. 단순 ${}_nC_r$ 합산형이 아닌 *케이스 분리 후 합*.

### 4b.5 자기참조 — 매개변수가 결과 식에도 등장 (EQ·MX·CB)
- **정의**: 매개변수 $a, b, k$가 *조건과 결과 모두에 등장*. 학생이 답을 구한 후 *원 매개변수 값과 일치*하는지 *순환 검증*.
- **표본**:

### 4b.6 표면 모순 — 정의 (v3.7 원본 보존, v4.0 5종 인덱스 위에서 보강)
- **정의**: 발문에 *학생 직관과 충돌하는 조건* 부여 → 학생이 *기본 개념 환원*을 거쳐 *통찰 강제 갱신*. I-VF (Verification-Forced)와 I-XU·I-EQV 결합 패턴. 표면 읽기로는 "모순 같은데?"이지만 *적절한 개념 환원* 시 *유일 케이스로 압축*되어 답 도출.
- **표본**:

- **자연 오답**: 표면 모순으로 *답 없음* 선언 → 환원 단계 누락 → 답 도출 실패

- **출제 시 발문 어구**: [[발문어구사전]] §1.2 조건 부여 어구 사용. 모순 *명시* 금지 (학생이 *발견*해야 함).

### v2 §1.2 축 2 (발문 워딩 11 패턴)

축 2 워딩 패턴은 그 자체로 *깊이 추정에 영향 미미*. 발문 어구로는 깊이 1~2 default. 단, 다음 워딩은 깊이 3 *후보 신호*:
- 2.3 "~의 개수가 ~가 되도록 하는 ~" — 정수 자유도 제거 → 깊이 3 후보
- 2.4 "~에 관계없이 항상" — 보편화 → 깊이 3 후보
- 2.5 "정확히 ~개" — 카운트 한정 → 깊이 3 후보

### §3.3 P-FG3 — 구간 $[k-a, k+a]$ 슬라이딩 max·min 매개변수 추론
- **원형**: 마더텅 14회 8번 (2024 6월학평 30번)
- **본질**: 두 미정 이차 $f$, $g$ + (가) $f(x) \le 0 \le g(x)$ + (나) 구간 $[k-2, k+2]$에서 $f$의 max와 $g$의 min이 같게 되는 $k$의 *min 0, max 1* + (다) $f(x) = f(0)$ 모든 실근 합 음수 → $f(3) + g(11)$
- **변별 통찰**: 구간 *슬라이딩*에서 max·min의 *동적 변화*. (나)의 "$k$의 min·max"가 그래프상 *꼭짓점·축* 위치를 결정. (다)가 *축 부호*를 결정. 세 조건이 *함수 형태* 완전 결정.
- **회피 카운팅**: "정수 개수" 결론식 X. "$f(3) + g(11)$" 결합 결론식 ✓
- **default 깊이**: 3 (★ 5 최상위)
- **출제 응용**: 구간 슬라이딩 어구 ([[bank/발문어구사전]] §12) + 3조건 박스 + 결합 결론.

### §3.4 P-FG4 — $\{x-f(k)\}\{x-g(k)\}=0$ 매개변수 함수 그래프 + 근 개수
- **원형**: 마더텅 15회 8번 (2023 9월학평 21번)
- **본질**: 미정 이차 $f$, 이차항 계수 1인 이차 $g$ + $\{x-f(k)\}\{x-g(k)\}=0$이 *서로 다른 두 실근 0, 4*를 갖는 $k$ 개수 3 → $f(2)=4$일 때 $g(8) - f(8)$
- **변별 통찰**: 방정식의 근 = $f(k)$ 또는 $g(k)$. "서로 다른 두 실근 0, 4" = $\{f(k), g(k)\} = \{0, 4\}$. *$k$ 개수 = 3*은 $f(k)=0, f(k)=4, g(k)=0, g(k)=4$의 *교점 분포 추론*. → 함수 형태 결정
- **회피 카운팅**: "$k$ 개수 3"은 *추론 단서*로 사용 (카운팅 결론식 X). 결합 결론식 $g(8) - f(8)$ ✓
- **default 깊이**: 3 (★ 5 최상위)
- **출제 응용**: $\{x-f(k)\}\{x-g(k)\}$ 형 매개변수 곱 부등식·방정식 + 근 위치 단서 + 결합 결론.
