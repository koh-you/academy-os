## 1. 4축 정의

### 축 S1 — 풀이 단계 분배 (Step Distribution)
`\step{N}`의 명시·균형·정합. 통찰형 ★ 4·5 풀이는 단계가 많고, 절차형 ★ 3은 적음. 단계 수가 *난이도와 정합*되어야 함. **3 패턴**.

### 축 S2 — 자연 한국어·자세도 (Natural Korean & Verbosity)
"~한다/~이다" 책 말투 + 압축 금지. 학생이 *왜* 그렇게 푸는지 따라가게. **3 패턴**.

### 축 S3 — 수식·디자인 정합 (Math Layout & Design)
디스플레이 배치·인라인 행렬 분리·줄바꿈 wrapper. *수식 가독성*. **4 패턴**.

### 축 S4 — 답·검증 마무리 (Answer Closure)
`\begin{answerbox}` + 마지막 \step + 빠른 정답표. *답의 명확한 클로저*. **3 패턴**.

## 2. 축 S1 — 풀이 단계 분배 (3 패턴)

### S1.1 \step{N} 모든 단계 명시
- **정의**: 모든 풀이 단계가 `\step{N}`로 번호화. 본문 산문 속에 식이 *흘러내리지 않음*
- **표본**: 1회차-답지.tex 모든 풀이 (1~25번) — \step 매크로 일관 사용
- **위반 신호**: 한 \step에 *5개 이상의 식 변환* 또는 \step 없는 식 나열
- **★ 별 단계 수 가이드**:
  - ★ 1·2: 2~3 단계
  - ★ 3: 3~5 단계
  - ★ 4: 5~7 단계
  - ★ 5: 7~10 단계 (10 초과는 풀이 압축 검토)

### S1.2 한 단계당 1~2개 식 + 짧은 설명
- **정의**: 각 \step은 *짧은 한국어 설명 + 1~2개 식 변환*. 학생이 한 단계당 *하나의 통찰·도구*를 따라감
- **표본**:
  - 1회차 #1 \step{1}: "첫 부등식 $\frac{x-3}{4} \ge a$에서 $x \ge 4a+3$." (1 변환)
  - 1회차 #2 \step{1}: "$A+B = \begin{pmatrix}\ldots\end{pmatrix} = \begin{pmatrix}3 & 2 \\ 2 & 5\end{pmatrix}$." (1 디스플레이)
- **위반 신호**: 한 \step에 *3개 이상의 식 변환* 또는 *5줄 이상의 한국어 설명*

### S1.3 첫 단계는 진입점·도구 식별
- **정의**: \step{1}이 *문제 해석·조건 정리·핵심 도구 식별*. 학생이 *어디서 시작할지* 명시
- **표본**:
  - 1회차 #7 \step{1}: "절댓값 안의 식의 부호가 바뀌는 점을 먼저 찾는다" → 진입점 명시
  - 1회차 #3 \step{1}: "먼저 $A^2$를 행렬곱의 정의대로 직접 계산하여 우변의 행렬과 비교할 준비를 한다" → 도구 식별
- **위반 신호**: \step{1}이 *답 계산부터 시작*하거나 *진입점 없이 식 변환*

## 3. 축 S2 — 자연 한국어·자세도 (3 패턴)

### S2.1 "~한다/~이다" 책 말투 일관
- **정의**: 동사 어미 "~한다 / ~이다 / ~된다 / ~이라 하자" 일관. *존댓말·반말 혼용 금지*
- **표본**: 1회차-답지.tex 전체 — "구한다", "정리한다", "비교하여 본다" 일관
- **위반 신호**: "구합니다", "~할게요", "~봅시다" 등 존댓말 / "구해", "풀어" 등 반말
- **참조**: [[feedback-natural-korean-wording]]

### S2.2 자세한 설명 + 압축 금지
- **정의**: 풀이는 *왜* 그렇게 푸는지 짧게 설명. "계산 생략", "정리하면 ~", "...로 정리되어" 같은 *압축 표현 금지*
- **표본**: 1회차 #6 \step{1}: "(가)에서 $f(2)=0$이므로 $x=2$가 근이다. (나)에서 $\sqrt{2}-1$이 근이고 계수가 유리수이므로 켤레 $-\sqrt{2}-1$도 근이다."  *왜 켤레가 근인지* 설명
- **위반 신호**: "정리하면 답은 N이다" / "계산하면 ~" 같은 *단계 점프*
- **참조**: [[feedback-solution-verbosity]]

### S2.3 압축 신조어·비표준 학습 용어 금지
- **정의**: "비이웃", "분기" (학습자 비표준), 한자어식 압축 명사 금지. *자연 한국어 풀어쓰기*
- **위반 예시**:
  - "비이웃" → "이웃하지 않는" 또는 "서로 떨어진"
  - "분기" (case branching 의미) → "경우를 나누어"
- **참조**: [[feedback-no-compressed-terms]]

## 4. 축 S3 — 수식·디자인 정합 (4 패턴)

### S3.1 디스플레이 수식 뒤 짧은 텍스트 금지
- **정의**: `$$...$$` 디스플레이 직후 *50자 미만 한국어 텍스트 단독* 금지. 디스플레이는 *문장 끝* 또는 *다음 단계 시작*에 배치
- **표본**: 1회차 #5 \step{3}: "$f(x) = (x - 2)^{2}(x^{2} + 4x + 12)$." → 마침표로 문장 끝 (적합)
- **위반 신호**: `$$...$$` 직후 "가 성립할 때 ~" / "의 값을 구하시오" 단독
- **참조**: [[feedback-display-math-layout]]

### S3.2 \step 안 디스플레이 뒤 텍스트 금지
- **정의**: 한 \step{N} 안에서 *본문 → 디스플레이 → 추가 텍스트* 순서 금지. 디스플레이 뒤 결론은 *다음 \step{N+1}*로 분리
- **표본**: 1회차 #5 \step{3}~\step{4}: \step{3}은 디스플레이로 끝, \step{4}는 새 도구 시작
- **위반 신호**: 한 \step 안에 "식 → 디스플레이 → 정리하면 ~" 3단 구조
- **참조**: [[feedback-step-display-then-text-forbidden]]

### S3.3 인라인 행렬·긴 결과식 디스플레이 분리
- **정의**: 페널티 환경에서 인라인 행렬·긴 결과식이 *줄 끝 빈공간*을 유발하면 디스플레이로 분리
- **표본**: 1회차 #3 \step{1}: $A^2$ 계산은 디스플레이 `$$ ... $$` 사용 (인라인 회피)
- **위반 신호**: 발문·풀이 본문에 인라인 `$A = \begin{pmatrix}\ldots\end{pmatrix}$` 컬럼 폭 초과
- **참조**: [[feedback-inline-matrix-display-split]]

### S3.4 \nob·\cond 줄바꿈 wrapper 사용
- **정의**: `\nob{$x$축}`·`\cond{$x \ne 0$}` 등 변수+한글·단서 조건 wrapping
- **위반 신호**: `$x$축` 같이 wrapping 없이 줄 끝 분리 가능 형태
- **참조**: CLAUDE.md §"줄바꿈 방지" 참조

## 5. 축 S4 — 답·검증 마무리 (3 패턴)

### S4.1 \begin{answerbox} 정답 박스
- **정의**: 각 풀이 시작 직후 `\begin{answerbox}\sffamily\bfseries 정답: ⑤ $\frac{4}{3}\pi$\end{answerbox}` 등으로 정답 명시. 객관식·단답·서술 모두
- **표본**: 1회차-답지.tex 25문 전수 — answerbox 일관 사용
- **위반 신호**: answerbox 없이 풀이 시작 / 답 박스 위치가 풀이 끝 (산만)

### S4.2 마지막 \step 답 도출 + 정답 강조
- **정의**: 마지막 \step에서 *답 명확 도출*. 선택: `\textbf{정답 N}` 또는 박스에 답
- **표본**: 1회차 #4 \step{6}: "합의 법칙으로 $2+5+4+1 = 12$." 답 명확
- **위반 신호**: 마지막 \step이 *식 계산만* + 답 명시 없음

### S4.3 빠른 정답표 (quickgrid) 답지 첫 페이지
- **정의**: 답지 첫 페이지에 `quickgrid` 환경으로 모든 문제의 *답만* 한 줄씩
- **표본**: 1회차-답지.tex line 9~15 — 25문 5×5 그리드
- **위반 신호**: 빠른 정답표 누락 / 답 형식 불일치 (객관식 ⑤ vs 단답 12)
- **시험지 답지 한정**: 유형편·연습편 답지는 빠른 정답표 *권장*만
- **시판 양식 차이**: 일품은 *별책 〈빠른 정답 찾기〉* 제공. 우리 책 답지는 *동일 PDF 내* quickgrid

## 5.5 카테고리 C — 시판 옵션 패턴 (v0.1 신규, 우리 책 채택 검토)

시판 해설지(일품 22개정 표본)에서 발견된 *추가 양식 옵션*. 우리 책 답지에 *채택 시* 교육 효과 향상 기대.

### S5.1 채점 기준 표 (서술형 풀이, 신규)
- **정의**: 서술형 풀이 끝에 *채점 기준 + 부분 점수 비율* 표 제공. 학생이 자기 풀이의 *부분 점수*를 확인 가능
- **시판 표본 (일품 해설지)**:
  - **일품 03 함수 #16 [서술형] 풀이 끝**:
    ```
    채점 기준                                  비율
    1. g(h(x)) = g(x/2)임을 알 수 있다.       40%
    2. 함수 h(x)를 구할 수 있다.              40%
    3. (h ∘ h)(8)의 값을 구할 수 있다.        20%
    ```
  - **일품 03 함수 #19 [서술형] 풀이 끝**: 4단계 채점 기준 표
- **출제 응용**: 서술형 풀이에 *단계별 부분 점수* 명시 → 학생의 *자기 평가 능력* 향상
- **우리 책 채택 안 (v0.2 결정)**: 시험지(testpaper)의 *논술형* 풀이에 채택 검토. \soltitle 다음에 \examscore 매크로 신설 가능
- **세련도 보너스**: 채택 시 서술형 답지의 *교육적 가치* ↑

### S5.2 "다른 풀이" 옵션 (★ 4·5 한정, **마스터 2026-06-22 채택**)
- **정의**: 한 문제에 *두 가지 풀이*를 제시. 표준 풀이 + 더 우아한·짧은 *다른 풀이*
- **시판 표본 (일품 해설지)**:
  - **일품 07 함수 #19 풀이 끝**: "다른 풀이" 명시 + 더 우아한 풀이 1줄 ($f(1/8) + f(1) + f(4) = f(1/8 \cdot 1) + f(4) = f(1/8 \cdot 4) = f(1/2)$ 한 줄 환원)
  - **일품 01 도형의 방정식 #07 풀이 끝**: "다른 풀이" — 외심 좌표 다른 환원
- **출제 응용**: 표준 풀이 + 다른 풀이 = 학생이 *통찰의 다양성* 학습. ★ 4·5에 *권장* (의무 아님)

  - **일품 다수 풀이**에 [1등급 비밀노트] 박스

## 6. 답지 세련도 점수 산정 (refinement_score_sol)

### 점수 산정
- 답지 1편 전체의 *모든 축 패턴 적용 여부* 평가
- $\text{refinement\_score\_sol}$ = (적용된 패턴 개수) / (총 패턴 수 13) × 100점 만점
- **기준**:
  - **90+**: 우수 (모든 축 + 거의 모든 패턴 충족)
  - **75~89**: 표준 (4 축 모두 1개 이상 패턴 적용)
  - **60~74**: 보강 권장 (특정 축 누락)
  - **<60**: 재작성 권장

### 답지 1편 단위 의무 패턴 (v0.1 권장)
- S1.1 \step 명시 (모든 풀이)

위 6 패턴은 답지 1편 *최소 요건*. 모두 충족 시 ★ 표준 답지.
