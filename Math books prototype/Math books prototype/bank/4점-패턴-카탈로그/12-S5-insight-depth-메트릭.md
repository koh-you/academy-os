# 12. S5 insight_depth 메트릭 정의

> **상태**: **v1.0 정식 효력 (2026-06-23 마스터 승인)**. S5 카탈로그 v2 *2단계* 산출물. 산식 = **가중 합산 (max × 2 + average)** · 임계값 **★ 5 = score ≥ 7** · **★ 5 최상위 = score ≥ 8.5 + max = 3 + count ≥ 5**. 88문 전체 깊이 채점 완료 (§5). 3단계 (03 카탈로그 v2 + bank/anchors + problem-review v3.2 + schema v3.2) 진입.
> **목적**: schema v3.0의 *단순 insight 카운트*만으로는 "★ 5 통찰 위장 정교도"를 측정 불가 → 각 통찰 단계의 **깊이 1·2·3** 채점 가이드를 도입하여 *insight_depth_score* 산출.
> **승인 절차**: v0.1 골격 → v0.2 산식 1차안 → v0.3 가중 산식 + 88문 전체 채점 → **v1.0 정식 효력 (임계값 확정)** → v1.1 (3단계 완료 후 보강 예정).

## 1. 진입 배경 (2026-06-23 S5 2단계)

### 1.1 schema v3.0 단순 카운트 한계
- `insight_score = 라벨링된 통찰 단계 수` (1단계당 +1) — 통찰 *질* 측정 불가
- 동일 insight_score = 4 슬롯이라도, 한 슬롯은 *진정 변별 통찰*, 다른 슬롯은 *진부한 절차 호출*. 둘이 같은 ★ 등급으로 처리됨

### 1.2 동화고 1회차 그룹 B 검수에서 격상
- ★ 5 슬롯이 *insight_score 충족했음에도 쉬움*. 통찰 위장이 학습된 학생에게 쉽게 노출되는 패턴
- 03 카탈로그 v1.6의 220문+은 시판 책 1등급+사고력 기반이라 *진정 변별 표준 부족*

### 1.3 11번 산출물 (마더텅 최고난도 88문) 기반 새 메트릭
- 88문 ★ 5 최상위 16문 = insight_score ≥ 5 슬롯이지만, *각 통찰의 깊이*는 차등 존재
- 88문 통계 (§7.3)의 "6대 패턴"이 깊이 점수 도출의 직접 근거

## 2. insight_depth 정의 (1·2·3점)

### 2.1 채점 원칙
각 *라벨링된 통찰 단계*에 깊이 점수 1·2·3 부여:

| 깊이 | 명칭 | 정의 | 학습된 학생 발견 가능성 |
|---:|---|---|---|
| **1** | 얕은 통찰 (Shallow) | 단원 표준 절차의 *명시적 호출*. 발문에 "사용해" 또는 표준 정리 적용 | 거의 모두 발견 |
| **2** | 중간 통찰 (Standard) | 위장된 호출. 발문에 *간접 단서*만 있어 학생이 통찰 *연결* 필요 | 상위권 발견 (변별 시작) |
| **3** | 깊은 통찰 (Deep) | 진정 변별. 위장이 정교하여 *호출 자체*를 학생이 *재구성*해야 함 | 최상위만 발견 (진정 변별) |

### 2.2 깊이별 위장 정교도 기준

**깊이 1** (얕은):
- 발문에 "근과 계수의 관계를 이용하여 ~" 같은 *호출 지시* 명시
- 단원 표준 문제 패턴 그대로 (보기·예제와 거의 동일 구조)
- 통찰 *적용 방식*이 자명

**깊이 2** (중간):
- 위장: 도형 → 식 / 식 → 도형 / 절댓값 분기 / 케이스 분류 등 *학습된 표준 위장* 사용
- 단원 내 *두 개념 결합* (예: 근과 계수 + 부호 분석)
- 통찰 *적용 시점*은 자연스럽지만 *전개*가 정교

**깊이 3** (깊은):
- 위장: 통찰 호출 자체가 *재구성 단계* 필요 (예: 케일리-해밀턴을 *직접 적용*이 아닌 행렬 항등식 조작으로 *유도*)
- 단원 간 결합 (I-XU) 또는 *비표준 통찰 호출* (I-PD의 주기 *발견* 등)
- *조건 자유도 제거*가 핵심 — 정수 카운트·임계점·접점 동시 만족

## 4. insight_depth_score 산식 (마스터 확정 2026-06-23 — 가중 합산 채택)

### 4.1 산식 (확정 v0.3)
```
insight_depth_score = max(depths) × 2 + average(depths)
```

- **max × 2**: 가장 깊은 통찰이 *2배 가중*. 한 슬롯에 깊이 3 통찰이 있으면 6점 보장
- **+ average**: 통찰 단계의 평균 깊이가 보조 점수. 통찰 양의 영향
- 점수 범위: 최소 3점 (깊이 1만 단독) ~ 최대 9점 (모두 깊이 3)

**핵심 효과** (단순 합산과 차이):
1. 깊이 1만으로 채워진 슬롯은 max=1 → 최대 점수 = 1×2 + 1 = **3점** (★ 5 진입 자동 차단)
2. 깊이 3 통찰 1개 + 깊이 1 다수 = max=3 → 6점 이상 보장
3. ★ 4 천장 정책 *불요* — 산식에 *진정 변별 1개 필수*가 내재

### 4.2 ★ 산정 알고리즘 v3.2 (마스터 확정 2026-06-23)

기존 schema v3.0:
```
insight_score = 통찰 단계 카운트
★ 5 = insight_score ≥ 4
```

**신규 v3.2 (확정)**:
```
insight_depth_score = max(depths) × 2 + average(depths)

★ 5 최상위 = depth_score ≥ 8.5 + max = 3 + insight_count ≥ 5
★ 5        = depth_score ≥ 7                 (max ≥ 3 자연 강제)
★ 4        = depth_score 5 ≤ score < 7       (max = 2 슬롯 또는 max=3 + count 미달)
★ 3 절차형 = depth_score < 5                  (max = 1 슬롯 + 양적 부족)
```

**임계값 7 채택 근거** (88문 분포 §6.1):
- 점수 **8.00~8.24 자연 공백**이 ★ 5/★ 4 분리선
- 임계 7로 설정하면 미래 슬롯 (가능한 score 7.0~7.99)도 ★ 5 인정 — 진정 변별 확보
- max = 3 필수가 자동 강제 (max=2 최대 = 6.00 < 7)
- 8.5 + count ≥ 5 = 진정 변별 정점 (88문 중 19문, 22%)

### 4.3 가중 합산의 자동 보정 효과 (★ 4 천장 정책 불요)

가중 산식 자체가 다음을 자동 보장:
- **깊이 1만 채워진 슬롯**: max=1 → 점수 ≤ 3 → ★ 4 또는 ★ 3 자동 강등
- **깊이 2 통찰 다수**: max=2 → 점수 ≤ 6 → ★ 4
- **깊이 3 통찰 1개**: max=3 → 점수 ≥ 6 (보조 통찰 있을 시 7+)
- **깊이 3 통찰 다수**: max=3 + 평균 ≥ 2 → 점수 ≥ 8 (★ 5 최상위 후보)

**진정 변별 1개가 필수 조건이 됨** — 별도 ★ 4 천장 정책 작성 불요.

### 4.4 ★ 5 최상위 분리 (보너스 라벨)
- depth_score ≥ 8 + max = 3 + insight_count ≥ 5 → ★ 5 *최상위* 라벨
- 의미: *진정 변별 깊이 3* + *통찰 양 5개 이상* — 다층 진정 변별
- bank/anchors의 *대표 앵커* 1순위 후보
