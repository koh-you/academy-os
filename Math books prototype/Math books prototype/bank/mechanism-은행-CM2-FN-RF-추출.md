## FN (함수) Mechanism 13개

### FN-M1. 함수 정의 · 판정 (정의역·공역·치역 대응)
- **원리**: 정의역의 모든 원소가 공역의 유일한 원소에 대응 · 정의역 제한으로 함수 조건 부여
- **심층 조건**:
  - 정의역의 각 원소가 정확히 하나의 함숫값
  - 공역과 치역의 구별 (공역 ⊃ 치역)
  - 치역 조건 해석 (원소 $k$개·합·극값 조건 동시)
- **자유도**: 정의역 구간 선택 (경계 포함/제외)·치역 해석 우선순위
- **앵커**: 고쟁이-CM2-CH07-STEP2-#517, #519
- **오답 유도**: 공역·치역 혼동·정의역 제한 없이 함수 판정·부분집합 개수 오계산

### FN-M2. 특수함수 판정 (일대일·일대일대응·항등·상수)
- **원리**: 특수함수 정의를 조건으로 함수값을 단계적 결정. 일대일대응 = 정의역 크기 = 공역 크기 = 치역 크기
- **심층 조건**:
  - 일대일함수: 서로 다른 입력 → 서로 다른 출력
  - 일대일대응: 일대일 + 치역 = 공역
  - 항등함수: 모든 $x$에서 $f(x) = x$
  - 상수함수: 모든 $x$에서 $f(x) = k$
- **자유도**: 여러 조건 교차 시 소거 순서
- **앵커**: 고쟁이-CM2-CH07-STEP2-#526~#534
- **오답 유도**: 항등함수도 일대일대응임 놓침·상수함수 치역 크기 오판·두 식으로 정의된 함수 경계값 오판

### FN-M3. 합성함수 정의 조건 · 합성 가능성 (치역 ⊂ 정의역)
- **원리**: $(f \circ g)(x)$ 정의되려면 $g$의 치역이 $f$의 정의역에 포함
- **심층 조건**:
  - 정의역 → 치역 → 정의역 체인 확인
  - 이차함수 계수 결정 시 여러 경우 분류
  - "모든 함수에서 성립" vs "존재하는 함수만"
- **자유도**: 경우의 수 분류·계수 결정 방식
- **앵커**: 고쟁이-CM2-CH07-STEP2-#536, #541
- **오답 유도**: $f$ 정의역·$g$ 치역 방향 혼동·경우 누락

### FN-M4. 합성함수 · 반복합성 · 사이클 구조 ($f^n$ 주기)
- **원리**: 반복 합성 $f^n = I$가 되는 최소 $n$ 찾기 → 순열 사이클 분해 (각 사이클 길이 lcm)
- **심층 조건**:
  - 순열을 사이클로 분해 (1주기: 고정점·2주기: 대합·3주기 이상)
  - 지수 나머지 활용 ($a^{100}$에서 100 mod 주기)
  - 반복합성 궤도 추적
- **자유도**: 사이클 구조 파악·지수 mod 계산
- **앵커**: 고쟁이-CM2-CH07-STEP2-#542~#548, #562
- **오답 유도**: 주기를 1 어긋남·지수 mod 실수·사이클 분해 오류

### FN-M5. 합성함수 방정식 실근 · 치환 두 단계 ($f(x)=t \to f(t)=\ldots$)
- **원리**: $(f \circ f)(x)$ = 조건 형태 방정식을 $f(x) = t$로 치환 → $f(t)$ = 조건으로 두 단계 분해
- **심층 조건**:
  - $f$의 고정점 개념 ($f(x) = x$의 해)
  - 각 $t$값에서 $f(x) = t$의 실근 개수 (그래프 교점)
  - 구간별 함수 정의 시 경계값 누락 방지
- **자유도**: 치환 선택·그래프 그리기 vs 직접 계산
- **앵커**: 고쟁이-CM2-CH07-STEP2-#549~#555 · STEP3-#586
- **오답 유도**: 치환 후 원식 대입 실수·구간별 역상 누락·대칭 미활용

### FN-M6. 역함수 존재 조건 · 일대일대응 판정
- **원리**: 역함수 존재 ⟺ 일대일대응. 이차함수는 축 기준 증가 구간 선택. 두 식으로 정의된 함수는 양쪽 구간 단조성 + 접합점 연속성
- **심층 조건**:
  - 이차 최솟값(최댓값)과 정의역 경계 대응
  - 두 식으로 정의된 함수: 각 구간 일대일 + 접합점 함숫값 같음 + 치역 = 공역
  - 자기역상 조건 ($f: X \to X$에서 $f(k) = k$)
- **자유도**: 정의역 경계값 선택·매개변수 부등식 방향
- **앵커**: 고쟁이-CM2-CH07-STEP2-#533~#534, #567, #571
- **오답 유도**: $k \ge 1$ vs $k > 1$ 경계 혼동·두 조건 (일대일 + 치역=공역) 중 하나 누락

### FN-M7. 역함수 관계식 · 매개식 결정 ($f^{-1}(a) = b \Leftrightarrow f(b) = a$)
- **원리**: 역함수 조건의 양방향 대응을 이용하여 함수식 매개변수 결정
- **심층 조건**:
  - 역함수 정의 양방향 대응
  - 매개식에서 특정 $x$ 값 대입 (전략적 선택)
  - 두 개 이상의 역함수 관계 연립
- **자유도**: 대입할 $x$ 값 선택·역방향 해석 우선순위
- **앵커**: 고쟁이-CM2-CH07-STEP2-#557~#560, #565~#566
- **오답 유도**: 역함수 방향 혼동·$x$ 값 선택 실수·부호 실수

### FN-M8. 역함수 그래프 · $y=x$ 대칭 · 고정점
- **원리**: 일대일대응 함수 $f$와 역함수 $f^{-1}$의 그래프는 $y=x$에 대해 대칭. 두 그래프 교점은 $y=x$ 위 (즉 $f(x) = x$의 해)
- **심층 조건**:
  - $y=x$ 위의 점 $(a, a)$는 대칭 교점
  - $f(f(x)) = x$인 대합 함수 → $f$ 기울기 $= -1$ (다항)
  - 점·직선 거리·대칭점 좌표 계산
- **자유도**: 대칭 활용 vs 직접 계산·기울기 1 접선 조건 해석
- **앵커**: 고쟁이-CM2-CH07-STEP2-#568~#574 · STEP3-#588
- **오답 유도**: $y=x$ 대칭 놓침·$f(x) = x$ 해 누락·거리 공식 실수

### FN-M9. 함수 개수 · 부분집합 · 여사건 (카운팅 도구)
- **원리**: 방정식 해집합 → 부분집합 개수 (혹은 $2^n - 1$). 여사건으로 조건 위반 경우 제외. 일대일함수는 순열 $P(n,k)$·전사는 스털링 수
- **심층 조건**:
  - 방정식 해 $k$개 → 부분집합 개수 $2^k$
  - 곱 = 0 조건 → 여사건 (모든 인수 ≠ 0의 여집합)
  - 일대일함수·전사함수
- **자유도**: 포함배제 vs 여사건·분할 유형 열거
- **앵커**: 고쟁이-CM2-CH07-STEP2-#575~#584 · STEP3-#591, #593
- **오답 유도**: 공집합 포함/제외 혼동·중복 카운트·분할 중복

### FN-M10. 함수방정식 · Cauchy형 · 소인수분해
- **원리**: 함수방정식 $f(x+y) = f(x) + f(y)$ (Cauchy)·$f(xy) = f(x)f(y)$·$f(2n) = f(n)$ 재귀 등을 초기 대입으로 기본값 유도 후 구조 파악
- **심층 조건**:
  - 기본값 대입 ($f(0), f(1)$)
  - 부등식 함수방정식은 양방향 결합으로 등호 강제
  - 소인수분해 vs 십진 표현
- **자유도**: 첫 대입 $x, y$ 선택·일반화 도출 방식
- **앵커**: 고쟁이-CM2-CH07-STEP2-#520~#524, #540 · STEP3-#585, #597~#599
- **오답 유도**: $f(0)$ 미결정·$-1$ 계수 누락·반례 구성 실패

### FN-M11. 두 식으로 정의된 함수 · 경계값 연속성 · 이차 축 위치
- **원리**: 두 식으로 정의된 함수 일대일대응 조건: 각 구간 일대일 + 경계점 연속 (또는 점프) + 치역 = 공역. 이차 축이 구간 경계 기준으로 증감 결정
- **심층 조건**:
  - $x < a$·$x \ge a$ 경계 함숫값 연속 또는 순서 보존
  - 이차 축 $a/2$ 기준
  - 양쪽 최댓값·최솟값 대응
- **자유도**: 축 위치 범위 결정·경계값 함숫값 계산
- **앵커**: 고쟁이-CM2-CH07-STEP2-#531~#532 · STEP3-#603, #608
- **오답 유도**: 축 위치 조건 놓침·경계 포함/제외 혼동·부등식 방향 실수

### FN-M12. 역함수 반복 · 두 식으로 정의된 함수 역 계산
- **원리**: 두 식으로 정의된 함수의 역함수는 구간별 계산. $f(x) = y$에서 $x$를 $y$로 표현 후 교환. 반복 계산 시 각 단계 구간 판별
- **심층 조건**:
  - 각 $y$값에 대응하는 $x$의 구간 파악
  - 반복 후 결과값이 어느 구간인지 재판별
  - 부분 개수 증가 ($f^{-1}$인 식 = $f$ 조각)
- **자유도**: 순차 대입 vs 패턴 인식·반복 횟수 mod 계산
- **앵커**: 고쟁이-CM2-CH07-STEP2-#561~#562, #571
- **오답 유도**: 구간 경계 판정 오류·역함수 식 유도 실수·반복 방향 혼동

### FN-M13. 역함수 존재 · 매개변수 조건 · 3식 연립
- **원리**: 두 식으로 정의된 함수 역함수 존재 = (1) 각 구간 일대일 + (2) 경계점 연속·단조 + (3) 치역 = 공역. 세 조건이 매개변수를 연립 제약
- **심층 조건**:
  - 일대일: 각 구간 축 조건 또는 기울기 부호
  - 연속·단조: 경계값 = 또는 순서 보존
  - 치역: 양쪽 극값 대응
- **자유도**: 조건 순서·매개변수 범위 교집합
- **앵커**: 고쟁이-CM2-CH07-STEP3-#595, #603
- **오답 유도**: 접합 조건 누락·부등식 범위 좁히기 실수·축 위치 조건 오류

## RF (유리·무리함수) Mechanism 7개

### RF-M1. 유리함수 $y=\frac{ax+b}{cx+d}$ · 점근선 · 대칭중심
- **원리**: 점근선은 $x = -\tfrac{d}{c}$ (수직)·$y = \tfrac{a}{c}$ (수평). 대칭중심은 두 점근선의 교점. 이 점 기준 180도 회전 대칭
- **심층 조건**:
  - 점근선 이동에 따른 함수 평행이동
  - 대칭중심에서 수직 거리 (원 반지름 최소)
  - 사분면 판정 (분자·분모 부호로 $a, c$ 부호 결정)
- **자유도**: 점근선 조건 해석 (필수 vs 충분)·사분면 케이스 분류
- **앵커**: 고쟁이-CM2-CH08-STEP2-#646~#671 · STEP3-#699
- **오답 유도**: 점근선 계산 오류·대칭중심 놓침·사분면 판정 오류

### RF-M2. 유리함수 위 점과 도형 · 산술기하평균 (최적화)
- **원리**: 유리함수 위 점 $(x, y)$에서 좌표축에 내린 수선의 발로 만든 직사각형 넓이·두 점 사이 거리 최소화 → $t + k/t \ge 2\sqrt{kt}$ (AM-GM)
- **심층 조건**:
  - 넓이 = $xy$ 형태 → $t + c/t$ 꼴 정리
  - 등호 조건: $t = \sqrt{c}$
  - 정의역 제한 확인 ($x > 0$)
- **자유도**: 변수 치환·분석 기하 vs AM-GM
- **앵커**: 고쟁이-CM2-CH08-STEP2-#660, #661
- **오답 유도**: AM-GM 등호 조건 미확인·정의역 밖의 답·기울기 혼동

### RF-M3. 무리함수 $y=\sqrt{ax+b}+c$ · 정의역·치역·평행이동
- **원리**: 무리함수 $y = \sqrt{ax+b} + c$. 정의역 $ax+b \ge 0$. 치역 $y \ge c$ ($a>0$). 평행이동 $(-b/a, c)$
- **심층 조건**:
  - $a$ 부호에 따른 정의역·치역 결정
  - 사분면 판정 (정의역 시작점·치역 범위)
  - 수평선과의 교점 0 or 1개
- **자유도**: 정의역·치역 부호 조건 판단·사분면 케이스
- **앵커**: 고쟁이-CM2-CH08-STEP2-#675~#689 · STEP3-#702
- **오답 유도**: 정의역 부등호 방향·치역 상한·하한 혼동·사분면 오판

### RF-M4. 무리함수와 직선 · 교점 개수 조건 (접선·경계 2케이스)
- **원리**: 무리함수와 직선 $y = kx$ 교점 개수 = 2 조건 → 두 경계 케이스: (1) 접함 ($D=0$) (2) 시작점 $(-b/a, c)$ 통과
- **심층 조건**:
  - 제곱 → 이차방정식 판별식 · 부호 조건 재확인
  - 시작점 조건: 직선이 정의역 시작 $x$값에서 함숫값 일치
  - 닫힌 vs 열린 구간
- **자유도**: 접선·경계점 조건 순서·부호 필터
- **앵커**: 고쟁이-CM2-CH08-STEP2-#690 · STEP3-#705, #710
- **오답 유도**: 판별식 후 부호 조건 누락·경계점 개념 부재·닫힘·열림 경계

### RF-M5. 역함수 · $y=x$ 대칭 · 접선 기울기 ±1 (최적화)
- **원리**: 무리함수 $f$와 역함수 $f^{-1}$의 그래프는 $y=x$ 대칭. 기울기 1 접선이 $y=x$에 접할 때 $f(x)$와 $f^{-1}(x)$의 그래프 사이 거리 최소
- **심층 조건**:
  - 기울기 1 (또는 -1) 접선 조건
  - $y=x$ 거리 = $|f(x) - x|/\sqrt{2}$
  - 대칭축 위 대각선 계산
- **자유도**: 접선 기울기 선택·거리 공식 vs 좌표 직접 계산
- **앵커**: 고쟁이-CM2-CH08-STEP2-#696, #697 · STEP3-#707
- **오답 유도**: 기울기 1 접선 누락·거리 공식 실수·대각선 vs 변 혼동

### RF-M6. 유리·무리 두 식으로 정의된 함수 · 일대일대응 · 역함수 존재 (매개변수 3식)
