## 1. 결론 요약

**시판 프로 교재는 여백을 "채우기" 위해 순수 장식을 넣지 않는다.** 대신 다음 셋 중 하나로 여백을 활용:

| 접근 | 대표 벤더 | 성격 |
|---|---|---|
| **A. 여백을 그대로 둔다** (콘텐츠 자연 흐름) | 블랙라벨·절대등급 STEP·마더텅·완자 문제 페이지 | 문항 사이 균등 · 학생 필기 공간 겸용 |
| **B. 사이드 컬럼 (좌 or 우)에 학습 스캐폴딩 배치** | 개념원리·개념+유형·EBS 올림포스·마플교과서·라이트쎈·수학의바이블·절대등급 개념 페이지·블랙라벨 개념 페이지 | 부속 개념·힌트·경계 케이스·심화 팁 |
| **C. 여백을 학생 자율 정리 스캐폴딩으로 구조화** | EBS 올림포스 "상위 1%" · 수학의바이블 개념CHECK | 밑줄·라벨(추론/풀이/실수) 학생 채움 |

**모든 벤더가 공통 채택**: 문항별 인디케이터 (난이도·기출 소스·서술형·중요도 등 얇은 배지) — **콘텐츠 기능** (여백 시각 채움 부수 효과는 있지만 목적이 학습 정보 전달).

**어느 벤더도** 좌측 골드 stripe·문항 dot·페이지 코너 오너먼트·챕터 색 세로 tab·문항 그룹 카드 프레임 같은 **순수 장식**을 사용하지 않았다.

## 3. 채택 후보 요소 (근거 인용)

DeeP Math 정리편은 이미 **좌측 큰 필수 예제 원형 배지 + 우측 짧은 얇은 챕터 배지 + KEY Point 크림 박스** 채택 (기존 디자인 정독 v1.0 확인). 세션 58에서 "여백 채우기" 이슈가 발생한 페이지에 대해 다음을 근거 인용 후 채택 후보로 제안:

### 후보 α. 우측 사이드 컬럼 = "생각해 봅시다" 힌트 컬럼 (개념원리형)

- **근거**: 개념원리 연습문제 페이지 16·17 (`참고자료/공통수학2/[고등1-2] 공통수학2 (2022개정)/[고등1-2] 개념원리 공통수학2 (2022개정).pdf` p.16·17)
- **기능**: 문항별 우측 세로 여백에 짧은 접근 힌트 (예: `$\overline{AB}\le 2 \Rightarrow \overline{AB}^2 \le 4$` · "집을 원점으로 하는 좌표평면 생각")
- **DeeP Math 적용**: 정리편 연습문제 페이지 (dmcheck·dmlevel) 옆 여백에 짧은 학습 스캐폴딩. **학습 기능**이 명확 (여백 채움은 부수 효과)
- **매크로 신설 필요**: `\dmhint{짧은 힌트}` (문항 우측 여백에 회색 sans 얇게)

### 후보 β. 개념 페이지 사이드 컬럼 = "빈틈 개념" (좌) + "심화 Note" (우) (EBS 올림포스·절대등급·블랙라벨형)

- **근거**: 
  - EBS 올림포스 p.7 좌 `빈틈 개념` + 우 `1등급 Note` 2 사이드 컬럼
  - 블랙라벨 p.8 좌 `비법노트` (A·B·C·D 알파벳 배지 + 짧은 정리)
  - 절대등급 p.6 우 크림 배경 사이드 컬럼 (수직선 대응·특수 케이스)
- **기능**: 개념 페이지에서 부속 개념·경계 케이스·심화 팁을 사이드에 배치
- **DeeP Math 적용**: `dmconcept` 환경 개념 페이지 여백이 남는 경우, 좌·우 중 하나에 사이드 컬럼 개설 (선택형)
- **매크로 신설 필요**: `\dmsidenote{제목}{본문}` (좌/우 자동 배치 옵션)

### 후보 γ. 문항별 인디케이터 배지 (마플시너지·라이트쎈·완자형)

- **근거**: 
  - 마플시너지: 문항별 4종 라벨 (`NORMAL·BASIC·TOUGH` 우측 상단 · `최다빈출·학교기출` 좌측 · `해설 내신연계문제` 우측 하단 · `모의고사 핵심유형` 상단)
  - 라이트쎈: `서술형·중·상·교육청 기출`
  - 완자: `학평 기출` · 별점 배지
- **기능**: 문항 성격 정보 (기출 소스·난이도·유형) 시각 전달
- **DeeP Math 적용**: 정리편 문항이 원본 (개념원리·RPM·고쟁이 STEP 1·블랙라벨 STEP 1)에서 오는 만큼, **출처 배지** 또는 **유형 라벨**을 문항 옆에 얇게 배치 가능
- **매크로 신설 필요**: `\dmsource{개념원리}` · `\dmtypelabel{내분점}` 등

### 후보 δ. 자율 정리 프레임워크 = 학생 채움 프레임 (EBS 올림포스 "상위 1%")

- **근거**: EBS 올림포스 고난도 교사용 "1등급을 넘어서는 상위 1%" 페이지 (구성·특징 소개 부분): 문항 아래 `추론` `문항 파헤치기` `풀이` `실수 Point 찾기` 4 라벨 + 밑줄이 붙어 학생이 각 항목을 채움
- **기능**: 최상위 문항에서 여백을 "학생 자율 사고 프레임" 으로 구조화
- **DeeP Math 적용**: `dmrepresentative` 대표 예제 아래 심화 문항 (Level 3·심화)에서 사고 프레임 밑줄 옵션 (선택형)
- **매크로 신설 필요**: `\dmthinkframe{추론,풀이,실수}` (밑줄+라벨 자동 렌더)

### 후보 ε. 유형 배너 안 미니 요약 (라이트쎈형)

- **근거**: 라이트쎈 p.16 `유형 09` 배너 바로 아래 "① 선분의 내분점이 어떤 직선 위의 점이다 → 점의 좌표를 직선의 방정식에 대입한다" 3~5개 접근 팁을 얇게 나열
- **기능**: 유형별 접근 스크립트를 유형 배너 안에 통합 (학생 사전 학습 스캐폴딩)
- **DeeP Math 적용**: `dmtypebanner` (대표 예제 배너) 안 또는 아래에 접근 팁 슬롯
- **매크로 신설 필요**: `\dmtypehint{①... ②... ③...}`

## 4. 기각 유의 요소 (5안 재실수 방지 · [[feedback_design_avoid_amateur_ornaments]])

**어느 벤더도 사용하지 않음** = 다시 제안하지 말 것:

| 요소 | 왜 시판이 안 쓰나 (관찰) |
|---|---|
| 좌측 세로 골드/컬러 stripe (콘텐츠 무관) | 챕터 인식은 얇은 세로 인덱스 배지·챕터 배너로 충족. stripe는 추가 정보를 담지 않음 |
| 문항별 dot (좌측 여백에 점) | 문항 번호 배지 자체가 시각 앵커. 별도 점 불필요 |
| 페이지 코너 오너먼트 (트라이앵글·라인 장식) | 표지·챕터 표제지에만 사용 (블랙라벨 표지·마플시너지 표지). 본문에 반복 노출은 없음 |
| 챕터 색 세로 tab (본문 페이지 옆에) | 마플교과서·개념+유형의 얇은 세로 인덱스 배지가 유사 기능. 색 tab이 아니라 **얇은 텍스트 라벨** (내용 = 챕터명 = 정보 전달) |
| 문항 그룹 카드 프레임 (여러 문항을 라운드 사각으로 묶기) | 어느 벤더도 개별 문항이 아닌 "그룹 문항"을 프레임으로 묶지 않음. 프레임은 개념 박스·조건 박스·KEY Point 등 **콘텐츠 단위**에만 |

**공통 원칙**: 시판 프로들은 여백에 **정보 (콘텐츠 기능)** 만 넣는다. 시각 채움 목적으로 **순수 도형·색 라인**은 넣지 않는다.

## 5. 마스터 승인 대기 사항

### 5.1 DeeP Math 정리편 채택 여부 (5 후보 각각)

| 후보 | 신설 매크로 | 파일 영향 범위 | 승인 |
|---|---|---|---|
| α. 우측 힌트 컬럼 | `\dmhint{}` | 연습문제 페이지 · 8권 확산 시 ~40건 | ⬜ |
| β. 개념 페이지 사이드 컬럼 | `\dmsidenote{}{}` | dmconcept 환경 · 개념 페이지 여백 큰 곳만 (~20건) | ⬜ |
| γ. 문항별 인디케이터 (출처·유형) | `\dmsource{}` · `\dmtypelabel{}` | 모든 예제·확인문제 (~200건 · 자동 추출 가능) | ⬜ |
| δ. 자율 정리 프레임워크 | `\dmthinkframe{}` | Level 3 심화 문항만 (~15건) | ⬜ |
| ε. 유형 배너 미니 요약 | `\dmtypehint{}` | dmtypebanner 사용 슬롯 (~30건) | ⬜ |

### 5.2 우선순위 제안

**세션 58 여백 이슈가 특히 심했던 페이지 유형에 우선 적용**:
1. **후보 α (우측 힌트 컬럼)** = 즉효 · 학습 기능 명확 · 개념원리 벤치마크 강력. **1순위 채택 추천**
2. **후보 γ (문항별 인디케이터)** = 이미 원본 관리 체계 (원본 은행 tier 매핑) 있으므로 `\dmsource{}` 로 자동 매핑 가능. **2순위**
3. **후보 β (사이드 컬럼)** = 개념 페이지 여백이 큰 경우만 · smoke-test 필요. **3순위**
4. 후보 δ·ε = 심화 · 후순위

### 5.3 smoke-test 계획 (승인 후)

`bank/design-smoke-test/` 에서:
- α 후보만 우선 시연 (기존 CM2-GM-01 정리편 파일 복사 후 힌트 컬럼 추가)
- 1p 시각 확인 → 마스터 승인 → 전 파일 전파 ([[feedback_design_smoke_test_first]])

## 6. 특이사항

- 벤치마크 정독 페이지가 **CM2 도형의 방정식 초반 (평면좌표·직선의 방정식) 60여 페이지에 집중** — 다른 단원 (집합과 명제·함수·유리무리함수)에서 여백 처리 편차가 있는지는 추가 정독 필요 (단, 벤더별 기본 레이아웃은 챕터 무관 일관됨을 확인)
- 완자 기출PICK 스타일 (문항 아래 즉시 축소 풀이)은 DeeP Math 정리편 성격 (문제풀이집 아님)과 어긋남 → **채택 후보에서 제외**
- 후보 γ의 `\dmsource{}` 는 이미 [[feedback_asset_unification_v2]] 원본 tier 관리 체계와 결합 시 시너지 큼 (사후 확산 자동화 가능)
- 여백을 **완전히 그대로 두는 것**도 시판 (블랙라벨 STEP·절대등급 STEP·완자 문제 페이지) 관행. 즉 "여백이 남았다 → 뭘 넣어야 한다" 는 강박 자체가 잘못. **5 후보 중 어느 것도 채택하지 않는 결정도 유효**
