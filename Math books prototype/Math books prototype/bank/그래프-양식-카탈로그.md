# 그래프 양식 카탈로그

마스터 영구 정책 [[feedback_graph_extraction_study]] (2026-06-30) 적용. 시판 책·기출 답지의 그래프 표현 방법을 정교 학습. 우리 책 그래프 오류 절대 금지.

## 🔴 우선순위 (2026-06-30 마스터 명시)

**고쟁이 양식 > 학평 양식** ([[feedback_solution_format_priority]] 영구 정책). 학평 양식 단일 출처 [[feedback_graph_design_style]] 폐기 (보조 양식으로 격하). 고쟁이 답지 그래프 양식 *제1 우선* 차용.

- ✅ 컬러 사용 OK (보라·파랑·빨강 강조) — 학평 흑백 only 강제 폐기
- ✅ 선 굵기 자유 (학평 0.4pt 강제 폐기)
- ✅ 정점·길이 라벨 위치는 고쟁이 양식
- ✅ 도형 면 음영 (색깔로 면 구분) — 고쟁이 차용

## 8개 학습 항목

| # | 항목 | 점검 포인트 |
|---|---|---|
| 1 | **좌표축 스케일** | 단위 길이, 가로:세로 비율 (1:1, 1:1.2 등), 격자 간격, x·y 범위 |
| 2 | **그래프 길이** | 곡선·직선의 시작·끝점, 영역 표시 (음영·해칭) |
| 3 | **점선 사용** | 보조선·관측선·평행선 (점선) vs 본 곡선 (실선), 점선 패턴 |
| 4 | **텍스트 폰트** | 한글: 명조·고딕 / 영문 변수: italic / 라벨 폰트 통일성 |
| 5 | **텍스트 크기** | 좌표 라벨 (small) · 곡선 라벨 (normal) · 각도 라벨 (small) · 제목 (큰) 위계 |
| 6 | **필체 (수식 폰트)** | Computer Modern · Times · 한글 LaTeX 필체, italic 일관성 |
| 7 | **표기 위치** | 좌표 라벨: x축 아래/y축 왼쪽 / $y=f(x)$ 라벨: 곡선 오른쪽 끝점 옆 / 각도: 호 안 / 점 P: 점 오른쪽 위 |
| 8 | **좌표 표현** | $(a, b)$ · $\mathrm{P}(a, b)$ · $\mathrm{O}$(원점) 표기, 점 마커 (●·○·×·☆) |

### 🌟 고쟁이 공통수학1 2025 답지 그래프 (GJ-CM1-S/)

**1차 학습 (p.5 다항식 §1, 2026-06-30 세션 7) — 도형 그림 8항목 메타**:

p.5에서 발견된 도형 그림 사례:
- **#026 직육면체 다른 풀이** — 각 면을 *색깔로 구분* (보라·파랑 등). 6면체 정점 라벨 A·B·C·D·E (변 옆), 변 라벨 *a, b, h* (각 변 옆 작은 글씨)
- **#027 직각삼각형** — 빗변을 *빨강* 강조, 한 직각 마크, ABC 정점 명시
- **#028 직육면체 + 대각선** — 대각선 점선 강조, 정점 라벨 + 길이 라벨

| 항목 | 고쟁이 답지 양식 |
|---|---|
| 1. 좌표축 스케일 | 도형 1:1 비율 |
| 2. 그래프 길이 | 적절한 점·변 영역 |
| 3. 점선 사용 | 대각선·보조선 점선, 본 면 실선 |
| 4. 텍스트 폰트 | 한글 명조 · 영문 변수 italic |
| 5. 텍스트 크기 | 정점 라벨 (small) · 길이 라벨 (small) |
| 6. 필체 | LaTeX Computer Modern italic |
| 7. 표기 위치 | 정점 라벨: 점 옆 (오른쪽 위) · 길이 라벨: 변 옆 (가까운 쪽) |
| 8. 좌표 표현 | $\mathrm{A}$, $\mathrm{B}$ 명조 · 변 라벨 $a, b, h$ italic |

**고쟁이 vs 학평 양식 차이** *(2026-06-30 마스터 명시 정정: 고쟁이 우선)*:
- 학평 양식 ([[feedback_graph_design_style]], 보조): 흑백·0.4pt 선
- 고쟁이 답지: **컬러 사용** (보라·파랑·빨강 강조)
- 우리 책 적용: **고쟁이 양식 우선** ([[feedback_solution_format_priority]]) — *컬러 OK*, 선 굵기 자유, 도형 면 음영 OK
- 정점 라벨·길이 라벨 위치 양식 차용

**2차 학습 (p.9-30, 다항식 + 항등식·나머지정리 단원, 2026-06-30 세션 7) — 추가 발견 양식**:

**컬러·흑백 혼용 패턴**:
- 큰 도형 (사각형 ABCD + 분할 영역 등): **컬러 음영 사용** (보라 #C0AFD8·파랑 #B8D4F0 등)
- 작은 도형 (삼각형 단순·중점 표시 등): **흑백** (얇은 선)
- 도형 면 *구분*이 필요할 때 컬러, 단순 표기는 흑백
- 우리 책 적용: *고쟁이 양식 우선* — 도형 면 구분이 핵심이면 컬러 사용 OK

**점선·실선 사용 (도형)**:
- 본 도형 변: 실선 (0.6-0.8pt)
- 보조선·중점선·내접원: 점선 또는 얇은 실선
- 대각선 강조: 컬러 + 두꺼움

**정점·길이 라벨 위치 표준화**:
- 정점 라벨: 점 옆 *오른쪽 위* (1순위) 또는 *위/왼쪽 위* (2순위)
- 변 길이 라벨: 변 옆 *가까운 쪽* (작은 글씨)
- 각도 라벨: 호 안 (작은 글씨)
- 원의 반지름: 원 안 또는 중심에서 끌어낸 선 옆

**조립제법·다항식 나눗셈 양식** (수식 도형):
- 조립제법: 점선 격자 안에 정렬
- 세로 나눗셈: 박스 안에 정렬

**3차 학습 (p.31-178, 방정식·부등식·경우의수·행렬 전 단원, 2026-06-30 세션 7) — 추가 양식**:

**함수 그래프 (p.80 등)**:
- 곡선 **검정** 위주 (도형의 컬러 음영과 다름)
- 좌표축 검정 화살표, 라벨 `x`·`y` 끝점 아래/왼쪽
- 곡선 옆에 `y=f(x)`·`y=g(x)` 라벨
- 좌표 표기 `(-3, 6)` 점 옆 작은 글씨
- 직선·접선: 검정 또는 점선
- 우리 책 적용: 함수 그래프는 학평 양식과 유사 (흑백 위주)

**도로망 격자 그림 (p.130, 경우의 수)**:
- 노드 (●) + 간선 (실선) + 숫자 라벨
- 회색 + 노란색 컬러 사용 (격자 음영)
- 경우의 수 단원 특화 양식
- 우리 책 적용: 경우의 수 단원 도로망 문제 시 차용 권장

**컬러 사용 결론** (단원별):
| 단원 | 컬러 빈도 | 비고 |
|---|---|---|
| 다항식·항등식·인수분해 | 낮음 | 도형 등장 시만 컬러 |
| 복소수·이차방정식 | 매우 낮음 | 거의 흑백 |
| 이차함수 (함수 그래프) | 매우 낮음 | *검정 곡선 위주* |
| 여러 방정식·부등식 | 중간 | 영역 그림에 컬러 음영 |
| 경우의 수 | 높음 | 도로망·격자 컬러 음영 |
| 행렬 | 낮음 | 등호 정렬 위주 |

우리 책 적용: 단원별 컬러 빈도 패턴 차용 — 도형 면 구분이 필요한 단원만 컬러, 함수 그래프는 흑백 유지.

## 우리 책 TikZ 작성 체크리스트

그래프 작성 시 8항목 점검:

```
□ 좌표축 스케일 (1:1 또는 명시된 비율)
□ 그래프 길이 (적절한 x·y 범위)
□ 점선/실선 구분 (보조선·관측선=점선)
□ 폰트 통일 (변수 italic, 한글 명조)
□ 텍스트 크기 위계 (라벨 small, 본 곡선 normal)
□ 필체 일관성
□ 표기 위치 (좌표·곡선·각도)
□ 좌표 표현 ($(a,b)$·$\mathrm{P}(a,b)$)
```

빌드 후 시각 검사 — 학평 양식과 비교.
