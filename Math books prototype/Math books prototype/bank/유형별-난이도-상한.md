# 유형별 난이도 상한 카탈로그 (v1.0)

**신설**: 2026-07-13 · 세션 39 · 방안 K1 · 마스터 지적 계기 ("박스만 있으면 배점 부풀림")
**목적**: CM2 문항 유형별 star 상한을 명시 · 청사진의 star·composite 부풀림 자동 감지 · 정의박스 위장 술수 차단

---

## 배경

세션 39 정밀 재평가에서 발견:
- **6회 #16 부분집합 개수** (교과 표준 유형) → 정의박스로 심화 위장 → 청사진 composite 33 (star_premium) → 실측 12 (★ 3~4)
- 정의박스에 교과 표준 정의를 회고하는 것만으로 배점·star 부풀림
- **정의박스 = 심층 통찰 아님. 실제 문제 심층은 풀이 단계·통찰 실현·역방향 결합 등에서 결정**

## 유형 분류 · CM2 (도형의 방정식 + 집합과 명제)

### 🟢 기초 (Basic) — 교과 표준 유형 · **star 상한 ★ 2**

교과과정에 명시된 표준 정리·공식을 직접 적용하는 유형. 정의박스 있으면 위장 감지.

**CM2-GM**:
- 두 점 사이 거리 (거리 공식 직접 적용)
- 선분의 내분점·중점 (공식 대입)
- 무게중심 좌표 (공식 대입)
- 직선의 방정식 (기울기·절편)
- 원의 방정식 (표준형·일반형 변환)
- 원의 접선 (원 위 점 접선 공식)
- 도형의 이동 · 단일 대칭·평행이동 (규칙 적용)

**CM2-ST**:
- 집합의 표현 (원소·부분집합·여집합)
- 집합 연산 (합·교·차·여집합)
- 부분집합의 개수 (2^n 공식)
- 명제와 조건 (표준 참·거짓)
- 명제의 대우·역·이 (규칙 적용)

**정의박스 유무**: 
- 교과 표준 정의박스 (거리 공식·부분집합 개수 공식·무게중심 공식 등) → **위장 감지 RED**
- 실제 심층 통찰이 있어야 정의박스 정당

---

### 🟡 중급 (Standard) — 표준 응용 유형 · **star 상한 ★ 3~4**

교과 표준을 두 단계 이상 결합·응용하는 유형.

**CM2-GM**:
- 원과 직선의 위치관계 (거리·반지름 대소)
- 원의 접선 (외부 점에서 접선 길이 · 접점)
- 두 개의 이동 결합 (대칭+평행이동)
- 정점 (직선 계수 매개변수에 따른 정점)
- 수직이등분선 (중점+수직 조건)

**CM2-ST**:
- 부분집합 개수 조건 (특정 원소 포함/배제)
- 두 집합 원소 개수 M+m (포함배제·상한·하한)
- 명제 진리집합 (부등식·구간)
- 명제 필요·충분 조건 (P⊂Q 관계)

**정의박스 유무**:
- 정의박스 없이 자연 서술 자주 사용
- 정의박스 있어도 심층 통찰이 문제 자체에 있어야 정당

---

### 🟠 응용 (Applied) — 다중 조건·역방향 · **star 상한 ★ 4~5**

다중 제약·역방향·자취 결합이 등장하는 유형.

**CM2-GM**:
- 두 원 두 점 만남 조건 (정수 매개변수 카운트)
- 자취 (조건 만족 점의 자취 방정식 유도)
- 원과 직선 정수 조건 (교점 개수·매개변수)
- 원의 접선 다중 조건 (기울기·원점 지남·정수)
- 대칭·평행이동 결합 (다중 이동 후 위치관계)

**CM2-ST**:
- 부분집합 다중 조건 (원소 포함·배제·개수 결합)
- 필요·충분 조건 다중 판정 (여러 순서쌍)
- 명제 대우·역·이 결합 (다중 명제 참거짓)

---

### 🔴 심층 (Deep) — 지문형·다중 통찰·정의 확장 · **star 상한 ★ 5 (star_premium 도달 가능)**

지문형 다중 제약·다중 통찰 실현·정의 확장·역방향 자취 결합.

**요구 특성**:
- **narrative_length_chars ≥ 250** (지문 실질 요구)
- **constraints ≥ 3** (다중 제약)
- **insight_count ≥ 3** (다중 통찰 유형)
- **정의박스**: 교과 표준 회고 아님 · 신 정의·비표준 정리·구조 확장 포함
- **역방향·자취·다층 통찰** 결합 필요

**정의박스 정당성 판정**:
- ✅ 정당: 신 정의 (예: 근축·팬터그래프 대응 규칙·이중 대칭 규칙)
- 🔴 위장: 교과 표준 회고 (예: 무게중심 공식·부분집합 개수 공식·거리 공식)

## 정의박스 사용 원칙 (마스터 지시 2026-07-13 · 강화)

### 🔴 절대 원칙 · 교과 표준 개념 회고 자체 금지

**마스터 지시** (2026-07-13):
> "교과 표준 개념은 회고를 해주면 안 돼"

**규칙**:
- 정의박스에 교과 표준 개념 (거리 공식·중점·내분점·무게중심·부분집합 개수 공식·집합 연산·명제 대우 등) **회고 자체 금지**
- 학생이 교과에서 이미 학습한 개념을 시험지에서 다시 알려주는 것 = 문제 신뢰도 저하 · 학습 저해
- 정의박스 사용 자체가 **신 정의·확장 정의·비표준 정리**에 국한

### 정의박스 허용 조건 (매우 제한적)

**허용** (Deep 유형만):
- ✅ 신 정의 · 교과 밖 (예: "두 원의 근축" · "팬터그래프 대응 규칙 (kx, ky)")
- ✅ 확장 정의 · 두 표준 개념 결합 신구조 (예: "이중 대칭이동 규칙")
- ✅ 지문형 소재 정의 (예: "GPS 삼변측량 세 원 방정식")

**금지** (Basic·Standard·Applied 유형 전부):
- 🔴 무게중심 공식 회고
- 🔴 부분집합 개수 2^n 회고
- 🔴 거리 공식·중점 공식 회고
- 🔴 원 접선 조건 회고
- 🔴 명제 대우 규칙 회고
- 🔴 집합 연산 (여집합·차집합) 정의 회고
- 🔴 조합 C(n,k) 정의 회고

### 자동 검사 로직 (blueprint-content-analyzer.mjs)

```javascript
function detectTextbookRecap(slot) {
  if (!slot.hasDefBox) return null;
  // 정의박스 내용 감지 (청사진 answer_note·narrative_theme에서 키워드)
  const context = (slot.answerNote + ' ' + slot.narrativeTheme + ' ' + slot.type).toLowerCase();
  const recapKeywords = [
    '거리 공식', '중점 공식', '내분점 공식', '무게중심 좌표',
    '부분집합 개수', '2\\^n', '조합의 수',
    '집합 연산', '드모르간', '여집합의 정의',
    '원 위 점 접선', '접선의 방정식',
    '명제의 대우', '역·이', '대우의 정의',
  ];
  for (const k of recapKeywords) {
    if (context.includes(k)) {
      return {
        violation: 'textbook-recap',
        msg: `정의박스에 교과 표준 개념 "${k}" 회고 · 마스터 지시 위반`,
        keyword: k,
      };
    }
  }
  // 유형 분류로 감지 (Basic·Standard 유형에 정의박스 있으면 자동 위장)
  const typeClass = classifySlotType(slot.type, slot.primary_tool);
  if (typeClass === 'Basic' || typeClass === 'Standard' || typeClass === 'Applied') {
    return {
      violation: 'defbox-in-non-deep',
      msg: `유형 ${typeClass}에 정의박스 배치 · Deep 유형에만 허용`,
      typeClass,
    };
  }
  return null;
}
```

### 자동 검사 로직 (blueprint-content-analyzer.mjs)

```javascript
function detectDefBoxDisguise(slot) {
  if (!slot.hasDefBox) return null;
  const typeClass = classifySlotType(slot.type, slot.primary_tool);
  if (typeClass === 'Basic' || typeClass === 'Standard') {
    return {
      violation: 'defbox-disguise',
      msg: `유형 ${typeClass}에 정의박스 배치 · star_premium 위장 감지`,
      declared_star: slot.star,
      max_star: typeClass === 'Basic' ? 2 : 4,
    };
  }
  return null;
}
```
