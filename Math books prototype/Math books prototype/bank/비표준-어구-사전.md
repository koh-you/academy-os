### §1.4b-2 부등호 관련 비공식 용어 (v1.4 신설 · 2026-07-13 세션 35)

수학 답지·풀이·Critical Point에서 부등호 강도를 설명할 때 학술적 압축 용어("강한 부등호"·"약한 부등호") 대신 자연 한국어로 조건을 직접 명시.

**배경**: 와부고 CM2 1회 답지 Critical Point #13·#15·#16 3곳에서 "강한 부등호" 3회 사용. 이는 학술 용어 (strict inequality)의 직역이며 고등학교 표준 어구 아님. 학생 이해도 낮음.

| 🔴 어구 | 권장 대체 | 비고 |
|---|---|---|
| "강한 부등호" | "$<$ (등호 없음)" · "등호 미포함" · 조건 직접 명시 | strict inequality의 직역 · 학술 용어 · 학생 이해도 낮음 |
| "약한 부등호" | "$\le$ (등호 포함)" · "등호 포함" · "이상·이하" | weak/non-strict inequality의 직역 · 학술 용어 |
| "엄격한 부등호" | 위와 동일 | strict의 다른 번역 · 표준 아님 |
| "느슨한 부등호" | 위와 동일 | 위와 동일 |

**권장 표현 예시**:
- 잘못: "강한 부등호 $|3-5|<\overline{\mathrm{OP}}<3+5$로 쓰면 경계점 $2, 8$ 놓침"
- 좋음: "등호 없이 $|3-5|<\overline{\mathrm{OP}}<3+5$로 쓰면 경계 값 $2,\,8$을 놓친다"

- 잘못: "정의 ``원점과 거리 $<2$''는 경계 미포함. 두 원이 ``서로 다른 두 교점''도 강한 부등호로 $0<d<4$"
- 좋음: "정의 ``원점과의 거리 $<2$''는 경계 미포함. ``서로 다른 두 교점''도 마찬가지로 $0<d<4$ (등호 없음)"

**적용 zone**: `\criticalpoint` · `\solnote` · 서술형 풀이 · `\solpart` · 자연어 설명 등 학생 노출 zone 전체.

## §3. \solnote (통찰 박스) 어구 표준 (v1.0 신설)

> **\solnote는 학생 답지에 출력되는 박스**. 따라서 §1·§2 모두 적용 + 추가 규약.

### §3.1 \solnote 구조 표준

학생 답지의 \solnote는 *RPM 비법노트 양식*을 차용:
- **한 문장 핵심 통찰** 또는 **공식·정리 박스**
- 메타 코멘트·함정 분석·내부 코드명 절대 금지
- 한국어 자연 문장 (RPM 비법노트와 동일 톤)

### §3.2 \solnote 권장 양식

**유형 A — 공식 박스**:
```
\solnote{$_nC_r$의 두 분리: ① 특정한 대상을 포함하지 않는 경우 $\to$ $_{n-1}C_r$.
② 포함하는 경우 $\to$ $_{n-1}C_{r-1}$. 따라서 $_nC_r = _{n-1}C_r + _{n-1}C_{r-1}$.}
```

**유형 B — 한 줄 통찰 (자연 한국어)**:
```
\solnote{계수가 실수인 삼차방정식에서 한 허근이 $\alpha$이면 켤레복소수 $\bar\alpha$도 근이다.
따라서 두 허근의 합과 곱이 자동으로 결정된다.}
```

**유형 C — 다른 풀이 안내**:
```
\solnote{다른 풀이: 근과 계수의 관계 대신 인수정리를 이용하여 $(x - 1)$이 인수임을 확인한 후 조립제법으로 풀이할 수도 있다.}
```

### §3.3 \solnote 금지 양식

🔴 메타 코멘트형: "학생이 ~ 놓치면 함정 — 본 문제는 ~ 표준 절약 경로"
🔴 내부 코드명형: "(P-FG1 시범)" "★ 5 변별"
🔴 압축 신조어형: "대칭식 환원으로 $x+y, xy$만으로 결정"
🔴 외래어형: "세 케이스 모두 점검"

### §3.4 \solnote 옵션 매크로 (v1.1 예정)

LaTeX 옵션으로 \solnote 출력 모드 분리:
- `\solnotemode{student}` — 학생용 (RPM 비법노트 양식만)
- `\solnotemode{teacher}` — 교사용 (검수 메타 포함, 별도 PDF)
- `\solnotemode{none}` — 출력 안 함

### §3.5 \solnote 말투 반례 (v1.3 신설 · 2026-07-07)

와부고 CM2 답지 solnote 8회 재작성 사건 계기. **아이디어·핵심개념 전달**이 목적이더라도 부자연스러운 문어체·과장·형식적 표현은 금지.

#### 🔴 금지 문어체·과장·형식 표현

#### ✅ 좋은 예 vs 나쁜 예 대조

**좋은 예 (아이디어 + 자연 말투)**:
```
\solnote{$A_n$은 "$n$의 배수 전체"를 뜻하므로, 배수집합 사이의 관계 문제는 
사실 자연수의 배수·약수 관계 문제와 같다. 예를 들어 $A_m \subset A_n$은 
"$m$이 $n$의 배수"와 같은 뜻이고, 두 배수집합의 교집합은 두 수의 최소공배수와 
이어진다. 집합 표기를 배수·약수 관계로 바꿔 읽는 것이 이 유형의 요령이다.}
```
→ 자연스러운 서술, 구체적 예시("예를 들어..."), 요령을 한 번만 언급

**나쁜 예 (문어체·형식)**:
```
🔴 \solnote{$A_n$이 "$n$의 배수 전체의 모임"으로 정의된다는 사실을 앞세우면, 
배수집합 사이의 관계 문제는 집합의 문제가 아니라 자연수의 배수·약수 관계 
문제로 옮겨진다. ...집합의 언어를 정수의 언어로 옮겨 읽는 관점 전환이 
이 유형의 열쇠이다.}
```
→ "사실을 앞세우면" 문어체, "이 유형의 열쇠이다" 과장, "관점 전환" 반복

**좋은 예 (개념 + 자연 흐름)**:
```
\solnote{$k$의 값이 어떻든 항상 지나는 점을 찾는 문제는 식을 "$k$에 관한 
항등식"으로 다시 읽는 데서 출발한다. 방정식을 $k$의 다항식 꼴로 정리하면 
"$k$의 각 차수의 계수가 모두 $0$"이라는 여러 개의 식이 나온다. 하나였던 
방정식이 연립방정식으로 갈라지고, 그 해가 곧 항상 지나는 정점이다.}
```

**나쁜 예 (과장·독립·형식)**:
```
🔴 \solnote{$k$의 값에 관계없이 지나는 점을 찾는다는 문제의식이 곧 "식을 
$k$에 관한 항등식으로 바라보는 관점의 전환"이다. ...$k$의 각 차수의 계수가 
모두 $0$이라는 여러 개의 독립 조건으로 분해된다.}
```
→ "문제의식이 곧" 학술, "독립 조건" 확통 용어, "분해된다" 학술
