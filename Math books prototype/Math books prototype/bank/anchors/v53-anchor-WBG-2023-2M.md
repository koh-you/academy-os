## 4. 🔴 핵심 규명 — 선택형이 composite 24 를 넘는가

### 답: 넘는다. 이 회차 선택형 천장은 **#15 = 29.67** 이며, 24 를 **5.67 초과**한다.

24 초과 선택형은 #15 한 문항이지만, 20 이상 선택형이 3문(#11 20.33 · #14 22.33 · #15 29.67)으로 2025 선택형 천장(23)을 이미 두 문항이 육박·상회한다.

### #15 축 분해 — 어느 축에서 벌었는가

```
#15  집합족 Q → 차집합족 R → ∪·∩·− 닫힘 S = P 가 되는 n(Q) 최솟값
```

| 축 | 값 | 기여 | 구성 근거 |
|---|---:|---:|---|
| depth | 8.67 | **8.67** | 깊이 3 통찰 2개(집합족 자기참조 구조 파악 · 원소 분리 필요성) + 깊이 2 (배제 논증) → max 3, avg 2.67 |
| min(N+2L, 6) | N=1, L=0 | **1** | 🔴 **여기서 5점을 잃는다.** 지문 없음 · 소문항 없음. 새 연산 정의 블록으로 N=1 만 인정 |
| 2T | T=2 | **4** | 「S 가 세 연산에 닫힌 집합족」이라는 **정의를 수학 언어로 번역하는 것 자체가 통찰** — 닫힘 → 원소 분리 → 단일원소집합 생성 |
| R | 3 | **3** | R.exist(3개 구성 제시) + R.case(|Q|≤2 불가 MECE 배제) + R.boundary(최솟값) |
| −F | 1 | **−1** | S 의 역할(R 을 포함하며 닫힌 최소 집합족인지)이 발문만으로 일의적이지 않다. 제시된 예시로 해석이 수렴하므로 F=1 |
| E | 2 | **2** | (가)(나)(다) 세 조건 모두 필수 · 예시가 정의 보조로 재사용 |
| 2P | P=3 | **6** | 완전 참신. 유형 카탈로그 매칭 불가. 「부분집합의 집합족」이라는 층을 학생이 스스로 세워야 한다 |

| **합계** | | **29.67** | |

### 🔴 이 분해가 말하는 것

- **선택형이 못 얻은 것은 구조 축뿐이다.** #15 는 구조 축 6점 중 **1점만** 얻고도 29.67 에 도달했다. 같은 수학 실체에 지문 1개와 3소문항 계단을 붙여 구조 축을 만점(6)으로 만들면 **34.67** 이 되어 premium 임계(30)를 넘는다.
- 즉 「★ 5 = 선택형 도달 불가」는 **축 구성상 성립하지 않는다.** 선택형의 구조적 상한은 `51 − 5 = 46` 이고, 실기출 표본에서 이미 29.67 이 관측되었다.
- **2025 의 선택형 천장 23 은 그 해의 우연이다.** 2023 선택형은 같은 평균(14.7)을 유지하면서 꼬리 하나를 29.67 까지 올렸다. 즉 와부고 페르소나는 **선택형 1문에 정점을 배치하는 선택지를 실제로 행사한다.**
- 판정 축 비중 검사: `2T + E + 2P = 12`, composite 29.67 → **40.4%** (상한 60% 통과). 점수의 과반은 측정 축(depth + R + M)에서 나왔다.
- 🔴 **premium 자격**: `M ≥ 2` 를 만족(M=3)하므로 #15 는 M 하한 게이트를 통과한다. composite 29.67 은 임계 30 에 0.33 모자란다 — **선택형만으로 premium 문턱에 도달한 실측 사례**로 기록한다.

## 5. 채점 중 판단이 갈린 지점 (마스터 확인 요청)

1. **#15 의 M** — M=3(정점) 으로 채점했다. 근거는 「표준 접근 무효 + 비자명한 귀결」이다. 다만 §2.16.2b 의 M=3 문언은 「**단원 교차 융합** + 비자명한 귀결 + 표준 접근 무효」로 세 요건을 연접으로 읽을 여지가 있고, #15 는 집합 단원 내부에 머문다. **M=2 로 낮추면 composite = 27.67** 이 되며, 그래도 24 는 넘는다. 핵심 결론은 어느 쪽에서도 바뀌지 않는다.
2. **#14 의 발문 표기** — 두 번째 조건이 재편집본에서 `420 ∉ A_n^C ∪ A_9` 로 읽힌다. 이 독해로는 정답이 6이 되어 정답표 ①(16)과 어긋난다. 정답 16 과 정합하는 독해는 `420 ∈ A_n^C ∪ A_9` (= n ∤ 420) 또는 `420 ∉ A_n ∪ A_9` 이다. **재편집 과정의 조판 오류로 판단**하여 F 감점을 부과하지 않았다. 원본 학교 인쇄물 확보 시 재확인 필요.
3. **#1 의 F=1** — 발문이 "다음 **명제** 중 거짓인 것"인데 ①("우리의 청춘은 아름답다")은 명제가 아니다. 의도된 함정이나 서술로는 부정확하므로 F=1 을 부과했다. 감점 없이 두면 composite 7.00.
4. **#12 의 H=1** — 증명 빈칸형은 풀이 경로 전체가 인쇄되어 있다. 「답 노출」 축을 경로 노출로 확장 적용했다. H=0 으로 보면 composite 13.00.
5. **#5 의 M** — 「f 와 f⁻¹ 의 교점이 하나면 그 점은 y=x 위」는 엄밀 논증이 가능한 비자명 사실이지만 교과서에 성질로 실려 있어 학생은 암기 적용한다. **M=1** 로 채점했다. M=2 로 보면 16.33.
6. **#11 의 E** — 2025 앵커 「포함배제 최대최소 = 20」과 눈금을 맞추기 위해 E=1 로 두었다(E=2 시 21.33). 동일 원형 문항이므로 교차 회차 정합을 우선했다.
7. **서술형 #16·#17 의 낮은 값** — 각 8.0점·6.0점으로 배점은 높으나 수학 실체는 정의 판정(M=1)·나머지 4분류(M=1)에 머문다. **배점과 composite 가 크게 어긋나는 구간**이며, 와부고가 서술형을 "채점 가능한 논술 훈련" 용도로도 쓴다는 신호로 읽힌다.
