# 지문 소스풀 스키마 v1.0

> **작성일**: 2026-07-14 · 세션 36 · 마스터 지시
> **배경**: 2회 #17 팬터그래프 (사도기) 재출제 사건 = 지문 소스 풀 부족 신호. 이전 회차에서 그림 퀄리티 이유로 폐기한 사도기가 재등장. 새 소재 발굴 파이프라인 필요.
> **목적**: 최근 10년 (2015~2025) 평가원·교육청 국어영역 지문(과학·사회·기술)에서 수학 연계 가능한 소재를 체계적으로 수집·매핑

## 1. 수집 대상 범위

### 1.1 시험 종류

| 주관 | 시험 종류 | 연간 실시 회수 | 10년간 총 회수 |
|---|---|---|---|
| **한국교육과정평가원** | 대학수학능력시험 | 1회 (11월) | 10회 |
| 한국교육과정평가원 | 모의평가 | 2회 (6월·9월) | 20회 |
| 시·도교육청 | 전국연합학력평가 (학평) | 3회 (3·4·7·10월) | 30회 |
| **소계** | | | **60회** |

**총 지문 수 예상**: 회당 국어 지문 4~5개 × 60회 ≈ **240~300 지문**

### 1.2 영역별 우선순위

**국어영역 4대 영역**:
1. 🥇 **과학기술 지문** (최우선) — 물리·화학·생물·지구과학·공학 mechanism
2. 🥇 **사회 지문** (최우선) — 경제·법·통계·심리·인구·정책
3. 🥈 **인문·예술 지문** (선별) — 역사·철학·언어학 (수학 매핑 약함)
4. ❌ **문학** (제외) — 시·소설은 수학 연계 부적합

**우선순위 기준**: 수학 mechanism 매핑 가능성

## 2. 수집 데이터 필드 스키마

각 지문에 대해 다음 필드 수집:

```yaml
- id: SRC-2024-SN-K01           # 코드: SRC-{연도}-{시험}-K{번호}
  year: 2024
  test:
    org: 평가원                   # 평가원 · 교육청 · 강남서초
    type: 수능                    # 수능 · 6월모평 · 9월모평 · 3월학평 · 4월학평 · 7월학평 · 10월학평
    session: 국어                 # 국어 · 화작 · 언매
  passage:
    number: 15-17                 # 지문에 딸린 문항 번호
    domain: 과학기술              # 과학기술 · 사회 · 인문·예술
    subdomain: 생명공학            # 세부 (물리·화학·생물·지구·공학·경제·법·통계·심리·역사·철학)
    topic: CRISPR 유전자 편집       # 소재 (한 줄 요약)
    keywords: [DNA, 절단, 효소, 확률적]     # 5~10 키워드
  math_mapping:
    plausible: high               # high · medium · low · none
    math_units:                   # 매핑 가능한 수학 단원
      - CM1-CB (경우의 수)         # 확률적 과정
      - CM2-FN (함수)              # 반응 속도 함수
    mechanism_type: 확률적 절단     # 수학화 가능한 mechanism
    figure_potential: high        # 좌표평면 대응 도해 가능성
    complexity: 3                 # 1(단순) ~ 5(복합)
    example_problem_seed: |       # 수학 문제 소재로 변환 시 seed
      두 개의 유전자 표적 위치 A(2, 0)·B(0, 3)에서 절단 확률을...
  usage:
    used_in_papers: []            # 실제 시험지 사용 이력
    reject_reason: null           # 폐기 시 사유
    review_notes: null
  source_link: https://example.com   # 원본 지문 링크 (교육청·평가원 공식)
```

## 3. mechanism 유형 분류 (수학 연계)

지문의 mechanism을 다음 유형으로 분류:

### 3.1 도형·좌표 mechanism (CM2-GM 매핑)
- 삼각측량·삼변측량 (GPS·지진·전파)
- 좌표평면 대응 (사도기·확대·축소·변환)
- 원·타원 궤도 (행성·인공위성·전자궤도)
- 대칭·반사 (거울·프리즘·안테나)
- 최단 경로·거리 (로봇·차량·물류)

### 3.2 집합·명제 mechanism (CM2-ST 매핑)
- 조사·분류 (인구·통계·유전)
- 조건 결합·필충 (규칙·법·계약)
- 배제·포함 (백신·검사·필터)
- 명제 진리값 (증명·모순)

### 3.3 함수 mechanism (CM2-FN 매핑)
- 반응·성장·감쇠 (화학·생물·전기)
- 진동·주기 (전기파·음파·역학)
- 최적화·극값 (경제·물류·기하)
- 합성·역함수 (변환·역변환)

### 3.4 유리·무리 mechanism (CM2-RF 매핑)
- 속도·유속 (물리·유체·전기)
- 압력·부피 (기체·화학)
- 광학·굴절 (렌즈·프리즘)
- 조합·비율 (혼합·용해)

### 3.5 경우의 수·확률 (CM1-CB 매핑)
- 순열·배치 (좌석·조합·조합화학)
- 조합·선택 (팀·집합)
- 확률적 mechanism (유전·유전자·양자)

### 3.6 행렬 mechanism (CM1-MX 매핑)
- 상태 전이 (인구·질병·경제)
- 그래프·네트워크 (연결·경로)
- 좌표 변환 (회전·확대)

### 4.1 검색 소스

**공식 자료**:
- 평가원 공식 사이트 (`suneung.re.kr`) — 수능·6월·9월 모의평가
- 시·도교육청 사이트 — 학평 문제·해설
- EBS 사이트 (`ebs.co.kr`) — 지문 해설
- 자이스토리·마더텅·에듀넷 등 시판 국어 학습서

**대체 검색 키워드**:
- "2024 수능 국어 지문 과학"
- "2023 6월 모의평가 국어 사회"
- "2022 9월 모의평가 국어 기술"
- "고등학교 국어 지문 CRISPR"
- "학평 국어 지문 확률"

### 4.2 수집 절차

1. **연도별·시험별 순회**: 2015 → 2016 → ... → 2025
2. **각 회차 지문 4~5개 확인**: 소재·mechanism 요약
3. **수학 연계 판정**: plausibility high/medium/low
4. **폐기 지문**: 문학·순수 인문 (수학 매핑 불가)
5. **선별 지문**: 스키마 필드 완성

## 5. 실전 활용 워크플로우

### 5.1 신규 시험지 지문형 슬롯 출제 시

1. `bank/지문-소스풀-2015-2025.md` 인덱스에서 mechanism 유형별 검색
2. 이미 사용한 지문 (`usage.used_in_papers` 이력)은 제외
3. 미사용 · 수학 연계 high 지문 우선 셀렉트
4. 지문의 mechanism을 수학화 (`example_problem_seed` 참조)
5. bank/도해-카탈로그.md에 해당 mechanism 표준 도해 있으면 재사용
6. 없으면 신규 도해 작성 (feedback_figure_authoring_protocol 5-step)

### 5.2 실전 예시

**시나리오**: 3회 시험지 서술형 정점 슬롯 지문형 필요

1. 인덱스에서 CM2-GM 매핑 · figure_potential: high · 미사용 검색
2. 결과: SRC-2019-SN-K15 (지진 진앙 삼변측량), SRC-2022-K06-K07 (인공위성 궤도) 등
3. SRC-2022 선택
4. mechanism (인공위성 3개 지상 관측) → 수학화 (좌표평면 세 원 교점)
5. 도해 카탈로그 M-02 GPS 삼변측량 참조 (좌표평면 대응 도해 재사용)
6. 시험지 작성

**효과**: 매 회차마다 새 소재 · 자기복제 방지 · 사도기 재출제 사건 방지
