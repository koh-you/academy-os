## 1. 허용되는 이미지 소스 (우선순위)

### 🥇 1순위: `bank/도해-카탈로그.md` archive (자체 승인 iteration)

- 세션별 마스터 승인 완료된 TikZ 코드 재사용
- 신규 필요 시 다른 소스 검색

### 🥈 2순위: Wikimedia Commons CC-BY-SA

**허용 조건**:
- 라이선스: CC-BY-SA (2.0/2.5/3.0/4.0)·CC-BY (동일)·CC0 (Public Domain)
- 파일 저장 위치: `figures/commons/`
- 파일명 규약: `commons-{mechanism_name}-{date}.{ext}`
  - 예: `commons-pantograph-20260714.png`

**출처 표기 의무**:
```latex
\begin{center}
\includegraphics[width=0.7\linewidth]{figures/commons/commons-pantograph-20260714.png}
\end{center}
\vspace{-2mm}
{\footnotesize\itshape\color{gray} 출처: Wikimedia Commons (원저작자 · CC BY-SA 4.0)}
```

**금지**:
- 라이선스 불명확 이미지
- non-commercial only (NC) 라이선스 (교육 상업 이용 시 문제 소지)
- 개인 사진작가 개인 사이트 이미지

### 🥉 3순위: 참고자료/ 폴더 PDF 크롭 (교육 목적 인용)

**허용 조건**:
- 참고자료 PDF (기출·시판 책·EBS 자료 등)에서 그림 크롭
- 교육 목적 · 비상업 원본 인용
- 원본 형태 유지 (편집·변형 최소)
- 파일 저장 위치: `figures/reference/`
- 파일명 규약: `ref-{source_code}-{page}-{fig}.png`
  - 예: `ref-seon-cm2-p123-fig1.png` (쎈 공통수학2 p.123 그림 1)

**출처 표기 의무**:
```latex
\begin{center}
\includegraphics[width=0.5\linewidth]{figures/reference/ref-seon-cm2-p123-fig1.png}
\end{center}
\vspace{-2mm}
{\footnotesize\itshape\color{gray} 출처: 쎈 공통수학2 (2024), p.123 (교육 목적 인용)}
```

**주의**:
- 시판 책 대량 크롭 금지 (회당 최대 1~2건)
- 저작권자 명시 필수
- 상업 배포용 자료에는 사용 지양 (내부 훈련용만)

### 4순위: TikZ 신규 작성 (좌표평면 대응 도해)

- 좌표평면·수학 그래프·정밀 도해는 TikZ 유지
- 자체 저작 · 저작권 이슈 없음
- 파일 저장 위치: 시험지 tex 파일 내 인라인 or `figures/typed/` (재사용 시)

## 3. `figures/` 폴더 구조 표준

```
figures/
├── commons/                     # Wikimedia Commons CC-BY-SA 이미지
│   ├── commons-pantograph-{date}.png
│   ├── commons-gps-satellite-{date}.png
│   └── LICENSES.md              # 각 이미지의 라이선스·출처 매핑
├── reference/                   # 참고자료 크롭 (교육 목적)
│   ├── ref-{source_code}-{page}-{fig}.png
│   └── LICENSES.md              # 각 이미지의 출처·페이지 매핑
├── typed/                       # TikZ 신규 도해 (자체 저작 · 재사용)
│   ├── kepler-orbit.tex

└── ai-generated/                # (미채택 · 미사용)
```

## 5. 출처 표기 매크로 (신설 예정)

`templates/style.sty`에 신설:

```latex
% Wikimedia Commons 출처 표기
\newcommand{\commonsCite}[2]{%
  \vspace{-2mm}%
  {\footnotesize\itshape\color{gray}
    출처: Wikimedia Commons (#1 · #2)%
  }%
}
% 사용: \commonsCite{원저작자}{CC BY-SA 4.0}

% 참고자료 인용 출처 표기
\newcommand{\referenceCite}[3]{%
  \vspace{-2mm}%
  {\footnotesize\itshape\color{gray}
    출처: #1, p.#2 · #3%
  }%
}
% 사용: \referenceCite{쎈 공통수학2 (2024)}{123}{교육 목적 인용}
```
