# 교재별 tier 캘리브레이션 표 v2.0 (v1.12 실측 회귀 매트릭스 기반)

## 목적

각 참고 교재의 섹션별 tier 매핑을 **v1.12 실측 회귀 매트릭스** (23종 벤더 · 2133문 실측 · 세션 62 flywheel) 기반으로 정의. Agent·시스템 자동 tier 판정 유효 · 신뢰도 임계 기반 승계.

## v1.3 → v2.0 전환 사유 (2026-07-21 세션 63 마스터 결정)

**v1.3 원칙** (2026-07-16 세션 46):
- 마스터 초기 라벨링만 유효 · Agent 자체 tier 재판정 절대 금지
- "실력Up" 등 섹션 문자열 → tier 매핑을 마스터 관점으로 일괄 지정

**v1.3 한계**:
- 초기 마스터 라벨링은 벤더 4~6종만 (블랙라벨·고쟁이·마플·쎈·개념원리·RPM)
- 실측 정합률 미검증 (마스터 감각 기반)
- 신규 벤더 추가 시 마스터 수동 라벨링 대기 (병목)

**v2.0 개선**:
- **v1.12 실측 회귀 매트릭스 (23종 벤더 · 세션 62 flywheel 결과)** 기준
- 각 벤더별 정합률·신뢰도 (A+~C 6단계) 세분
- **신뢰도 임계 정책**: A+·A급 (신뢰 ≥ 0.75)만 자동 tier 승계 · A- 이하는 수동 검증 대기
- 세션 63 P2 #77에서 이미 1030건 자동 정정 실행 (실측 검증)

## 신뢰도 임계 정책 (v2.0 신설)

### 자동 tier 승계 (A+·A급 · 신뢰 ≥ 0.75)

**대상 벤더** (v1.12 검증 완료):
- **A+ (100% 정합)**: 블랙라벨 STEP 3 · EBS 올림포스 고난도 (band 4) · 일품 (통합) · 1등급마스터 STEP 3·1등급++ · 플래티넘 STEP 3 · 2026-6월 학평 CM1
- **A (90%+ 정합)**: 마플시너지 STEP 3 · 쎈 C 사고력 · 일등급만들기 STEP 3 · 수학의 신 STEP 3 · EBS 학평기출 · 마더텅

**정책**:
- `star-classify.mjs v1.8 --min-confidence 0.75` 자동 --write 허용
- 신 파일 정독 시 위 벤더는 tier 필드 자동 채움
- Agent (problem-author v2.3+ · concept-author v1.2+) 자동 tier 신뢰 · 재판정 불요

### 수동 검증 대기 (A-·B+급 · 신뢰 0.5~0.75)

**대상 벤더**:
- **A- (78~85%)**: 절대등급 · 수학의바이블 (CM1+CM2) · 바이블 유형온 · 라이트쎈
- **B+ (73~82%)**: 완자 · 유형ZIP · 짱중요 · 마플교과서 · 유형만렙

**정책**:
- 자동 --write 배제 · dry-run 리포트만
- 신 파일 정독 시 tier 필드 예측값 (alt 포함) 기재 · 마스터 승인 대기
- Agent pick 시 alt·note 필드 참고

### 폐기 대상 (B·C급 · 신뢰 < 0.5)

**대상 벤더**:
- **B (45~68%)**: RPM · 개념원리 (CM2 통합)
- **C (28% · 소단원 특이)**: 개념원리 CM2 원·이동·ST·FN 4파일

**정책**:
- v1.3 초기 마스터 라벨링 유지 (자동 정정 안 함)
- 세션 62 v1 → v2 재정독 결과 (--write) 승인된 것만 반영
- 세션 63 P3 확대 정독 결과 부분 상향 (CM2-GM-이동·CM2-FN B- 승격)
