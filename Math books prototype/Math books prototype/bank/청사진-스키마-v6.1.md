# 통합 청사진 스키마 v6.1

**설립 목적**: 모든 교재 (시험지·정리편·유형편·연습편·테스트지) 출제의 단일 진입점. **시리즈 = 변수, 스키마 = 상수**. 어느 시리즈든 이 스키마로 청사진 작성 → `source-filter`·`problem-author`/`concept-author` → Gate 5.0 자동 검증 → 검수.

**격차 배경 (v6.0 → v6.1)**:
- v6.0은 시험지 25문 청사진 전용 · `slot.type = 선택형|서답형` 두 유형만
- v6.1은 정리편 (개념·대표·확인·연습·실전) 등 다양한 시리즈 슬롯 유형 지원

## §1. 최상단 스키마

```yaml
# 청사진.yaml
series_type: exam | jeongribyeon | yuhyeongpyeon | yeonseubpyeon | testpaper
series_name: DeeP Red 1회 | DeeP Math 정리편 | ...
book_title: 2026-2학기 와부고 예상 중간 1회 | 공통수학2 정리편 · 평면좌표 | ...
unit_code: CM1-EQ | CM1-PL | CM2-GM | CM2-ST | CM2-FN | CM2-RF | CM1-CB | CM1-MX
target_audience: 상위권 | 중상위권 | 중위권 | 중하위권 | 하위권
version: v1.0
established: YYYY-MM-DD

# 시리즈별 메타 (조건부 필드)
exam_meta:                        # series_type = exam 일 때만
  total_score: 100                # 총점 (시험지 100점 정합)
  duration_min: 50                # 시험 시간
  선택형_count: 12
  서답형_count: 5

  page_count: 15                  # 예상 페이지 수
  개념_count: 3                   # 개념 소단원 수
  대표예제_count: 6               # 대표 예제 수
  확인_count: 12                  # 확인 문제 수
  Level1_count: 12                # Level 1 연습
  Level2_count: 12                # Level 2 연습
  Level3_count: 3                 # Level 3 심화
  실전_count: 3                   # 실전유형 맛보기
```

## §2. 슬롯 스키마 (slots[])

각 슬롯은 문항 하나. 시리즈에 따라 slot.type이 다름.

```yaml
slots:
  - slot_id: 1                    # 시리즈 내 문항 번호
    slot_type: 선택형 | 서답형 | 개념 | 대표예제 | 확인 | Level1 | Level2 | Level3 | 실전
    unit_code: CM2-GM
    sub_section: (개념 슬롯인 경우) 두 점 사이의 거리 | 내분점·중점 | 무게중심
    
    # star 등급 (v3.0 3층 모델 · schema.md)
    target_star: 3 | 4 | 5 | 5_premium
    composite_range: [13, 19]     # star 3 = 13~19 · star 4 = 20~26 · star 5 = 27~32 · premium ≥ 33
    
    # 원본 은행 참조 (v3.0 tier 매핑 · Phase A · v6.2 필수 원본 번호)
    source:
      source_id: 고쟁이-CM2-CH01-STEP1-#014 | 개념원리-CM2-GM-#25 | RPM-CM2-GM-0018 | 마-CM2-GM-원-0512 | ...
      # 🔴 v6.2 (세션 63 신규): source_id에 실제 원본 번호 필수 (#숫자 or -0000 형식)
      # ❌ "개념원리-CM2-GM-표준유형 (거리·정삼각형)" 등 번호 없는 표준유형 참조 문구는 RED
      # ❌ "RPM-CM2-ST-명제 유사" 등 "유사" 표기는 RED (실 문항 pick 필수)
      # ✅ Gate 5.0 G3-a로 자동 검증 (source-filter --verify + 원본 번호 정규식)
      tier: star_3 | star_4 | star_5 | star_5_premium
      variation_type: number_only | equivalent | inspired | new
      copyright_similarity_target: [0.30, 0.85]  # 최소 변형 정책
    
    # mechanism 필드 (v2.0 · 89 mechanism)
    mechanism:
      primary: 거리 공식 미지수 결정      # Mechanism 은행 참조
      secondary: [조건 결합, 매개변수]     # 보조 mechanism
      insight_type: 절차형 | 조건통합형 | 통찰형 | 개념통합형
      depth: 1 | 2 | 3                      # 절차 1 · 조건 통합 2 · 통찰 3
    
    # 조건·구조 (문항 설계 · Gate 5.0에 참조)
    structure:
      constraint_count: 1 | 2 | 3+          # 조건 개수
      unknowns_count: 1 | 2 | 3+            # 미지수 개수
      subquestion_count: 0 | 2 | 3          # 소문항 개수 (0 = 단답)
      figure_needed: false | true
      figure_type: 좌표평면대응 | 원리도식 | 관계도  # figure_needed=true 일 때
    
    # 발문 요약 (저작권 준수 · 조건과 구할 대상만)
    problem_summary: |
      (2~4줄 요약)
    
    # 정답 (mathjs 검증 가능 형태)
    answer: 
    answer_verified_at: YYYY-MM-DD
    
    # 배점 (exam 전용)
    score:                          # series_type = exam
    
    # 페이지 배치 (조판 · Gate 5.0 layout 검증)
    page_placement:
      page_num: 1
      column: left | right | full
      probpair_partner: (opt) slot_id     # probpair 매크로 짝
    
    # 자기복제 방지 (structure-signature-check)
    signature:
      defBox: false | true              # 정의박스 사용
      primary_axis: 거리 | 내분 | 무게중심
      layout_hint: probpair | pagepair | probpairfillpage | grid
      narrative_length_chars: 100

# ── 정점 자격 (star 4·5·premium 슬롯만) ────
peak_qualification:
  slots: [15, 16, 17]                   # 정점 슬롯 목록
  qualification_criteria:
    C1_multi_polynomial_determination: false
    C2_condition_integration_integer_freedom: true
    C3_identity_square_disguise: false
    C4_multi_division_factor_combination: false
    C5_self_reference_parametric: false
    C6_unit_coupling_XU: false
  qualified_count: 3+                    # premium 4+ 필수
```

## §3. 시리즈별 slot_type 매핑

### 시험지 (exam)
- `slot_type: 선택형` — 5지 객관식 · 4점 배점
- `slot_type: 서답형` — 단답·논술 · 6·8점

### 정리편 (jeongribyeon)
- `slot_type: 개념` — 소단원 개념 요약 (dmconcept 박스)
- `slot_type: 대표예제` — star 3·4급 · 원본 pick + 최소 변형 + 풀이 포함
- `slot_type: 확인` — star 3·4급 · 대표예제 유형 훈련 · 발문만
- `slot_type: Level1` — star 3·4급 · 기초 연습
- `slot_type: Level2` — star 4·5급 · 표준 연습
- `slot_type: Level3` — star 5 premium · 심화 (통찰 정점)
- `slot_type: 실전` — 학평 기출 · star 4·5

### 유형편 (yuhyeongpyeon)
- `slot_type: 유형` — 유형별 대표 문제
- `slot_type: STEP1` — 기본 (도트 ●○○)
- `slot_type: STEP2` — 표준 (도트 ●●○)
- `slot_type: STEP3` — 심화 (도트 ●●●)

### 테스트지 (testpaper)
- `slot_type: dot1~5` — 5단계 도트 (\dota~\dote)

## §4. Gate 5.0 필수 검증 (시리즈 무관 14 도구)

청사진 저장 직후 자동 실행:

1. **`blueprint-validate.mjs`** — 스키마 정합 (필수 필드·타입)
2. **`blueprint-score-validator.mjs`** — composite 자동 산출 · target vs computed gap 검증
3. **`source-filter.mjs`** — 각 slot.source가 tier 매핑에 존재하는지
4. **`copyright-similarity-check.mjs`** — 각 slot 변형 유사도 0.30~0.85
5. **`structure-signature-check.mjs`** — 정점 슬롯 시그니처 자기복제
6. **`master-feedback-check.mjs`** — 마스터 지적 RED 키워드
7. **`cm1-curriculum-check.mjs`** — CM1 한정 · 교과과정 위반
8. **`standard-check.mjs`** — 교과 표준 용어·기호
9. **`overfull-check.mjs`** — 빌드 후 layout 위반
10. **`choices-width-check.mjs`** — 보기 환경 사전 검증
11. **`figure-need-compliance.mjs`** — 도형 필요성 정합
12. **`figure-answer-leakage-check.mjs`** — 도형 답 노출
13. **`figure-tikz-label-check.mjs`** — TikZ 라벨 4대 규약
14. **`insight-depth-check.mjs`** — 통찰 깊이 자동 채점

### 시리즈별 확장 게이트

- 시험지 추가: `total-score-check.mjs` (100점 정합)·`exam-layout-analyzer.mjs` (vspace 균등도)·`cross-round-insight-check.mjs` (회차 간)
- 정리편·유형편 추가: (필요시 신설 · 지금은 공통 14로 충분)
- 테스트지 추가: 15문 4페이지 정합

## §6. 워크플로우 순서 (모든 시리즈 공통)

```
1. design-author agent → 스타일·매크로·색 팔레트 (신규 시리즈만)
   ↓
2. 청사진.yaml 작성 (본 스키마 v6.1)
   ↓
3. Gate 5.0 자동 검증 (14 도구) → RED 0 도달까지 재작성
   ↓
4. concept-author (정리편) or problem-author v2.0 agent
   - 각 slot의 source_id → 원본 pick
   - 최소 변형 (숫자 or 동등 변형)
   - tex 조판
   ↓
5. solution-author agent → 답지 tex
   ↓
6. 빌드 (xelatex 2-pass) + 자동 검증 (post-tool hook)
   ↓
7. 검수 4종 (problem-review · solution-review · exam-review · independent-solve)
   ↓
8. 마스터 시각 확인 · 자산화 (refresh-all)
```
