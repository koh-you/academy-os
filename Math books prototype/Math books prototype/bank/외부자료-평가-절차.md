# 외부 자료 평가·분석 절차 v1.0 (2026-06-29 신설)

> **단일 출처**: 본 시스템 외부의 시판 책·PDF·기출 자료를 정독·평가·분석할 때 따르는 절차. 신규 출제 절차 (`bank/workflow.md` 7단계) + 자동 차단 게이트 5종이 *내부 자료 출제*에 적용되는 것과 달리, 본 절차는 *외부 자료 평가·보고*에 적용된다.
>
> **신설 동기**: 2026-06-29 아샘 짱 내신 FINAL 분석 사건. 분석자(클로드)가 본 시스템 단일 출처(`bank/CM1-교과과정.md` §1, `bank/anchors/CM1-MX.md`)를 무시하고 외부 지식으로 "행렬 곱셈은 CM1 범위 외 → RED" 단정. 마스터 신뢰도 의구심 제기. 본 절차로 재발 방지.

## §1. 적용 범위

- 시판 시험지·문제집 PDF 정독·평가
- 기출 문항 (학평·평가원·EBS·수능) 분석
- 다른 출판사·학원 자료 비교
- 모든 외부 자료에 대한 "★ 분포·난이도·교과 범위·통찰 깊이" 보고

본 절차가 적용되지 *않는* 영역:
- 본 시스템 자체 출제 (`bank/workflow.md` 7단계 적용)
- 본 시스템 자체 검수 (`bank/검수-절차.md` 3축 5단계 적용)

## §2. 의무 절차 5단계

### 단계 1 — 평가 대상 식별

1. 자료의 단원·시험범위 확인 (자료 표지·범위 표기)
2. 본 시스템 대응 단원 코드 확인 (예: CM1-MX, CM2-GM)

### 단계 2 — 단일 출처 6종 의무 grep

평가 *시작 전*에 반드시 다음 6종 단일 출처를 직접 grep:

| 단일 출처 | 의무 grep 내용 |
|---|---|
| `bank/CM1-교과과정.md` | 해당 단원의 §1 표 (허용·금지 도구) |
| `bank/schema.md` | 3층 모델 (M·I·X) + ★ 산정 알고리즘 |
| `bank/anchors/{과목}-{단원}.md` | 단원 ★ 1~5 앵커 풀 (T-code 분포) |
| `bank/마스터-지적/INDEX.md` | 부정 지적 누적 (위반 패턴) |
| `bank/4점-패턴-카탈로그/03-패턴-카탈로그.md` | 4축 패턴 (★ 4·5 슬롯 비교) |
| `bank/CM1-교과과정.md` §3.0 | 상위 과정 기본형 침투 금지 원칙 |

**🔴 grep 결과를 보고서에 명시 인용 의무** (단계 5 참조).

### 단계 3 — 외부 지식 단정 금지

다음 표현은 **단일 출처 인용 없이 사용 금지**:

| 🔴 금지 표현 | 사용 조건 |
|---|---|
| "교과 범위 외" | `bank/CM1-교과과정.md` §1 또는 §2 줄 번호 인용 의무 |
| "CM1 범위 외" "CM2 범위 외" | 동일 |
| "RED" 단정 | 단일 출처 §1·§2·§3 + 자동 도구 결과 인용 의무 |
| "2022 개정에서 X는 제외" | `bank/CM1-교과과정.md` 표 1행 인용 의무 |
| "교과서 표준 아님" | 단일 출처 + 시판 책 확인 의무 |

**🔴 분석자(클로드)는 외부 지식과 본 시스템 단일 출처가 충돌하면 *반드시 단일 출처를 따른다*.** 외부 지식이 더 정확할 가능성이 있더라도, 분석자가 자체 판단으로 단일 출처를 우회하면 신뢰도 체계 붕괴.

만약 분석자가 단일 출처가 *틀렸다*고 판단하면 → 분석 보고서를 보류하고 **마스터에게 단일 출처 검토 요청**.

### 단계 4 — 분석 내용 작성

내부 출제와 동일한 v3.0 3층 모델 + v3.4 ★ 5 최상위 기준 + 8 통찰 유형 적용. 다음 항목 의무:

- 각 슬롯 ★ 추정 (base_star + X 보정)
- 통찰 유형 라벨링 (I-XU·I-PD·I-CON 등 8종)
- depth_score 계산 (max × 2 + avg)
- ★ 5 strict 후보 식별 (depth ≥ 8.5, max=3, count ≥ 5)
- 본 시스템 자산과 비교 (앵커 풀, 미니모의·동화고 시리즈)

### 단계 5 — 보고서 작성 의무 인용

보고서 작성 시 다음 위치에 단일 출처 인용 의무:

1. **"교과 범위" 판정 부분**: `bank/CM1-교과과정.md:NN` (해당 줄 번호) 인용
2. **"RED" 단정 부분**: 단일 출처 + 자동 도구 결과 ("`cm1-curriculum-check.mjs` 위반 N건") 인용
3. **★ 5 strict 식별 부분**: `bank/schema.md` v3.4 §"★ 5 최상위 기준" 인용
4. **본 시스템과 비교 부분**: `bank/anchors/{단원}.md` 또는 `bank/INDEX.md` 통계 인용

## §3. 점검 자가 체크리스트 (보고서 송신 전)

분석자(클로드) 메시지 송신 직전 다음 항목 자체 점검:

- [ ] "교과 범위 외" / "RED" 단정에 `bank/CM1-교과과정.md:NN` 줄 인용 있는가?
- [ ] 외부 지식과 단일 출처가 충돌하지 않는가? (충돌 시 마스터 요청)
- [ ] 본 시스템 자산 (앵커·INDEX 통계) 통계가 보고서 주장과 모순되지 않는가?
- [ ] ★ 5 strict 식별이 `bank/schema.md` v3.4 임계와 일치하는가?
- [ ] 보고서가 본 시스템 자체 데이터를 *무시*하고 외부 지식만으로 결론짓지 않았는가?

자가 점검 통과하지 못하면 보고서 송신 보류.
