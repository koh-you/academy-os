## 5. 인사이트 — 마스터 책 작성 정책

### 5.1 같은 단원 다중 대상층 패턴
같은 단원·같은 유형 풀로 **여러 대상층 책을 동시 작성**. 본문 변형으로 ★ 조정 → 작업 효율 + 라벨 정합.

### 5.2 schema-driven label calibration
problem-review 검수에서 발견된 라벨 드리프트(예: 상위권 #8 등 22문)를 본문 강화로 해결. v1.0 → v2.0 진화 패턴.

### 5.3 우리 시스템과의 정합
- 마스터의 책 작성 패턴이 schema §10.6 cohort 정규화 정책과 일치
- audience별 ★ 분포가 schema §3.1 권장 분포와 거의 일치:
  - 상위권: {3:30, 4:40, 5:30} 권장 vs 책 {31, 41, 28} ✓
  - 중상위권: {2:15, 3:35, 4:35, 5:15} 권장 vs 책 {13, 37, 28, 22} ✓
  - 중위권: {2:25, 3:50, 4:25} 권장 vs 책 {25, 41, 25, 9(★4 추가)} 거의 일치

### 5.4 v1.3 시점 활용

bank-query CLI로 즉시 활용 가능:
```bash
node scripts/bank-query.mjs --unit CM1-EQ --star 3 --source OUT  # 마스터 책의 ★3 풀
node scripts/bank-query.mjs --unit CM1-EQ --star 4 --freq 3      # 학평 ★4 필수 패턴
```

recommend-slots-by-book.mjs로 신규 대상층 책 작성 시 즉시 슬롯 추천 가능. 같은 단원에 대해 (상위권→중상위권→중위권→중하위권→하위권) 5권 시리즈 작성 워크플로우 자동화 가능.
