## 0. 리스크 스코어링 개요

**리스크 스코어 R** (0~10점, 예상 iteration 회수와 강한 상관):

```
R = R_source + R_mechanism + R_precision + R_novelty − R_mitigation
```

| 축 | 배점 | 의미 |
|---|---|---|
| **R_source** | 0~3 | 소스 성숙도 (archive 유무·검증 완료 여부) |
| **R_mechanism** | 0~3 | mechanism 복잡도 (링크 수·자유도) |
| **R_precision** | 0~2 | 수치 정밀도 요구 (tip boundary·비율) |
| **R_novelty** | 0~2 | 신규성 (기존 archive 미매칭 · 신설) |
| **R_mitigation** | 0~3 | 완화 요소 (자동 도구·template lib·마스터 사전 승인) |

### 예상 iteration 매트릭스

| R 총점 | 예상 iteration | 판정 | 대응 |
|---|---|---|---|
| **0~2** | 0~1회 | GREEN · 안심 | 즉시 진행 |
| **3~4** | 1~3회 | YELLOW · 주의 | 마스터 사전 승인 권장 |
| **5~7** | 4~10회 | RED · 위험 | archive 대체 검토 필수 |
| **8~10** | 10+회 | 🔴 CRITICAL | 도입 재검토 (Commons/참고자료 우회) |

**세션 36 실증**: 사도기 v1~v5 = 5회, GPS 3회, 위성 3회 = 총 27+회 (초기 R 예상 8~10 → CRITICAL).

## 3. R_precision · 수치 정밀도 요구

| 요구 | 배점 | 예시 |

## 7. 리스크별 대응 규약

### GREEN (R 0~2)

- 즉시 진행 가능
- Gate 4.5 자동 도구 3종 통과만 확인
- 마스터 사전 승인 불필요

### YELLOW (R 3~4)

- 마스터 사전 승인 권장 (스케치·수치 예시 제시)
- 자동 도구 3종 통과 후 시각 확인 요청
- iteration ≤ 3회 예상 → 3회 초과 시 소스 재검토

### RED (R 5~7)

- **archive 대체 검토 필수**
- `bank/도해-카탈로그.md` M-01~M-N 유사 mechanism 재사용 검토
- 우회 소스 (Wikimedia Commons·참고자료 크롭) 검토
- 마스터 사전 승인 없이 진행 금지
- iteration 4회 초과 시 즉시 중단·재설계

### CRITICAL (R 8~10)

- **도입 재검토**
- 대안 소스 (Commons·참고자료 크롭) 우선
- TikZ 신규 작성 최후의 수단
- 마스터 명시적 승인 없이 진행 절대 금지
