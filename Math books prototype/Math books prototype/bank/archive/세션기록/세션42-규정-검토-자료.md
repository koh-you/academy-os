### 2.2 우회 원인 가설

**가설 A. 프롬프트가 너무 길어 agent가 앞부분만 정독**
- v1.3 프롬프트는 425 line
- 발문 카탈로그·심층 원칙·범위 규정은 중반부 이후에 있음

**가설 B. 카탈로그 자체가 "지시적"이 아니라 "설명적"**
- 예: "⟨⟩ 금지"라고 명시했지만 대안 예시 부재
- agent가 대안 확신 못 하면 원본 유지 경향

**가설 C. agent가 자체 검증 조항을 형식적으로 통과**
- "5축 체크: PASS"라고 자체 보고하지만 실제 grep 수행 안 함
- 청사진에 "check: true" 필드만 채움

**가설 D. 시스템 문서 간 상호 참조 부족**
- 예: schema §2.13 (신규 조합 신중)이 problem-author 프롬프트에서 명시적 이식되어 있지 않음
- agent가 §2.13 언급만 보고 실제 적용 안 함

## 3. 마스터 검토 요청 항목

### 3.1 v1.4 개발 전 확인 필요

1. **시스템 문서 강제도 재정의**:
   - 어떤 문서가 "필수 정독"이고 어떤 게 "권장"인가?
   - "필수"라도 agent가 우회하면 어떻게 감지·차단할 것인가?

2. **agent 프롬프트 크기 vs 준수도 트레이드오프**:
   - 프롬프트 확장으로 계속 대응하면 준수도 떨어짐
   - "필수 조항 1페이지"로 압축 vs "전면 카탈로그 링크"

3. **자체 검증 형식화 문제**:
   - agent가 자체 "체크: PASS"라고 보고하는 것을 어떻게 검증?
   - 각 체크마다 자동 도구 grep 결과 강제 첨부?

4. **정밀 다층구조 정의**:
   - "P1~P6 신호" ≠ "정밀 다층구조"
   - 정밀 다층구조란 무엇인가? (마스터의 판단 기준)

5. **신규 조합 신중 기준**:
   - schema §2.13은 있지만 "얼마나 신중해야 하는가"의 구체 기준 부재
   - "시중교재 실재 검증 방법"의 절차 명시 필요

### 3.2 카탈로그 실효성 검증

각 카탈로그 실제 준수도:
- ⟨⟩ 금지 문서는 8회 지적 → 카탈로그 등재됨 → 9회 재발 → **문서 존재만으로는 준수 안 됨** 실증

## 4. 발견된 시스템 결함 (미해결)

### 4.1 표기 정확성 카탈로그 부재
- 합집합·교집합 표기 괄호 규정 없음
- "$(A \cup B) \cap C$" vs "$A \cup B \cap C$" 규정 명시 필요

### 4.2 표현 정확성 카탈로그 부재
- "실수 $a$에 대하여 다항식 $f_a(x)$" 오용 규정 없음
- $a$가 계수인지 변수인지 명확 구분 규정 필요

### 4.3 발문 간결성 카탈로그 부재
- 소문항 발문 길이 규정 없음
- "장황한 발문" 판별 기준 없음

### 4.4 CM2 학기별 시험 범위 카탈로그 부재
- 2학기 중간 = GM + ST · 다항식 포함 여부 미명시
- 각 회차 range.units 사전 검증 절차 없음

### 4.5 신규 조합 실재성 검증 절차 부재
- schema §2.13에 "시판 실재만 이식" 원칙은 있음
- 하지만 "이 조합이 시판 실재인가"를 검증하는 절차·도구 없음
- data/all-premium-samples.json 1,326문 검색 도구 부재
