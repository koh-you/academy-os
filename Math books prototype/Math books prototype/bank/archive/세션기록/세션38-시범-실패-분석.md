- **2회 골든 페이지 1**: `\probpair×2 + \vfill`
- **2회 골든 페이지 2**: `\probpair×2 + \vfill`
- 2회 페이지 3만 `\probgridfour` (주석: "마스터 반복 지적 대응 · 고정 슬롯")

**decider 판정 근거**:
- 3회 페이지 1·2: 4문 모두 SMALL(34mm) · 편차 σ=0 · 특수요소 0
- decider 규칙: 편차 σ ≤ 8mm AND 특수요소 0 → `\probgridfour`
- 판정: probgridfour 정확 매칭

**골든 관행 (마스터 실전)**:
- 페이지 1·2 = **어떤 조건이든 probpair×2 + \vfill 기본**
- 페이지 3 = **마스터 반복 지적으로 grid** (문항 크기 균등 시)
- 서답형은 청사진 결정

**근본 원인**:
1. **decider 판정 vs 마스터 골든 관행 불일치** — decider의 임의 알고리즘이 골든 관행 반영 안 함
2. **골든 관행 문서화 부재** — CLAUDE.md · templates · style.sty 어디에도 "선택형 페이지 1·2 = probpair×2 기본" 규칙 명시 없음. 2회 tex에 주석은 있지만 시스템 지식으로 등재 안 됨
3. **첫 제작 시 골든 참조 부족** — 알고리즘만 신뢰, 마스터 실전 관행 검색 안 함

## 3. 개선방안

### 방안 A · golden-layout-registry 신설 (이슈 1)

**목적**: 마스터 확립 골든 배치 관행을 시스템 지식으로 등재. decider가 참조.

**신설 파일**: `bank/golden-layout-registry.yaml`
```yaml
# 마스터 확립 골든 배치 관행 (실전 관행 → decider 참조)
# 알고리즘 우선순위: registry > decider 알고리즘 판정

CM2:
  선택형:
    page_1: probpair×2 + \vfill   # 편차·특수요소 무관 · 마스터 골든
    page_2: probpair×2 + \vfill   # 편차·특수요소 무관 · 마스터 골든
    page_3: probgridfour          # 문항 균등 시 grid, 특수요소 있으면 pair×2
    page_3_override:
      - condition: 특수요소 ≥ 2
        layout: probpair×2 + \vfill
  서답형:
    default: 청사진 layout_hint 우선

CM1:
  # TODO: 1회 골든 참조로 등재
```

**decider 개선**:
```javascript
// 1순위: registry 조회
const registry = loadGoldenRegistry();
const preset = registry[unit][section][`page_${pageN}`];
if (preset && !slotHasOverride) return preset;
// 2순위: 알고리즘 판정
```

**등재 프로세스**:
- 마스터 명시 관행 발견 시 registry에 즉시 등재
- 신규 관행 감지 자동 알림 (2회 tex 주석 grep 등)

**관련**: [[feedback_layout_auto_decider]] v3.0 갱신
