## 3. 실패 양상 (예상)

**probpair 매크로 특성** (v3.1, 세션 31 신설):
- `\probpair{좌}{우}`가 savebox로 좌우 슬롯 자연 크기 측정
- max(좌, 우) + probvpadding = 통일 높이
- 좌우 baseline 정렬

**편차 σ ≈ 13.5mm의 결과**:
- 짧은 슬롯(#1 35mm)이 긴 슬롯(#4 60mm)과 pair → 짧은 쪽에 25mm 여백 발생
- 상단 정렬 시 짧은 슬롯 하단에 큰 여백 · 시각적 불균형
- Page 하단 \vfill이 하단으로 밀려 페이지 균형 실패

**추가 요인**:
- probpair 사이 \vfill이 pair 간격 조정 · 슬롯 내부 여백은 조정 못 함
- 페이지 상단 \vspace{4mm} vs 페이지 2 \vfill (일관성 없음)

## 5. 근본 원인

### 결함 1 · 슬롯 크기 편차 정책 부재
- registry는 macro 선택 규칙만 명시 (probpair×2 vs probgridfour)
- **슬롯 크기 편차 제약 정책 없음**
- decider가 편차 계산은 하나 (σ 리포트) · **편차 큰 경우 대응 로직 없음**

### 결함 2 · 청사진에 예상 크기 필드 부재
- 청사진의 각 슬롯에 `estimated_mm` 필드 없음
- 저자·decider 모두 실제 tex 렌더링 후에야 편차 발견 (사후)
- 사전 예방 시스템 없음

### 결함 3 · 문항 배치 재조정 로직 부재
- decider가 문항 순서 fixed로 취급 (1~12 순차 · 4문/페이지)
- 편차 큰 슬롯을 다른 페이지로 이동하거나 pair 파트너 변경 가능성 미탐색

### 방안 I · 청사진 슬롯 예상 크기 필드

**청사진 slots[] 신규 필드**:
- `estimated_mm: N` (int, 저자 예상 or 자동 산출)
- 자동 산출 로직: `layout-auto-decider`의 `estimateHeightSlot()` 함수 재사용

**검사 로직**:
```javascript
function checkSlotSizeUniform(pageSlots) {
  const heights = pageSlots.map(s => s.estimated_mm);
  const sd = stddev(heights);
  if (sd > 10) return { warning: true, sd };
  return { warning: false };
}
```

### 방안 J · decider 슬롯 재배치 자동 시도

**로직**:
- 편차 σ > 10mm 감지 시 4문 slot 재배치 (편차 최소 pair 조합 탐색)
- 예: (1,2,3,4) 대신 (1,4,2,3) 배치 · pair (1,4) + (2,3) 편차 균등화

**한계**: 문항 번호 유지 필요 시 재배치 어려움. 대안: **crop grid 강제** (probgridfour로 100mm 고정).
