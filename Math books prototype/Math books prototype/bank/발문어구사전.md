## 1. 발문 도입 어구

### 1.1 변수·미지수 설정

| 표준 | 사용 빈도 (시판) | 예 |
|---|---|---|
| "~를 ~라 하자." | 매우 높음 | "두 양수 $a$, $b$의 곱을 $k$라 하자." |
| "~를 ~라 할 때," | 매우 높음 | "$f(x) = x^3 + ax + b$라 할 때," |
| "다음 조건을 만족시키는 ~에 대하여" | 높음 | "다음 조건을 만족시키는 두 자연수 $a$, $b$에 대하여" |
| "~인 ~가 있다." | 중 | "복소수 $z = a + bi$가 다음 조건을 만족시킨다." |

### 1.2 조건 부여

| 표준 | 예 |
|---|---|
| "다음 [조건]을 만족시킨다." | "복소수 $z$가 다음 조건을 만족시킨다." |
| "~이 성립한다." | "다음 등식이 성립한다." |
| "~을 만족시키도록 ~을 정한다." | "조건을 만족시키도록 $k$의 값을 정한다." |

3. ★ 5 슬롯은 *모두 "추론하기"* 라벨이어야 함 (절대 표준)
4. 검수 도구 `scripts/rpm-wording-check.mjs`에 [출제의도] 라벨 검사 추가 (v1.1 예정)

## §20. 학평 풀이 어구 보강 (v2.3 신설)

### §20.1 학평 풀이 압축 어구 (RPM과 다른 학평 특징)

학평 해설은 RPM 답지보다 *압축적*. 동일 의미 어구도 짧게 표현:

| 학평 압축 | RPM 표준 (대응) | 비고 |
|---|---|---|
| "이라 하자" / "이라 하면" | "라 하면" / "이라 하자" | 동일 |
| "이므로" | "이므로" | 동일 |
| "이다." | "이다." | 동일 |
| "따라서" | "따라서" / "$\\therefore$" | RPM은 둘 다 빈번 |
| "주어진 식은 ... 이다." | "주어진 식 = ..." | RPM이 더 명시적 |

**관찰**: 학평 해설은 *공간 제한* 때문에 RPM보다 압축적. 본 시스템 답지는 *학습용*이므로 **RPM 표준이 우선** (자세함 우선).
