## EQ-M1. 복소수 사칙연산·실수부·허수부 분리 (복소수)

- **원리**: 복소수를 실수부와 허수부로 분리하고 각각을 0이 되는 조건으로 변환하여 정수 및 실수 계수를 결정한다.
- **심층 조건**:
  - 복소수 상등: 실수부=0, 허수부=0 동시 만족
  - 비분해형 분모 유리화: (a+bi)/(c+di) = (a+bi)(c-di) / (c²+d²)
  - 다항식 대입: z를 정해진 식에 대입한 후 다시 분리
- **자유도**: 허수 단위 i의 거듭제곱 적용 vs 상등 조건 중 어느 것을 우선하는지 판단
- **앵커**: 고쟁이-CM1-CH04-STEP2-#288, #289, #290
- **오답 유도**: 허수부 조건을 놓치고 실수부 조건만 사용; 분모 유리화 계산 오류

## EQ-M2. 켤레복소수·실수 조건 & 상등식 연립 (복소수)

- **원리**: z와 켤레복소수 z̄의 관계식을 이용하여 z의 실수부·허수부 또는 모듈러스 조건을 도출한다.
- **심층 조건**:
  - z + z̄ = 2·Re(z) (실수부 2배)
  - z - z̄ = 2i·Im(z) (허수부 2배 + i 계수)
  - z·z̄ = |z|² (모듈러스 제곱)
  - 켤레 상등: z = z̄ ⟺ z는 실수
- **자유도**: 주어진 조건에서 z + z̄ vs z - z̄ vs z·z̄ 중 어느 관계식을 먼저 세울지 판단
- **앵커**: 고쟁이-CM1-CH04-STEP2-#295, #296, #297, #300, #301
- **오답 유도**: z̄ 대신 z 자신을 사용; 켤레의 성질 (z̄)² ≠ (z)² 혼동

## EQ-M3. 복소수 거듭제곱의 주기성 & i^n 규칙 (복소수)

- **원리**: i의 거듭제곱은 4주기(i¹=i, i²=-1, i³=-i, i⁴=1)를 따르고, 복소수 z의 고차 거듭제곱도 유사 주기를 보인다.
- **심층 조건**:
  - i^n의 4주기: n ≡ 0,1,2,3 (mod 4) 각각 1, i, -1, -i
  - z^8=1 또는 z^3=1 같은 근의 주기: n값을 주기로 나눈 나머지로 축약
  - 교대급수/부분합: 텔레스코핑 또는 주기별 그룹핑
- **자유도**: 주어진 n 또는 m에 대해 n mod 주기를 계산하여 축약할지, 직접 계산할지 판단
- **앵커**: 고쟁이-CM1-CH04-STEP2-#304, #305, #306; STEP3-#350, #362, #365
- **오답 유도**: 주기 크기 착각(2주기로 생각); 부호 오류(i² = +1으로 착각)

## EQ-M4. 음수 제곱근의 부호 조건 & 근호식 엄격 관리 (복소수)

- **원리**: √(-a²) = ai (a>0일 때), √x·√y = -√(xy) (x<0, y<0 조건)과 같이 제곱근의 부호를 엄격히 관리한다.
- **심층 조건**:
  - √(-k)는 순허수; √k√k = |k| 아님 (부호 반대일 때)
  - 두 조건 병합: √x·√y=√(xy) vs √x·√y=-√(xy) 구간 분기
  - 절댓값·제곱근 혼합: |x| = √(x²), √(x²) = |x|의 관계
- **자유도**: 근호 안이 음수인지 양수인지 먼저 판정하고 부호를 결정할 것인지 후차 결정
- **앵커**: 고쟁이-CM1-CH04-STEP2-#313, #314, #315
- **오답 유도**: 부호 조건 없이 √(xy) = √x·√y 자동 적용; 절댓값 처리 누락

## EQ-M5. 이차방정식 판별식·중근·근의 부호 판정 (이차방정식)

- **원리**: 판별식 D의 부호로 실근·중근·허근을 판정하고, 근과 계수의 관계로 두 근의 부호를 분석한다.
- **심층 조건**:
  - D > 0: 서로 다른 두 실근
  - D = 0: 중근
  - D < 0: 켤레 허근 (실계수 방정식에서만)
  - 근의 부호: αβ의 부호(곱), α+β의 부호(합)로 부호 판정
- **자유도**: D만 계산할지, D와 함께 근과 계수를 모두 사용할지 판단
- **앵커**: 고쟁이-CM1-CH04-STEP2-#318, #319, #320, #321, #322
- **오답 유도**: 중근 조건 K에 관계없이 성립한다는 항등식 해석 실패; 근의 부호 조건과 D 조건 분리 실패

## EQ-M6. 근과 계수의 관계 & 대칭식 (이차방정식)

- **원리**: α+β=-b/a, αβ=c/a를 이용하여 근을 직접 구하지 않고 대칭식(α²+β², α³+β³ 등)을 계산한다.
- **심층 조건**:
  - 기본 항등식: (α+β)² = α² + 2αβ + β²
  - 3제곱: α³+β³ = (α+β)³ - 3αβ(α+β)
  - 역수·분수 대칭식: 1/α + 1/β = (α+β)/(αβ)
  - 새 방정식: α,β를 근으로 갖는 이차방정식 재구성
- **자유도**: 어떤 대칭식을 계산할 것인지, 그리고 근과 계수 관계 어느 조합을 사용할지 판단
- **앵커**: 고쟁이-CM1-CH04-STEP2-#326, #327, #328; CH05-STEP2-#402, #429; CH06-STEP2-#523, #524
- **오답 유도**: 근의 합·곱 대입 오류; 대칭식 전개 계산 실수

## EQ-M7. 허근의 켤레 성질 & 실계수 방정식 (이차방정식)

- **원리**: 실계수 이차방정식이 허근을 가지면, 그 두 근은 반드시 켤레 쌍이다.
- **심층 조건**:
  - 두 허근: α + β = -b/a (실수), αβ = c/a (실수)
  - α와 ᾱ의 관계: α + ᾱ = 2·Re(α), αᾱ = |α|²
  - 근과 계수 연립: α + ᾱ = -b/a, α·ᾱ = c/a 동시 만족
- **자유도**: 허근이 주어졌을 때 그 켤레를 즉시 인식할지, 아니면 두 번째 근을 계산으로 구할지 판단
- **앵커**: 고쟁이-CM1-CH04-STEP2-#329, #331, #332; STEP3-#346, #347
- **오답 유도**: 계수가 실수인 것을 간과하고 임의의 두 근을 놓음; 켤레 성질 오해

## EQ-M8. 이차함수 그래프 & 직선 위치 관계 (이차함수)

- **원리**: 이차함수와 직선의 교점 개수, 접선 조건(D=0), 그리고 특정 영역 위·아래 조건을 판별식과 함수값으로 판정한다.
- **심층 조건**:
  - 접선: D = 0 (중근)
  - 두 교점 사이 거리: |α - β| = √D / |a|
  - 특정 점에서 부호: f(x₀) > 0 또는 f(x₀) < 0
  - 근의 분리: 특정 점과 근의 대소 관계 (경계값 부호 판정)
- **자유도**: 판별식만 쓸지, 함수값 부호까지 결합할지 판단
- **앵커**: 고쟁이-CM1-CH05-STEP2-#402, #403, #412, #413, #415, #416
- **오답 유도**: 접선 조건에서 D=0만 쓰고 y절편 미결정; 근의 분리에서 경계값 부호 누락

## EQ-M9. 제한 범위에서 최댓값·최솟값 & 축 위치 case (이차함수)

- **원리**: 폐구간 [a, b]에서 이차함수의 최댓값·최솟값은 축의 위치에 따라 경계값 중 하나이거나 꼭짓점 값이다.
- **심층 조건**:
  - 축 x = p가 구간 [a, b] 안: 최솟값 = f(p)
  - 축이 구간 왼쪽: 최솟값 = f(a)
  - 축이 구간 오른쪽: 최솟값 = f(b)
  - 부호 조건 병합: 축 위치 + 최댓값·최솟값 수치 조건
- **자유도**: 3개 case를 모두 계산할지, 아니면 축 위치 하나만 확정할지 판단
- **앵커**: 고쟁이-CM1-CH05-STEP2-#426, #428, #430, #432; STEP3-#448, #458
- **오답 유도**: case 분리 누락; 축이 구간 경계에 있을 때 등호 처리 오류

## EQ-M10. 삼·사차방정식 인수분해 & 조립제법 (삼·사차방정식)

## EQ-M11. 복이차 치환 & 공통부분 치환 (삼·사차방정식)

- **원리**: x⁴ + ax² + b = 0을 X = x²로 치환하거나, (x² - 4x)² 형태에서 공통부분을 한 문자로 대체한다.
- **심층 조건**:
  - 복이차: X ≥ 0 조건 (X = x²이므로 음수 근 배제)
  - 공통부분 치환: 같은 식이 두 번 이상 나타날 때 효과적
  - 실근 vs 허근: X의 부호에 따라 x의 실근 개수 결정
- **자유도**: 공통부분을 얼마나 깊게 찾을 것인지, 그리고 치환 후 판별식 조건을 함께 체크할지 판단

## EQ-M12. 연립이차방정식 & 인수분해/치환 (연립이차방정식)

- **원리**: 두 이차식의 연립을 인수분해 또는 대칭식 치환(x+y, xy)으로 풀어서 해를 구한다.
- **심층 조건**:
  - 선형 소거: (일차) × (이차) 형태면 일차식으로 대입 소거
  - 인수분해: f(x,y)·g(x,y) = 0 형태로 변형하여 일차 인수 도출
  - 대칭식: A = x+y, B = xy로 A, B 구하면 x, y는 t² - At + B = 0의 근
- **자유도**: 어느 변수를 소거할지, 또는 대칭식을 활용할지 판단

## EQ-M13. ω의 성질 & x³=1 허근의 주기 (특수 근)

- **원리**: x³ = 1의 허근을 ω라 할 때, ω² + ω + 1 = 0이 성립하고, ω³ = 1이므로 거듭제곱이 3주기를 따른다.
- **심층 조건**:
  - ω³ = 1, ω ≠ 1 ⟹ ω² + ω + 1 = 0
  - 1 + ω + ω² = 0 (항등식)
  - ω^n의 값: n mod 3에 따라 ω^0=1, ω^1=ω, ω^2=ω̄
  - 분수식 간단화: (1+ω+ω²)의 결과 0 활용
- **자유도**: ω의 켤레가 ω²임을 인식할지, 거듭제곱 주기를 적용할지 판단
- **앵커**: 고쟁이-CM1-CH06-STEP2-#509, #510, #511; STEP3-#530, #537
- **오답 유도**: ω³=1과 ω²+ω+1=0 중 하나만 사용; 복잡한 분자·분모 간단화 실수

## EQ-M14. 부정방정식 & 정수 조건 (부정방정식)

- **원리**: 정수 조건을 갖는 방정식에서 인수분해 또는 완전제곱식으로 변형하여 정수 쌍을 열거한다.
- **심층 조건**:
  - 근과 계수: 두 근의 곱·합이 정수이면 정수 근 존재
  - 인수분해: (x-a)(x-b) = N 형태에서 정수 약수 쌍 열거
  - 완전제곱: (x-a)² + (y-b)² = N에서 두 제곱 합 분해
  - 실수 조건: A² + B² = 0이면 A = 0, B = 0
- **자유도**: 모든 가능한 약수 쌍을 나열할지, 문제 조건으로 범위를 제한할지 판단
- **앵커**: 고쟁이-CM1-CH06-STEP2-#523, #524, #525, #526; STEP3-#536
- **오답 유도**: 음수 약수 쌍 누락; 완전제곱 형태 변형 실수

## EQ-M15. 절댓값 부등식 & 경계점 경우분류 (부등식)

- **원리**: |f(x)| ≤ a 또는 |f(x)| + |g(x)| ≥ b를 경계점으로 구간을 나누어 풀이한다.
- **심층 조건**:
  - 절댓값 하나: |x-a| ≤ b ⟺ a-b ≤ x ≤ a+b
  - 절댓값 두 개: 경계점으로 3구간 이상 분리
  - 합/차 함수: |f(x)| + |g(x)|는 구간에 따라 다항식으로 표현
  - 최솟값: |x-a| + |x-b|의 최솟값 = |a-b|
- **자유도**: 모든 구간을 나열할지, 핵심 구간만 계산할지 판단
- **앵커**: 고쟁이-CM1-CH07-STEP2-#562, #563, #564, #566; STEP3-#602
- **오답 유도**: 경계점 누락; 절댓값 풀이 후 등호 조건 혼동

## EQ-M16. 이차부등식 상시 성립 & 판별식 조건 (부등식)

- **원리**: f(x) > 0이 모든 x에 대해 성립하려면 a > 0 AND D < 0이어야 한다.
- **심층 조건**:
  - 아래 볼록 (a>0): f(x) > 0 성립하려면 D < 0
  - 위로 볼록 (a<0): f(x) < 0 성립하려면 D < 0
  - 최댓값·최솟값 부등식: 최댓값·최솟값을 조건으로 변환
  - 이중 판별식: x 변수 먼저 소거하고, 그 후 y 판별식 조건
- **자유도**: D < 0인지 D ≤ 0인지(등호 포함 여부) 정확히 관리할지 판단
- **앵커**: 고쟁이-CM1-CH07-STEP2-#570, #572, #573, #574, #576, #582; STEP3-#593, #606
- **오답 유도**: 판별식 조건만 쓰고 최고차 계수 부호 누락; 등호 포함 여부 오류

## EQ-M17. 근의 분리 & 경계값 부호 조건 (근의 분리)

- **원리**: 이차방정식의 두 근이 특정 구간에 위치하도록 하려면 판별식, 축 위치, 그리고 경계값에서의 함수 부호 3가지를 모두 확인한다.
- **심층 조건**:
  - 두 근이 (a, b) 구간 안: D ≥ 0, a < 축 < b, f(a) > 0, f(b) > 0
  - 한 근이 (a, c) 안, 다른 근이 (b, d) 안 (b>c): f(c) > 0, f(b) < 0 등 부호 조건 4개
  - 근의 합·곱 조건: (α+β)/2 (축), α·β (곱)의 부호·크기
- **자유도**: 3가지 조건을 동시에 체크할지, 순차적으로 체크할지 판단
- **앵커**: 고쟁이-CM1-CH05-STEP2-#405, #406; CH07-STEP2-#594, #595, #596; STEP3-#611, #612
- **오답 유도**: 경계값 부호 조건 누락; 등호 포함 여부 오류

## EQ-M18. 연립이차부등식 정수해 개수 & 매개변수 범위 (연립부등식)

- **원리**: 두 이차부등식의 해를 수직선에 그려서 교집합을 구하고, 그 안의 정수 개수가 지정된 값이 되도록 하는 매개변수 범위를 역산한다.
- **심층 조건**:
  - 첫 부등식: (x-a)(x-b) ≥ 0이면 x ≤ a ∨ x ≥ b (a<b 가정)
  - 둘째 부등식: (x-c)(x-d) ≤ 0이면 c ≤ x ≤ d (c<d 가정)
  - 교집합: 수직선에 두 해를 표시하고 정수 카운트
  - 역산: 정수 개수 조건에서 매개변수 범위 추출
- **자유도**: 정수해 개수를 정확히 셀지, 또는 근의 대소를 사전에 분기할지 판단
- **앵커**: 고쟁이-CM1-CH07-STEP2-#585, #586, #587, #589; STEP3-#614
- **오답 유도**: 수직선 표시 오류; 정수 경계값에서의 등호 포함 여부 혼동
