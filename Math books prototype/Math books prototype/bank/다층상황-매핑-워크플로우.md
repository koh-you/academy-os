# 다층 상황부여 매핑 워크플로우 v1.0

> **목적**: 수학 개념(예: "원의 방정식·접선")이 주어졌을 때 3층 구조(Frame·Object·Math)의 다층 상황 발문 초안을 3~5개 자동 제안하는 매핑 시스템 명세.
> **작성일**: 2026-07-10 · Phase 3 상황부여 강화 프로젝트
> **의존 자료**:
> - [`bank/학교기출-다층상황-카탈로그.md`](학교기출-다층상황-카탈로그.md) — 7 대유형(A-G) · 15 패턴(P01-P15) · 3층 구조
> - [`bank/외부자료-상황후보-DB.md`](외부자료-상황후보-DB.md) — 22 소스(S001-S022) · 개념 역인덱스 8 카테고리
> **자동화 도구**: [`scripts/situation-generator.mjs`](../scripts/situation-generator.mjs)

---

## 0. 사용 시나리오 (한 눈에)

1. 마스터·솔루션 작성자가 목표 슬롯 결정: 예 "**★ 5 · CM2-GM · 원의 방정식 접선**"
2. 스크립트 호출: `node scripts/situation-generator.mjs --concept "원의 방정식" --star 5`
3. 스크립트가 카탈로그 패턴 + DB 소재를 교차 매핑하여 3~5개 다층 상황 후보 출력
4. 마스터가 후보 중 1~2개 선택, 소재 조사 후 발문 확정
5. 발문 확정 후 `problem-review`·`solution-author`로 후속 절차 진행

**중요**: 스크립트는 **후보 제안** 도구지 완성 발문 생성기가 아님. 최종 발문은 소재 원리 조사·수식 세팅·검증을 마스터가 수행.

## 1. 입력·출력 명세

### 1.1 입력

| 인수 | 필수 | 기본값 | 값 | 예 |
|---|---|---|---|---|
| `--concept` | ✅ | — | 수학 개념 키워드 | `"원의 방정식"`, `"접선"`, `"함수"`, `"명제"`, `"경우의 수"` |
| `--star` | | 5 | 목표 별점 (1~5) | `4`, `5` |
| `--source-prefer` | | auto | 카테고리 A~F 강제 지정 | `B` (도구), `C` (자연현상) |
| `--top` | | 3 | 상위 후보 수 | `3`, `5` |
| `--used` | | — | 제외할 소재 ID (자기복제 방지) | `"S001,S002"` |
| `--format` | | markdown | 출력 포맷 | `markdown`, `json` |

### 1.2 출력

각 후보 = 다음 6항 세트:

```
[후보 N]
- 재구성 유형: 유형-A1 / B2 / C1 등 (§3 참조)
- 패턴 참조: P01·P04 등 (카탈로그)
- 층 1 (Frame): 세계관·도구·현상 소개 텍스트 초안
- 층 2 (Object): 구체 대상 텍스트 초안 (조건 박스·시각 자료 요구사항 포함)
- 층 3 (Math): 수학 조건·문제 텍스트 초안
- 참고 소스: S00N (외부DB) + P0N (카탈로그)
- 재현 난이도: 하 / 중 / 상
- 자기복제 위험: 회차별 사용 이력 확인 지침
```

## 2. 매핑 로직 5단계

### Step 1: 수학 개념 파싱

입력 `--concept` 값을 표준 태그로 정규화. 예:

| 사용자 입력 | 정규화 태그 | 단원 코드 |
|---|---|---|
| "원", "원의 방정식", "원방정식" | `circle_equation` | CM2-GM |
| "접선", "원의 접선" | `tangent_line` | CM2-GM |
| "직선", "직선의 방정식" | `line_equation` | CM2-GM |
| "함수", "함수 그래프" | `function_graph` | CM2-FN |
| "합성함수", "역함수" | `function_composition` | CM2-FN |
| "집합" | `set` | CM2-ST |
| "명제" | `proposition` | CM2-ST |
| "경우의 수", "순열", "조합" | `counting` | CM1-CB |
| "행렬" | `matrix` | CM1-MX |
| "이차방정식", "이차함수" | `quadratic` | CM1-EQ |
| "도형의 이동", "대칭" | `symmetry_translation` | CM2-GM |

파싱 실패 시 사용자에게 표준 태그 목록 제시.

### Step 2: 카탈로그 패턴 조회

카탈로그의 15 패턴 중 해당 개념 태그와 부합하는 것을 조회. 매핑 표(스크립트 내부):

| 개념 태그 | 우선 패턴 | 재현 난이도 |
|---|---|---|
| `circle_equation` | P01·P02 (A·B형) · P14 (F형) | 중~상 |
| `tangent_line` | P01·P02 | 중~상 |
| `line_equation` | P02·P10 | 하~중 |
| `symmetry_translation` | P01·P12 | 중 |
| `function_graph` | P07·P13 (F형·G+F형 융합) | 중~상 |
| `function_composition` | P08·P13 | 중 |
| `set` | P04·P05·P09 (D형·F형) | 하 |
| `proposition` | P06·P08·P09 (E·F형) | 중 |
| `counting` | P03·P10·P11·P12 (C·G형) | 중~상 |
| `matrix` | (CM1) — G형 P10 참조 | 중 |
| `quadratic` | P06 (E형 증명) | 중 |

`--star`가 3 이하면 D형(P04·P05)만 권장. ★ 4~5는 A·B·C·E·F·G형 전부 열림.

### Step 3: DB 역인덱스에서 소재 조회

DB의 "수학 개념 → 외부자료 역인덱스"에서 해당 개념의 소스 ID 목록 획득. 예 `circle_equation` → [S001, S002, S004, S011, S012, S013, S014, S022].

`--source-prefer`가 지정되면 해당 카테고리만 필터.
`--used`에 지정된 ID 제외.

### Step 4: 층별 조합 (패턴 골격 + 소재 채움)

각 (패턴, 소재) 쌍에 대해:

1. **층 1 (Frame)** 초안 = 카탈로그 패턴의 층 1 형식 + DB 소재의 "원리 요약" 첫 2~3문장
2. **층 2 (Object)** 초안 = 카탈로그 패턴의 층 2 구조 (조건 박스·규칙 명세·시각 자료) + DB 소재의 "상황부여 활용 예"
3. **층 3 (Math)** 초안 = 개념 태그의 표준 수식 골격 (원 방정식·좌표 대응·경우의 수 등) + 목표 별점에 맞는 조건 복잡도

### Step 5: 다층 검증

각 후보에 대해 4항목 자동 점검:

- [ ] 층 1이 층 3과 직접 연결되지 않고 층 2를 경유하는가? (Frame → Object → Math)
- [ ] 층 2가 관용어 수준이 아닌 실질 역할을 하는가? (시각 자료/조건 박스/규칙 명세)
- [ ] 층 3의 수식이 층 2 대상에 자연스럽게 연결되는가?
- [ ] `--used` 소재와 겹치지 않는가?

한 항목이라도 실패하면 후보 제외 or 재구성 유형 변경.

## 3. 재구성 패턴 5~7 표준화 유형

카탈로그 15 패턴을 실용 관점에서 다음 7 유형으로 압축:

### 유형-A1: 기계도구 + 실물 대상

- **골격**: (도구 원리 소개 문단) → (구체 대상 시각 자료: 캐릭터·구조체·도안) → (도구 작용 후 수학화)
- **카탈로그 매핑**: P01 (사도기+펭귄)
- **소재 매핑**: S001(사도기)·S004(아스트롤라베)·S005(카메라 옵스큐라)·S011(앙부일구)
- **적합 개념**: `circle_equation`·`tangent_line`·`symmetry_translation`
- **★ 범위**: 4~5
- **재현 난이도**: 상 (도구 원리 조사 + 대상 도안 설계)

### 유형-B1: 천체 현상 + 이상화 모델

- **골격**: (현실 현상 사진 or 실측 문단) → (이상화 모델 3항 가정 박스) → (모델 위 수식·방정식)
- **카탈로그 매핑**: P02 (개기월식+3원 모델)
- **소재 매핑**: S002(개기월식)·S013(케플러)·S014(GPS)·S022(사이언스타임즈)
- **적합 개념**: `circle_equation`·`tangent_line`·`line_equation`
- **★ 범위**: 5
- **재현 난이도**: 중~상 (모델 설계 · 정의 박스 자체 구성)

### 유형-B2: 광학·자연 현상 + 좌표 모델

- **골격**: (광학·자연 원리 소개) → (좌표계 위 굴절·반사 경로 시각) → (직선·각·좌표 조건)
- **카탈로그 매핑**: P02 변형
- **소재 매핑**: S005(카메라 옵스큐라)·S012(무지개)·S015(프리즘)·S016(태양광 반사판)
- **적합 개념**: `line_equation`·`quadratic`·`function_graph`
- **★ 범위**: 4
- **재현 난이도**: 중

### 유형-C1: 활동·놀이 + 반복 규칙

- **골격**: (놀이·게임 프레임) → (규칙 3단계 명시 + 상태 카드·주머니) → (2회 이상 반복 후 경우의 수·확률)
- **카탈로그 매핑**: P03 (숫자 뽑기 2회)
- **소재 매핑**: (외부 소재 의존도 낮음, 자체 설계 우선)
- **적합 개념**: `counting`
- **★ 범위**: 5
- **재현 난이도**: 상 (규칙 정합 + 반복 상태 추적)

### 유형-D1: 학급·조사 프레임 + 조건 박스 (즉시 이식)

- **골격**: ("A고등학교 학생 N명…" 첫 줄) → (조건 박스 (가)(나) 2~3항) → (집합·경우의 수 조건)
- **카탈로그 매핑**: P04·P05·P09
- **소재 매핑**: (자체 설계) + S018(선거방송)·S021(KOSIS)
- **적합 개념**: `set`·`proposition`·`counting`
- **★ 범위**: 3~4 (하) or 4~5 (은닉 강화 시)
- **재현 난이도**: 하

### 유형-E1: 정리·증명 + 도해 + 빈칸

- **골격**: (수학 정리 명제 소개) → ([증명] 프레임 + 도해) → (빈칸 (가)(나)(다) 3항)
- **카탈로그 매핑**: P06 (예각삼각형+산술기하)
- **소재 매핑**: S006(파르테논 황금비)·S015(프리즘 각)
- **적합 개념**: `quadratic`·`proposition`·`symmetry_translation`
- **★ 범위**: 4~5
- **재현 난이도**: 중

### 유형-F1: 5명제 이진코딩 답

- **골격**: ("다음은 …의 성질에 대한 명제들이다.") → (명제 5개 카탈로그 ㄱ~ㅁ) → ($16a_1 + 8a_2 + 4a_3 + 2a_4 + a_5$)
- **카탈로그 매핑**: P08 (합성·역함수 5명제)
- **소재 매핑**: (자체 설계, 개념별 5명제 세팅)
- **적합 개념**: `function_composition`·`proposition`·`set`
- **★ 범위**: 3~4
- **재현 난이도**: 중 (5명제 미묘한 오답 설계)

### 참고: 유형 선택 가이드 표

| 개념 | 1순위 유형 | 2순위 유형 |
|---|---|---|
| 원의 방정식·접선 | A1·B1 | B2 |
| 도형의 이동·대칭 | A1·E1 | (자체) |
| 함수 그래프·합성 | F1·D1 | E1 |
| 집합·명제 | D1·F1 | E1 |
| 경우의 수·순열·조합 | C1 | D1 |
| 이차방정식·이차함수 | B2·E1 | A1 |

## 4. 품질 체크리스트 (다층 요건)

발문 확정 전 다음 8항목을 100% 통과해야 함.

### Frame (층 1)

- [ ] 첫 2~4줄 안에 세계관·도구·현상을 명시적 문장으로 소개했는가?
- [ ] 문장이 관용어("어떤 도구를 사용해서")가 아닌 구체 명명("사도기의 정의는… 원리는…")인가?

### Object (층 2)

- [ ] 시각 자료(그림·좌표계) or 구체 조건 박스 or 규칙 명세(3단계)가 있는가?
- [ ] 관용어("어떤 대상") 없이 대상성이 확립되었는가? (캐릭터·구조체·조사 결과·명제 등)
- [ ] 층 1과 층 3을 실질 연결하는가? (관용어 수준 아님)

### Math (층 3)

- [ ] 층 2 대상에 자연스럽게 이어지는가? (갑작스러운 등장 아님)
- [ ] 수식·조건이 목표 별점에 부합하는가? (★ 5는 통찰 3개 이상 강제)
- [ ] 층 1의 프레임이 층 3 풀이에서 의미론적 앵커로 유지되는가?

### 자기복제 방지

- [ ] 같은 소재를 시리즈 내 2회차 이상 재사용하지 않는가?
- [ ] 같은 재구성 유형을 같은 회차에 2슬롯 이상 사용하지 않는가?

**모든 항목 통과 후 발문 확정** → `problem-review` 호출.

## 5. 자동화 도구 사용 예

### 5.1 기본 사용

```bash
# 원의 방정식 ★ 5 후보 3개 (기본)
node scripts/situation-generator.mjs --concept "원의 방정식" --star 5

# 접선 ★ 5 후보 5개, B(도구) 카테고리 강제
node scripts/situation-generator.mjs --concept "접선" --star 5 --source-prefer B --top 5

# 자기복제 방지: S001·S002는 이미 사용됨
node scripts/situation-generator.mjs --concept "원의 방정식" --star 5 --used "S001,S002"

# JSON 출력 (파이프라인 통합)
node scripts/situation-generator.mjs --concept "함수" --star 5 --format json > candidates.json
```

### 5.2 반복 워크플로우

1. 회차 슬롯 결정 후 `situation-generator` 여러 개념에 대해 순차 실행
2. 후보 중 1~2개 선정하여 마스터 검토
3. 소재 원리 조사 (Wikipedia·MathWorld·평가원 지문 등)
4. 발문 초안 작성
5. `problem-review` → `solution-author` 표준 워크플로우

### 5.3 회차 이력 관리

같은 시리즈 안에서 `--used` 인수에 이미 사용된 소재 ID를 누적:

- 회차 1: S001, S002 사용
- 회차 2: `--used "S001,S002"`
- 회차 3: `--used "S001,S002,S004,S011"`
