# 발문 금지 워딩 카탈로그 v1.0

**배경 (2026-07-14 세션 42 마스터 지적)**: 8회 시험지 v1.2에서 발문에 답 형태 노출 (자취가 원임을·도형(원)의)·불필요 관용어 (근거와 함께)·비표준 기호 (⟨보기⟩)·교과 회고 (여집합 별도 설명) 등 발문 결함 다수 발견. 발문 워딩 결함이 fake premium 못지 않게 문항 품질을 훼손함.

**적용 범위**: `\begin{problem}` 발문·서술형 소문항 지시문·정의박스·`\begin{conditions}` 조건 서술 전체.

## 1. 🔴 답 노출 (H 축 감산 강제)

**정의**: 발문에서 정답의 형태·개수·범위 등을 미리 알려주는 표현. 학생 통찰 발동 기회 박탈.

### 1.1 자취 형태 노출

| 금지 | 대체 | 이유 |
|---|---|---|
| "자취가 원임을 서술하시오" | "자취의 방정식을 구하시오" | 자취가 원인지 학생이 유도 |
| "자취의 원 $C_2$라 할 때" | "자취를 $C_2$라 할 때" | 원 형태 학생 발견 |
| "도형(원)의 방정식을 구하시오" | "도형의 방정식을 구하시오" | 원 형태 노출 금지 |
| "이루는 원의 반지름은?" | "이루는 도형의 반지름은?" 또는 재구성 | 원 형태 노출 |

### 1.2 개수·범위 노출

| 금지 | 대체 | 이유 |
|---|---|---|
| "정수 $a$의 개수는?" (감지 힘든 정도의) | 개수 노출 정당 (문항 자체가 카운트 유형이면 허용) | 카운트 발문 정당 |
| "네 점의 좌표를 구하시오" (실제 4개일 때) | "점들의 좌표를 모두 구하시오" | 개수 사전 노출 금지 |
| "$k$의 값의 합을 구하시오" (여러 값 존재 명시) | 정당 (합 문제) | 정당 |

## §6. 🔴 표기 정확성 (v2.0 신설 · 세션 42 후반부)

**정의**: 수학 표기법 위반. 학생 이해 혼란·수학 논리 왜곡.

### 6.1 집합 연산 표기 (괄호 강제)

**9회 #5 실제 결함**:
```latex
% ❌ 위반 예 (실제 9회 #5 유형)
$A \cup B \cap C$    % 우선순위 모호

% ✅ 정정
$(A \cup B) \cap C$ 또는 $A \cup (B \cap C)$ (의도 명확화)
```

**grep 패턴**: `\\cup [A-Z]*\\cap` (연속 사용 시 괄호 없음 감지)

### 6.2 여집합·집합 표기 정합

- $A^c$ 사용 시 반드시 전체집합 $U$ 사전 정의
- $\overline{A}$·$A^c$·$U \setminus A$ 혼용 금지 (하나만 채택)

### 6.3 좌표점 표기

- 로마체 좌표점: `\mathrm{P}(a, b)` (기울임체 P 금지)
- 여러 점: `\mathrm{A}$, $\mathrm{B}$, $\mathrm{C}` (쉼표+공백 정합)
- $\overline{\mathrm{AB}}$ (선분) vs $\mathrm{AB}$ (문자열) 구분

### 6.4 grep 패턴 자동 감지

```regex
\\cup [A-Z]*\\cap                    # 괄호 없는 집합 연산 chain
[^\\{]P\([0-9a-z]+, ?[0-9a-z]+\)     # 기울임체 좌표점
\\overline\{[A-Z]{2,}\}[^,\.\s]      # 미완성 선분 표기
```

## §7. 🔴 표현 정확성 (v2.0 신설 · 세션 42 후반부)

**정의**: 수학 개념 표현 오용. 특히 계수 vs 변수 혼동.

### 7.1 다항식 매개 표기 (핵심)

**9회 #17 실제 결함**:
```latex
% ❌ 위반 (실제 9회 #17)
실수 $a$에 대하여 다항식 $f_a(x)$는 ...

% 문제: $a$는 계수(매개변수)이고 $x$가 변수
% $f_a(x)$가 $a$에 대한 다항식으로 오독 가능
```

**정정 표기**:
```latex
% ✅ 대안 1 (명확)
실수 $a$에 대하여, 다항식 $f(x) = x^2 - 2ax + a^2 - 4$를 생각하자.

% ✅ 대안 2 (첨자 유지, 변수 명시)
실수 $a$에 대하여, $x$에 대한 다항식 $f_a(x) = x^2 - 2ax + a^2 - 4$를 생각하자.
```

**핵심 원칙**:
- **다항식의 변수를 명시** ("$x$에 대한 다항식") · 매개(계수)와 변수 구분 명확화
- $f_a$ 첨자로 매개 표시할 때 반드시 "$x$에 대한" 명시

### 7.2 함수 정의 표기

- 함수 정의 시 정의역·공역 명시 원칙:
  - `$x$에 대한 함수 $f(x) = ...`
  - `실수 전체에서 정의된 함수 $f: \mathbb{R} \to \mathbb{R}$` (CM2 범위에서는 자제)
- CM2에서는 "$x$의 함수 $f(x)$" 표기 표준

### 7.3 매개변수 표현

**금지**: "매개변수" 용어 자체 (미적분Ⅱ § 곡선의 방정식 정식 용어 · CM2 침투 금지)
**대체**: "실수 $k$의 값에 관계없이"·"$k$에 대한 조건"·"임의의 실수 $k$에 대하여"

### 7.4 grep 패턴 자동 감지

```regex
다항식 \$f_[a-z]\(x\)\$          # 변수 명시 없는 다항식 첨자 표기
매개변수                          # CM2 침투 금지 어구
$f_a$이(라|고)                    # $a$가 계수인데 $f_a$가 명사로 사용
```

## §8. 🔴 발문 간결성 (v2.0 신설 · 세션 42 후반부)

**정의**: 소문항 발문이 장황할 때 학생 이해 저해. "정밀 다층구조"가 아닌 언어 장황화로 난이도 위장.

### 8.1 원칙

#### 🔴 v2 개정 (2026-07-30 세션 105 마스터 확립) — 길이는 대리 지표다

마스터 문제제기:
> **"왜 숫자 제한을 두어야 하는가? 문제가 길면 안 되는 건가?"**

**정당한 문제제기다. 길이 자체는 난이도·품질과 무관하다.** 평가원 지문형 문항은 길다. 길이가 곧 결함이면 지문형을 쓸 수 없다.

길이 제한이 실제로 잡으려던 것은 셋이다:

| 진짜 잡으려는 것 | 직접 지표 (판정에 사용) |
|---|---|
| 한 발문에 **다중 지시**가 섞임 | **지시 동사 개수 ≤ 1** (§8.3) |
| **조건이 발문에 뭉침** → 조건박스로 분리해야 함 | **발문 내 독립 조건 ≤ 1** (2개↑면 조건박스) |
| 좁은 컬럼 **조판 붕괴** | **렌더 줄 수 ≤ 3행** (PDF 실측) |

🔴 **길이(40자)는 판정에서 제외하고 참고 출력으로만 남긴다.** 위 세 직접 지표가 판정축이다.

**오탐 실증**: 재현-1회 #16(2) 46자 —
> "고정점 $\mathrm{A}(a,b)$, 추적점 $\mathrm{C}(x,y)$일 때 연필 $\mathrm{B}$의 좌표를 $a,b,x,y$로 나타내시오"

다중 지시도 아니고 조건 뭉침도 아니다. 길어진 이유는 **점 5개의 좌표 표기**이며, 40자로 줄이려면 필요한 정보를 빼야 한다. → 길이 규칙의 오탐.

#### 참고 지표 (판정 아님)

- 소문항 1개당 발문 길이 **≤ 40자 권장** (지문형 예외 · 지문 자체 별도 계산)
- 🔴 **측정 정의**: **렌더 글리프** 기준 · **공백 제외** · **마지막 지시 어구**("구하시오"·"서술하시오"·"논술하시오"·"나타내시오"·"보이시오") **제외**
- ⚠️ §8.4 grep 패턴의 **`60`은 임계가 아니라 완충값**이다. 정규식이 `(1)` 뒤 문자를 통째로 세어 LaTeX 마크업(`$...$`·`\mathrm{}`)이 섞여 부풀려지므로 **"40 + 마크업 여유 20"** 으로 잡은 값이다. **60을 표준으로 오독하지 마라** — 세션 105에 실제로 그 오독이 있었고, "60자 초과 0건"을 성과로 보고했으나 정책 기준(40자)으로는 3건 초과 상태였다
- 조건이 많으면 문제 상단 `(가) (나) (다)` 조건 목록으로 분리 (조건박스 적용 기준은 [[feedback_condition_box_required_star5]] §적용 기준 세분화 참조 — **문장 구조에 녹은 조건은 면제**)

### 8.3 다중 지시 분리 원칙

- "~하고, ~하며, ~를 이용하여" 다중 지시 절대 금지
- 조건 3개 이상이면 (가)(나)(다) 상단 conditions 박스로 분리
- 소문항은 단일 지시 (구하시오·서술하시오·판정하시오 · 하나만)

### 8.4 grep 패턴

```regex

서술하시오.*구하시오               # 다중 지시 동시 요구
하고,.*하며                         # 다중 지시 나열
```

## §9. 🔴 시험 범위 검증 (v2.0 신설 · 세션 42 후반부)

**정의**: 각 회차의 시험 범위를 명확 규정 · 범위 밖 소재 사전 차단.

### 9.1 CM2 학기별 시험 범위 (와부고 기준)

| 학기·시기 | 범위 | 단원 코드 |
|---|---|---|
| **1학기 중간** | 도형의 방정식 | CM2-GM 전체 |
| **1학기 기말** | 도형의 방정식 + 집합과 명제 (일부) | CM2-GM + CM2-ST §1~§2 |
| **2학기 중간** | 도형의 방정식 (심화) + 집합과 명제 (전체) | CM2-GM 심화 + CM2-ST 전체 |
| **2학기 기말** | 함수 + 유리·무리함수 | CM2-FN + CM2-RF |

**중요**: **2학기 중간에 다항식 (CM1-PL) 포함되지 않음** · #14 다항식 나눗셈은 범위 밖

### 9.2 청사진 range.units 강제 검증

```yaml
range:
  units: [CM2-GM, CM2-ST]     # 2학기 중간 표준 · CM1-PL 배제
  sub_units_included:
    CM2-GM: [G01, G02, G03, G04]     # 도형 4개
    CM2-ST: [S01, S02, S03]           # 집합·명제 3개
  excluded_units: [CM1-PL, CM1-EQ, CM1-CB, CM1-MX, CM2-FN, CM2-RF]
```

### 9.3 범위 침입 시 처리

- 청사진에 범위 밖 unit이 slot에 등장 → 자동 도구 RED
- CM1 결합 유형은 range.units 명시 없으면 배제
- 부분 결합 (예: "이차함수 문제인데 CM2 관점만") 허용 여부는 문서 명시 필요

### 9.4 자동 도구 (D6 신설)

`scripts/curriculum-scope-check.mjs`:
- 각 슬롯 unit 필드 vs range.units 대조
- 발문·풀이 grep으로 침입 소재 감지 (예: "다항식의 나눗셈"·"이차함수의 그래프")
- RED 시 재출제 강제
