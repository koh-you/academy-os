# 앵커 견주기 판정 명세 v2.0

## 🔴 v1 → v2 에서 바뀐 것 — 정답표가 사라졌다

v1 은 **학평 문번**(`#30 → ★ 5 프리미엄`)을 정답표로 놓고 사다리를 시험했다. **그것이 틀렸다.**

> **마스터 확정 (2026-08-01)**: 「문번으로 평가하는 건 이미 다 삭제했다」 · 「**사다리가 정답표로 충분해**」

**왜** — 세션 106 판정자 2인이 독립으로 **「문번·배점은 깊이 신호가 아니다」**라고 냈고 그래서 견주기로 전환했다.
세션 107 본 검정이 실측으로 재확인했다 — **같은 문번이 다른 깊이를 준다**:

| 문번 | 판정 (V1/V2) |
|:-:|---|
| #21 (2024.3) · #21 (2022.3) | A4/A4 · **A3/A3** |
| #30 x 4회차 | A5/A5 세 번 · **A4/A4 한 번** |
| #27 x 2회차 | **둘 다 A2/A2** |

두 판정자가 **각 문항마다 서로 일치**했다. 판정 잡음이 아니라 **문항이 실제로 다른 것**이다.

🔴 **그래서 v1 의 「밴드 적중」 통과선은 무효다.** 문번은 표본을 층화할 때 참고하는 **약한 사전분포**로만 남는다.
폐기 표시: `bank/학평-공통앵커-규약-v1.md` §6밴드 체계 표 머리.

### 정답표가 사다리라면 무엇을 검정하는가

외부 대조가 없어도 **자(尺)로서의 자격**은 검정할 수 있다. 자에게 물을 것은 넷이다.

| | 묻는 것 | 재는 법 |
|:-:|---|---|
| ① **내부 정합** | 자의 눈금끼리 모순이 없는가 | 앵커 맹검 서열 · 중복·통찰 충돌 검사 |
| ② **재현성** | 사람을 바꿔도 같은 칸에 얹히는가 | 잡음비 (판정자 간) |
| ③ **안정성** | 시간을 두고 다시 재도 같은 칸인가 | 잡음비 (시점 간) |
| ④ **적용 가능성** | 어떤 문항이 와도 견줄 자리가 있는가 | 「견줄 상대가 없다」 건수 |

🔴 **①이 ②보다 먼저다.** 눈금이 서로 모순이면 아무리 재현돼도 그 재현은 뜻이 없다.
세션 107 에서 실제로 A5d 와 A4c 가 **같은 문항**이었다 — 두 밴드의 대표를 한 문항이 겸했다.

## 1. 사다리 위치의 수치 환산

판정자는 점수를 매기지 않는다. 「어느 앵커와 같은 급인가」만 말한다.
그 말을 집계하려면 수치가 필요하므로 **환산 규칙만** 정한다.

| 판정자 표기 | 수치 |
|---|:-:|
| `A3 과 같음` | 3.0 |
| `A3~A4` | 3.5 (중점) |
| `A5 보다 깊음` | 5.5 |
| `A1 보다 얕음` | 0.5 |
| `견줄 상대가 없다` | **결측** — ④의 집계 대상. 사유를 반드시 기록 |

🔴 **판정자에게 이 표를 주지 않는다.** 판정자는 말로 답하고, 환산은 집계자가 한다.
수치를 보여 주면 「점수를 매기지 말라」는 지시와 충돌한다.

🔴 **「위치」와 「가장 가까운 앵커」는 다른 것을 잰다** (판정자 V1 지적).
`A3~A4` 라 적고 A3 을 고른 것과 A4 를 고른 것은 표기가 같아도 다른 판정이다.
**연속량(위치)은 잡음비·간격에**, **이산 결정(가장 가까운 앵커)은 밴드 배정에** 쓴다. 섞지 않는다.

## 2. ① 내부 정합 — 자의 눈금끼리 모순이 없는가

**(1) 앵커 중복 금지.** 한 문항이 두 밴드의 대표일 수 없다.
검사: 앵커 전체를 원 출처까지 펼쳐 대조한다. 시판 교재 앵커는 「(교육청 기출)」 표기를 특히 확인한다.
> 실패 사례 — CM2 A5d(고쟁이 CH05-STEP3 #367) = A4c(학평 2020.11 #29). **그 경계는 정의상 0 이었다.**

**(2) 밴드 안 통찰 충돌 금지.** 같은 밴드의 두 앵커가 같은 통찰을 요구하면 한 점에 뭉쳐 **눈금이 성글어진다.**
→ [[feedback_anchor_selection_rules]] §2

**(3) 출처 등급과 어긋나지 않을 것.** 정독 파일이 문항별로 손 분류한 등급이 있으면 그것을 따른다.
`tier_mapping` 은 STEP 단위 일괄 배정이라 **문항별 손 분류가 더 정밀하다.**
> 실패 사례 — A5e(고쟁이 #595)는 출처 파일이 **★ 4 후보**로 분류한 문항이었다.

**(4) 앵커 맹검 서열.** 밴드를 감춘 채 앵커들을 깊이 순으로 세우게 한다.
- **통과선**: 판정자 2인 이상에서 **역전 0** · 밴드 평균 간 **최소 간격 0.5칸 이상**
- 🔴 이것은 순환논법이 아니다. 판정자는 **어느 앵커가 어느 밴드인지 모른 채** 세운다

## 3. ② 재현성 — 잡음비

**일원배치 변량모형의 분산성분비.** 구현: `scripts/noise-ratio.mjs` (단일 출처).

```
MSE     = 문항별 「판정자 간 표본분산」의 평균          … 판정자를 바꿀 때의 흔들림
MS_item = k x (문항 평균들의 표본분산)                  k = 판정자 수
s2_item = (MS_item - MSE) / k                          … 문항이 실제로 벌어진 정도
잡음비  = MSE / s2_item
```

**통과선: 0.042 이하.**

| 실측 | 잡음비 |
|---|:-:|
| 절대값 채점 12문 x 3인 | 0.067 |
| 견주기 (밴드 균등 12문) x 2인 | 0.039 |
| **견주기 본 검정 (밴드 균등 20문) x 2인** | **0.034** |

### 🔴 잡음비는 표본 구성에 좌우된다 — 반드시 밴드 균등으로 잰다

| 견주기 표본 | 잡음비 |
|---|:-:|
| 밴드 균등 12문 | 0.039 |
| 밴드 치우친 20문 | **0.066** |

분모(`s2_item`)가 **문항이 얼마나 벌어져 있는가**이기 때문이다. 한쪽에 몰린 표본은
분모가 줄어 잡음비가 커진다 — **사다리가 나빠서가 아니다.**
- 🔴 표본은 **밴드 균등**으로 짠다
- 🔴 **다른 표본에서 잰 잡음비끼리 비교하지 않는다**

## 4. ③ 안정성 — 시점을 바꿔도 같은 칸인가

같은 문항 묶음을 **시차를 두고 다시** 얹는다. 재판정자는 이전 산출물을 보지 않는다.
집계는 §3 과 같은 식이되 `rater` 자리에 **회차**를 넣는다.

**통과선: 잡음비 0.042 이하** (재현성과 같은 선).

🔴 **아직 한 번도 측정하지 않았다.** 자로 쓰려면 이것이 있어야 한다 —
재현성만 있고 안정성이 없으면 「그날의 자」다.

## 5. ④ 적용 가능성 — 견줄 자리가 있는가

**통과선: 「견줄 상대가 없다」 0건.**

판정자에게 이 답을 **허용해야** 한다 ([[feedback_axis_validation_dual_criteria]] — 판정 불가를 막으면
없는 눈금이 있는 척 메워진다). 다만 남발하지 않도록 사유를 반드시 쓰게 한다.

### 🔴 사다리는 밴드 x 형식 격자로 채운다
지금까지 **세로(밴드)만 채우고 가로(형식)를 비워** 두었다. 세션 107 판정자 2인이 공통으로 지목한 빈칸:

| 빈칸 | 증상 |
|---|---|
| 빈칸추론이 **A3 에만** | A4·A5 로 올라오면 견줄 상대가 없다 |
| 보기형이 **A4 에만** | |
| **「짧은데 깊은」 앵커 없음** | A4·A5 앵커가 전부 조건상자 두세 줄 이상. 짧고 깊은 문항에서 판정이 **+1.5칸** 튀었다 |
| GM 최상단 눈금이 사실상 하나 | A5b·A5c 둘 다 「이차함수 + 원」 |
| CB 최상단이 한 문뿐 | CB 상위 문항이 오면 곧바로 판정 불가 |

## 6. 🔴 맹검 절차

**문번은 정답표가 아니게 됐지만 맹검은 여전히 필요하다** — 회차·문번·배점이 보이면
판정자가 문항을 풀지 않고 **관습적 난이도 인상**으로 답하게 된다.

1. 문항 원문을 **전사**한다. 회차·문번·배점·단원을 모두 지운다
2. 무작위 순서로 라벨을 붙인다. **밴드 순서로 늘어놓지 않는다**
3. 판정자에게 주는 것: 전사된 발문 + 사다리 문서. **표본의 밴드 구성을 알리지 않는다**
   (밴드마다 몇 문인지 알면 답을 맞춰 배분할 수 있다)
4. 판정자는 **전부 자력으로 푼 뒤** 위치를 정한다
5. 두 판정자는 서로의 산출물을 보지 않는다

### 🔴 앵커 정독이 맹검을 깬다 — 세션 107 실패
앵커를 확인하러 원문 PDF 를 열면 **표본 문항이 같은 PDF 안에 있었다.** 판정자 2인이 독립 신고했다.
> V1: 「그 정보를 판정에 쓰지 않았다고 믿지만, **믿음은 증거가 아니다.**」

**수리 (둘 중 하나 · 앞쪽 우선)**
