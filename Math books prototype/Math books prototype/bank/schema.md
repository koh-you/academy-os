## 1. 코드 체계

### 1.1 문제 코드: `{과목}-{단원}-{일련번호}`

- **과목**: `CM1`(공통수학1) / `CM2`(공통수학2). 추후 미적분·확률통계 등 확장 시 동일 2자리 코드 추가.
- **단원**: 2자리 영문 약자 (아래 표).
- **일련번호**: 3자리 zero-padded (`001`~`999`). 단원 내 등록 순서.

예: `CM2-FN-001`, `CM1-EQ-027`, `CM2-RF-A12`(앵커)

### 1.2 단원 약자

| 과목 | 단원 | 약자 |
|---|---|---|
| CM1 | 다항식 | PL |
| CM1 | 방정식과 부등식 | EQ |
| CM1 | 경우의 수 | CB |
| CM1 | 행렬과 그 연산 | MX |
| CM2 | 도형의 이동 | GM |
| CM2 | 집합과 명제 | ST |
| CM2 | 함수 | FN |
| CM2 | 유리함수와 무리함수 | RF |

추가 과목/단원이 생기면 본 표에 행 추가 후 코드 부여.

### 1.3 유형 코드 (단원 내부)

기존 유형 코드 그대로 유지(R01-R07, M01-M07, T01-T22 등). 문제 YAML의 `type:` 필드에 기록.

### 1.4 등록 prefix 체계 (v3.1, 2026-06-24 통합 등록 정책)

`bank/problems/`의 모든 .md 파일은 다음 5종 prefix 중 하나로 시작한다. 자동화 도구(`build-index.mjs`, `bank-query.mjs`, `anchor-compare.mjs`, `build-anchors.mjs`, `recommend-slots-by-book.mjs`)는 본 표를 *단일 등록 정책*으로 인식한다.

| prefix | 출처 종류 | 단위 | 파일 ID 예시 | status | 본문 | 통찰 라벨 |
|---|---|---|---|---|---|---|
| `DI-` | 깊이와통찰 학원 표본 | 1:1 (문항) | `DI-F1-007.md` | `meta_only` | 미등록 | 정답률 z-score 정규화 |
| `OUT-` | 우리 책 출제 | 1:1 (문항) | `OUT-04-유리함수와무리함수-001.md` | `approved` | 등록 | 직접 채점 |
| `MS-` | 마플시너지 유형 카탈로그 | n:1 (유형 1개 = 5~14문 풀 대표) | `MS-01-03.md`, `MS-II04-16.md` | `type_meta_only` | 미등록 (정책 금지) | BASIC·NORMAL·TOUGH → ★ 매핑 |
| `SRC-` | 시판 책 정점 표본 | 1:1 (문항) | `SRC-블랙라벨-CM1-PL-001.md` | `meta_only` | 미등록 (정책 금지) | I-XX × depth 라벨링 + score |
| `EX-` | 학평·평가원·EBS·수능 본기출 | 1:1 (문항) | `EX-마더텅-PL-137.md`, `EX-2024-6평-28.md` | `meta_only` | 미등록 (정책 금지) | I-XX × depth 라벨링 + score |

**status 종류**:
- `approved`: 본문·풀이 등록 완료. 책에 인용 가능.
- `meta_only`: 메타데이터(통찰·★·정답률)만 등록. 본문은 원 출처(PDF) 참조.
- `type_meta_only`: 유형 단위 메타 (n:1 풀 대표). 마플시너지처럼 *카탈로그 유형* 단위.

**원 출처별 등록 금지 정책**:
- 마플시너지·시판 책·학평·평가원 본문은 *저작권·정책상 본문 전사 금지*. 메타데이터(통찰 라벨·정답률·★·세련도 패턴)만 등록.
- 책 출제 시 본문은 변형 출제 후 OUT-*로 별도 등록.

**자동화 도구 인식 규칙**:
- `INDEX.md` 통계: 5종 prefix 카운트 분리 표시.
- `bank-query.mjs`: `--source DI|OUT|MS|SRC|EX|all`로 필터.
- `anchor-compare.mjs`: SRC·EX 정점이 anchor 풀로 자동 진입.
- `recommend-slots-by-book.mjs`: ★별·prefix별 가중치로 추천.

## 2. 3층 분리 모델 (v3.0)

문제 난이도를 **세 층(1층 노동량 M·2층 통찰도 I·3층 외부 맥락 X)**으로 분리해 측정한다. 7축의 "한 그릇에 다 담기" 구조를 폐기. 채점자는 풀이를 **실제로 단계별로 나열**한 뒤 채점한다.

> **v3.0 변경 (2026-06-20)**: v2.0의 7축 → **3층 모델**로 재구성. 문제점 해결: "절차로 점수 끌어올리기" 차단 (마스터 지적, 4회차 검수 사례). I(통찰)를 ★ 결정 주축으로 격상. 절차형 ★ 4 천장(M_total ≥ 11 예외). 통찰 8유형 명시.

### 2.1 1층 — 기본 노동량 M (4축, 각 1~3점)

| 축 | 코드 | 의미 | 1점 | 2점 | 3점 |
|---|---|---|---|---|---|
| 풀이 단계 수 | **Mₛ** | 식 변형·논리 추론 단계 수 | 1~3단계 | 4~6단계 | 7+ 단계 |
| 계산 부담 | **Mₖ** | 산술·대수 처리량 | 한 줄 내 | 중간 | 다단계 대수 처리 |
| 표현 추상도 | **Mₐ** | 문제 표현의 추상 수준 | 구체 수치 | 매개변수 포함 | 일반 함수·집합 추상 |
| 함정 카테고리 수 | **Mₜ** | 함정 카테고리 수 (T-범위/T-부호/T-경계/T-단위/T-표기 중 해당 수) | 0~1개 | 2~3개 | 4+개 |

**M_total = Mₛ + Mₖ + Mₐ + Mₜ** (범위 4~12).

#### M 축별 채점 가이드

- **Mₛ**: 식 변형·논리 추론 한 단계로 카운트. 단순 산술 정리 제외.
- **Mₖ**: **계산만 무거운 문제는 변별력 약함** — 인수분해·이차 표준식 등 일반 학생이 어려움 없이 가능한 양은 Mₖ=1로 매김.
- **Mₐ**: 수치 구체 1, 매개변수 1개 2, 일반 함수 $f$·집합 $A$ 추상 3.
- **Mₜ (5개 표준 함정 카테고리)**:
  - **T-범위**: 정의역·치역·범위 제약 누락
  - **T-부호**: 부호 실수 (예: 이차부등식 a<0일 때 부호 반전)
  - **T-경계**: 경계값 처리 (≤ vs <)
  - **T-단위**: 단위·차수 혼동
  - **T-표기**: 기호 표기 오해 (공통수학 외 기호)
  - 출제 YAML의 `traps_used: [T-범위, T-부호, ...]` 명시 의무

> **C(개념 결합) 폐기 — 2층 흡수**: v2.0의 C 축은 "노동량이 아니라 통찰"로 재분류. 단원 경계를 넘는 개념 결합은 2층 I-XU로, 같은 단원 내 두 개념 결합은 통찰 카운트에서 제외.

### 2.2 2층 — 인지 통찰도 I (10유형 체크리스트, v3.6 확장)

문제 풀이에 요구되는 통찰을 10유형 중 하나(또는 복수)로 식별·카운트한다. **v3.6 (2026-06-26)**: 마스터 "사고 유발 정도" 정의 (진입 저항·전략 분기·검증 부담) 직접 측정을 위해 I-SC·I-VF 2종 신설. 기존 I-MI(다중 해석)는 *케이스* 분기이고, I-SC는 *전략* 분기로 분리.

| 코드 | 통찰 유형 | 정의 |
|---|---|---|
| **I-XU** | Cross-Unit synthesis | 단원 경계를 넘는 개념 결합 (EQ+MX, CB+EQ 등) |
| **I-BW** | Backward reasoning | 역방향 사고 (결과 조건 → 원인 역추적) |
| **I-RT** | Representation Translation | 표현 전환 (대수↔기하·방정식↔부등식·조합↔개수·행렬↔연립) |
| **I-EQV** | EQuiValence transformation | 조건의 동치 변환 (학생이 조건의 의미 해석) |
| **I-MI** | Multi-Interpretation | 다중 해석 (한 조건이 여러 경우 포함, 학생이 모두 따져야) |
| **I-PD** | Pattern Discovery | 일반항·점화식·주기성·규칙 발견 |
| **I-SYM** | SYMmetry exploitation | 대칭성 활용 (함수 대칭·근의 켤레·배치 대칭·행렬 대칭) |
| **I-CON** | CONdition consolidation | 조건 통합 (여러 독립 조건을 단일 식·관계로 결합) |
| **I-SC** *(v3.6)* | Strategy Choice | **전략 분기·선택** (두 개 이상의 해법 갈래 비교 후 효율적인 것 선택. 케이스 분기와 구별 — *해법 자체*가 갈래) |
| **I-VF** *(v3.6)* | Verification-Forced | **사후 검증 강제** (답 도달 후 케이스 유효성 다중 점검·기각이 풀이 마지막 단계에 의무. 분기 결과의 일부가 *조건 위배로 기각*되어야 함) |

#### 채점 절차 — 단계별 라벨링 (v3.0 핵심)

풀이를 **단계별로 나열**한 뒤, 각 단계가 어떤 통찰을 요구하는지 라벨링. 한 단계가 두 유형에 해당하면 1개로만 카운트(주 통찰 1개). `insight_score = 라벨링된 단계 수`.

```yaml
insights_used:
  - step: 1
    type: I-XU
    description: "MX 케일리식 → EQ 근과 계수 관계 전환"
  - step: 3
    type: I-RT
    description: "조합 식 → 부분집합 카운트"
insight_score: 2
```

#### 8유형 정의·판별 기준

##### I-XU (단원 경계 결합)
**정의**: 풀이에 서로 다른 단원의 핵심 정리·공식이 모두 필요한 경우.
**판별**:
- 풀이 단계의 핵심 도구가 2개 이상 단원에 걸침
- 한 단원의 도구를 빼면 풀이가 끊김
- 단순 표기 차용은 인정 안 함 (예: 조합 기호 등장만으로는 불가)
**예시**: 행렬 $A^2 = 3A - 2E$ (MX 케일리식) → $a + b = 3, ab = 2$ → 이차방정식 $x^2 - kx + 2 = 0$ 의 근 (EQ 근과 계수).

##### I-BW (역방향 사고)
**정의**: 결과 조건이 먼저 주어지고 원인을 역추적.
**판별**:
- 문제 진술에 "~이 되도록 하는 $a$"·"~을 만족시키는 모든 $k$"·"~이 성립할 조건"이 핵심
- 학생이 답이 갖춰야 할 성질을 먼저 분석해야 식 변형이 가능
- 단순 미정계수 대입 (예: $f(1) = 0$ 으로부터 $a$) 은 표준 절차, 인정 안 함
**예시**: 사차방정식 $x^4 - (k+1)x^2 + k = 0$ 이 서로 다른 네 정수 실근 → $k$ 가 완전제곱수, $k \ne 1$ 분석.

##### I-RT (표현 전환)
**정의**: 한 표현에서 다른 표현으로 옮겨야 풀 수 있음.
**판별**:
- 풀이 핵심 단계에서 표현이 바뀜
- 원 표현 그대로는 풀이가 진행 안 됨
- 단순 치환($x^2 = t$)은 표현 전환 아님 (같은 대수 영역)
**예시 (4가지)**:
- 대수↔기하: 그래프 교점 → 이차방정식 정수 근
- 방정식↔부등식: 해의 비교
- 조합↔개수세기: $_5C_0 + \cdots + _5C_5 = 2^5$ (부분집합 카운트)
- 행렬↔연립: $\det A = 0$ 의 의미 → 해 존재 조건

##### I-EQV (조건의 동치 변환)
**정의**: 학생이 조건을 풀이 가능한 등가 조건으로 옮김.
**판별**:
- 원 조건이 직관적 의미는 있지만 풀이에 직접 쓸 형태가 아님
- 학생이 조건을 변형해야 함
- 표준 공식 대입은 인정 안 함
**예시**: "$f(x)$ 의 $y$ 절편 $\ge 0$" → "$f(0) = b \ge 0$" → "두 근 $p, q$ 같은 부호이거나 0".

##### I-MI (다중 해석)
**정의**: 한 조건이 여러 경우를 포함, 학생이 모두 따져야 함.
**판별**:
- "또는"·"적어도"·"$\ge$" 등이 서로 다른 풀이 경로를 만듦
- 분기가 독립적 풀이 시나리오를 만들 때만 인정
- 단순 절댓값 구간 분할은 표준 분기로 인정 안 함 (T-부호 카테고리에 해당)
**예시**: "이차방정식이 적어도 하나의 양의 정수 근" → 두 근 모두 양 / 한 근만 양·다른 음 / 한 근만 양·다른 비실수, 세 경우 분석.

##### I-PD (패턴 발견)
**정의**: 일반항·점화식·주기성을 학생이 스스로 발견.
**판별**:
- "$A^2, A^3, \ldots$ 계산 후 일반항 추정 + 증명" 같은 발견 절차 포함
- 패턴이 문제에 명시되지 않음
- 단순 등비/등차 계산은 PD 아님
**예시**: $A = \begin{pmatrix} 1 & 1 \ 0 & 1 \end{pmatrix}$ 의 $A^n$ 의 (1,2) 성분이 $n$ 임을 발견·귀납 증명.

##### I-SYM (대칭성 활용)
**정의**: 풀이에 대칭성 발견·활용이 핵심.
**판별**:
- 함수의 축 대칭 ($f(x) = f(-x)$, $f(x) = -f(-x)$)
- 근의 켤레쌍 ($\alpha, \bar\alpha$ 또는 $\alpha, -\alpha$)
- 배치의 대칭 ($p < q$ 순서쌍 → $\{p, q\}$ 무순 쌍 환원)
- 행렬의 대칭/반대칭 ($A^T = \pm A$)
- 단순 "$x^2 = t$ 치환"은 표준 절차, 인정 안 함
- 대칭성을 풀이에 **활용해 단계 단축**할 때만 인정
**예시**: 사차방정식 $x^4 - 5x^2 + 4 = 0$ 의 실근이 모두 0 중심 대칭 → 합 = 0 즉시 결론.

##### I-CON (조건 통합)
**정의**: 여러 독립 조건을 단일 식·관계로 결합.
**판별**:
- 2개 이상 조건이 주어지고 학생이 단일 식으로 결합
- 결합 후 풀이가 단순화
- 단순 "교집합 구하기" ($x > 1$ 이고 $x < 5$) 는 표준 절차, 인정 안 함
**경계 정책**: 공통수학1에서 인정은 보수적. 대부분 I-EQV로 처리. CM2 이상에서 본격 활용.
**예시 (CM2 이상)**: "$f(0) = 1$, $f(1) = 3$, $f(2) = 7$ 만족 이차함수" → 차분 분석으로 한 번에 결정 (공통수학1에서는 직접 미정계수 3개 연립이 표준이라 인정 어려움).

##### I-SC (전략 분기·선택, v3.6 신설)
**정의**: 풀이 시작 시점에 *해법 자체*가 두 갈래 이상으로 갈리고, 학생이 효율적 갈래를 선택해야 함.
**판별**:
- 풀이 가능한 *전혀 다른 도구*가 2개 이상 (예: 대수 vs 기하 · 직접 카운트 vs 여사건 · 인수분해 vs 판별식 · 행렬 거듭제곱 vs 케일리 폐쇄식)
- 한 갈래가 다른 갈래보다 *현저히 빠르거나 유일하게 풀림* — 비효율 갈래 선택 시 풀이 지연·실패
- 학생이 *처음 30초 안에 갈래 선택* 의사결정을 해야 함
- 답지에 `[다른 풀이]` 섹션이 있고 두 풀이가 *완전히 다른 도구* 사용 시 강한 신호
- 단순 *케이스 분기* ($k > 0$ vs $k < 0$ 각각 계산)는 I-MI, 아님
**예시**:
- "9권 책 3+3+3 분배 + 학생 A에 특정 책 X 포함" → (갈래 1) 학생 A의 3권 직접 선택 후 나머지 / (갈래 2) 전체 분배 후 X 포함 조건 비율로 환원. 학생은 더 빠른 갈래 선택.
- "정십이각형 정삼각형 아닌 이등변삼각형 개수" → (갈래 1) 정점·이등변 쌍 직접 카운트 후 정삼각형 중복 보정 / (갈래 2) 전체 삼각형 $\binom{12}{3}$ → 변별형 빼기. 갈래 비교 후 효율 선택.

##### I-VF (사후 검증 강제, v3.6 신설)
**정의**: 답 도달 후 케이스 유효성·기각 점검이 풀이 마지막 단계에 *의무*이고, 분기 결과의 *일부가 조건 위배로 기각*되어야 함.
**판별**:
- 풀이 분기로 N개 후보를 얻은 후 *각 후보를 원 조건에 재대입*하여 *일부 기각* (M < N)
- "이 중 자연수인 경우" · "이 중 정의역 안인 경우" · "이 중 중복 없는 경우" 같은 *사후 필터*가 핵심
- 단순 "계산 검산" (정답 검토)은 I-VF 아님
- 검증 단계가 없으면 *틀린 답*에 도달 가능해야 함 (검증이 풀이의 본질)
**예시**:
- "$24x + ay = 1$, $6bx + 2y = 1$ 해 없음, 자연수 $(a, b)$ 쌍" → $ab = 8$의 네 쌍 $(1,8), (2,4), (4,2), (8,1)$ 중 $b \ne 4$ 검증으로 $(2, 4)$ *기각* → 3쌍.
- "자연수 성분 $A^2 - 9A + 14E = O$, 성분 합의 최댓값" → 케해 $(\mathrm{tr}, \det) = (9, 14)$의 정수 분해 분기 후 *각 분기 자연수 성분 가능성 재검증* (일부 분기 기각).
- I-MI와의 차이: I-MI는 *모든 분기가 답에 기여*(분기 N개 모두 카운트), I-VF는 *일부 분기 기각*(N개 중 M개만 답).

### 2.8 통찰 위장 검증 (v3.5 신설)

같은 통찰 *이름*이라도 깊이가 다르면 ★ 다름. 출제·검수 시 *통찰 위장* (depth 1·2를 depth 3으로 라벨링) 차단:

| 위장 형태 | 검출 방법 | 차단 |
|---|---|---|
| I-EQV(3) 위장 | "동치 변환"이 *단순 식 정리* 수준이면 depth 1·2 | `insight-depth-check.mjs`가 신호 부족 시 강등 |
| I-CON(3) 위장 | "조건 통합"이 *3 조건 단순 연립*이면 depth 2 | 자유도 제거 ≥ 2 필수 (P2 신호) |
| I-MI(3) 위장 | "다중 해석"이 *절댓값 분기*만이면 depth 2 | T-부호 함정으로 처리, MI 깊이 강등 |
| I-XU(3) 위장 | "단원 결합"이 *표기 차용*만이면 미인정 | 두 단원 핵심 도구 *동시 필수* 검증 |
| **I-SC(3) 위장** *(v3.6)* | "전략 분기"가 *단순 케이스 분기* (예: $k>0$ vs $k<0$)면 I-MI로 재라벨 | 두 갈래가 *다른 도구* (대수/기하·직접/여사건) 인지 검증. 같은 도구면 강등 |
| **I-VF(3) 위장** *(v3.6)* | "검증 강제"가 *단순 정답 검산*이면 미인정 | 분기 후보 N개 중 *기각 M ≥ 1*인지 검증. 모든 분기 유효면 강등 (I-MI로 흡수) |

검수 시 위장 발견 → 깊이 강등 → depth_score 재산정 → ★ 재산정.

### 2.11 procedural_friction 축 (v3.8 반대 방향, 질 저하 경고) — 방안 4

**v3.8 방향 전환 (2026-07-06 마스터 재지시)**: v3.7에서 friction ≥ 2 시 base ★ +0.5로 설계했으나 **폐기**. "통찰형에 계산을 더럽게 심는 건 질 저하지 질 향상 아님." 계산 마찰로 어렵게 만드는 건 문제의 질을 낮춘다.

**v3.8 정의**: procedural_friction 축은 유지하되 **★ 조정 신호에서 질 저하 경고 신호로 뒤집는다**. 통찰형 슬롯에 friction 트리거가 매칭되면 "계산으로 어렵게 만든 슬롯"으로 YELLOW 경고.

#### friction 트리거 (5종)

| 코드 | 트리거 | 판정 근거 |
|---|---|---|
| **F1** | 4차 인수분해·완전제곱 판별 | $x^4 + \cdots = 0$ + 인수분해·판별 필수 |
| **F2** | 복소수 다중 곱셈 (3+ 인자) | $(a+bi)(c+di)(e+fi)$ 또는 $\alpha\beta\gamma$ 복소수 곱 |
| **F3** | 행렬 3×3+ 성분 계산 or 반복 거듭제곱 ≥ 5회 | $A^5, A^6, \ldots$ or 3×3 행렬 |
| **F4** | 조합 케이스 분기 ≥ 4갈래 | `\begin{cases}` 브레이스 4개 이상 or 명시적 4갈래 |
| **F5** | 부호 결정 조건 ≥ 3개 | $a > 0, b < 0, c > 0$ 또는 3+ 부호 조건 |

#### friction_score 산출

```
friction_score = |{F1, F2, F3, F4, F5} matched|   # 0~5
```

#### v3.8 판정 (반대 방향)

```
# 계산 연습 단원 = friction 인정 (자연스러움)
COMPUTATION_UNITS = {"CM1-PL": ["다항식의 연산", "인수분해"], "CM1-EQ": ["복소수 사칙"]}

if slot.unit_sub ∈ COMPUTATION_UNITS[unit]:
  # 계산 연습 슬롯 — friction 자연스러움, 경고 없음
  friction_verdict = "OK (계산 연습 슬롯)"
elif friction_score >= 2 and insight_count >= 1:
  # 통찰형 슬롯에 friction 매칭 — 질 저하 신호
  friction_verdict = "🟡 YELLOW — 통찰에 계산 마찰 심음 (질 저하 위험)"
elif friction_score >= 3 and insight_count == 0:
  # 순수 절차형에 friction만 심은 슬롯 — "쉽지만 짜증"
  friction_verdict = "🟡 YELLOW — 순수 계산 노가다 슬롯"
else:
  friction_verdict = "OK"

# base ★ 조정 없음 (v3.7 +0.5 폐기)
```

**friction ≥ 3인 통찰형 슬롯**: 재출제 검토 대상. 계산을 빼거나 통찰 자체를 강화하는 방향으로 재설계.

#### YAML 필드

```yaml
friction_triggers: [F1, F3]      # 매칭 트리거 코드
friction_score: 2                 # 매칭 트리거 수
friction_verdict: "🟡 YELLOW"     # v3.8: 질 저하 판정
```

`procedural-friction-check.mjs` v2.0 (v3.8)가 자동 판정.

#### 계산 연습 단원 화이트리스트

friction 트리거가 자연스러운 슬롯:
- **CM1-PL**: 다항식 사칙연산·인수분해·항등식 미정계수 (초반부)
- **CM1-EQ**: 복소수 사칙연산·거듭제곱 (초반부)
- **CM1-MX**: 행렬 연산 (초반부)

이 슬롯은 friction 매칭돼도 경고 없음. 그 외 통찰형·응용형 슬롯은 friction 심으면 YELLOW.

### 2.12 ★ 5 최상위 이중 게이트 (v3.8 단순화) — 방안 3

**v3.8 변경 (2026-07-06 마스터 재지시)**: v3.7 게이트 3 (실측 정답률)은 수집이 현실적으로 어렵다는 마스터 지적으로 **폐기**. `pending` 상태 개념도 폐기. 게이트 1 + 게이트 2 이분법.

#### 이중 게이트 조건 (모두 AND)

```
star_premium = True if:
  # 게이트 1 — depth 조건 (v3.4 유지)
  depth_score_effective >= 8.5    # effective_depth 기반 (§2.9 감쇠 반영)
  AND max(effective_depths) == 3
  AND insight_count >= 5

  # 게이트 2 — P1~P6 카드 (v3.7 신규 유지)
  AND |{signal_ref} intersect {P1, P2, P3, P4, P5, P6}| >= 2
    # 진정 변별 6대 패턴 중 2개 이상 명시 연결
else:
  star_premium = False
```

**pending 상태 폐기** — 게이트 1·2 통과 시 즉시 `star_premium: true`. 게이트 2 미통과 시 `star_premium: false` (게이트 1은 통과했지만 카드 부족).

#### YAML 필드

### 2.14 통찰 조합 참신도 스코어 (v3.9 U자 곡선) — 방안 6

**v3.9 재조정 (2026-07-06 마스터 재재지시)**: v3.8은 count=0을 최고점(5)으로 매겼으나 이는 "시판·기출 어디에도 없는 오리지널 조합"으로, **시험 대비 훈련 교재 목적에 위배**. count=0은 오히려 위험 신호. 최적 = 시판 상위권에 실재하지만 학생 훈련 부족한 조합 = **count 3~30 스위트 스팟**.

#### 참신도 곡선 U자 (v3.9)

슬롯의 통찰 유형 집합(정렬)을 `data/insight-combo-frequency.json`에서 조회:

| 매칭 문항 수 | novelty_score (v3.9) | 의미 |
|---:|---:|---|
| ≥ 100문 | 0 | 흔함 (학생 훈련 완료) |
| 30~99문 | 1 | 중간 (표준 응용) |
| 10~29문 | **3** | 참신 (시판 상위권 준정점) |
| 3~9문 | **4** | 진정 스위트 스팟 (시판 정점·킬러) |
| 1~2문 | 3 | 경계 (극희귀, 이식 or 검토) |
| **0문** | **🔴 -1 (오리지널 위험)** | 시판·기출 밖 = 시험 대비 무관 |

**핵심 변화**: count=0은 v3.8에서 5점(최상) → v3.9에서 **-1점 (RED 위험)**. 시판·기출·수능에 실재하는 조합만 이식하는 것이 우리 교재의 역할.

#### 회차 목표 (v3.9 재조정)

시험지 1회분 (25문 기준) 참신도 합계 목표 유지:
- **최소**: `novelty_total ≥ 30`
- **권장**: `novelty_total ≥ 45`
- **정점**: `novelty_total ≥ 60`

★ 4·5 슬롯 평균 novelty_score ≥ 3 목표 (스위트 스팟 지향).

#### 세이프가드 (v3.9 → v3.10 완화)

- `novelty_score < 0` 슬롯 (오리지널 위험) 시험지당 **최대 1문** — 그 이상이면 회차 RED
- ★ 5 슬롯 novelty_score ≤ 1 (흔함·중간) → 🔴 RED (기존 유지)
- ★ 5 슬롯 novelty_score < 0 (오리지널) → 🔴 RED (기본)
- **★ 5 슬롯은 `seed_id` 필드에 실존 시판·기출 문항 인용 의무** (§2.15 참조)
- **v3.10 예외 (`origin_verified: school_original`)**: 학교 자체 완성도 검증된 오리지널은 count=0이어도 감점 완화 (아래 세부 참조)

### 2.16 v5.1 8축 정밀 스코어 (2026-07-11 확립) — 지문·종속성·번역·엄밀성·정확성·필수성·예측 저항

**배경 (2026-07-11 마스터 확립)**: 와부고 CM2 1회 재출제 v3 반려 사건 계기. 기존 v4.0 (유형 기반 base ★)이 다음 한계 노출:

1. **절차적 라벨 부풀림** — "증명 서술" 발문만 추가하면 insight label 카운트 상승, 실제 mechanism 이해 불필요
2. **지문-수학 연계도 미평가** — 지문이 flavor인지 mechanism-driven인지 별도 축 없음
3. **소문항 종속성 강도 미측정** — (1)→(2)→(3) 형식적 vs 실질적 구분 없음
4. **답 노출 위험 미검출** — 그림·조건이 답 스포일러가 되는지 자동 검출 없음
5. **수학적 엄밀성 미측정** — 필요충분·존재성·유일성·경계·경우 분류가 스코어에 반영 안 됨
6. **지문 학문적 정확성 미측정** — 지문 mechanism이 학문적으로 정확한가?
7. **조건 필수성 미측정** — "이것저것 섞어놓기" 방지 축 없음 (모든 조건이 필수인가?)
8. **표준 유형 재조합에 무방비** — 학생이 즉시 유형 식별 가능한 문제가 ★ 5 자격 통과

v4.0의 type_id + base_star는 **자격 gate**로 유지하되, v5.1의 8축은 **정밀 스코어**로 실제 통찰 밀도를 정량화한다. 두 층이 병렬 작동.

#### 2.16.1 축 정의

##### 축 N (Narrative Depth) — 지문 학문 밀도 (0~4)

| N | 기준 |
|---|---|
| 0 | 지문 없음 or flavor ≤ 3문장 |
| 1 | 지문 학문 개념 ≤ 1개, 소문항이 지문 없이 풀림 |
| 2 | 학문 개념 2~3개, 소문항 중 1개 mechanism 이해 필요 |
| 3 | 5~6문단 학문 밀도, 소문항 다수 mechanism 이해 필요 |
| 4 | 평가원 국어 비문학·과학탐구 수준, 소문항 전체 mechanism-driven |

**판정 절차**:
1. 지문 문장 수 카운트 (문장 종료 부호 `. ! ?` 기준)
2. 학문 용어 밀도 = (전문 명사 + 개념 정의어) / 총 어절
3. 소문항 발문에서 지문 참조 어구 (`지문의`, `앞의 정의에 따라`, `mechanism에 의하여`) 카운트
4. 소문항 논리적 완결성 검사 — 지문 삭제 후 풀 수 있는가?

##### 축 L (Layer Coupling) — 소문항 종속성 강도 (0~3)

| L | 기준 |
|---|---|
| 0 | 소문항 단일 or 병렬 (각 독립적) |
| 1 | 표면적 종속 — "(1) 결과를 이용하여" 명시만, 실제 대체 가능 |
| 2 | 실질 종속 — (2)가 (1) 결과를 도구로 사용, 대체 시 풀이 재구축 필요 |
| 3 | 도구 축적 chained — (1)→(2)→(3) 각 단계가 앞 결과의 **구조**를 재사용 |

**판정 절차**:
1. (2), (3) 발문에서 "(1)의 결과"·"(1)에서 구한"·"(2)의 도구를" 등 참조 어구 grep
2. 대체 검사 — (1) 결과를 다른 방법(직접 계산 등)으로 대체 가능한지
3. 구조 재사용 검사 — (2)에서 얻은 방정식·부등식·좌표가 (3)에서 명시적으로 등장하는지

##### 축 T (Translation Insight) — Mechanism → Math 번역 (0~3)

| T | 기준 |
|---|---|
| 0 | 표준 공식 직접 적용 (원 방정식·거리·기울기 등 교과서 절차) |
| 1 | 표준 개념 변형 (평행이동·대칭 정의 응용, 표준 인수분해 등) |
| 2 | Mechanism의 수학적 번역 자체가 통찰 (사도기 → 3배 확대 좌표 대응 등) |
| 3 | Multi-step mechanism decomposition (mechanism 여러 단계를 수학 언어로 분해) |

**판정 절차**:
1. 지문의 mechanism 명사구 추출 (예: 사도기·평행사변형·닮음)
2. 소문항 풀이의 수학 요소 추출 (예: 좌표 대응·비례식·원 방정식)
3. mechanism → math semantic 매핑 검사 (mechanism 이해 없이 풀이 도달 가능?)
4. 번역 단계 수 카운트 (mechanism 1단계 vs multi-step)

##### 축 H (Hint Exposure Penalty) — 답 노출 감점 (양수, composite에서 뺌; 0~3)

- **3**: 그림에서 정답값·좌표·특정 반지름 유추 가능 (예: 원 그림에 (2,2)·반지름 2 라벨 → r_A max=2 노출)
- **2**: 조건이 정답 유도의 직접 힌트 (예: 발문에 "값은 정수 3개"라 명시 → 정답 카운트 노출)
- **1**: 그림 라벨이 부분 정답 노출 (예: 좌표축 눈금이 정답 값과 일치)
- **0**: 노출 없음

**자동 검출 절차** ([[feedback_figure_authoring_protocol]] 5-step와 병행):
1. 그림 tex 파싱 → 모든 숫자 라벨·좌표 라벨 추출
2. 답지의 정답 값 리스트 추출
3. 라벨 리스트와 정답 리스트의 교집합 검사
4. 특정 반지름·중심 좌표가 그림에 직접 등장하는지 확인

##### 축 R (Rigor) — 수학적 엄밀성 5 서브축 (0~5)

각 서브축 0 (미충족) or 1 (충족), R_total = 합.

| 서브축 | 1점 기준 |
|---|---|
| **R.exist** | 답의 존재를 명시적 논증 (해가 있음을 보이는 조건 확인) |
| **R.unique** | 유일해 or 다중해 명시 논증 (판별식·대칭 이용) |
| **R.iff** | 필요충분 관계 정확 (역·이·대우 확인 or 양방향 화살표) |
| **R.boundary** | $\le$ vs $<$·열림·닫힘 경계 명확 (극단 케이스 처리) |
| **R.case** | 배제·통합 MECE 완전 경우 분류 (누락 없음) |

**판정 절차**:
1. 풀이·발문에서 존재성·유일성·경계·경우 관련 어구 grep
2. 각 서브축 충족 여부 이진 판정
3. R_total = 합 (0~5)

| F | 기준 (지문형) | 기준 (무지문형) |
|---|---|---|
| 0 | mechanism 서술 부정확 or 오해 유발 | 발문·조건이 부정확하거나 중의적 — 답이 갈릴 수 있음 |
| 1 | 근사·단순화가 학문 정확성 손상 | 서술은 통하나 모호·군더더기 조건 존재 · 해석에 관용 필요 |
| 2 | 학문적으로 정확, 근사·단순화 명시적·정당 | 수학적으로 정확·일의적·자족적 (외부 관용 없이 그대로 성립) |
| 3 | 학문 완전 정확 + 학생이 지문에서 진짜 새 개념 학습 (평가원 비문학·과탐 수준) | 정확·일의적 + **서술 자체가 사고를 유도** (조건 제시 순서·형식이 문제 구조를 드러냄) |

**판정 절차**:
1. **지문형**: 지문의 mechanism 서술 → 학문적 사실 대조 (참고자료·교과서·백과). 근사·단순화 언급이 명시적인가 ("근사할 수 있다"·"이상적 조건에서"). 학생이 얻는 학문 지식이 정확하고 학습 가치가 있는가?
2. **무지문형**: 발문·조건을 문자 그대로 읽어 **다른 해석이 가능한지** 검사. 사용되지 않는 조건(flavor)이 서술에 섞여 있는지 검사 (축 E와 별개 — E는 조건의 필수성, F는 **서술의 정확성**).
3. **공통 감점**: 상위 과정 용어 오용·비표준 조어·풀이법을 직접 노출하는 지시절은 F를 낮춘다.

##### 축 E (Efficient Constraints) — 조건의 필수성·밀도 (0~3, v5.1 신설)

| E | 기준 |
|---|---|
| 0 | 조건 여러 개 중 일부는 flavor (지문 서사만 있고 실제 사용 안 됨) |
| 1 | 조건 모두 사용되나 단일 방향으로만 (각 조건 1회 사용) |
| 2 | 조건 모두 필수 + 일부 조건이 여러 소문항에 재사용 |
| 3 | 조건 최소 + 각 조건이 여러 방향에서 사용 + 조건 하나 제거하면 문제 성립 안 됨 |

**판정 절차**:
1. 지문·발문에서 모든 조건 목록화 (숫자·부등식·정의 등)
2. 각 조건이 (1)(2)(3) 어느 소문항에서 사용되는지 매핑
3. 조건 사용 횟수 카운트 + 조건 제거 시 문제 성립성 검사

**의도**: 세션 27 마스터 지적 "동그라미 그려놓고는 좌표를 구해라 필요충분조건을 구해라 등등 이것저것 섞어놓기만" 대응. 조건이 flavor로 나열된 문제 차단.

##### 축 P (Predictive Resistance) — 예측 저항성 (0~3, v5.1 신설)

| P | 기준 |
|---|---|
| 0 | 발문 즉시 표준 유형 식별 · 풀이 방향 명확 (표준 카탈로그 유형 직접 매치) |
| 1 | 표준 유형이나 조건 조합이 낯설음 (유형은 알지만 접근 방법 선택 필요) |
| 2 | 유형 식별 어려움 · 학생이 접근 방법 여러 개 시도해야 |
| 3 | 완전 참신 · 학생이 문제 구조 재구조화 필요 (사도기 → 좌표 대응 등) |

**판정 절차**:
1. 카탈로그 유형 매칭 시도 (`bank/유형카탈로그/*.md` 참조)
2. 첫 접근에서 답에 이르기까지 시행착오 필요성 평가
3. 발문 첫 30초 독해로 풀이 방향 예측 가능성

**의도**: 표준 카탈로그 재조합 문제가 ★ 5 자격 통과하는 것 차단. 세션 27 GPS는 "두 원 교점 조건" 즉시 인식 (P=0), 사도기는 "이 물건을 어떻게 좌표화?" 재구조화 필수 (P=3).

#### 2.16.2 composite 공식 (v5.1)

```
composite = depth_score + N + 2·L + 2·T + R + F + E + 2·P − H_penalty
```

- **depth_score**: 기존 v3.4 (max_depth × 2 + avg_depth) 유지
- N, L, T, R, F, E, P: v5.1 신규 축 (v5.0 = 5축 → v5.1 = 8축 확장)
- H_penalty: 감점 (양수), composite에서 뺌
- 2배 가중치 (L, T, P): 종속성·번역 통찰·예측 저항이 depth·N·R·F·E보다 변별력 큼

**최대 composite**: 12 (depth) + 4 (N) + 6 (2L) + 6 (2T) + 5 (R) + 3 (F) + 3 (E) + 6 (2P) − 0 = **45**

| 순수 수학 (depth + R) | 10 | 28% |

🔴 **결론: v5.1 8축은 "구조적 복잡성"을 재고 "수학적 난이도"를 재지 못한다.**
- 지문 있음 → N 확보 · 3소문항 계단식 → 2L 확보 → **9점 자동**
- 여기에 의미 축 판정을 얹으면 premium 도달
- 내용이 중학 수준이어도 이 구조만 갖추면 점수가 나온다
- 수학을 재는 축은 `depth`(통찰 유형 **라벨** 기반)와 `R`(**키워드** 검출)뿐이고 **둘 다 내용을 보지 않는다**

#### 축 M 정의 (0~3 · 가중 ×2)

> **지문·소문항·조건박스·계단식 구조를 전부 벗겨낸 뒤 남는 수학의 실체**

> 🔴 **v5.4 개정 (2026-07-31 세션 106)** — 0~3 → **0~5**.
> 종전 3(정점) 기준이 「단원 교차 융합 **+** 비자명한 귀결 **+** 표준 접근 무효」로
> **세 가지를 묶어 놓고 세는 법이 없었다.** 인상으로 매기니 상단이 3에 몰렸다 —
> 실측 상단 천장 도달 **54%**, 우리 회차 15슬롯 중 9개가 동일값.
> 상단 세 칸을 **구성 겹수**로 다시 썼다. 하단은 도구 수준으로, 상단은 구성 겹수로 갈린다.

| M | 기준 | 구성 겹수 |
|---|---|:-:|
| **0** | 중학 도구만으로 풀린다 (기본 닮음·합동·비례·일차식 조작) | 0 |
| **1** | 고등 교과의 표준 도구를 **바로 적용**하면 풀린다 (교과서 예제·기본 유형) | 0 |
| **2** | 표준 도구를 쓰되 **어디에 쓸지를 정해야** 한다 (도구 결합·되짚기) | 0~1 |
| **3** | **자리를 한 번 만들어야** 한다 — 불변량·자취·형상을 스스로 세워야 조건이 식이 된다 | 1 |
| **4** | **만든 것을 재료로 다시** 만들어야 한다 | 2 |
| **5** | 만든 조각들이 **서로를 제약해** 동시에 결정된다 | 3 |

> **판정 물음 (v5.4.1 · 2026-07-31 개정)**
> 포장을 벗긴 뒤 — **「문제의 조건을 식으로 옮기려면, 문제가 주지 않은 것을 몇 개 만들어야 하는가.」**
>
> **판정 절차** — 조건을 하나씩 짚으며 묻는다. 「이 조건을 **지금 바로** 식으로 쓸 수 있는가?」
> - 바로 쓸 수 있다 → 0
> - 무언가를 **먼저 만들어야** 쓸 수 있다 → 그 만든 것을 센다
> - 그것을 만들려고 **또 만들어야** 한다 → 겹으로 센다

| 조건 예시 | 식으로 옮기려면 | 겹 |
|---|---|:-:|
| 두 점 사이의 거리가 5 | 거리 공식에 바로 넣는다 | 0 |
| 삼각형 넓이가 최대 | **넓이를 무엇의 함수로 쓸지**부터 정해야 한다 | 1 |
| 구간별 함수가 일대일 | 각 조각의 **증감·치역·이음점**을 만들고 그것들이 서로를 제약한다 | 2~3 |

> 🔴 **폐기된 물음** — 「문제가 준 것만으로 계산을 시작할 수 있는가」(v5.4 초안).
> 「구성해야만 풀리는가」로 읽혀 **웬만한 문제가 무식한 연립으로 뚫리므로 대부분 0겹**이 됐다.
> 실측에서 채점자 1인이 20문 중 12문을 같은 값에 몰았고, **표본 절반이 이 한 문장에 걸린다**고 보고했다.

#### 🔴 기준 경로 — 공식 해설의 경로를 쓴다 (마스터 확정 2026-07-31)

지름길이 있는 문항에서 **어느 경로를 채점하는가**가 값을 절반 넘게 바꾼다.
(세우면 빨라지지만 안 세워도 연립으로 뚫리는 구조 — 예: 「직각을 발견하면 지름」)

> **기준 경로 = 공식 해설이 취한 경로.** 학평은 회차 해설 PDF, 우리 문항은 우리 답지.

| 후보 | 기각 사유 |
|---|---|
| 표준 도구 최단 경로 | 「무식하게 풀 수 있으면 안 깊다」로 귀결된다. **출제자가 설계한 깊이를 부정**한다 |
| 실제 풀이자가 세우는 구조 | 사람마다 다르다. 재현되지 않는다 |
| ✅ **공식 해설의 경로** | **밖에 있는 문서가 경로를 정해 준다.** 출제 의도가 반영되고 채점자가 봐도 같은 것을 본다 |

🔴 **채점 순서**: 먼저 스스로 푼다 → 그다음 해설을 열어 **해설의 경로로** 겹수를 센다.
스스로 푼 경로가 해설과 다르면 **해설을 따른다.** (스스로 풀지 않으면 해설을 읽어도 겹수가 안 보인다)

🔴 **채점은 3인 평균**으로 한다. 채점자 간 흔들림이 ±1 칸이라 단독 채점으로는 밴드가 뒤집힌다.
3인 평균이면 흔들림이 $1/\sqrt{3}$ 로 줄고 값이 0.33 단위로 나와 실효 해상도가 16칸이 된다.

🔴 **근거** — 학평 상단 23문 원본 정독 2건이 서로 모른 채 같은 기준에 도달했다.
「수치를 놓을 자리가 이미 있는가 vs 스스로 만들어야 하는가」(적중 13/16) ·
「대상이 어떻게 생겼는지 스스로 복원한 뒤에야 셈이 시작되는가」(적중 13/15).
최상위 7문의 풀이 소요 시간도 겹수 순서와 일치했다 (17·20·24·28·33·35·38분).
**단 두 기준 모두 그 문항들에서 사후로 뽑은 것이라, 새 표본 검정 전에는 확정이 아니다.**

**판정 절차 — 「벗겨보기」 (필수)**

1. 지문·소재를 **삭제**한다
2. 소문항 계단을 **삭제**하고 최종 질문만 남긴다
3. 조건박스를 **본문에 녹인다**
4. 남은 것을 **한 줄로 쓴다**
5. 🔴 **그 한 줄이 몇 학년 수준인가** — 그것이 M이다

**#16 적용 예시** (강화 전):
> 벗겨낸 결과: *"AA 닮음으로 닮음비 1:2를 얻고, 내분점 공식으로 좌표를 쓰고, 원의 방정식에 대입하라."*
> → 닮음(중2) + 내분점(CM2 기본) + 대입(기계적) → **M = 0~1**

#### composite 공식 (v5.3)

> 🔴🔴 **v5.4 개정 (2026-07-31 세션 106 · 마스터 확정)** — **포장 축 4개를 composite 에서 뺀다.**
>
> 마스터 지적: *「소문항·지문 밀도 이런 게 수학적 깊이랑 상관이 있을 리가 없어.」*
>
> 이는 **v5.3 이 축 M 을 신설한 근거와 같다** — 「지문 있음 → N 확보 · 3소문항 계단식 → 2L 확보 →
> **9점 자동**. 내용이 중학 수준이어도 이 구조만 갖추면 점수가 나온다.」
> **그 포장으로 지목된 것이 정확히 N 과 L 이다.** 그것을 난이도 점수에 남겨 둔 채
> M 을 더한 것은 진단과 처방이 어긋난 상태였다.
>
> 실측이 이를 뒷받침한다 — 우리 시험지 채점에서 **소문항 얽힘(L)만 척도 전 구간이 작동**했다.
> 잘 작동한 것이 아니라 **소문항을 세 개 달면 값이 오르기 때문**이다.

```
composite = depth_score + 2·M + 2·T + R + E + 2·P
```

**제외된 4축과 새 자리** — 폐기가 아니라 **자리 이동**이다. 난이도 점수에만 더하지 않는다.

| 축 | 새 자리 | 근거 |
|---|---|---|
| 지문 밀도 (N) | **문항 형식 기술자** | 난이도가 아니라 「이 문항이 어떻게 생겼는가」. 회차 구성 관리에 쓴다 |
| 소문항 얽힘 (L) | **문항 형식 기술자** | 〃 |
| 답 노출 (H) | **검사 항목** | 우리 시험지 34슬롯 전량 0. 이미 게이트가 막고 있다 — 난이도가 아니라 통과·차단 |
| 서술 정확성 (F) | **검사 항목** | 0(틀림)만 잡으면 된다. 값의 크기가 난이도를 뜻하지 않는다 |

🔴 **최대 composite 는 재산출 필요.** M 이 0~5 가 되었고 4축이 빠졌다.

#### 동반 규칙

**① 구조 축 상한** — 🔴 **폐기.** N·L 이 composite 에서 빠졌으므로 상한을 걸 대상이 없다.

**② 판정 비중 상한** — 판정 축(**T·E·P** · 2T+E+2P) 기여가 composite의 **60% 초과 시 🟡 경고**

> 🔴 **v5.3 재보정 (2026-07-30 세션 105)** — 종전 **40%** 는 구조를 확인하지 않고 정한 값이었다.
> 실측: 17슬롯 중 **13슬롯이 발동**. 76% 에서 울리는 경고는 신호가 아니다.
>
> 회차 전체 실측 — 측정축(`depth + min(N+2L,6) + R − H`) 합계 **150** ·
> 판정축(`2T + E + 2P`) 합계 **133** → **구조적 판정 비중 47.0%**.
> 즉 40% 는 **현행 축 구성으로 도달 불가능한 값**이었고, 그 상한을 지키려면 판정을
> 억지로 낮춰야 하므로 **오히려 점수 맞추기를 유도한다.**
>
> → **60%** (판정이 측정의 1.5배를 넘는 지점) 로 올린다. 재보정 후 경고 **0슬롯**.
>
> **분자에서 제외된 축**:
> - **F** — v5.3 에서 감점 축이 되었다. 감점은 「기여」가 아니다
> - **M** — 수학 실체에 대한 판정이므로 지배해도 된다 (§2.16.2b)
>
> 🔴 **근본 해법은 상한 조정이 아니라 측정 축 강화다.** 수학을 재는 축이
> `depth`(라벨 기반)와 `R`(키워드)뿐이고 **둘 다 문항 내용을 보지 않는다.**
> 상한을 올린 것은 잘못된 기준을 걷어낸 것일 뿐 문제를 해결한 것이 아니다. **별도 과제.**
판정이 절반을 넘으면 그것은 측정이 아니라 의견이다. (#16은 50%였다.)

**③ 🔴 premium 자격에 M 하한** — `star_premium` 조건에 추가:
```
star_premium = (composite ≥ 임계) AND (base_star_gate ≥ 4) AND (M ≥ 2)
```
**M ≤ 1 이면 composite가 아무리 높아도 premium 불가.** 포장만으로 정점에 도달하는 경로를 차단한다.

#### 🔴 금지 — 점수 맞추기

문항을 강화해야 할 때 **의미 축(T·F·P) 판정을 올려서 composite를 맞추지 마라.** M을 올리려면 **수학 실체를 바꿔야** 한다. 판정 상향으로 임계를 통과시키는 것은 [[feedback_ssot_routing_gap]] 계열의 자기기만이다.

#### 임계값 재보정 필요

M(가중 2, 최대 6)이 추가되면 전 슬롯 composite가 상승한다. 🔴 `composite ≥ 30` premium 임계는 v5.1 분포로 잡힌 값이므로 **실기출 기준 표본으로 재보정하기 전까지는 절대값 판정을 유보하고 슬롯 간 상대 순위 + M 하한만 사용**한다.

#### 2.16.4 v4.0 base_star과의 통합

v5.0 composite와 v4.0 base_star는 **AND 조건**으로 병렬 검증:

```
[Step A] 유형 자격 (v4.0)
  base_star_gate = catalog[type_id].base_star

[Step B] 8축 정밀 (v5.1)
  composite = depth_score + N + 2L + 2T + R + F + E + 2P − H_penalty
  composite_star = threshold_lookup(composite)

[Step C] 최종 ★
  effective_star = min(composite_star, base_star_gate + 1)
  # composite가 base_star_gate + 2 이상이면 base_star 재분류 검토 신호

[Step D] star_premium 판정
  star_premium = (composite >= 30) AND (base_star_gate >= 4)
  # 유형이 이미 ★ 4 이상 자격 있고 정밀 스코어도 30 이상일 때만 premium
```

**의도**:
- v4.0 base_star: 유형이 원천적으로 ★ 4·5 자격 있는가? (catalog 기반)
- v5.0 composite: 실제 문제 인스턴스가 그 자격에 부합하는 정밀 통찰 밀도인가?
- 두 층 모두 통과해야 star_premium 인정 → 표면 라벨링 부풀림 차단

#### 2.16.8 판정 절차 사례 — 세션 27 #17 케플러 (반려본 자기 검증)

**Given**:
- 지문: 케플러 궤도 개념 + 관측 영역·두 궤도 정의 (약 6문장)

- 그림: 정사각형 + 두 원 (중심 좌표 (2, 2)·(6, 5) 직접 라벨, 반지름 2·4 원 렌더)

**N 채점**:
- 6문장 학문 밀도 있지만 케플러 mechanism이 소문항에 재활용 안 됨 → 소문항이 지문 삭제해도 풀림
- N = 2 (학문 개념 있으나 mechanism-driven 미달)

**L 채점**:
- (1) 거리 5 → (2) 조건 (다) 부등식 → (3) 최댓값
- 표면적 종속 (참조 어구는 있으나 (1) 결과 5를 (3)에서 재사용 여부 미명시)
- L = 2 (실질 종속)

**T 채점**:
- 케플러 mechanism = 원 궤도 근사. 이를 수학화한 것은 원 방정식 (기본)
- 표준 개념 변형 수준 → T = 1

**H 채점**:

**R 채점**:
- exist: 부등식 조건 아래 답이 존재함 논증 있음 → 1
- unique: 최댓값 조건에서 유일해 논증 (구석점) → 1
- iff: 필요충분 관계 명시 안 됨 → 0
- boundary: $\le$ 부등식 경계 처리 있음 → 1
- case: 경우 분류 없음 (단일 경로) → 0
- R_total = 3

**F 채점** (v5.1 추가):
- 케플러 원 궤도 근사 명시 있음 (편심률 작은 궤도)

- F = 1 (근사 명시는 있으나 학문 정확성 손상)

**E 채점** (v5.1 추가):
- 조건 (가)(나)(다) 3개 나열, 각 조건이 (2)(3)에서 사용
- 그러나 조건이 단일 방향으로만 사용 (각 조건 1회)
- E = 1 (조건 모두 사용되나 재사용·다중 방향 부재)

**P 채점** (v5.1 추가):

**배경 (2026-07-14 마스터 확립)**: 와부고 CM2 2회 시험지에서 서술형 정점 밀도가 1회 대비 -5.4점 하락. 원인 진단 결과 v5.1 8축이 **지문형 편중** (N·T·F·P 4축이 mechanism 종속) → 순수 수학형 comp 상한이 22~28로 제한. 서술형 5문 중 지문형 아닌 슬롯이 자연스럽게 comp 24 미만으로 강제되어 star_premium 진입 불가.

#### 2.16.9.1 축 T (Transformation Insight) 재정의 — 다중 표현 통찰 포함

| T | 기준 (v5.2) |
|---|---|
| 0 | 표준 공식 직접 적용 (원 방정식·거리·기울기 등 교과서 절차) |
| 1 | 표준 개념 변형 (평행이동·대칭 정의 응용, 표준 인수분해) |
| 2 | **표현 전환 통찰** — 지문형: mechanism → math 번역 / 순수형: 대수↔기하↔집합↔논리 표현 간 전환 (예: 부등식 → 자취, 명제 → 집합 진리집합, 조건 → 원소 카운트) |
| 3 | **Multi-step 재구조화** — 지문형: mechanism decomposition / 순수형: multi-representation chain (예: 자취 → 두 자취 위치관계 → 명제 진리값의 3단 표현 chain) |

**판정 절차 (v5.2)**:
1. 문제 유형이 지문형인지 순수 수학형인지 판정 (지문 문장 수 · mechanism 명사 존재 확인)
2. 지문형이면 v5.1 §2.16.1 T 기준 적용
3. 순수형이면 표현 전환 횟수 · 표현 chain 길이 카운트
   - 단일 표현: T=0~1
   - 2 표현 간 전환 (예: 대수↔기하): T=2
   - 3+ 표현 chain: T=3

**의도**: 순수 수학형에서 (예: "명제 진리집합 ⇒ 집합 카운트 ⇒ 부등식 조건")처럼 표현 전환이 통찰의 핵심인 문항이 T=2~3 도달. 지문형의 mechanism 번역과 동등 가치.

#### 2.16.9.2 축 F (Formal Precision) 재정의 — 수학 정의 정확성 포함

| F | 기준 (v5.2) |
|---|---|
| 0 | 정의·개념 서술 부정확 or 학생 오해 유발 |
| 1 | 표준 정의 사용, 학문 손상 없음 |
| 2 | 정의 정확 + **필충·경계·존재성·동등성 중 하나 이상 명시** (순수 수학형에서 도달 가능) |
| 3 | 학문 완전 정확 + 학생이 새로운 개념 학습 (지문 mechanism 완비 or 순수형 정의 심화) |

**판정 절차 (v5.2)**:
1. 발문·풀이에서 수학 정의 어구 grep ("~라 한다"·"~의 정의"·"~이 성립한다"·"필요충분"·"경계는 포함/제외")
2. 정의의 정확성 검사 (교과서·표준 참조 대조)
3. 순수형은 정의 심화 요소 (필충·경계·유일성) 하나 이상이면 F=2 도달

**의도**: 순수 수학형이 "정의 정확 + 경계 명시"만으로 F=2 확보. 지문형만의 배타적 축 벗어남.

#### 2.16.9.3 축 D (Decomposition Density) 신설 — 조건 분해·재결합 밀도

| D | 기준 (v5.2) |
|---|---|
| 0 | 단일 조건·단일 도구 순차 적용 |
| 1 | 조건 2~3개 결합, 각 조건 단일 소문항 사용 |
| 2 | 조건 다층 결합 + 각 조건이 여러 소문항 재사용 (다중 관점) |
| 3 | 조건 분해 → 재결합 → 상호 참조 (i↔ii↔iii 상호 의존 그래프 형성) |

**판정 절차 (v5.2)**:
1. 발문에서 모든 조건 목록화 (숫자·부등식·정의·집합 등)
2. 각 조건이 어느 소문항에서 사용되는지 매핑 표 작성
3. 조건 재사용 횟수 카운트
   - 각 조건 1회 사용: D=1
   - 조건 다수가 여러 소문항 재사용: D=2
   - 소문항 간 상호 참조 그래프 형성: D=3

**의도**: 순수 수학형에서 조건 다층 결합이 통찰의 핵심인 경우 (예: 2회 #14 부분집합 X 조건 (가)(나)(다) 결합) → D=2로 정점 진입.

**E 축과의 관계**: E (Efficient Constraints)는 조건 필수성 (제거 시 문제 성립 안 됨) 측정. D (Decomposition Density)는 조건 재사용·다중 관점 측정. **두 축은 상보**:
- E 3 + D 0: 조건 최소 필수 (효율적) but 단일 관점 (얕음)
- E 2 + D 2: 조건 일부 재사용 (효율 중간) + 다중 관점 (깊음)
- E 3 + D 3: 필수 조건 + 상호 참조 그래프 (이상적)

#### 2.16.9.4 composite 공식 (v5.2)

```
composite (v5.2) = depth_score + N + 2·L + 2·T + R + F + E + 2·P + 2·D − H_penalty
```

- **신규 항**: `+ 2·D` (Decomposition Density, 2배 가중치)
- **T·F 재정의**: v5.1 대비 순수 수학형에서 상한 상향 (지문형은 변동 없음)
- **최대 composite (v5.2)**: 12 (depth) + 4 (N) + 6 (2L) + 6 (2T) + 5 (R) + 3 (F) + 3 (E) + 6 (2P) + 6 (2D) − 0 = **51**

#### 2.16.10.3 회차 간 게이트 (series-level)

**series_top5_delta**: 이전 회차 대비 top5_composite_sum 상대 차이

| delta | 판정 | 대응 |
|---|---|---|
| ≥ 0% | 🟢 GREEN | 정점 밀도 유지·개선 |
| -3% ~ 0% | 🟢 GREEN (경계) | 허용 범위 |
| -5% ~ -3% | 🟡 YELLOW | 개선 검토 권장 |
| -10% ~ -5% | 🔴 RED | 시험지 재출제 검토 |
| < -10% | 🔴 RED (심각) | 시험지 재출제 의무 |

**자동 도구**: `scripts/composite-distribution-check.mjs` (task 27)에서 청사진 대조.

#### 2.16.10.4 지표 통과 판정 로직

```
[Step 1] premium_count ≥ target.count?
[Step 2] premium_total_composite ≥ target.total_composite?
[Step 3] premium_min_composite ≥ target.min_composite?
[Step 4] premium_avg_composite ≥ target.avg_composite?
[Step 5] top5_composite_sum ≥ target.top5_composite_sum?
[Step 6] series_top5_delta ≥ -3%?  (이전 회차 청사진 필요)
```

**모두 통과 = 🟢 GREEN premium density**
**1건 미달 = 🟡 YELLOW**
**2건 이상 미달 = 🔴 RED (재출제 검토)**

#### 2.16.10.5 사례 검증 — 2회 vs 1회 v5.2 재산정

**1회 v5.2 재산정 예상** (D 축 활성):
| 지표 | 값 |
|---|---|
| premium_count | 4 (#14/15/16/17) |
| premium_total_composite | 42+36+43+43 = 164 |
| premium_min_composite | 36 |
| premium_avg_composite | 41.0 |
| top5_composite_sum | 43+43+42+36+27 = 191 |

**2회 v5.2 재산정 예상**:
| 지표 | 값 |
|---|---|
| premium_count | 3 (#15/16/17, #14 comp 31로 ★ 5 진입하나 premium 33 미달) |
| premium_total_composite | 36+42+43 = 121 |
| premium_min_composite | 36 |
| premium_avg_composite | 40.3 |
| top5_composite_sum | 32+31+36+42+43 = 184 |

**Series delta (2회 vs 1회)**:
- top5 delta: (184-191)/191 = -3.7% → 🟡 YELLOW (경계)
- premium_min·avg 유지 · count -1

**판정**: v5.2 아래에서 2회의 정점 밀도는 v5.1 대비 gap 축소. YELLOW 판정으로 재출제까지 이르지 않음. 지문형 밀도 정책 (§2.16.11 예정) 조정 시 GREEN 진입 가능.

#### 2.16.10.6 하위 호환

- v5.1 청사진의 `star_premium_target: N` → v5.2 `premium_targets.count: N`로 자동 마이그레이션
- v5.1 슬롯의 composite 값은 그대로 유지 (재산정 강제 없음)
- v5.2 신규 지표는 신규 청사진부터 명시 의무

**의도**: "정점 슬롯 3문 목표"라는 개수 지시가 "각 정점의 강도 저하"로 이어지지 않도록 강도 지표를 4중 안전망으로 명시. 회차 간 정점 밀도가 자연 하락하는 시스템 결함 방지.

```
    star ∈ [1, 3]
    insight_cap: 0   # 통찰형 출제 금지
    insight_types_allowed: []
    M_cap: {Mₛ: 3, Mₖ: 3, Mₐ: 2, Mₜ: 2}

  하위권:
    star ∈ [1, 3]
    insight_cap: 0
    insight_types_allowed: []
    M_cap: {Mₛ: 2, Mₖ: 2, Mₐ: 1, Mₜ: 1}

도출 절차:
  fit = []
  for tier in [상위권, 중상위권, 중위권, 중하위권, 하위권]:
    if star ∈ tier.star_range
       AND insight_score <= tier.insight_cap
       AND ∀ I-type in insights_used: I-type ∈ tier.insight_types_allowed
       AND ∀ axis ∈ {Mₛ, Mₖ, Mₐ, Mₜ}: M[axis] ≤ tier.M_cap[axis]:
      fit.append(tier)
  return fit
```

**audience_primary** (가장 자연스러운 1개): `fit` 중 ★가 해당 대상층의 "주력대"(§3.1 분포에서 가장 비율 높은 ★)와 일치하는 곳. 동률이면 더 빡빡한 캡을 가진 쪽 우선.

문제 YAML 등록 시 도출 결과를 `audience_fit`, `audience_primary` 필드에 기록. `problem-review` 에이전트가 알고리즘대로 재계산하여 일치 검증.

## 4. 앵커 비교 규약

### 4.1 앵커 보유 목표

각 단원마다 **★1~★5 × 5문 = 25문**의 표준 앵커 풀을 유지한다. 단원 진입 시점에 ★1·★2 앵커는 추가(상위권 작업 시점에는 비어 있을 수 있음).

### 4.2 신규 문제 등록 시 앵커 비교

모든 신규 문제는 **같은 단원·같은 ★의 앵커 2개**를 지정하고, **각 축마다 +1/0/-1** 비교 근거를 남긴다.

```yaml
anchors: [CM2-RF-A11, CM2-RF-A12]
anchor_diff:
  CM2-RF-A11:
    C: 0      # 같음
    S: +1     # 신규 문제가 1단계 많음
    T: +1
    rationale: "분모 분해 단계 추가 + 정의역 함정 1개 더"
  CM2-RF-A12:
    D: -1
    rationale: "표준 절차 위주, A12보다 통찰 덜 필요"
```

### 4.3 검증 기준

신규 문제의 raw 합이 같은 ★ 앵커 평균 ±2점 안에 들어와야 한다. 벗어나면 앵커 재지정 또는 ★ 재산정.

### 4.4 앵커 파일 위치

`bank/anchors/{과목}-{단원}.md` (예: `bank/anchors/CM2-RF.md`). 한 파일에 그 단원의 ★1~★5 앵커 전체 + 각 앵커의 8축 점수표.

### 4.5 교차 책 비교 절차 (cross-book consistency, v1.3 추가)

신규 문제 ★ 산정 시 **같은 단원·같은 유형 코드(T·R·M)**의 자매 책 슬롯과도 비교한다. 앵커만으로 검수 통과해도 같은 패턴이 다른 책에서 다른 ★로 라벨되면 라벨 드리프트가 누적된다.

#### 절차

1. 신규 문제의 단원·유형 코드 추출 (예: CM1-EQ T45)
2. 같은 단원의 다른 자료(`output/{과목}/practice0*-*.tex`, `test0*-*.tex`)에서 동일 유형 코드 슬롯 검색
3. 발견된 자매 슬롯의 8축 점수·표시 라벨·정★ 비교
4. 정★ 차이별 처리:
   - **차이 0~1**: 정합. 통과.
   - **차이 ≥2**: **반드시** 패턴 분석으로 차이 원인 명시. 단순 절차 변경(예: 부호 변환·계수 교체)만으로 차이 2 이상이면 둘 중 하나의 라벨이 드리프트. 어느 쪽을 기준으로 재산정할지 사용자에게 보고.
   - **차이 1**: 패턴 차이 한 줄 코멘트 권장.

#### 사례 (2026-06-06 발견 — practice01 #3 vs practice02 #3)

| 자료 | 문제 | 차이점 | T축 | raw | 정★ | 표시 |
|---|---|---|---|---|---|---|
| practice01 #3 | $x-3<3x-1<x+4$ | — | 1 | 9 | ★1 | \dota |
| practice02 #3 | $2x-3<x+1<3x-5$ | 부호 변환 1개 | 2 | 10 | ★2 | \dotc ❌ |

같은 T45 표준 A<B<C 풀이인데 표시 라벨이 ★1↔★3로 2단계 차이. 단순 부호 변환 추가만으로 T=1→2 (raw +1). practice02 #3의 \dotc는 -1 드리프트. 결과: practice02 #3 라벨 강등 또는 문제 강화 필요.

#### 책 단위 검수 절차에 통합

`problem-review` 에이전트가 책 단위 검수를 시작할 때 다음을 추가 실행:

```
for slot in book.slots:
  같은 단원·같은 유형 코드의 자매 책 슬롯 검색
  각 자매 슬롯의 정★ 산정 (또는 기록된 정★ 활용)
  차이 ≥2 발견 시 보고서에 "교차 책 라벨 드리프트" 섹션으로 추가
```

#### 자매 책의 범위

같은 단원 약자(EQ, FN, RF 등)를 사용하는 모든 `output/{과목}/*.tex`. 단원 표지(`\chapterintro`)나 작업 메모만 있는 파일 제외.

### 5.3 status 흐름

- `meta_only` — **외부 라벨·빈도만 등록, 본문·8축 채점 미수행** (v1.4.2 신설). 기출 자료 대량 메타 등록 단계. 외부 라벨 calibration과 빈도 산정에 사용. 본문·풀이·8축 점수·앵커·audience_fit 모두 비어 있음.
- `draft` — 본문·풀이·8축 채점·앵커·근거 모두 채워짐. 검수 전.
- `reviewed` — `problem-review` 에이전트 통과.
- `approved` — 마스터 최종 컨펌. 실제 책에 사용 가능.

`approved` 상태만 `output/*.tex`에 인용 가능. 사용 시 `\inputbank{CM2-FN-001}` 패턴(매크로 추후 구현).

### 5.4 빈도(`frequency`) 자동 산정

`status: meta_only` 등록이 일정량 누적되면 빈도를 자동 산정한다.

```
group by (unit, type)
for each group:
  count = group.size
  if count == 1:        frequency = 1  (희귀 — 단발 출제)
  elif count <= 4:      frequency = 2  (빈출 — 본문 등록 우선)
  else:                 frequency = 3  (필수 — 본문 등록 최우선, 앵커 후보)
```

산정 대상은 `status ∈ {meta_only, draft, reviewed, approved}` 전체. 자동화 스크립트 `scripts/bank-frequency.mjs`(추후 작성)로 일괄 갱신.

## 7. 출제 프롬프트 표준 (7요소, v3.2)

신규 문제 출제 시 항상 아래 7개를 프롬프트에 명시한다.

1. **단원·유형 코드** (예: CM2-FN T03)
2. **target ★** (1~5)
3. **target 대상층** (5단계 중 하나)
4. **선호 통찰 유형 + 깊이 (v3.2 갱신)**
   - 8유형(I-XU/I-BW/I-RT/I-EQV/I-MI/I-PD/I-SYM/I-CON) 중 어떤 통찰을 어느 단계에 심을지 명시 + 각 통찰의 *깊이 1·2·3* 지정
   - ★ 3: 깊이 1 통찰 1~2개 또는 깊이 2 통찰 1개
   - ★ 4: 깊이 2 통찰 2~3개 (max=2, score 6 이상)
   - **★ 5: 깊이 3 통찰 1개 이상 필수** (max=3 강제) + 보조 통찰로 depth_score ≥ 7 도달
   - **★ 5 최상위**: 깊이 3 통찰 1개 이상 + 총 통찰 5개 이상 + depth_score ≥ 8.5
5. **M 프로파일** (Mₛ·Mₖ·Mₐ·Mₜ 각 target 점수)
6. **앵커 2개** (같은 단원·같은 ★·**같은 통찰 유형**의 앵커 — 없으면 ±1★ 또는 가장 가까운 유형. ★ 5 신규 시 [[12-S5-insight-depth-메트릭]] §6.3 *★ 5 최상위 19문 인덱스*에서 셀렉 권장)
7. **출처·변형 정책** (참고자료 페이지 + 1순위 숫자만 / 2순위 동등 / 신규 창작)

예시 프롬프트 (v3.0):
```
CM1-EQ T16 (미정계수 결정) 의 ★ 4 문제를 중상위권 대상으로 출제.

선호 통찰: I-BW (역방향 사고) 1개 + I-EQV (조건 동치 변환) 1개.
  - 1단계: 결과 조건 "두 정수 근 + |f(0)|+|f(4)|≤10" 분석 (I-BW)
  - 3단계: |f(0)|+|f(4)|≤10 의 의미 → a 의 범위 동치 변환 (I-EQV)

M 프로파일: Mₛ=3 (7단계), Mₖ=2 (중간), Mₐ=2 (매개 a), Mₜ=2 (T-경계+T-부호).

앵커: CM1-EQ-A03 (★ 4 I-BW형), CM1-EQ-A04 (★ 4 I-EQV형) 과 비교 가능하게.
변형 정책: 신규 창작.
완성 후 M 4축 점수 · insight_score · insights_used · audience_fit 모두 YAML에 기록.
```

## 10. 외부 라벨 calibration (v1.4 신설)

기출/시판 교재의 외부 라벨을 흡수해 우리 8축 ★ 산정을 객관 검증한다. 8축 정의·임계값(§2)은 그대로 두고, 외부 라벨은 **검증·메타 데이터**로만 사용한다.

### 10.1 외부 라벨 출처와 매핑

| 출처 | 라벨 종류 | 우리 ★로 변환 | 가중치 |
|---|---|---|---|
| **실측 정답률** (EBSi 가채점·자이스토리·사설학원) | `actual_correct_rate` | 80%↑=★1, 60~80%=★2, 40~60%=★3, 20~40%=★4, 20%↓=★5 | **0.7 (최우선)** |
| 마더텅 기출문제집 (★ 1~4 단계) | `label_star` | 1→1, 2→2~3, 3→3~4, 4→4~5 | 0.2 (정답률 있을 때) / 0.6 (없을 때) |
| 학평 배점 (2/3/4점) | `score_points` | 2→★1~2, 3→★2~3, 4→★3~5 | 0.1 (정답률 있을 때) / 0.4 (없을 때) |
| 학평 대상 학년 | `exam_grade` | 고1 학평=학생 체감 그대로 / 고2 학평=학생 체감 +0.5★ 보정 | 보정 항 |
| 시판 문제집 자체 ★ (개념원리·쎈 등) | `label_star` | 출처별 환산표 누적 작성 | 0.2 (보조) |

**정답률이 ground truth에 가장 가까움** — EBSi 가채점 통계는 수만~수십만 표본의 실측치. 마스터 정책: 정답률이 있는 문제는 정답률을 0.7 가중치로 최우선, 마더텅 ★·배점은 보조.

### 10.2 `external_consensus_star` 도출 알고리즘

복수 외부 라벨이 있을 때 가중 평균으로 단일 ★ 합의를 계산. **정답률 유무에 따라 가중치 표가 달라진다.**

```
inputs: external_labels (list of {source, label_star, score_points,
                                  exam_grade, actual_correct_rate, ...})

step 1. 각 라벨을 our_star 스케일(1~5)로 환산

  (a) 정답률 → our_star 후보 (가장 신뢰)
      rate ≥ 0.80 → 1
      0.60 ≤ rate < 0.80 → 2
      0.40 ≤ rate < 0.60 → 3
      0.20 ≤ rate < 0.40 → 4
      rate < 0.20 → 5
      (경계는 선형 보간 — 예: rate=0.50이면 3.0, rate=0.30이면 4.0)

  (b) 마더텅 ★ → our_star 후보
      마더텅 1 → 1
      마더텅 2 → 2.5 (실측 raw 보정 시 2~3)
      마더텅 3 → 3.5
      마더텅 4 → 4.5

  (c) 학평 배점 → our_star 후보
      2점 → 1.5
      3점 → 2.5
      4점 → 4.0

  (d) 고2 학평 출제분이면 (b)(c) 후보에 +0.5 보정
      (정답률 (a)는 학생 표본이 이미 결과로 반영되어 있어 보정 불필요)

step 2. 가중 평균 — 정답률 유무 + cohort_type 분기 (v2.0 보정)

  CASE 1A: 정답률 있음 + cohort_type=national_exam (EBSi 등)
    weighted_avg = 0.7 * 정답률환산
                 + 0.2 * 마더텅환산
                 + 0.1 * 배점환산

  CASE 1B: 정답률 있음 + cohort_type=academy_internal (v2.0 신설)
    weighted_avg = 0.5 * cohort_normalized_star   # raw 정답률 대신 z-score 기반 ★
                 + 0.3 * 마더텅환산
                 + 0.2 * 배점환산
    (※ academy_internal cohort는 상위권 편향으로 raw 정답률을 0.7 가중치로 쓰면 과대평가됨.
       v2.0 결정: z-score 기반 cohort_normalized_star를 0.5 가중치로 사용하고 외부 라벨 보조 비중 증가)

  CASE 2: 정답률 없음 (cohort 무관)
    weighted_avg = 0.6 * 마더텅환산
                 + 0.4 * 배점환산

  external_consensus_star = round(weighted_avg)  # 1~5

step 3. delta = our_star - external_consensus_star
  flag = pass     if |delta| ≤ 1
  flag = warn     if |delta| = 2
  flag = mismatch if |delta| ≥ 3

  추가 — 정답률이 있는 문제의 mismatch는 8축 채점 재검토 우선순위 최상위 (ground truth와 어긋남).
```

#### 표본 규모 가드

정답률 표본 `correct_rate_sample_n`이 너무 작으면 신뢰도 낮음. 권장 기준:

| 표본 n | 처리 |
|---|---|
| n ≥ 10000 | 가중치 0.7 그대로 적용 |
| 1000 ≤ n < 10000 | 가중치 0.5로 하향, 마더텅 0.3, 배점 0.2 |
| n < 1000 또는 미상 | 정답률 미사용 (CASE 2로 처리) |

### 10.3 검증 절차

- `problem-review` 에이전트는 **`status: draft` 이상**(8축 점수 보유)인 문제에 대해 §10.2 알고리즘을 실행하여 `calibration.flag` 검증.
- `meta_only` 문제는 8축 점수가 없으므로 calibration 검증 대상 외. 그러나 **외부 라벨·빈도 풀에 합산**되어 §10.4 표본·통계에는 기여한다.
- `mismatch` 발견 시: 8축 점수 재검토 또는 외부 라벨 출처 확인 (마더텅 라벨 자체 오류·시판 책 라벨 드리프트 가능).
- `warn` 발견 시: 한 줄 코멘트로 차이 원인 설명 권장.

### 10.4 라벨 누적과 schema 진화 (표본 기반)

본 시점에서는 외부 라벨을 **8축 raw에 직접 반영하지 않는다** (8축 정의 안정성 유지). 대신 calibration log를 누적해 8축 자체의 약점을 객관 데이터로 식별한다.

#### 수집 데이터 (3종)

1. **매핑 delta** — `bank/problems/*.md`에 등록된 외부 라벨 보유 문제마다 `our_star - external_consensus_star`. 우선 마더텅 1,585문항 우선 메타 등록으로 즉시 1차 표본 확보.
2. **신규 출제 delta** — 우리가 학평·시판 교재 변형으로 만든 신규 문제 (외부 라벨 자동 상속) — 작업 누적분.
3. **flag 분포** — pass/warn/mismatch 비율 (단원·★·축별).

#### 분석 단위와 답하는 질문

| 분석 단위 | 답하는 질문 | v2.0 결정에 활용 |
|---|---|---|
| 단원 × ★ 평균 delta | "다항식 ★3에서 평균 -0.6"이면 어느 축 점수가 인색? | 축별 가이드(§2.1) 보강 |
| 단원 평균 delta | "행렬은 항상 +1.0 높게" | 단원 친숙도 계수 도입 (C안의 핵심) |
| 축별 mismatch 비율 | "D=3 50% mismatch / D=1 5% mismatch" | D 채점 가이드(§2.1) 보강, D/I 통합 검토 |

#### 표본 충분성 기준 (시간 아닌 표본 수)

| 분석 단위 | 통계 의미 최소 표본 |
|---|---|
| 단원 × ★ 평균 delta | 단원당 ★별 **30문항 이상** |
| 축별 mismatch 비율 | 축당 **50문항 이상** |
| schema v2.0 결정 | 단원 4개 × ★ 5단계 × 30문항 = **약 600문항 누적 시 1차 검토** |

마더텅 1,585문항 전체 메타 등록 직후 1차 분석 가능. 본 분석은 자동화 스크립트(`scripts/calibration-report.mjs`, 추후) 결과에 따라 사용자 검토.

#### log 저장 위치

`bank/calibration-log.md` — 단원별·★별 delta 통계 표 (자동 갱신). 단, **현재(v1.4)는 수동 등록**. 표본 100문항 누적 시점에 자동화 스크립트 작성.

### 10.6 정답률 표본 출처(cohort) 차등 처리 (v1.4.3 신설)

정답률 데이터는 **표본 출처별 신뢰도가 다르다**. 출처 분류와 처리 정책을 정식 분리한다.

#### cohort_type 4가지

| cohort_type | 의미 | 표본 규모 | 절대값 신뢰도 | 처리 |
|---|---|---|---|---|
| `national_exam` | 전국 학평·모의평가 가채점 (EBSi 등) | 수만~수십만 | 높음 (편향 적음) | **절대값 그대로 사용**. §10.2 (a) 표 적용 |
| `academy_internal` | 학원 자체 시험 결과 | 수십~수백 | **낮음 (상위권 편향)** | **절대값 사용 금지**. 자료 내 정규화 후 상대 ★ 사용 |
| `online_estimate` | 사설 학원 가채점·예측 | 수천~수만 | 중간 | 가중치 0.5로 하향 |
| `editor_estimate` | 출판사 자체 ★ 환산값 | — | 보조 | §10.2 (b) 표 적용, 보조 가중치 |

#### `academy_internal` 정규화 절차

학원 자체 시험 정답률은 **표본 작음 + 상위권 편향**으로 절대값이 실제보다 5~15%p 높게 나오는 경향. 자료 내 분포에서 **상대 위치**만 추출한다.

```
[1] 같은 cohort 단위(예: 한 자료의 한 회차 묶음)의 정답률 전체 수집
    rates = [r_1, r_2, ..., r_n]

[2] 분포 통계 산정
    mean = average(rates)
    std = stddev(rates)

[3] 각 문항의 z-score 계산
    z_i = (r_i - mean) / std

[4] z-score → 상대 ★ 매핑 (정규분포 가정)
    z > +1.0   → 상대 ★1 (상위 16% — 쉬움)
    +0.3 ~ +1.0 → 상대 ★2
    -0.3 ~ +0.3 → 상대 ★3 (평균 부근)
    -1.0 ~ -0.3 → 상대 ★4
    z < -1.0   → 상대 ★5 (하위 16% — 어려움)

[5] external_labels에 기록
    actual_correct_rate: r_i           # raw 값 유지 (참고용)
    relative_difficulty_z: z_i          # 자료 내 z-score
    cohort_normalized_star: ★_i         # 정규화된 상대 ★

[6] §10.2 calibration에서 이 값 사용
    cohort_type=academy_internal 시
    cohort_normalized_star를 정답률 환산 ★ 대신 사용
```

#### 유형별 정규화 (선택 — 표본 풍부 시)

유형마다 평균 정답률이 다르다(예: 다항식 덧셈은 85%, 인수분해는 65%). 표본이 충분하면 유형 단위로 분리 정규화:

```
for each (unit, type) group with size ≥ 20:
  유형 내 mean·std·z_i 별도 산정 → 상대 ★ 도출
유형 표본 < 20인 경우 전체 cohort 분포로 fallback
```

#### §10.2 알고리즘 갱신 (cohort 분기 추가)

step 1 (a) 정답률 환산에 cohort 분기:

```
if cohort_type == national_exam:
    환산 = (a) 표 그대로 (80%↑=★1 ... 20%↓=★5)
elif cohort_type == academy_internal:
    환산 = cohort_normalized_star  # 자료 내 z-score 기반 ★ 사용
elif cohort_type == online_estimate:
    환산 = (a) 표 그대로, step 2 가중치 0.5로 하향
elif cohort_type == editor_estimate:
    환산 = (b) 표 그대로 (보조 라벨)
```

### 10.5 빈도(frequency) 활용

`frequency` 필드는 ★ 산정에 영향 없음. 다음 결정에 사용:
- **교재 슬롯 채울 때**: `frequency=3`(필수 패턴)을 ★3~4 슬롯에 우선 배치
- **연습지 구성**: `frequency=3`만으로 "필수 유형 정복" 묶음, `frequency=1`은 "심화 도전" 묶음
- **앵커 후보 선정**: `frequency≥2` & `flag=pass`인 문제를 앵커 우선 후보로

`grade_origin` 필드는 `exam_grade`와 동의어지만 외부 라벨이 없는 신규 출제 문제에도 명시 (출제자가 의도한 학년 대상).
