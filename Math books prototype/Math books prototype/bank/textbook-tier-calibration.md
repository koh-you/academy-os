# 교재별 tier 캘리브레이션 표 (v1.3 · 마스터 승인 확정 2026-07-16)

## 목적

각 참고 교재의 섹션별 tier 매핑을 **마스터 관점**으로 명시. Agent 정독·pick 시 이 표만 참조 · **자체 tier 재판정 절대 금지**.

## 관점 갭 확립 (2026-07-16 세션 46 계기)

**System (Agent) 결함**: 섹션명 문자열 (예: "실력Up") → tier 매핑 · 절대 난이도 감각 부재 · 교재 간 상대 위치 무지 → **일괄 +1~2 tier 인플레이션** 발생.

**Master 관점** (본 표 기준): 교재의 대상 학생층·상대 위치·섹션 특성 종합 판단.

## 교재 층위 분류 (마스터 관점)

### 상위권 pool (star_5·premium 중심)
- **블랙라벨** (CM1·CM2 2024·2022개정)
- **고쟁이** (CM1·CM2 2025)

### 중상위권~중위권 pool (star_3·4 중심 · 소수 star_5)
- **RPM** (CM1·CM2)

### 하위권~중위권 pool (star_1·2·3 중심)
- 개념원리 · 라이트쎈 등 (미정독)

### 모의고사 배점 기반 자동 분류 (마스터 확립 · 2026-07-16 세션 46)
모의고사 문제 (전국연합·수능·평가원 기출)는 **원문 배점 기반 tier 매핑**:

| 배점 | tier |
|---|---|
| **2점** | star_1·2 |
| **3점** | star_3 |
| **4점** | star_4·5 (혼재) |

**별도 큐레이션 섹션 (문제집 자체 편집)**:
- **1등급 도전 코너** (EBS 올림포스 등) = **star_5_premium** 확정

**적용 대상 자료**:
- EBS 올림포스 전국연합학력평가 기출문제집
- 마더텅 전국연합 20분 미니모의고사
- 참고자료/고1·2 모의고사 기출 모음
- 참고자료/고1·2 모의고사 변형 모음

## 캘리브레이션 표

### 🟦 블랙라벨 (상위권 · STEP 3단계)

| STEP | tier | 정독 상태 |
|---|---|---|
| STEP 1 | **star_3·4** (혼재 · 문항별 재판정 여지) | 미착수 |
| STEP 2 | **star_5** | ✅ CM1·CM2 완료 |
| STEP 3 | **star_5_premium** | ✅ CM1·CM2 완료 |

### 🟦 고쟁이 (상위권 · STEP 3단계)

| STEP | tier | 정독 상태 |
|---|---|---|
| STEP 1 | **star_3·4** (혼재 · 문항별 재판정 여지) | 미착수 (Stage 1 P2) |
| STEP 2 | **star_5** | ✅ 완료 (v1.0 확립) |
| STEP 3 | **star_5_premium** | ✅ 완료 (v1.0 확립) |

### 🟨 RPM (중위권 · 섹션 다층 구조) — 세션 46 신설·마스터 확립

| 섹션 | tier | 특성 |
|---|---|---|
| 교과서 문제 정복하기 | **star_1·2** (100%) | 기초 계산 · 하위권 pool |
| 유형익히기 대표문제 | **star_3·4** | 유형 mechanism 정착 |
| 유형익히기 유형JP | **star_3·4** | 유형 응용 |
| 시험에 꼭 나오는 문제 (기본) | **star_3·4** (star_4 비율 slightly ↑) | 시험 실전 |
| 시험에 꼭 나오는 문제 · 중요★ | **star_3·4** | 시험 빈출 (5스타 없음) |
| 시험에 꼭 나오는 문제 · 실력Up 🏆 | **star_4·5 혼재** | 심화 (일부만 5스타) |

**주의**: Agent 관점 오류 (2026-07-16 확인) — 유형JP·중요★·실력Up를 모두 star_5로 라벨했음. **본 표가 정본**.

### 🟨 EBS 올림포스 전국연합학력평가 기출문제집 2025 (모의고사 기출·섹션 4단계) · Stage 1 P3 착수 예정

**정답률 필드 없음 확인 (2026-07-16 마스터 확인)**. **모의고사 배점 기반 매핑 + 섹션별 특성 결합**:

| 섹션 | tier 결정 방식 | 특성 |
|---|---|---|
| ① 개념 짚어보기 | **정독 제외** | 개념 요약 (문제 없음) |
| ② 개념 확인 문제 | **star_1·2 · 정독 제외** (star_1·2 pool은 RPM 교과서 정복하기로 충분 확보 · 중복 불요) | EBS 자체 편집 |
| ③ 내신 & 학평 유형 연습 | **원문 모의고사 배점 기반** (2점=star_1·2 / 3점=star_3 / 4점=star_4·5) | 학평 기출 문제 발췌 |
| ④ 1등급 도전 | **star_5_premium** 확정 | 고난도 · 킬러 큐레이션 |

**적용 원칙**:
- 유형 연습 각 문제는 원문 모의고사 배점 확인 후 tier 매핑
- 1등급 도전은 배점 무관 premium 확정
- 개념 확인 문제는 EBS 자체 편집이므로 배점 규칙 미적용

파일 예정: `bank/mechanism-데이터-ebs-올림포스-*.md`

## Agent 준수 원칙 (강제)

1. **본 표만 참조** — `bank/textbook-tier-calibration.md` 필독 · 다른 판단 소스 사용 금지
2. **자체 재판정 절대 금지** — 섹션명·문제 난이도 자체 평가로 tier 조정 금지
3. **범위 자체 결정 금지** — "star_4 이상만 정독" 같은 축소 결정 금지 · 마스터 지시 대상 전수
4. **혼재 tier 표기 정확** — "star_3·4 혼재" 라벨은 그대로 사용 · 임의로 star_4로 통일 금지
5. **경계 사례 문항별 flag** — 혼재 tier에서 star_5 후보 발견 시 별도 `master_review_flag: true` 표시
