## M1. 조건 상호 참조 (Cross-referencing Conditions) — 4개

### [앵커 M1-1] WBG-2025M #2 · 원 조건·정수 범위
- **소재**: 방정식 $x^2+y^2+2ax-4ay+6a^2-2a-3=0$이 원 나타내는 정수 $a$ 개수
- **방법론**: M1 + M6
- **다층구조**: 판별식(원 조건) + 정수 조건 + 경계값 검토의 순환 종속. 학생이 정수 조건을 먼저 놓치면 범위 오산

### [앵커 M1-2] WBG-2025M #5 · 집합 연산 중첩
- **소재**: $U-[\{(A\cup B)\cap(A\cup B^{c})\}\cup\{(B\cap C^{c})\cup(B\cup C)^{c}\}]$
- **방법론**: M1 + M2 (대수↔논리)
- **다층구조**: 각 괄호가 독립적으로 보이나 $(A\cup B)\cap(A\cup B^{c})=A$ 관계가 이전 결과 알아야 발동

### [앵커 M1-3] WBG-2025M #3 · 도형 이동 · 역상
- **소재**: 방정식 $f(3-y, x+2)=0$이 나타내는 도형이 원본을 어떻게 이동시켰는가
- **방법론**: M1 + M3
- **다층구조**: 표기 $(x,y) \to (3-y, x+2)$의 이동 규칙과 결과 점 위치의 역방향 결합

### [앵커 M1-4] WBG-2025M #7 · 직선·두 원 매개변수
- **소재**: 직선 $mx-y-3m+4=0$이 두 원과 모두 만나지 않는 정수 $m$
- **방법론**: M1 + M4
- **다층구조**: 매개변수 $m$과 두 거리 조건이 삼각 결합. 두 원과의 관계가 동시 제약

## M2. 대상 다중 관점 (Multi-perspective Object) — 5개

### [앵커 M2-1] WBG-2025M #4 · 집합·명제·기호 해석
- **소재**: $A=\{\varnothing, \{\varnothing, \{\varnothing\}\}\}$에서 원소·부분집합 판정
- **방법론**: M2 (집합론↔논리↔기호)
- **다층구조**: 같은 $\{\varnothing\}$ 표기가 원소 vs 부분집합 판정에서 다르게 해석

### [앵커 M2-2] WBG-2025M #6 · 선택과목·집합·최댓값·최솟값
- **소재**: 선택과목 조사 · 3과목 모두 선택 최댓값 $M$·최솟값 $m$
- **방법론**: M2 (집합론↔조합론↔최적화)
- **다층구조**: 벤다이어그램(기하) → 포함-배제 원리(대수) → 부등식 최적화의 삼중 변환

### [앵커 M2-3] WBG-2025M #11 · 무게중심·거울 반사·궤적
- **소재**: 점 $A(a, 2a)$·$P$(y축)·$Q$(y=x) 삼각형 APQ 둘레 최소 시 무게중심 $G$
- **방법론**: M2 (기하 거울반사↔대수 거리↔논리 궤적)
- **다층구조**: 기하학적 대칭 → 대수적 거리 공식 → 논리적 궤적 도출

### [앵커 M2-4] WBG-2025M #15 · 원·격자점·집합
- **소재**: 평행이동 원의 교집합 · 격자점 개수
- **방법론**: M2 + M6
- **다층구조**: 원의 교점(기하) → 근축(대수) → 격자점 개수(집합)의 관점 연쇄

### [앵커 M2-5] WBG-2025M #16 · 사도기·닮음·좌표 변환
- **소재**: 사도기(복합기) · 삼각형 닮음 · 좌표 대응
- **방법론**: M2 (기하 닮음↔대수 좌표↔논리 대응)
- **다층구조**: 닮음(기하) → 좌표 계산(대수) → 변환 일관성(논리)의 삼중 해석

## M3. 조건 재해석 (Condition Reinterpretation) — 4개

### [앵커 M3-1] WBG-2025M #5 (재) · 집합 연산 축약
- **소재**: 중첩 집합식 → $(A\cup B)\cap(A\cup B^{c})=A$ 발견 → 식 간소화
- **방법론**: M3 + M5
- **다층구조**: 표면 복잡성 > 실질 간단함. 중복 표현에서 진정한 제약 추출

### [앵커 M3-2] WBG-2025M #8 · 부분집합 조건 논리합
- **소재**: 조건 (나) "$X-A \subset X-B$ 또는 $X-B \subset X-A$"
- **방법론**: M3 + M1
- **다층구조**: 논리합이 경우 수 증가로 보이나 역방향 해석하면 $A, B$의 구조 이용 단순화

### [앵커 M3-3] WBG-2025M #14 · 대칭이동 · 궤적
- **소재**: 점 $A(0,1)$을 직선 $2ax-4y-a^2=0$에 대칭이동한 점 $P$의 궤적
- **방법론**: M3 + M7
- **다층구조**: P의 좌표를 역으로 보면 a의 조건이 부등식으로 재해석. a 소거로 궤적 도출

### [앵커 M3-4] WBG-2025M #17 · 개기월식·공통외접선
- **소재**: 태양·지구·달·공통외접선·본그림자
- **방법론**: M3 + M2
- **다층구조**: "개기식 종료" 물리 조건 → 기하 제약 3개로 재해석

## M4. 숨겨진 구조 (Hidden Structure) — 4개

### [앵커 M4-1] WBG-2025M #10 · 포물선·이등변삼각형·숨은 대칭축
- **소재**: 이차함수 $y=(x-k)^2-3$과 $y=6$의 교점 · $\triangle$AOB 이등변 · $k$의 개수·최솟값
- **방법론**: M4 + M6
- **다층구조**: 이등변 조건이 실제로는 $k$의 함수 관계로 축약. 대칭성 먼저 발견해야 경우 수 정리

### [앵커 M4-2] WBG-2025M #13 · 삼각형 넓이·외적 구조
- **소재**: $\triangle$OAB 넓이 $S$를 $x_1, x_2, y_1, y_2$로 표현
- **방법론**: M4
- **다층구조**: $S = \frac{1}{2}(x_1 y_2 - x_2 y_1)$의 외적 표현 발견 필수

### [앵커 M4-3] WBG-2025M #12 · 내분점·넓이 이등분·숨은 중선
- **소재**: 원점·$A(a,12)$·$B(6,4)$·AB의 3:1 내분점 $P$·넓이 이등분·$x$절편 -12
- **방법론**: M4 + M1
- **다층구조**: 넓이 이등분이 "직선이 무게중심 지나거나 특정 변 이등분"으로 축약

### [앵커 M4-4] WBG-2025M #9 · 두 원 교점·근축
- **소재**: 두 원 $(x+1)^2+y^2=9$·$(x-2)^2+(y-4)^2=16$의 교점 $x$좌표
- **방법론**: M4
- **다층구조**: 근축(radical axis) 개념 사용하면 계산량 단순화. 두 원 방정식의 차

## M5. 다층 판정 (Layered Judgment) — 4개

### [앵커 M5-1] WBG-2025M #8 (재) · 부분집합·논리합 판정
- **소재**: 조건 (나) 두 부분집합 관계의 논리합
- **방법론**: M5
- **다층구조**: 1차 판정과 2차 판정이 상호 배타 or 포함. 최종은 두 판정 결과의 합·차·교

### [앵커 M5-2] WBG-2025M #15 (재) · 원·격자점·삼중 교집합
- **소재**: 두 원 교차 조건 → 격자점 → 삼중 교집합
- **방법론**: M5
- **다층구조**: 3층 판정 (거리 조건 → 격자점 → 특정 교집합)이 순차·종속

### [앵커 M5-3] WBG-2025M #16 (재) · 닮음·좌표·넓이비
- **소재**: 삼각형 닮음 · 좌표 대응 · 원의 변환·넓이비
- **방법론**: M5
- **다층구조**: 닮음(1차) → 좌표 변환(2차) → 넓이 계산(3차) 판정 연쇄

### [앵커 M5-4] WBG-2025M #17 (재) · 원·직선·공통접선·달 위치
