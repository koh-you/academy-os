## 2. 프로젝트 개요

### 목적
- 단원별 핵심 개념·유형을 **효율적 분량**으로 정리
- 개념 → 대표 유형 → 연습 → 실전 폐루프 학습
- 상위권 학생을 위한 **깊이 있는 심화 학습**

### 대상층
- **상위권** (schema.md 대상층 · ★ 3~5)
- 대표 예제는 **★ 4** 급 · 개념 확인이 아니라 실전 감각 형성

### 벤치마킹
- **수능특강**: 디자인 (녹색 톤·프레임·라벨) · 예제/유제 배치
- **RPM**: 개념 훑기 · 유형별 분류
- **개념원리**: 상세 풀이·개념 정합

## 3. 교재 구조 (v1.1 상세 재편)

### 단원 흐름 (마스터 지시 반영)

```
[단원 시작]
   ↓
① 개념 1 요약 (1페이지) — 두 점 사이 거리
   ↓
② 대표 예제 1 (★ 4급 · 풀이) + 확인 문제 (하단)
   ↓
③ 개념 2 요약 (1페이지) — 선분의 내분점·중점
   ↓
④ 대표 예제 2 (★ 4급 · 풀이) + 확인 문제 (하단)
   ↓
⑤ 개념 3 요약 (1페이지) — 삼각형의 무게중심
   ↓
⑥ 대표 예제 3 (★ 4급 · 풀이) + 확인 문제 (하단)
   ↓
⑦ 연습문제 (Level 1 · Level 2 · Level 3)
   ↓
⑧ 실전유형 맛보기 (학평 유형 · 단원당 1~2 페이지)
   ↓
[단원 종료]
```

### 페이지 유형 상세

#### ① 개념 요약 페이지 (1개념당 1페이지)
- **1 페이지 전체를 하나의 소개념** (예 "두 점 사이의 거리")에 할당
- 여유 공간 활용 · 풍부한 설명 · 도해·예시·응용 팁 포함
- 수능특강 개념 페이지 확장판 (더 크게)

#### ② 대표 예제 페이지 (개념 요약 다음)
- **상단**: 대표 예제 (★ 4급) · 풀이·답
- **하단**: 확인 문제 2~3문 (★ 3~4급 · 답만 or 풀이 답지에)
- 수능특강 예제·유제 스타일

#### ⑦ 연습문제 페이지 (Level 1·2·3, v1.2 재정의)
- **Level 1** (★ 3·4): 기본 응용 · 12문
- **Level 2** (★ 4·5): 심화 · 10문 · RPM 필수·상 혼합
- **Level 3** (★ 5 프리미엄): 도전 · 8문 · RPM 상·학평 최상위 · 통찰 정점

#### ⑧ 실전유형 맛보기 (학평 소스)
- **소스**: 학평 (전국연합학력평가) 기출·변형
- 단원당 1~2 페이지 · 6문
- **★ 4·5급** (학평 실전 감각)

## 9. LaTeX 스타일 (`templates/deep-note.sty` 신규)

### 색 팔레트 (수능특강 녹색 · 학원 브랜딩 조율)

```latex
\definecolor{dn-primary}{HTML}{5B7F3F}     % 짙은 녹색 (배너·강조)
\definecolor{dn-light}{HTML}{DAE5CE}       % 옅은 녹색 (개념 박스 배경)
\definecolor{dn-accent}{HTML}{E6ECDD}      % 아주 옅은 (라벨 배경)
\definecolor{dn-ink}{HTML}{222222}         % 본문 텍스트
\definecolor{dn-highlight}{HTML}{C05050}   % 강조 색 (핵심 공식·붉은 톤)
```

### 필수 매크로 (수능특강 스타일 벤치마킹)

```latex
% 챕터 배너 (녹색 큰 사각)
\newcommand{\dnchapter}[2]{...}  % \dnchapter{01}{평면좌표}

% 개념 요약 페이지 (1p 전체)
\newenvironment{dnconcept}[2]{...}  % 개념 번호 + 제목

% 개념 부속 라벨 (수능특강 `예`·`참고`·`설명`)
\newenvironment{dnexample}{...}    % 예
\newenvironment{dnnote}{...}       % 참고
\newenvironment{dnexplain}{...}    % 설명

% 대표 예제 (★ 4급 · 상단)
\newenvironment{dnrepresentative}[1]{...}  % 문제 번호

% 풀이 (길잡이·풀이)
\newenvironment{dnapproach}{...}   % 길잡이
\newenvironment{dnsolution}{...}   % 풀이

% 확인 문제 (하단 · 2~3문)
\newcommand{\dncheck}[1]{...}      % 확인 문제 번호

% 연습문제 Level 배너
\newcommand{\dnlevel}[1]{...}      % \dnlevel{1} · \dnlevel{2} · \dnlevel{3}

% 실전유형 맛보기 배너
\newcommand{\dnrealtype}{...}
```
