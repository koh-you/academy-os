## §2. RED pseudo-formal 종결어미 (label + 본문 서술 · 모두 감지)

| 종결 | 대체 | 예시 |
|---|---|---|
| ~ 확인 | ~ 확인한다 · ~ 를 확인 | "실효성 확인" → "조건을 만족하는지 확인한다" |
| ~ 조사 | ~ 를 살핀다 · ~ 를 검토한다 | "만남의 개수 조사" → "만나는 점의 개수를 살핀다" |
| ~ 판단 | ~ 를 판단한다 · ~ 를 결정한다 | "부호 판단" → "부호를 결정한다" |
| ~ 결정 | ~ 를 결정한다 · ~ 가 정해진다 | "위치 결정" → "위치가 정해진다" |
| ~ 판정 | ~ 를 판정한다 · ~ 를 정한다 | "근 판정" → "근의 존재를 확인한다" |
| ~ 산정 | ~ 를 계산한다 · ~ 를 구한다 | "넓이 산정" → "넓이를 구한다" |
| ~ 도입 | ~ 를 도입한다 · ~ 로 놓는다 | "변수 도입" → "변수를 도입한다" |
| ~ 구성 | ~ 를 구성한다 · ~ 로 이룬다 | "방정식 구성" → "방정식을 세운다" |
| ~ 형성 | ~ 를 형성한다 · ~ 를 이룬다 | "삼각형 형성" → "삼각형을 이룬다" |
| ~ 유도 | ~ 를 유도한다 · ~ 가 나온다 | "관계식 유도" → "관계식이 나온다" |
| ~ 처리 | ~ 인 경우 따로 · ~ 별도로 | "예외 처리" → "예외인 경우 따로" |
| ~ 검증 | ~ 를 확인한다 | "값 검증" → "값을 확인한다" |
| ~ 필수 | ~ 해야 한다 · ~ 가 필요하다 | "조건 필수" → "조건을 만족해야 한다" |
| ~ 도출 | ~ 를 얻는다 · ~ 가 나온다 | "결과 도출" → "결과를 얻는다" |
