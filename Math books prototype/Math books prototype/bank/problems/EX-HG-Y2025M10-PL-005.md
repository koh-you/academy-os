**문제**

$x$에 대한 다항식 $x^3 + (2a + 3)x^2 + (3a + 5)x + a + 3$이 $(x + b)(x + c)^2$으로 인수분해되도록 하는 세 실수 $a$, $b$, $c$에 대하여 $a + b + c$의 최댓값을 $M$, 최솟값을 $m$이라 할 때, $M + m$의 값은? [4점]

① 5 ② 6 ③ 7 ④ 8 ⑤ 9

**답**: ② 6

**풀이**:

$(x+b)(x+c)^2 = x^3 + (b+2c)x^2 + (2bc+c^2)x + bc^2$.

계수 비교 → $b = 2a+3-2c$, $bc^2 = a+3$, $2bc+c^2 = 3a+5$.

두 식에서 $a$ 표현 → $(c-1)^2(c-2)(c+1) = 0$. $c = 1, 2, -1$.

- $c = 1$: $a = 2$, $b = 5$. $a+b+c = 8$.
- $c = 2$: $a = 1$, $b = 1$. $a+b+c = 4$.
- $c = -1$: $a = -2$, $b = 1$. $a+b+c = -2$.

$M = 8$, $m = -2$. $M + m = 6$.

- 사차방정식 $c$ 정확 인수분해 (I-PD depth 3) + 다항식·매개변수·다중 case 결합 (I-XU depth 3) + 세 계수 동시 충족 (I-CON depth 3) + a의 두 표현 동치 (I-EQV depth 3).
