**문제**

두 상수 $p$ ($p > 0$), $q$에 대하여 이차함수 $f(x) = \tfrac{1}{2}(x - p)^2 + q$가 있다. 함수 $f(x)$와 양수 $m$에 대하여 함수 $g(x)$를 $g(x) = -f(x - m)$이라 할 때, 방정식 $f(x) = g(x)$가 서로 다른 두 실근 $\alpha$, $\beta$ ($\alpha < \beta$)를 갖는다. 함수 $h(x)$를 $h(x) = \begin{cases} f(x) & (x \le \alpha \text{ 또는 } x \ge \beta) \\ g(x) & (\alpha < x < \beta) \end{cases}$라 할 때, 함수 $h(x)$는 다음 조건을 만족시킨다.

> $x$에 대한 방정식 $h(x) = t$의 서로 다른 실근의 개수가 2 이상이면서 서로 다른 모든 실근의 합이 $4p + 2m$이 되도록 하는 모든 실수 $t$의 값의 범위는 $g(p) < t < 5$이다.

$f(m) + g(m) = -4$일 때, $m \times (p - q)$의 값을 구하시오. [4점]

**답**: (정독 시 보강 필요 — 킬러 ★ 5 문항)

**풀이 (개략)**

$g(x) = -f(x - m)$: $f$를 $m$만큼 평행이동 후 x축 대칭. 두 이차함수의 합·차 분석.

$h(x)$는 분할 정의. 수평선 $y = t$와의 교점 합이 $4p + 2m$ 조건 분석 → 매개변수 도출.

자세한 case 분석은 정독 시 보강.
