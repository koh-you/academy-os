**문제**

다항식 $P(x)$에 대하여 $(x - 2)P(x) - x^2$을 $P(x) - x$로 나누었을 때의 몫은 $Q(x)$, 나머지는 $P(x) - 3x$이다. $P(x)$를 $Q(x)$로 나눈 나머지가 10일 때, $P(30)$의 값을 구하시오. (단, 다항식 $P(x) - x$는 0이 아니다.) [4점]

**답**: 91

**풀이**:

$(x-2)P - x^2 = (P-x)Q + (P-3x)$ → $(x-3)(P-x) = (P-x)Q$ → $Q = x - 3$.

나머지 차수 < $\deg(P-x)$ → $P$ 차수 1. $P(x) = 3x + b$.

$P(3) = 10$ → $b = 1$. $P(x) = 3x + 1$. $P(30) = 91$.

- 자기참조 나눗셈 + 차수 분석 결합 (I-XU depth 3) + 인수분해 패턴 (I-PD depth 3) + 차수 결정 동치 (I-EQV depth 3) + 조건 통합 (I-CON depth 3).
