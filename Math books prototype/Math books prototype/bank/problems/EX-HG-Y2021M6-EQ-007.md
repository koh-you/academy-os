**문제**

삼차방정식 $x^3 + x - 2 = 0$의 서로 다른 두 허근을 $\alpha$, $\beta$라 할 때, $\dfrac{\beta}{\alpha} + \dfrac{\alpha}{\beta}$의 값은? [3점]

① $-\dfrac{7}{2}$ ② $-\dfrac{5}{2}$ ③ $-\dfrac{3}{2}$ ④ $-\dfrac{1}{2}$ ⑤ $\dfrac{1}{2}$

**답**: ③ $-\dfrac{3}{2}$

**풀이**: $x^3 + x - 2 = (x-1)(x^2 + x + 2)$. 허근 $\alpha$, $\beta$는 $x^2 + x + 2 = 0$의 두 근. 근과 계수의 관계로 $\alpha + \beta = -1$, $\alpha\beta = 2$. $\dfrac{\beta}{\alpha} + \dfrac{\alpha}{\beta} = \dfrac{\alpha^2 + \beta^2}{\alpha\beta} = \dfrac{(\alpha+\beta)^2 - 2\alpha\beta}{\alpha\beta} = \dfrac{1 - 4}{2} = -\dfrac{3}{2}$.
