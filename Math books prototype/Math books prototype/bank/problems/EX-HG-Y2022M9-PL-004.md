**문제**

최고차항의 계수가 1인 사차다항식 $f(x)$가 다음 조건을 만족시킬 때, $f(4)$의 값은? [4점]

(가) $f(x)$를 $x + 1$로 나눈 나머지와 $f(x)$를 $x^2 - 3$으로 나눈 나머지는 서로 같다.

(나) $f(x + 1) - 5$는 $x^2 + x$로 나누어떨어진다.

① $-9$ ② $-8$ ③ $-7$ ④ $-6$ ⑤ $-5$

**답**: ③ $-7$

**풀이**: (가) → $f(-1) = f(\sqrt 3) = f(-\sqrt 3) = c$. 홀수항: $3a + c = 0$. (나) → $f(0) = f(1) = 5$.

$d = 5$, $c = -3a$, $b = 2a - 1$, $a - b = 4$ → $a = -3$, $b = -7$, $c = 9$.

$f(4) = 256 - 192 - 112 + 36 + 5 = -7$.
