**문제**

이차방정식 $x^2 + 2x + 3 = 0$의 서로 다른 두 근을 $\alpha$, $\beta$라 할 때, $\dfrac{1}{\alpha^2 + 3\alpha + 3} + \dfrac{1}{\beta^2 + 3\beta + 3}$의 값은? [4점]

① $-\dfrac{1}{3}$ ② $-\dfrac{1}{2}$ ③ $-\dfrac{2}{3}$ ④ $-\dfrac{5}{6}$ ⑤ $-1$

**답**: ③ $-\dfrac{2}{3}$

**풀이**: $\alpha^2 = -2\alpha - 3$ → $\alpha^2 + 3\alpha + 3 = \alpha$. 같은 방식으로 $\beta^2 + 3\beta + 3 = \beta$. 식 $= \dfrac{1}{\alpha} + \dfrac{1}{\beta} = \dfrac{\alpha + \beta}{\alpha\beta} = \dfrac{-2}{3}$.
