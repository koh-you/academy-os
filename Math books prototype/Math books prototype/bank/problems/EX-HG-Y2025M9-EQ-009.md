**문제**

$x$에 대한 삼차방정식 $x^3 - 6x^2 + (k+8)x - 2k = 0$은 서로 다른 세 실근 $\alpha$, $\beta$, $\gamma$ ($\alpha < \beta < \gamma$)를 갖는다. $2\alpha + \beta = 2\gamma$일 때, 상수 $k$의 값은? [4점]

① $\tfrac{27}{8}$ \quad ② $\tfrac{7}{2}$ \quad ③ $\tfrac{29}{8}$ \quad ④ $\tfrac{15}{4}$ \quad ⑤ $\tfrac{31}{8}$

**답**: ④ $\tfrac{15}{4}$

**풀이**: $x = 2$ 대입 → $8 - 24 + 2(k+8) - 2k = 0$ → 항상 $0$. 즉 $x = 2$는 항상 근.

인수분해: $x^3 - 6x^2 + (k+8)x - 2k = (x - 2)(x^2 - 4x + k)$.

나머지 인수 $x^2 - 4x + k = 0$의 두 근 $= 2 \pm \sqrt{4 - k}$ (단, $k < 4$이고 두 근이 $2$가 아니어야 함).

세 근 정렬: $\alpha = 2 - \sqrt{4-k}$, $\beta = 2$, $\gamma = 2 + \sqrt{4-k}$.

$2\alpha + \beta = 2\gamma$ → $2(2 - \sqrt{4-k}) + 2 = 2(2 + \sqrt{4-k})$ → $6 - 2\sqrt{4-k} = 4 + 2\sqrt{4-k}$ → $4\sqrt{4-k} = 2$ → $\sqrt{4-k} = \tfrac{1}{2}$ → $4 - k = \tfrac{1}{4}$ → $k = \tfrac{15}{4}$.

**검산**: 두 근 $= 2 \pm \tfrac{1}{2}$, 세 근 $\tfrac{3}{2}$, $2$, $\tfrac{5}{2}$. $2 \cdot \tfrac{3}{2} + 2 = 5 = 2 \cdot \tfrac{5}{2}$ ✓.

**왜 ★ 4인가**

- 매개변수 식에서 $x = 2$가 항상 근임을 발견 (I-PD) + 인수분해 동치 변환 (I-EQV) + 정렬·조건 통합 (I-CON). depth_score 6.
