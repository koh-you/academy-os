**문제**

이차항의 계수가 $1$인 이차다항식 $f(x)$에 대하여 $f(x) + 2$는 $x + 2$로 나누어떨어지고, $f(x) - 2$는 $x - 2$로 나누어떨어질 때, $f(10)$의 값을 구하시오. [3점]

**답**: ($f(-2) = -2$, $f(2) = 2$. $f(x) = x^2 + ax + b$. $4 - 2a + b = -2 \Rightarrow b = -6 + 2a$. $4 + 2a + b = 2 \Rightarrow b = -2 - 2a$. $-6 + 2a = -2 - 2a$, $a = 1$, $b = -4$. $f(10) = 100 + 10 - 4 = 106$)
