**문제**

두 인형 $\mathrm{A, B}$에게 색이 정해지지 않은 셔츠와 바지를 모두 입힌 후, 입힌 옷의 색을 정하는 컴퓨터 게임이 있다. 서로 다른 모양의 셔츠와 바지가 각각 $3$개씩 있고, 각 옷의 색은 빨강과 초록 중 하나를 정한다. 한 인형에게 입힌 셔츠와 바지는 다른 인형에게 입히지 않는다. $\mathrm{A}$인형의 셔츠와 바지의 색은 서로 다르게 정하고, $\mathrm{B}$인형의 셔츠와 바지의 색도 서로 다르게 정한다. 이 게임에서 두 인형 $\mathrm{A, B}$에게 셔츠와 바지를 입히고 색을 정할 때, 그 결과로 나타날 수 있는 경우의 수는?

\[
\text{① } 252 \quad \text{② } 216 \quad \text{③ } 180 \quad \text{④ } 144 \quad \text{⑤ } 108
\]

**풀이**

네 단계를 곱의 법칙으로 분리:

**(1) 셔츠 모양**: $3$개의 셔츠 모양 중 $\mathrm{A, B}$가 각각 다른 것 → $_3\mathrm{P}_2=6$.

**(2) 바지 모양**: 마찬가지로 $\mathrm{A, B}$가 다른 바지 → $_3\mathrm{P}_2=6$.

**(3) $\mathrm{A}$의 색**: $\mathrm{A}$ 셔츠 색과 바지 색이 다름. 두 색(빨강, 초록) 중 (셔츠, 바지) = (빨강, 초록) 또는 (초록, 빨강) → $2$.

**(4) $\mathrm{B}$의 색**: 마찬가지로 $2$.

곱의 법칙: $6\times 6\times 2\times 2 = 144$.

**답** **④ $144$**

**해설**
"한 인형에게 입힌 옷은 다른 인형에게 입히지 않음" 조건은 셔츠 모양·바지 모양에 대한 제약이고, 색 제약은 각 인형의 옷 안에서 색이 다른 것뿐이다. 두 종류의 제약이 모양 결정과 색 결정에 **독립적으로** 작용한다는 게 곱셈 구조의 키.

자주 빠지는 함정:
- "$\mathrm{A,B}$의 색도 서로 달라야 한다"고 잘못 읽어 색 단계에서 추가 제약 부과.
- 셔츠 모양 결정에 $3\times 3=9$로 잡아 같은 모양 중복 허용 (조건 위반).
- 색 단계에서 $2\times 2$ 대신 $2$만 곱함 ($\mathrm{B}$의 색 단계 누락).
- $\mathrm{A,B}$ 구별 안 하고 $/2$ 나누는 실수 (인형 구별됨).

8축 점수 근거: C=2 (곱의 법칙 + 다단계 결정), S=3 (4단계 곱셈), D=2 (제약 분리 표준 응용), K=2, A=2, T=3 (제약 오해·색 단계 누락·인형 구별 함정), I=2 (제약 독립성 통찰).
