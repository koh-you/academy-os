**문제**

복소수 $z$에 대하여 $z + \bar{z} = -1$, $z\bar{z} = 1$일 때,
$$\dfrac{\bar{z}}{z^5} + \dfrac{(\bar{z})^2}{z^4} + \dfrac{(\bar{z})^3}{z^3} + \dfrac{(\bar{z})^4}{z^2} + \dfrac{(\bar{z})^5}{z}$$
의 값은? (단, $\bar{z}$는 $z$의 켤레복소수이다.) [4점]

① $2$ ② $3$ ③ $4$ ④ $5$ ⑤ $6$

**답**: ④ $5$

**풀이**: $z\bar z = 1$이므로 $\bar z = 1/z$. 각 항은 $\dfrac{\bar z^k}{z^{6-k}} = \dfrac{1/z^k}{z^{6-k}} = \dfrac{1}{z^6}$. 5개 항 모두 $\dfrac{1}{z^6}$. $z$는 $t^2 + t + 1 = 0$의 근이므로 $z^3 = 1$, $z^6 = 1$. 따라서 합 $= 5$.
