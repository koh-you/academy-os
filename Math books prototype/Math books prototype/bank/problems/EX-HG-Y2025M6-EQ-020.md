**문제**

$x$에 대한 삼차방정식 $(x - 1)(x^2 + ax + b) = 0$의 서로 다른 세 근을 $\alpha$, $\beta$, $\gamma$라 하자. $(2\alpha + 2\beta - \gamma)^2 = -81$일 때, $(4 + \alpha)(4 + \beta)(4 + \gamma)$의 값을 구하시오. (단, $a$, $b$는 실수이다.) [4점]

**답**: 65

**풀이**:

$(\cdots)^2 = -81 < 0$ → 좌변 허수 → 두 근이 켤레 허근. $x^2 + ax + b = 0$의 두 근이 $u \pm vi$ ($v \ne 0$), 다른 근 $= 1$.

$\alpha = 1$, $\beta = u + vi$, $\gamma = u - vi$ (일반성 잃지 않음).

$2 + 2(u + vi) - (u - vi) = 2 + u + 3vi$. 제곱 $= (2+u)^2 - 9v^2 + 6v(2+u)i = -81$.

허수부 $0$ → $v(2 + u) = 0$. $v \ne 0$이므로 $u = -2$.

실수부 $-9v^2 = -81$ → $v^2 = 9$.

$\beta\gamma = u^2 + v^2 = 4 + 9 = 13$. $\beta + \gamma = 2u = -4$.

$(4 + \alpha)(4 + \beta)(4 + \gamma) = 5 \cdot (16 + 4(\beta + \gamma) + \beta\gamma) = 5 \cdot (16 - 16 + 13) = 5 \cdot 13 = 65$.

**왜 ★ 5 strict인가**

- 제곱 음수 → 복소수 도출 (I-PD depth 3) + 삼차+켤레 허근+근과 계수 결합 (I-XU depth 3) + 실수·허수부 분리 (I-EQV depth 3).
