**문제**

집합 $X = \{-2, -1, 0, 1, 2\}$에 대하여 함수 $f: X \to X$가 역함수가 존재하고 다음 조건을 만족시킨다.

(가) $(f \circ f)(-1) + f^{-1}(-2) = 4$

(나) $k = 0, 1$일 때, $f(k) \times f(k - 2) \le 0$이다.

$6f(0) + 5f(1) + 2f(2)$의 값을 구하시오. [4점]

**답**: (정독 시 보강 필요 — 킬러 ★ 5)

**왜 ★ 5 strict인가**

- 일대일대응·합성·역함수·부호 조건 결합 (I-XU depth 3) + 합 = 4 case 분기 (I-PD depth 3) + 조건 통합 (I-CON depth 3) + 5! case (I-MI depth 3).
- depth_score 8.8.
