**문제**

두 실수 $a$, $b$에 대하여 이차방정식 $x^2 + ax + b = 0$의 서로 다른 두 근은 $\alpha$, $\beta$이고, 이차방정식 $x^2 + 3ax + 3b = 0$의 서로 다른 두 근은 $\alpha + 2$, $\beta + 2$이다. 다음 조건을 만족시키는 자연수 $n$의 최솟값을 구하시오. [4점]

(가) $\alpha^n + \beta^n > 0$
(나) $\alpha^n + \beta^n = \alpha^{n+1} + \beta^{n+1}$

**답**: $6$

**풀이 (마더텅 답지)**: $\alpha + \beta = -a$, $\alpha\beta = b$. 두 번째 방정식에서 $(\alpha+2)+(\beta+2) = -3a$, $(\alpha+2)(\beta+2) = 3b$. 연립: $\alpha + \beta = 2$, $\alpha\beta = 4$. $x^2 - 2x + 4 = 0$에서 $x^3 = -8$이므로 $\alpha^3 = -8$, $\beta^3 = -8$. $\alpha^6 + \beta^6 = 64 + 64 = 128$, $\alpha^7 + \beta^7 = -8(\alpha^4 + \beta^4) = \dots = 128$. 따라서 구하는 $n$의 최솟값은 $6$이다.
