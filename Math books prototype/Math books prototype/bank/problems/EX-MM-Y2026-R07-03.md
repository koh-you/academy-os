**문제**

이차방정식 $x^2 - 6x + 11 = 0$의 서로 다른 두 허근을 $\alpha$, $\beta$라 할 때, $11\left(\dfrac{\overline{\alpha}}{\alpha} + \dfrac{\overline{\beta}}{\beta}\right)$의 값을 구하시오. (단, $\overline{\alpha}$, $\overline{\beta}$는 각각 $\alpha$, $\beta$의 켤레복소수이다.) [3점]

**답**: $14$

**풀이 (마더텅 답지)**: 이차방정식 $x^2 - 6x + 11 = 0$의 두 허근은 $x = 3 \pm \sqrt{2}i$이므로 $\alpha = 3 - \sqrt{2}i$, $\beta = 3 + \sqrt{2}i$라 하면 $\overline{\alpha} = 3 + \sqrt{2}i = \beta$, $\overline{\beta} = 3 - \sqrt{2}i = \alpha$. 근과 계수의 관계로 $\alpha + \beta = 6$, $\alpha\beta = 11$. $\therefore 11\left(\dfrac{\overline{\alpha}}{\alpha} + \dfrac{\overline{\beta}}{\beta}\right) = 11\left(\dfrac{\beta}{\alpha} + \dfrac{\alpha}{\beta}\right) = 11 \cdot \dfrac{\alpha^2 + \beta^2}{\alpha\beta} = 14$
