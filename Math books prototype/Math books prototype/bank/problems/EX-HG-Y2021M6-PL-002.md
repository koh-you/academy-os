**문제**

$x$의 값에 관계없이 등식
$$3x^2 + ax + 4 = bx(x-1) + c(x-1)(x-2)$$
가 항상 성립할 때, $a + b + c$의 값은? (단, $a$, $b$, $c$는 상수이다.) [3점]

① $-6$ ② $-5$ ③ $-4$ ④ $-3$ ⑤ $-2$

**답**: ③ $-4$

**풀이**: $x = 1$ 대입: $3 + a + 4 = 0$ → $a = -7$. $x = 2$: $12 + 2a + 4 = 2b$ → $2 = 2b$ → $b = 1$. $x^2$ 계수: $3 = b + c$ → $c = 2$. 따라서 $a + b + c = -7 + 1 + 2 = -5$.

**검증**: $a + b + c = -7 + 1 + 2 = -5$. 답 ② $-5$.
