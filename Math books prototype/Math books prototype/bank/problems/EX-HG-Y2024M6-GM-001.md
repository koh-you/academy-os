**문제**

그림과 같이 길이가 $2a$인 선분 AB를 지름으로 하는 반원이 있다. 호 AB 위의 두 점 C, D가 $\overline{AC} = \overline{CD} = a - 1$, $\overline{BD} = 8$을 만족시킬 때, $a^3 - \dfrac{1}{a^3}$의 값은? (단, $a$는 $a > 4$인 상수이다.) [4점]

① 231 ② 232 ③ 233 ④ 234 ⑤ 235

**답**: ④ 234

**풀이**:

중심각 $\alpha_1 = \angle AOC$, $\alpha_2 = \angle COD$, $\alpha_3 = \angle DOB$. $\alpha_1 = \alpha_2$ (현 AC = 현 CD), $\alpha_1 + \alpha_2 + \alpha_3 = \pi$ → $\alpha_3 = \pi - 2\alpha_1$.

현 = $2a \sin(\alpha/2)$. $BD = 2a \sin(\alpha_3 / 2) = 2a \cos \alpha_1 = 8$ → $\cos \alpha_1 = \tfrac{4}{a}$.

$AC = 2a \sin(\alpha_1/2) = a - 1$. 반각: $\cos \alpha_1 = 1 - 2 \sin^2(\alpha_1/2) = \tfrac{a^2 + 2a - 1}{2a^2}$.

같음 → $a^2 + 2a - 1 = 8a$ → $a^2 - 6a - 1 = 0$ → $a = 3 + \sqrt{10}$ ($> 4$ ✓).

$a^2 = 6a + 1$, $\tfrac{1}{a} = a - 6$. $a^3 = 37a + 6$, $\tfrac{1}{a^3} = 37a - 228$.

$a^3 - \tfrac{1}{a^3} = 6 + 228 = 234$.
