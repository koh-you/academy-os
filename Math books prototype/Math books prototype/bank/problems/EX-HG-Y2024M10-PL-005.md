**문제**

다항식 $(x^2 + 2x)(2x^2 + 4x + 5) + 3$이 $(x + a)^2(2x^2 + bx + c)$로 인수분해될 때, $a + b + c$의 값을 구하시오. (단, $a$, $b$, $c$는 상수이다.) [3점]

**답**: 8

**풀이**: $t = x^2 + 2x$ → $2t^2 + 5t + 3 = (2t + 3)(t + 1) = (2x^2 + 4x + 3)(x + 1)^2$.

$a = 1$, $b = 4$, $c = 3$. 합 $= 8$.
