**문제**

실수 $k$와 최고차항의 계수가 $\tfrac{1}{2}$인 이차함수 $f(x)$에 대하여 $x$에 대한 방정식 $f(x) + x = k$가 서로 다른 두 자연수 $\alpha$, $\beta$를 근으로 가질 때, 함수 $f(x)$는 다음 조건을 만족시킨다.

(가) $f(\beta) = \beta$

(나) 모든 실수 $x$에 대하여 $f(x) \ge \beta$이다.

$f(0) \le \alpha + \beta + f(\alpha)$일 때, 모든 $f(6)$의 값의 곱은? [4점]

① 45 ② 48 ③ 51 ④ 54 ⑤ 57

**답**: ① 45

**풀이**:

(나) → $f$의 최솟값 $= \beta$, 꼭짓점 $y = \beta$. (가) $f(\beta) = \beta$ → 꼭짓점의 $x$좌표 $= \beta$.

$f(x) = \tfrac{1}{2}(x - \beta)^2 + \beta$.

$f(x) + x = k$의 두 근 $\alpha, \beta$ → 식 $\tfrac{1}{2}(x-\beta)^2 + \beta + x - k = 0$에서 한 근 $\beta$ 대입: $0 + \beta + \beta - k = 0$ → $k = 2\beta$. 두 근의 합 $\alpha + \beta = \beta + (\beta - 2) = 2\beta - 2$ ... 직접 풀면:

$\tfrac{1}{2}(x-\beta)^2 + x + \beta = 2\beta$ → $(x-\beta)^2 + 2x - 2\beta = 0$ → $(x-\beta)(x - \beta + 2) = 0$ → 근 $\beta, \beta - 2$.

따라서 $\alpha = \beta - 2$. 자연수 조건 → $\beta \ge 3$.

조건 $f(0) \le \alpha + \beta + f(\alpha)$:

$f(0) = \tfrac{\beta^2}{2} + \beta$. $f(\alpha) = f(\beta - 2) = \tfrac{1}{2} \cdot 4 + \beta = \beta + 2$. $\alpha + \beta + f(\alpha) = (2\beta - 2) + (\beta + 2) = 3\beta$.

$\tfrac{\beta^2}{2} + \beta \le 3\beta$ → $\beta(\beta - 4) \le 0$ → $\beta \le 4$. 결합: $\beta = 3, 4$.

$f(6) = \tfrac{(6-\beta)^2}{2} + \beta$:
- $\beta = 3$: $\tfrac{9}{2} + 3 = \tfrac{15}{2}$.
- $\beta = 4$: $2 + 4 = 6$.

곱 $= \tfrac{15}{2} \cdot 6 = 45$.

**왜 ★ 5인가 (strict 미달, base ★ 5)**

- $f(\beta) = \beta$ + $f(x) \ge \beta$ → 꼭짓점 패턴 발견 (I-PD depth 3).
- 4 조건 동시 충족 (I-CON depth 3).
