**문제**

$x$에 대한 다항식 $x^3 + ax^2 + bx - 4$를 $x + 1$로 나누었을 때의 몫은 $Q(x)$이고 나머지는 3이다. $(x^2 + a)Q(x - 2)$가 $x - 2$로 나누어떨어질 때, $Q(1)$의 값은? (단, $a$, $b$는 상수이다.) [4점]

① $-15$ ② $-13$ ③ $-11$ ④ $-9$ ⑤ $-7$

**답**: ③ $-11$

**풀이**:

$P(-1) = 3$ → $a - b = 8$.

$Q(x) = x^2 + px + q$. $(x+1)Q + 3 = P$ → $p = a - 1$, $q = -7$.

$(x^2 + a)Q(x-2)$ at $x = 2$ → $(4 + a)Q(0) = 0$. $Q(0) = -7 \ne 0$ → $a = -4$.

$p = -5$. $Q(x) = x^2 - 5x - 7$. $Q(1) = -11$.

**왜 ★ 4인가**

- 두 나눗셈 조건 통합 (I-CON) + Q(0)≠0 강제 발견 (I-PD) + 계수 동치 (I-EQV). depth_score 6.
