**문제**

$x$에 대한 사차방정식 $(2x^2 + kx)^2 + 10(2x^2 + kx) + 16 = 0$의 서로 다른 실근의 개수가 2가 되도록 하는 모든 자연수 $k$의 값의 합을 구하시오. [4점]

**답**: 18

**풀이**:

$t = 2x^2 + kx$로 치환: $(t+2)(t+8) = 0$ → $t = -2$ 또는 $-8$.

- $2x^2 + kx + 2 = 0$: 판별식 $D_1 = k^2 - 16$.
- $2x^2 + kx + 8 = 0$: 판별식 $D_2 = k^2 - 64$.

두 방정식의 공통근 없음 ($-2 \ne -8$). 총 실근 2:

- $D_1 > 0, D_2 < 0$: $16 < k^2 < 64$ → 자연수 $k = 5, 6, 7$. 합 18.
- (다른 case는 동시 만족 불가 또는 실근 ≠ 2)

**왜 ★ 4인가**

- 치환으로 이차로 환원 (I-PD) + 두 이차식 판별식 case 분기 (I-MI) + 동시 조건 (I-CON). depth_score 7.
