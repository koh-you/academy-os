**문제**

$x$, $y$에 대한 이차식 $x^2 + kxy - 3y^2 + x + 11y - 6$이 $x$, $y$에 대한 두 일차식의 곱으로 인수분해 되도록 하는 자연수 $k$의 값을 구하시오. [3점]

**답**: $2$

**풀이**: $(x + ay + b)(x + cy + d)$ 꼴. $ac = -3$, $a + c = k$ (자연수), $bd = -6$, $b + d = 1$, $ad + bc = 11$. $a + c = k > 0$이고 $ac = -3$이므로 $k = 2$, $\{a, c\} = \{3, -1\}$. $b + d = 1$, $bd = -6$이므로 $\{b, d\} = \{3, -2\}$. $(a, c, b, d) = (3, -1, -2, 3)$이면 $ad + bc = 9 + 2 = 11$ ✓. $k = 2$.
