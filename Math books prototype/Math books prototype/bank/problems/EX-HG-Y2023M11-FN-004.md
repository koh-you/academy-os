**문제**

집합 $X = \{-3, -2, -1, 0, 1, 2\}$에서 실수 전체의 집합으로의 일대일함수 $f(x)$가 다음 조건을 만족시킨다.

(가) 집합 $X$의 모든 원소 $x$에 대하여 $\{f(x) + x^2 - 5\} \times \{f(x) + 4x\} = 0$이다.

(나) $f(0) \times f(1) \times f(2) < 0$

$f(-3) + f(-2) + f(-1) + f(0) + f(1) + f(2)$의 값을 구하시오. [4점]

**답**: 26

**풀이**:

$f(x) = -x^2 + 5$ 또는 $-4x$. $x = -1$에서 둘 다 $4$ → $f(-1) = 4$.

일대일·부호 조건 추적 → $f(-3) = 12$, $f(-2) = 8$, $f(-1) = 4$, $f(0) = 5$, $f(1) = -4$, $f(2) = 1$. 합 $= 26$.

**왜 ★ 5 strict인가**

- 집합·일대일·인수분해 분기 결합 (I-XU depth 3) + $x=-1$ 일치 패턴 (I-PD depth 3) + 모든 조건 통합 (I-CON depth 3) + case 분기 (I-MI depth 3).
- depth_score 8.8 (max=3, avg=2.8, count=5) → **★ 5 strict 충족**.
