**문제**

상수 $a$에 대하여 다항식 $f(x)$를 $(x - a)^2$으로 나눈 나머지는 $2f(x) + 6x^2 - 4$이다. $\{f(x)\}^2 - 2f(x) + 3$을 $x^2 - 4x - 5$로 나눈 나머지가 2일 때, $f(a^2)$의 값을 구하시오. [4점]

**답**: 16

**풀이**:

**1단계 — $f$의 차수·최고차 계수 결정**. 나머지는 차수 ≤ 1이어야 함. $2f(x) + 6x^2 - 4$가 차수 ≤ 1이 되려면 $f$의 $x^2$ 계수가 $-3$, $f$가 이차.

$f(x) = -3x^2 + bx + c$. 그러면 나머지 $= 2(-3x^2 + bx + c) + 6x^2 - 4 = 2bx + 2c - 4$.

**2단계 — $(x-a)^2$ 나눔**. $f(x) = -3x^2 + bx + c = -3(x-a)^2 + (b - 6a)x + (c + 3a^2)$.

나머지 비교: $b - 6a = 2b$ → $b = -6a$. $c + 3a^2 = 2c - 4$ → $c = 3a^2 + 4$.

따라서 $f(x) = -3x^2 - 6ax + 3a^2 + 4$.

**3단계 — 두 번째 조건**. $\{f(x)\}^2 - 2f(x) + 3 = (f(x) - 1)^2 + 2$. 이를 $(x-5)(x+1)$로 나눈 나머지가 상수 2 → $f(5) = f(-1) = 1$.

- $f(5) = -75 - 30a + 3a^2 + 4 = 3a^2 - 30a - 71 = 1$ → $a^2 - 10a - 24 = 0$ → $a = 12$ 또는 $-2$.
- $f(-1) = -3 + 6a + 3a^2 + 4 = 3a^2 + 6a + 1 = 1$ → $3a(a + 2) = 0$ → $a = 0$ 또는 $-2$.

교집합: $a = -2$.

**4단계 — $f(a^2) = f(4)$**. $f(x) = -3x^2 + 12x + 16$. $f(4) = -48 + 48 + 16 = 16$.

**왜 ★ 5 strict인가**

- 자기참조 식 (나머지 자체가 $f$를 포함) → 차수 강제 발견 (I-PD depth 3).
- PL + EQ 단원 결합 (I-XU depth 3).
- 두 나머지 조건 동시 충족 (I-CON depth 3).
