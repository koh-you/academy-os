**문제**

그림과 같이 중심이 같고 반지름의 길이가 각각 $1, 2, 3, 4, 5$인 다섯 개의 원이 있다. 이 다섯 개의 원을 경계로 하여 안에서부터 다섯 개의 영역 $\mathrm{A, B, C, D, E}$로 나누고, 서로 다른 $3$가지 색의 물감을 사용하여 색칠된 문양을 만들려고 한다. 각 영역은 $1$가지 색으로만 칠하고, 이웃한 영역은 서로 다른 색을 칠한다. $3$가지 색의 물감은 각각 $10$통 이하만 사용할 수 있고 물감 $1$통으로는 영역 $\mathrm{A}$의 넓이만큼만 칠할 수 있을 때, 만들 수 있는 서로 다르게 색칠된 문양의 개수는?

\[
\text{① } 9 \quad \text{② } 12 \quad \text{③ } 15 \quad \text{④ } 18 \quad \text{⑤ } 21
\]

**그림(동심원 영역)**:
- 동심원 $5$개, 반지름 $1, 2, 3, 4, 5$
- 안에서부터 영역 라벨: $\mathrm{A, B, C, D, E}$ (라벨은 중심에서 일렬 표시)

**풀이**

영역 $\mathrm{A}$의 넓이를 단위로 잡으면 ($\mathrm{A}=\pi$):
$$\mathrm{A}=1,\;\mathrm{B}=3,\;\mathrm{C}=5,\;\mathrm{D}=7,\;\mathrm{E}=9 \quad (\text{단위: }\mathrm{A}\text{의 넓이}).$$

**단계 1.** 인접 구조는 $\mathrm{A}\text{–}\mathrm{B}\text{–}\mathrm{C}\text{–}\mathrm{D}\text{–}\mathrm{E}$ 일렬(경로). 이웃 다른 색이라는 조건만 보면 $3\cdot 2^4=48$가지.

**단계 2.** 면적 제약. 한 색이 칠하는 영역 면적 합 $\le 10$ (단위로 환산). 가장 큰 영역 $\mathrm{E}=9$가 어디 들어가는지가 관건.

- $\mathrm{E}$가 들어가는 색 $X$: $X$의 합 $\le 10$이 되려면 $\mathrm{E}$ 외에 추가로 들어갈 수 있는 영역은 $\mathrm{A}(=1)$뿐. (다른 큰 영역과 합치면 $\mathrm{E}+\mathrm{B}=12$ 등으로 초과.)
- $\mathrm{D}$가 들어가는 색 $Y$ ($Y\neq X$, $\mathrm{D},\mathrm{E}$ 인접): 합 $\le 10$이 되려면 $\mathrm{D}$ 외 추가 영역은 $\mathrm{A}(=1)$ 또는 $\mathrm{B}(=3)$. ($\mathrm{D}+\mathrm{C}=12$ 초과, $\mathrm{D}+\mathrm{A}+\mathrm{B}=11$ 초과.)
- $\mathrm{C}$는 어느 색에 들어가도 큰 영역과 합쳐지면 초과. 따라서 $\mathrm{C}$는 $X,Y$가 아닌 제3색 $Z$.

**단계 3.** 각 영역의 색을 풀어내기.

조건 $\mathrm{C}=Z$, $\mathrm{D}=Y$ 그리고 $\mathrm{C}\text{–}\mathrm{D}$ 인접에서 $Y\neq Z$ ✓.

$\mathrm{B}$의 색: $\mathrm{B}\text{–}\mathrm{C}$ 인접에서 $\mathrm{B}\neq Z$. 또 $\mathrm{B}$가 $X$이면 $X$의 합 $\ge 9+3=12$ 초과 — 불가. 따라서 $\mathrm{B}=Y$.

$\mathrm{A}$의 색: $\mathrm{A}\text{–}\mathrm{B}$에서 $\mathrm{A}\neq Y$. $\mathrm{A}=X$ 또는 $\mathrm{A}=Z$ 가능.

각 경우 검증:
- $\mathrm{A}=Z$: 색 분포 $X=\{\mathrm{E}\}$(합 $9$), $Y=\{\mathrm{B},\mathrm{D}\}$(합 $10$), $Z=\{\mathrm{A},\mathrm{C}\}$(합 $6$). 모두 $\le 10$ ✓.
- $\mathrm{A}=X$: $X=\{\mathrm{A},\mathrm{E}\}$(합 $10$), $Y=\{\mathrm{B},\mathrm{D}\}$(합 $10$), $Z=\{\mathrm{C}\}$(합 $5$). 모두 $\le 10$ ✓.

**단계 4.** 두 패턴 $\mathrm{ZYZYX}$, $\mathrm{XYZYX}$ 각각에 $3$색을 역할 $X, Y, Z$로 배정 = $3!=6$가지.

총 $2\times 6=12$.

**답** **② $12$**

**해설**
큰 영역 $\mathrm{E}, \mathrm{D}, \mathrm{C}$가 어느 색에 들어갈 수 있는지를 면적 제약으로 강하게 제한하는 게 풀이의 출발. $\mathrm{C}$가 항상 제3색이라는 점을 잡으면 나머지가 도미노처럼 결정된다.

자주 빠지는 함정:
- 면적 제약을 잊고 $48$로 답하는 실수.
- $\mathrm{E}$가 어느 색에 들어가도 된다고 생각해 분기를 너무 많이 잡음.
- 두 색만 사용하는 패턴이 가능한지 검증 누락 (총 $25$를 두 색에 분배하면 한 색이 $\ge 13$이 되어 항상 초과 — 불가).

검증: 색 $1,2,3$으로 직접 enum 시 $(1,2,1,2,3)$, $(1,2,3,2,1)$, $(1,3,1,3,2)$, $(1,3,2,3,1)$ 4가지 (시작색 $1$ 고정). 시작색 $3$가지 곱해 $12$ ✓.
