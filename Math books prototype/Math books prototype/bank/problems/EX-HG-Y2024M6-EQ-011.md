**문제**

$x$에 대한 삼차방정식 $x^3 - (a^2 + a - 1)x^2 - a(a-3)x + 4a = 0$이 서로 다른 세 실근 $\alpha$, $\beta$, $\gamma$ ($\alpha < \beta < \gamma$)를 가질 때, $\alpha \times \gamma = -4$가 되도록 하는 모든 실수 $a$의 값의 합은? [4점]

① 1 ② 2 ③ 3 ④ 4 ⑤ 5

**답**: ① 1

**풀이**:

근과 계수: $\alpha\beta\gamma = -4a$. $\alpha\gamma = -4$ → $\beta = a$. 따라서 인수분해: $(x - a)(x^2 + (1-a^2)x - 4) = 0$.

나머지 두 근은 $\alpha + \gamma = a^2 - 1$, $\alpha\gamma = -4$. $\alpha, \gamma = $ $t^2 - (a^2-1)t - 4 = 0$의 근. $D > 0$ 항상 ✓.

$\beta = a$가 두 근과 다름 + 정렬 $\alpha < a < \gamma$.

- $a = -1$: $\alpha + \gamma = 0$, $\alpha\gamma = -4$ → $\alpha, \gamma = -2, 2$. $-2 < -1 < 2$ ✓.
- $a = 2$: $\alpha + \gamma = 3$, $\alpha\gamma = -4$ → $\alpha, \gamma = -1, 4$. $-1 < 2 < 4$ ✓.
- $a = -2$: $\alpha + \gamma = 3$, $\alpha\gamma = -4$ → $\alpha, \gamma = -1, 4$. $\beta = -2 < -1 = \alpha$ ✗.

합 $= -1 + 2 = 1$.
