**문제**

최고차항의 계수가 1인 삼차다항식 $f(x)$와 모든 항의 계수가 실수인 두 다항식 $P(x)$, $Q(x)$가 다음 조건을 만족시킨다.

(가) $f(x)$를 $P(x)$로 나누었을 때의 몫은 $Q(x)$이고 나머지는 $P(x) + \{Q(x)\}^2$이다.

(나) $f(x)$를 $Q(x)$로 나누었을 때의 몫은 $P(x)$이고 나머지는 $P(x) + \{Q(x)\}^2$이다.

$P(0) = -2$, $Q(0) = 1$일 때, $f(2)$의 값은? [4점]

① $-3$ ② $-2$ ③ $-1$ ④ $0$ ⑤ $1$

**답**: ⑤ 1

**풀이**:

$\deg(P + Q^2) < \deg P$ 및 $< \deg Q$ → $\min < \deg P, \deg Q$. $\deg f = 3$이라 $\deg P + \deg Q = 3$. 가능: $\deg P = 2, \deg Q = 1$.

$P(x) = ax^2 + bx + c$, $Q(x) = dx + e$. $P + Q^2$가 상수 (차수 < 1) → 계수 0:

$a + d^2 = 0$, $b + 2de = 0$.

또 $ad = 1$ (f의 최고차 1). $a = -d^2$이라 $ad = -d^3 = 1$ → $d = -1$, $a = -1$, $b = 2$.

$P(0) = c = -2$, $Q(0) = e = 1$.

$P(x) = -x^2 + 2x - 2$, $Q(x) = -x + 1$.

$f(x) = PQ + P + Q^2 = x^3 - 3x^2 + 4x - 3$. $f(2) = 8 - 12 + 8 - 3 = 1$.
