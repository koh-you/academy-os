**문제**

이차함수 $f(x) = ax^2 + bx + 5$가 다음 조건을 만족시킬 때, $f(-2)$의 값을 구하시오. [4점]

(가) $a$, $b$는 음의 정수이다.

(나) $1 \leq x \leq 2$일 때, 이차함수 $f(x)$의 최댓값은 $3$이다.

**답**: $3$

**풀이**: $a < 0$ (위로 볼록), 꼭짓점 $x = -b/(2a) < 0$ ($a, b < 0$). 구간 $[1, 2]$에서 단조감소, 최댓값 $f(1) = a + b + 5 = 3$ → $a + b = -2$. 음의 정수: $(a, b) = (-1, -1)$. $f(-2) = -4 + 2 + 5 = 3$.
