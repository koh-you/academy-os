**문제**

그림과 같이 선분 AB를 빗변으로 하는 직각삼각형 ABC가 있다. 점 C에서 선분 AB에 내린 수선의 발을 H라 할 때, $\overline{CH} = 1$이고 삼각형 ABC의 넓이는 $\dfrac{4}{3}$이다. $\overline{BH} = x$라 할 때, $3x^3 - 5x^2 + 4x + 7$의 값은? (단, $x < 1$) [4점]

① $13 - 3\sqrt 7$ ② $14 - 3\sqrt 7$ ③ $15 - 3\sqrt 7$ ④ $16 - 3\sqrt 7$ ⑤ $17 - 3\sqrt 7$

**답**: ④ $16 - 3\sqrt 7$

**풀이**: $|AB| = \tfrac{8}{3}$. $CH^2 = AH \cdot BH$ → $AH = \tfrac{1}{x}$. $AH + BH = AB$ → $3x^2 - 8x + 3 = 0$. $x < 1$에서 $x = \tfrac{4 - \sqrt 7}{3}$.

$3x^2 = 8x - 3$ → $3x^3 = 8x^2 - 3x$. $3x^3 - 5x^2 + 4x + 7 = 9x + 4 = 12 - 3\sqrt 7 + 4 = 16 - 3\sqrt 7$.

**왜 ★ 5 strict인가**

- 직각삼각형 수선 공식·삼차식 값 결합 (I-XU depth 3) + CH² = AH·BH 패턴 (I-PD depth 3) + 이차식 만족 활용 (I-EQV depth 3) + 조건 통합 (I-CON depth 3).
