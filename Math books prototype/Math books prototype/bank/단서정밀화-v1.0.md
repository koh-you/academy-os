# 단서(\cond) 정밀화 규약 v1.0 (2026-06-27 마스터 확립)

> **마스터 명시 (2026-06-27, EQ-미니모의고사-시범-1회차 정밀 비교 후)**: "본 시스템 단서(\cond)가 기호·범위만 차단하는데 마더텅은 4 카테고리 함정을 사전에 사전 차단한다. 사고 깊이 유도 갭의 핵심."

## 0. 목적

`\cond{...}` 발문 단서가 *학생이 함정으로 빠질 가능성*을 *사전 차단*하면서도 *불필요한 친절은 회피*. 4 카테고리 중 ≥ 1개 활성 의무 (★ 4·5 슬롯).

- **불충분 차단**: 학생이 함정 케이스로 풀이 → 답 틀림 → 학습 효과 ✗
- **과잉 친절**: 학생이 *생각 없이* 차단된 길만 따라감 → 사고 유도 ✗
- **본 규약 목표**: 4 카테고리 분류로 *함정의 필요·충분 차단* 균형

---

## 1. 4 카테고리 함정 차단

### 카테고리 A — 기호 정의 차단

학생이 표기 자체를 *오해*할 가능성을 차단.

| 표기 | 정의 단서 (\cond 예) |
|---|---|
| $\bar{z}$ (켤레복소수) | $\bar{z}$는 $z$의 켤레복소수 |
| $\omega$ (1의 3제곱근) | $\omega$는 $x^3 = 1$의 실수가 아닌 한 근 |
| ${}_n\mathrm{P}_r$, ${}_n\mathrm{C}_r$ | 순열·조합의 표준 표기 (생략 가능 — 교과서 표준 기호) |
| $\lfloor x \rfloor$ (가우스) | $\lfloor x \rfloor$는 $x$를 넘지 않는 가장 큰 정수 |
| $\det A$, $\mathrm{tr}\, A$ | 🔴 CM1 외 — 사용 금지 |

**기준**: 교과서 표준 기호는 정의 생략 OK. 비표준·교과 외(가우스 등) 또는 *해석 분기* 가능 기호는 정의 의무.

### 카테고리 B — 정수성·실수성·양수성 차단

학생이 변수의 *범위·정의역*을 잘못 가정할 가능성을 차단.

| 함정 | 단서 예 |
|---|---|
| 실수만 vs 허수 포함 | $a$, $b$는 실수 |
| 정수만 vs 분수 포함 | $a$, $b$, $c$는 정수 |
| 자연수만 vs 0·음수 포함 | $n$은 자연수 |
| 양수만 vs 음수 포함 | $k > 0$ |
| 자명해 $x = 0$ 함정 | $x \ne 0$ |
| 분모 $\ne 0$ 함정 | $a + b \ne 0$ |

**기준**: 답을 *유한 케이스*로 한정하기 위한 범위 단서. 학생이 *무한 후보로 분기*하지 않도록.

### 카테고리 C — 예외값 차단

답 도출에 *치명적 예외*가 발생하는 특정 값을 차단.

| 함정 | 단서 예 |
|---|---|
| $a = b$로 두 방정식 같음 | $\alpha \ne \beta$ |
| 두 점 일치 | 점 $\mathrm{P}$와 점 $\mathrm{Q}$는 서로 다른 점 |
| 한 점 = 원점 | $\mathrm{C} \ne \mathrm{O}$ |
| 한 근 = 매개변수 | $k \ne 0$ |
| 분기 함수의 경계 | $a \ne 2$ (단, $2$에서 정의되지 않음) |

**기준**: 그 값을 *허용*하면 답이 무수히 많아지거나 분모가 0이 되는 *수학적 비정합* 발생 시 차단.

### 카테고리 D — 중복 회피 차단

같은 객체를 *여러 번 지칭*해도 학생이 *별도 객체*로 해석하지 않도록.

| 함정 | 단서 예 |
|---|---|
| 두 번 등장한 점 일치 | 점 $\mathrm{C}$는 점 $\mathrm{A}$도 아니고 점 $\mathrm{O}_1$도 아님 |
| 같은 변수의 다른 인덱스 | $a_1 < a_2 < a_3$ (단, 자연수 $a_i$는 모두 서로 다름) |
| 보기 ㄱ과 ㄴ 변수 분리 | (ㄱ의 $k$와 ㄴ의 $k$는 서로 다른 변수) |
| 자기참조 매개변수 | $f(k) = k$의 *고정점* (점화 $k$와 결과 $k$가 같은 변수) |

**기준**: 표기의 *모호성*으로 학생이 케이스를 잘못 나눌 가능성 차단.

## 2. 적용 의무

### ★ 4·5 슬롯 (의무)

- **\cond ≥ 1개** + **카테고리 ≥ 1개 명시**
- 카테고리 라벨링은 청사진 YAML에 `cond_categories: [A, B]` 등으로 기록
- 검수 게이트: `cond_categories` 누락 시 RED

### ★ 3 슬롯 (권장)

- 카테고리 B (정수성·실수성) 이상 1개 권장
- 카테고리 A는 비표준 기호 사용 시 의무

### ★ 1·2 슬롯 (자유)

- 단서 자체가 자명한 절차형이므로 강제 X

## 3. 4 카테고리 활성도 점검 (mini-rubric)

각 슬롯의 `\cond` 통과 여부:

| 점검 | 통과 기준 |
|---|---|
| 카테고리 명시 | `cond_categories` 필드 ≥ 1개 |
| 함정 매핑 | 차단한 *구체 함정 1개* 청사진에 명시 |
| 동치성 | 단서 추가로 *답의 유일성* 보장 (mathjs 재검증) |
| 비과잉 | 학생이 *생각하지 않고* 따라가지 않도록 — 단서가 *풀이 단계*를 직접 안내 X |

**비과잉 RED 예시**: `\cond{x = 1을 대입하여 $f(1)$을 먼저 구하라}` — 단계 안내 → 사고 우회 위장

## 4. 본 1회차 적용 후행 분석 (시범)

| # | 본 1회차 단서 (있음) | 카테고리 | 함정 차단 |
|---|---|---|---|
| 1 | "$a$, $b$는 정수" (가정) | B | 분수해 분기 |
| 2 | "$\bar{z}$는 $z$의 켤레복소수" | A | 표기 오해 |
| 4 | "$a$, $b$는 양의 정수" + "$a + b = 5$" | B + D | 정수·자유도 |
| 6 | (보기 ㄱ·ㄴ·ㄷ·ㄹ 각각 독립) | D | 보기 변수 분리 |
| 7 | "$x \ne 0$" (제곱합 분기) | C | 자명해 차단 |
| 8 | "$a < b$, $a$, $b$는 자연수" | B + D | 카운팅 분기 |

**1회차 카테고리 활성도**: A 1슬롯·B 4슬롯·C 1슬롯·D 3슬롯. 모든 ★ 4·5 슬롯 ≥ 1 카테고리 통과. 다양성 권장 (A·B·C·D 골고루 — 본 1회차는 B 편향).

**개선 권고**: 신규 회차 출제 시 카테고리 A·C 슬롯 ≥ 2개씩 (현재 1개씩만).
