**제외 (응용)**: 중점 활용 (평행사변형 등)

## 02 직선 (CM2-GM-02)

### 02|1 직선의 방정식 (개념원리 p.34~35)

**핵심 개념**:
1. 기울기·$y$절편 표준형 $y = mx + n$
2. 한 점과 기울기 $y - y_1 = m(x - x_1)$
3. 두 점 $y - y_1 = \dfrac{y_2 - y_1}{x_2 - x_1}(x - x_1)$ ($x_1 = x_2$이면 $x = x_1$)
4. $x$절편·$y$절편 $\dfrac{x}{a} + \dfrac{y}{b} = 1$
5. 좌표축에 평행·수직 직선 $x = a$, $y = b$
6. 일반형 $ax + by + c = 0$

**제외 (응용)**: 세 점 공선 조건 · 정점 (§02 필수예제·보충)

### 02|2 두 직선의 위치 관계 (개념원리 p.47~48)

**핵심 개념**:
1. 위치 관계 3종: 평행·일치·한 점에서 만남
2. 평행 조건 $m = m'$, $n \ne n'$
3. 수직 조건 $mm' = -1$
4. 표준형·일반형 통합 판정 (계수 비교 조건 + 연립방정식 해)

**제외 (응용)**: 수직이등분선 (필수예제) · 세 직선 삼각형 미형성 (필수예제) · 두 직선 교점 지나는 직선 (§02 보충학습)

### 02|3 점과 직선 사이의 거리 (개념원리 p.56~57)

**핵심 개념**:
1. 점-직선 거리 공식 $d = \dfrac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}$
2. 원점-직선 거리 $d = \dfrac{|c|}{\sqrt{a^2 + b^2}}$
3. 평행한 두 직선 사이의 거리 (정의)

**제외 (응용)**: 삼각형 넓이 (특강) · 평행 직선 거리 공식 유도 (필수예제)

## 05 집합과 명제 (CM2-ST)

개념원리 소단원 구성 (**12 소단원**). 우리 05 파일 dmconcept 3개 대응:
- c1 집합의 뜻과 연산 = 1-01·1-02·2-01·2-02·2-03 통합
- c2 명제와 조건·역·대우 = 3-01·3-02·3-03·3-04 통합

### 05|1-01 집합의 뜻과 표현 (개념원리 p.120~121)

**핵심 개념**:
1. 집합의 정의 (대상 분명한 모임) · 원소
2. 원소와 집합 관계 기호 $\in$·$\notin$
3. 집합의 표현 3방법: 원소나열법·조건제시법·벤 다이어그램
4. 원소 개수에 따른 분류: 유한집합·무한집합·공집합 $\emptyset$
5. 유한집합 원소 개수 표기 $n(A)$ ($n(\emptyset)=0$)

**제외 (응용)**: 집합 판정 (모임 분명성) · 조건제시법 표현 변환 응용

### 05|1-02 집합 사이의 포함 관계 (개념원리 p.127~129)

**핵심 개념**:
1. 부분집합 정의 ($A \subset B$·$A \not\subset B$)
2. 부분집합의 성질 3종 ($\emptyset \subset A$·$A \subset A$·추이관계)
3. 서로 같은 집합 ($A=B$ 정의 · $A \subset B$이고 $B \subset A$)
4. 진부분집합 정의 (자기 자신 제외)
5. 부분집합의 개수 $2^n$·진부분집합 개수 $2^n - 1$
6. 특정 원소 포함/제외 부분집합 개수 ($2^{n-k}$·$2^{n-m}$·$2^{n-k-m}$)

**제외 (응용)**: 부분집합 나열 유형 · 특정 원소 갖는 부분집합 활용

### 05|2-01 집합의 연산 (개념원리 p.138~140)

**핵심 개념**:
1. 합집합 $A \cup B$·교집합 $A \cap B$ 정의
2. 서로소 $A \cap B = \emptyset$
3. 합/교집합 성질 (공집합·자기 자신·흡수)
4. 전체집합 $U$·여집합 $A^C$·차집합 $A - B$
5. 집합의 연산 성질 ($A \cup A^C = U$·$(A^C)^C = A$·$A - B = A \cap B^C$ 등)

**보충학습**: 집합의 연산을 이용한 여러 가지 표현 ($A \subset B$·$A \cap B = \emptyset$과 같은 표현)

**제외 (응용)**: 벤 다이어그램 색칠 · 특정 원소 배치 문제

### 05|2-02 집합의 연산 법칙 (개념원리 p.150~151)

**핵심 개념**:
1. 교환법칙·결합법칙·분배법칙 3법칙
2. 드모르간의 법칙 $(A \cup B)^C = A^C \cap B^C$·$(A \cap B)^C = A^C \cup B^C$

**제외 (응용)**: 복잡한 식 간단히 하기 (필수 09) · 세 집합 확장

### 05|2-03 유한집합의 원소의 개수 (개념원리 p.156)

**핵심 개념**:
1. 합집합 원소 개수 $n(A \cup B) = n(A) + n(B) - n(A \cap B)$
2. 세 집합 확장 $n(A \cup B \cup C)$ 공식
3. 여집합·차집합 원소 개수 $n(A^C) = n(U) - n(A)$·$n(A - B) = n(A) - n(A \cap B)$

**제외 (응용)**: 활용 (참가자·과목 신청 문제) · 최댓값·최솟값

### 05|3-01 명제와 조건 (개념원리 p.166~168)

**핵심 개념**:
1. 명제의 정의 (참·거짓 판별 가능한 문장/식)
2. 명제의 부정 $\sim p$
3. 조건 정의 (변수 포함 · 참거짓 판별)
4. 진리집합 $P = \{x \mid x \in U, p(x) \text{ 참}\}$
5. 조건의 부정 진리집합 = $P^C$
6. "$p$ 또는 $q$"·"$p$ 그리고 $q$" 진리집합 ($P \cup Q$·$P \cap Q$)·부정 (드모르간)

**제외 (응용)**: 조건 부정과 진리집합의 원소 열거

### 05|3-02 명제 p → q (개념원리 p.172)

**핵심 개념**:
1. 명제 $p \to q$ 정의 (가정 $p$·결론 $q$)
2. 명제 $p \to q$의 참거짓과 진리집합 포함관계 ($P \subset Q \Leftrightarrow $ 참)
3. 반례 정의

**제외 (응용)**: 명제 참거짓 판정과 진리집합 응용 (원소 개수) · 반례 원소 구하기

### 05|3-03 '모든'이나 '어떤'을 포함한 명제 (개념원리 p.176)

**핵심 개념**:
1. "모든 $x$" 참거짓 판정 ($P = U$이면 참)
2. "어떤 $x$" 참거짓 판정 ($P \ne \emptyset$이면 참)
3. "모든"·"어떤"의 부정 (서로 바뀜 + 조건 부정)

**제외 (응용)**: 절대부등식 응용 (모든 실수에 대하여 참인 조건 → 판별식)

### 05|3-04 명제의 역과 대우 (개념원리 p.180~181)

**핵심 개념**:
1. 명제의 역 $q \to p$·대우 $\sim q \to \sim p$ 정의
2. 명제와 그 대우 참거짓 일치
3. 삼단논법: $p \to q$, $q \to r$ 모두 참이면 $p \to r$ 참

**제외 (응용)**: 대우 이용 반례 판정 활용

### 05|3-05 충분조건과 필요조건 (개념원리 p.184)

**핵심 개념**:
1. 충분조건·필요조건 정의 ($p \Rightarrow q$일 때 $p$는 충분·$q$는 필요)
2. 필요충분조건 $p \Leftrightarrow q$
3. 진리집합 포함관계 ($P \subset Q$·$P = Q$)와 충분/필요/필요충분 대응

**제외 (응용)**: 미지수 결정 (조건 만족하는 상수 값 범위)

### 05|3-06 명제의 증명 (개념원리 p.191)

**핵심 개념**:
1. 정의·정리
2. 대우를 이용한 증명
3. 귀류법 (결론 부정 → 모순)

**제외 (응용)**: $\sqrt{2}$ 무리수 증명 등 대표 유제 (본문 예제 활용)

### 05|3-07 절대부등식 (개념원리 p.195~196)

**핵심 개념**:
1. 절대부등식 정의 (모든 실수 대입해도 성립)
2. 부등식 증명에 이용되는 실수의 성질 5종 ($a > b \Leftrightarrow a - b > 0$·$a^2 \ge 0$·$|a|^2 = a^2$ 등)
3. 여러 가지 절대부등식 ($a^2 \pm ab + b^2 \ge 0$·$a^2 \pm 2ab + b^2 \ge 0$·$a^2 + b^2 + c^2 - ab - bc - ca \ge 0$)
4. 산술평균과 기하평균의 관계 $\dfrac{a+b}{2} \ge \sqrt{ab}$ ($a, b > 0$)

**보충학습**: 코시-슈바르츠 부등식 $(a^2 + b^2)(x^2 + y^2) \ge (ax + by)^2$

**제외 (응용)**: 합·곱 일정할 때 최댓/최솟값 (필수 17~19) · 최적화 활용

**핵심 개념**:
1. 일대일함수 정의 ($x_1 \ne x_2 \Rightarrow f(x_1) \ne f(x_2)$)
2. 일대일대응 정의 (일대일함수 + 치역 = 공역)
3. 항등함수 $I(x) = x$
4. 상수함수 $f(x) = c$

**보충학습**: 우함수 ($f(-x) = f(x)$·$y$축 대칭)·기함수 ($f(-x) = -f(x)$·원점 대칭)

**제외 (응용)**: 일대일대응 되기 위한 조건 (계수 결정) · 그래프 판정

### 06|03 합성함수 (개념원리 p.224~225)

**핵심 개념**:
1. 합성함수 $g \circ f: X \to Z$ 정의·$(g \circ f)(x) = g(f(x))$
2. 합성함수 정의 조건 (치역 $\subset$ 정의역)
3. 합성함수의 성질 3종:
   - 교환법칙 성립하지 않음 ($g \circ f \ne f \circ g$)
   - 결합법칙 ($h \circ (g \circ f) = (h \circ g) \circ f$)
   - 항등함수 $f \circ I = I \circ f = f$

**제외 (응용)**: 그래프 통해 값 구하기 · 조건식 만족 계수 결정

### 06|04 역함수 (개념원리 p.234~236)

**핵심 개념**:
1. 역함수 $f^{-1}: Y \to X$ 정의
2. 역함수 존재 조건 (일대일대응 필요충분)
3. 역함수 구하기 3단계 ($y = f(x) \to x = f^{-1}(y) \to$ 문자 교환)
4. 역함수의 성질:
   - $(f^{-1})^{-1} = f$
   - $f^{-1} \circ f = I_X$·$f \circ f^{-1} = I_Y$
   - $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$
5. 역함수 그래프 = 원함수 그래프 직선 $y = x$ 대칭

**제외 (응용)**: 조건 $f^{-1}(a) = b$ 활용 상수 결정 · 그래프 교점 응용

## 07 유리함수 (CM2-RF-01 · **2 소단원**)

### 07|01 유리식 (개념원리 p.248~249)

**핵심 개념**:
1. 유리식 정의 ($A/B$·$B \ne 0$) · 다항식·분수식 분류
2. 유리식의 성질 (통분 $A/B = AC/(BC)$·약분 $A/B = (A \div C)/(B \div C)$)
3. 사칙연산 (덧셈·뺄셈·곱셈·나눗셈)
4. 특수한 형태 계산:
   - (분자 차수) $\ge$ (분모 차수) → 대분수식 변형
   - 유리식 4개 이상 → 두 개씩 묶기
   - 분모 인수 곱 → 부분분수 $\dfrac{1}{AB} = \dfrac{1}{B-A}\left(\dfrac{1}{A} - \dfrac{1}{B}\right)$
   - 번분수식

**특강 (개념 페이지 옆)**: 비례식 ($a:b = c:d \Leftrightarrow a/b = c/d$)

**제외 (응용)**: 비례식 값 계산 응용 · $f(1) + f(2) + \cdots$ 부분분수 소거형

### 07|02 유리함수 (개념원리 p.259~261)

**핵심 개념**:
1. 유리함수 정의 · 다항함수·분수함수
2. 유리함수 정의역 (분모 $\ne 0$)
3. $y = k/x$ ($k \ne 0$) 그래프:
   - 정의역 $\{x \mid x \ne 0\}$·치역 $\{y \mid y \ne 0\}$
   - 사분면 (부호 따라)·점근선 $x$축·$y$축
   - 원점 및 $y = \pm x$ 대칭
4. $y = k/(x-p) + q$ 그래프 (평행이동 결과):
   - 점근선 $x = p$·$y = q$
   - 점 $(p, q)$ 대칭
5. $y = (ax+b)/(cx+d)$ 그래프: $y = k/(x-p) + q$ 꼴로 변형
6. $y = (ax+b)/(cx+d)$ 역함수: $f^{-1}(x) = (-dx+b)/(cx-a)$

**제외 (응용)**: 그래프 개형 판별 · 계수 결정 · 함숫값 범위

## 08 무리함수 (CM2-RF-02 · **2 소단원**)

### 08|01 무리식 (개념원리 p.276)

**핵심 개념**:
1. 무리식 정의 (근호 안 문자 · 유리식으로 표현 불가)
2. 무리식이 실수가 되기 위한 조건: (근호 안의 식의 값) $\ge 0$·(분모) $\ne 0$
3. 제곱근의 성질 ($\sqrt{a}\sqrt{b} = \sqrt{ab}$·$\sqrt{a^2 b} = a\sqrt{b}$ 등 · $a, b > 0$)
4. 분모의 유리화 3형태 ($a/\sqrt{b}$·$c/(\sqrt{a} + \sqrt{b})$·$c/(\sqrt{a} - \sqrt{b})$)

**제외 (응용)**: $x = \sqrt{3}$ 등 대입 계산 응용 · $f(1) + \cdots + f(99)$ 소거형

### 08|02 무리함수 (개념원리 p.279~280)

**핵심 개념**:
1. 무리함수 정의 · 정의역 (근호 안 $\ge 0$)
2. $y = \sqrt{x}$ 그래프 (역함수 $y = x^2$ ($x \ge 0$) 이용)·부호 4종 ($\sqrt{x}$·$-\sqrt{x}$·$\sqrt{-x}$·$-\sqrt{-x}$)
3. $y = \sqrt{ax}$ ($a \ne 0$) 그래프 (사분면·정의역·치역)
4. $y = \sqrt{a(x-p)} + q$ 그래프 (평행이동 결과)
5. $y = \sqrt{ax+b} + c$ 그래프: $y = \sqrt{a(x + b/a)} + c$ 꼴로 변형

**제외 (응용)**: 그래프 개형 판별 · 계수 결정 · 직선과 교점 개수
