## 단계 1 — v3.0 3층 모델 재산정 (M·I·X)
각 문항을 [`bank/schema.md`](schema.md) v3.0 루브릭으로 채점:
1. **1층 M (4축)** — Mₛ(단계) · Mₖ(계산) · Mₐ(추상도) · Mₜ(함정 카테고리) 각 1~3점. M_total = 4~12

3. **3층 X (단원 친숙도)** — Xᵤ (CM1-MX +1.0 / CM1-CB·CM2-FN +0.5 / 기타 0)
4. **★ 산정** — schema §2 알고리즘으로 base_star (절차형 ★ 4 천장, ★ 5는 절차형 불가) → effective_star = base + round(Xᵤ)
5. 본 ★와 시험지/교재의 배점·라벨(`\pointbadge`·`\dotX`)이 일치하는지 비교
6. 책 단위 정합: 책의 `audience` 디폴트 분포(§3.1)와 실제 ★ 분포가 ±5%p 이내인지

## 단계 4 — 수정 적용
- 결과 표에서 위반·드리프트가 **0**이면: 보고만 하고 완료.
- 위반·드리프트가 있으면: **마스터에게 묻지 말고 즉시 수정안 적용 후 재빌드·재검수**까지 1패스로 진행. 단, 다음 경우는 마스터 결정 필요:
  - 라벨 드리프트가 5문항 초과 (광범위 재출제는 시험지 정체성 변경 가능)
  - 디자인 위반이 보호 영역(🔴, [`유형편-디자인.md`](../templates/유형편-디자인.md) §"변경 가능/금지 영역")에 해당
  - 새 패턴이 같은 시험지의 다른 문항과 다시 충돌
  - 세련도 미달(★ 4·5 슬롯 refine < 의무) 처리 결정 (보강 vs 강등 vs 유지)
- 위 예외 시 분류된 위반 표를 먼저 보고하고 마스터의 (A·B·C 단계 선택) 결정을 받음.
- **점수 변동 시 [[feedback_100_point_policy]] 적용** (**시험지 한정**) — 시험지(testpaper) 작업물의 점수 변동은 상향·하향 페어링으로 총합 100점 정확 유지. **유형교재(유형편·연습편)는 점수 개념 없음 — 도트(`\dota`·`\dotb`·`\dotc`) 라벨로 표기, 100점 정책 적용 외**.
