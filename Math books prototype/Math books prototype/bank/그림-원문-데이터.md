# 원본 은행 문항별 그림 원문 유무 데이터

**단일 출처**: 각 원본 은행 (개념원리·RPM·고쟁이·블랙라벨·EBS·전국연합) 문항에 대해 **원문(교재·기출 원본)에 그림이 있는지** 축적. 조판 판정 시 이 카탈로그를 조회하며, 신규 정독 시 확장.

## 데이터 스키마

각 항목:
- **source_id**: 정독 파일의 문항 코드 (예: RPM-CM2-GM-#0020)
- **figure_in_original**: `true` (그림 있음) · `false` (그림 없음) · `unknown` (원 PDF 미조회)
- **figure_type**: 좌표평면_대응 · 순수기하 · 도식 · 그래프 · 표 · 기타 (있을 때만)
- **figure_description**: 원문 그림 세부 (예: "삼각형 ABC와 두 수선의 발 D, E")
- **verified_by**: 조회 방법 (`problem_summary` · `PDF조회` · `solution_summary_inference`)
- **verified_date**: 확인 일자

## 판정 기준

1. **problem_summary에 "그림과 같이 / 다음 그림에서 / 그림 참조" 등 지시** → `figure_in_original: true` 유력
2. **solution_summary에 "그림에서 / 위 그림" 언급** → `true` 확인
3. **solution_summary에 "A(x, y)로 좌표화" 같은 좌표 설정** (문제 자체 좌표 무언급) → `false` (풀이자 설정)
4. **problem_summary·solution_summary 모두 그림 언급 없음 + 순수 기하 서술** → `false`
5. **원 PDF 조회로 실물 확인** (가장 확실 · verified_by: PDF조회)

## 활용

- 신규 조판 시 이 카탈로그 조회 · `figure_in_original: true`면 재현 · `false`면 그림 없이 발문만
- `unknown`이면 원 PDF 조회 후 확정
- `scripts/figure-check.mjs`가 이 카탈로그 참조 예정

## 확장 계획 (다음 세션 이후 지속)

1. **정독 파일 신설 시 자동 기록**: subagent가 원본 은행 문항 정독 시 `figure_in_original` 필드 필수 기록 · 이 카탈로그에 자동 편입
2. **원 PDF 조회 백로그**: `unknown` 항목에 대해 순차 PDF 조회 · 확정
3. **`scripts/figure-check.mjs` 확장 (예정)**: Check C · source_id로 이 카탈로그 조회 · 편집물에 그림이 있는데 `figure_in_original: false`면 RED
4. **그림 유형 통계**: 시간 지나면 학평 vs 시판 · 단원별 · 스타 tier별 그림 비율 통계 산출 · 조판 지침에 활용
