>
> **케일리해밀턴 정리 (T09)**: 2022 개정 공통수학1 행렬 단원의 *명시 학습 요소는 아님*. 그러나 시판 다수 책이 옵션으로 다루고 마스터 명시 (2026-06-24 CLAUDE.md §3.0)로 *답지·풀이 직접 인용 허용*. 단 출제 시 *학생이 케해를 유도해야만* 풀 수 있는 발문은 신중.

## 소단원 2: 거듭제곱·주기·폐쇄식 (T05–T09)

### T05: 행렬의 거듭제곱 ($A^n$ 직접 계산 + 추측·증명)
- **id**: `CM1-MX-T05`
- **base ★**: 4
- **meta_type**: MX-power-regularity
- **section**: MX-ops
- **본질 통찰**: $A^2, A^3, A^4, ...$ 계산 → 패턴 추측 → 수학적 귀납 (CM1 외) 대신 *직접 검증*
- **대안 발문**: $A^{10}$ 성분, $A^n$의 일반항, $A^n$의 성분합

### T06: 거듭제곱의 규칙성·주기성 ★★★
- **id**: `CM1-MX-T06`
- **base ★**: 4
- **meta_type**: MX-power-regularity
- **section**: MX-ops
- **본질 통찰**: $A^k = E$ 또는 $A^k = -E$ 같은 *주기*가 발생 → $A^n$ 대신 $A^{n \mod k}$
- **대안 발문**: $A^{2026}$, 누적합 $A + A^2 + \cdots + A^n$, 주기 결정
- **7회차 v2 #23 사용** (누적합) / **v3 #22 사용** (자기참조 $A^2+A+E=O \to A^3=E$)

### T07: 행렬의 곱셈의 성질 (교환법칙 비성립 등)
- **id**: `CM1-MX-T07`
- **base ★**: 4
- **meta_type**: MX-noncomm
- **section**: MX-ops
- **본질 통찰**: $AB \ne BA$, $(A+B)^2 = A^2 + AB + BA + B^2$ ≠ $A^2+2AB+B^2$
- **대안 발문**: ㄱㄴㄷ 명제 셋, $(A+B)^2 = A^2+B^2$ 조건, 가환 행렬 조건

### T08: 단위행렬 $E$ / $E$ 포함 식
- **id**: `CM1-MX-T08`
- **base ★**: 3
- **meta_type**: MX-identity
- **section**: MX-ops
- **본질 통찰**: $E$의 가환성 ($AE = EA = A$), $E$를 포함한 인수분해 등

### T09: 케일리-해밀턴 정리 (옵션) ★★★★
- **id**: `CM1-MX-T09`
- **base ★**: 4
- **meta_type**: MX-identity
- **section**: MX-ops
- **본질 통찰**: $A^2 - (\mathrm{tr}\,A)A + (\det A)E = O$ 폐쇄식 인용 → 거듭제곱 분해
- **대안 발문**: $A^2 = pA + qE$ 형태 직접 제시 (학생은 받아쓰기, 케해 X 풀이도 가능) / 케해 인용형
- **CM1 정책**: *시판 옵션 도구로 답지 직접 인용 허용*. 단 발문에 "케해를 유도하라"는 강요는 신중
- **7회차 v2 #22 시리즈 사용 (5/6/7v1 자기복제)** — v3에서는 v3.0 신규 유형으로 대체

## 소단원 3: 응용·결합 (T10–T14)

### T10: 행렬의 실생활 활용 / 곱셈 응용

- **meta_type**: MX-application
- **section**: MX-ops
- **본질 통찰**: 자재비·운반비 표 → 행렬 모델링 → 곱셈

### T11: 행렬의 곱셈과 이차방정식 (자기참조 폐쇄식 유도) ★★★
- **id**: `CM1-MX-T11`
- **base ★**: 4
- **meta_type**: MX-power-regularity
- **section**: MX-ops
- **본질 통찰**: $A^2 + pA + qE = O$ 형태 폐쇄식을 *직접 곱셈*으로 유도 (케해 미사용)
- **대안 발문**: $A^2 + 3A + 2E$ 같은 식의 성분합, $A^n = ?$ 폐쇄식 활용
- **7회차 v2 #22 v3 ($A^2+A+E=O$) 사용**

### T12: $2 \times 1$ 행렬과의 곱이 주어지는 경우 (마더텅 단독)
- **id**: `CM1-MX-T12`
- **base ★**: 4
- **meta_type**: MX-application
- **section**: MX-ops
- **본질 통찰**: $A\begin{pmatrix}x\\y\end{pmatrix} = \begin{pmatrix}p\\q\end{pmatrix}$로 미지 행렬 $A$ 결정. 학평 표준 유형
- **🔴 시리즈 누락 — 권장**

### T13: ㄱㄴㄷ 명제 변별 (행렬의 성질)
- **id**: `CM1-MX-T13`
- **base ★**: 5
- **meta_type**: MX-proposition
- **section**: MX-ops
- **본질 통찰**: 3개 명제의 참/거짓 판정. 반례 행렬 제시 또는 항등식 증명. *영인자·비가환성·멱영·멱등* 등의 통찰
- **대안 발문**: $A^2 = O$이면 $A = O$? / $A^2 = E$이면 $A = \pm E$? / $AB = O$이면 $A = O$ 또는 $B = O$?
- **시리즈 #14 표준 사용 (5/6/7회차)**

### T14: 자연수 행렬 + 조건 → 개수 (자유도 추적) ★★★★
- **id**: `CM1-MX-T14`
- **base ★**: 5
- **meta_type**: MX-degree-of-freedom
- **section**: MX-ops
- **본질 통찰**: 자연수·정수 성분 + 조건 (예: $A^2 = kA$, $\det A = 0$, $\mathrm{tr}\,A = $ 정수) → 유한 케이스 카운팅. *자유도 추적*
- **대안 발문**: 모든 성분 자연수 + 성분합 조건 + 행렬 조건 → 행렬의 개수, 가능한 $(a, d)$의 순서쌍
- **7회차 v2 #19 사용**
