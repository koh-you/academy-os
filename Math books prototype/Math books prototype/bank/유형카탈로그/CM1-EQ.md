# CM1-EQ 표준 유형 카탈로그 (방정식과 부등식)

> **단일 출처**. 시험범위가 "여러 가지 방정식·부등식"인 경우 본 카탈로그에서 *서로 다른 T-code* ≥ 7개 사용 의무.
>
> 본 카탈로그는 *2022 개정 공통수학1 §"방정식과 부등식"* 범위 내. 복소수·이차방정식·이차함수 단원은 별도 카탈로그 (시험범위 외이나 도구 활용은 §"여러 가지 방정식" 안에서 OK).

## 소단원 1: 여러 가지 방정식 (E01–E13)

### E01: 삼차방정식 인수분해 (인수정리·조립제법)
- **id**: `CM1-EQ-E01`
- **base ★**: 3
- **meta_type**: EQ-cubic-quartic-factor
- **section**: EQ-multi-eq
- **본질 통찰**: $f(\alpha)=0$인 정수·유리수 $\alpha$ 찾기 → $(x-\alpha)$ 인수분해 후 이차 잔여 풀이
- **대안 발문**: 모든 실근 합·곱, 가장 큰 근, 자연수 근의 개수, 정수근 활용
- **금지 변형**: 단순 인수분해만으로 ★ 4 라벨링 X. 매개변수 추가해야 ★ 4 도달

### E02: 사차방정식 인수분해 (인수정리 반복)
- **id**: `CM1-EQ-E02`
- **base ★**: 3
- **meta_type**: EQ-cubic-quartic-factor
- **section**: EQ-multi-eq
- **본질 통찰**: $f(\alpha)=0$ 두 번 적용 → 두 일차 + 한 이차 분해 (또는 두 일차 + 두 일차)
- **대안 발문**: 실근의 합, 곱, 가장 큰 근 등

### E03: 복이차방정식 (y=x² 치환)
- **id**: `CM1-EQ-E03`
- **base ★**: 3
- **meta_type**: EQ-cubic-quartic-factor
- **section**: EQ-multi-eq
- **본질 통찰**: $x^4 + ax^2 + b = 0$ 형태 → $y = x^2$ 치환 → 이차방정식 → $x = \pm\sqrt{y}$
- **대안 발문**: 모든 실근의 곱, 가장 큰 실근

### E04: 사차방정식 묶기 ($(x²+a)(x²+b)$ 또는 $(x^2-3x)^2$ 꼴)
- **id**: `CM1-EQ-E04`
- **base ★**: 4
- **meta_type**: EQ-cubic-quartic-factor
- **section**: EQ-multi-eq
- **본질 통찰**: $f(x) = (x^2-3x)^2 - 2(x^2-3x) - 8 = 0$ 같은 *부분식 치환* 패턴 → 치환 식의 이차방정식
- **대안 발문**: 실근 개수, 가장 큰 실근, 자연수 근

### E05: 삼차방정식 중근 조건 ★★★
- **id**: `CM1-EQ-E05`
- **base ★**: 4
- **meta_type**: EQ-multiplicity
- **section**: EQ-multi-eq
- **본질 통찰**: $f(x) = (x-a)^2(x-b)$ 형태 또는 $f(\alpha)=0$이고 $f'(\alpha)=0$ (CM1 미분 X이므로 *인수분해 + 미정계수 비교*로 처리)
- **대안 발문**: "중근을 갖도록 하는 $k$의 값", "삼차방정식이 두 근만 가질 조건"
- **출제 빈도**: 시리즈 5회마다 ≥ 1회
- **🔴 7회차 v2 누락 — 마스터 직접 지적**

### E06: 사차방정식 중근 조건 ★★★★
- **id**: `CM1-EQ-E06`
- **base ★**: 5
- **meta_type**: EQ-multiplicity
- **section**: EQ-multi-eq
- **본질 통찰**: $(x-a)^2(x^2+bx+c)$ 또는 $(x-a)^2(x-b)^2$ 등 다중 분해 + 추가 조건 (모든 근 정수 등)
- **대안 발문**: "사차방정식이 정확히 두 실근을 갖고 모두 중근일 조건" → 발문은 "겹친 실근을 갖도록..." 자연어로
- **출제 빈도**: 변별 슬롯 1~2회 시리즈
- **🔴 7회차 v2 누락 — 마스터 직접 지적**

### E07: 켤레무리수 근 (단일 무리수 $a+b\sqrt{c}$)
- **id**: `CM1-EQ-E07`
- **base ★**: 4
- **meta_type**: EQ-conjugate-root
- **section**: EQ-multi-eq
- **본질 통찰**: 유리계수 다항방정식의 한 근이 $a+b\sqrt{c}$이면 $a-b\sqrt{c}$도 근 → $(x^2-2ax+a^2-b^2c)$ 인수
- **대안 발문**: 나머지 두 근의 합·차·곱, 계수 결정
- **CM1 허용 한계**: *단일 무리수*만 (예: $1+\sqrt{3}$). $\sqrt{2}+\sqrt{3}$ 같은 *두 종류 무리수*는 CM2 무리식
- **7회차 v2에서 #17 사용**

### E08: 켤레허근 ($a+bi$ 짝) ★★★
- **id**: `CM1-EQ-E08`
- **base ★**: 4
- **meta_type**: EQ-conjugate-root
- **section**: EQ-multi-eq
- **본질 통찰**: 유리계수 사차·삼차의 한 근이 $a+bi$이면 $a-bi$도 근 → $(x^2-2ax+a^2+b^2)$ 인수
- **대안 발문**: 나머지 실근, 계수 결정, 추가 조건 (자연수 근 등)
- **시험범위 안**: 복소수 *도구* 활용 (시험범위 yaml v1.1 정정으로 명시 허용)
- **🔴 7회차 v2 누락 — 마스터 직접 지적 ("3차 4차방정식의 켤레근에서 허근이 나오는 문제")**

### E09: ω 활용 (1의 3제곱근) ★★★★
- **id**: `CM1-EQ-E09`
- **base ★**: 5
- **meta_type**: EQ-omega
- **section**: EQ-multi-eq
- **본질 통찰**: $x^3=1$의 허근 $\omega$ → $\omega^2+\omega+1=0$, $\omega^3=1$ 활용. 거듭제곱 주기성 + 부등식 활용
- **대안 발문**:
  - $\omega^{2025} + \omega^{2026} + \omega^{2027}$의 값
  - $\frac{1}{\omega} + \frac{1}{\omega^2}$의 값
  - $(1+\omega)^n$ 또는 $(\omega-1)(\omega^2-1)$ 활용
  - $x^3+1=0$ 또는 $x^3-1=0$의 허근으로 $\omega$ 도입
- **출제 빈도**: 변별 슬롯, 시리즈 3~5회마다 1회
- **🔴 7회차 v2 누락 — 마스터 직접 지적 ("ω 문제들은 고차방정식의 중요 유형")**

### E10: 모든 근이 정수일 조건 + 정수근 정리
- **id**: `CM1-EQ-E10`
- **base ★**: 4
- **meta_type**: EQ-integer-root
- **section**: EQ-multi-eq
- **본질 통찰**: 정수계수 다항방정식이 정수근 $\alpha$를 가지면 $\alpha \mid$ 상수항. 가능 후보 모두 검사
- **대안 발문**: "삼차방정식이 정수근을 가질 자연수 $k$의 합", "사차방정식의 모든 근이 자연수일 조건"

### E11: 사차방정식 + 추가 조건 (자연수 근·정수 자유도) ★★★★
- **id**: `CM1-EQ-E11`
- **base ★**: 5
- **meta_type**: EQ-integer-root
- **section**: EQ-multi-eq
- **본질 통찰**: $x^2(x-a)(x-b)=0$ 같은 부분 인수 + (가)(나)(다) 다중 조건 → 자연수 자유도 카운트
- **대안 발문**: 순서쌍 $(a,b)$ 개수, 가능한 $a+b$의 합
- **7회차 v2 #21 사용** (보강으로 (다) 조건 추가)

### E12: 연립이차방정식 (대입·소거)
- **id**: `CM1-EQ-E12`
- **base ★**: 3
- **meta_type**: EQ-system
- **section**: EQ-multi-eq
- **본질 통찰**: $x+y=k$, $xy=p$ 또는 $x^2+y^2=r^2$, $x+y=k$ → 한 식 대입 후 이차방정식
- **대안 발문**: 순서쌍 $(x,y)$ 중 특정 조건 만족

### E13: 연립이차방정식 + 매개변수 (실근 조건)
- **id**: `CM1-EQ-E13`
- **base ★**: 4
- **meta_type**: EQ-system
- **section**: EQ-multi-eq
- **본질 통찰**: 매개변수가 들어간 연립이차 → 한 식 대입 후 판별식 ≥ 0 (실근 조건)

## 소단원 2: 여러 가지 부등식 (I01–I12)

### I01: 이차부등식 직접 풀이
- **id**: `CM1-EQ-I01`
- **base ★**: 2
- **meta_type**: EQ-quad-ineq-basic
- **section**: EQ-multi-ineq
- **본질 통찰**: 인수분해 후 두 근 사이/바깥 결정
- **대안 발문**: 해의 길이, 정수해 개수

### I02: 이차부등식 + 정수해 카운트
- **id**: `CM1-EQ-I02`
- **base ★**: 3
- **meta_type**: EQ-quad-ineq-basic
- **section**: EQ-multi-ineq
- **본질 통찰**: 인수분해 + 정수 범위 카운트

### I03: 매개변수 이차부등식 + 정수해 개수 조건
- **id**: `CM1-EQ-I03`
- **base ★**: 4
- **meta_type**: EQ-quad-ineq-param
- **section**: EQ-multi-ineq
- **본질 통찰**: $(x-a)(x-b) \le 0$ 형태에서 $a < b$ 또는 $a > b$ 분기 → 정수 개수 = $|b-a|+1$ 활용
- **7회차 v2 #15 사용**

### I04: 연립이차부등식
- **id**: `CM1-EQ-I04`
- **base ★**: 3
- **meta_type**: EQ-quad-ineq-basic
- **section**: EQ-multi-ineq
- **본질 통찰**: 각 부등식 풀이 → 교집합/합집합

### I05: 매개변수 연립이차부등식 + 정수해 개수
- **id**: `CM1-EQ-I05`
- **base ★**: 4
- **meta_type**: EQ-quad-ineq-param
- **section**: EQ-multi-ineq
- **본질 통찰**: 매개변수 변화에 따른 교집합 정수 카운트 분기 추적
- **7회차 v2 #18 사용**

### I06: 절댓값 부등식 단일
- **id**: `CM1-EQ-I06`
- **base ★**: 2
- **meta_type**: EQ-quad-ineq-basic
- **section**: EQ-multi-ineq
- **본질 통찰**: $|f(x)| \le k$ → $-k \le f(x) \le k$

### I07: 절댓값 부등식 합·차 ($|x-a|+|x-b| \le k$)
- **id**: `CM1-EQ-I07`
- **base ★**: 4
- **meta_type**: EQ-abs-ineq
- **section**: EQ-multi-ineq
- **본질 통찰**: 두 절댓값 영점 $x=a$, $x=b$로 *케이스 3분기* → 각 케이스 부등식 풀이
- **7회차 v2 #3 보강 사용**

### I08: 매개변수 절댓값 부등식
- **id**: `CM1-EQ-I08`
- **base ★**: 4
- **meta_type**: EQ-quad-ineq-param
- **section**: EQ-multi-ineq

### I09: 분수부등식 (단순 $\frac{f}{g} \le 0$)
- **id**: `CM1-EQ-I09`
- **base ★**: 4
- **meta_type**: EQ-frac-ineq
- **section**: EQ-multi-ineq
- **본질 통찰**: $\frac{f(x)}{g(x)} \le 0$ → $f(x) \cdot g(x) \le 0$ 변환 + $g(x) \ne 0$ 제약
- **7회차 v2 #20 사용**

### I10: 모든 실수에서 성립할 조건 (판별식 활용)
- **id**: `CM1-EQ-I10`
- **base ★**: 4
- **meta_type**: EQ-all-real-ineq
- **section**: EQ-multi-ineq
- **본질 통찰**: $ax^2+bx+c > 0$ ∀$x$ → $a > 0$ 및 판별식 < 0 (또는 $a = 0$ 경우 분기)

### I11: 항상 성립할 조건 + 매개변수 분기
- **id**: `CM1-EQ-I11`
- **base ★**: 4
- **meta_type**: EQ-quad-ineq-param
- **section**: EQ-multi-ineq
- **본질 통찰**: I10 + 매개변수 자유도 추적

### I12: 부등식 해집합 + 정수 자유도 ★★★
- **id**: `CM1-EQ-I12`
- **base ★**: 5
- **meta_type**: EQ-quad-ineq-param
- **section**: EQ-multi-ineq
- **본질 통찰**: 부등식 해의 *길이·정수 개수*를 매개변수의 함수로 추적 + 추가 자유도 결합
