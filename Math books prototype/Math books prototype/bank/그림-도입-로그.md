## 0. 로그 형식

각 엔트리는 YAML 블록 (append 방식). 파일 상단 스키마 참조 · 하단으로 최신 엔트리 추가.

### 필드 스키마

```yaml
- log_id: LOG-YYYYMMDD-{round}-{slot}     # 예: LOG-20260717-DR2-14
  date: 2026-07-17                          # ISO date
  session: 47                                # 세션 번호
  round: DeeP-Red-2회                        # 회차 식별자
  slot: 14                                   # 문항 번호
  tier: star_5_premium                       # 청사진 tier
  mechanism_primary: 두 원 접선              # 청사진 필드 or 자유 텍스트
  figure_type: 유형2                         # 유형1(원리)·유형2(좌표)·유형3(관계도)
  figure_source: tikz-inline                 # archive·commons·reference·tikz-inline·matplotlib
  archive_ref: null                          # 재사용 시 M-01·M-02...
  layer1_verdict: REQUIRED                   # figure-need-check 판정 (REQUIRED·RECOMMENDED·OPTIONAL·NO)
  layer1_scores: { C: 3, V: 3, S: 3 }        # 3축 스코어
  R_predicted: 1                             # figure-risk-predict 예측 (0~10)
  R_level_predicted: GREEN                   # GREEN·YELLOW·RED·CRITICAL
  iterations_actual: 1                       # 실측 iteration 회수 (1 = 첫 시도 승인)
  master_verdict: approved                   # approved·revised·rejected·skipped
  reason: "좌표평면 대응 도해 · 두 원 접선 관계 명확 · 답 노출 없음"
  file_ref: "output/공통수학2/DeeP-Red-2회/DeeP-Red-2회-답지.tex#L342"
  reused_from: null                          # 재사용 시 log_id 참조
  will_be_archived: true                     # 승인 후 M-N 등재 여부
  archived_as: null                          # 등재 후 코드 (M-06 등)
  notes: ""                                  # 추가 메모
```

### 필수 필드 vs 선택 필드

**필수**: log_id · date · session · round · slot · tier · layer1_verdict · master_verdict
**선택 (미해당 시 null)**: figure_type · figure_source · R_predicted · iterations_actual · reused_from · archived_as

## 1. master_verdict 분류

| verdict | 의미 | R 실측 iteration 계산 |
|---|---|---|
| **approved** | 마스터 승인 (첫 시도) | 1 |
| **revised** | 수정 후 승인 (N회 iteration) | 실측 N |
| **rejected** | 최종 폐기 (다른 소스로 전환) | 폐기 전 iteration 회수 |
| **skipped** | 도입 결정 후 시간 부족 등으로 미실행 | null |

## 2. figure_source 분류

- `archive` — bank/도해-카탈로그.md M-N 재사용
- `commons` — Wikimedia Commons CC-BY-SA
- `reference` — 참고자료/ PDF 크롭
- `tikz-inline` — 문제/답지 tex 안 TikZ 직접 작성
- `tikz-typed` — `templates/figures/*.sty` 표준 매크로
- `matplotlib` — `scripts/figures/*.py` Python 스크립트

## 3. 로그 사용 절차

### 3.1 신규 회차 완료 시 (append)

```bash
node scripts/figure-log-append.mjs \
  --round "DeeP-Red-3회" --slot 14 --tier star_5_premium \
  --figure-type 유형2 --figure-source tikz-inline \
  --layer1-verdict REQUIRED --r-predicted 1 --iterations 1 \
  --master-verdict approved --reason "좌표평면 대응 · 답 노출 없음"
```

### 3.2 back-test 분석 (정기)

```bash
node scripts/figure-backtest.mjs                          # 전체 로그 상관 분석
node scripts/figure-backtest.mjs --round DeeP-Red-2회      # 특정 회차만
node scripts/figure-backtest.mjs --since 2026-07-01        # 특정 날짜 이후
```

- R 예측 vs 실측 iteration 회귀 (Pearson r)
- 평균 절대 오차 (MAE)
- 판정 등급 (GREEN/YELLOW/RED/CRITICAL) 정확도
- 임계값 재캘리브레이션 권고

### 3.3 archive 자동 확장 (승인 시)

`will_be_archived: true` 엔트리 → 자동으로 `bank/도해-카탈로그.md` M-N 등재:

```bash
node scripts/figure-archive-extend.mjs           # 미등재 승인 엔트리 일괄 처리
```

### 3.4 재사용률 통계

```bash
node scripts/figure-reuse-stats.mjs              # M-01~M-N 재사용 빈도
```

- 미사용 archive 감지 (도입 후 재사용 0회)
- 과사용 archive 감지 (5회+ 사용 시 신규 mechanism 발굴 권고)
- `reused_from` 필드 카운트
