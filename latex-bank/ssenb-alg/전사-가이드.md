## 2. ingest 명령과 옵션 근거

```
node scripts/problem-bank/ingest-scan-badges.mjs \
  --pdf "C:/Users/PC/Downloads/쎈B.pdf" \
  --out output/problem-bank/ssenb-alg \
  --title "쎈B 대수" --folder "대수" --grade 고2 --subject 수학 \
  --badge3 --max-badge 120 --page-offset 0 --pages 6-141 \
  --units "01 지수,02 로그,03 지수함수,04 로그함수,05 삼각함수,06 삼각함수의 그래프,07 삼각함수의 활용,08 등차수열과 등비수열,09 수열의 합,10 수학적 귀납법" \
  --unit-pages "6-17,18-29,30-43,44-57,58-69,70-87,88-99,100-119,120-129,130-141"
```

PDF 는 저장소 안으로 복사하지 않는다. `book_id` 는 `pbk_7a575d05a2` 다(옛 패키지와 다르다 — 크롭 경로를 옛 것과 섞지 말 것).

### `--page-offset 0` (필수 · 실측)

**인쇄 쪽 = pdf 쪽.** 쪽 바닥글을 200dpi 로 잘라 직접 읽어 확인했다: pdf 7 = 「01 지수 · 7」, pdf 119 = 「08 등차수열과 등비수열 · 119」, pdf 141 = 「10 수학적 귀납법 · 141」. 차례는 **pdf 4쪽**이고 거기 적힌 6·18·30·44·60·70·88·102·120·130 은 **개념정리 쪽**이다. 이 옵션을 빼면 쪽 번호 OCR 이 흔들려 id 가 어긋난다.

### `--pages 6-141`

pdf 6(01 개념정리)부터 pdf 141(10 마지막 문항 쪽)까지. pdf 1~5(표지·머리말·Ⅰ 대단원 표지·차례)와 pdf 142~144(상용로그표 1·2 · 삼각함수표)는 넣지 않는다.

### `--badge3` (필수 · 실측)

08 등차수열과 등비수열의 배지가 `001`~`108` 로 **세 자리(앞 0 포함)** 다. 기본 판정은 「세 자리 = 유형 라벨」이라 이 모드를 안 쓰면 그 단원이 통째로 날아간다. 인쇄 103~107쪽 실측:

| | 검출 |
|---|---|
| `--badge3` 없이 | **2개** (p103 1 · p104~106 0 · p107 1) |
| `--badge3` | **27개** |

### `--max-badge 120` (필수 · 실측)

또 유형 상자 바로 앞 문항의 크롭이 **다음 유형 상자와 대표 문제까지 물고 내려올 수 있다**(예 인쇄 17쪽 `17-66` 크롭이 유형 16 상자와 67번 대표 문제를 통째로 삼켰다). 크롭 아래쪽에 유형 상자·다음 문항이 섞여 있으면 그 부분은 전사하지 않는다.

## 무엇이 참인가 — 배지 번호와 쎈 통번호

**배치 목록·크롭 파일 이름의 번호를 맹신하지 않는다.** `review_note` 가 비어 있어도 OCR 오독이 섞인다.

**id 의 뒷자리는 언제나 쪽 이미지에서 읽은 배지 번호다.** 크롭 파일 이름과 다르면 배지 번호를 쓰고 `review_needed` 에 「번호 불일치: 크롭 \<파일번호\> → 배지 \<실제\>」로 적는다.

**누락 판정은 「쎈 NNNN」 통번호로 한다.** 이게 가장 확실한 기준이다 — 문항마다 오른쪽 위에 있고 **한 중단원 안에서는 정확히 1씩 증가한다.** 그리고

> **배지 − 1 = 통번호 − (그 단원 첫 통번호)**

가 항상 성립한다(3절 표의 「쎈 통번호」 첫 값을 쓴다). 단원이 바뀌면 통번호가 건너뛰므로 **단원을 넘어서는 연속성은 보지 않는다.**

이 기준이 미적분1 새 쇄에서 빠진 143개를 찾아낸 바로 그 기준이다. 대표 문제가 빠진 채 뒤 배지가 당겨지면 **배지만 보면 완벽히 연속**이라 「단원 문항 수 = 마지막 배지」 검사에 안 걸린다. 통번호만 그 자리를 짚는다.

통번호는 **문항 크롭 안에 그대로 들어 있다**(크롭 오른쪽 위 「쎈 0753」). manifest 에는 통번호 필드가 없으니 전사할 때 크롭에서 읽어 `ssen_ref` 에 적는다.

담당 쪽의 통번호를 순서대로 적어 보고 **끊긴 자리가 있으면 그 자리에 문항이 있다**는 뜻이니 쪽 이미지에서 찾아 채운다. 앞 배치의 마지막 통번호와도 이어지는지 본다.

### `number_gap(expected N)` 는 「여기서 번호가 건너뛰었다」는 뜻이다

거의 전부 **대표 문제가 빠진 자리**다. `review_note` 에 `number_gap(expected N)` 가 있으면 **N 번 문항이 그 바로 위에 있는데 크롭이 없다**는 뜻이니 쪽 이미지에서 전사해 채운다. 채워 넣은 문항은 `review_needed` 에 「크롭 없음 — 쪽 이미지에서 전사」라고 적는다.

단원 첫 쪽의 `number_gap` 은 **앞 단원의 끝 번호를 기준으로 계산된 것이라 의미가 없다**(예 `31-01!number_gap(expected 67)`). 무시한다.

## items.json 구조

```json
{
  "book": "쎈B 대수", "variant_level": 0,
  "units": [ { "code": "01", "title": "지수", "pages": "7~17", "groups": [
      { "id": "U1-A1", "section": "유형 01 거듭제곱근", "items": ["7-01", "7-02"] },
      { "id": "U1-A2", "section": "유형 02 거듭제곱근의 계산", "passage": "다음 식을 간단히 하시오.", "items": ["8-05"] }
  ] } ],
  "items": { "7-01": { "page": 7, "body": "…", "answer": "", "answer_source": "" } }
}
```

- 그룹 id: `U<단원>-<배치이름><n>` (예 `U1-A1`). 배치 안에서 1부터.
- 그룹 = 「유형 상자 하나」 또는 「공통 지시문 하나」. 유형 상자의 설명 글(연한 바탕 · 「해결 전략」)은 전사하지 않는다 — `section` 제목만 쓴다.
- `section`: 유형 상자의 「유형 01 제목」 그대로(제목에 `;` 가 들어가는 것도 원문대로 — 「유형 20 삼각부등식; 이차식의 꼴」). 제목이 두 줄이면 원문의 `;` 까지 한 줄로 잇는다.

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽. 필수. |
| `body` | 발문 LaTeX. 지시문은 넣지 않는다(그룹 `passage`). |

## 표기 규약 (고2 대수 · 지수·로그 / 삼각함수 / 수열)

- 거듭제곱근·지수: `$\sqrt[3]{8}$`, `$\sqrt[n]{a}$`, `$a^{\frac{1}{2}}$`(지수 안은 `\frac`), `$2^{\sqrt{2}}$`, `$(a^2)^3$`, `$a^{-n}$`. 로그: `$\log_2 8$`, `$\log_a x$`(밑은 아래첨자), 상용로그 `$\log 2$`, `$\log_{\frac{1}{2}} x$`. 상용로그표 값은 원문 그대로(`0.3010`). 「$\log$의 진수」·「밑」·「정수 부분」·「소수 부분」은 한글.
- 지수·로그함수: `$y=2^x$`, `$y=\left(\dfrac{1}{2}\right)^{x}$`, `$y=\log_2 (x-1)+3$`, `$y=a^{bx+c}+r$` 꼴. 점근선·평행이동·대칭이동·최댓값·최솟값은 한글. 방정식·부등식 `$2^{x+1}=8$`, `$\log_2 x<3$`. 「$x$축」 `$x$축`.
- 삼각함수: `$\sin\theta$`, `$\cos\dfrac{\pi}{3}$`, `$\tan(-\theta)$`, `$\sin^2\theta$`, 호도법 `$\dfrac{\pi}{6}$`, 각 `$\theta$`, 「$60^\circ$」 `$60^\circ$`, 「제2사분면」·「동경」·「주기」는 한글. 부채꼴 호의 길이 `$l=r\theta$`, 넓이 `$S=\dfrac{1}{2}r^2\theta$`. 사인법칙·코사인법칙은 원문 그대로(`$\dfrac{a}{\sin A}=2R$` · `$a^2=b^2+c^2-2bc\cos A$`) — 삼각형 변은 `$a$`, 각은 `$A$`. 삼각형·사각형 이름은 `삼각형~$\pt{ABC}$`·`$\angle\pt{A}$`·`$\seg{AB}$`.
- 수열: `$a_n$`, `$\{a_n\}$`, `$a_{n+1}=a_n+3$`, `$S_n$`, 합 `$\displaystyle\sum_{k=1}^{n} a_k$`(`\displaystyle` 를 붙여 본문에서도 위아래 첨자), 첫째항·공차·공비·등차중항·일반항·계차수열은 한글. 수학적 귀납법의 「$n=k$일 때 …」 는 한글 그대로, 증명 빈칸 ㈎㈏㈐ 는 원문 기호 그대로 두고 네모 빈칸은 `\blank`.
