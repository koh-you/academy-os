# 쎈B 대수 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-26. **스캔 PDF**(글자 레이어 없음)이고, 문항 번호는 **중단원마다 01 부터 다시 시작**한다. 문항이 100개를 넘는 **08 등차수열과 등비수열**만 배지가 `001`~`108` 로 **세 자리(앞 0 포함)** 로 찍히고, 나머지 단원은 두 자리다(같은 번호 체계 · 자릿수만 다름). id 는 `쪽-번호`(예 `85-81`, `119-104`)이고 items.json 은 `id_style` 을 쓰지 않는다(쎈B 공통수학1 과 같은 방식). 출처 배지는 「쎈B 대수 85쪽 81번」으로 찍히므로 문항마다 `page`(인쇄 쪽)를 적는다.

교재는 **쎈의 B단계 유형 학습서**다. 중단원마다 「개념 정리」 한 쪽 + 「유형 뽀개기」 여러 쪽으로만 이루어져 있다(「실전 감각 UP」 구역은 이 책에 없다). 유형 상자 바로 아래 「대표 문제」가 오고 그 뒤로 같은 유형의 문항이 이어진다.

## 입력

- 문항 크롭 `output/problem-bank/ssenb-alg/items/pbk_<책id>-<쪽>-<번호>.jpg` (220 dpi).
- 쪽 전체 `output/problem-bank/ssenb-alg/qa/pNNN.jpg` — 구역·유형 제목·태그·난이도·연계 쎈 번호는 **여기서** 읽는다. 문항 크롭만 보고 판단하지 않는다.
- 인쇄 쪽 = pdf 쪽 (offset 0).
- 답·해설은 이 배치에 없다. `answer` 는 **빈 문자열**로 두고 `answer_source: ""` 로 남긴다 — 답지(`C:/Users/PC/Desktop/교재 라텍스 조판/쎈B 대수_정답.pdf`)는 전사 뒤 별도 ingest 로 붙인다.

## 놓친 문항을 채운다 (중요)

스캔 검출기가 번호 배지를 못 읽어 크롭이 없는 문항이 있다. 특히 **「01 대표 문제」처럼 유형 상자 바로 밑에 오는 첫 문항**과 색 배지가 잘 안 잡힌다. 배치 목록에 번호가 비어 있으면 **원본 PDF 쪽 렌더(`qa/pNNN.jpg`)에서 직접 전사해 넣는다.** 빠뜨리면 그대로 사라진다.

### 무엇이 참인가 — 배지 번호와 쎈 연계번호

**배치 목록·크롭 파일 이름의 번호를 믿지 말 것.** 검출기가 배지를 못 읽은 쪽에서 순번을 매겨 밀리는 구간이 있다(쎈B 공통수학1 에서 실제로 났던 사고: 크롭 66~88 = 실제 배지 69~97).

**id 의 뒷자리는 언제나 쪽 이미지에서 읽은 배지 번호다.** 크롭 파일 이름과 다르면 배지 번호를 쓰고 `review_needed` 에 「번호 불일치: 크롭 \<파일번호\> → 배지 \<실제\>」로 적는다.

**누락 판정은 「쎈 NNNN」 연계번호로 한다.** 이게 가장 확실한 기준이다 — 문항마다 오른쪽 위에 있고 **책 전체에서 1씩 증가**한다(p7 = 0038~0043 · p85 = 0753~0758 · p119 = 1022~ · p141 = 1209~1210). 담당 쪽의 연계번호를 순서대로 적어 보고 **끊긴 자리가 있으면 그 자리에 문항이 있다**는 뜻이니 쪽 이미지에서 찾아 채운다. 앞 배치의 마지막 연계번호와도 이어지는지 본다.

### 문항이 아닌 쪽

**개념 정리 쪽**(각 중단원 첫 쪽 · pdf 6·18·30·44·60·70·88·102·120·130쪽)과 **대단원 표지**(p59 Ⅱ 삼각함수 · p101 Ⅲ 수열), **삽화 쪽**(p58·p87·p100 「나를 바꾸는 힘 · 나바툰」), **부록**(p142~144 상용로그표·삼각함수표)에는 문항이 없다. 검출기가 개념 상자의 「01·1」 번호나 빈칸 번호(❶❷❸)를 문항으로 잡은 것이 섞여 있으면 전사하지 않고 `review_needed` 에 적는다.

문항 쪽 안에도 문항이 아닌 덩어리가 있다: **유형 상자**(「유형 25 원리합계」 + 연한 바탕 해결 전략 — `section` 제목만 쓰고 본문은 전사하지 않는다), 쪽 아래 **「mini 나눔」 명언 상자**(p119 등), 쪽 오른쪽 세로 **단원 탭**. 이것들이 크롭으로 잡혀 있으면 전사하지 않는다.

## items.json 구조

```json
{
  "book": "쎈B 대수", "variant_level": 0,
  "units": [ { "code": "01", "title": "지수", "pages": "7~17", "groups": [
      { "id": "U1-A1", "section": "유형 01 거듭제곱근", "items": ["7-01", "7-02"] },
      { "id": "U1-A2", "section": "유형 02 거듭제곱근의 계산", "passage": "다음 식을 간단히 하시오.", "items": ["8-05"] }
  ] } ],
  "items": { "7-01": { "page": 7, "body": "…", "answer": "", "answer_source": "" } }
}
```

- 그룹 id: `U<단원>-<배치이름><n>` (예 `U1-A1`). 배치 안에서 1부터.
- 그룹 = 「유형 상자 하나」 또는 「공통 지시문 하나」. 유형 상자의 설명 글(연한 바탕 · 「해결 전략」)은 전사하지 않는다 — `section` 제목만 쓴다.
- `section`: 유형 상자의 「유형 01 제목」 그대로(제목에 `;` 가 들어가는 것도 원문대로 — 「유형 20 삼각부등식; 이차식의 꼴」).

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽. 필수. |
| `body` | 발문 LaTeX. 지시문은 넣지 않는다(그룹 `passage`). |
| `figure` | `"tikz:fig-<id>"` 또는 `"crop:fig-<id>.jpg"`. 원문에 그림·표가 있을 때만. |
| `figure_layout` | 생략 = 옆. 넓은 표·그래프는 `"below"`. |
| `choices` | 5지선다(각 `$…$`). `choices_layout` 생략 = 3-2, `"ii"` = 2-2-1, `"v"` = 세로. |
| `subs` | 소문항 `(1)(2)…`. |
| `tag` | 번호 옆 표시가 있을 때만 — 「대표 문제」·「서술형」. |
| `level` | 번호 오른쪽 난이도 동그라미 — `"하"`·`"중"`·`"상"` 중 하나. |
| `ssen_ref` | 오른쪽 위 「쎈 0753」 연계 번호. 있으면 숫자만(`"0753"`). |
| `answer` | **이 배치에서는 빈 문자열**. |
| `answer_source` | **빈 문자열**. |

## 표기 규약 (고2 대수 · 지수·로그 / 삼각함수 / 수열)

- 거듭제곱근·지수: `$\sqrt[3]{8}$`, `$\sqrt[n]{a}$`, `$a^{\frac{1}{2}}$`(지수 안은 `\frac`), `$2^{\sqrt{2}}$`, `$(a^2)^3$`, `$a^{-n}$`. 로그: `$\log_2 8$`, `$\log_a x$`(밑은 아래첨자), 상용로그 `$\log 2$`, `$\log_{\frac{1}{2}} x$`. 상용로그표 값은 원문 그대로(`0.3010`). 「$\log$의 진수」·「밑」·「정수 부분」·「소수 부분」은 한글.
- 지수·로그함수: `$y=2^x$`, `$y=\left(\dfrac{1}{2}\right)^{x}$`, `$y=\log_2 (x-1)+3$`, `$y=a^{bx+c}+r$` 꼴. 점근선·평행이동·대칭이동·최댓값·최솟값은 한글. 방정식·부등식 `$2^{x+1}=8$`, `$\log_2 x<3$`. 「$x$축」 `$x$축`.
- 삼각함수: `$\sin\theta$`, `$\cos\dfrac{\pi}{3}$`, `$\tan(-\theta)$`, `$\sin^2\theta$`, 호도법 `$\dfrac{\pi}{6}$`, 각 `$\theta$`, 「$60^\circ$」 `$60^\circ$`, 「제2사분면」·「동경」·「주기」는 한글. 부채꼴 호의 길이 `$l=r\theta$`, 넓이 `$S=\dfrac{1}{2}r^2\theta$`. 사인법칙·코사인법칙은 원문 그대로(`$\dfrac{a}{\sin A}=2R$` · `$a^2=b^2+c^2-2bc\cos A$`) — 삼각형 변은 `$a$`, 각은 `$A$`. 삼각형·사각형 이름은 `삼각형~$\pt{ABC}$`·`$\angle\pt{A}$`·`$\seg{AB}$`.
- 수열: `$a_n$`, `$\{a_n\}$`, `$a_{n+1}=a_n+3$`, `$S_n$`, 합 `$\displaystyle\sum_{k=1}^{n} a_k$`(`\displaystyle` 를 붙여 본문에서도 위아래 첨자), 첫째항·공차·공비·등차중항·일반항·계차수열은 한글. 수학적 귀납법의 「$n=k$일 때 …」 는 한글 그대로, 증명 빈칸 ㈎㈏㈐ 는 원문 기호 그대로 두고 네모 빈칸은 `\blank`.
- 분수 `\dfrac`, 좌표 쉼표 뒤 `\,`, 단위 `$8\,\mathrm{cm}$`. 「(단, …)」 → `\cond{…}`. 명사 + 기호는 `점~$\pt{P}$`. 본문 수식은 `$…$` 만(`$$`·`\[` 금지). 줄바꿈은 손으로 넣지 않는다. 원문의 별도 줄 식은 `\par\smallskip\centerline{$…$}\par\smallskip\noindent`.
- 보기 「ㄱ, ㄴ, ㄷ」 상자는 body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건 상자·계산 과정 상자는 `\exprbox{…}`. 범위 물결은 `$\sim$`.
- **원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다.** 크롭에 워터마크가 겹쳐 있어도 원문 글자만 전사한다.

## 그림

- 좌표평면·수직선·단위원·삼각형·그래프는 TikZ 로 다시 그린다(`figures/fig-<id>.tex`). 정점 2.2pt · 축 0.7pt · 곡선 0.5~0.6pt, 라벨은 원문 것만, **답이 그림에서 읽히지 않게**. 첫 줄 주석에 「\<id\>(쪽) — 무엇 · 다시 그린 까닭」.
- 실생활 삽화·사진은 크롭: `node scripts/latex-bank/crop-figure.mjs --pdf "C:/Users/PC/Desktop/교재 라텍스 조판/쎈B 대수.pdf" --page <쪽> --item <manifest bbox_normalized> --rel <문항 안 비율> --out latex-bank/ssenb-alg/figures/fig-<id>.jpg`.
- 원문에 없는 그림은 넣지 않는다.

## 확정 절차

1. 쪽 이미지(`qa/pNNN.jpg`)로 구역·유형 제목·태그·난이도를 파악해 그룹을 만든다.
2. 문항 크롭을 하나씩 읽어 `body`/`choices`/`subs` 를 전사한다. 배지 번호가 id 의 뒷자리.
3. **연계번호(쎈 NNNN)가 끊긴 자리와 아래 「크롭 없는 번호」 중 담당 쪽에 있는 것을 쪽 이미지에서 찾아 채운다.**
4. `node scripts/latex-bank/check-batch.mjs <out.json> --bank latex-bank/ssenb-alg` 로 컴파일 확인.
5. 확실치 않은 것은 `review_needed` 에 적는다. 답은 이 단계에서 채우지 않는다.
