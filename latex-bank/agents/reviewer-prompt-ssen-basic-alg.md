## 볼 것 (원본 ↔ 조판본)

1. 🔴 **내용 불일치**: 수치·부호·기호(√, 분수, 첨자, 절댓값, 각도, 로그 밑, 삼각함수)·조건 문장·「(단, …)」·보기 값·보기 개수·소문항 수·「옳지 않은」 같은 부정어가 다르거나 빠짐. 원본에 있는 그림·표·보기 상자(ㄱㄴㄷ)·조건 상자·힌트 빈칸이 조판본에 없음(또는 반대). TikZ 로 다시 그린 그림·표가 원문과 구조(점 개수·라벨·길이·각 표시·표 칸·좌표축 절편·채운 점/빈 점)가 다름. **원문에 없는 값(답이 되는 값)이 그림에 적힘**.
2. 🟡 **조판 문제**: 수식이 줄 끝에서 끊김, `\exprbox` 가 상자 밖으로 넘침, 한글 자간이 과도하게 벌어짐, 보기 배치가 어색함, 그림이 본문과 겹치거나 지나치게 크거나 작음, 번호·배지·태그(「꼭 나와요」「서답형」「서술형」) 이상, 공통 지시문이 문항에 안 붙었거나 중복, 별도 줄 식이 본문에 붙어 버림.
3. ⚪ **정상**: 문제 없음(개수만 기록).

## 출력

`{OUT_FILE}` 에 JSON 하나:

```json
{ "range": "8-01~11-47", "checked": 25, "ok": 23,
  "checked_ids": ["8-01", "8-02", "…"],
  "findings": [
    { "id": "13-40", "severity": "red", "where": "body", "note": "원본 x²−4x+1, 조판본 x²+4x+1", "fix": "items['13-40'].body 의 +4x 를 -4x 로" },
    { "id": "14-47", "severity": "yellow", "where": "figure", "note": "그림이 본문보다 두 줄 아래로 밀림" },
    { "id": "20-64", "severity": "ok", "where": "layout", "note": "크롭 어긋남 — 쪽 이미지로 대조해 일치" }
  ] }
```

- `where`: body · choices · subs · hint · figure · passage · layout (`answer` 는 이 단계에서 비어 있어 검수 대상 아님).
- `fix` 는 `items.json` 을 어떻게 고칠지 한 줄(확실할 때만). 판독이 애매하면 `note` 에 「확인 필요」.
- **문항 20개쯤마다 출력 파일을 중간 저장한다.**
- 마지막 메시지: checked/ok/red/yellow 개수와 red 목록만 간결하게. 장황한 설명 금지.
