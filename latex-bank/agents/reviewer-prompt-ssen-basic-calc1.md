## 맥락

학원 내부 오답지·시험지용으로 스캔 교재 문항을 LaTeX 로 다시 조판했다(`latex-bank/ssen-basic-calc1/items.json` · 규약 `latex-bank/ssen-basic-calc1/전사-가이드.md`). **문항 id 는 `인쇄쪽-번호`**(예 `116-07`)이고 번호는 **구역마다 01 부터 다시 시작하는 두 자리 배지**다. 1,061문항 · 9단원.

문항마다 `latex-bank/ssen-basic-calc1/review/<id>.png` 에 **왼쪽 = 원본 스캔 크롭, 오른쪽 = 조판본**이 나란히 있다. 조판본이 원문과 내용이 같은지 확인하는 것이 과제다. **수학적 풀이는 하지 않는다**(답은 이 단계에서 비어 있고 조판본에 안 나온다).

### 이 책에는 연계번호가 없다

쎈B 계열의 「쎈 NNNN」 같은 책 전체 통번호가 **없다.** 그래서 누락·어긋남 판정은 **쪽 이미지의 배지 번호**로만 한다. 구역(개념 / 자신감 UP! 기본&핵심 유형 / 학교 시험 기출로 실전 감각 UP!)이 바뀌면 배지가 01 로 되돌아가는 것이 정상이다.

### 쪽 이미지 번호는 인쇄 쪽과 같다

이 책은 `pdf 쪽 = 인쇄 쪽` 이다(같은 계열이라도 확통은 5 차이가 난다 — 헷갈리지 말 것). id 목록 두 번째 칸이 그 쪽 이미지 경로이고, `crop-page.mjs` 에도 같은 번호를 넘긴다.

### 원본 크롭을 믿을 수 없는 경우 (이 계열에서 잦다)

1. **크롭이 없는 문항** — 2단 배치 쪽에서 검출기가 오른쪽 컬럼 배지를 통째로 놓친 자리가 많다. 전사 에이전트가 쪽 렌더로 넣었으므로 review 그림에 원본이 비어 있거나 다른 문항이 들어 있다.
2. **크롭 번호가 실제 배지와 어긋난 구간** — 유형 라벨 상자(「유형 042」 같은 상자)를 문항으로 세어 그 뒤가 한 칸씩 밀리는 일이 흔하다.
3. 크롭이 위·아래로 잘려 첫 줄이 안 보이거나 이웃 문항이 섞여 있을 수 있다.

**위 셋 중 하나라도 의심되면 반드시 쪽 이미지 `output/problem-bank/ssen-basic-calc1/qa/pNNN.jpg` 를 Read 로 열어 그 쪽에서 해당 배지 번호 문항을 찾아 대조한다.** **크롭이 비어 있다는 이유로 문항을 건너뛰지 않는다.** 쪽 이미지가 흐려 안 읽히면 원본 PDF 에서 다시 크게 잘라 본다:

```bash
# pt 상자(x0 y0 x1 y1 · 쪽 전지 기준 533.9pt 폭)를 크게 잘라 PNG 로. 마지막 인자는 확대율.
node latex-bank/tools/crop-page.mjs ssen-basic-calc1 <쪽> <x0> <y0> <x1> <y1> <out.png> 4
```

두 컬럼 판이라 왼쪽 컬럼 전체는 `20 <y0> 280 <y1>`, 오른쪽 컬럼은 `285 <y0> 530 <y1>` 쯤이다. 출력 PNG 는 `latex-bank/ssen-basic-calc1/검수/2026-09-28/tmp/<이 배치 이름>/` 아래에 만든다(예 `tmp/07/`). **여러 배치가 동시에 돈다 — 자기 배치 폴더 말고는 어떤 폴더도 지우지 않는다.**

**「원본과 조판본이 다른 문항이다」는 것 자체가 red 지적이 아니다.** 쪽 이미지에서 배지 번호로 확인해 조판본 내용이 그 번호 문항과 같으면 정상이고, `note` 에 「크롭 어긋남 — 쪽 이미지로 대조해 일치」라고만 적는다. 조판본이 **엉뚱한 번호의 문항**을 담고 있으면 red 다.

## 이 책에서 특히 조심할 것

미적분이라서 다음이 자주 나오고, 하나만 어긋나도 답이 달라진다.

- **극한 표기**: $\lim_{x \to a}$ 의 $a$ 와 방향($a+$ · $a-$ · $\infty$ · $-\infty$), $\displaystyle$ 여부.
- **도함수 표기**: $f'(x)$ · $f''(x)$ · $\dfrac{dy}{dx}$ 의 프라임 개수.
- **정적분의 위끝·아래끝**: $\int_{a}^{b}$ 의 두 값이 바뀌지 않았는지, 적분변수 $dx$ · $dt$.
- **증감표**: 행·열 수, $+$ $-$ $0$ 부호, 극대·극소 표시, 화살표(↗ ↘) 방향.
- **그래프**: 접선·점근선·극값 위치, 채운 점/빈 점, **원문에 없는 값(답이 되는 좌표나 넓이)이 그림에 적혔는지**.
- **조건 문장**: 「미분가능」·「연속」·「모든 실수」·「구간」의 열림/닫힘.
- **부정어**: 「옳지 않은」·「아닌 것」.

## 볼 것 (원본 ↔ 조판본)

1. 🔴 **내용 불일치**: 수치·부호·기호(√, 분수, 첨자, 절댓값, 극한, 적분, 시그마)·조건 문장·「(단, …)」·보기 값·보기 개수·소문항 수·부정어가 다르거나 빠짐. 원본에 있는 그림·표·증감표·보기 상자(ㄱㄴㄷ)·조건 상자·힌트 빈칸이 조판본에 없음(또는 반대). TikZ 로 다시 그린 그림·표가 원문과 구조(점 개수·라벨·칸·좌표축 절편·채운 점/빈 점)가 다름. **원문에 없는 값(답이 되는 값)이 그림이나 표에 적힘**.
2. 🟡 **조판 문제**: 수식이 줄 끝에서 끊김, `\exprbox` 가 상자 밖으로 넘침, 한글 자간이 과도하게 벌어짐, 보기 배치가 어색함, 그림·표가 본문과 겹치거나 지나치게 크거나 작음, 번호·배지·태그(「꼭 나와요」「서답형」「서술형」) 이상, 공통 지시문이 문항에 안 붙었거나 중복, 별도 줄 식이 본문에 붙어 버림.
3. ⚪ **정상**: 문제 없음(개수만 기록).

## 출력

`{OUT_FILE}` 에 JSON 하나:

```json
{ "range": "8-01~11-47", "checked": 25, "ok": 23,
  "checked_ids": ["8-01", "8-02", "…"],
  "findings": [
    { "id": "13-40", "severity": "red", "where": "body", "note": "원본 적분 위끝 3, 조판본 2", "fix": "items['13-40'].body 의 \\int_0^2 를 \\int_0^3 으로" },
    { "id": "14-47", "severity": "yellow", "where": "figure", "note": "증감표가 본문보다 두 줄 아래로 밀림" },
    { "id": "20-64", "severity": "ok", "where": "layout", "note": "크롭 어긋남 — 쪽 이미지로 대조해 일치" }
  ] }
```

- `where`: body · choices · subs · hint · figure · passage · layout (`answer` 는 이 단계에서 비어 있어 검수 대상 아님).
- `fix` 는 `items.json` 을 어떻게 고칠지 한 줄(확실할 때만). 판독이 애매하면 `note` 에 「확인 필요」.
- **문항 20개쯤마다 출력 파일을 중간 저장한다.**
- 마지막 메시지: checked/ok/red/yellow 개수와 red 목록만 간결하게. 장황한 설명 금지.
