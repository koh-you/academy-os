## 2. ingest 명령과 옵션 근거

```
node scripts/problem-bank/ingest-scan-badges.mjs \
  --pdf "C:/Users/PC/Downloads/1063741566-22개정-SSEN-B-미적분1-본책.pdf" \
  --out output/problem-bank/ssenb-calc1 \
  --title "쎈B 미적분1" --folder "미적분1" --grade 고2 --subject 수학 \
  --badge3 --no-green-type --badge-x-tol 16 --max-badge 120 \
  --page-offset -6 --pages 12-133 \
  --units "01 함수의 극한,02 함수의 연속,03 미분계수와 도함수,04 도함수의 활용 (1),05 도함수의 활용 (2),06 도함수의 활용 (3),07 부정적분,08 정적분,09 정적분의 활용" \
  --unit-pages "12-23,24-35,36-49,50-63,64-79,80-95,96-105,106-121,122-133"
```

PDF 는 저장소 안으로 복사하지 않는다. 쪽 크기 824.28×588pt · `Page rot 270` 이라 `pdftoppm`·`pdfjs` 는 세로로 올바르게 렌더한다.

### `--page-offset -6` (필수)

**인쇄 쪽 = pdf 쪽 − 6.** 새 쇄 스캔은 본책 앞에 번호 없는 6쪽(표지·SSI·판권·추천·차례)이 붙어 있다. 실측: pdf 12=인쇄 6 · pdf 64=인쇄 58 · pdf 83=인쇄 77 · pdf 95=인쇄 89 · pdf 120=인쇄 114 · pdf 133=인쇄 127. 차례는 **pdf 10쪽**(인쇄 4쪽)이다.

### `--pages 12-133`

pdf 12(인쇄 6 · 01 개념정리)부터 pdf 133(인쇄 127 · 09 마지막 문항 쪽)까지. pdf 11(인쇄 5 · Ⅰ 대단원 표지)과 pdf 134(인쇄 128 · MEMO)·pdf 135~140(뒤표지류)은 넣지 않는다.

### `--badge3` (필수)

이 책의 배지는 두 자리까지만 가지만(최대 88), `--badge3` 는 **자릿수 대신 왼쪽 「유형」 꼬리표 상자로 유형 라벨을 가르는 모드**다. 이 책의 유형 라벨은 「유형 13」처럼 **두 자리**라 기본 모드(「세 자리 = 유형 라벨」)로는 유형 라벨과 문항 배지를 구분하지 못한다.

### `--no-green-type` (필수)

Ⅱ 다항함수의 미분법(03~06)은 초록 색조다. 기본 규칙 「평균 밝기 140 이상 초록 글자 = 유형 라벨」에 **문항 배지가 통째로 걸린다.** 실측(pdf 76~79 · 인쇄 70~73):

| | 검출 |
|---|---|
| `--badge3` 만 | **2개**(p76 0 · p77 1 · p78 1 · p79 0) |
| `--badge3 --no-green-type` | **18개**(p76 5 · p77 5 · p78 4 · p79 4) |

파랑 단원(09 · pdf 131~133)에서는 켠 것과 끈 것의 결과가 **15개로 완전히 같았다.** 쎈B 공통수학2 에서 확인한 것과 같은 성질이다.

### `--badge-x-tol 16` (이 책 때문에 추가한 옵션)

새 쇄 스캔은 평판이 아니라 **책을 펼쳐 찍은 판**이라 쪽 안에서 종이가 휜다. 한 컬럼 안에서 **위쪽 배지와 아래쪽 배지의 x 가 10pt 넘게 벌어지고**, 한 번의 회전 보정(`estimateSkewDegrees` 는 ±1.5°가 상한)으로는 펴지지 않는다. 기본값 8pt 창으로는 **컬럼 맨 위 배지가 창 밖으로 밀려 통째로 빠진다.**

실측(인쇄 15쪽 · 실제 6문항 50·51·52·53·54·55): 기본 8 → 52·55 **2개만**. 디버그 좌표는 `50@x=50`·`52@x=39`(같은 컬럼), `53@x=314`·`55@x=303`.

| `--badge-x-tol` | 인쇄 7~17쪽 검출 | 비고 |
|---|---|---|
| 8(기본) | 51 | 컬럼 첫 배지가 빠짐(p15 2개, p16 4개) |
| 14 | 53 | p15 4개로 회복, p12 의 34 는 여전히 빠짐 |
| **16** | **54** | p12 34 까지 회복, 오검출 없음 |
| 18 | 56 | p14 에 본문 숫자 「11」·「13」을 배지로 주움(오검출) |

### `--max-badge 120` (이 책 때문에 추가한 옵션)

`ingest-scan-badges.mjs` 는 **읽은 번호가 60을 넘으면 OCR 오독으로 보고 순번으로 덮어썼다**(베이직쎈처럼 쪽마다 번호가 다시 시작하는 판 기준). 이 책은 중단원마다 번호가 이어져 **88까지** 가므로 기본값이면 61번부터 전부 어긋난다.

실측(인쇄 17쪽): 기본값이면 `62, 63⚠(64), 64⚠(65), 65⚠(66), 66⚠(67)` 로 덮어써진다. `--max-badge 120` 이면 `62, 64, 65, 66, 67` + 「63 자리에 구멍」으로 **읽은 값 그대로** 남는다(63 은 검출되지 않은 대표 문제다). 옛 쇄 가이드가 「`number_corrected(N)` 의 N 이 거의 언제나 맞다」고 적어 둔 것이 바로 이 덮어쓰기였다.

두 옵션 모두 **기본값이 종전 동작과 같아** 다른 책의 ingest 결과는 바뀌지 않는다.

### 왜 대표 문제가 빠지나 — 새 쇄의 서식이 바뀌었다

| | 옛 쇄 | 새 쇄 |

| 유형 라벨 | 「유형 13」 두 자리 | 같음 · **색 알약 안 흰 글자** → 못 읽는다 |

## 무엇이 참인가 — 배지 번호와 쎈 통번호

**배치 목록·크롭 파일 이름의 번호를 맹신하지 않는다.** `review_note` 가 비어 있는 문항은 OCR 이 읽은 배지 그대로지만, OCR 오독도 섞여 있다(예: 인쇄 8쪽에서 배지 10 을 `29` 로 읽었다 — `number_gap(expected 10)` 로 표시됨).

**id 의 뒷자리는 언제나 쪽 이미지에서 읽은 배지 번호다.** 크롭 파일 이름과 다르면 배지 번호를 쓰고 `review_needed` 에 「번호 불일치: 크롭 <파일번호> → 배지 <실제>」로 적는다.

**누락 판정은 「쎈 NNNN」 통번호로 한다.** 이게 가장 확실한 기준이다 — 문항마다 오른쪽 위에 있고 **한 중단원 안에서는 정확히 1씩 증가한다.** 단원이 바뀌면 건너뛰므로 **단원을 넘어서는 연속성은 보지 않는다.** 통번호는 **문항 크롭 안에 그대로 들어 있다**(예 `items/pbk_b778934920-7-02.jpg` 오른쪽 위 「쎈 0045」). manifest 에는 통번호 필드가 없으니 전사할 때 크롭에서 읽어 `ssen_ref` 에 적는다.

담당 쪽의 통번호를 순서대로 적어 보고 **끊긴 자리가 있으면 그 자리에 문항이 있다**는 뜻이니 쪽 이미지에서 찾아 채운다. 배지 번호 − 1 = 통번호 − (그 단원 첫 통번호) 가 항상 성립한다.

### `number_gap(expected N)` 는 「여기서 번호가 건너뛰었다」는 뜻이다

거의 전부 **대표 문제가 빠진 자리**다. `review_note` 에 `number_gap(expected N)` 가 있으면 **N 번 문항이 그 바로 위에 있는데 크롭이 없다**는 뜻이니 쪽 이미지에서 전사해 채운다. 채워 넣은 문항은 `review_needed` 에 「크롭 없음 — 쪽 이미지에서 전사」라고 적는다.

### 유형 상자 제목은 쪽 이미지에서 읽는다

이 책의 유형 라벨은 **색 알약 안 흰 글자**(「유형 13 미정계수의 결정 (2)」)라 OCR 에 전혀 잡히지 않는다 — `type_label` 은 **전부 비어 있다.** 그래서 유형 상자 바로 앞 문항의 크롭이 **다음 유형 상자와 대표 문제까지 물고 내려올 수 있다.** 그룹(`section`)은 반드시 쪽 이미지에서 읽고, 크롭 아래쪽에 유형 상자·다음 문항이 섞여 들어와 있으면 그 부분은 전사하지 않는다.

## 입력

- 문항 크롭 `output/problem-bank/ssenb-calc1/items/pbk_b778934920-<쪽>-<번호>.jpg` (220 dpi).
- 쪽 전체 `output/problem-bank/ssenb-calc1/qa/pNNN.jpg` — 파일 이름의 NNN 은 **pdf 쪽**이다(인쇄 쪽 = NNN − 6). 구역·유형 제목·태그·난이도·쎈 통번호는 **여기서** 읽는다. 문항 크롭만 보고 판단하지 않는다.
- 답·해설은 이 배치에 없다. `answer` 는 **빈 문자열**로 두고 `answer_source: ""` 로 남긴다 — 답지(`C:/Users/PC/Desktop/교재 라텍스 조판/쎈B고등미적분1_정답.pdf`)는 전사 뒤 별도 ingest 로 붙인다.

## items.json 구조

```json
{
  "book": "쎈B 미적분1", "variant_level": 0,
  "units": [ { "code": "01", "title": "함수의 극한", "pages": "7~17", "groups": [
      { "id": "U1-A1", "section": "유형 01 함수의 극한값의 존재", "items": ["7-01", "7-02"] },
      { "id": "U1-A2", "section": "유형 02 함수의 극한값 구하기", "items": ["8-06"] }
  ] } ],
  "items": { "7-01": { "page": 7, "body": "…", "answer": "", "answer_source": "" } }
}
```

- 그룹 id: `U<단원>-<배치이름><n>` (예 `U1-A1`). 배치 안에서 1부터.
- 그룹 = 「유형 상자 하나」 또는 「공통 지시문 하나」. 유형 상자의 설명 글(연한 바탕)은 전사하지 않는다 — `section` 제목만 쓴다.
- `section`: 유형 상자의 「유형 01 제목」 그대로. 제목이 두 줄이면 원문의 `;` 까지 한 줄로 잇는다(예 「유형 16 정적분으로 정의된 함수의 극한; $\lim\limits_{x\to a}\frac{1}{x-a}\int_a^x f(t)dt$ 꼴」).

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽. 필수. |
| `body` | 발문 LaTeX. 지시문은 넣지 않는다(그룹 `passage`). |
| `figure` | `"tikz:fig-<id>"` 또는 `"crop:fig-<id>.jpg"`. 원문에 그림·표가 있을 때만. |
| `figure_layout` | 생략 = 옆. 넓은 표·그래프는 `"below"`. |
| `choices` | 5지선다(각 `$…$`). `choices_layout` 생략 = 3-2, `"ii"` = 2-2-1, `"v"` = 세로. |
| `subs` | 소문항 `(1)(2)…`. |
| `tag` | 번호 옆 표시가 있을 때만 — 「대표 문제」「서술형」「집중공략」. |
| `level` | 번호 오른쪽 난이도 동그라미(하·중·상)가 있으면 원문 그대로. |
| `ssen_ref` | 오른쪽 위 「쎈 0532」 통번호. 있으면 숫자만(`"0532"`). |
| `answer` | **이 배치에서는 빈 문자열**. |
| `answer_source` | **빈 문자열**. |

## 표기 규약 (고2 미적분1 · 함수의 극한과 연속 · 다항함수의 미분법 · 다항함수의 적분법)

- 극한: `$\displaystyle\lim_{x\to 2} f(x)$`(`\displaystyle` 붙여 아래첨자가 아래에), `$x\to 0+$`, `$x\to 2-$`, `$x\to\infty$`, `$x\to-\infty$`. 「$f(x)$가 $x=1$에서 연속」은 한글. 좌극한·우극한·불연속·수렴·발산은 한글. 부정형은 `$\dfrac{0}{0}$ 꼴`·`$\dfrac{\infty}{\infty}$ 꼴`·`$\infty-\infty$ 꼴`·`$\infty\times 0$ 꼴`처럼 「꼴」을 붙인다.
- 연속·정리: 사잇값 정리·최대·최소 정리·평균값 정리·롤의 정리는 한글. 구간은 `$[-2,\,3]$`·`$(a,\,b)$`, 「닫힌구간 $[0,\,2]$」처럼 한글 + 기호.
- 미분: `$f'(x)$`, `$f'(a)$`, `$f''(x)$`, `$y'$`, `$\dfrac{dy}{dx}$`, `$\dfrac{d}{dx}f(x)$`. 미분계수·도함수·접선의 기울기·미분가능·증분은 한글. 평균변화율은 `$\dfrac{\Delta y}{\Delta x}$`. 증가·감소·극대·극소·극값·변곡은 한글, 「$f'(x)=0$」 그대로. 속도 `$v(t)$`·가속도 `$a(t)$`, 변화율 `$\dfrac{dV}{dt}$`.
- 적분: `$\displaystyle\int f(x)\,dx$`, `$\displaystyle\int_{0}^{1} x^2\,dx$`(`\,dx`), `$\displaystyle\int_{a}^{b} f(x)\,dx=\Big[F(x)\Big]_{a}^{b}$`, 적분상수 `$C$`. 부정적분·정적분·넓이·부피는 한글. 합 `$\displaystyle\sum_{k=1}^{n}$`.
- 함수·그래프: `$f(x)=x^3-3x^2+2$`, `$y=f(x)$의 그래프`, 「$x$축」 `$x$축`, 「$y$좌표」 `$y$좌표`. 절댓값 `$|x|$`, 가우스 `$[x]$`, 합성함수 `$(f\circ g)(x)$`, 근호 `$\sqrt{3x}$`. 그래프·좌표평면은 그림.
- 도형·단위: `$\seg{AB}$`, `$\angle\pt{B}=45^\circ$`, `삼각형~$\pt{ABC}$`, `$8\,\mathrm{cm}$`, `$20\,\mathrm{km/h}$`, `$\mathrm{cm}^3/\mathrm{s}$`. 「점~$\pt{P}$」처럼 명사 + 기호는 `~`. 원점은 `$\pt{O}$`.
- 분수 `\dfrac`, 좌표 쉼표 뒤 `\,`(`$(2,\,1)$`). 「(단, …)」 → `\cond{…}`. 본문 수식은 `$…$` 만(`$$`·`\[` 금지). 줄바꿈은 손으로 넣지 않는다. 원문의 별도 줄 식은 `\par\smallskip\centerline{$…$}\par\smallskip\noindent`.
- 보기 「ㄱ, ㄴ, ㄷ」 상자는 body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건 ㈎㈏ 상자는 `\exprbox{…}`. 범위 물결은 `$\sim$`.
- **원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다.** 크롭에 워터마크가 겹쳐 있어도 원문 글자만 전사한다.
