# 베이직쎈 확률과 통계 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-26. 베이직쎈 공통수학1·2 가이드(`latex-bank/ssen-basic-cm1/전사-가이드.md`, `latex-bank/ssen-basic-cm2/전사-가이드.md`)에서 굳어진 규약을 그대로 쓰고, 표기 규약만 확률과 통계용(`latex-bank/rpm-prob/전사-가이드.md`)으로 바꾼다. 원천은 `items.json` 하나이며 `items/*.tex` 는 `build.mjs` 가 만든다.

**이 책은 스캔 PDF다**(글자 레이어 없음 — `getTextContent()` 가 빈 문자열). 힌트 줄이 없으므로 모든 글자는 크롭·쪽 이미지를 직접 읽어 전사한다.

## 입력 (읽을 것)

- 문항 크롭: `output/problem-bank/ssen-basic-prob/items/pbk_516d30655f-<인쇄쪽>-<번호>.jpg` (220 dpi). 번호 배지가 크롭 안에 보인다.
- 공통 지시문 크롭: `items/pbk_516d30655f-p<인쇄쪽>-passage-<n>.jpg` (말풍선 아이콘 줄).
- 쪽 전체: `output/problem-bank/ssen-basic-prob/qa/pNNN.jpg` — **NNN 은 pdf 쪽**(인쇄 쪽 = NNN + 5). 구역 제목·공통 지시문·유형 라벨·태그·개념 번호는 여기서 읽는다.
- 답·해설은 이 배치에 없다. `answer` 는 **빈 문자열**, `answer_source` 도 **빈 문자열**로 둔다 — 답지는 전사 뒤 별도 ingest 로 붙인다.
- 배치 목록의 ⚠(flagged)는 크롭 경계가 불확실한 문항이다 — 쪽 이미지에서 원문을 확인한다.

### 무엇이 참인가 — 배지 번호

**배치 목록·크롭 파일 이름의 번호를 믿지 말 것.** 검출기가 배지를 못 읽은 자리에서 순번이 밀릴 수 있다.

**id 의 뒷자리는 언제나 쪽 이미지에서 읽은 배지 번호다.** 크롭 파일 이름과 다르면 배지 번호를 쓰고 `review_needed` 에 「번호 불일치: 크롭 X → 배지 Y」로 적는다.

**누락 판정은 배지 번호의 연속성으로 한다.** 이 책에는 책 전체 통번호가 없으므로, 한 구역(개념 블록 하나 · 유형 블록 하나 · 실전 감각 UP 하나) 안에서 01,02,03… 이 끊기면 그 자리에 문항이 있다는 뜻이다. 쪽 이미지에서 찾아 채우고 `review_needed` 에 「크롭 없음 — 쪽 이미지에서 전사」로 적는다.

### 크롭이 자주 빠지는 자리 (이 책에서 확인)

- **한 줄에 문항 둘이 나란히 놓인 개념 쪽**(「05 ₆Π₂   06 ₄Π₄」처럼 기호 계산만 있는 짧은 문항). 검출기는 컬럼 왼쪽 여백의 배지만 잡으므로 **오른쪽 문항(06·08 …)이 통째로 빠진다.** 인쇄 8쪽에서 06·08 이 빠진 것을 확인했다. 개념 쪽 번호가 한 칸씩 건너뛰면 이 경우를 먼저 의심한다.
- 검은 상자 안 흰 숫자·연한 색 배지는 OCR 이 못 읽어 크롭이 없을 수 있다. 정상이며 쪽 이미지로 채운다.
- 대단원 표지·개념정리 블록을 문항으로 잡은 오검출이 섞일 수 있다. 전사하지 않고 `review_needed` 에 적는다.

## items.json 구조 (여러 단원)

```json
{
  "book": "베이직쎈 확률과 통계",
  "source_package": "output/problem-bank/ssen-basic-prob",
  "variant_level": 0,
  "units": [
    { "code": "01", "title": "여러 가지 순열", "pages": "8~19", "groups": [
      { "id": "U1-PA1", "section": "개념 01 중복순열", "passage": "다음을 기호를 사용하여 $_n\\Pi_r$ 꼴로 나타내시오.", "items": ["8-01", "8-02"] },
      { "id": "U1-TA1", "section": "유형 001 중복순열의 수의 계산", "items": ["10-01", "10-02"] },
      { "id": "U1-RA1", "section": "실전 감각 UP", "items": ["18-01"] }
    ] }
  ],
  "items": { "8-01": { "page": 8, "body": "…", "answer": "", "answer_source": "" } }
}
```

- 그룹 id: `U<단원>-P<배치이름><n>`(개념 쪽 · 지시문 하나 = 그룹 하나 · 지시문 없는 개념 쪽 문항은 passage 없이 그룹) · `U<단원>-T<배치이름><n>`(유형 · 라벨 하나 = 그룹 하나) · `U<단원>-R<배치이름>1`(실전 감각 UP). 배치 이름을 꼭 넣어 병합 때 겹치지 않게 한다.
- `section` 은 구역 제목 그대로: 「개념 NN 제목」(아래 부록의 개념 목록) · 「유형 NNN 제목」 · 「실전 감각 UP」.
- 유형 상자 안의 연한 바탕 설명 글·도식은 전사하지 않는다 — `section` 제목만 쓴다.
- 그룹 순서·문항 순서는 책 순서(쪽 → 왼쪽 컬럼 → 오른쪽 컬럼).
- 그룹에 공통 그림이 있으면 `figure` 를 그룹에 둔다.

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽. 필수(출처 배지가 「베이직쎈 확률과 통계 9쪽 13번」으로 찍힌다). |
| `body` | 발문 LaTeX(필수). 지시문은 body 에 넣지 않는다(그룹 `passage`). |
| `choices` | 5지선다 보기 5개(각각 `$…$`). `choices_layout`: 생략 = 3-2, `"ii"` = 2-2-1(분수처럼 키 큰 보기), `"v"` = 세로(긴 식). |
| `subs` | 소문항 `(1)(2)…` 본문 배열. |
| `hint` | 개념 쪽 「◎」 풀이 힌트(빈칸형). 줄바꿈은 `\\\\`, 빈칸은 `\blank`(넓은 빈칸 `\blank[2.4em]`). |
| `tag` | 「꼭 나와요」·「서답형」·「서술형」(배지 옆·위 표시가 있을 때만). 여러 개면 「꼭 나와요 · 서술형」. |
| `figure` | `"tikz:fig-<id>"`(figures/fig-&lt;id&gt;.tex) 또는 `"crop:fig-<id>.jpg"`. 원문에 그림·표가 있을 때만. |
| `figure_layout` | 생략 = 옆. 넓은 표·그래프는 `"below"`. |
| `answer` | **이 단계에서는 빈 문자열.** |
| `answer_source` | **빈 문자열.** |

## 표기 규약 (확률과 통계 · 경우의 수·확률·통계)

- 순열·조합: `${}_n\mathrm{P}_r$`, `${}_5\mathrm{C}_2$`, 중복순열 `${}_n\Pi_r$`, 중복조합 `${}_n\mathrm{H}_r$`, 팩토리얼 `$n!$`. 원순열·같은 것이 있는 순열·최단 거리는 한글 그대로. 같은 것이 있는 순열의 수 `$\dfrac{n!}{p!\,q!\,r!}$`.
- 이항정리: `$(a+b)^n$`, 일반항 `${}_n\mathrm{C}_r a^{n-r}b^r$`, 이항계수 `${}_n\mathrm{C}_r$`, 파스칼의 삼각형은 표(`tabular`) 또는 TikZ.
- 확률: `$\mathrm{P}(A)$`, `$\mathrm{P}(A\cap B)$`, `$\mathrm{P}(A\cup B)$`, 조건부확률 `$\mathrm{P}(B\mid A)$`, 여사건 `$A^{\mathrm{c}}$` → `\comp{A}`, 표본공간 `$S$`, 공사건 `$\varnothing$`. 독립·종속·배반·시행·근원사건은 한글 그대로. 독립시행의 확률 `${}_n\mathrm{C}_r p^r (1-p)^{n-r}$`.
- 확률분포: 확률변수 `$X$`, `$\mathrm{P}(X=x)$`, `$\mathrm{E}(X)$`, `$\mathrm{V}(X)$`, `$\sigma(X)$`, `$\mathrm{E}(aX+b)$`, 이항분포 `$\mathrm{B}(n,\,p)$`, 정규분포 `$\mathrm{N}(m,\,\sigma^2)$`, 표준정규분포 `$\mathrm{N}(0,\,1)$`, 표준화 `$Z=\dfrac{X-m}{\sigma}$`, 확률밀도함수·확률질량함수는 한글.
- 통계적 추정: 표본평균 `$\overline{X}$`(실현값 `$\overline{x}$`), 모평균 `$m$`, 모표준편차 `$\sigma$`, 표본의 크기 `$n$`, 표본비율 `$\hat{p}$`, 모비율 `$p$`, 신뢰구간 `$\overline{x}-1.96\dfrac{\sigma}{\sqrt{n}}\le m\le\overline{x}+1.96\dfrac{\sigma}{\sqrt{n}}$`, 「신뢰도 $95\,\%$」.
- **확률분포표·표준정규분포표**는 본문 안 표다. 좁은 표(`z` / `P(0\le Z\le z)` 두 열, 확률분포표 `X` / `P(X=x)` 두 줄)는 **`tabular` 로 다시 적는다**(크롭하지 않는다). 원문 배치대로 확률분포표는 본문 아래(`figure_layout: "below"` 가 필요하면), 표준정규분포표는 오른쪽.
- 단위·기호: `$25\,\%$`, `$8\,\mathrm{cm}$`, `$250\,\mathrm{mL}$`, `$990\,\mathrm{g}$`. 점·선분은 `$\pt{A}$`·`$\seg{AB}$`, 「점 P」는 `점~$\pt{P}$`(`~` = 안 끊는 공백).
- 분수 `\dfrac`(선택지·답·힌트 모두), 좌표·나열 쉼표 뒤 `\,`(`(3,\,-1)`, `$\mathrm{B}(n,\,p)$`). 「(단, …)」 → `\cond{…}`.
- 본문 안 수식은 `$…$` 만 쓴다(`$$`·`\[` 금지). 줄바꿈을 손으로 넣지 않는다. 원문의 별도 줄 식은 `\par\smallskip\centerline{$…$}\par\smallskip\noindent`.
- 보기 「ㄱ, ㄴ, ㄷ」 상자: body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건 ㈎㈏ 상자·자료 나열: `\exprbox{…}`. 범위 물결은 `$\sim$`.
- 집합은 원문대로 `$S=\{1,\,2,\,3\}$`, `$X=\{a,\,b\}$`, 동전 앞·뒷면은 `$\mathrm{H}$`·`$\mathrm{T}$`.
- **원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다.** 크롭에 스캔 얼룩·워터마크가 겹쳐 있어도 원문 글자만 전사한다.

## 그림

- 좌표평면·수직선·정규분포곡선·확률분포 막대그래프·벤다이어그램·도형·수형도는 **TikZ 로 다시 그린다**: `figures/fig-<id>.tex` (예 `fig-19-14.tex`). 규약 — 정점 2.2pt · 파생점 2pt, 축 0.7pt · 곡선/도형 0.5~0.6pt, 라벨은 선과 겹치지 않게 최소 이동, 축 라벨은 화살표 옆, 눈금 표시 없음, 라벨은 원문에 있는 것만, **답이 그림에서 읽히지 않게**. 첫 줄 주석에 「<id>(인쇄 쪽) — 무엇 · 다시 그린 까닭」.
- 실생활 삽화·사진·복잡한 회로도는 크롭: `node scripts/latex-bank/crop-figure.mjs --pdf "C:/Users/PC/Desktop/교재 라텍스 조판/2022개정 베이직쎈 확통.pdf" --page <pdf쪽> --item <manifest bbox_normalized 네 값> --rel <문항 안 그림 비율> --out latex-bank/ssen-basic-prob/figures/fig-<id>.jpg` → `figure: "crop:fig-<id>.jpg"`.
- 표(확률분포표·표준정규분포표)는 그림이 아니라 `tabular` 로 적는다(위 표기 규약).
- 원문에 없는 그림은 넣지 않는다.

## 확정 절차

1. 쪽 이미지(`qa/pNNN.jpg` · NNN = pdf 쪽 = 인쇄 쪽 − 5)로 구역·공통 지시문·유형 라벨·태그를 파악해 그룹을 만든다.
2. 문항 크롭을 하나씩 읽어 `body`/`choices`/`subs`/`hint`/`tag` 를 전사한다. **배지 번호가 id 의 뒷자리.**
3. 구역 안에서 번호가 끊긴 자리를 쪽 이미지에서 찾아 채운다(특히 한 줄에 둘씩 놓인 짧은 개념 문항).
4. `node scripts/latex-bank/check-batch.mjs <out-파일> --bank latex-bank/ssen-basic-prob` 로 컴파일이 통과하는지 확인한다(xelatex 오류 = 전사 오류).
5. 확실치 않은 것(판독 불가·번호 불일치·크롭 없음·오검출)은 `review_needed` 로 보고한다. **답은 이 단계에서 채우지 않는다.**
