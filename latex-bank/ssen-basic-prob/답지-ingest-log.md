## 8. 다시 만드는 법

`답지-대상-문항목록.json` 은 items.json 에서 만든 파생 파일이다. items.json 이 바뀌면 이렇게 다시 만든다.

```
node -e "
const fs=require('fs');
const j=JSON.parse(fs.readFileSync('latex-bank/ssen-basic-prob/items.json','utf8'));
const keep=new Set(['02','03','04','05','06']);
const DROP=new Set(['47-12','48-17','50-27','63-20','78-19','106-20']);   // 4절: 답지에 대응 문항이 없다
const units=j.units.filter(u=>keep.has(u.code)).map(u=>({code:u.code,title:u.title,pages:u.pages,groups:u.groups.map(g=>({id:g.id,section:g.section,items:g.items}))}));
const u7=j.units[6];
const P=['U7-PW','U7-TX','U7-PX','U7-PY','U7-TY'];
const R=new Set(['146-01','146-02','146-03','146-04','146-05','146-06','147-07','147-08','147-11','147-12','148-13','148-14','148-15','148-16']);
const g7=u7.groups.filter(g=>P.some(p=>g.id.startsWith(p))||g.id==='U7-RAA1').map(g=>({id:g.id,section:g.section,items:g.id==='U7-RAA1'?g.items.filter(i=>R.has(i)):g.items}));
units.push({code:u7.code,title:u7.title,pages:u7.pages,groups:g7});
for (const u of units) u.groups=u.groups.map(g=>({...g,items:g.items.filter(i=>!DROP.has(i))})).filter(g=>g.items.length);
fs.writeFileSync('latex-bank/ssen-basic-prob/답지-대상-문항목록.json', JSON.stringify({units},null,1));
"
```

그 다음 2절 명령을 그대로 실행하면 재현된다.
