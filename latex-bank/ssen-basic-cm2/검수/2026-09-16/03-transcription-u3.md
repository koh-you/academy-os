[리뷰 렌더 잘림 · 2건] `42-39`·`50-22` — 리뷰 시트(`_single.tex` 110mm 낱장)에서 그림 오른쪽이 잘린다. book.pdf(31·38쪽)는 정상. 원인: `build.mjs` `renderItemBody`가 그림을 `0.4\linewidth` minipage에 두는데 낱장 linewidth 98mm의 0.4 = 39mm보다 TikZ 폭(42-39 ≈48mm · 50-22 ≈52mm)이 넓다. 제안: 리뷰용 낱장 `paperwidth`를 넓히거나(예: 150mm), 그림 있는 문항만 minipage 비율을 `0.5`로 두거나, `fig-42-39`·`fig-50-22`의 `scale`을 0.42→0.34 · 0.36→0.30으로 낮춘다(정독 그림 규약의 점 크기는 그대로).
2. [리뷰 렌더 배지 겹침 · 2건] `51-03`·`52-07` — 낱장에서 출처 배지(`\dmkichul`, 5mm 위)가 첫 줄 오른쪽 끝의 `\dfrac` 분자에 겹친다. book.pdf(39쪽)는 겹치지 않음. 첫 줄 끝에 키 큰 수식이 오는 문항이 리뷰 폭에서만 생기는 일이며, 위 1번처럼 낱장 폭을 넓히면 같이 사라진다.
3. [`~`가 무효 · 1건 실측, 규약 전반] `58-02` — 원천 `점~$(4,\,a)$`인데도 「점 / (4, a)」로 갈렸다. kotex(xetexko)가 한글과 라틴/수식 사이에 자체 줄바꿈 글루를 넣으므로 `~`만으로는 못 막는다. 1단원에서 `점~$\pt{P}$` 166건을 넣은 규약이 실제로는 보장되지 않는다는 뜻이므로, 필요한 곳은 `\nob{점 $(4,\,a)$}`(= `\mbox`)로 바꾸거나 `_single.tex`/`book.tex` 서문에 `\XeTeXinterchartokenstate`·kotex 옵션으로 한글→라틴 경계의 break를 끄는 쪽을 검토한다.
4. [조사·어미 줄머리 · 8건] `44-01`(「(0, a) / 를」) · `44-03`(「(2, −1) / 을」) · `46-15`(「=0 / 의」) · `47-24`(「2 : 1 / 인」) · `47-25`(「=b / 이다.」) · `53-16`(「m / 의」) · `56-03`(「(2, 4) / 를」) · `59-11`(「−3 / 일 때」) · 힌트 `43-44`(「□ / 이다.」) · `42-39`(「원 / 의」). 리뷰 폭에서만 생기는 것이며 원문 책도 「점 P / 에 대하여」(47-26)처럼 같은 자리에서 갈린다. 실제 출력 폭(book.pdf)에서 재확인하고, 막고 싶으면 3번과 같은 `\nob` 처리.
5. [빈칸 폭 · 2건] `40-15` 힌트 반지름 빈칸($\sqrt{10}$) · `50-25` 힌트 최댓값·최솟값 결과 빈칸($5\sqrt2$·$3\sqrt2$)은 원문이 넓은 상자. 1단원 13-04와 같은 처리: `\blank`→`\blank[2.4em]`. (`40-15` hint 3번째 `\blank`, `50-25` hint 5·7번째 `\blank`.)
