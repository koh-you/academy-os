# 베이직쎈 공통수학2 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-15. 1단원(104문)에서 굳어진 규약을 2·3단원 전사에 그대로 쓴다. 원천은 `items.json` 하나이며 `items/*.tex` 는 `build.mjs` 가 만든다.

## 입력 (읽을 것)

- 문항 크롭: `output/problem-bank/ssen-basic-cm2/items/pbk_c31f68c566-<쪽>-<번호>.jpg` (220 dpi). 번호 배지가 크롭 안에 보이므로 **id 는 크롭 안의 배지 번호로 확정**한다(manifest 의 number_label 과 다르면 보고).
- 쪽 전체: `output/problem-bank/ssen-basic-cm2/qa/p0NN.jpg` (pdf 쪽 번호 · 인쇄 쪽 = pdf 쪽 + 6). 공통 지시문(말풍선 줄)·구역 제목·유형 라벨(「유형 016 제목」)·「꼭 나와요/서답형/서술형」 태그는 여기서 읽는다.
- 답: `output/problem-bank/ssen-basic-cm2/answers/<item_id>.jpg`(답 줄 크롭) · 해설 `solutions/<item_id>.jpg`. 답 크롭이 없거나 다른 문항 것이면 발문을 직접 풀어 `answer_source` 에 「계산(…)」으로 적는다.

## items.json 구조 (여러 단원)

```json
{
  "book": "베이직쎈 공통수학2",
  "units": [
    { "code": "02", "title": "직선의 방정식", "groups": [
      { "id": "U2-P1", "section": "개념 06 한 점과 기울기가 주어진 직선의 방정식", "passage": "다음 직선의 방정식을 구하시오.", "items": ["22-01", "22-02"] },
      { "id": "U2-T1", "section": "유형 010 한 점과 기울기가 주어진 직선의 방정식", "items": ["26-01", "26-02"] },
      { "id": "U2-R1", "section": "실전 감각 UP", "items": ["37-01"] }
    ] }
  ],
  "items": { "22-01": { "body": "…", "answer": "…", "answer_source": "답지" } }
}
```

- 그룹 id: `U<단원>-P<n>`(개념 쪽 · 지시문 하나 = 그룹 하나 · 지시문 없는 개념 쪽 문항은 passage 없이 그룹) · `U<단원>-T<n>`(유형 · 라벨 하나 = 그룹 하나) · `U<단원>-R1`(실전 감각 UP).
- `section` 은 구역 제목 그대로: 「개념 NN 제목」(차례 기준) · 「유형 NNN 제목」 · 「실전 감각 UP」.
- 그룹 순서·문항 순서는 책 순서(쪽 → 왼쪽 컬럼 → 오른쪽 컬럼).
- 그룹에 공통 그림이 있으면 `figure` 를 그룹에 둔다(1단원 P5).

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `body` | 발문 LaTeX(필수). 지시문은 body 에 넣지 않는다(그룹 passage). |
| `choices` | 5지선다 보기 5개(각각 `$…$`). `choices_layout`: 생략 = 3-2, `"ii"` = 2-2-1(분수 좌표처럼 키 큰 보기), `"v"` = 세로(긴 식). |
| `subs` | 소문항 `(1)(2)…` 본문 배열. |
| `hint` | 개념 쪽 「◎」 풀이 힌트(빈칸형). 줄바꿈은 `\\\\`, 빈칸은 `\blank`(넓은 빈칸 `\blank[2.4em]`). |
| `tag` | 「꼭 나와요」·「서답형」·「서술형」(배지 옆 표시가 있을 때만). |
| `figure` | `"tikz:fig-<id>"`(figures/fig-<id>.tex) 또는 `"crop:fig-<id>.jpg"`. 원문에 그림이 있을 때만. |
| `answer` | 답. 선택형은 `①`~`⑤`, 서답형은 LaTeX(`$…$`). 소문항은 `(1) … (2) …`, 힌트 빈칸형은 `답 (힌트 $…$, $…$)`. |
| `answer_source` | `"답지"` · `"답지(…) · 계산 확인"` · `"계산(답지 크롭 누락)"` 등 — 답을 어디서 확정했는지. |

## 표기 규약 (정독 v3.8 · 프로토타입 style.sty 와 동일)

- 점·선분: `$\pt{A}(1,\,2)$` · `$\seg{AB}$` · `$\seg{AB}^2$` · `$\angle\pt{A}$` · 삼각형 `삼각형~$\pt{ABC}$` · 원점 `$\pt{O}$`.
- 좌표 쉼표 뒤 `\,`: `(3,\,-1)`. 비 `$1\,:\,2$` 또는 `$2:1$`(원문대로 · 빈칸이 있으면 `\,:\,`).
- 분수는 `\dfrac`(선택지·답·힌트 모두). 근호 `\sqrt{2}`. 절댓값 `|x|`. 제곱 `x^2`. 뺄셈 부호 `-`.
- 「점 P」처럼 명사 + 기호는 `점~$\pt{P}$`(`~` = 안 끊는 공백). 「(단, …)」은 `\cond{…}` (괄호·「단,」은 매크로가 붙인다).
- 직선·원의 방정식은 원문 그대로: `$y=2x+1$`, `$x^2+y^2-2x=0$`, 직선 이름 `직선~$l$` · `$l:\ y=2x$`.
- 「$x$축」「$y$절편」처럼 축·절편은 `$x$축`, `$y$절편`.
- 본문 안 수식은 `$…$` 만 쓴다(`$$`·`\[` 금지). 줄바꿈을 손으로 넣지 않는다(조판이 정한다).
- 원문에 있는 한글·부호·수치·조건 문장을 바꾸지 않는다(문항 수·순서·소문항 수·보기 값 = 원문).

## 그림

- 좌표평면·수직선·도형처럼 좌표가 주어진 그림은 TikZ 로 다시 그린다: `figures/fig-<id>.tex` (예: `fig-19-17.tex`). 규약 — 정점 2.2pt · 파생점 2pt, 축 0.7pt · 곡선/도형 0.5~0.6pt, 라벨은 선과 겹치지 않게 최소 이동, 축 라벨 `x`·`y` 는 화살표 옆, 눈금 표시 없음, **답이 그림에서 읽히지 않게**(원문에 없는 값을 적지 않는다). 첫 줄 주석에 「구역 id(본책 쪽) — 무엇 · TikZ 로 다시 그린 까닭」.
- 실생활 삽화·복잡한 도형 사진은 크롭: `node scripts/latex-bank/crop-figure.mjs --pdf "C:/Users/PC/Documents/카카오톡 받은 파일/베이직쎈-공통수학2.pdf" --page <pdf쪽> --item <manifest bbox_normalized 네 값> --rel <문항 안 그림 비율> --out latex-bank/ssen-basic-cm2/figures/fig-<id>.jpg` → `figure: "crop:fig-<id>.jpg"`.
- 원문에 없는 그림은 넣지 않는다. 어느 쪽을 썼는지 README 「그림 기록」 표에 한 줄씩 남긴다.

## 확정 절차

1. 페이지 qa 이미지로 구역·지시문·유형 라벨을 파악 → 그룹을 만든다.
2. 문항 크롭을 하나씩 읽어 body/choices/subs/hint/tag 를 전사한다. 배지 번호가 id 다.
3. 답 크롭을 읽어 answer 를 적고 answer_source 를 남긴다. 크롭이 없으면 직접 풀어 「계산」.
4. `node scripts/latex-bank/build.mjs --bank latex-bank/ssen-basic-cm2` 로 컴파일이 통과하는지 확인한다(xelatex 오류 = 전사 오류).
5. 확실치 않은 것(판독 불가·번호 불일치·답 불일치)은 `검수-필요` 목록으로 보고한다.
