% 1269(본책 176쪽) — 각각 평행한 직선 4개(왼쪽 위에서 오른쪽 아래로), 3개(가로 · 아래쪽), 2개(오른쪽 위에서 왼쪽 아래로)가 서로 만나는 그림. 스캔 그림을 TikZ 로 다시 그림. 라벨 없음.
\begin{tikzpicture}[line width=0.6pt]
  % 4개 (\ 방향)
  \foreach \x in {0.0,0.28,0.56,0.84} { \draw (\x,2.6) -- (\x+1.3,-0.3); }
  % 2개 (/ 방향)
  \foreach \x in {2.3,2.55} { \draw (\x,2.6) -- (\x-1.3,-0.3); }
  % 3개 (가로)
  \foreach \y in {0.15,0.4,0.65} { \draw (-0.4,\y) -- (2.9,\y); }
\end{tikzpicture}
