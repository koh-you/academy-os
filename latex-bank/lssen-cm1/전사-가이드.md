## items.json 구조

```json
{
  "book": "라이트쎈 공통수학1", "id_style": "number", "variant_level": 0,
  "units": [ { "code": "01", "title": "…", "pages": "8~23", "groups": [
      { "id": "U1-A1", "section": "개념 01-1 다항식의 덧셈과 뺄셈", "passage": "다음을 계산하시오.", "items": ["0001", "0002"] },
      { "id": "U1-A2", "section": "유형 03 다항식의 전개식에서 계수 구하기", "items": ["0057"] },
      { "id": "U1-A3", "section": "실전 Training", "items": ["0126"] }
  ] } ],
  "items": { "0001": { "page": 9, "body": "…", "answer": "…", "answer_source": "답지" } }
}
```

- 그룹 id: `U<단원>-<배치이름><n>` (예 `U1-A1`, `U1-A2`). 배치 안에서 1부터.
- 그룹 = 「공통 지시문 하나」 또는 「같은 구역에서 지시문 없이 이어지는 문항 묶음」. 지시문(`[0261~0262] …`)은 `passage`(대괄호 번호는 뺀다).
- `section`: 개념 쪽은 쪽 머리의 「개념 01-1 제목」(라이트쎈) / 「01-1 제목」(쎈)을 `개념 01-1 제목` 으로, 유형 쪽은 유형 상자의 「유형 03 제목」을 그대로, 그 밖(「실전 Training」「서술형」「기본 다잡기」 등)은 쪽 머리띠 원문 그대로.

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽. 필수. |
| `body` | 발문 LaTeX. 지시문은 넣지 않는다(그룹 passage). |
| `figure` | `"tikz:fig-<id>"`(figures/fig-<id>.tex) 또는 `"crop:fig-<id>.jpg"`. 원문에 그림·표가 있을 때만. 표는 `tabular` 를 fig-<id>.tex 에. |
| `figure_layout` | 생략 = 옆(side). 넓은 표·그래프 보기는 `"below"`. |
| `choices` | 5지선다(각 `$…$`). `choices_layout` 생략 = 3-2, `"ii"` = 2-2-1, `"v"` = 세로. 보기가 그림이면 fig-<id>-1~5.tex 를 choices 에 `\input`(베이직쎈 123-01 선례). |
| `subs` | 소문항 `(1)(2)…`. |
| `hint` | 개념 쪽 빈칸 풀이 힌트(`\blank`). |
| `tag` | 「서술형」「대표」「집중공략」 등 번호 옆 표시가 있을 때만. |
| `level` | 라이트쎈 「B⁻ B⁰ B⁺」(유형 Master 아이콘 · 녹색/파랑/자주)·쎈 「상/중/하」 난이도 표시가 있을 때만 원문 글자 그대로. |
| `answer` | 답. 선택형 `①`~`⑤`, 서답형 LaTeX, 소문항 `(1) … (2) …`. |
| `answer_source` | `"답지"` · `"해설"` · `"계산(…)"`. |

## 표기 규약
 (고1 공통수학1 · 다항식·방정식과 부등식·경우의 수·행렬)

- 다항식: `$x^3-2x^2+x-1$`, 나눗셈 몫·나머지는 한글 그대로, 조립제법 표는 크롭 그림. 항등식 `$ax^2+bx+c=0$이 $x$에 대한 항등식`. 인수분해 결과 `$(x-1)(x+2)$`.
- 복소수: 허수단위 `$i$`, `$z=a+bi$`, 켤레복소수 `$\bar{z}$`, `$i^2=-1$`, 실수부·허수부 한글. 근호 `$\sqrt{-3}$`, `$\sqrt{2}\,i$`.
- 방정식·부등식: `$x^2-3x+2=0$`, 근과 계수의 관계 `$\alpha+\beta$`, `$\alpha\beta$`, 판별식 `$D$`, `$D/4$`. 연립은 원문처럼 별도 줄이면 `\begin{cases}…\end{cases}` (인라인 `$\begin{cases} x+y=3 \\ xy=2 \end{cases}$`). 부등식 `$1<x\le 3$`, 절댓값 `$|x-1|<2$`, 가우스 `$[x]$`. 「해가 없다」 등 한글 그대로.
- 이차함수: `$y=x^2-2x+3$`, 꼭짓점·축·최댓값 한글, 그래프는 크롭 그림. 「$x$축」 `$x$축`.
- 경우의 수: 순열 `${}_n\mathrm{P}_r$`, 조합 `${}_n\mathrm{C}_r$`, 팩토리얼 `$n!$`, 「서로 다른」「일렬로」 한글 그대로. 표는 크롭.
- 행렬: `$A=\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$`(본문·보기·답 모두 pmatrix), 단위행렬 `$E$`, 영행렬 `$O$`, 역행렬 `$A^{-1}$`, 성분 `$a_{ij}$`, `$(i,\,j)$ 성분`.
- 분수 `\dfrac`, 좌표 쉼표 뒤 `\,`. 「(단, …)」 → `\cond{…}`. 명사 + 기호는 `점~$\pt{P}$`(`~`). 본문 수식은 `$…$` 만(`$$`·`\[` 금지). 줄바꿈은 손으로 넣지 않는다. 원문의 별도 줄 식(정의식·연립방정식)은 `\par\smallskip\centerline{$…$}\par\smallskip\noindent` 로 둔다(build 가 폭에 맞춰 줄인다).
- 보기 「ㄱ, ㄴ, ㄷ」 상자: body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건 ㈎㈏ 상자: `\exprbox{…}`. 상자 크롭은 쓰지 않는다. 범위 「㈎~㈑」「1~10」 의 물결은 `$\sim$`(`~` 는 LaTeX 공백).
- 원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다. 문항 크롭에 회색 워터마크가 겹쳐 있어도 원문 글자만 전사한다.
