% 0011~0014(본책 9쪽) 공통 지시문 그림 — 수직선 위의 다섯 점 A·B·C·D·E(같은 간격 눈금 9칸, A·B·C·D·E 는 0·3·4·6·9번째 눈금). 스캔 그림이라 TikZ 로 다시 그림.
% 라벨은 원문 그대로 A·B·C·D·E 만. 좌표 수치는 원문에 없으므로 적지 않는다.
\begin{tikzpicture}[scale=0.75, line width=0.6pt]
  \draw[<->, >=stealth] (-0.7,0) -- (9.7,0);
  \foreach \x in {0,...,9} { \draw[line width=0.5pt] (\x,-0.09) -- (\x,0.09); }
  % 같은 간격 표시(작은 호)
  \foreach \x in {0,...,8} { \draw[line width=0.35pt] (\x+0.25,0.13) arc (160:20:0.27); }
  \foreach \x/\lab in {0/A, 3/B, 4/C, 6/D, 9/E} {
    \fill (\x,0) circle (2.2pt);
    \node[below=1pt, font=\small] at (\x,-0.05) {$\mathrm{\lab}$};
  }
\end{tikzpicture}
