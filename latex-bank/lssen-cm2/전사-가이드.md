## items.json 구조

```json
{
  "book": "라이트쎈 공통수학2", "id_style": "number", "variant_level": 0,
  "units": [ { "code": "01", "title": "…", "pages": "8~23", "groups": [
      { "id": "U1-A1", "section": "개념 01-1 다항식의 덧셈과 뺄셈", "passage": "다음을 계산하시오.", "items": ["0001", "0002"] },
      { "id": "U1-A2", "section": "유형 03 다항식의 전개식에서 계수 구하기", "items": ["0057"] },
      { "id": "U1-A3", "section": "실전 Training", "items": ["0126"] }
  ] } ],
  "items": { "0001": { "page": 9, "body": "…", "answer": "…", "answer_source": "답지" } }
}
```

- 그룹 id: `U<단원>-<배치이름><n>` (예 `U1-A1`, `U1-A2`). 배치 안에서 1부터.
- 그룹 = 「공통 지시문 하나」 또는 「같은 구역에서 지시문 없이 이어지는 문항 묶음」. 지시문(`[0261~0262] …`)은 `passage`(대괄호 번호는 뺀다).
- `section`: 개념 쪽은 쪽 머리의 「개념 01-1 제목」(라이트쎈) / 「01-1 제목」(쎈)을 `개념 01-1 제목` 으로, 유형 쪽은 유형 상자의 「유형 03 제목」을 그대로, 그 밖(「실전 Training」「서술형」「기본 다잡기」 등)은 쪽 머리띠 원문 그대로.

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽. 필수. |
| `body` | 발문 LaTeX. 지시문은 넣지 않는다(그룹 passage). |
| `figure` | `"tikz:fig-<id>"`(figures/fig-<id>.tex) 또는 `"crop:fig-<id>.jpg"`. 원문에 그림·표가 있을 때만. 표는 `tabular` 를 fig-<id>.tex 에. |
| `figure_layout` | 생략 = 옆(side). 넓은 표·그래프 보기는 `"below"`. |
| `choices` | 5지선다(각 `$…$`). `choices_layout` 생략 = 3-2, `"ii"` = 2-2-1, `"v"` = 세로. 보기가 그림이면 fig-<id>-1~5.tex 를 choices 에 `\input`(베이직쎈 123-01 선례). |
| `subs` | 소문항 `(1)(2)…`. |
| `hint` | 개념 쪽 빈칸 풀이 힌트(`\blank`). |
| `tag` | 「서술형」「대표」「집중공략」 등 번호 옆 표시가 있을 때만. |
| `level` | 라이트쎈 「B⁻ B⁰ B⁺」(유형 Master 아이콘 · 녹색/파랑/자주)·쎈 「상/중/하」 난이도 표시가 있을 때만 원문 글자 그대로. |
| `answer` | 답. 선택형 `①`~`⑤`, 서답형 LaTeX, 소문항 `(1) … (2) …`. |
| `answer_source` | `"답지"` · `"해설"` · `"계산(…)"`. |

## 표기 규약
 (고1 공통수학2 · 도형의 방정식·집합과 명제·함수)

- 점·좌표·선분: `점~$\pt{A}(1,\,2)$`, `$\seg{AB}$`, `$\seg{AB}^2$`, `직선~$l$`, `원~$\pt{O}$`. 각 `$\angle\pt{A}$`, 삼각형 `삼각형~$\pt{ABC}$` · 넓이 `$\triangle\pt{ABC}$`, 사각형 `$\square\pt{ABCD}$`. 거리 `\,\mathrm{km}` 등 단위는 `\mathrm`.
- 직선·원·도형의 방정식은 원문 그대로: `$y=2x+1$`, `$x^2+y^2-2x=0$`, `$(x-1)^2+(y+2)^2=4$`. 「$x$축」「$y$절편」 은 `$x$축`. 평행이동 `$(x,\,y)\longrightarrow(x+2,\,y-3)$`, 대칭이동은 문장 그대로.
- 집합: `$A=\{1,\,2,\,3\}$`, `$\{x\mid x\text{는 } 10 \text{ 이하의 자연수}\}$` 는 `$\{x \mid x$는 $10$ 이하의 자연수$\}$` 처럼 한글은 수식 밖에. `$\in$`, `$\notin$`, `$\subset$`, `$\not\subset$`, `$\cup$`, `$\cap$`, 여집합 `$A^{\mathrm{c}}$` → 매크로 `\comp{A}`, 전체집합 `$U$`, 공집합 `$\varnothing$`, 원소의 개수 `$n(A)$`, 차집합 `$A-B$`.
- 명제: `$p\longrightarrow q$`, 부정 `$\sim p$`, 「$p$이면 $q$이다」 는 한글 그대로, 「모든/어떤」 그대로, 조건 `$p:\ x>1$`. 필요·충분조건 문장은 원문대로. 대우·역은 한글.
- 함수: `$f(x)=x^2-1$`, `$f:X\longrightarrow Y$`, 합성 `$(g\circ f)(x)$`, 역함수 `$f^{-1}(x)$`, 정의역·공역·치역 한글. 유리함수 `$y=\dfrac{2x+1}{x-1}$`(본문·보기·답 모두 `\dfrac`), 무리함수 `$y=\sqrt{2x-1}+3$`. 절댓값 `$|x|$`, 가우스 `$[x]$`.
- 부등식·구간: `$1<x\le 3$`(`\le`·`\ge`), 좌표 쉼표 뒤 `\,`. 「(단, …)」 → `\cond{…}`. 명사 + 기호는 `점~$\pt{P}$`(`~`). 본문 수식은 `$…$` 만(`$$`·`\[` 금지). 줄바꿈은 손으로 넣지 않는다.
- 보기 「ㄱ, ㄴ, ㄷ」 상자(보기 참·거짓 문항): `hint` 가 아니라 body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}` 로 적는다(테두리 상자 · 줄바꿈 `\\`). 상자 크롭이 있으면 쓰지 말고 이 LaTeX 로.
- 원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다. 문항 크롭에 회색 워터마크(로고·이메일)가 겹쳐 있어도 원문 글자만 전사한다.
