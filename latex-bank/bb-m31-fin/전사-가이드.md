# 100발100중 3-1 기말 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-19. RPM 공통수학2 가이드(`latex-bank/rpm-cm2/전사-가이드.md`)의 **표기 규약·문항 필드·확정 절차를 그대로** 쓴다(중학 3-2: 삼각비·삼각비의 활용·원과 직선·원주각 — 삼각비 `\sin A`, 선분 `\seg{AB}`, 각 `\angle\pt{A}`, 단위 `\,\mathrm{cm}`). 이 책은 **기출 모음 문제집**(텍스트 PDF · 2단 · 구역마다 번호가 다시 시작)이라 다음이 다르다.

- **id 는 「인쇄 쪽-번호」**(`12-07`). 크롭 첫 줄의 큰 색 숫자가 번호. 집중공략·서술형 쪽의 **예제**(큰 번호 + 모범답안 상자)는 `12-e1`, 그 아래 **연습문제**는 `12-01` 이다. items.json 은 `id_style: "page-number"` 이고 출처 배지는 「100발100중 3-1 기말 12쪽 7번」 / 「… 40쪽 예제 1」. 문항마다 `page`(인쇄 쪽)를 적는다.
- **구역(section)** 은 쪽 머리·번호 옆 표시로 정한다: `기출 Best` · `집중공략` · `서술형 문제` · `실전 모의고사 N회` · `파이널 모의고사 N회` · `고난도 기출문제` · `최다 오답문제` 등 원문 표기 그대로. 번호 옆 작은 글씨(「07 입체도형에서의 삼각비의 값」)는 유형 라벨이라 `type` 필드에 적는다(배치 목록의 「(유형 …)」).
- **예제는 문항으로 넣되 발문만 전사**한다(모범답안·채점기준·서술 Tip 은 넣지 않는다). 예제의 답은 모범답안 마지막 줄(★ 또는 ∴)에서 읽어 `answer_source: "예제 모범답안"`. 예제 크롭에 딸린 자동 그림 크롭이 모범답안 상자를 포함하면 figure 로 쓰지 말고 review_needed 에 적는다(그림이 문제 쪽에만 있으면 그대로 쓴다).
- **그림은 TikZ 로 그리지 않는다.** `prepare-text-pdf-bank.mjs` 가 벡터 그림을 300dpi 로 크롭해 두었다(`figures/fig-<id>.png`). 배치 목록의 `crop:fig-….png` 를 `figure` 에 쓴다. 잘못된 크롭(글자 섞임·잘림·상자 포함)은 review_needed.
- **답은 별도 답지 PDF(스캔)의 「빠른 정답」쪽 렌더**(배치 md 끝에 경로)로 확정한다: 구역 이름과 인쇄 쪽 범위(예 「기출 Best · 12~13쪽」)가 상자 머리에 있으니 자기 배치의 쪽에 맞는 상자를 찾아 번호별 답을 읽는다. `answer_source: "답지(빠른정답)"`. 못 찾으면 해설 쪽(a007~)에서 찾고 `"답지(해설)"`, 그래도 없으면 직접 풀어 `"계산"`.
- **번호 빈틈**(배치 목록 ⚠ number_gap): 집중공략 표시(빨간 동그라미 번호)처럼 번호가 그래픽이라 크롭 목록에서 빠진 문항이다. 쪽 이미지(qa/pNNN.jpg)를 보고 그 번호의 문항을 **쪽 렌더로 전사해 넣는다**(id 는 쪽-번호 · 그림은 review_needed 에 「크롭 필요」). 반대로 목록에 있지만 문항이 아닌 것(구역 머리의 큰 숫자 등)은 items 에 넣지 않고 review_needed 에 적는다.
- 서술형 문항은 「그 과정을 서술하시오」 까지 body 에 그대로. 배점 「[5점]」 은 body 끝에 그대로 둔다.
- 힌트 줄(글자 레이어)은 한글·숫자만 정확하고 수식은 글꼴 코드라 어긋난다 — 수식은 크롭을 읽어 전사한다.

## items.json 구조

```json
{
  "book": "100발100중 3-1 기말", "id_style": "page-number", "variant_level": 0,
  "units": [ { "code": "01", "title": "3-2 중간(…)", "pages": "8~152", "groups": [
      { "id": "U1-A1", "section": "기출 Best", "items": ["8-01", "8-02"] },
      { "id": "U1-C3", "section": "집중공략", "items": ["40-e1", "40-01"] }
  ] } ],
  "items": {
    "12-07": { "page": 12, "type": "입체도형에서의 삼각비의 값", "body": "그림과 같은 직육면체에서 …", "figure": "crop:fig-12-07.png", "choices": ["$\\dfrac{\\sqrt{2}}{5}$", "…"], "answer": "②", "answer_source": "답지(빠른정답)" },
    "40-e1": { "page": 40, "tag": "예제", "type": "삼각비를 활용하여 직각삼각형의 높이 구하기", "body": "그림과 같이 나무로부터 … [5점]", "figure": "crop:fig-40-e1.png", "answer": "$7.3\\,\\mathrm{m}$", "answer_source": "예제 모범답안" }
  }
}
```

- 그룹은 「같은 쪽 · 같은 구역」 묶음. 그룹 순서·문항 순서는 책 순서(쪽 → 왼쪽 컬럼 → 오른쪽 컬럼).

## 확정 절차

1. 배치 md 의 쪽 이미지(`qa/pNNN.jpg`)를 열어 구역·번호 빈틈·예제/연습문제를 파악한다.
2. 문항 크롭을 하나씩 읽어 body/choices/subs 를 전사한다(힌트 줄과 대조). 크롭 첫 줄 번호가 id.
3. 빠른정답 쪽 렌더(a001~a006)에서 구역·쪽 범위 상자를 찾아 answer 를 적는다.
4. 배치 목록의 `figure` 를 옮겨 적고 크롭 파일을 한 번 열어 본다.
5. `node scripts/latex-bank/check-batch.mjs <out.json> --bank latex-bank/bb-m31-fin` 로 컴파일 확인.
