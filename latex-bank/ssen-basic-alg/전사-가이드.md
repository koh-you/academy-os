# 베이직쎈 대수 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-26. 베이직쎈 공통수학1(`latex-bank/ssen-basic-cm1/전사-가이드.md`)·공통수학2에서 굳어진 규약을 그대로 쓰고 **표기 규약만 대수(지수·로그 / 삼각함수 / 수열)** 로 바꾼다. 원천은 `items.json` 하나이며 `items/*.tex`·`book.tex` 는 `build.mjs` 가 만든다.

## 이 책의 사실 (쪽 렌더로 실제 확인한 것)

- **스캔 PDF**(글자 레이어 없음, `getTextContent` 0자). 본문 PDF 208쪽 · 답지 PDF 128쪽.
- **인쇄 쪽 = pdf 쪽 (offset 0).** p8→8쪽, p15→15쪽, p26→26쪽, p61→61쪽, p152→152쪽, p205→205쪽 바닥글로 확인했다. 베이직쎈 공통수학2의 `+6` 과 다르다.
- 문항 쪽은 **pdf 8~205쪽**. 206~208쪽은 상용로그표①②·삼각함수표이고 문항이 없다.
- 문항 번호는 **구역마다 01 부터 다시 시작하는 두 자리 배지**다. 세 자리 문항 번호는 없다(쎈B 와 다르다 — `--badge3` 를 쓰지 않았다). **id 는 `인쇄쪽-번호`**(예 `116-07`). items.json 은 `id_style` 을 쓰지 않는다.
- 구역은 셋뿐이다: **개념 쪽(기본 문제)** · **「자신감 UP! 기본&핵심 유형」** · **「학교 시험 기출로 실전 감각 UP!」**.
- **구역은 언제나 쪽 맨 위에서 바뀐다.** 8~205쪽 전부를 머리띠 OCR 로 훑어 확인했다 — 한 쪽 안에서 번호가 01 로 되돌아가는 자리는 없다. 그래서 `쪽-번호` id 는 책 전체에서 유일하다.
- 유형 라벨은 **「유형 001 제목」 세 자리**(왼쪽에 초록 「유형」 꼬리표 상자). 책 전체에서 001~127 까지 1씩 는다.
- 개념 쪽 오른쪽 위의 「유형 | 001, 002」·「유형 | 041~044」 는 그 개념에 이어지는 유형 번호 안내다. **문항이 아니다.**
- **연계번호가 없다.** 쎈B 의 「쎈 NNNN」 같은 책 전체 통번호가 이 책에는 없다 → 누락 판정은 **쪽 안 배지 번호의 연속성**(01,02,03,… 이 끊기지 않는지)으로만 한다.

## 입력 (읽을 것)

- 문항 크롭: `output/problem-bank/ssen-basic-alg/items/pbk_<해시>-<쪽>-<번호>.jpg` (220 dpi). 번호 배지가 크롭 안에 보인다.
- 쪽 전체: `output/problem-bank/ssen-basic-alg/qa/pNNN.jpg` (**pdf 쪽 = 인쇄 쪽**). 공통 지시문(말풍선 줄)·구역 제목·유형 라벨(「유형 016 제목」)·「꼭 나와요 / 서답형 / 서술형」 태그는 **여기서** 읽는다. 문항 크롭만 보고 판단하지 않는다.
- 배치 목록(`latex-bank/ssen-basic-alg/work/batch-<이름>.md`)의 ⚠ 표시(flagged)는 크롭 경계가 불확실한 문항이다 — 쪽 이미지에서 원문을 확인한다.
- 구역별 배지 번호 점검표: `latex-bank/ssen-basic-alg/work/배지-점검.md`. **어느 구역에서 번호가 빠지거나 밀렸는지**가 적혀 있다. 담당 쪽이 거기 걸려 있으면 번호를 쪽 이미지로 다시 읽는다.
- 배치 지도: `latex-bank/ssen-basic-alg/work/배치-지도.md`. 배치마다 쪽·중단원·문항 수와 **배치 안에서 구역이 바뀌는 자리**(⚠)가 적혀 있다.
- **답·해설은 이 단계에 없다.** `answer` 는 **빈 문자열**, `answer_source` 도 **빈 문자열**로 둔다. 답지(`C:/Users/PC/Desktop/교재 라텍스 조판/베이직쎈 대수 정답 및 해설.pdf`, 128쪽)는 전사가 끝난 뒤 별도 ingest 로 붙인다. 배치 목록 줄 끝의 `답 …/answers/…jpg`·`해설 …/solutions/…jpg` 경로는 **아직 없는 파일**이니 열지 않는다.

## 무엇이 참인가 — 배지 번호

**배치 목록·크롭 파일 이름의 번호를 믿지 말 것.** 검출기가 배지를 못 읽은 자리에서 순번이 밀려 실제 배지와 어긋날 수 있다.

**id 의 뒷자리는 언제나 쪽 이미지(`qa/pNNN.jpg`)에서 읽은 배지 번호다.** 크롭 파일 이름과 다르면 배지 번호를 쓰고 `review_needed` 에 「번호 불일치: 크롭 <파일번호> → 배지 <실제>」로 적는다.

**누락 판정은 쪽 안 배지 번호의 연속성으로 한다.** 이 책에는 연계번호가 없다. 담당 쪽의 배지 번호를 순서대로 적어 보고, 한 구역 안에서 번호가 끊기면 그 자리에 문항이 있다는 뜻이니 쪽 이미지에서 찾아 채운다. 구역이 바뀌는 쪽에서는 번호가 01 로 되돌아가는 것이 정상이다(끊김이 아니다).

이 판의 배치 목록에는 **「빠진 번호」 줄이 찍히지 않는다**(id 가 `쪽-번호` 꼴이라 `make-batches.mjs` 의 통번호 검사가 걸리지 않는다). 대신 `work/배지-점검.md` 를 쓴다.

**manifest 의 `type_label`(배치 목록의 「구역(자동 추정)」)도 믿지 말 것.** 실측해 보니 개념 번호는 최대 +2 까지 밀려 있고(예: 98쪽을 「개념 32」로 적었지만 실제는 「개념 30 일반각」), 유형 라벨은 10개만 남고 나머지는 앞 라벨이 그대로 이어져 있다(예: 53·67·82·103·122쪽 모두 「유형 013 로그의 정의」). **구역 제목(`section`)은 반드시 쪽 이미지 맨 위의 「개념 NN 제목」·「유형 NNN 제목」 을 읽어서 쓴다.** 철자는 아래 부록의 개념 목록과 맞춘다.

**한 줄에 문항이 둘 나란히 놓인 쪽**(「01 $35^\circ$  02 $260^\circ$」)에서는 검출기가 **오른쪽 문항의 배지를 자주 놓친다.** 그런 쪽에서는 짝수 번호가 통째로 비어 보인다 — 반드시 쪽 이미지로 채운다. 98~102쪽(개념 11 일반각과 호도법)이 대표적이다.

**검은 상자 안 흰 숫자 배지는 OCR 이 못 읽어 크롭이 빠질 수 있다.** 이건 정상이며, 배치 목록에 번호가 비어 있으면 **쪽 이미지에서 직접 전사해 넣는다.** 빠뜨리면 그대로 사라진다. 채운 문항은 `review_needed` 에 「크롭 없음 — 쪽 이미지에서 전사」로 적는다.


- 그룹 id: `U<단원>-P<배치이름><n>`(개념 쪽 · 지시문 하나 = 그룹 하나 · 지시문 없는 문항은 passage 없이 그룹) · `U<단원>-T<배치이름><n>`(유형 · 라벨 하나 = 그룹 하나) · `U<단원>-R<배치이름>1`(실전 감각 UP). 배치 안에서 1부터 세고, 병합할 때 겹치지 않게 **배치 이름을 꼭 넣는다**(`U1-PA1`, `U1-TA1`).
- `section` 은 구역 제목 그대로: 「개념 NN 제목」(아래 부록 목록 기준) · 「유형 NNN 제목」(쪽 이미지의 라벨 그대로) · 「실전 감각 UP」.
- 유형 상자의 설명 글(연한 바탕의 공식 요약)은 전사하지 않는다 — `section` 제목만 쓴다.
- 그룹 순서·문항 순서는 책 순서(쪽 → 왼쪽 컬럼 → 오른쪽 컬럼).
- 그룹에 공통 그림이 있으면 `figure` 를 그룹에 둔다.

## 표기 규약 (고2 대수 · 지수·로그 / 삼각함수 / 수열)

`latex-bank/rpm-alg/전사-가이드.md` 의 대수 규약과 같다.

- **거듭제곱근·지수**: `$\sqrt[3]{8}$`, `$\sqrt[n]{a}$`, `$a^{\frac{1}{2}}$`(지수 안의 분수는 `\frac`, 본문 분수는 `\dfrac`), `$2^{\sqrt{2}}$`, `$(a^2)^3$`, `$a^{-n}=\dfrac{1}{a^n}$`. 「$n$제곱근」·「세제곱근」·「대소 비교」는 한글 그대로.
- **로그**: `$\log_2 8$`, `$\log_a x$`(밑은 아래첨자), 상용로그 `$\log 2$`, `$\log_{\frac{1}{2}} x$`, 진수·밑은 한글. 상용로그표 값은 원문 그대로(`0.3010`).
- **지수·로그함수**: `$y=2^x$`, `$y=\left(\dfrac{1}{2}\right)^{x}$`, `$y=\log_2 (x-1)+3$`. 점근선·평행이동·대칭이동·정의역·치역은 한글. 방정식·부등식 `$2^{x+1}=8$`, `$\log_2 x<3$`.
- **삼각함수**: `$\sin\theta$`, `$\cos\dfrac{\pi}{3}$`, `$\tan(-\theta)$`, `$\sin^2\theta$`, 호도법 `$\dfrac{\pi}{6}$`, 각 `$\theta$`, 육십분법 `$60^\circ$`, 「제2사분면」·「동경」·「시초선」은 한글. 주기·최댓값·최솟값 한글. 사인법칙·코사인법칙은 원문 그대로(`$\dfrac{a}{\sin A}=2R$`, `$a^2=b^2+c^2-2bc\cos A$` · 삼각형 변은 `$a$`, 각은 `$A$`). 부채꼴 호 `$\arc{AB}$`, 호의 길이 `$l=r\theta$`, 넓이 `$S=\dfrac{1}{2}r^2\theta$`.
- **수열**: `$a_n$`, `$\{a_n\}$`, `$a_{n+1}=a_n+3$`, `$S_n$`, 제$n$항은 `제~$n$항`, 합 `$\displaystyle\sum_{k=1}^{n} a_k$`(`\displaystyle` 을 붙여 본문에서도 위아래 첨자). 등차중항·등비중항·공차·공비·일반항·원리합계는 한글. 수학적 귀납법의 「$n=k$일 때 …」 는 한글 그대로, 증명 빈칸은 `\blank`, 증명 상자는 `\exprbox{…}`, ㈎㈏ 는 원문 기호 그대로.
- **도형·단위**: `$\seg{AB}$`, `$\angle\pt{A}$`, `삼각형~$\pt{ABC}$`, `$\pt{O}$`, `$8\,\mathrm{cm}$`, 「점 P」는 `점~$\pt{P}$`(`~` = 안 끊는 공백).
- 분수는 `\dfrac`(선택지·답·힌트 모두). 좌표 쉼표 뒤 `\,`: `(3,\,-1)`. 비 `$1\,:\,2$`. 「(단, …)」 → `\cond{…}`(괄호와 「단,」 은 매크로가 붙인다).
- 본문 안 수식은 `$…$` 만 쓴다(`$$`·`\[` 금지). 줄바꿈을 손으로 넣지 않는다(조판이 정한다). 원문의 별도 줄 식은 `\par\smallskip\centerline{$…$}\par\smallskip\noindent`.
- 보기 「ㄱ, ㄴ, ㄷ」 상자는 body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건·식 상자는 `\exprbox{…}`. 범위 물결은 `$\sim$`.
- 본문 안의 빈칸 □ 는 `\blank`. 「‘○’를, ‘×’를 ( ) 안에 써넣으시오」 꼴의 괄호는 `(\hspace*{1.2em})`, 기호는 `$\bigcirc$`·`$\times$`.
- **원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다.** 크롭에 워터마크가 겹쳐 있어도 원문 글자만 전사한다.

## 그림

- 좌표평면·수직선·삼각형·부채꼴·그래프처럼 좌표가 주어진 그림은 **TikZ 로 다시 그린다**: `latex-bank/ssen-basic-alg/figures/fig-<id>.tex`. 규약 — 정점 2.2pt · 파생점 2pt, 축 0.7pt · 곡선/도형 0.5~0.6pt, 라벨은 선과 겹치지 않게 최소 이동, 축 라벨 `x`·`y` 는 화살표 옆, 눈금 표시 없음, **답이 그림에서 읽히지 않게**(원문에 없는 값을 적지 않는다). 첫 줄 주석에 「<id>(인쇄 쪽) — 무엇 · 다시 그린 까닭」.
- 실생활 삽화·복잡한 사진은 크롭:
  `node scripts/latex-bank/crop-figure.mjs --pdf "C:/Users/PC/Desktop/교재 라텍스 조판/베이직쎈 대수.pdf" --page <pdf쪽> --item <manifest bbox_normalized 네 값> --rel <문항 안 그림 비율> --out latex-bank/ssen-basic-alg/figures/fig-<id>.jpg`
  → `figure: "crop:fig-<id>.jpg"`.
- **원문에 없는 그림은 넣지 않는다.**
