# 개념원리 중학 3-2 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-21. RPM 중학 3-2 가이드(`latex-bank/rpm-m32/전사-가이드.md`)의 **표기 규약(중3-2: 삼각비·원과 직선·원주각·산포도·상자그림과 산점도)·문항 필드·확정 절차를 그대로** 쓴다. 이 책은 **개념서**(텍스트 PDF · 구역마다 번호가 다시 시작 · 문항 종류가 여럿)라 다음이 다르다.

## id 와 문항 종류

id 는 **「인쇄 쪽-종류번호」**. 배치 목록의 id 가 그대로 id 다(크롭 배지 번호와 대조). items.json 은 `id_style: "page-number"`.

| id | 종류 | 출처 배지 | 전사 범위 |
| --- | --- | --- | --- |
| `17-01` | 개념원리 확인하기 · 계산력 강화하기 · 이런 문제가 시험에 나온다 · 중단원 마무리하기 · 실력 UP 의 큰 번호 01, 02 … | 「개념원리 중학 3-2 17쪽 1번」 | 문항 전체 |
| `17-h1` | 핵심문제 익히기의 **핵심문제 01**(회색 상자 · 아래에 풀이·답이 인쇄된 예제) | 「… 17쪽 핵심문제 1」 | **상자 안 발문만**(풀이·답·KEY POINT 는 넣지 않는다) |
| `17-c1` | 핵심문제 익히기의 **확인 1** | 「… 17쪽 확인 1」 | 문항 전체 |
| `34-e1` | 서술형 대비 문제의 **예제 1**(풀이 과정·채점 기준이 인쇄된 예제) | 「… 34쪽 예제 1」 | **발문만**(「[7점]」 배점은 body 끝에 그대로) |
| `34-u1` | 서술형 대비 문제의 **유제 1**(스스로 서술하기 포함) | 「… 34쪽 유제 1」 | 발문만(빈 풀이 과정 상자·「답」 칸은 넣지 않는다) |

- 문항마다 `page`(인쇄 쪽 = id 앞부분)를 적는다. 배치 목록의 「인쇄 N쪽」과 쪽 이미지 바닥글 번호가 같은지 본다.
- `tag`: 「꼭나와」(번호 위 빨간 배지) · 「서술형」 등 번호 옆 표시. `level` 은 이 책에 없다(난이도 표시 없음).
- **구역(section)** 은 배치 목록의 구역 이름 그대로: `개념원리 확인하기` · `핵심문제 익히기` · `계산력 강화하기` · `이런 문제가 시험에 나온다` · `중단원 마무리하기` · `서술형 대비 문제`. 중단원 마무리는 STEP 표시를 붙인다: `중단원 마무리하기 STEP 1 기본 문제` · `… STEP 2 발전 문제` · `… STEP 3`(쪽 이미지의 STEP 띠 기준). 핵심문제는 상자 제목 띠의 유형 이름을 `type` 에 적는다(「삼각비의 값」).
- 핵심문제·예제의 답은 인쇄된 답 줄(배치 목록 「답 크롭」 · `answers/<id>.jpg` 는 본문 「답」 줄)에서 읽어 `answer_source: "본문 답"`. 나머지 문항의 답은 정답 PDF 빠른정답 상자의 항목 크롭(`answers/<id>.jpg`)에서 읽어 `answer_source: "답지"`. 크롭이 없거나 잘렸으면 정답 PDF 쪽 렌더(`qa/answers-pNNN.jpg`)에서 같은 구역·쪽 상자를 찾고, 그래도 없으면 직접 풀어 `"계산"`.
- 소문항 ⑴⑵⑶ 은 `subs` 배열(원문 「⑴」은 `\dmsubprob` 가 붙이므로 본문에서는 뺀다). 빈칸 □ 는 `\blank`.
- **그림은 TikZ 로 그리지 않는다.** `prepare-text-pdf-bank.mjs` 가 벡터 그림을 300dpi 로 크롭해 두었다(`figures/fig-<id>.png`). 배치 목록의 `crop:fig-….png` 를 `figure` 에 쓴다. 번호 배지·제목 띠·QR·보기 상자만 든 크롭은 쓰지 않고 review_needed 에 적는다. 그림이 있는데 크롭이 없으면 review_needed 「크롭 필요」.
- 「보기」 상자는 `\bogi{ㄱ. …\\ ㄴ. …}`, 자료·조건 상자는 `\exprbox{…}`(가이드 공통).
- 힌트 줄(글자 레이어)은 한글·숫자만 정확하고 수식은 글꼴 코드라 어긋난다 — 수식은 크롭을 읽어 전사한다.

## items.json 구조

```json
{
  "book": "개념원리 중학 3-2", "id_style": "page-number", "variant_level": 0,
  "units": [ { "code": "01", "title": "삼각비", "pages": "11~14", "groups": [
      { "id": "U1-A1", "section": "개념원리 확인하기", "items": ["11-01", "11-02"] },
      { "id": "U1-A2", "section": "핵심문제 익히기", "items": ["12-h1", "12-c1", "12-h2", "12-c2"] }
  ] } ],
  "items": {
    "11-01": { "page": 11, "body": "다음 \\blank\\ 안에 알맞은 것을 써넣으시오.", "subs": ["제곱하여 $49$가 되는 수는 $\\blank$, $\\blank$이므로 …", "$0$의 제곱근은 $\\blank$이다.", "…"], "answer": "⑴ $7$, $-7$, $7$, $-7$ ⑵ $0$ ⑶ 없다", "answer_source": "답지" },
    "12-h1": { "page": 12, "type": "제곱근의 뜻", "body": "다음 중 옳지 않은 것은?", "choices": ["$…$", "$…$", "$…$", "$…$", "$…$"], "answer": "⑤", "answer_source": "본문 답" },
    "12-c1": { "page": 12, "body": "다음 중 그 값이 나머지 넷과 다른 하나는?", "choices": ["$…$", "…"], "answer": "②", "answer_source": "답지" },
    "34-e1": { "page": 34, "body": "$a<b$, $ab<0$일 때, $\\sqrt{(-a)^2}+\\sqrt{b^2}-\\sqrt{(5a)^2}+\\sqrt{(-2b)^2}$을 간단히 하시오. [7점]", "answer": "$4a+3b$", "answer_source": "본문 답" }
  }
}
```

- 그룹은 「같은 쪽 · 같은 구역」 묶음(핵심문제와 그 확인은 같은 그룹). 그룹 순서·문항 순서는 책 순서(쪽 → 왼쪽 컬럼 → 오른쪽 컬럼). 그룹 id 접두는 `U{UNIT_NO}-{BATCH}`.

## 확정 절차

1. 배치 md 의 쪽 이미지(`qa/pNNN.jpg`)를 열어 구역·문항 종류·STEP 을 파악한다.
2. 문항 크롭을 하나씩 읽어 body/choices/subs 를 전사한다(힌트 줄과 대조). 핵심문제·예제·유제는 발문만.
3. 답 크롭(`answers/<id>.jpg`)으로 answer 를 적는다.
4. 배치 목록의 `figure` 를 옮겨 적고 크롭 파일을 한 번 열어 본다.
5. `node scripts/latex-bank/check-batch.mjs <out.json> --bank latex-bank/gn-m32` 로 컴파일 확인.
