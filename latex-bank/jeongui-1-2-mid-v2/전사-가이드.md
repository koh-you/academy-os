# 2026 정의여고 1-2 중간고사 프린트 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-19. RPM 공통수학2 가이드(`latex-bank/rpm-cm2/전사-가이드.md`)의 **표기 규약·문항 필드·확정 절차를 그대로** 쓴다. 이 자료는 교재가 아니라 **기출 모음 프린트**(HWP 출력 텍스트 PDF · 2단 · 문항 41개 · 공통수학2 평면좌표·직선의 방정식·원의 방정식)라 다음이 다르다.

- **id 는 프린트 번호 2자리**(`01`~`41`). 크롭 첫 줄의 「N.」 이 id. items.json 은 `id_style: "number"` 이고 출처 배지는 「2026 정의여고 1-2 중간고사 프린트 03번 · 1쪽」 → 문항마다 `page`(pdf 쪽 = 인쇄 쪽) 를 적는다.
- **출처 태그와 난이도**: 배치 목록의 「(유형 2024년교육청고1공통9월>20[4점])」 이 원 출처(학평 연도·월·번호·배점)이고 「Lv3 어려움」 이 프린트의 난이도 라벨이다. 문항 필드에 `source_tag: "2024 교육청 고1 9월 20번 [4점]"`(띄어쓰기 정리) · `level: "Lv3 어려움"` 으로 적는다. 정독·변형 단계에서 쓴다.
- **그림은 TikZ 로 그리지 않는다.** 원문 그림이 래스터 이미지라 `prepare-text-pdf-bank.mjs` 가 300dpi 로 크롭해 두었다(`figures/fig-<id>.png`). 배치 목록의 `crop:fig-….png` 를 `figure` 에 그대로 쓴다. 크롭이 잘못됐으면 review_needed.
- **글자 레이어 힌트**: 한글·숫자는 정확하지만 수식은 HWP 사설 글꼴이라 빠져 있다(「점 A,B,」 처럼 좌표가 비어 보임). 수식은 반드시 크롭을 읽어 전사한다.
- **답**: 배치 목록의 답 크롭(`answers/…jpg` · 「N. [정답] ②」 줄)으로 확정하고 `answer_source: "답지"`. 서답형 수식 답도 그 줄에 있다. 해설 크롭(`solutions/…jpg`)은 대조용.
- **그룹**: 공통 지시문이 없으므로 그룹은 「같은 쪽의 문항 묶음」 하나씩(`section` 은 `"p1"` 처럼 쪽). `id` 는 `U1-<배치><n>`.
- 보기 「ㄱ, ㄴ, ㄷ」 상자는 body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 서답형은 `choices` 없이 answer 만.

## items.json 구조

```json
{
  "book": "2026 정의여고 1-2 중간고사 프린트", "id_style": "number", "variant_level": 0,
  "units": [ { "code": "01", "title": "평면좌표·직선·원", "pages": "1~14", "groups": [
      { "id": "U1-A1", "section": "p1", "items": ["01", "02", "03"] }
  ] } ],
  "items": { "03": { "page": 1, "source_tag": "2024 교육청 고1 9월 20번 [4점]", "level": "Lv3 어려움", "body": "그림과 같이 좌표평면 위에 세 점 …", "figure": "crop:fig-03.png", "choices": ["$\\dfrac{21}{2}$", "$11$", "$\\dfrac{23}{2}$", "$12$", "$\\dfrac{25}{2}$"], "answer": "④", "answer_source": "답지" } }
}
```

## 확정 절차

1. 배치 md 의 쪽 이미지(`qa/p0NN.jpg`)를 열어 문항 배치를 본다.
2. 문항 크롭을 하나씩 읽어 body/choices/subs 를 전사한다(힌트 줄의 한글과 대조). 「N.」 이 id.
3. 답 크롭을 읽어 answer 를 적는다.
4. 배치 목록의 `figure` 를 옮겨 적고 크롭 파일을 한 번 열어 본다.
5. `node scripts/latex-bank/check-batch.mjs <out.json> --bank latex-bank/jeongui-1-2-mid` 로 컴파일 확인.
