- 문항 크롭: `output/problem-bank/ssen-basic-cm1/items/pbk_308b2f635f-<쪽>-<번호>.jpg` (220 dpi). 번호 배지가 크롭 안에 보이므로 **id 는 크롭 안의 배지 번호로 확정**한다(manifest 의 number_label 과 다르면 보고).
- 쪽 전체: `output/problem-bank/ssen-basic-cm1/qa/p0NN.jpg` (pdf 쪽 번호 = 인쇄 쪽 번호 · offset 0). 공통 지시문(말풍선 줄)·구역 제목·유형 라벨(「유형 016 제목」)·「꼭 나와요/서답형/서술형」 태그는 여기서 읽는다.
- 답: `output/problem-bank/ssen-basic-cm1/answers/<item_id>.jpg`(답 줄 크롭) · 해설 `solutions/<item_id>.jpg`. 답 크롭이 없거나 다른 문항 것이면 해설 크롭 또는 발문을 직접 풀어 `answer_source` 에 「해설」·「계산(…)」으로 적는다.
- 배치 목록의 ⚠ 표시(flagged)는 크롭 경계가 불확실한 문항이다 — 쪽 이미지에서 원문을 확인한다.

## items.json 구조 (여러 단원)

```json
{
  "book": "베이직쎈 공통수학1",
  "units": [
    { "code": "01", "title": "다항식의 연산", "pages": "8~24", "groups": [
      { "id": "U1-P1", "section": "개념 01 다항식의 정리", "passage": "다음 다항식을 $x$에 대하여 내림차순으로 정리하시오.", "items": ["8-01", "8-02"] },
      { "id": "U1-T1", "section": "유형 001 다항식의 정리", "items": ["19-01", "19-02"] },
      { "id": "U1-R1", "section": "실전 감각 UP", "items": ["23-01"] }
    ] }
  ],
  "items": { "8-01": { "body": "…", "answer": "…", "answer_source": "답지" } }
}
```

- 그룹 id: `U<단원>-P<n>`(개념 쪽 · 지시문 하나 = 그룹 하나 · 지시문 없는 개념 쪽 문항은 passage 없이 그룹) · `U<단원>-T<n>`(유형 · 라벨 하나 = 그룹 하나) · `U<단원>-R1`(실전 감각 UP). 배치 전사 때는 배치 이름을 접미로 붙인다(`U1-PA1`, `U1-TA1`).
- `section` 은 구역 제목 그대로: 「개념 NN 제목」(차례 기준 · 배치 목록 머리의 개념 목록) · 「유형 NNN 제목」 · 「실전 감각 UP」.
- 그룹 순서·문항 순서는 책 순서(쪽 → 왼쪽 컬럼 → 오른쪽 컬럼).
- 그룹에 공통 그림이 있으면 `figure` 를 그룹에 둔다.

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `body` | 발문 LaTeX(필수). 지시문은 body 에 넣지 않는다(그룹 passage). |
| `choices` | 5지선다 보기 5개(각각 `$…$`). `choices_layout`: 생략 = 3-2, `"ii"` = 2-2-1(분수처럼 키 큰 보기), `"v"` = 세로(긴 식). |
| `subs` | 소문항 `(1)(2)…` 본문 배열. |
| `hint` | 개념 쪽 「◎」 풀이 힌트(빈칸형). 줄바꿈은 `\\\\`, 빈칸은 `\blank`(넓은 빈칸 `\blank[2.4em]`). |
| `tag` | 「꼭 나와요」·「서답형」·「서술형」(배지 옆 표시가 있을 때만). |
| `figure` | `"tikz:fig-<id>"`(figures/fig-<id>.tex) 또는 `"crop:fig-<id>.jpg"`. 원문에 그림이 있을 때만. |
| `answer` | 답. 선택형은 `①`~`⑤`, 서답형은 LaTeX(`$…$`). 소문항은 `(1) … (2) …`, 힌트 빈칸형은 `답 (힌트 $…$, $…$)`. |
| `answer_source` | `"답지"` · `"해설"` · `"계산(답지 크롭 누락)"` 등 — 답을 어디서 확정했는지. |

## 표기 규약 (고1 공통수학1 · 다항식·방정식과 부등식·경우의 수·행렬)

- 다항식: `$x^3-2x^2+x-1$`, 내림차순·오름차순·몫·나머지는 한글 그대로. 조립제법 표는 별도 줄 `array` 로 적는다: `\par\smallskip\centerline{$\begin{array}{c|cccc} 2 & 1 & -3 & 0 & 5 \\ & & 2 & -2 & -4 \\ \hline & 1 & -1 & -2 & 1 \end{array}$}\par\smallskip\noindent` (빈칸은 `\blank`, 세로선은 첫 열 뒤 `|`). 항등식 `$x$에 대한 항등식`. 인수분해 결과 `$(x-1)(x+2)$`.
- 복소수: 허수단위 `$i$`, `$z=a+bi$`, 켤레복소수 `$\bar{z}$`, `$i^2=-1$`, 실수부분·허수부분 한글. 근호 `$\sqrt{-3}$`, `$\sqrt{2}\,i$`.
- 방정식·부등식: `$x^2-3x+2=0$`, 근과 계수의 관계 `$\alpha+\beta$`, `$\alpha\beta$`, 판별식 `$D$`, `$D/4$`. 연립은 `$\begin{cases} x+y=3 \\ xy=2 \end{cases}$`. 부등식 `$1<x\le 3$`(`\le`·`\ge`), 절댓값 `$|x-1|<2$`, 「해가 없다」 등 한글 그대로. 수직선 그림은 TikZ.
- 이차함수: `$y=x^2-2x+3$`, 꼭짓점·축·최댓값 한글, 그래프는 TikZ(축·곡선·교점 라벨만 · 답이 읽히지 않게). 「$x$축」 `$x$축`.
- 경우의 수: 순열 `${}_n\mathrm{P}_r$`, 조합 `${}_n\mathrm{C}_r$`, 팩토리얼 `$n!$`, 「서로 다른」「일렬로」 한글 그대로. 표·수형도는 TikZ 또는 `tabular`.
- 행렬: `$A=\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$`(본문·보기·답 모두 pmatrix), 단위행렬 `$E$`, 영행렬 `$O$`, 성분 `$a_{ij}$`, `$(i,\,j)$ 성분`, `$m\times n$ 행렬`.
- 분수 `\dfrac`(선택지·답·힌트 모두), 좌표 쉼표 뒤 `\,`. 「(단, …)」 → `\cond{…}`. 명사 + 기호는 `점~$\pt{P}$`(`~`). 본문 수식은 `$…$` 만(`$$`·`\[` 금지). 줄바꿈은 손으로 넣지 않는다. 원문의 별도 줄 식은 `\par\smallskip\centerline{$…$}\par\smallskip\noindent`.
- 보기 「ㄱ, ㄴ, ㄷ」 상자: body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건 ㈎㈏ 상자: `\exprbox{…}`. 범위 「㈎~㈑」「1~10」 의 물결은 `$\sim$`.
- 원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다.

## 그림

- 좌표평면·수직선·도형처럼 좌표가 주어진 그림은 TikZ 로 다시 그린다: `figures/fig-<id>.tex` (예: `latex-bank/ssen-basic-cm2/figures/fig-19-17.tex`). 규약 — 정점 2.2pt · 파생점 2pt, 축 0.7pt · 곡선/도형 0.5~0.6pt, 라벨은 선과 겹치지 않게 최소 이동, 축 라벨 `x`·`y` 는 화살표 옆, 눈금 표시 없음, **답이 그림에서 읽히지 않게**(원문에 없는 값을 적지 않는다). 첫 줄 주석에 「구역 id(본책 쪽) — 무엇 · TikZ 로 다시 그린 까닭」.
- 실생활 삽화·복잡한 도형 사진은 크롭: `node scripts/latex-bank/crop-figure.mjs --pdf "C:/Users/PC/Downloads/베이직쎈 공통수학1.pdf" --page <pdf쪽> --item <manifest bbox_normalized 네 값> --rel <문항 안 그림 비율> --out latex-bank/ssen-basic-cm1/figures/fig-<id>.jpg` → `figure: "crop:fig-<id>.jpg"`.
- 원문에 없는 그림은 넣지 않는다.

## 확정 절차

1. 페이지 qa 이미지로 구역·지시문·유형 라벨을 파악 → 그룹을 만든다.
2. 문항 크롭을 하나씩 읽어 body/choices/subs/hint/tag 를 전사한다. 배지 번호가 id 다.
3. 답 크롭을 읽어 answer 를 적고 answer_source 를 남긴다. 크롭이 없으면 해설 크롭 → 직접 풀어 「계산」.
4. `node scripts/latex-bank/check-batch.mjs <out-파일> --bank latex-bank/ssen-basic-cm1` 로 컴파일이 통과하는지 확인한다(xelatex 오류 = 전사 오류).
5. 확실치 않은 것(판독 불가·번호 불일치·답 불일치)은 `review_needed` 로 보고한다.
