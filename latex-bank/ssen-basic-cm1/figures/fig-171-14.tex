% 실전 감각 UP 171-14(본책 171쪽) — 평행한 직선 2개(왼쪽 아래로 비스듬)·2개(오른쪽 아래로 비스듬)·3개(가로, 아래쪽)가 서로 만나는 그림. 스캔 그림을 TikZ 로 다시 그림. 라벨·수치 없음.
\begin{tikzpicture}[scale=0.62, line width=0.55pt]
  % 왼쪽 위 → 오른쪽 아래 2개
  \draw (0.9,3.2) -- (3.4,-0.2);
  \draw (1.4,3.2) -- (3.9,-0.2);
  % 오른쪽 위 → 왼쪽 아래 2개
  \draw (2.6,3.2) -- (0.1,-0.2);
  \draw (3.1,3.2) -- (0.6,-0.2);
  % 가로 3개
  \foreach \y in {0.1,0.5,0.9} { \draw (-0.5,\y) -- (4.4,\y); }
\end{tikzpicture}
