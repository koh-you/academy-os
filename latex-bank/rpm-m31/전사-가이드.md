# RPM 중학 3-1 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-16. 베이직쎈 가이드(`latex-bank/ssen-basic-cm2/전사-가이드.md`)의 표기 규약을 그대로 쓰되, 이 책은 **텍스트 PDF** 라 다음이 다르다.

- **id 는 책 전체 번호 4자리**(`0001`~`1133`). 크롭 안 배지 번호가 id 다. items.json 은 `id_style: "number"` 이고 출처 배지는 「RPM 중학 3-1 0013번 · 9쪽」으로 찍힌다 → 문항마다 `page`(인쇄 쪽)를 적는다.
- **그림은 TikZ 로 그리지 않는다.** `prepare-text-pdf-bank.mjs` 가 벡터 그림을 300dpi 로 미리 크롭해 두었다(`figures/fig-<id>.png` · 그룹 그림 `figures/fig-g<시작>-<끝>.png`). 배치 목록에 적힌 `crop:fig-….png` 를 `figure` 에 그대로 쓴다. 크롭이 잘못됐으면(글자가 섞였거나 그림이 잘렸거나 그림이 없는데 크롭이 있거나) `figure` 를 빼거나 그대로 두고 **review_needed 에 적는다**(호출자가 다시 크롭한다).
- 배치 목록에 **글자 레이어 힌트**가 있다. 원문 글꼴 코드라 기호(`` ` ``·`'`·`ù`·`Ó`)가 어긋나지만 숫자·한글 문장은 정확하므로 크롭을 읽을 때 대조용으로 쓴다. `숨은 글자` 는 교사용 답이 흰 글자로 박힌 것이라 참고만 한다(답은 반드시 답 크롭으로 확정).

## 입력

- 문항 크롭 `…\rpm-공통수학1-수학\items\pbk_c9a59dba4b-<id>.jpg`, 공통 지시문 크롭 `items\pbk_c9a59dba4b-group-<시작>-<끝>-p<쪽>.jpg`, 쪽 전체 `qa\p0NN.jpg`.
- 답 `answers\pbk_c9a59dba4b-<id>.jpg`(「답」 줄 크롭) · 해설 `solutions\pbk_c9a59dba4b-<id>.jpg`. 644문항 전부 있다.

## items.json 구조

```json
{
  "book": "RPM 중학 3-1", "id_style": "number", "variant_level": 0,
  "units": [ { "code": "01", "title": "다항식의 연산", "pages": "7~19", "groups": [
      { "id": "U1-A1", "section": "교과서 01-1 다항식의 덧셈과 뺄셈", "passage": "다음을 계산하시오.", "items": ["0001", "0002"] },
      { "id": "U1-A2", "section": "교과서 01-1 다항식의 덧셈과 뺄셈", "items": ["0009"] },
      { "id": "U1-B1", "section": "유형 01 다항식의 덧셈과 뺄셈", "items": ["0040"] },
      { "id": "U1-C1", "section": "중단원 마무리하기", "items": ["0126"] }
  ] } ],
  "items": { "0001": { "page": 9, "body": "$(x^2+2x-1)+(3x^2-x+4)$", "answer": "$4x^2+x+3$", "answer_source": "답지" } }
}
```

- 그룹 id: `U<단원>-<배치이름><n>` (예 `U1-A1`, `U1-A2`, …). 배치 안에서 1부터. 병합할 때 겹치지 않게 배치 이름을 꼭 넣는다.
- 그룹 = 「공통 지시문 하나」 또는 「같은 구역에서 지시문 없이 이어지는 문항 묶음」. 지시문(`[0001~0006] …`)은 `passage` 에 대괄호 번호 없이 문장만 적고, 지시문에 딸린 그림은 그룹 `figure` 에 둔다. 그룹 순서·문항 순서는 책 순서(쪽 → 왼쪽 컬럼 → 오른쪽 컬럼).
- `section` (구역 제목):
  - 개념 쪽(「교과서 문제 정복하기」): `교과서 01-1 다항식의 덧셈과 뺄셈` (배치 목록의 유형 라벨 「01-1 …」 앞에 「교과서 」).
  - 유형 쪽(「유형 익히기」): `유형 09 원의 접선의 길이 (3)` — 쪽 이미지의 「유형 | 09」 번호와 제목을 그대로(배치 목록의 라벨은 번호가 없고 뒷글자가 잘려 있을 수 있다).
  - 그 밖의 구역(「시험에 꼭 나오는 문제」 「서술형 주관식」 「실력 Up」 등)은 쪽 머리띠 원문 그대로. 이 판은 「실력 Up」 표기이며 유형 쪽 머리띠는 「유형 | 09 제목」.

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽(배치 목록 「인쇄 N쪽」). 필수. |
| `body` | 발문 LaTeX. 지시문은 넣지 않는다(그룹 passage). 「오른쪽 그림에서/그림과 같이」 같은 문구는 원문대로 둔다. |
| `figure` | 배치 목록의 `crop:fig-<id>.png`. 원문에 그림·표·자료 상자가 있을 때만. 크롭이 **수식만 든 상자**(계산식 한 줄)이면 figure 로 쓰지 말고 그 수식을 body 끝에 `\exprbox{$…$}` 로 적는다(원문처럼 테두리 상자 · 변형 원본으로 쓰기 위해). |
| `figure_extra` | 배치 목록에 `fig-<id>-2.png` 같은 둘째 크롭이 있고 그것이 풀이 과정 상자·자료 표처럼 본문 아래 오는 것이면 여기에(`crop:fig-<id>-2.png`). 항상 본문 아래 가운데에 놓인다. 구역 머리띠(「서술형 주관식」 「실력 UP」)가 잘못 잡힌 크롭은 쓰지 않는다. |
| `figure_layout` | 생략 = 자동(크롭 폭 170pt 이하 오른쪽 · 넘으면 본문 아래). 원문과 다르게 놓이면 `"side"`/`"below"` 로 지정. |
| `choices` | 5지선다 보기(각 `$…$` 또는 문장). `choices_layout` 생략 = 3-2, `"ii"` = 2-2-1, `"v"` = 세로. 보기가 그림·그래프면 body 끝에 `\\par` 뒤 그림을 두고 review_needed. |
| `subs` | 소문항 `(1)(2)…` 배열. |
| `tag` | 「대표문제」·「서술형」·「중요」(번호 옆·위 표시가 있을 때만). 여러 개면 「대표문제 · 중요」. |
| `level` | 난이도 표시 「상」「중」「하」「중하」(번호 옆 회색 글자). 없으면 생략. |
| `answer` | 답 크롭 그대로. 선택형 `①`~`⑤`, 서답형 LaTeX(`$…$`), 단위 포함(`$8\,\mathrm{cm}^2$`), 소문항 `(1) … (2) …`. |
| `answer_source` | `"답지"`. 답 크롭이 다른 문항 것이면 직접 풀어 `"계산(답 크롭 불일치)"`. |

## 표기 규약 (중3-1 · 실수와 그 연산·다항식의 곱셈과 인수분해·이차방정식·이차함수)

- 제곱근·실수: `$\sqrt{2}$`, `$\sqrt{a^2}=|a|$`, `$-\sqrt{(-3)^2}$`, 유리화 `$\dfrac{\sqrt{2}}{2}$`, 제곱근표 값은 원문 그대로. 「$\sqrt{a}$의 값」 같은 한글은 수식 밖.
- 곱셈 공식·인수분해: `$(a+b)^2=a^2+2ab+b^2$`, `$x^2-4=(x+2)(x-2)$`, 「전개」「인수분해」 한글. 계산 과정 상자·빈칸 상자는 `\exprbox{…}`(빈칸 `\blank`).
- 이차방정식: `$x^2-3x+2=0$`, 근의 공식 `$x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$`, 중근·근의 개수 한글, 「두 근을 $\alpha$, $\beta$」.
- 이차함수: `$y=ax^2+bx+c$`, `$y=a(x-p)^2+q$`, 꼭짓점·축·최댓값·최솟값 한글, 그래프는 크롭 그림. 「$x$축」 `$x$축`, 「$y$절편」.
- 도형·단위: `$\seg{AB}$`, `$\angle\pt{A}$`, `$8\,\mathrm{cm}^2$`, 「점~$\pt{P}$」(`~`).
- 분수 `\dfrac`, 좌표 쉼표 뒤 `\,`. 「(단, …)」 → `\cond{…}`. 본문 수식은 `$…$` 만(`$$`·`\[` 금지). 줄바꿈은 손으로 넣지 않는다.
- 보기 「ㄱ, ㄴ, ㄷ」 상자: body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건 ㈎㈏ 상자: `\exprbox{…}`. 상자 크롭은 쓰지 않는다.
- 원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다. 문항 크롭에 회색 워터마크가 겹쳐 있어도 원문 글자만 전사한다.

## 확정 절차

1. 배치 md 의 쪽 이미지(`qa/p0NN.jpg`)로 구역(교과서/유형 NN/중단원 마무리하기/서술형 주관식/실력 UP)·지시문·태그·난이도를 파악해 그룹을 만든다.
2. 문항 크롭을 하나씩 읽어 body/choices/subs 를 전사한다(힌트 줄과 대조). 배지 번호가 id.
3. 답 크롭을 읽어 answer 를 적는다.
4. 배치 목록의 `figure` 를 옮겨 적는다. 크롭 파일(`figures/fig-<id>.png`)을 열어 원문 그림과 같은지 한 번 본다 — 글자가 섞였거나 잘렸으면 review_needed.
5. `node scripts/latex-bank/check-batch.mjs <out.json> --bank latex-bank/rpm-m31` 로 컴파일 확인.
