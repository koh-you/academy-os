글자 \fbox{A}를 어떤 비율로 확대 복사하여 큰 글자 \fbox{A}를 만들고, 확대한 \fbox{A}를 같은 비율로 확대 복사하여 더 큰 글자 \fbox{A}를 만들었다. 이와 같은 작업을 계속하였더니 $5$회째의 복사본의 글자 크기가 처음 원본의 글자 크기의 $2$배가 되었다. $8$회째의 복사본의 글자 크기가 $4$회째의 복사본의 글자 크기의 $2^{\frac{n}{m}}$배일 때, $m+n$의 값을 구하시오. \cond{$m$과 $n$은 서로소인 자연수이다.}
