### 배지 자릿수 — 07 명제·08 함수는 세 자리

- **01~06, 09, 10 단원**: 배지가 두 자리(`01`~`99`).
- **07 명제 · 08 함수**: 배지가 **처음부터 세 자리**(`001`, `002`, …, `100` 이상). 같은 번호 체계이고 자릿수만 다르다.
- id 뒷자리는 **자릿수가 아니라 숫자값**으로 적는다. 배지 `007` → id `88-07`. 배지 `019` → id `91-19`. 배지 `100` → id `124-100`.

## items.json 구조

```json
{
  "book": "쎈B 공통수학2", "source_package": "output/problem-bank/ssenb-cm2", "variant_level": 0,
  "units": [ { "code": "01", "title": "평면좌표", "pages": "7~15", "groups": [
      { "id": "U1-A1", "section": "유형 01 두 점 사이의 거리", "items": ["7-01", "7-02"] },
      { "id": "U1-A2", "section": "유형 02 같은 거리에 있는 점", "items": ["7-06"] }
  ] } ],
  "items": { "7-01": { "page": 7, "body": "…", "answer": "", "answer_source": "" } }
}
```

- 그룹 id: `U<단원>-<배치이름><n>` (예 `U1-A1`). 배치 안에서 1부터.
- 그룹 = 「유형 상자 하나」. 유형 상자의 설명 글(연한 바탕의 공식·해결 전략)은 전사하지 않는다 — `section` 제목만 쓴다.
- `section`: 유형 상자의 「유형 NN 제목」 그대로. 제목이 두 줄로 꺾여 있어도 한 줄로 잇는다.
- 그룹 순서·문항 순서는 책 순서(쪽 → 왼쪽 컬럼 → 오른쪽 컬럼).

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽. 필수. |
| `body` | 발문 LaTeX. 지시문은 넣지 않는다(그룹 `passage`). |
| `figure` | `"tikz:fig-<id>"` 또는 `"crop:fig-<id>.jpg"`. 원문에 그림·표가 있을 때만. |
| `figure_layout` | 생략 = 옆. 넓은 표·그래프는 `"below"`. |
| `choices` | 5지선다(각 `$…$`). `choices_layout` 생략 = 3-2, `"ii"` = 2-2-1, `"v"` = 세로. |
| `subs` | 소문항 `(1)(2)…`. |
| `tag` | 번호 옆 표시가 있을 때만 — 「대표 문제」「서술형」. 유형 상자 오른쪽의 「집중공략」은 그룹이 아니라 유형의 표시이므로 문항 `tag` 에 넣지 않는다. |
| `level` | 번호 오른쪽 난이도 점(`·⊜·`, `··⑧`, `⑨··` 등)이 있으면 원문 그대로. |
| `ssen_ref` | 오른쪽 위 「쎈 0016」 연계 번호. 있으면 숫자만(`"0016"`). |
| `answer` | **이 배치에서는 빈 문자열**. |
| `answer_source` | **빈 문자열**. |

## 표기 규약 (공통수학2 · 도형의 방정식·집합과 명제·함수)

- 점·좌표·선분: `점~$\pt{A}(1,\,2)$`, `$\seg{AB}$`, `$\seg{AB}^2$`, `직선~$l$`, 원점 `$\pt{O}$`. 각 `$\angle\pt{A}$`, 삼각형 `삼각형~$\pt{ABC}$` · 넓이 `$\triangle\pt{ABC}$`, 사각형 `$\square\pt{ABCD}$`. 단위는 `\mathrm`(`\,\mathrm{km}`).
- 직선·원·도형의 방정식은 원문 그대로: `$y=2x+1$`, `$x^2+y^2-2x=0$`, `$(x-1)^2+(y+2)^2=4$`. 「$x$축」「$y$절편」 은 `$x$축`·`$y$절편`. 평행이동 `$(x,\,y)\longrightarrow(x+2,\,y-3)$`, 대칭이동은 문장 그대로. 내분·외분은 한글 + `$1\,:\,3$`.
- 집합: `$A=\{1,\,2,\,3\}$`. 조건제시법의 한글은 수식 밖에 — `$\{x \mid x$는 $10$ 이하의 자연수$\}$`. `$\in$`, `$\notin$`, `$\subset$`, `$\not\subset$`, `$\cup$`, `$\cap$`, 여집합 `\comp{A}`(= `$A^{\mathrm{c}}$`), 전체집합 `$U$`, 공집합 `$\varnothing$`, 원소의 개수 `$n(A)$`, 차집합 `$A-B$`, 진부분집합은 한글.
- 명제: `$p\longrightarrow q$`, 부정 `$\sim p$`, 조건 `$p:\ x>1$`, 진리집합 `$P$`. 「$p$이면 $q$이다」·「모든」·「어떤」·역·대우·귀류법·충분조건·필요조건·필요충분조건은 **한글 원문 그대로**. 절대부등식·산술평균과 기하평균의 관계·코시-슈바르츠 부등식도 문장은 한글.
- 함수: `$f(x)=x^2-1$`, `$f:X\longrightarrow Y$`, 합성 `$(g\circ f)(x)$`, 역함수 `$f^{-1}(x)$`, 정의역·공역·치역·일대일대응·항등함수·상수함수는 한글. 유리함수 `$y=\dfrac{2x+1}{x-1}$`, 무리함수 `$y=\sqrt{2x-1}+3$`. 점근선은 한글 + `$x=1$`.
- 분수는 `\dfrac`(본문·보기·답 모두). 근호 `\sqrt{2}`. 절댓값 `$|x|$`. 가우스 `$[x]$`. 부등식 `$1<x\le 3$`(`\le`·`\ge`). 좌표 쉼표 뒤 `\,`.
- 「(단, …)」 → `\cond{…}`(괄호·「단,」은 매크로가 붙인다). 명사 + 기호는 `점~$\pt{P}$`(`~` = 안 끊는 공백). 본문 수식은 `$…$` 만(`$$`·`\[` 금지). 줄바꿈은 손으로 넣지 않는다. 원문의 별도 줄 식은 `\par\smallskip\centerline{$…$}\par\smallskip\noindent`.
- 보기 「ㄱ, ㄴ, ㄷ」 상자는 body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건 `(가)(나)` 상자는 `\exprbox{…}`. 범위 물결은 `$\sim$`. 연립은 `$\begin{cases} x+y=3 \\ xy=2 \end{cases}$`.
- **원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다.** 크롭에 워터마크가 겹쳐 있어도 원문 글자만 전사한다.

## 부록 — 이 패키지를 다시 만들 때

실제로 쓴 스크립트는 `scripts/problem-bank/ingest-scan-badges.mjs` 로 보존해 두었다(공용 스크립트 사본 + 아래 한 줄 수정 · import 는 절대 경로).

```
node scripts/problem-bank/ingest-scan-badges.mjs --pdf "C:/Users/PC/Desktop/교재 라텍스 조판/쎈B 공통수학2.pdf" \
  --out output/problem-bank/ssenb-cm2 \
  --title "쎈B 공통수학2" --folder "공통수학2" --grade 고1 --subject 수학 \
  --badge3 --no-green-type --page-offset 0 --pages 7-150 \
  --units "01 평면좌표,02 직선의 방정식,03 원의 방정식,04 도형의 이동,05 집합의 뜻과 표현,06 집합의 연산,07 명제,08 함수,09 유리식과 유리함수,10 무리식과 무리함수" \
  --unit-pages "7-15,16-29,30-45,46-59,60-71,72-85,86-105,106-125,126-139,140-150"
```

- `--page-offset 0` 이 없으면 쪽 머리의 「정답 및 풀이 N쪽」 을 인쇄 쪽으로 잘못 읽어 id 가 `1-02` 처럼 나온다.
- `--badge3` 는 07 명제·08 함수의 세 자리 배지 때문에 필요하다.
- **`--no-green-type` 은 `scripts/problem-bank/ingest-scan-badges.mjs` 의 옵션이다**(이 책 때문에 추가했다). 이 책의 II 집합과 명제(05·06·07)는 **문항 배지 글자가 초록(≈161,171,125 · 평균 152)**이라, 「평균 밝기 140 이상 초록 = 유형 라벨」 기본 규칙에 걸려 배지가 통째로 유형 라벨로 먹힌다(p91 은 문항 7개인데 검출 0개였다). 이 책의 진짜 유형 라벨은 색 알약 안 **흰 글자**라 OCR 에 잡히지 않으므로 `hasTagLeft` 만으로 충분하다. 주황(01~04)·파랑(08~10) 단원에서는 껐을 때와 켰을 때 결과가 **완전히 같았다**(p31–35 24개 동일, p108–112 22개 동일).
