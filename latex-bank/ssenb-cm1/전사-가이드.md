# 쎈B 공통수학1 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-26. **스캔 PDF**(글자 레이어 없음)이고, 문항 번호는 **중단원마다 01 부터 다시 시작**한다. 뒷단원은 `033` 처럼 세 자리로 찍힌다(같은 번호 체계 · 자릿수만 다름). id 는 `쪽-번호`(예 `12-33`)이고 items.json 은 `id_style` 을 쓰지 않는다(베이직쎈과 같은 방식). 출처 배지는 「쎈B 공통수학1 12쪽 33번」으로 찍히므로 문항마다 `page`(인쇄 쪽)를 적는다.

교재는 **쎈의 B단계 유형 학습서**다. 「유형 뽀개기」 구역이 본체이고, 유형 상자 바로 아래 「대표 문제」가 오고 그 뒤로 같은 유형의 문항이 이어진다.

## 입력

- 문항 크롭 `output/problem-bank/ssenb-cm1/items/pbk_c6485f4bd1-<쪽>-<번호>.jpg` (220 dpi).
- 쪽 전체 `output/problem-bank/ssenb-cm1/qa/pNNN.jpg` — 구역·유형 제목·태그·난이도·연계 쎈 번호는 **여기서** 읽는다. 문항 크롭만 보고 판단하지 않는다.
- 인쇄 쪽 = pdf 쪽 (offset 0).
- 답·해설은 이 배치에 없다. `answer` 는 **빈 문자열**로 두고 `answer_source: ""` 로 남긴다 — 답지(`2022개정_고1_공통수학1_쎈B_교재_해설_pdf파일_.pdf`)는 전사 뒤 별도 ingest 로 붙인다.

## 놓친 문항을 채운다 (중요)

스캔 검출기가 **「01 | 대표 문제」처럼 검은 상자 안 흰 숫자**를 못 읽어 크롭이 없는 문항이 있다. 배치 목록에 번호가 비어 있으면 **원본 PDF 쪽 렌더(`qa/pNNN.jpg`)에서 직접 전사해 넣는다.** 빠뜨리면 그대로 사라진다.

### 무엇이 참인가 — 배지 번호와 쎈 연계번호

**배치 목록·크롭 파일 이름의 번호를 믿지 말 것.** 구간에 따라 실제 배지와 어긋난다(예: 27~30쪽 크롭 66~88 = 실제 배지 69~97, 53쪽 크롭 67~71·29 = 실제 70~75). 검출기가 배지를 못 읽은 쪽에서 순번을 매겨 밀린 탓이다.

**id 의 뒷자리는 언제나 쪽 이미지에서 읽은 배지 번호다.** 크롭 파일 이름과 다르면 배지 번호를 쓰고 `review_needed` 에 「번호 불일치: 크롭 <파일번호> → 배지 <실제>」로 적는다.

**누락 판정은 「쎈 NNNN」 연계번호로 한다.** 이게 가장 확실한 기준이다 — 문항마다 오른쪽 위에 있고 책 전체에서 1씩 증가한다. 담당 쪽의 연계번호를 순서대로 적어 보고 **끊긴 자리가 있으면 그 자리에 문항이 있다**는 뜻이니 쪽 이미지에서 찾아 채운다. 앞 배치의 마지막 연계번호와도 이어지는지 본다.

### 문항이 아닌 쪽

대단원 표지(「II 방정식」 + 중단원 유형 목차)와 단원 첫 개념정리 쪽에는 문항이 없다. 검출기가 중단원 번호 상자를 문항으로 잡은 것이 섞여 있으니 전사하지 않고 `review_needed` 에 적는다.

## items.json 구조

```json
{
  "book": "쎈B 공통수학1", "variant_level": 0,
  "units": [ { "code": "01", "title": "다항식의 연산", "pages": "7~15", "groups": [
      { "id": "U1-A1", "section": "유형 01 다항식의 덧셈과 뺄셈", "items": ["7-01", "7-02"] },
      { "id": "U1-A2", "section": "유형 02 다항식의 곱셈", "passage": "다음 식을 전개하시오.", "items": ["8-05"] }
  ] } ],
  "items": { "7-01": { "page": 7, "body": "…", "answer": "", "answer_source": "" } }
}
```

- 그룹 id: `U<단원>-<배치이름><n>` (예 `U1-A1`). 배치 안에서 1부터.
- 그룹 = 「유형 상자 하나」 또는 「공통 지시문 하나」. 유형 상자의 설명 글(연한 바탕)은 전사하지 않는다 — `section` 제목만 쓴다.
- `section`: 유형 쪽은 유형 상자의 「유형 01 제목」 그대로. 그 밖(「실전 감각 UP」 등)은 쪽 머리띠 원문 그대로.

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽. 필수. |
| `body` | 발문 LaTeX. 지시문은 넣지 않는다(그룹 `passage`). |
| `figure` | `"tikz:fig-<id>"` 또는 `"crop:fig-<id>.jpg"`. 원문에 그림·표가 있을 때만. |
| `figure_layout` | 생략 = 옆. 넓은 표·그래프는 `"below"`. |
| `choices` | 5지선다(각 `$…$`). `choices_layout` 생략 = 3-2, `"ii"` = 2-2-1, `"v"` = 세로. |
| `subs` | 소문항 `(1)(2)…`. |
| `tag` | 번호 옆 표시가 있을 때만 — 「대표 문제」「서술형」「집중공략」. |
| `level` | 번호 오른쪽 난이도 점(`·⊜·` 등)이 있으면 원문 그대로. |
| `ssen_ref` | 오른쪽 위 「쎈 0072」 연계 번호. 있으면 숫자만(`"0072"`). |
| `answer` | **이 배치에서는 빈 문자열**. |
| `answer_source` | **빈 문자열**. |

## 표기 규약 (공통수학1 · 다항식·방정식과 부등식·경우의 수·행렬)

- 다항식: `$x^3-2x^2+x-1$`, 항등식 `$ax^2+bx+c=0$이 $x$에 대한 항등식`, 인수분해 `$(x-1)(x+2)$`. 조립제법 표는 크롭.
- 복소수: `$i$`, `$z=a+bi$`, 켤레복소수 `$\bar{z}$`, `$\sqrt{-3}$`, `$\sqrt{2}\,i$`. 실수부·허수부는 한글.
- 방정식·부등식: 근과 계수의 관계 `$\alpha+\beta$`·`$\alpha\beta$`, 판별식 `$D$`·`$D/4$`. 연립은 `$\begin{cases} x+y=3 \\ xy=2 \end{cases}$`. 부등식 `$1<x\le 3$`, 절댓값 `$|x-1|<2$`, 가우스 `$[x]$`.
- 이차함수: `$y=x^2-2x+3$`, 꼭짓점·축·최댓값은 한글, 그래프는 그림. 「$x$축」 `$x$축`.
- 경우의 수: `${}_n\mathrm{P}_r$`, `${}_n\mathrm{C}_r$`, `$n!$`. 「서로 다른」「일렬로」는 한글 그대로.
- 행렬: `$A=\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$`(본문·보기·답 모두 pmatrix), `$E$`·`$O$`·`$A^{-1}$`·`$a_{ij}$`·`$(i,\,j)$ 성분`.
- 분수 `\dfrac`, 좌표 쉼표 뒤 `\,`. 「(단, …)」 → `\cond{…}`. 명사 + 기호는 `점~$\pt{P}$`. 본문 수식은 `$…$` 만(`$$`·`\[` 금지). 줄바꿈은 손으로 넣지 않는다. 원문의 별도 줄 식은 `\par\smallskip\centerline{$…$}\par\smallskip\noindent`.
- 보기 「ㄱ, ㄴ, ㄷ」 상자는 body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건 상자는 `\exprbox{…}`. 범위 물결은 `$\sim$`.
- **원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다.** 크롭에 워터마크가 겹쳐 있어도 원문 글자만 전사한다.

## 그림

- 좌표평면·수직선·도형·그래프는 TikZ 로 다시 그린다(`figures/fig-<id>.tex`). 정점 2.2pt · 축 0.7pt · 곡선 0.5~0.6pt, 라벨은 원문 것만, **답이 그림에서 읽히지 않게**. 첫 줄 주석에 「<id>(쪽) — 무엇 · 다시 그린 까닭」.
- 실생활 삽화·사진은 크롭: `node scripts/latex-bank/crop-figure.mjs --pdf "C:/Users/PC/Desktop/교재 라텍스 조판/쎈b 공통수학1.pdf" --page <쪽> --item <manifest bbox_normalized> --rel <문항 안 비율> --out latex-bank/ssenb-cm1/figures/fig-<id>.jpg`.
- 원문에 없는 그림은 넣지 않는다.

## 확정 절차

1. 쪽 이미지(`qa/pNNN.jpg`)로 구역·유형 제목·태그·난이도를 파악해 그룹을 만든다.
2. 문항 크롭을 하나씩 읽어 `body`/`choices`/`subs` 를 전사한다. 배지 번호가 id 의 뒷자리.
3. **위 표의 「크롭 없는 번호」 중 담당 쪽에 있는 것을 쪽 이미지에서 찾아 채운다.**
4. `node scripts/latex-bank/check-batch.mjs <out.json> --bank latex-bank/ssenb-cm1` 로 컴파일 확인.
5. 확실치 않은 것은 `review_needed` 에 적는다. 답은 이 단계에서 채우지 않는다.
