## 번호가 다시 시작하는 자리 (이 책의 핵심)

| 자신감 UP! 기본&핵심 유형 | 첫 쪽에 「자신감 UP! 기본&핵심 유형」 띠, 각 유형 상자에 「유형 NNN 제목」 | 검정 두 자리 | **소단원마다** 01 부터 |
| 학교 시험 기출로 실전 감각 UP! | 「학교 시험 기출로 실전 감각 UP!」 띠 | 검정 두 자리 | **중단원마다** 01 부터 · 중단원 끝 |

그래서 **id 는 `쪽-번호`**(예 `12-45`, `22-09`)이고 `items.json` 에 `id_style` 은 쓰지 않는다(베이직쎈 공통수학1·2와 같다). 한 중단원 안에 같은 배지 번호가 여러 번 나오지만 쪽이 다르므로 id 는 겹치지 않는다.

책이 스스로 쓰는 이름은 「A단계」가 아니라 **1 기본기 탄탄!(쉬운 개념 학습 + 기본 문제 반복 훈련) → 2 기본기 쑥쑥!(기본·핵심 유형 집중 훈련) → 3 기본기 완성!(기출 문제로 실전 연습)** 이다(구성 안내 2~3쪽). 퀵테스트에서 말하는 **A단계 = 1단계의 「기본 문제」**(개념 쪽 번호 문항)다. 범위는 아래 「A단계 문항 범위」 표를 쓴다.

## 무엇이 참인가 — 배지 번호

**배치 목록·크롭 파일 이름의 번호를 믿지 말 것.** 검출기가 배지를 못 읽은 자리에서 순번이 밀릴 수 있다.

**id 의 뒷자리는 언제나 쪽 이미지에서 읽은 배지 번호다.** 크롭 파일 이름과 다르면 배지 번호를 쓰고 `review_needed` 에 「번호 불일치: 크롭 X → 배지 Y」로 적는다.

**누락 판정은 배지 번호의 연속성으로 한다.** 이 책에는 연계번호가 없으므로, 담당 쪽의 배지를 `01,02,03,…` 순서로 적어 보고 **끊긴 자리가 있으면 그 자리에 문항이 있다**는 뜻이니 쪽 이미지에서 찾아 채운다. 구역이 바뀌는 자리(개념→유형, 유형→실전, 소단원 경계)에서는 번호가 01 로 돌아가는 것이 정상이니 끊김으로 보지 않는다. 앞 배치의 마지막 번호와 이어지는지도 본다.

검출기가 놓치기 쉬운 것:
- 개념 쪽 왼쪽 컬럼 맨 위 문항(공통 지시문 바로 아래)과 쪽 맨 끝 문항.
- 「◎」 풀이 힌트(빈칸형)가 붙은 긴 문항 — 힌트 상자 때문에 경계가 흔들린다.
- 그림이 큰 문항.

## 문항이 아닌 쪽

**pdf/인쇄 7 · 43 · 106 · 107쪽은 문항이 없다.** 대단원 표지(43 · 107)는 중단원 목차의 두 자리 번호(`03`, `06`, `15` …)가 배지로 오검출되어 문항처럼 잡혀 있다. **전사하지 않고 `review_needed` 에 「대단원 표지 오검출」로 적는다.** 106쪽 「꿈향자」 칼럼도 같다. 개념 정리 부분(쪽 위 절반)만 있는 영역이 잡힌 것도 전사하지 않는다.

## items.json 구조 (여러 단원)

```json
{
  "book": "베이직쎈 미적분1",
  "source_package": "output/problem-bank/ssen-basic-calc1",
  "variant_level": 0,
  "units": [
    { "code": "01", "title": "함수의 극한", "pages": "8~29", "groups": [
      { "id": "U1-PA1", "section": "개념 01 $x \\to a$일 때 함수의 수렴", "passage": "함수 $y=f(x)$의 그래프가 아래 그림과 같을 때, 다음 극한값을 구하시오.", "items": ["8-01", "8-02", "8-03"] },
      { "id": "U1-TA1", "section": "유형 001 함수의 수렴과 발산", "items": ["13-01", "13-02"] },
      { "id": "U1-RA1", "section": "학교 시험 기출로 실전 감각 UP!", "items": ["27-01"] }
    ] }
  ],
  "items": { "8-01": { "page": 8, "body": "…", "answer": "", "answer_source": "" } }
}
```

- 그룹 id: `U<중단원>-P<배치><n>`(개념 쪽 · 공통 지시문 하나 = 그룹 하나 · 지시문 없는 개념 쪽 문항은 `passage` 없이 그룹) · `U<중단원>-T<배치><n>`(기본&핵심 유형 · 「유형 NNN」 라벨 하나 = 그룹 하나) · `U<중단원>-R<배치>1`(실전 감각 UP). 배치 이름을 접미로 넣어 병합 때 겹치지 않게 한다(`U1-PA1`, `U1-TB2`).
- `section` 은 구역 제목 그대로: 「개념 NN 제목」(부록의 개념 목록 · 쪽 왼쪽 위 상자) · 「유형 NNN 제목」(유형 상자 머리) · 「학교 시험 기출로 실전 감각 UP!」.
- 유형 상자의 설명 글(연한 바탕의 ①②③ 풀이 전략)은 전사하지 않는다 — `section` 제목만 쓴다.
- 그룹 순서·문항 순서는 책 순서(쪽 → 왼쪽 컬럼 → 오른쪽 컬럼).
- 그룹에 공통 그림이 있으면 `figure` 를 그룹에 둔다.

## 문항 필드

| 필드 | 뜻 |
|---|---|
| `page` | 인쇄 쪽(= pdf 쪽). 필수. |
| `body` | 발문 LaTeX(필수). 공통 지시문은 body 에 넣지 않는다(그룹 `passage`). |
| `choices` | 5지선다 보기 5개(각각 `$…$`). `choices_layout`: 생략 = 3-2, `"ii"` = 2-2-1(분수처럼 키 큰 보기), `"v"` = 세로(긴 식). |
| `subs` | 소문항 `(1)(2)…` 본문 배열. |
| `hint` | 개념 쪽 「◎」 풀이 힌트(빈칸형). 줄바꿈은 `\\\\`, 빈칸은 `\blank`(넓은 빈칸 `\blank[2.4em]`). |
| `tag` | 「꼭 나와요」·「서답형」·「서술형」(배지 옆·위 표시가 있을 때만). 여러 개면 「꼭 나와요 · 서술형」. |
| `figure` | `"tikz:fig-<id>"`(figures/fig-\<id\>.tex) 또는 `"crop:fig-<id>.jpg"`. 원문에 그림·표가 있을 때만. |
| `figure_layout` | 생략 = 옆. 넓은 표·그래프는 `"below"`. |
| `answer` | **이 단계에서는 빈 문자열.** |
| `answer_source` | **빈 문자열.** |

「서답형」은 실전 감각 UP 구역 안의 띠 제목이기도 하다(그 아래 문항은 모두 서답형). 띠 아래 문항에는 `tag` 를 붙이되 띠 자체를 문항으로 전사하지 않는다.

## 표기 규약 (고2 미적분Ⅰ · 함수의 극한과 연속 · 다항함수의 미분법 · 다항함수의 적분법)

- 극한: `$\displaystyle\lim_{x\to 2} f(x)$`(`\displaystyle` 를 붙여 아래첨자가 아래로), `$x\to 0+$` · `$x\to 0-$`(원문은 `x → 0+`), `$x\to\infty$`, `$x\to-\infty$`, `$\infty$`. 「$f(x)$가 $x=1$에서 연속」·좌극한·우극한·수렴·발산은 한글 그대로.
- 극한 계산: `$\dfrac{0}{0}$ 꼴`, `$\dfrac{\infty}{\infty}$ 꼴`, `$\infty-\infty$`, `$\infty\times 0$` 꼴 — 원문 표기를 그대로 옮긴다. 미정계수 `$a$`, `$b$` 는 그대로.
- 연속: 구간 `$[a,\,b]$`·`$(a,\,b)$`·`$[a,\,b)$`, 「닫힌구간 $[-1,\,4]$」처럼 한글 + 구간. 최대·최소 정리, 사잇값 정리는 한글.
- 미분: `$f'(x)$`, `$f'(a)$`, `$\dfrac{dy}{dx}$`, `$y'$`, 평균변화율 `$\dfrac{\Delta y}{\Delta x}$`, 증분 `$\Delta x$`. 미분계수·도함수·접선의 기울기·미분가능·증가·감소·극대·극소·극값·변곡은 한글. 「$f'(x)=0$」 그대로. 속도·가속도 `$v(t)$`, `$a(t)$`.
- 적분: `$\displaystyle\int f(x)\,dx$`, `$\displaystyle\int_{0}^{1} x^2\,dx$`(적분변수 앞 `\,`), `$\displaystyle\int_{-a}^{a} x^n\,dx$`, 적분상수 `$C$`, `$F(x)$`, `$\dfrac{d}{dx}$`. 부정적분·정적분·피적분함수·적분 구간·넓이·거리는 한글.
- 함수·그래프: `$f(x)=x^3-3x$`, 「$x$축」 `$x$축`, 「$y=f(x)$의 그래프」, 절댓값 `$|x|$`, 가우스 `$[x]$`, 무리함수 `$\sqrt{x}$`. 구간별 정의 함수는 `$f(x)=\begin{cases} x & (x\ne 1) \\ -1 & (x=1) \end{cases}$`(원문의 괄호 조건 그대로).
- 도형·단위: `$\seg{AB}$`, `$\angle\pt{A}$`, `삼각형~$\pt{ABC}$`, `$8\,\mathrm{cm}$`, `$16\,\mathrm{m/s}$`, `$t$초`. 「점~$\pt{P}$」처럼 명사 + 기호는 `~`(안 끊는 공백).
- 분수는 `\dfrac`(선택지·답·힌트 모두). 좌표 쉼표 뒤 `\,`: `$(3,\,-1)$`. 「(단, …)」 → `\cond{…}`. 본문 수식은 `$…$` 만(`$$`·`\[` 금지). 줄바꿈은 손으로 넣지 않는다. 원문의 별도 줄 식은 `\par\smallskip\centerline{$…$}\par\smallskip\noindent`.
- 보기 「ㄱ, ㄴ, ㄷ」 상자: body 끝에 `\bogi{ㄱ. …\\ ㄴ. …\\ ㄷ. …}`. 조건 ㈎㈏㈐ 상자: `\exprbox{…}`. 범위 「㈎~㈐」·「1~10」 의 물결은 `$\sim$`.
- 빈칸 □ 는 `\blank`. 개념 쪽 「◎」 힌트의 빈칸도 같다.
- **원문의 수치·조건·보기 순서·소문항 수를 바꾸지 않는다.** 크롭에 워터마크·스캔 얼룩이 겹쳐 있어도 원문 글자만 전사한다.

## 확정 절차

1. 쪽 이미지(`qa/pNNN.jpg`)로 구역(개념 / 기본&핵심 유형 / 실전 감각 UP)·개념 제목·유형 라벨·공통 지시문·태그를 파악해 그룹을 만든다.
2. 문항 크롭을 하나씩 읽어 `body`/`choices`/`subs`/`hint`/`tag` 를 전사한다. **배지 번호가 id 의 뒷자리.**
