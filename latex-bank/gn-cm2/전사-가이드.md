# 개념원리 공통수학2 · LaTeX 전사 가이드 (items.json 작성 규약)

확인일: 2026-09-21. RPM 가이드(`latex-bank/rpm-cm2/전사-가이드.md`)의 **표기 규약(도형의 방정식·집합과 명제·함수)·문항 필드·확정 절차를 그대로** 쓴다. 이 책은 **개념서(고등 개념원리)** 라 다음이 다르다.

## id 와 문항 종류

id 는 **「인쇄 쪽-번호」**. 배치 목록의 id 가 그대로 id 다(크롭 배지 번호와 대조). items.json 은 `id_style: "page-number"`.

| id | 종류 | 출처 배지 | 전사 범위 |
| --- | --- | --- | --- |
| `12-1` · `34-456` | **통번호 문항**(책 전체에서 이어지는 번호): 개념원리 익히기 · 확인체크 · 연습문제(STEP 1 · STEP 2 · 실력 UP) | 「개념원리 공통수학2 12쪽 1번」 | 문항 전체 |
| `13-e1` | **필수·발전 예제**(중단원마다 01부터 · 상자 안 발문 + 설명·풀이·KEY Point 딸림) | 「… 13쪽 예제 1」 | **상자 안 발문만**(「설명」·풀이·답·KEY Point 는 넣지 않는다) |

- 문항마다 `page`(인쇄 쪽 = id 앞부분)를 적는다. 배치 목록의 「인쇄 N쪽」과 쪽 이미지 바닥글 번호가 같은지 본다.
- `tag`: 예제는 「필수」/「발전」(배지 색 · 배치 목록 태그), 연습문제의 「교육청 기출」(번호 위 작은 배지), 예제 아래 「확인체크」(배치 목록 태그 · 번호 왼쪽 파란 배지). `level` 은 연습문제의 띠 「STEP 1」/「STEP 2」/「실력 UP」(쪽 이미지 기준).
- **구역(section)** 은 배치 목록의 구역 이름: `개념원리 익히기` · `필수·발전 예제` · `연습문제` · `특강`. 연습문제는 쪽 이미지의 띠를 붙여 `연습문제 STEP 1` · `연습문제 STEP 2` · `연습문제 실력 UP`. 예제는 상자 제목 띠의 유형 이름(「다항식의 전개식에서 계수 구하기」)을 `type` 에 적는다. `특강` 구역은 「특강 01」(초록 번호) 예제(배치 목록 태그 「특강」 → `tag: "특강"` · 발문만)와 그 아래 확인체크(통번호)가 문항이다(번호 없는 「예제 ▸」 특강은 전사하지 않는다).
- 예제 크롭은 상자 오른쪽 끝까지 담는다 — 상자 제목 띠 오른쪽의 작은 회색 글 「더 다양한 문제는 RPM … N쪽」과 QR 은 문항이 아니므로 옮기지 않는다. 오른쪽에 그림이 있으면 배치 목록의 `crop:fig-…` 를 쓴다.
- 이 책은 **윤곽선 PDF(글자 레이어 없음)** 라 힌트 줄이 OCR 결과다 — 한글·숫자도 틀릴 수 있으니 반드시 크롭을 읽어 전사하고 힌트는 참고만 한다. 연습문제 오른쪽 여백 「생각해 봅시다!」 힌트는 옮기지 않는다.
- 답: 통번호 문항의 답은 본책 끝 「빠른 정답 찾기」 항목 크롭(`answers/<id>.jpg` · `answer_source: "답지"`) — 크롭에 이웃 번호의 답이 함께 보일 수 있으니 **자기 번호의 것만** 읽는다. 예제의 답은 풀이 블록 크롭(`answers/<id>.jpg` · 풀이 끝의 굵은 값 또는 「따라서 …」 결론 · `"본문 풀이"`). 크롭이 없거나 잘렸으면 빠른 정답 쪽 렌더(`qa/answers-pNNN.jpg`)에서 찾아 `"답지(쪽 렌더)"`, 그래도 없으면 직접 풀어 `"계산"`.
- 소문항 ⑴⑵⑶ 은 `subs` 배열(원문 「⑴」은 `\dmsubprob` 가 붙이므로 본문에서는 뺀다). 빈칸 □ 는 `\blank`. 조건 상자 ㈎㈏ 는 `\exprbox{…}`, 보기 ㄱㄴㄷ 은 `\bogi{ㄱ. …\\ ㄴ. …}`.
- **그림은 TikZ 로 그리지 않는다.** `prepare-text-pdf-bank.mjs` 가 벡터 그림을 300dpi 로 크롭해 두었다(`figures/fig-<id>.png`). 배치 목록의 `crop:fig-….png` 를 `figure` 에 쓴다. 번호 배지·제목 띠·QR·보기 상자·수식 조각만 든 크롭은 쓰지 않고 review_needed 에 적는다. 그림이 있는데 크롭이 없으면 review_needed 「크롭 필요」.
- 힌트 줄(글자 레이어)은 한글·숫자만 정확하고 수식은 글꼴 코드라 어긋난다 — 수식은 크롭을 읽어 전사한다.
- 「특강」 쪽과 개념 설명 쪽은 이 은행에 없다(배치 목록에 없으면 전사하지 않는다).

## items.json 구조

```json
{
  "book": "개념원리 공통수학2", "id_style": "page-number", "variant_level": 0,
  "units": [ { "code": "01", "title": "다항식의 덧셈과 뺄셈", "pages": "10~13", "groups": [
      { "id": "U1-A1", "section": "개념원리 익히기", "items": ["12-1", "12-2", "12-3"] },
      { "id": "U1-A2", "section": "필수·발전 예제", "items": ["13-e1", "13-4", "13-5", "13-e2", "13-6"] }
  ] } ],
  "items": {
    "12-1": { "page": 12, "body": "다음 두 다항식 $A$, $B$에 대하여 $A+B$, $A-B$를 계산하시오.", "subs": ["$A=…$, $B=…$", "…"], "answer": "⑴ $…$ ⑵ $…$", "answer_source": "답지" },
    "13-e1": { "page": 13, "type": "다항식의 덧셈과 뺄셈", "tag": "필수", "body": "세 다항식 …", "answer": "$…$", "answer_source": "본문 풀이" },
    "13-4": { "page": 13, "tag": "확인체크", "body": "…", "answer": "$…$", "answer_source": "답지" },
    "33-47": { "page": 33, "tag": "교육청 기출", "level": "STEP 1", "body": "…", "choices": ["$…$", "$…$", "$…$", "$…$", "$…$"], "answer": "①", "answer_source": "답지" }
  }
}
```

- 그룹은 「같은 쪽 · 같은 구역」 묶음(예제와 그 아래 확인체크는 같은 그룹). 그룹 순서·문항 순서는 책 순서(쪽 → 위에서 아래). 그룹 id 접두는 `U{UNIT_NO}-{BATCH}`.

## 확정 절차

1. 배치 md 의 쪽 이미지(`qa/pNNN.jpg`)를 열어 구역·STEP 띠·문항 종류(예제 상자 · 확인체크 · 통번호)를 파악한다.
2. 문항 크롭을 하나씩 읽어 body/choices/subs 를 전사한다(힌트 줄과 대조). 예제는 발문만.
3. 답 크롭(`answers/<id>.jpg`)으로 answer 를 적는다.
4. 배치 목록의 `figure` 를 옮겨 적고 크롭 파일을 한 번 열어 본다.
5. `node scripts/latex-bank/check-batch.mjs <out.json> --bank latex-bank/gn-cm2` 로 컴파일 확인.
