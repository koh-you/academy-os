## 조사 범위와 한계

교육·입시정보는 대입분석, 모집요강, 중학교, 고등학교, 교육정보 카테고리를 묶었다. 여기의 ‘모집요강’은 대학·학교 입시정보이며 학원 신규 반 모집과 구분했다. 같은 글의 다양한 목적을 한 숫자로 완전히 표현할 수 없으므로 원래 카테고리도 함께 보아야 한다.

관찰한 구성은 여섯 가지다.

1. **교육·입시정보:** 입시 일정, 전형 변화, 대학별 모집과 학교 선택 정보를 제공한다. 실제 시행 연도와 공식 출처 확인이 필요한 유형이다.
2. **학교별 시험 분석:** 학교·학년·학기·시험을 제목에 넣고 범위, 문항 구성, 출제 특징과 준비 방향을 설명한다. [중계중 최근 3년 비교 사례](https://blog.naver.com/skills_in_math2/224400925807)는 연도별 시험 구성에서 학습 방향으로 이어지는 구조다. 본문에 적힌 시험 수치 자체를 이번 조사에서 원본 시험지와 대조한 것은 아니다.
3. **학습성과·학생 후기:** 결과와 과정의 증거를 보여준다. [학생 후기 사례](https://blog.naver.com/skills_in_math2/223892362587)는 시험 준비에서 도움된 점, 학습 변화, 다음 목표를 질문과 답으로 구성한다. [시험 실적 사례](https://blog.naver.com/skills_in_math2/223206066075)는 성과 소개용이다.
4. **수업·학습관리:** 수업 흐름과 공부 습관을 설명한다. [순공랭킹 사례](https://blog.naver.com/skills_in_math2/224000502622)는 공부 시간 기록에서 자습 환경과 학습 루틴으로 이어진다. 다른 학원의 학생 수치나 사례를 우리 학원의 사례로 전용해서는 안 된다.
5. **모집·개강:** 학기와 방학에 맞춰 대상, 과정, 시간표, 상담 정보를 제시한다. [세션 개강 사례](https://blog.naver.com/skills_in_math2/224385549364)는 중등·고등 대상별 학습 필요와 수업 정보를 연결한다.
6. **이벤트·학원 생활:** 학습 동기와 참여를 만드는 공지다. [개념노트 경진대회 사례](https://blog.naver.com/skills_in_math2/224207028059)는 취지, 대상, 제출물, 평가·진행 방식, 시상을 순서대로 제시한다.

최근에는 2026년 6월 39개, 7월 33개, 8월 31개, 9월 1~4일 6개다. 특히 8월에는 서로 다른 31일에 매일 한 편씩 발행했다. 이는 일정한 제작 주기를 운영한다는 근거이지만, 자동 예약이나 AI 사용의 증거는 아니다.

## 으뜸수학 고태영T에 적용할 제작 방식

**OS에서 사실을 확정하고, Chat에서 채널별 문장을 다듬은 뒤 OS에 완성본을 저장**하는 현재 방식이 맞다. 자동화할 부분은 자료 배열, 초안 지시문, 태그 추천, 채널별 변환이다. 학생의 실제 변화와 시험 분석의 근거는 선생님이 확인한 원천에서 가져와야 한다.

| 반복 유형 | OS에 입력할 자료 | 블로그 구성 | 인스타그램 구성 |
| --- | --- | --- | --- |
| 명예의 전당 | 학교·학년·시험·확인 성과·준비 과정·공개 동의 | 성과 → 준비 과정 → 선생님 관찰 → 다음 목표 | 핵심 성과 또는 노력 한 줄 → 과정 2~3문장 → 응원 |
| 학교별 시험 분석 | 시험 원본·범위·문항 구성·검증한 특징 | 기본 정보 → 주요 유형 → 준비 제안 | 카드별 핵심 3가지 + 짧은 캡션 |
| 수업 소개 | 수업일지·학습 목표·실제 활동·사용 가능한 사진 | 학습 문제 → 수업 과정 → 관찰한 변화 | 현장 장면 하나 → 설명 → 상담 안내 |
| 학습 성장 기록 | 과제·오답·자습 등 검증 가능한 기록 | 처음의 어려움 → 달라진 행동 → 다음 계획 | 전후 행동 변화 중심 |
| 개강 안내(후속 템플릿) | 실제 대상·요일·시간·기간·문의처 | 대상 → 과정 → 일정 → 신청 안내 | 대상과 일정 중심 공지 |
| 교육정보(후속 템플릿) | 공식 원문 URL·적용 연도·확인일 | 바뀐 점 → 해당 학생 → 준비할 것 | 핵심 변경 3개 + 출처 |

처음에는 **주 3회**를 운영안으로 제안한다. 월요일 수업·학습관리, 수요일 학교별 시험 분석, 금요일 성과·성장 기록을 배치하고, 개강이나 시험 일정이 있으면 해당 회차를 교체한다. 이것은 경쟁사의 성과로 검증된 횟수가 아니라 선생님이 유지할 수 있는 시작안이다. 소재 하나로 블로그 본문과 인스타그램 캡션·카드 문구를 동시에 만든다.

## 이번 구현 범위

- 화면과 메뉴를 SNS 콘텐츠 스튜디오로 변경.
- 기존 SNS 문구를 인스타그램 캡션으로 명확히 표시. Chat 전달문에 블로그 본문과 인스타그램의 첫 줄·짧은 문단·마무리 문장을 구분해 요청.
- 학교·지역·과목·학년·유형에서 태그를 자동 추천. 지역 기본값은 창동이며 직접 변경·비우기 가능. 학생 이름·점수·등급은 태그 생성에 사용하지 않음.
- 블로그 태그와 인스타그램 태그를 별도 편집·저장. 인스타그램 추천은 관련성 중심으로 최대 5개로 정한 제품 기본값이며 플랫폼 정책의 보증은 아님.
- 입력이 바뀌면 추천만 갱신. 사람이 편집한 확정 내용은 반영 버튼 없이 자동으로 바꾸지 않음.
- 기존 저장 키와 캡션 필드를 유지해 과거 자료와 호환. 새 필드가 없는 과거 글도 열 수 있음.
- 자동 발행·이미지 생성·정기 예약·새 교육정보 수집은 이번 범위에 포함되지 않음. 발행 URL 기록은 기존 네이버 게시물용이며 인스타그램 글은 캡션과 태그를 복사해 발행.
