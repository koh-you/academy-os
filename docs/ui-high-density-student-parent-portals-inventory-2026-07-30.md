# UI-8J 학생·학부모 포털 inventory — 2026-07-30

## 범위와 금지선

- 대상: 학생 포털과 학부모 포털의 계정 머리말, 탭, 읽기 카드, 학생 쓰기 카드, 시험 후 제출, 자료·리포트, 모바일 화면이다.
- 이번 UI 묶음은 표시 shell과 접근성만 다룬다.
- 숙제 완료, 질문 추가·상태 변경·삭제, 시험 후 제출, 파일 선택·업로드·열기, 로그아웃을 실행하지 않는다. Supabase `homeworks`·`app_state`·Storage와 외부 알림 원천도 변경하거나 호출하지 않는다.

## 현재 공통 기반

- 학생·학부모 상위 메뉴와 마이페이지 하위 메뉴는 공통 `WorkspaceTabs` 기반 `PortalTabBar`를 사용한다.
- 읽기 카드는 `ListCard`, 빈 상태는 `EmptyState`, 학생 쓰기 결과는 `InlineSaveStatus`, 성적 표는 이름 있는 `DataTableShell`을 사용한다.
- 1100px 이하에서 수업 기록을 한 열로 바꾸고, 767px 이하에서 머리말·계정 행동·지표·질문·시험 후 제출을 한 열로 바꾸는 모바일 규칙이 이미 있다.
- 학생 쓰기는 `writeEnabled`가 실제 학생 세션에서만 열리며 교사 미리보기에서는 비활성 안내를 표시한다.

## 확인된 표시·모바일 예외

1. 교사 미리보기 머리말에 같은 `onLogout`을 쓰는 `관리 화면으로`와 `로그아웃`이 함께 보이며 계정 행동의 의미가 중복된다.
2. 실제 학생 데이터는 한 명으로 서버 범위가 제한되지만 학생 선택 control이 항상 보여 모바일 머리말을 불필요하게 길게 만든다.
3. 수업 기록 미니 달력은 날짜 button을 제공하지만 달력 이름·grid/columnheader/gridcell 의미가 없다.
4. 자료·리포트·수업 코멘트·시험 파일명처럼 외부 또는 교사 입력에서 오는 긴 문자열의 카드 내부 줄바꿈 경계가 화면별로 일정하지 않다.
5. 숙제 행동·질문 행동·시험 후 제출은 이미 저장 상태와 disabled 계약을 갖췄다. 남은 작업은 모바일에서 행동 폭, 긴 상태·파일명, 입력 그룹 간격을 맞추는 표시 보강으로 제한한다.
6. 위 예외는 저장 계약을 바꾸지 않고 해결할 수 있다. 실제 학생 쓰기나 Storage 호출을 눌러야만 확인할 수 있는 항목은 이번 연쇄 구현의 필수 gate가 아니다.

## 연쇄 구현

1. `UI-8J-1`: 학생·학부모 계정 머리말과 수업 기록 달력의 맥락·접근성을 정리하고 읽기 카드의 긴 내용 줄바꿈을 보강한다.
2. `UI-8J-2`: 숙제·질문·시험 후 제출의 모바일 행동·상태·파일명 배치를 정리하고 기존 저장/preview/실패 계약을 보존한다.
3. `UI-8J-3`: 계정·읽기·쓰기 shell과 bearer·Supabase·Storage 경계를 통합 회귀하고 독립 사람 시각 절차를 누적한다.

## 사람 검수

inventory 자체에는 사람 gate가 없다. 구현 뒤 실제 저장 없이 교사 미리보기와 학부모 포털을 desktop/390px에서 탐색하고, 학생 실제 화면은 입력·파일·완료·질문 행동을 누르지 않은 채 계정 머리말·탭·기존 읽기 자료와 빈 상태만 본다. 실제 학생 쓰기는 사용자가 필요할 때 별도 작업으로 새로 시작한다.

## 진행 갱신

- UI-8J-1: 교사 미리보기에서는 `관리 화면으로`만, 실제 학생 화면에서는 날짜와 `로그아웃`만 기본 표시하며 학생 선택은 실제로 둘 이상 전달될 때만 보이게 했다.
- 학부모·학생 계정 행동에 이름과 group 의미를 부여했고 로그아웃·학생 선택 callback은 기존 경로를 유지했다.
- 수업 기록 미니 달력에 학생 이름, grid·요일·날짜·선택 의미와 keyboard focus를 추가했다. 날짜 선택은 기존 local state만 바꾼다.
- 자료·리포트·수업 기록·숙제 읽기 카드의 긴 교사/외부 문자열을 카드 내부에서 줄바꿈하고, 모바일 자료 링크 행동을 한 열 전체 폭으로 정리했다.
