## 1. 총평

구조는 이미 잡혀 있었다 — 공용 컴포넌트 20여 개, 버튼 6종 규칙, 행 액션 규칙 R1~R6, 모달 셸 잠금. 문제는 **규칙이 화면마다 다르게 적용된 것**이었다: 같은 저장 상태를 4가지 문구로, 같은 파괴 행동을 3가지 확인 방식(window.confirm / 전용 모달 / 없음)으로, 같은 계층의 탭을 두 variant 로. 정말 위험한 것(P0)은 알림관리 공지 즉시 발송 1곳뿐이었고, P1 의 대부분은 "확인 없는 파괴 행동", "저장 안 한 초안의 조용한 소실", "저장 실패 메시지가 모달 뒤에 숨음" 세 유형이었다. 태블릿(641~1100px)에서는 사이드바가 본문 위 865px 블록이 되어 사실상 쓸 수 없었다.
