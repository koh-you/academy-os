# 공통 답안지 채점 실험

## 첫 사용

1. 시험지관리 → 채점 실험 → 공통 답안지 PDF를 내려받아 A4 원본 크기로 출력한다.
2. 같은 양식에 선생님 정답 1장과 학생 답안을 작성한다. 객관식은 번호, 단답형은 최종 답을 쓴다. 사용하지 않는 번호는 비운다.
3. 정답지 PDF/JPG/PNG를 올린다. 원본을 보며 직접 입력하거나 ‘선택한 답안 AI 판독 (유료)’를 누른다. 파일 업로드만으로 유료 호출하지 않는다.
4. 정답을 원본과 대조한 뒤 ‘정답 확정’을 누른다. 빈 정답은 채점 대상에서 제외한다.
5. 학생 답안을 올리고 페이지별 이름을 확인한다. PDF는 최대 10쪽이며 한 쪽이 한 명의 고정 20문항 답안이다. 실험당 최대 30장, 입력 파일은 15MB 이하.
6. 판독 초안을 확인·수정하고 각 답의 ‘원본 확인’을 체크한다. 전사 수정은 해당 확인과 수동 판정을 해제한다. 분수·소수 동치 허용 변경 또는 정답 수정 뒤에는 정답을 다시 확정한다.
7. 다른 모양의 수식은 확인 필요로 남는다. 교사가 정답/오답을 선택할 수 있다. 풀이 과정·서술형 부분점수는 이 실험에 포함하지 않는다.
8. 화면을 떠나기 전에 ‘실험 파일 내려받기’를 누른다. 원본 이미지·정답·답안·확인 상태를 JSON 파일로 내려받으며 ‘다시 열기’로 복원한다. 서버 성적 저장이 아니며 다른 기기 자동 동기화는 없다.

정답지도 손글씨 판독 오류가 있으므로 먼저 확정한다. 학생의 모든 답을 대조해야 인식기가 확신하며 틀린 경우도 발견할 수 있다. 결과는 공식 성적·알림·재시험에 반영하지 않는다. QR 자동 배분·오답지 출력은 후속 단계다.

## 유료 판독 경계

- 원장 인증과 명시적 실행 확인이 있어야 선택한 한 쪽만 외부 AI로 전송한다. 기본 공급자는 기존 서버의 Anthropic, 없으면 OpenAI 설정을 사용한다.
- 자동 호출·자동 재시도 없음. 진행 중 중복 실행 차단. 응답을 못 받으면 비용 발생 여부를 단정하지 않는다.
- API/화면 검증에는 주입한 가상 응답만 사용했다. 실제 필체 인식률·한국어 및 수식 정확도·실제 호출 비용은 미검증이며 사람 승인 후 시험해야 한다.
- 원본은 브라우저에서 읽고 판독 요청 시에만 서버를 경유한다. 이 기능은 Supabase/Storage에 원본·결과를 저장하지 않는다.

## 남겨둔 스캔 확인 — TASKalfa 4012i

상태: 스캔 기능은 있으나 과거 전송 실패. 데스크탑과 유선망 연결. 설정 및 실제 전송 확인 대기.

1. 데스크탑에 고정 폴더(예: `C:\AcademyScan`)를 만들고 스캔 계정에 공유·파일 쓰기 권한을 준다.
2. 복합기에 컴퓨터 주소, 공유 이름, 사용자 계정을 저장 대상으로 등록한다. 실패 시 오류 코드로 주소·계정·권한·방화벽을 좁힌다. 방화벽 전체 해제나 무암호 전체 공유로 우회하지 않는다.
3. PC를 켜두고 절전 해제 상태에서 시험용 종이 한 장을 전송한다. 자동급지·양면 가능 여부도 실물에서 확인한다.
4. 초기 설정: 300dpi·회색조·일반 PDF, 원본에 맞는 단면/양면, 빈 페이지 자동 삭제 끔. 스테이플 제거 후 급지한다.
5. 여러 장을 PDF로 저장하고 장수·순서·앞뒷면·연필 선명도·잘림을 확인한다. 필요하면 컬러/높은 해상도와 비교한다.
6. 성공 설정을 ‘시험 답안’으로 등록한다. 공유폴더가 준비되지 않으면 USB로 전송을 우선 확인한다.
7. 현재는 파일을 OS에 직접 올린다. 폴더 감시·자동 업로드 프로그램은 아직 구현하지 않았다.
