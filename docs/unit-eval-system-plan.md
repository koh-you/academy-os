## 0. 목표

1. 학생 단원별 평가 시험지를 **미리 만들어 파일로 고정**하고, 여러 학생·여러 시점에 그대로 재사용한다.
2. 시험지를 OS 프로그램에 목록으로 등록하고, 학생 테스트(데일리/단원)를 진행한다.
3. 테스트 결과를 토대로 점수·재시험 여부·재시험 일정을 알림톡과 연동한다.

## 1. 핵심 개념

- **시험지 목록(라이브러리)**: 미리 만든 시험지 파일들의 카탈로그. 한 번 만들면 안 바뀐다.
- **응시 기록**: 누가 언제 어떤 시험지를 봤고 몇 점인지. 계속 쌓인다. (OS의 기존 `테스트 관리` 기능을 확장)
- 두 축을 분리한다. 시험지는 재생성하지 않는다.

## 6. 재시험 · 알림톡 연동 (기존 체인 활용)

- 기존: `record.needsRetest` → 보충관리가 `retest` 태스크 생성 → 날짜·시간 예약 → "재시험 안내" 알림톡 문구 생성.
- 학부모/학생 알림톡 본문에 `재시험 일정` 항목이 이미 있음.
- 확장 지점: 5번의 자동 `needsRetest`가 이 체인의 입력이 되도록 연결. 재시험지는 같은 단원의 다른 난이도(또는 동일) 시험지를 목록에서 지정.
