## 0. 목표

1. 학생 단원별 평가 시험지를 **미리 만들어 파일로 고정**하고, 여러 학생·여러 시점에 그대로 재사용한다.
2. 시험지를 OS 프로그램에 목록으로 등록하고, 학생 테스트(데일리/단원)를 진행한다.
3. 테스트 결과를 토대로 점수·재시험 여부·재시험 일정을 알림톡과 연동한다.

## 1. 핵심 개념

- **시험지 목록(라이브러리)**: 미리 만든 시험지 파일들의 카탈로그. 한 번 만들면 안 바뀐다.
- **응시 기록**: 누가 언제 어떤 시험지를 봤고 몇 점인지. 계속 쌓인다. (OS의 기존 `테스트 관리` 기능을 확장)
- 두 축을 분리한다. 시험지는 재생성하지 않는다.

## 4. 워터마크

- 모든 페이지에 "으뜸수학학원" 텍스트 + 로고 이미지 삽입. 로고 PNG는 사용자 제공(대기 중).
- 위치: **대각선 반투명 중앙** (확정). 페이지 중앙에 약 45° 회전, 낮은 불투명도.
- 방식: Node 스크립트 + `pdf-lib`. 원본 PDF 로드 → 전 페이지 반복 → 회전·반투명 로고·텍스트 그림 → `*_wm.pdf` 저장.
- 실행: (a) 폴더 배치 처리 CLI, (b) OS 업로드 시 서버 자동 삽입 후 저장. 둘 다 가능.
- 매쓰플랫/수학비서 중 무엇으로 만들었는지와 무관하게 동일 처리.

## 5. 테스트 진행 (기존 기능 확장)

- OS `테스트 관리`: 반·날짜·학생별 응시 상태·정답 수 기록, `/api/test-sessions` 저장, 학생별 이력.
- 확장 지점: 응시할 시험지를 3번 목록에서 선택 → 세션에 시험지 ID·총문항 자동 연결.
- 점수 저장 시 컷라인 적용 → `needsRetest` 자동 설정. 컷라인 기준 `TBD` (예: 정답률 X% 미만).

## 6. 재시험 · 알림톡 연동 (기존 체인 활용)

- 기존: `record.needsRetest` → 보충관리가 `retest` 태스크 생성 → 날짜·시간 예약 → "재시험 안내" 알림톡 문구 생성.
- 학부모/학생 알림톡 본문에 `재시험 일정` 항목이 이미 있음.
- 확장 지점: 5번의 자동 `needsRetest`가 이 체인의 입력이 되도록 연결. 재시험지는 같은 단원의 다른 난이도(또는 동일) 시험지를 목록에서 지정.

### 확정됨

- 과정(선행/현행) 구분 안 함, 난이도 2단계.
- 단원테스트 난이도1 = 베이직쎈 단원마무리(소단원 12문항). 난이도2 = `쎈B 단원마무리` 대체 교재(미정).
