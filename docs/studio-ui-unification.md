# 시험분석 · SNS UI 정리

## 기능 위치 대응

| 기능 | 현재 → 개선 |
| --- | --- |
| 시험 원본·문항 구조·AI 분석·검수·미리보기·기록 | 기존 7단계 탭 유지, 단계별 작업 안내와 검수 원본 참고 제공 |
| 시험 산출물·복사·TXT·ZIP·프롬프트 | 기존 위치 유지, 최종 문구에 공통 채널 선택·미리보기 적용 |
| SNS 자료·성적 가져오기·동의·사실 확인 | 자료 준비 유지, 공통 제목·단계·요약 표현 |
| Chat 전달·JSON 가져오기 | 전달 단계 유지, 가져오기는 취소 가능한 모달에서 미리보기 후 반영 |
| SNS 본문·캡션·카드·링크·태그 | 완성본 내 채널 탭, 공통 편집/미리보기, 추천·직접 편집 유지 |
| SNS 확정본·이력·발행 기록 | 기존 저장·이력 유지, 저장 상태 바 고정 |

재사용: PageHeader, WorkspaceTabs, StickySaveBar, Modal, Disclosure. 공통 추가는 표현용 편집/미리보기와 모달 내부 초점 관리이며 API·DB·CAS·도메인 저장은 합치지 않는다.

대표 동선은 시험 기본정보→문항수→검수→프롬프트/산출물 저장과 SNS 자료→Chat→JSON 미리보기/취소/반영→채널 편집→서버 저장/새로고침이다. 유료 분석은 실행하지 않고 가상 데이터 검수를 사용한다. 기존 시험 산출물 기능은 이동·삭제하지 않는다. 두 화면 간 자료 연결은 후속 제안이다.


## 검증 결과와 제한

- 변경 전 focused safe browser 5/5 통과. 변경 후 SNS 자료·Chat·모달 취소/반영·태그 패널·채널 전환·저장/재조회/새로고침·409/불일치 보존, 시험 기본정보·문항 수·검수·프롬프트·채널별 산출물 저장/재조회/새로고침을 확인했다.
- PC 편집/미리보기 동시 표시, 390px에서 편집/미리보기 전환과 가로 넘침 없음 확인. 모달 Escape 취소 후 호출 버튼으로 초점 복귀 확인.
- 관련 output-draft-contract, prompt-studio-draft, blog-hybrid, pipeline-boundary, CSS-domain-split fixture 통과. check:fast(lint·828 scenario·build) 통과, 초기 main 947.94KB로 기존 예산 내.
- 원본 참고는 가상 source 응답과 대체 뷰어를 사용하여 선택·iframe URL·원본 열기 링크를 확인했다. 실제 운영 PDF 업로드, PDF 렌더러 호환성, 유료 AI 분석·재실행, 실제 외부 발행은 실행하지 않았다. 이 경계의 기존 구현은 변경하지 않았다. 전체 업로드부터 AI 분석까지 운영 E2E가 통과했다고 주장하지 않는다.
- 비교 이미지: 로컬 `C:/Users/PC/.codex/worktrees/studio-ui-evidence/`의 before/after-mobile, before/after-desktop, exam-desktop, exam-mobile, import-dialog PNG. before 이미지는 이번 branch의 UI 수정 전 SNS 가상 화면이다. 시험분석은 변경 후 화면만 기록했으며 변경 전후 코드는 diff로 대조했다.
- 클릭 수 감소를 수치로 측정하지 않았다. 채널별 필드 분리와 태그 추천 패널로 기본 편집 화면의 노출 항목을 줄였으며 기존 복사·버전·발행 URL·프롬프트·다운로드 기능은 유지한다.
- 모달과 추천 패널만 임시 UI 상태를 갖는다. 콘텐츠 값은 기존 도메인 편집 원천을 그대로 사용한다. 가져오기 취소는 기존 편집값을 건드리지 않으며, 태그 반영은 편집본에 적용 후 별도 저장한다.
