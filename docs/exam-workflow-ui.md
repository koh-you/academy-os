# 시험분석 작업 흐름 UI

## 문제와 변경

산출물에서 여러 입력 묶음이 동시에 펼쳐지고, 최종 미리보기 아래 프롬프트 편집이 계속 이어져 화면이 길었다. 모든 단계에서 학교·학년·고사·분석 선택 목록도 상단을 차지했다.

| 기존 위치 | 개선 위치 / 보존 기능 |
| --- | --- |
| 분석 목록 상시 표시 | 원본 단계 기본 표시, 다른 작업에서는 접힘. ‘다른 분석 선택’으로 재접근 |
| 7개 단계 탭 | PC 유지, 모바일 작업 단계 선택 메뉴. 상단 4개 전체 흐름과 현재 작업 안내 |
| 동시에 열린 산출물 입력 | 총평 메모·글 구성·주요문항·Chat 전달·완성본·공개/작성 기준 선택 |
| 작은 반복 안내 | 작성 도움말 토글. 오류와 고정 저장 상태는 계속 표시 |
| 미리보기 아래 프롬프트 전체 | ‘카드 제작 작업 열기’, 내부 역할별 펼치기 |
| 긴 완성본 입력칸 | 기본 10행, 필요하면 크기 조절 가능. 블로그/인스타 편집·복사/TXT 유지 |

원본/PDF 등록, 추출·검증, 문항 수/경계 확정, AI 분석/수정, 문항 검수, 최종 미리보기, 프롬프트·ZIP·작성 규칙·공개 범위·주요문항·기록 기능은 삭제하지 않았다. 탭과 접힘은 표시만 바꾸며 입력 state와 저장 계약을 이동하지 않았다. 새로운 AI 실행이나 운영 쓰기는 없다.

## 검증

변경 전 기존 가상 시험분석 시나리오 통과. 변경 후 검수·프롬프트·산출물 저장/서버 재조회/새로고침, 산출물 그룹 전환 후 총평 유지, 도움말 토글, 모바일 단계 전환 후 검수/카드 편집본 유지와 가로 넘침을 확인한다. 원본 참고는 기존 가상 응답이며 유료 AI·실제 운영 PDF 업로드는 실행하지 않는다.
