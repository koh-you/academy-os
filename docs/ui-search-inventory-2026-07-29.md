# UI-3D 검색 인벤토리 — 2026-07-29

| 화면 | 검색 state | 기존 normalization·결과 | 공통 표시 |

## 공통 규칙

- `SearchField`는 controlled value를 가공하지 않고 `onChange(nextValue)`에 그대로 전달한다. 문자열 정규화와 결과 계산은 각 화면에 남긴다.
- label, 결과 건수, `type=search`, 32px 지우기 버튼, focus-visible을 같은 구조로 사용한다. 390px에서는 입력 높이를 44px로 유지한다.
- 지우기는 기존 setter에 빈 문자열만 전달한다. 선택 학생, 반, 고사, 저장 draft, 모달 open state는 변경하지 않는다.
- 0건 안내는 검색어가 있는 경우와 원천 자체가 비어 있는 경우를 구분한다.
- 검색 UI 검수 과정에서 발송·저장·업로드·등록·삭제·보충 되돌리기는 실행하지 않는다.

## 사람 검수

필수 중단 gate는 없다. 배포 후 각 검색창에 일부 이름/학교를 입력하고 결과 건수와 목록이 함께 줄어드는지, `×`로 지웠을 때 기존 전체 목록이 복귀하는지 확인한다. 390px에서는 입력과 지우기 버튼이 잘리지 않아야 한다. 선택·저장·발송·업로드·되돌리기 버튼은 누르지 않는다.
